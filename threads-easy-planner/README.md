# ✏️ Threads AI 기획기 (threads-easy-planner)

초보자도 버튼 하나로 완성하는 **스레드(Threads) AI 글 기획 및 바이럴 포스팅 자동화 프로그램**.  
복잡한 프롬프트 작성이나 설정 없이, 주제/소재를 입력하고 **가전 주부형·독신형·워킹맘형 등 원하는 상황별 페르소나 버튼을 누르면**  
피드를 멈추는 **5대 훅(자책/부정명령/썰/논쟁/반전)부터 4단계 공감 본문, 첫 댓글(자댓글) CTA, 후속 아이디어 5선**까지 3초 만에 완성합니다.

---

## Mobile and desktop support (v1.19)

- The service uses a single responsive interface: the desktop sidebar becomes a compact mobile header and fixed bottom tabs below the `md` breakpoint.
- Topic input, persona generation, saved plans, access checks, and AI-key handling stay on the same routes and server actions for every device.
- On mobile, a fixed bottom action runs the same planner generation flow; the extra bottom spacing prevents it from covering content.
- Provider and model controls are kept in the collapsible advanced-AI settings section to prioritize the fast mobile creation flow.

## 🎯 핵심 기능 및 워크플로우

### 1. 다양한 상황별 페르소나 원클릭 글 생성 (6대 핵심 페르소나)
키워드나 소재를 입력하고(또는 비워둔 채로) 원하는 페르소나 버튼을 클릭하면, 그 페르소나의 직업, 시점, 상황, 고유한 어조가 프롬프트에 100% 주입되어 생생한 1인칭 썰 글이 즉시 완성됩니다:
- 👩‍🍳 **가전·살림 주부형** `[살림 9단 꼼꼼 비교]`
  - 살림/가전 필수템, 가성비·내구성 찐후기, 남편/아이 실생활 활용도 중심의 동네 이웃/언니 실속 톤
- 🏠 **독신·자취생형** `[2030 자취 찐현실 썰]`
  - 퇴근 후 설거지/청소 귀차니즘, 원룸 생존 꿀팁, 배달비 절약 중심의 솔직담백 20대 자취생 톤
- 💼 **워킹맘·직장인형** `[퇴근길 지친 30대 공감]`
  - 회사 업무 + 육아/살림 병행의 피로를 덜어주는 시간 단축 꿀팁, 퇴근길 지하철 공감 친한 언니 반말 톤
- 💄 **20대 쇼핑·뷰티 에디터형** `[감성 추천 & 종결템 썰]`
  - "이거 비싼 건 줄 알았는데;; 가성비템이었다니...", 버릴 색/버릴 템 없는 인생템 종결 톤
- ⚡ **IT·테크 리뷰어형** `[팩트 분석 & 스펙 비교]`
  - 스펙 분석, 3주간 실사용 장단점, "모르면 평생 손해 보는" 논리 팩트 분석 톤
- 💰 **N잡러·재테크 부업형** `[자본주의 현실 극복]`
  - 통장 잔고 현실, 월 100 추가 파이프라인 만드는 자본주의 현실 실행 톤

### 2. "🎲 오늘 뭐 쓰지?" 업종별 10선 추천 주제 발굴
- 주제 선정이 막막할 때 클릭 시 **10대 인기 업종/타깃 칩** 제공
  (`자취/생활꿀팁`, `직장인/이직`, `부업/재테크`, `IT/테크`, `뷰티/패션`, `자기계발`, `맛집/여행`, `육아/살림`, `인간관계`, `1인사업/마케팅`)
- 4대 심리(공감·손해회피·호기심·반전) 기반으로 알고리즘 반응이 가장 뜨거운 주제 10개 실시간 발굴
- 추천 카드 클릭 시 해당 주제로 즉시 글 생성 직행

### 3. 실전 52만 회 & 1.6만 회 떡상글 벤치마킹 구조
실제 스레드에서 폭발적인 조회수와 댓글을 기록한 실전 사례를 분석하여 프롬프트에 완벽히 이식했습니다:
- **4단계 황금 구조**: [피드 멈추기] → [공감 쌓기] → [반전/체험] → [해결 종결]
- **극압축 가독성 호흡**: 4~6줄 짧은 문장 + 1~2줄 단위 빈 줄(`\n\n`) 단락 구분
- **스레드 날것의 감정 부호**: `;;`, `...`, `??`, `ㅠㅠ`, `땅땅!` 및 커뮤니티 호칭(`스치니`, `치니`)
- **본문 제품명 노출 금지**: 본문에서 특정 상업적 브랜드명을 숨겨 호기심을 극대화하고, **첫 댓글(자댓글)로 제품명과 링크를 푸는 스레드 실전 떡상 공식** 적용

### 4. 5대 바이럴 훅 유형별 대안 세트
대표 글 1개 외에도 각각 다른 심리를 자극하는 5대 훅 유형 대안 글을 동시에 생성합니다:
1. **자책형**: "아 나 진짜 멍청하게 왜 여태...", 솔직한 자책과 현실 고백
2. **부정 명령형**: "워싱소다 백식초 이런 거 다 소용없더라 제발 사지 마", 손해 회피
3. **리얼 썰형**: "치니 추천글 보고 주문했거든?? 물색깔 보고 기절함....", 1인칭 리얼 경험담
4. **논쟁형**: "솔직히 A vs B 뭐가 맞음?", 댓글 토론 유발
5. **반전형**: "이거 비싼건줄 알았는데;; 가성비템이었다니...", 상식 파괴
- 결과 화면에서 각 훅 유형별 본문 미리보기, 개별 복사, 원클릭 본문 즉시 적용 지원

### 5. 7종 "다시 써줘" 원클릭 리라이팅
- ⚡ **더 자극적으로** (반전과 호기심 극대화)
- 🌿 **더 자연스럽게** (편안한 이웃/친구 일상 대화체)
- ✂️ **더 짧게** (군더더기 없는 핵심 3줄 압축)
- 🎓 **더 전문적으로** (신뢰도 높은 인사이트 톤)
- 🤣 **더 웃기게** (유머와 B급 밈, 드립)
- 🛡️ **광고 느낌 빼기** (100% 내돈내산 찐후기 감성)
- 🎯 **후킹만 다시 만들기** (첫 문장 후킹만 집중 업그레이드)

## 🛠️ 기술 스택 및 연동 규격

- **프레임워크**: Next.js 16 (App Router, Turbopack), React 19, TypeScript
- **스타일링**: Tailwind CSS v4
- **인증 및 권한**: AIMaster 공용 Supabase (`profiles`, `programs`, `subscriptions`, `user_program_access`)
- **BYOK 원칙**: 회원이 등록한 본인 API 키(`user_api_keys`) 사용, 관리자 키 폴백 금지
- **사이드바 표준**: 21개 프로그램 공통 규격 준수 (메뉴 바로 아래 계정 표시 및 로그아웃)
- **캐싱 방지**: 레이아웃 및 동적 라우트에 `force-dynamic`, `force-no-store` 선언 준수
