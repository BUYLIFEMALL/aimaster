# ✏️ Threads AI 기획기 (threads-easy-planner)

초보자도 버튼 하나로 완성하는 **스레드(Threads) AI 글 기획 및 바이럴 포스팅 자동화 프로그램**.
복잡한 프롬프트 작성이나 설정 없이, 주제를 입력하거나 "오늘 뭐 쓰지?" 버튼을 클릭하면
스레드 피드에서 스크롤을 멈추는 **첫 문장 후킹부터 본문, 댓글 CTA, 후속 시리즈 아이디어**까지 한 번에 완성합니다.

---

## 🎯 핵심 기능

1. **주제 입력 또는 "🎲 오늘 뭐 쓰지?" 추천**
   - 직접 키워드/주제 입력 가능
   - "오늘 뭐 쓰지?" 클릭 시 10개 대표 업종/타깃 칩(자취, 직장인, 부업, IT, 뷰티 등) 제공
   - 타깃별 지금 가장 반응 좋은 스레드 주제 10개 실시간 추천 & 클릭 시 즉시 글 생성

2. **5단계 원클릭 글 생성**
   - 🎯 **1. 스레드 주제**: 콘텐츠의 핵심 테마
   - ⚡ **2. 첫 문장 후킹**: 피드 스크롤을 1초 만에 멈추게 하는 강력한 첫 문장
   - 📝 **3. 전체 본문**: 모바일 가독성 최적화 줄바꿈, 450자 이내의 깔끔한 완결
   - 💬 **4. 마지막 댓글/CTA**: 알고리즘 참여를 폭발시키는 댓글 유도 질문
   - 💡 **5. 후속 콘텐츠 아이디어 (5선)**: 시리즈로 이어서 올릴 수 있는 다음 주제 제안
   - 영역별 원클릭 복사 버튼 제공

3. **7종 "다시 써줘" 원클릭 리라이팅**
   - ⚡ **더 자극적으로** (반전과 호기심 극대화)
   - 🌿 **더 자연스럽게** (편안한 이웃/친구 일상 대화체)
   - ✂️ **더 짧게** (군더더기 없는 핵심 3줄 압축)
   - 🎓 **더 전문적으로** (신뢰도 높은 인사이트 톤)
   - 🤣 **더 웃기게** (유머와 B급 밈, 드립)
   - 🛡️ **광고 느낌 빼기** (100% 내돈내산 찐후기 감성)
   - 🎯 **후킹만 다시 만들기** (본문은 유지하고 첫 문장 후킹 5종 업그레이드)

---

## 🛠️ 기술 스택 및 구조

- **프레임워크**: Next.js 16 (App Router), React 19, TypeScript
- **스타일링**: Tailwind CSS v4
- **인증 및 권한**: AIMaster 공용 Supabase (`profiles`, `programs`, `subscriptions`, `user_program_access`)
- **AI 엔진**: OpenAI (GPT-4o, GPT-4.1), Google Gemini (Gemini 2.5 Flash), Anthropic Claude (Claude 3.5 Sonnet)
- **BYOK 원칙**: 회원이 등록한 본인 API 키(`user_api_keys`) 사용, 관리자 키 폴백 없음
