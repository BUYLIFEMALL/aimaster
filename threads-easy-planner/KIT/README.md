# ALLA AI — 설치 안내서 (독립 운영판)

> **ALLA AI**는 Threads(스레드) 글 기획 자동화 프로그램입니다(폴더 이름은 `threads-easy-planner`).

> 수강생 배포 키트 · 2026-10-23 · 윈도우·맥 공통
> 내 컴퓨터에 압축을 풀고 → **패키지 설치마법사**를 더블클릭해 내 계정(Supabase·Vercel)으로 설정하면 → **내 사이트에서 Threads 글감 추천·글 세트 생성·다시 쓰기·보관함**을 바로 씁니다.
> AIMaster와 연결되는 부분은 없습니다. 모든 계정·키·데이터는 수강생 본인 것입니다.

**이 프로그램이 하는 일**
- 「오늘 뭐 쓰지?」 — 분야를 고르면 AI가 스레드 주제 10개를 추천(공감·손해회피·호기심·반전 4대 심리 기준)
- 주제 하나로 **대표 글 1개 + 첫 문장(훅) 유형 5가지 글**(자책형·부정 명령형·리얼 썰형·논쟁형·반전형)을 한 번에 생성
- 사진·짧은 영상을 올리면 그 장면을 보고 1인칭 경험담으로 글을 씀
- **글과 함께 이미지 자동 생성**: 글이 나오면 그 내용에 맞는 생활 사진 느낌 이미지를 1~2장 바로 만듦(나노바나나 = Gemini 키 / GPT Image = OpenAI 키), 다운로드·다시 만들기·프롬프트 고치기
- 「더 자극적으로·더 자연스럽게·더 짧게·광고 느낌 빼기」 등 7가지 원클릭 다시 쓰기
- 만든 글과 이미지를 **내 콘텐츠 보관함**에 저장(30일 보관 뒤 자동 삭제)
- 게시는 직접 복사해서 Threads에 붙여 넣는 방식입니다(자동 게시 기능은 없습니다 — 그래서 Meta 앱을 만들 필요가 없습니다).

함께 들어 있는 파일

## 0. 준비물 (처음 한 번)

| 무엇 | 어디서 | 비용 |

| **Supabase 계정** | https://supabase.com (DB·로그인) | 무료 플랜 |

## 1. 압축 풀기 · 폴더 정하기

1. 압축 파일을 풉니다(윈도우: 마우스 오른쪽 → [압축 풀기]). 이 프로그램은 `threads-easy-planner` 폴더입니다.
2. 원하는 곳으로 옮깁니다. 예: 윈도우 `D:\work\planner`, 맥 `~/work/planner`
   - **경로에 한글·공백 없이, 짧게**(윈도우는 경로가 길면 빌드가 실패합니다). **GitHub 저장소 폴더 안에는 풀지 마세요.**

## 2. 패키지 설치마법사 실행 (DB 만들기부터 인터넷에 올리기까지 한 번에)

프로그램 폴더 맨 위에 있는 실행 파일을 **더블클릭**합니다.

- **윈도우**: `패키지설치마법사.cmd` 더블클릭 (「Windows의 PC 보호」 창이 뜨면 [추가 정보] → [실행])
- **맥**: `패키지설치마법사.command` 더블클릭 (「확인되지 않은 개발자」 창이 뜨면 마우스 오른쪽 클릭 → [열기] → [열기], 처음 한 번만)

마법사가 8단계를 차례로 안내합니다. **필요한 화면은 마법사가 브라우저로 직접 열어 주고, 붙여 넣을 내용은 클립보드에 복사해 둡니다.**

| 단계 | 마법사가 하는 일 | 내가 할 일 |
|---|---|---|
| ① Node.js | 설치돼 있는지 확인(윈도우는 없으면 자동 설치 제안) | 설치 후 마법사 다시 실행 |
| ② Supabase 프로젝트 | 프로젝트 목록 열기(이미 조직이 있으면 그 조직의 [New project] — 새 조직 만들지 않기) | 이름·DB 비밀번호(Generate 후 메모)·지역 **Asia-Pacific**(서울은 Need a specific region?) → 생성 → **주소창 주소 붙여넣기** |
| ③ Supabase 키 | API Keys 화면 열기, **맞는 키인지 자동 확인** | Publishable key → Secret key 순서로 붙여넣기(화면에 안 보임) |
| ④ DB 만들기 | 설치 SQL을 **클립보드에 복사**하고 SQL Editor 열기, 끝나면 **성공 여부 자동 확인** | 빈 칸 클릭 → 붙여넣기 → [Run] |
| ⑤ 이메일 확인 끄기 | Sign In / Providers 화면 열기 | 맨 위 User Signups 칸의 **Confirm email 끄기** → Save |
| ⑥ 내 사이트 설정 | 주소·비밀값 자동 생성 | 사이트 이름(영문 소문자, 주소가 됨) · 화면 위쪽(탭 제목)에 보일 내 이름/브랜드 |
| ⑦ 설치·빌드 | 프로그램 설치·확인(3~5분) | 기다리기 |
| ⑧ 인터넷에 올리기 | Vercel 연결·설정 등록·배포, **실제 주소 자동 확인**, 로그인 주소 설정 화면 열기 | 브라우저에서 Vercel 로그인(처음이면 무료 가입) · 마법사가 연 Supabase URL Configuration에 주소 붙여넣기 |

- 중간에 창을 닫아도 **다시 더블클릭하면 이어서** 진행합니다(처음부터 하려면 질문에 `n`).
- 끝나면 내 사이트가 열리고, 프로그램 폴더에 **`설치결과.txt`**(내 사이트 주소)가 생깁니다.

## 3. 설치 확인 · (선택) 관리자 지정

- Supabase **Table Editor**에 `tep_saved_plans`가 보이고, `https://내주소/login`에서 **[회원가입] 탭 → 가입 → 로그인**이 되면 설치 성공입니다.
- ⑤단계에서 Confirm email을 끄지 않았다면 가입 확인 메일의 링크를 눌러야 로그인됩니다.

**(선택) 내 계정을 관리자로**: Supabase SQL Editor에서
`update public.profiles set is_admin = true where email = '내이메일@example.com';`
(이 프로그램은 관리자 전용 화면이 없어 하지 않아도 됩니다.)

> 마법사가 안 될 때만(고급): `KIT/env.example`을 `.env.local`로 복사해 값을 채우고 `npm install` → `npm run build` → `npx vercel@latest deploy --prod` 후 Vercel **Settings → Environment Variables**에 같은 값을 넣고 다시 배포합니다. **AI 코딩 도구에 설치를 맡기지 말고** 마법사를 직접 실행하세요(마법사는 사람이 답을 입력하는 방식입니다).

## 4. 플랫폼 앱 만들기 — 이 프로그램은 필요 없습니다

이 프로그램은 글을 **만들어 주는** 도구이고, Threads에 자동으로 올리지 않습니다. 그래서 Meta(Threads) 개발자 앱을 만들 필요가 없습니다. 만든 글은 [복사] 버튼으로 복사해 Threads 앱에 붙여 넣어 게시합니다.

## 5. AI 키 등록 · 첫 글 만들기

내 사이트 → 좌측 **🔑 API키 등록·관리**
1. OpenAI·Gemini·Claude 중 **1개만 저장해도** 바로 쓸 수 있습니다(발급 방법: `KIT/PLATFORMS.md`).
2. 좌측 **✏️ 스레드 기획기** → 세 가지 중 편한 방법으로 시작합니다.
   - 소재 칸에 쓰고 싶은 내용을 적고 **글 생성하기**
   - **🎭 상황별 페르소나 원클릭 생성** 버튼(자취생·직장인 등 글쓴이 역할을 골라 바로 생성)
   - 아무 생각이 없을 때: **원클릭 랜덤 썰 뽑기 · 3초 무드 픽 · 📁 업종/타깃별 추천 주제 10선**(분야를 고르고 추천 주제 하나 클릭)
3. **🖼 글과 함께 이미지 만들기**가 켜져 있으면(기본 켬) 글이 나온 뒤 이어서 이미지가 만들어집니다(1~2분). 모델·비율(세로 4:5 / 정사각 1:1)·장수(1~2장)는 생성 화면의 이미지 설정 칸에서 고릅니다. 마음에 안 들면 **이미지 다시 만들기**·**이 장만 다시**, 직접 고치려면 **프롬프트 보기·고치기**.
4. 결과 카드에서 대표 글과 첫 문장 유형 5가지 글을 비교 → 필요하면 **다시 써줘** 버튼으로 다듬기 → **보관함에 저장하기** → **복사하기** 후 Threads 앱에 붙여 넣기(이미지는 **⬇ 다운로드**해서 첨부)
5. **AI 추론 엔진 및 모델 설정**에서 모델을 고를 수 있습니다. 시험할 때는 저렴한 모델(예: GPT-4o-mini, Gemini 3.5 Flash Lite)을 쓰면 비용이 거의 들지 않습니다.

> 사용 순서 전체는 내 사이트의 **📖 사용 매뉴얼** 화면에도 있습니다.

## 7. (선택) 내 도메인 연결

1. Vercel → 프로젝트 → **Settings → Domains → Add** → 내 도메인 입력(예: `planner.hong.com`)
2. 안내대로 도메인 회사 DNS에 기록 추가(보통 `CNAME` → `cname.vercel-dns.com`, 루트 도메인은 `A` → `76.76.21.21`) → Vercel에서 **Valid** 확인
3. 주소가 바뀌었으니 아래를 **새 주소로** 고칩니다.
   - Vercel **Environment Variables**의 `NEXT_PUBLIC_SITE_URL` → 수정 후 **Redeploy**
   - Supabase **Authentication → URL Configuration**: Site URL을 새 주소로, Redirect URLs에 `https://새주소/**` 추가
   - 내 컴퓨터 `.env.local`의 `NEXT_PUBLIC_SITE_URL`

## 8. 자주 막히는 곳

| 증상 | 확인 |
|---|---|
| 회원가입 후 「가입 확인 메일을 보냈습니다」만 나오고 로그인이 안 됨 | Supabase **Authentication → Sign In / Providers → Confirm email 끄기**(또는 메일의 링크 누르기) |
| 확인 메일 링크를 눌렀더니 `localhost`로 감 | Supabase **Authentication → URL Configuration**에 Site URL = 내 주소, Redirect URLs = `내주소/**` |
| 「API 키 등록이 필요합니다」 | 좌측 **API키 등록·관리**에서 키 1개 저장 |
| 「키가 올바르지 않거나 인증에 실패」 | 키 앞뒤 공백 없이 다시 복사. Claude는 `sk-ant-api03-…` 키(워크스페이스 선택 후 발급)만 동작 |
| 「크레딧(잔액)이 부족」 | 해당 AI 사이트에서 결제 수단·충전 확인, 또는 Gemini 무료 키로 바꾸기 |
| 선택한 모델로 오류 | 위쪽 모델 선택에서 기본 추천 모델(GPT-4.1·Gemini Flash 등)로 바꿔 보기 — 내 키 계정에서 아직 열리지 않은 모델일 수 있습니다 |
| 마법사 ⑦ 빌드 실패 | 폴더 경로가 길거나 한글·공백이 있는지 확인 → 짧은 영문 경로로 옮긴 뒤 다시 실행 |
| 사이트가 다른 사람 주소로 이동함 | Vercel 환경변수 `NEXT_PUBLIC_STANDALONE_MODE`가 정확히 `true`인지 확인 → Redeploy |
| 이미지 칸에 「API 키가 필요합니다」 | 나노바나나는 Gemini 키, GPT Image는 OpenAI 키가 필요합니다 — 가진 키에 맞는 이미지 모델로 바꾸기 |
| 이미지 칸에 「저장하지 못했습니다」 | v1.01로 설치했다면 `KIT/upgrade-20261023-images.sql`을 Supabase SQL Editor에서 한 번 실행 |
| GPT Image에서 권한 오류 | OpenAI 조직 인증이 필요한 모델일 수 있음 — GPT Image 1 Mini 또는 나노바나나로 바꾸기 |
| 저장한 글이 다른 컴퓨터·브라우저의 보관함에 안 보임 | DB 저장이 실패하면 그 브라우저에만 임시 저장됩니다 — ④단계 SQL이 끝까지 실행됐는지(Table Editor에 `tep_saved_plans`) 확인 |
