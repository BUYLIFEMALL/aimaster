## 1. 우선순위별 개발 대기 과제

| 우선순위 | 구분 | 과제명 | 세부 내용 및 예상 효과 | 상태 |
|:---:|:---:|---|---|:---:|
| **P1** | 기능 | **스레드 500자 타래 분할기 (Thread Splitter)** | 500자 초과 시 1/2, 2/2 카드로 자동 슬라이스 분할하여 원클릭 복사 제공 | 대기 중 |
| **P1** | UI | **실시간 글자 수 카운터 & 칩** | 공백 포함/제외 글자 수, 줄바꿈 수, 읽기 시간 실시간 배지 표시 | 대기 중 |
| **P2** | 연계 | **threads-content-ops 보관함 내보내기** | 기획한 글을 27번 프로그램 스케줄러로 원클릭 전달 | 대기 중 |
| **P2** | 테마 | **퓨어 다크 테마(옵시디언 블랙) 토글** | 야간 크리에이터를 위한 인앱 다크 모드 전환 기능 | 대기 중 |
| **P3** | 기능 | **A/B 훅 성과 추적 메모** | Threads에 실제 발행 후 반응이 좋았던 훅을 메모하고 분석하는 기능 | 대기 중 |
