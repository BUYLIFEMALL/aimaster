# Threads AI 기획기 모바일 UI 작업 매뉴얼

최종 갱신: 2026-10-05

이 문서는 `threads-easy-planner`의 모바일·PC 공용 화면을 수정할 때 지켜야 할 구조와 검수 기준입니다. 모바일 전용 서비스가 아니라 같은 기능을 화면 폭에 맞게 재배치하는 반응형 UI입니다.

## 화면 구조

| 화면 폭 | 내비게이션 | 기획 화면 핵심 동작 |
| --- | --- | --- |
| `md` 이상(PC) | `Sidebar.tsx` 좌측 고정 사이드바 | 넓은 입력·결과 비교 화면 |
| `md` 미만(모바일) | `MobileNavigation.tsx` 상단 헤더 + 하단 탭바 | 주제 입력 → 페르소나 선택 → 하단 고정 생성 버튼 |

- 모바일 하단 탭은 `기획하기(/)`, `보관함(/saved)`, `설정(/settings)` 세 메뉴입니다.
- 모바일 상단 헤더에는 프로그램명·버전·사용 가이드 링크를 둡니다.
- PC의 좌측 사이드바와 모바일 내비게이션을 동시에 보이게 하면 안 됩니다. `Sidebar`는 `md` 이상에서만 표시합니다.

## 기능 공용 원칙

1. PC와 모바일은 동일한 URL, 로그인·이용 권한, Server Action, API 키, 보관함 데이터를 사용합니다.
2. 모바일 하단의 `이 내용으로 글 생성하기` 버튼은 별도 로직을 만들지 않고 `PlannerApp.handleGenerate()`를 호출합니다.
3. 따라서 API 키가 없을 때 안내 모달, 생성 중 상태, 결과 저장과 오류 처리는 PC와 모바일에서 항상 동일해야 합니다.
4. 모바일 전용 API·테이블·권한 판정은 만들지 않습니다.

## 모바일 우선 UX 규칙

- 첫 화면은 주제 입력, 추천/생성, 페르소나 선택을 우선 노출합니다.
- 제공사·모델 선택은 `고급 AI 설정` 접기 영역에 둡니다. 기본 생성 흐름을 가리지 않게 합니다.
- 하단 고정 요소가 본문·결과·모달을 가리지 않도록 `PlannerApp` 본문에 모바일 하단 여백(`pb-28`)을 유지합니다.
- 모바일 고정 생성 버튼은 하단 탭바 바로 위에 두고, 탭바보다 낮은 z-index를 사용합니다.
- 터치 버튼은 충분한 높이와 여백을 유지하고, 긴 텍스트는 줄바꿈 또는 말줄임으로 처리합니다.

## 관련 파일

- `src/components/layout/Sidebar.tsx` — PC 전용 사이드바
- `src/components/layout/MobileNavigation.tsx` — 모바일 상단 헤더·하단 탭바
- `src/app/(dashboard)/layout.tsx` — 두 내비게이션의 표시 위치 및 본문 하단 여백
- `src/components/planner/PlannerApp.tsx` — 고급 설정 접기·모바일 고정 생성 버튼·생성 로직

## 변경 후 검수

1. 375px 폭에서 상단 헤더, 하단 탭바, 고정 생성 버튼이 동시에 보이는지 확인합니다.
2. 모바일에서 생성 버튼을 눌러 기존과 같은 API 키 안내·생성 상태·결과 화면으로 이어지는지 확인합니다.
3. 보관함·설정 탭 이동 후에도 하단 탭의 활성 상태가 맞는지 확인합니다.
4. PC 폭에서 사이드바가 보이고 모바일 탭바가 숨겨지는지 확인합니다.
5. `npm.cmd run build`를 통과한 뒤, 로그인 세션으로 모바일 실기기 또는 브라우저 기기 모드에서 최종 확인합니다.
