## 1. 디자인 템플릿 개요
- **공식 스타일 템플릿 명칭**: **스레드 바이럴 스튜디오 스타일 — 기획기 변형 (Threads Viral Studio Style - Planner Variant)**
- **디자인 컨셉**: Meta Threads 공식 미니멀 모노톤을 베이스로 하여 텍스트 가독성을 극대화하고, 바이럴 파이어 앰버 및 일렉트릭 바이올렛 포인트를 결합하여 초보자도 직관적으로 버튼을 눌러 피드를 멈추는 글을 완성할 수 있도록 유도

## 3. 화면별 컴포넌트 구조 및 특징

### 1) 좌측 사이드바 (`Sidebar.tsx`)
- 공식 타이틀 `Threads AI 기획 자동화` 및 버전 뱃지(`v1.45`), `초간편판` 뱃지 고정
- 메뉴 구조:
  1. `✏️ 스레드 기획기` (메인 작업 스튜디오)
  2. `📁 내 콘텐츠 보관함` (저장된 글 불러오기 & 수정)
  3. `🔑 API키 등록·관리` (회원 본인 키 등록)
  4. `📖 사용 매뉴얼` (실전 순서 가이드)
- 하단 로그인 계정 정보 및 원클릭 로그아웃 바

### 2) 모바일 반응형 (`MobileNavigation.tsx`)
- 767px 이하 뷰포트에서 좌측 사이드바 자동 숨김
- 상단 고정 헤더: `@ Threads AI 기획 자동화` + `v1.45` + `📖 사용 매뉴얼` 바로가기
- 하단 고정 3탭 바: `기획하기`, `보관함`, `설정` (최소 높이 48px 이상 터치 보장)

### 3) 메인 기획 스튜디오 (`PlannerApp.tsx`)
- "오늘 스레드 뭐 쓰지? 🧐" 직관적 헤더
- 소재 입력창 + 사진(최대 5장) & 동영상(WebCodecs 핵심 5컷 정밀 추출) 시각 분석 업로더
- AI 엔진 선택 바 (OpenAI GPT-4.1, Gemini, Claude)
- 상황별 페르소나 원클릭 버튼 6종 (고부갈등, 살림주부, 독신자취, 워킹맘, 쇼핑에디터, IT리뷰어)
- 5대 첫 문장 훅 탭 (자책형, 부정명령형, 썰형, 논쟁형, 반전형)
- 7종 원클릭 다시 쓰기 및 보관함 저장/복사 바

### 4) 비주얼 사용 매뉴얼 (`/guide`)
- 한눈에 보는 핵심 작업 4단계 흐름도 (글감 선택 ➔ 원클릭 생성 ➔ 5대 훅 적용 ➔ 자동보관·CTA)
- 준비 단계(BYOK 회원 본인 API 키) 및 단계별 상세 실전 비법
- 트러블슈팅 FAQ 아코디언 제공

## 4. 검수 결과 및 주의사항
- **검수 브라우저**: Microsoft Edge 포그라운드(화면 노출) 실세션 검수 완료
  - 데스크톱 (1440px): `edge_threads_planner_desktop_main_v145.png`, `guide`, `saved`
  - 모바일 (375px): `edge_threads_planner_mobile_main_v145.png`, `guide`
- **주의사항**:
  - `threads-easy-planner`는 Next.js 16과 Tailwind v4를 사용하므로 CSS 커스텀 시 Tailwind v4 문법 규격을 유지할 것.
  - 외부 AI 호출은 반드시 회원 본인 등록 키(OpenAI/Gemini/Claude)만 사용하며 운영자 키 폴백을 절대 허용하지 않음.
