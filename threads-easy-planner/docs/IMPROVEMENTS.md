## 1. 해당 프로그램(threads-easy-planner) 추가개선 제안 (3대 핵심 항목)

### 1) 프로그램 로직 및 기능 개선
- **스레드 글자 수 카운터 및 분할 제안**:
  - Threads는 1회 게시물당 최대 500자 제한이 있습니다. 본문이 500자를 초과할 경우 자동으로 [이어지는 스레드 2/3편]으로 나누어 주는 **스레드 타래 분할(Thread Splitter)** 기능 추가 권장.
- **예약 발행 파이프라인 연동 지원**:
  - 현재 기획된 글을 보관함에 저장하거나 복사하여 수동으로 Threads 앱에 올리는 구조입니다. Meta Graph API를 이용해 사용자가 승인한 시간에 자동 예약 발행할 수 있는 API 연동 모드 옵션 추가 검토.

### 2) 사용자 인터페이스/UI 가독성 및 사용편리성 개선
- **다크 모드 지원 토글 추가**:
  - 현재는 클린 화이트/슬레이트 테마로 고정되어 있습니다. 밤 시간대 글을 쓰는 크리에이터를 위해 Threads 앱 특유의 퓨어 다크 테마 토글 버튼 추가 제안.
- **원클릭 글자 수 & 가독성 실시간 분석 칩**:
  - 에디터 상단에 실시간 공백 포함/제외 글자 수, 줄바꿈 수, 읽는 데 걸리는 예상 시간(초)을 배지 형태로 띄워 가독성 최적화를 직관적으로 지원.

### 3) 현재 만들어져 있는 다른 자동화 프로그램과의 연계가능한 기능
- **27번 Threads 콘텐츠 운영자동화 (`threads-content-ops`)와의 보관함 연계**:
  - `threads-easy-planner`에서 기획한 훅과 본문을 `threads-content-ops`의 주간 발행 스케줄러로 원클릭 내보내기(Export)할 수 있는 연계 파이프라인 구축.
- **46번 Threads 댓글자동화 (`threads-comment-reply`)와의 CTA 연계**:
  - 기획기에서 생성된 [첫 댓글 CTA 참여 질문]에 사용자들이 남긴 댓글을 46번 `threads-comment-reply`가 자동으로 감지하여 소통 댓글을 달아주는 크로스 플랫폼 자동화 워크플로우 제안.

## 2. 타 프로그램 탐색 기반 추가개선 제안 리포팅 (2026-10-17 지시 준수)

### 1) 31번 쇼츠 떡상 분석·대본 자동화 (`shorts-viral-studio`)
- **현황**: `DESIGN.md` 상 ⚪ 작업 예정 상태.
- **개선 제안**:
  1. **로직/기능**: 떡상 쇼츠 분석 시 `threads-easy-planner`의 5대 첫 문장 훅 알고리즘을 쇼츠 도입부(3초 이탈 방지 훅) 대본 생성에 이식하여 유튜브 쇼츠 시청 지속 시간을 극대화할 수 있음.
  2. **UI/UX**: 복잡한 대본 생성 단계를 `shorts-onestop-studio`처럼 단계별 프로그레스 바가 있는 플로우 위저드 스타일로 개편 필요.
  3. **연계**: 기획된 스레드 글을 31번 프로그램에 입력하면 60초 쇼츠 영상 대본으로 즉시 2차 가공해 주는 텍스트-투-쇼츠 파이프라인 연계 추천.

### 2) 44번 Threads 쇼핑제휴 자동화 (`threads-affiliate-poster`)
- **현황**: `DESIGN.md` 상 ⚪ 작업 예정 상태.
- **개선 제안**:
  1. **로직/기능**: 단순 상품 링크 나열이 아닌, `threads-easy-planner`의 [살림주부형/자취생형 솔직 실사용 썰] 템플릿을 제휴 글에 결합하여 스팸으로 차단되지 않는 자연스러운 스토리텔링 쿠팡 파트너스 글 생성 지원.
  2. **UI/UX**: 쿠팡 상품 검색창과 스레드 미리보기 창을 2열 스튜디오 형태로 배치하여 클릭률 높은 링크 카드 배치 유도.
