# 플레이리스트 채널 제작 자동화 — 사용 매뉴얼

> 대상: 이 프로그램을 쓰는 회원과, 회원 문의를 받는 운영 담당자. (개발·배포 인수인계는 [`AGENTS.md`](AGENTS.md))
> 주소: https://playlist-channel-studio.buylife.xyz · 현재 버전 v1.02 · FREE (가입 회원 누구나, 핸드폰 번호 등록 필수)

## 1. 한 줄 설명
장르만 고르면 유튜브 플레이리스트 채널 운영에 필요한 **제목, Suno 프롬프트, 가사, 유튜브 설명·태그, 썸네일**을 한 번에 만들어 줍니다.

## 2. 시작 전 준비 (한 번만)
1. AIMaster에 가입하고 **핸드폰 번호**를 등록합니다(없으면 프로그램을 쓸 수 없습니다).
2. 왼쪽 메뉴 **API키등록·플랫폼연동**에서 본인 키를 등록합니다.
   - **Google Gemini 키**: 권장. 텍스트와 썸네일 이미지 모두 가능합니다.
   - **OpenAI 키**(선택): GPT-4o 계열 텍스트, gpt-image-1 썸네일.
   - **Claude 키**(선택): 텍스트만 가능합니다(Claude는 이미지를 만들지 못합니다).
   - AI 비용은 **회원님 본인 계정**으로 나갑니다. 운영자나 다른 회원의 키는 쓰이지 않습니다. 선택한 모델의 키가 없으면 "키 등록이 필요합니다" 안내가 뜹니다.

## 3. 사용 순서
화면 위쪽에서 **텍스트 모델**과 **이미지 모델**을 고를 수 있습니다(기본: Gemini 2.5 Flash, 나노 바나나). 아래 "이 브라우저의 사용량"에서 호출 횟수와 예상 비용을 볼 수 있습니다(참고용, 이 브라우저에만 저장).

### 3-1. 장르
10개 카드 중 하나를 고르거나 원하는 장르를 직접 입력합니다. 누르는 즉시 제목 10개가 만들어집니다.

### 3-2. 제목
`playlist 🌙 새벽에 듣는 노래 | Midnight & Chill` 형식의 제목 10개 중 하나를 고르거나 직접 씁니다. 마음에 안 들면 **제목 다시 만들기**. 이후 **제목 변경**을 누르면 다른 제목을 고를 수 있으며, 이때 그 제목으로 만든 Suno 프롬프트·가사·설명·썸네일은 지워집니다(확인창이 뜹니다).

### 3-3. Suno 프롬프트
Suno 5.0 "Style of Music" 칸에 붙여 넣는 영어 프롬프트 3종(각 900자 미만). 복사 버튼을 누릅니다.

### 3-4. 가사
- **가사 언어**와 **이중 언어**(보조 언어 비율 10~90%)
- **곡 수** 1~20곡
- **은유 강도** 4단계(직설 → 시적 상징)
- **곡 구조** 15종 또는 자동(장르에 맞는 구조 추천)
- **인트로/아웃트로에도 가사 넣기**, **연주곡 모드**(가사 없이 구성 안내만), **주제 메모**
곡 수가 많으면 1~2분 걸립니다. 결과는 곡별 복사, 전체 복사, 빠른 이동 번호로 쓸 수 있습니다.

### 3-5. 유튜브 메타데이터
설명글, 해시태그 5개(`#playlist`가 맨 앞), 검색 키워드 15개. 가사를 먼저 만들면 곡 정보가 설명에 반영됩니다.

### 3-6. 썸네일
1. **스타일** 7종 중 선택(필요하면 **인물 참고 이미지** 업로드 — 저장되지 않고 이번 생성에만 쓰입니다) 후 **썸네일 배경 만들기**.
2. 배경에는 글자가 없습니다. 오른쪽 미리보기에 **제목 글자**가 얹히며 글자 내용, 글꼴 14종, 크기, 색, 굵기, 위치(위/가운데/아래)를 바꿀 수 있습니다.
3. **PNG 저장 / JPG 저장**, **이미지 프롬프트 복사**.
4. 마음에 안 들면 **수정 요청**에 "더 어둡게" 같은 요청을 적어 다시 만듭니다(현재 썸네일을 바탕으로 반영).

## 4. 내 프로젝트
만든 결과는 **내 프로젝트**에 자동 저장됩니다(최대 **30개**). 카드를 누르면 이어서 작업할 수 있고, 휴지통으로 삭제하면 저장된 썸네일도 함께 지워집니다.

## 5. 자주 묻는 질문 / 문제 해결
| 증상 | 원인과 해결 |
|---|---|
| "○○ API 키 등록이 필요합니다" | 고른 모델의 공급사 키가 없습니다. API키등록·플랫폼연동에서 등록하거나 다른 공급사 모델로 바꾸세요. |
| "API 키가 올바르지 않습니다" | 키를 다시 복사해 교체하세요. |
| 나노 바나나 프로·gpt-image-1 권한 오류 | 본인 Google 결제 연결 / OpenAI 조직 인증이 필요할 수 있습니다. 다른 이미지 모델을 고르세요. |
| "사용 한도를 넘었습니다" | 잠시 후 다시 시도하거나 본인 키의 한도·결제를 확인하세요. |
| "AI가 안전 정책으로 거부했습니다" | 장르·주제 메모·수정 요청을 조금 바꿔 다시 시도하세요. |
| "형식에 맞는 제목을 충분히 만들지 못했습니다" | 일시적인 응답 오류입니다. 같은 버튼으로 다시 시도하세요. |
| "프로젝트는 30개까지 저장할 수 있습니다" | 내 프로젝트에서 오래된 것을 삭제하세요. |
| 글꼴이 바뀌지 않음 | 처음에는 글꼴을 내려받는 데 몇 초 걸립니다. 잠시 후 다시 확인하세요. |
| "핸드폰 번호를 입력 후 사용해주세요!" | 메인 사이트에서 핸드폰 번호를 등록하세요. |

## 6. 운영 담당자 메모
- 썸네일 보관은 운영자 저장소를 쓰므로 사용자당 30개로 제한했고 1280x720 JPEG로 압축해 저장합니다. 사용량 기록은 회원 브라우저에만 저장됩니다.
- AI 호출 비용은 모두 회원 본인 키로 나갑니다(운영자 비용 없음). FREE 배지로 운영 중이며 관리자 프로그램 편집 화면에서 켜고 끌 수 있습니다.
- 문의 대응 시 확인할 것: ① 핸드폰 등록 여부 ② 고른 모델 공급사의 키 등록 여부 ③ 이미지 모델 사용 시 결제/조직 인증 ④ 프로젝트 수 한도.
