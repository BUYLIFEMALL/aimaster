# 플레이리스트 v1.23 플랜 — 배경(앨범 커버)으로 유튜브 썸네일 (2026-10-21)

> 주인님 지시: 「YOUTUBE 썸네일 자동화와 연결해 같은 앨범 커버로 썸네일까지」 → 방식 선택 「플레이리스트 안에서 바로」. 대상 ① 운영, DB 변경 없음.

- 유튜브 카드에 「🖼 썸네일」: 지금 배경 그림(이미지일 때 — Suno 커버 배경·앨범 커버 포함)을 유튜브 권장 1280×720 JPG로 만들어 미리보기·내려받기, 「올릴 때 이 그림을 썸네일로 지정」(기본 켬).
- 업로드가 끝나면 `/api/youtube/thumbnail`(같은 출처·`requireAccess`, JPG 2MB 이하)이 회원 공용 유튜브 연결 토큰으로 `thumbnails.set` 호출. 채널이 맞춤 썸네일 사용 인증(전화 인증)이 안 돼 있으면 안내 문구. 공용 기준 `youtube-upload-client`는 고치지 않고 이 앱 전용 `src/lib/youtube/thumbnail.ts`.
- 비용: Vercel 빌드 1회, AI 0회, 유튜브 무료 한도 썸네일 1회 50단위. 확인: 크롬 관리자 계정으로 앞서 올린 비공개 시험 영상(https://youtu.be/mPwlsDllUgk)에 썸네일 1회 지정.
