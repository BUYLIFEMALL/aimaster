# 플레이리스트 v1.21 플랜 — MP4 결과에 GIF 스티커 넣기 (IMP-PLS-008, 2026-10-21)

> 주인님 지시: 「결과 MP4에 GIF 스티커가 빠지는 문제(IMP-PLS-008)」 진행. 대상 ① 운영, DB 구조 변경 없음.

- 원인: `gifUrl`이 미디어 센터·편집 미리보기에만 넘어가고 내보내기 화면(`ExportStudio`)·`exportVideoMp4`에는 전달되지 않았다.
- 수정: `VideoStudio` → `ExportStudio` → `exportVideoMp4(…, gifUrl)`(마지막 선택 인자, 기존 호출 그대로 동작). 새 `src/lib/render/gif-frames.ts` — 브라우저 내장 `ImageDecoder`로 장면(최대 300)과 표시 시간을 미리 나눠 시각에 맞춰 반복 재생, 없는 브라우저는 첫 장면 고정. 위치·크기(1080p 기준 150px×크기%)·투명도·그림자·가운데 정렬은 미리보기와 같음, 720p는 비율로 줄임, 로고 다음·확대/흔들림 안에서 그림.
- 비용: Vercel 빌드 1회, AI 0회. 확인: tsc·시험·build → 배포 → 크롬 일반 회원으로 움직이는 시험 GIF를 넣고 짧은 MP4 생성(저장 위치는 브라우저 내부 저장소로 바꿔 끼움) → 서로 다른 시각 장면에서 스티커 모양이 바뀌는지.
