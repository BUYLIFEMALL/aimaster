## 4. 꼭 알아야 할 것

- **권리:** 새로 넣는 기능은 원본 수식·값·문구 없이 우리 것으로 작성. 기존 렌더 코드 권리 재확인 여부는 주인님 결정 대기.
- `src/lib/render/video-exporter.ts`는 **공용 `browser-mp4-encoder` 사본이 아님**. P-2 개선이 좋으면 공용 기준(`shorts-onestop-studio`)에 같은 개선을 제안 — 사본 파일은 직접 고치지 않는 공용 규칙.
- 미리보기와 MP4가 같은 그리기 함수를 쓰게 유지(v1.18~v1.21에서 미리보기·MP4 결과 맞춘 이력).
- 1시간 넘는 영상은 「내 PC 고속 변환」 로드맵 B `loop-mux`(`docs/analysis-pc-renderer-20261024/ROADMAP.md`, 음악 담당 작성)와 연결 검토.
- 버전: 배포할 때만 +0.01(코드·DB `programs.version`), 작은 수정은 모았다가 배포.
