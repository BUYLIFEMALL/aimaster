## 1. 이 프로그램만의 처리
| 항목 | 내용 |
|---|---|
| 옛 테마 이름 | `gold`·`gold-light`·`dark-50/100/200`·`gold-gradient`·`glass-card`·`gold-text`를 지우지 않고 `@theme`에서 **같은 다크 토큰으로 재연결**(남은 클래스가 밝게 보이지 않게). 새 코드는 `mx-*`만 쓴다 |
| 로그인·회원가입 | 공통 밝은 틀 → **다크 배경 + 연한 파랑 격자**(원칙 13: 프로그램 안 모든 페이지 같은 배경) |
| 금액 표기 | `lib/format.ts` `formatWon`(만원 → 억), `priceToOfficialPct`(거래가 ÷ 공시가격 %) — 공시가격은 원 단위라 /10000 |
