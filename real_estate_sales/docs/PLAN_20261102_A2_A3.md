## A2-1. 보유 자료 기준 최고가·최저가
| 항목 | 내용 |
|---|---|
| 비교 단위 | 같은 단지(법정동 + 건물명) · 같은 거래 종류(매매/전세/월세) · 전용면적 ±3㎡ · 최근 12개월 |
| 판정 | 새 거래가 비교 거래 3건 이상 중 가장 높으면 「📈 보유 자료 12개월 최고가」, 가장 낮으면 「📉 … 최저가」(㎡당 아닌 금액 기준, 면적 범위로 맞춤) |
| 표시 | 실거래 목록 배지, 상세 화면 「비교한 거래 n건 · 이전 최고 ○억(날짜)」, 텔레그램·알림톡 알림 줄 |
| 표현 원칙 | 「신고가」·「역대」라고 쓰지 않는다. 우리가 모은 자료(회당 20건 상한)라 빠진 거래가 있을 수 있다고 상세에 적는다 |
| 저장 | 비교는 이미 저장된 거래로 계산하고, 결과(최고가/최저가/해당 없음)만 수집 때 한 번 정해 `real_estate_listings`의 새 칸 1개 `price_rank`에 저장한다(목록 배지·거르기용, 매번 다시 계산하지 않음) |

## A2-2. 지역별 거래량 증가
| 항목 | 내용 |
|---|---|
| 자료 | 수집 때 이미 받는 응답의 **전체 건수 칸**을 시·군·구 × 계약월 × 거래 종류 × 건물 유형으로 기록(추가 API 호출 없음). 우리가 저장하는 20건 상한과 무관하게 실제 신고 건수에 가깝다 |
| 판정 | 「지난달 건수 ≥ 직전 3개월 평균 × 1.3, 그리고 10건 이상」이면 「🔥 거래량 증가」. 이번 달은 신고 기한(30일)이 남아 비교하지 않는다 |
| 표시 | 대시보드·관심 지역 화면에 지역별 최근 4개월 건수 막대와 증가 표시. 알림은 **한 달에 한 번**(매월 초 첫 수집 때 관심 지역 중 증가한 곳만 한 줄) |
| 저장 | 새 표 1개 `real_estate_trade_volume`(시·군·구, 계약월, 거래 종류, 유형, 건수, 갱신 시각). 회원 정보 없는 공공 집계라 회원별 RLS 대상 아님(읽기는 이용 권한 확인 뒤 서버에서) |
| 확인할 것 | 구현 첫 단계에서 실제 응답으로 전체 건수 칸 이름·값을 확인(서울 열린데이터·국토부 각각). 맞지 않으면 그 자료는 표시하지 않고 보고 |
