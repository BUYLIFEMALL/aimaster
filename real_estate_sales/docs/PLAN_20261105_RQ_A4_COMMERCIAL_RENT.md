## 1. 지금까지 확인한 것 (2026-11-05, 무료)
- 자료: 한국부동산원 「상업용부동산 임대동향조사」 — **분기마다** 상권별 임대료(㎡당)·공실률·투자수익률 등. 유형은 오피스·중대형 상가·소규모 상가·집합 상가(공표 보고서 기준). 상권은 「강남대로」「역삼역」처럼 이름 붙은 구역이고, 2026년 표본 개편으로 상권 재구획 중이라는 공지가 있다.
- 받는 길 두 가지:
  1. R-ONE Open API `https://www.reb.or.kr/r-one/openapi/SttsApiTblData.do` — 통계표 번호 `STATBL_ID`로 표를 고르고 `CLS_ID`(지역·상권)·`ITM_ID`(항목)·`DTACYCLE_CD`(주기)·`WRTTIME_IDTFR_ID`(시점)로 거른다. 통계표 목록은 `SttsApiTbl.do`(전체 769개). 브라우저에서 직접 부를 수 없고 서버를 거쳐야 함.
  2. 공공데이터포털 「한국부동산원_부동산통계 조회 서비스」(15134761) — 상업용부동산 임대동향조사 포함으로 적혀 있으나 요청 주소·칸은 포털 화면에 없음.
- **인증키 없이(견본 모드) 불러 봄:** 목록은 쪽 번호와 상관없이 같은 표 5개(지가지수)만 와서, 상가 임대료·공실률 표 번호를 찾을 수 없었다 → **인증키가 있어야 사전 검증이 된다.**

## 2. 범위(사전 검증 뒤 확정)
1. 실거래 주소 리포트의 상가·건물·토지 칸(v1.52)에 「🏷️ 이 상권 임대료·공실률(최근 분기)」: 그 필지가 속한 상권(같은 시군구·가장 가까운 상권)의 유형별 ㎡당 임대료·공실률·직전 분기 대비. 출처·기준 분기·「상권 평균이라 이 건물 값이 아님」 표시.
2. 상가 프로그램(`commercial-land-trade-alert`)의 추정 수익률 화면에 같은 값을 「상권 평균 임대료 참고」로 함께 표시(지금은 감시 화면의 월세 호가만 씀) — 2단계, 별도 승인.
3. 분기 자료라 서버 캐시(공용 표 1개, 분기마다 갱신) — DB 표 추가 승인 필요.
하지 않는 것: 건물별 임대료 추정, 수익률 보장 문구, 공실률로 투자 권유.

## 3. 단계
- **0단계 사전 검증(인증키 받은 뒤, 빌드 1회 또는 로컬):** 통계표 목록에서 상가 임대료·공실률 표 번호 찾기 → 상권 코드 목록·이름 → 필지(시군구·동·좌표)를 상권에 맞추는 방법 결정(이름 대조로 되는지, 좌표·경계가 필요한지) → 최근 분기 값 표본 10곳. 결과 보고 뒤 1단계.
- **1단계(빌드 1회 + DB 표 1개 승인):** 리포트 칸 + 분기 캐시.
- **2단계(별도):** 상가 프로그램 수익률 화면 연결.

## 4. 주인님이 해 주실 일 (둘 중 하나)
- **추천 — 공공데이터포털 15134761 「활용신청」**: 지금 실거래·상가 프로그램이 쓰는 공용 공공데이터 키(Vercel `DATA_GO_KR_SERVICE_KEY`) 계정으로 신청하면 키를 새로 넣지 않아도 된다(승인되면 바로 사전 검증). 다만 이 서비스가 R-ONE 상권 표까지 주는지는 승인 뒤에 확인.
- 또는 R-ONE 회원가입 → Open API 인증키 신청 → Vercel에 새 환경변수(`RONE_API_KEY`)로 등록.
- 운영자 공용 키 예외(§8 공공 무료 자료) 목록에 이 자료를 추가하는 것도 함께 승인 필요.
