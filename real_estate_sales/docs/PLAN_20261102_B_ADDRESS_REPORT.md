## 주소 검색(③번 길)
- 도로명주소 검색 API(행정안전부 `business.juso.go.kr`, 무료) **승인키 신청이 필요**합니다(주인님 몫 — 주소 DB 신청과 같은 사이트). 키가 오기 전에는 ①·②번 길만 연다.
- 결정 3에 따라 운영자 공용 키로 시작하고, 회원당 하루 조회 상한(예: 30회)을 둔다. 검색 결과의 건물관리번호 앞 19자리로 PNU를 만든다(임장 노트 v1.37과 같은 규칙).

## 규칙 점검
- 회원 본인 키: AI는 회원 키만. 공공 무료 키는 기존 예외(§8) 범위 — 주소 검색 키를 추가하면 같은 문서 §8에 적는다.
- 보관: 리포트·호가 입력은 회원별·RLS, 기존 `real-estate-sales` 1년 지정 안.
- 표현: 「급매」「신고가」 대신 근거와 기간을 함께. 참고용 고지.
