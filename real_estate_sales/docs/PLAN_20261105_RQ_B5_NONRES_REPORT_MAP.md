## 1. 지금과 빈칸
- 주소 리포트(`/report`)는 임장 노트에서 비주거 필지를 열면 공시지가·용도지역·건축물대장만 나오고 「상가·건물·토지 거래는 다음 단계에서」라고만 보여 준다.
- 지도는 리포트에 없다(임장 노트 편집 화면에만 위치 지정이 있음).

## 2. 자료의 한계 (상가 프로그램 v1.01 실측, 2026-10-31)
| 자료 | 지번 | 이 필지와 맞추는 방법 |
|---|---|---|
| 상업업무용 매매 `NrgTrade` — 집합(구분 상가) | 공개 | **같은 지번 = 같은 건물** 거래로 묶을 수 있음 |
| 상업업무용 — 일반(통건물) | 가림(`1***`) | 필지 단위 불가 → **같은 동·같은 용도** 비교만 |
| 토지 `LandTrade` | 가림 | **같은 동·같은 지목** 비교만 |
| 공장·창고 `InduTrade` | 가림(추정) | 같은 동·같은 용도 비교만 |
호출 한도: 토지 하루 1,000건(상가 프로그램과 공용 키를 같이 씀) — 리포트 한 번에 토지를 12달 부르면 하루 80번 남짓으로 끝난다.

## 3. 단계
### 0단계 — 사전 검증(관리자 진단 주소, 빌드 1회)
기존 `/api/admin/report-probe`(B0 때 만든 관리자 전용 진단)에 비주거 항목을 더해 운영 키로 측정:
1. 임장 노트·상가 감시 지역에서 고른 표본 15곳(집합 상가 5·통건물 5·토지 5)의 12개월 거래 중 **같은 지번으로 잡히는 비율**, 같은 동·같은 용도/지목 표본 수.
2. 지도: 브이월드 **2D 이미지(정적 지도) API**와 **주소→좌표 변환** 응답이 지금 개발키로 되는지, 응답 시간.
3. 판정: 집합 상가 같은 지번 비율 50% 이상이면 「같은 건물 거래」 칸을 넣고, 아니면 동 단위 비교만. 지도 API가 안 되면 지도 대신 「지도에서 보기」 바깥 링크(브이월드·네이버 지도 주소)로 대신.
결과를 이 문서에 적고 주인님께 보고한 뒤 1단계로.

### 1단계 — 리포트에 상가·건물·토지 칸(빌드 1회)
- 비주거 필지 리포트에 「🏬 상가·건물 거래」·「🌳 토지 거래」 칸: 최근 12개월(토지는 한도 때문에 6개월) 같은 동 같은 용도·지목의 건수·평당가 중간값·범위, 집합 상가는 (검증 통과 시) 같은 지번 거래 목록.
- 지분·취소 거래는 통계에서 뺌(상가 프로그램 규칙 그대로), 표본 5건 미만이면 중간값을 보여 주지 않음.
- 계산은 상가 프로그램 `commercial-land-trade-alert/src/lib/trades/parse.ts`를 **사본으로 가져와** 쓴다(프로그램끼리 서로 부르지 않음 — 공용 기준 코드 규칙).
- AI 총평 입력·저장 리포트·나란히 비교에도 새 칸 포함.
### 2단계 — 지도(1단계와 같은 배포)
- 리포트 위쪽에 위치 지도 한 장(서버가 브이월드 정적 지도를 받아 넘겨 줌 — 키를 화면에 노출하지 않음, 하루 캐시). 좌표는 임장 노트면 사진 위치, 실거래 매물이면 주소→좌표 변환.
- 0단계에서 지도 API가 안 되면 바깥 지도 링크만.

하지 않는 것: 상가 임대료·수익률(자료 없음, RQ-A4), 네이버 매물 호가, 주변 상권 분석, 지도 위 여러 거래 점 찍기(다음 단계 후보).

## 4. 검수
