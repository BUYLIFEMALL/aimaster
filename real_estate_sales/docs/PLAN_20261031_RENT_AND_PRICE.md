# 공시가 세대 맞추기 + 경기·인천 전월세 비교 개발 플랜 (2026-10-31, [역할: realty])

상태: 1~5번 완료(v1.29, 2026-10-31). 6번 기존 줄 복구는 별도 승인 대기. 대상 프로그램 `real_estate_sales`(운영 DB `esgxyikcnnvmlhygjkth`).

## 문제
1. 공시가: `collect.ts`가 `fetchApartAssessedPrice` 결과의 첫 줄(`value[0]`)만 쓴다. 호출은 10줄까지이고 면적을 맞추지 않아, 같은 필지의 다른 세대 값이 들어갈 수 있다(예: 경희궁의 아침 3단지 거래 3.185억·공시가 14.13억).
2. 전월세: 경기·인천은 `collect.ts`에서 빈 배열로 건너뛴다(RE-B4 2차). 공공데이터 15126474 승인 완료(2026-10-31).
3. 서울 전월세도 단지 이름만 맞추고 가장 최근 줄을 써서 면적이 다를 수 있다.

## 범위와 순서
1. 공시가: 전용면적(`prvuseAr`)이 가장 가까운 줄을 고르고, 오차가 크면 비워 둔다. 순수 함수로 만들어 시험한다.
2. 전월세: `molit.ts`에 `RTMSDataSvcAptRent` 응답 변환을 추가한다. 지역·달 단위 응답을 수집 한 번에 한 번만 받아 단지 이름과 면적으로 맞춘다.
3. 서울 전월세도 같은 면적 맞추기를 적용한다.
4. 화면 문구 「전월세 비교는 서울만」을 지운다.
5. 시험 계정으로 경기 지역 1곳 조회, DB·화면 대조.
6. 기존 줄 복구는 별도 승인(공시가 빈 줄 599, 필지 번호 오류 40, 값이 틀릴 수 있는 기존 공시가).

## 하지 않는 것
월세 비교 화면 신설, 연립·오피스텔 전월세, 기존 줄 자동 재계산.

## 검수
시험: 면적 맞추기·응답 변환(한 줄·여러 줄·빈 결과·해제 거래). 크롬: 시험 계정 상세 화면 공시가·전세가율. 확인 전 실제 응답 칸 이름을 먼저 대조한다(문서만 믿지 않음).

## 비용
Vercel 빌드 1회(사전 승인). 공공데이터·브이월드는 무료. 시험 때 AI 분석 설정을 끄고 조회해 AI 호출 0회. 회원 부담 변화 없음.
