## 2. 설계 — 자동 등록이 아니라 「제안 → 한 번 눌러 추가」

- **새 DB 표·스키마 변경 없음.** 다른 프로그램 표는 읽기만, 쓰기는 각 프로그램이 원래 쓰던 자기 표·자기 서버 액션만.
- 각 프로그램 관심 지역 화면 위에 「🔗 다른 부동산 프로그램에 등록한 지역」 상자: 아직 이 프로그램에 없는 시군구만, 출처(실거래·상가·매물 알림) 표시.
  - 실거래·상가: 기존 지역 켜기 버튼을 그대로 보여 줌 → 누르면 기존 서버 액션으로 추가(이용 권한 확인 그대로).
  - 매물 알림: 지역 감시는 동(`cortar_no`)을 골라야 하므로 「종로구 — 동 고르러 가기」 안내(자동 추가 없음).
- 공통 판정은 각 프로그램 안의 순수 함수(`suggestFromOtherPrograms`) + 시험. 프로그램끼리 서로 호출하지 않음.
