## 1. 디자인 리뉴얼 개요 및 사용자 지시 이행

주인님 지시사항:
> "https://yt-playlist.buylife.xyz/ 검정색 베이스로 작업하고 로고를 유투브 로그를 사용해주고 유투브 테마 느낌이 나게 다시 디자인해줘"  
> "하나의 자동화 프로그램은 같은 배경색상으로 작업해야해"

### 핵심 개선 사항
1. **검정색 베이스 (#0f0f0f 퓨어 옵시디언 블랙)**:
   - 메인 워크스페이스, 사이드바, 가이드북, 모달 전체를 일관된 유튜브 공식 다크 배경색 `#0f0f0f`로 통일.
   - 단일 페이지 내 배경색 불일치(Light / Dark 혼재)를 100% 제거하고 모든 서피스를 `#181818` / `#212121`, 테두리를 `#272727`로 통일.
2. **유튜브 공식 레드 로고 탑재**:
   - 좌측 사이드바 최상단 및 모바일 상단 바에 유튜브 공식 레드(`#ff0000`) 라운드 사각형 + 흰색 삼각 재생 아이콘(`▶`) 로고 배치.
3. **유튜브 테마 느낌의 알약형(Pill) UI 및 레드 포인트**:
   - 버튼, 선택 칩, 진행 게이지, 강조 배지에 유튜브 레드(`#ff0000`)와 알약형 라운드 스타일을 적용하여 유튜브 스튜디오 감성을 완벽 구현.
4. **📖 연동 & 사용 매뉴얼 메뉴 및 비주얼 가이드북 전면 구축 (최상단 지침 준수)**:
   - 좌측 사이드바 4번째 메뉴로 `📖 연동 & 사용 매뉴얼` 추가.
   - `/guide` 독립 URL 라우트 및 `?tab=guide` 탭 연동.
   - 5단계 파이프라인(Gemini API 연동 → 음원 & 타임라인 → 16:9 배경 & 로고 → 10종 스펙트럼 & 14종 파티클 → WebCodecs 1080p MP4 인코딩), 유튜브 플레이리스트 떡상 4대 골든 팁, 4종 FAQ 아코디언, 회원 본인 키 직접 연동 보안 원칙 배너 완비.

## 3. 화면별 리뉴얼 내역

### 1) 통합 사이드바 (`Sidebar.tsx`)
- 유튜브 레드 공식 플레이 로고(`▶`) 및 `v1.06` `YouTube Dark` 배지 탑재.
- 사이드바 배경 `#0f0f0f` 및 메뉴 서피스 `#181818` 적용.
- `📖 연동 & 사용 매뉴얼` 탭 메뉴 추가 및 활성화 인디케이터 연동.
- 모바일 햄버거 메뉴 및 슬라이드 드로어 네비게이션 지원.

### 2) 비주얼 가이드북 (`PlaylistGuideView.tsx` & `/guide`)
- 상단 히어로: 유튜브 레드 그라디언트 텍스트, 공식 가이드북 배지, "스튜디오 바로가기" / "Gemini API 키 연동" CTA.
- 5단계 표준 파이프라인: 단계별 넘버링, 배지, 핵심 기능 상세 설명.
- 유튜브 떡상 4대 골든 팁: 30초 훅 & 타임라인 필수 기재, 배경 무드-스펙트럼 색상 일치, 1~2시간 롱폼 루프 전략, 워터마크 브랜딩.
- 4종 FAQ 아코디언 및 회원 본인 API 키 직접 연동 보안 원칙 배너.

### 3) 미디어 센터 (`MediaCenter.tsx`)
- 최상위 컨테이너 `#0f0f0f` 다크 테마 일체화.
- 오디오 트랙 리스트: 점선 드롭존(`border-[#272727] hover:border-[#ff0000]`), WAV/MP3 지원 칩, 타임라인 원클릭 복사 버튼, 트랙 순서 변경(▲/▼) 및 삭제.
- 배경 미디어 드롭존: 16:9 가로 비율 권장, Gemini AI 배경 생성 모달 연동.
- 채널 로고 & GIF 스티커: 1:1 정사각 다크 카드.
- 인코딩 기본 프리셋: 1회/2회/3회 루프 알약 칩, 96k/128k/192k VBR 선택 칩.
- 스튜디오 입장하기: 유튜브 레드 풀 와이드 CTA 버튼.

### 4) 편집 스튜디오 (`EditorStudio.tsx`)
- 3단 콘솔 레이아웃: 좌측 FX 패널(320px) + 중앙 16:9 영화관 캔버스 + 우측 레이아웃 패널(320px).
- 좌측: 10종 오디오 스펙트럼, 8종 배경 필터, 10종 트렌디 오버레이, 4종 파티 FX, 14종 스타일 파티클.
- 중앙: 1920×1080 캔버스 오버레이 재생 버튼, 트랙 선택 드롭다운, 유튜브 플레이어 콘솔 바(재생/일시정지, 시크바, 실시간 타임스탬프).
- 우측: 로고/GIF X/Y 위치 및 크기 조절, 메인 컬러 팔레트 18색, 스펙트럼 원형 반경 및 감도/속도 세부 튜닝.

### 5) 고속 렌더링 스튜디오 (`ExportStudio.tsx`)
- 상단 헤더: "내보내기 & 렌더링" + 스튜디오 복귀 버튼.
- 렌더링 파라미터 요약 카드: 총 트랙 수, 루프 횟수, 최종 영상 길이, 해상도/FPS.
- FPS (30/60) & 해상도 (1080p/720p) 알약형 선택 칩.
- WebCodecs GPU 가속 실시간 프로그레스 바(유튜브 레드) 및 MP4 다운로드 버튼.

## 5. 다음 CLI 인수인계 및 주의사항

1. **단일 배경색 원칙 엄수**:
   - `yt-playlist-studio` 내의 모든 뷰(`/`, `/guide`, `?tab=media`, `?tab=editor`, `?tab=export`)는 반드시 `#0f0f0f` 배경색을 유지해야 합니다.
2. **WebCodecs 브라우저 지원**:
   - 비디오 내보내기는 클라이언트 브라우저의 WebCodecs API(`VideoEncoder`, `AudioEncoder`)를 사용하므로 최신 Microsoft Edge 또는 Chrome 환경에서 가장 안정적으로 고속 인코딩됩니다.
3. **회원 본인 Gemini API 키 원칙**:
   - AI 배경 생성은 사용자가 직접 등록한 Gemini API 키로 동작하며 운영자 키 폴백을 금지합니다.
