## 3. ★ 추가개선 제안 (3대 필수 제안 항목)

### ① 프로그램 로직 및 기능 개선
- **유튜브 썸네일 자동 캡처 추출기 (Thumbnail Snap)**:
  - 현재는 영상(MP4) 인코딩 내보내기만 가능하나, 유튜브 플레이리스트 업로드 시 필수적인 16:9 썸네일(JPG/PNG)을 현재 캔버스 프레임 기준으로 원클릭 캡처 다운로드하는 기능 추가 권장.
- **트랙 제목 일괄 번호 부여 (Auto-Track Numbering)**:
  - 업로드된 오디오 목록의 곡 제목 앞에 `01.`, `02.`, `03.` 번호를 원클릭으로 일괄 부여/정렬하는 편의 로직 추가 제안.

### ② 사용자 인터페이스/UI 가독성, 사용편리성 개선
- **오디오 스펙트럼 실시간 프리뷰 최적화**:
  - 현재 캔버스에서 10종 스펙트럼 전환 시 미세한 렌더링 딜레이가 발생할 수 있으므로, 오프스크린 캔버스 렌더링을 통한 60fps 고정 부드러운 애니메이션 강화 권장.
- **볼륨 게인 컨트롤러 추가**:
  - 각 트랙별 음량 편차를 보정할 수 있도록 트랙별 간단한 볼륨 게인 슬라이더(0~150%) 배치 제안.

### ③ 현재 만들어져 있는 다른 자동화 프로그램과의 연계가능한 기능
- **Suno 음악기획 자동화 (`suno-music-studio`) 연동**:
  - `suno-music-studio`에서 기획/생성된 BGM/음원 파일 목록 및 메타데이터를 원클릭으로 `yt-playlist-studio`에 바로 불러와 플레이리스트 영상을 즉시 조립할 수 있는 파이프라인 연계 제안.
- **유튜브 바이럴 파인더 (`youtube-viral-studio`) 연동**:
  - 떡상 유튜브 플레이리스트 키워드 및 트렌딩 곡 리스트를 `youtube-viral-studio`로부터 가져와 트랙 메타데이터 자동 추천 연계 가능.
