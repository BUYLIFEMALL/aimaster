## 1. 문제
상품소싱(발굴) → **(빈칸: 등록 정보 정하기)** → 상세페이지 → 마켓 등록기. 검색 결과 표본은 이미 모으지만, 「이 상품군에서 상품명에 많이 쓰이는 낱말·가격대·광고 비율·연관 검색어」를 한눈에 보여 주는 곳이 없다.

## 2. 단계 (하나씩)
| 단계 | 내용 | AI | 확장 | DB | 상태 |
|---|---|---|---|---|---|
| **E2-1** | 소싱 결과(쿠팡·네이버 공통 「내 검색 기록」)에 「📊 등록 정보 도우미」: 많이 쓰인 낱말 상위 20(몇 개 상품명에 나왔는지)·가격 분포(최저·1/4·가운데·3/4·최고)·광고 비율 + 「연관 키워드·월간 검색수」 표(회원 본인 검색광고 키, 표본 상품명에 쓰였는지 표시) | 0 | 변경 없음 | 없음 | **이번 구현** |
| E2-2 | 상품명·태그 초안(회원 본인 Claude 1회, 회원이 누를 때만, 재시도 0) + 규칙 검사(길이·중복 낱말·광고 문구·특수문자) | 회원 키 | 없음 | 없음 | 결정 뒤 |
| E2-3 | 확장이 카테고리 경로도 읽어 분포 카드 | 0 | 새 버전 | 칸 1개 | 결정 뒤 |
| E2-4 | 소싱 → 상세 → 등록기로 키워드·태그 넘기기 | 0 | 없음 | `shop_products` 칸 | 결정 뒤 |

## 3. E2-1 구현 순서
1. `lib/registerHelper.ts`(순수 함수): `topWords`·`priceStats`·`adShare`·`usedInNames` → 시험 `tests/registerHelper.test.mjs`.
2. `lib/actions/registerHelper.ts`: `relatedKeywordsAction(seed)` — `requireProgramAccess` + 회원 본인 `naver_ads_*` 3종, 없으면 등록 안내(폴백 없음), 기존 `getRelatedKeywords` 재사용, 검색수 순 상위 20.
3. `components/coupang/RegisterHelper.tsx`: 지금 거른 상품 기준(표본 수·조사 시각 함께 표시), 기준 키워드 칸(기본값 = 검색 키워드) + 「연관 키워드 불러오기」 버튼.
4. `ReviewResults.tsx` 표 아래에 붙임.
