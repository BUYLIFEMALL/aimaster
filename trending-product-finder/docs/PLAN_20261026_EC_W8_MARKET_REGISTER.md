대상: ① AIMaster 운영 — `trending-product-finder`(상품소싱 자동화) 안의 새 메뉴 (새 프로그램 아님)

상태: ⏩ **방향 바뀜(2026-10-26 주인님)** — 크롬 확장 등록기(방식 D)를 1단계로, 스마트스토어 먼저·쿠팡 다음. 새 플랜 [`PLAN_20261026_EC_W8_SMARTSTORE_EXTENSION.md`](PLAN_20261026_EC_W8_SMARTSTORE_EXTENSION.md). 이 문서는 방식 비교 근거로 남김

## 0. 결론 먼저
- **「회원이 자기 마켓 API 키를 우리 사이트에 넣고, 우리 서버가 대신 상품을 올리는 방식」은 네이버가 허용하지 않는다**(공식 기술지원 답변). 그래서 처음 백로그에 적힌 Phase 16 방식 그대로는 만들 수 없다.
- 추천: **1단계 「마켓 등록 파일 만들기」**(공식 엑셀 일괄등록 양식으로 채운 파일 + 이미지 묶음을 만들어 주고, 회원이 판매자센터에 직접 올림) → **2단계(선택) 「크롬 확장 입력 도우미」**(등록 화면 칸을 채워 주고 「등록」은 회원이 누름) → **3단계(주인님 결정) 공식 파트너 연동**.
- 1단계는 API 키·IP·심사가 필요 없고, 두 마켓 모두 같은 방식으로 되며, 여러 상품을 한 번에 올릴 수 있다.

## 1. 조사 결과 (2026-10-26)
| 항목 | 확인한 사실 | 근거 |
|---|---|---|
| 네이버 「내 스토어 애플리케이션」 | 판매자가 **직접** 연동하는 용도. 그 키를 받아(위탁받아) 서비스를 운영하는 방식은 **허용되지 않음** | 네이버 커머스API 기술지원 답변(GitHub 토론 #3463) |
| 네이버 제3자 정식 경로 | ① 커머스솔루션(솔루션마켓 게시 → 판매자가 구독, 테스트·최종 심사) ② API대행사(신청서 → 검토, **국내 법인 사업자 아니면 반려 가능**) | 같은 답변 |
| 네이버 IP 등록 | 내 스토어 애플리케이션은 IP 등록 불필요라는 답변. 솔루션·대행사 쪽은 답변에 없음 | 같은 답변 |
| 쿠팡 WING Open API | 판매자가 WING 「추가판매정보」에서 Access·Secret Key와 업체 코드(Vendor ID) 발급, HMAC 서명. 발급 때 「자체개발」을 고르고 **IP를 등록하면 그 IP에서만 호출 가능** | 연동 서비스 안내 문서들(공식 정책 문서는 확인 못 함) |
| 쿠팡 제3자 대행 허용 여부 | **공식 근거를 찾지 못함** — 쿠팡 판매자 지원센터 문의 필요 | — |
| 판매자 자격 | 쿠팡 판매자는 사업자등록 필요 가능성이 높음(Phase 17 기록과 같음). 네이버는 개인 판매자도 스토어 개설 가능 | 기존 `AGENTS.md` Phase 16·17 |
| 엑셀 일괄등록 | 두 마켓 모두 판매자센터에 엑셀 일괄(대량) 등록 기능이 있다고 알려져 있으나, **열 구성·이미지 넣는 방법·카테고리 코드는 웹에서 확인 못 함** → 판매자센터에서 양식을 직접 받아 확인해야 함 | — |
| 우리 서버 IP | Vercel 서버는 나가는 IP가 고정되지 않아, IP 등록을 요구하는 연동에는 맞지 않음 | 플랫폼 특성 |

## 2. 가능한 방식 5가지 비교
| 방식 | 어떻게 | 장점 | 막히는 점 | 판단 |
|---|---|---|---|---|
| A. 서버가 회원 키로 대신 등록 | 회원이 마켓 키를 설정에 저장 → 우리 서버가 API 호출 | 버튼 한 번에 등록 | **네이버 정책상 불가**, 쿠팡도 불명확, IP 고정 문제 | ❌ 만들지 않음 |
| B. 공식 파트너 등록 | 네이버 커머스솔루션/API대행사, 쿠팡 연동업체로 정식 등록 | 정식·완전 자동 | 법인·심사·수개월, 운영 책임(장애·보안)과 비용 | ⏸ 주인님 사업 결정 |
| C. **마켓 등록 파일 만들기** | 마켓 공식 엑셀 양식에 맞춘 파일 + 이미지 묶음 생성 → 회원이 판매자센터 「일괄등록」에 올림 | 키·IP·심사 없음, 여러 상품 한 번에, 정책 위반 걱정 없음, 화면이 바뀌어도 덜 깨짐 | 회원이 업로드 1번 해야 함, 양식이 바뀌면 맞춰야 함 | ✅ **1단계 추천** |
| D. 크롬 확장 입력 도우미 | 판매자센터 등록 화면을 열면 확장이 칸을 채움, 「등록」은 회원이 누름(블로그 확장과 같은 흐름) | 한 상품을 빠르게, 화면에서 바로 확인 | 등록 화면이 복잡(카테고리·옵션·고시정보), 화면 바뀌면 깨짐, 봇 탐지 주의(`docs/PLATFORM_PATTERNS.md` §20) | 🔸 2단계 후보 |
| E. 회원 PC에서 회원 키로 직접 호출 | 확장·데스크톱 앱이 회원 PC에서 API 호출(키가 서버에 안 옴) | 버튼 한 번에 등록 | 「판매자 직접 연동」으로 볼지 「대신 운영」으로 볼지 **애매**, 네이버 문의 없이 진행하기 위험 | ❌ 지금은 권하지 않음 |

## 3. 추천 단계
### 0단계 — 사전 확인 (무료, 코드 없음)
- 주인님(또는 시험용) **판매자 계정으로 스마트스토어센터·쿠팡 WING에 로그인**(주인님 직접) → 엑셀 일괄등록 양식 내려받기 → 제가 열 구성·필수 칸·이미지 넣는 방법(파일명/주소)·카테고리 코드 표·상품정보제공고시 항목을 분석해 문서로 정리.
- 판매자 계정이 없으면 0단계에서 멈추고 C 방식은 양식 확보 뒤 진행.

### 1단계 — 「📦 마켓 등록 준비」 메뉴 (상품소싱 안)
| 순서 | 화면 | 내용 | 가져다 쓰는 기존 코드 |
|---|---|---|---|
| 1 | 상품 고르기 | ⭐ 관심 상품·소싱 결과에서 「등록 준비에 담기」 | `SavedProductsPanel`, `SourcingResults` |
| 2 | 등록 초안 | 상품명(마켓별 글자 수 검사), 판매가(마진 계산기 값), 카테고리(마켓 코드 고르기), 태그, 옵션(색·크기), 배송비·반품비·출고지, 상품정보제공고시 기본값 | `lib/marketFees.ts`(공용 market-fees), E2 등록 정보 도우미(나중에 연결) |
| 3 | 이미지 | 대표 이미지·상세 이미지: 직접 올리기 또는 **AI 상세페이지 자동화**에서 만든 섹션 이미지 가져오기 | `shopDetailLink.ts`, 상세페이지 내보내기 |
| 4 | 검사 | 필수 칸 빠짐, 금지 단어·과장 표현, 이미지 크기·장수, 가격·할인 오류를 표로 표시 | 새로 |
| 5 | 파일 받기 | 「스마트스토어 일괄등록 파일」 「쿠팡 대량등록 파일」(.xlsx) + 이미지 ZIP | SheetJS 내보내기(주문 리포트 `writeWorkbook`), 무압축 ZIP(셀러 라벨 `rename`) |
| 6 | 안내 | 판매자센터 어디에 올리는지 4단계 카드(매뉴얼 지침) + 「🛒 쇼핑몰 흐름」 다음 단계 | 공용 `shop-flow` |

- **저장 위치**: 등록 초안은 회원 상품 정보라 개인정보는 없지만 「생성 데이터」이므로 **회원 PC 브라우저 저장(주문 리포트와 같은 A안)** 을 기본으로 한다. 서버에 저장하면 30일 자동 삭제 규칙을 따른다(결정 필요 시 주인님께).
- **키·계정**: 이 단계는 마켓 키를 받지 않는다. AI 문구 다듬기를 붙이면 회원 본인 AI 키만 쓴다.

### 2단계 — 크롬 확장 「입력 도우미」 (선택, 1단계 뒤 결정)
- 블로그 핵심 지침과 같은 흐름: **웹에서 완성 → 확장이 판매자센터 등록 화면 칸을 채움 → 「등록」은 회원이 누름**(기본값 「입력만」). 자동 등록 버튼은 두지 않는다.
- 봇 탐지 회피 원칙(사람처럼 입력·간격)을 처음부터 적용. 판매자센터 화면 구조 분석이 먼저 필요(주인님 계정 로그인 상태에서 화면만 읽기).

### 3단계 — 공식 파트너 연동 (주인님 사업 결정)
- 네이버: 커머스솔루션 입점(심사) 또는 API대행사 신청(국내 법인 필요). 쿠팡: 공식 연동 정책 문의부터.
- 우리 서버 IP 고정이 필요하면 별도 고정 IP 서버 비용이 생길 수 있음(운영자 비용 → 프리미엄 후보, `docs/GRADE_AND_BILLING_POLICY.md`).

## 4. 검수 방법 (1단계)
- 단위 시험: 마켓별 필수 칸·글자 수 검사, 엑셀 열 순서가 받은 양식과 같은지(양식 견본 파일로 비교), 이미지 ZIP 파일명.
- 크롬: 시험 계정으로 관심 상품 → 초안 → 파일 받기, 받은 엑셀을 열어 양식과 대조. **실제 판매자센터 업로드는 주인님 계정에서 주인님이 한 번 확인**(실제 상품이 등록되므로 「판매 중지」 상태로 올리거나 바로 삭제할지 정해야 함).
- 휴대폰 폭 390px 넘침 없음.

## 6. 주인님께 여쭐 것
1. **방향 승인**: C(마켓 등록 파일) 1단계 → D(입력 도우미) 2단계 순서로 갈지
2. **판매자 계정**: 스마트스토어·쿠팡 WING 판매자 계정이 있는지, 0단계 양식 내려받기 때 로그인해 주실 수 있는지(쿠팡은 사업자 필요 가능성)
3. **3단계 검토 여부**: 네이버 커머스솔루션/API대행사 정식 등록을 장기 과제로 둘지(법인 여부 포함)
4. 메뉴 이름: 「📦 마켓 등록 준비」(추천) / 「🛍 스토어 등록 파일」 / 「📤 마켓 업로드 도우미」
