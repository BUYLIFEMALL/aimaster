## 1. 무엇을 만드나
셀러가 해외 공장(알리바바·1688·위챗)과 주고받은 **견적서(PDF·엑셀·사진)와 위챗 대화(캡처 사진·복사한 글)**를 한 상품 단위로 올리면, AI가 읽어서

1. 공장별 비교표 — MOQ·단가(통화·수량 구간)·샘플비/금형비·양산 기간·결제 조건
2. 아직 확인 안 된 것 — 인증(KC 등)·로고 인쇄·포장 등
3. 물었는데 답 못 받은 것 — 날짜·공장·질문
4. 다음에 보낼 질문 3개 — 한국어·영어·중국어(복사 버튼)

를 한 화면에 보여 준다. 고른 공장 단가는 **기존 「5대 마켓 소싱 · 마진계산」으로 넘겨** 관세·배송·수수료까지 계산한다(원래 기획 4단계는 이미 있음 — 새로 만들지 않음).

## 2. 기존 기능과 비교 (원본 기획 / AIMaster / 채택)
| 기능 | 원래 기획(`sourcing/`) | AIMaster에 이미 있는 것 | 채택·이유 |
|---|---|---|---|
| 위치 | 독립 폴더·로컬 파일 폴더 `data/[상품]/` | 상품소싱기(`trending-product-finder`) 소싱 흐름 | **상품소싱기 안 메뉴** — 소싱 → 마진계산이 한 곳, 새 프로그램·새 도메인·새 권한 없음 |
| AI | Gemini Vision / Claude 3.5 Sonnet | 기본 AI = Claude, 기준 코드 `smartstore-register/src/lib/ai/claude.ts` | **회원 본인 Claude 키**, 기준 코드 방식(재시도 0·json_schema) 그대로 |
| PDF·사진 읽기 | OCR 따로 | Claude가 PDF·사진을 직접 읽음 | **Claude 문서·사진 입력** — OCR 도구 추가 없음 |
| 엑셀 견적서 | OpenPyXL/Pandas | 등록기에서 `xlsx` 사용 중 | **브라우저에서 `xlsx`로 글로 바꿔** 함께 보냄 |
| 마진 계산 | Landed Cost 수식 | 「5대 마켓 소싱 · 마진계산」(관세청 환율·관세·수수료) | **기존 계산기 재사용**(단가·통화를 주소로 넘김) |
| 질문 번역 | 한·영·중 | 없음 | 같은 AI 호출 1회 안에서 함께 만듦(추가 비용 없음) |

## 3. 화면 흐름 (처음 설정 0단계 · 매일 조작 2번 · 동의 1번)
1. 좌측 메뉴 「🏭 공장 견적 비교」 → 「새 상품」(이름만) 
2. 파일 끌어다 놓기(PDF·jpg/png·xlsx·txt, 상품당 최대 10개·합계 20MB) + 위챗 대화 붙여 넣기 칸
3. 「AI로 비교표 만들기」(비용 안내 1줄: 회원 Claude 키, 1회 약 30~150원) → 결과 4칸
4. 공장 줄의 「마진 계산 →」 → 기존 마진계산 화면에 단가·통화 채워 열림
5. 새 대화·견적이 오면 파일을 더 올리고 다시 만들기(이전 결과는 기록으로 남음)

## 4. 저장 (결정 항목 3에 따라)
- **추천안 A — 원본 파일은 저장하지 않음**: 파일은 분석할 때만 서버를 거쳐 Claude로 보내고 버림. DB에는 회원이 붙여 넣은 글·파일 이름 목록·AI 결과만 저장(회원별·RLS·**30일 자동 삭제**, `retention_exempt` 회원 제외). 저장공간을 쓰지 않아 500MB 한도와 무관.
- 안 B — 원본도 비공개 버킷 회원 폴더에 30일 보관(다시 분석할 때 다시 안 올려도 됨, 저장공간 사용).
- 새 표 2개: `factory_quote_projects`(상품 이름·붙여 넣은 글·파일 목록), `factory_quote_reports`(AI 결과 JSON·모델·만든 시각). 둘 다 `user_id` + owner-only RLS.

## 5. 구현 순서
1. 마이그레이션 SQL(`supabase/migrations/`) → **주인님 승인 뒤 운영 DB 적용**
2. `lib/factoryQuotes.ts`(결과 형태·검사·마진계산 주소 만들기, 순수 함수) + 시험
3. `lib/ai/claude.ts`(기준 코드 사본 방식, `@anthropic-ai/sdk` 추가) + `lib/actions/factoryQuotes.ts`(`requireProgramAccess`, 회원 `anthropic` 키만, 없으면 `/api-settings` 안내)
4. 화면 `app/(dashboard)/factory-quotes/` + 사이드바 메뉴 + 매뉴얼 한 절
5. 30일 정리(기존 정리 라우트에 표 2개 추가)
6. 시험·tsc·build → 미배포 대기(다음 상품소싱기 배포 때 함께)
