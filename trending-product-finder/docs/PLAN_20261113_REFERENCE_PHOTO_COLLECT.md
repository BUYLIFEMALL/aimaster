## 1. 지금 코드 사실
| 항목 | 현재 |
|---|---|
| 소싱 확장 읽기 | 쿠팡 카드: 줄 글·상품 주소·상품명(`extension/lib/page.js`), 네이버: `naver.js`. **사진은 안 읽음** |
| 확장 권한 | 우리 사이트·`www.coupang.com`·`search.shopping.naver.com`만(이미지 서버 권한 없음) |
| API 소싱 결과(알리·도매매·11번가) | 결과 줄에 `imageUrl` 있음(공식 API가 준 주소) — 화면 표시용 |
| 소싱 → 상세 | 주소 값 `from/name/source/price/flow`만(`lib/shopDetailLink.ts`), **사진 없음** |
| 상세 새 상품 | 대표이미지(`source_image_url`) 필수 → 사진 없으면 AI 분석 불가(상품명만 채우기 v1.23은 있음) |
| 등록기 대표사진 | `main_image_url ?? source_image_url`(11번가·스마트스토어) → **수집 사진이 원본 칸에 들어가면 그대로 등록될 위험** |

## 2. 만들 것(흐름)
1. **수집(회원 PC 확장)**: 쿠팡·네이버 쇼핑 검색 카드의 상품 사진 주소를 함께 읽어 확장 목록에 저장. 회원이 「상세페이지로」를 누른 상품만 **확장 뒤편이 회원 브라우저로 사진 1~3장을 받아**(서버 대신 받기 금지) 소싱 웹 화면에 넘김. API 소싱 결과(알리·도매매·11번가)도 같은 방식(이미 받은 `imageUrl`).
2. **넘기기**: 소싱 웹 → 상세페이지 새 상품 창으로 창끼리 전달(누끼·대표사진과 같은 `postMessage` 약속, 새 공용 모듈 `reference-photo-handoff`, 주소 고정·1회용 번호·25MB).
3. **상세페이지 저장**: 받은 사진을 회원 본인 폴더에 올리고 상품의 원본 사진 칸에 넣되 **출처 표시 `source_image_origin = 'collected'`**(새 DB 칸). 화면에 「🔎 수집한 참고 사진 — 등록에는 편집본·새 사진을 쓰세요」 배지. AI 상품 분석·섹션 이미지 생성(새로 만든 그림)은 그대로 이 사진을 입력으로 씀.
4. **등록 차단(핵심)**: 11번가·스마트스토어 등록기는 원본 칸이 `collected`이고 합성·편집 대표사진(`main_image_url`)이 없으면 **대표 이미지로 쓰지 않고 멈춤**: 「수집한 참고 사진은 등록에 쓸 수 없습니다. 바나나 합성·편집본이나 직접 찍은 사진을 대표사진으로 넣어 주세요」. 참고 사진 칸(`reference_image_urls`)에도 수집 사진을 넣지 않음(추가 이미지로 등록되는 칸이라).
5. **고지·동의**: 소싱 확장 첫 사진 수집 때 1회 확인 「원본 사진은 참고용입니다. 저작권은 원 판매자에게 있으며, 그대로 등록하면 신고·판매 정지될 수 있습니다」.

## 3. 범위·제한
- 상품 이미지만(리뷰 사진·사람 얼굴·판매자 정보 제외), 상품당 최대 3장, 하루 상한(기본 50상품), 사람 같은 간격, 차단·로그인 화면이면 즉시 중단.
- 회원 본인 저장공간·상품과 함께 30일(관리자·시험 계정 열외 그대로). 서버에서 마켓 이미지 주소로 직접 요청하지 않음.
- 네이버 쇼핑 자동 검색 보류는 그대로(회원이 연 화면만).

## 5. 검수 기준
1. 쿠팡·네이버 검색 화면에서 카드 사진 주소가 읽힘(시험 + 실물).
2. 「상세페이지로」 → 상세 새 상품 화면에 사진·배지가 채워지고 AI 분석이 됨(회원 본인 Gemini 키, 시험 1회 — 비용 승인).
3. 저장 뒤 11번가·스마트스토어 등록 화면이 「수집 참고 사진은 등록 불가」로 멈춤 → 바나나 합성으로 대표사진을 만들면 통과.
4. 허용 주소 밖 요청·25MB 초과·차단 화면 → 거절/중단.
5. 서버 로그에 마켓 이미지 서버 요청이 없음(전부 회원 브라우저).

## 7. 결정 항목(주인님)
1. ~~어떤 사진까지~~ → **확정(2026-11-13 주인님 「상세페이지까지 같이 받아」): 검색 카드 썸네일 + 상품 상세 페이지의 큰 사진까지.** 구현 기준: (가) 검색 카드 썸네일은 검색 화면에서 함께 읽음 (나) 큰 사진은 **회원이 직접 연 상품 상세 페이지**에서만 확장이 읽음(대표 사진·추가 사진 칸만, 상세 설명 본문 안 그림·리뷰 사진·판매자 정보 제외) — 우리가 상세 페이지를 자동으로 열어 돌지 않음 (다) 상품당 최대 3장(큰 사진 우선, 없으면 썸네일) (라) 확장 권한 추가: 쿠팡 상품 페이지는 기존 `www.coupang.com` 권한 안, 네이버는 상품 페이지 주소(`smartstore.naver.com`·`brand.naver.com`)와 이미지 서버를 새로 추가 → 회원 크롬에 권한 확인 창이 한 번 뜸 (마) 첫 수집 고지에 「큰 사진도 참고용·저작권은 원 판매자」 포함.
2. **대상 판매처**: 쿠팡·네이버 쇼핑 + API 소싱 3곳(알리·도매매·11번가) 모두(추천) / 쿠팡·네이버만.
3. **등록 차단 방식**: 수집 원본만 있으면 등록기가 멈춤(추천) / 경고만 하고 회원이 확인하면 진행.
4. **DB 칸 추가**: `shop_products.source_image_origin`(추천, 등록 차단의 근거) / 칸 없이 파일 경로로 구분(`…/collected/` 폴더 — DB 변경 없음, 대신 옛 상품과 섞일 때 판정이 약함).
5. 진행 범위: 4개 프로그램 한 번에(추천) / 소싱·상세 먼저, 등록 차단은 다음(그 사이 수집 사진이 그대로 등록될 위험).
