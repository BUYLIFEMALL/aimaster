# 📈 상품소싱 자동화 (trending-product-finder)

잘 팔리는 상품, 사람들이 많이 검색하는 상품, 지금 시즌/트렌드에 맞는 상품을 자동으로 발굴·추천해주는 AIMaster 서브프로젝트입니다.

## 핵심 흐름

**A. 키워드를 직접 아는 경우**
1. 회원이 관심 카테고리 + 추적할 키워드(최대 10개)를 등록
2. "지금 리포트 생성"을 누르면:
   - 네이버클라우드 API HUB(쇼핑인사이트)로 키워드별 관심도 지수 추이 조회
   - 코드로 결정적인 "기회 점수" 계산 (관심도 + 상승폭. 경쟁도는 Phase 2에서 추가)
   - 등록된 OpenAI/Gemini 키로 추천 사유 문장 생성
3. 트렌드 리포트 페이지에서 기회 점수 순으로 랭킹 확인

**B. 뭘 소싱할지 아직 모르는 경우 — 카테고리로 후보 상품군 추천받기**
1. 관심 키워드 등록 페이지에서 카테고리 + 대표 시드 키워드 1개(예: "청소기")만 입력
2. 네이버 검색광고 키워드도구로 연관 키워드 + 실제 월간 검색수(PC/모바일) + 경쟁정도를 대량 조회
3. 검색량 상위 후보는 쇼핑인사이트 관심도 추이까지 결합해 "후보점수" 산정, AI가 사유 요약
4. 마음에 드는 후보만 눌러서 관심 목록(A 흐름)에 바로 추가 → 이후 리포트 생성

## 설계 배경 — 두 번 조정한 이유

**1차 조정(설계 단계)**: 원래는 "카테고리 내 인기검색어 TOP500을 자동으로 스캔해서 상승
키워드를 발굴"하는 것까지 생각했지만, 그 TOP500 랭킹은 데이터랩 **웹사이트 UI 전용 기능**이고
공식 Open API로는 노출되지 않는다. 그래서 "회원이 직접 지정한 키워드를 추적"하는 방식으로
설계했다.

**2차 조정(구현 직후, 2026-08-31)**: 처음 구현할 때는 구(舊) `developers.naver.com` 방식의
API(`X-Naver-Client-Id` 헤더, `openapi.naver.com` 도메인)를 그대로 썼는데, 실제로는
**2026년 7월 31일부로 이 방식의 신규 발급이 전면 종료**된 상태였다. 조사해보니:
- **네이버쇼핑 검색 API**(경쟁 상품 수 조회용)는 **완전 종료, 공식 대체 API 없음** — 그래서
  Phase 1에서는 경쟁도 지표를 아예 뺐다(Phase 2에서 쿠팡파트너스로 대체 예정).
- **데이터랩 쇼핑인사이트**는 신규 발급 자체는 가능하지만, **네이버클라우드 플랫폼(NCP) 개인/
  사업자 계정**으로 `console.ncloud.com/naver-api-hub`에서 새로 신청해야 하고, 엔드포인트/
  인증 헤더가 바뀌었다(`api.ncloud-docs.com/docs/naver-api-hub-shopping-insight-*` 문서 기준
  으로 재구현: base URL `naverapihub.apigw.ntruss.com`, 헤더 `X-NCP-APIGW-API-KEY-ID`/
  `X-NCP-APIGW-API-KEY`).

**교훈**: 서비스명이 같아도("데이터랩 쇼핑인사이트") 발급 경로/인증 방식이 통째로 바뀔 수
있으니, 실사용 전 반드시 발급 화면까지 직접 확인할 것 — 이번엔 사용자가 직접 등록 화면을
보고서야 이 문제를 발견했다.

## 조사했지만 채택 보류한 소싱처 (2026-09-01)

"발굴→분석→소싱" 흐름을 알리·쿠팡·네이버 외로 넓힐 수 있는지 조사한 결과, 아래는 공식 API가
없거나 개인 셀러가 즉시 발급받기 어려워 이번엔 제외했다. 나중에 "이건 왜 뺐지?"라는 질문에
바로 답할 수 있도록 이유를 남겨둔다.

| 후보 | 탈락 이유 |
|---|---|
| 오너클랜(OwnerClan) | 공식 답변으로 "외부(타사) API 연동은 아직 준비중" 확인 — 현재는 자사 스마트스토어 연동용 API만 존재 |
| 1688.com Open Platform | 사업자 인증 + 알리바바와의 파트너십 계약 + ISV 승인이 전제조건이라 개인/해외 개발자는 사실상 불가 |
| Alibaba.com Open Platform | B2B 오픈플랫폼 App Key 체계는 있으나 개인 소상공인 승인 기준 불명확(신청해봐야 확인 가능) |
| Temu Open/Partner Platform | "승인된 파트너"만 접근 가능, 일반 개인 신청 경로 확인 안 됨 |
| SHEIN Open Platform | 입점 셀러용 API라 소싱/제휴 목적과 안 맞음(제휴는 CJ Affiliate 등 제3자 네트워크 경유) |
| 지마켓/옥션 ESM Trading API | 판매자(마스터ID) 가입이 선행돼야 해서 "발굴/비교" 목적엔 무겁고, 국내 상품이라 도매매 대비 우선순위 낮음 |
| 에누리 가격비교, 인스타/틱톡 해시태그, 네이버 급상승검색어 | 공식 오픈API 자체가 없음(비공식 스크래핑만 존재 — 이 저장소 원칙상 제외) |

## 다음 자동화 후보 백로그 (2026-09-02 조사)

"발굴→분석→소싱" 다음 단계, 즉 회원이 소싱 후보를 찾은 뒤에도 여전히 손으로 해야 하는
작업(알림 확인, 판매처 등록, 가격/재고 추적, 여러 키워드 반복 계산)을 자동화할 수 있는지
조사한 결과다. 우선순위는 "신규 API 발급 없이 기존 인프라로 바로 착수 가능한가"를 기준으로
나눴다.

**1순위 — 신규 API 발급 불필요, 기존 인프라 재사용**

| 후보 | 내용 | 비고 |
|---|---|---|
| 경쟁도 지표 부활 | Phase 7에서 이미 연동한 `lib/elevenst/client.ts`로 키워드별 등록 상품 수·평균가를 조회해 리포트 세 번째 신호로 추가 | 쿠팡파트너스 승인 없이도 Phase 2 목표를 사실상 대체 |
| threads-affiliate-poster 연결 | 소싱 후보 카드에 "쓰레드 홍보글 만들기" 버튼 → 원클릭 이동 | 두 서브프로젝트 모두 완성 상태, 연결 로직만 필요 |
| 리포트 이메일 알림 | 매일 자동 생성 리포트를 이메일로 요약 발송 | 루트 AIMaster `lib/email/*`(운영자 SMTP, 가입환영/구독만료 메일과 동일) 재사용 — 회원별 API 키 불필요, BYOK 원칙과 무관한 플랫폼 알림 |
| 일괄 마진계산 + CSV | 관심 키워드 전체를 한 번에 계산해 마진율 순 정렬, CSV로 내보내기 | 순수 UX/배치처리 개선 |

**2순위 — 신규 API 필요하지만 개인도 무료 즉시 발급 확인됨**

| 후보 | 내용 | 발급 근거 |
|---|---|---|
| 환율 자동 반영 | 원가 원화환산 기준 환율을 매일 자동 갱신 | 한국수출입은행 Open API(`oapi.koreaexim.go.kr`) — 본인인증만으로 무료 발급, 일 1,000회 제한 |
| 관세율 참고표 | 품목군별 대표 관세율을 `/fees`류 페이지로 제공 | 공공데이터포털 [관세청 관세환율정보](https://www.data.go.kr/data/15101230/openapi.do) — 무료 발급. 다만 상품 단위 HS코드 완전자동 매칭은 어려워 참고표 형태로 우선 제공 |
| 가격/재고 추적 알림 | 저장된 소싱 후보를 크론으로 주기 재조회해 품절·가격인상 감지 | Phase 4a 크론 인프라 재사용 |
| 기회점수 임계값 알림 | 점수가 기준(예: 80점) 이상인 키워드만 즉시 알림 | Phase 10(이메일 알림) 완료 후 이어서 착수 |

**3순위 — 신중 검토 (진입장벽 있음)**

| 후보 | 내용 | 리스크 |
|---|---|---|
| 스마트스토어 상품 자동등록 | 소싱 후보를 스토어 초안 상품으로 바로 등록 | 네이버 커머스API센터 앱 등록, 개인 판매자 가능 여부는 실제 신청 화면에서 재확인 필요 |
| 쿠팡 Wing Open API 상품등록 | 상품/가격/재고 관리(파트너스 제휴 API와 별개) | 쿠팡 셀러 가입 자체에 사업자등록이 필요할 가능성 높아 BYOK 진입장벽이 가장 큼 |

## 회원이 직접 연동해야 하는 것 (설정 페이지)
- 네이버클라우드 API HUB Client ID/Secret — `console.ncloud.com/naver-api-hub/application`에서
  개인 회원가입(사업자등록 불필요, 무료)으로 애플리케이션 등록 후 "쇼핑인사이트" 선택
- 네이버 검색광고 ACCESS LICENSE/SECRET KEY/CUSTOMER ID(선택) — `searchad.naver.com`에서
  개인/사업자 광고주로 무료 가입 후 도구 > API 사용 관리에서 발급. "카테고리로 후보 상품군
  추천받기" 기능에만 필요
- OpenAI 또는 Gemini 중 1개 — 추천 사유 생성용 (없어도 기회 점수/후보점수 계산 자체는 동작)
