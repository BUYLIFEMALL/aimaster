# 개선 제안 — AI 가사영상 자동화

> 작업 중 발견한 과제를 즉시 기록한다(`docs/IMPROVEMENT_HANDOFF_POLICY.md`). 미구현 제안은 완료로 표시하지 않는다.

## 1. 프로그램 로직·기능 개선
| # | 내용 | 근거 | 우선순위 | 상태 |
|---|---|---|---|---|
| L1 | Suno 곡 가져오기 + 시간 가사 자동(`get-timestamped-lyrics`, `music_tracks.task_id`·`suno_audio_id`) | 참고 앱의 최대 약점(.srt 직접 제작) 해소, 2026-10-21 주인님 2차 승인 | 높음 | 대기(2차) |
| L2 | 줄 끝 시각을 따로 정하기(지금은 다음 줄 시작 = 끝) | 간주가 긴 곡에서 앞 줄이 오래 남음 | 중간 | ✅ v1.02 완료(끝 칸·엔터 키, 크롬 실제 키 입력 검수) |
| L3 | 긴 곡(12분 초과)·저사양 PC: 결과를 메모리에 모으지 않고 파일 시스템 접근 API로 바로 디스크에 쓰기 | 공용 인코더는 `ArrayBufferTarget`(메모리) | 중간 | ✅ v1.02 완료(공용 엔진 `encodeMp4ToFile`, OPFS 쓰기 대상으로 20초 1080p 정상 확인) |
| L4 | 노래방 로마자 발음 표기(한글 음절 규칙 변환, AI 불필요) | 참고 앱에 있는 기능 | 중간 | 대기(2차) |
| L5 | 미리보기 `play()` 실패를 화면 안내로 보여 주기(지금은 조용히 무시) | 자동 재생 차단 환경 | 낮음 | 대기 |

- `playlist-channel-studio/src/lib/render/video-exporter.ts`: 해상도가 가로 1920×1080/1280×720으로 고정되어 세로 영상이 없고 글자 그리기가 없다(2026-10-21 코드 확인). 가사 층을 넣을 때 세로 대응도 함께 필요.
