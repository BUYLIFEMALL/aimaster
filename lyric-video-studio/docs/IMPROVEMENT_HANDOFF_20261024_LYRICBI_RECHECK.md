## 4. 꼭 알아야 할 것

- **권리:** Lyricbi는 비공개 상용 — 코드·수식·문구·프리셋 값 없이 우리 것으로. 로마자 변환도 공개 표기 규칙으로 새로 작성.
- **미리보기와 MP4가 같은 `drawFrame`을 쓰는 구조 유지** — 회전·움직임은 시간으로만 정해 프레임마다 같은 값(앰비언트 배경과 같은 방식).
- **공용 기준 코드:** `free-photo-search` 사본은 직접 고치지 않음(`node scripts/check-shared-modules.mjs --sync`), 사본 목록에 이 프로그램 추가. 오류 형식은 이 프로그램 형식으로 바꿔 던짐.
- **회원 연동 정보:** Pixabay·Pexels 키는 공용 연동 항목(`member_platform_accounts`/`user_api_keys`, `docs/MEMBER_INTEGRATIONS.md`)에서 재사용 — 새 등록 화면을 만들지 않음.
- **플레이리스트 모드는 하지 않음** — `playlist-channel-studio`(음악 담당이 Spectrum 묶음 P-1~P-6도 인계받음)와 겹침.
- 대기 항목 `?remix=`(IMPROVEMENTS 2026-10-22) — 따로 배포하지 말고 다음 빌드에 함께.
