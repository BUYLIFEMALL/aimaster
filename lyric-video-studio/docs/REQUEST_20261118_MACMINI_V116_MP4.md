## 순서
1. 음악 1개 준비(유료 생성 금지): 20초 안팎 기존 파일, 또는 ffmpeg가 있으면 `ffmpeg -f lavfi -i sine=frequency=440:duration=20 -ac 2 mac20.wav`
2. 「1 음악·가사 넣기」에서 음악 선택, 가사 칸에 아래 2줄 붙여넣기 → 「가사 적용」
   ```
   [00:01.00]맥 시험 첫 줄
   [00:10.00]맥 시험 둘째 줄
   ```
3. 왼쪽 메뉴 「4 MP4 내보내기」로 이동(**주소 새로고침 금지** — 넣은 음악이 사라짐). 「만들기 전 확인」 4개 ✅ 확인
4. **시험 A(메모리 방식)**: 「💾 파일로 바로 저장」 끈 채 「🎬 MP4 만들기」 → 100%·「완료 · N초」 → 「⬇ … 내려받기」
5. **시험 B(파일로 바로 저장 — 이번 수정 경로)**: 「💾 파일로 바로 저장」 켬 → 「🎬 MP4 만들기」 → 저장 창에서 이름 `mac-file.mp4` → 「💾 「mac-file.mp4」로 저장했습니다」 확인
6. 매 시험 뒤 「🩺 렌더 진단 기록」 펼쳐 「📋 진단 복사」 → 텍스트 파일로 보관(`diag-A.txt`, `diag-B.txt`)

## 합격 기준
- 진행이 5% 등에서 멈추지 않고 100% 도달, 「■ 취소」 없이 끝남
- 진단 「인코더:」 줄의 가속 여부를 적는다. 「영상 인코더가 응답하지 않아 기본 방식으로 다시 만드는 중…」이 보이면 = 실제 멈춤 뒤 대체가 동작한 것(끝까지 완료되면 합격, 진단을 꼭 보관)
- 파일: 20초 기준 h264 1920×1080 30fps 약 600프레임 · aac 2채널 · 약 20초, QuickTime에서 끝까지 재생, 가사 줄 강조
- 실패: 10초 넘게 진행이 멈춘 뒤 오류 상자, 또는 0바이트·재생 불가 → 그 화면 캡처와 진단을 보관

## 결과 전달
- A 파일·`mac-file.mp4`·`diag-A.txt`·`diag-B.txt`를 저장소 **밖** 공유 폴더 `/Volumes/gt1_mega/PDS/mus-mac/`(= 윈도우 `D:\PDS\mus-mac\`)에 둔다. 맥에 ffprobe가 있으면 `ffprobe -v error -show_entries stream=codec_name,width,height,nb_frames,duration -of compact <파일>` 결과도 함께
- 윈도우 음악 담당이 그 폴더의 지정 파일만 `ffprobe`·전체 디코드(`ffmpeg -xerror`)로 판정
- 맥 장비 정보(칩: Intel/Apple Silicon, macOS·브라우저 버전)를 꼭 적는다
- **Apple Silicon 확인은 장비가 준비되면 하는 일로 정리됨(2026-11-18 주인님 「이건 준비가되면 하는것으로 완료해」)** — 지금은 Intel 맥으로 할 수 있는 만큼만 하고, Apple Silicon을 「미검수」로 따로 보고하지 않는다. 장비가 준비되면 이 요청서를 그대로 다시 실행
