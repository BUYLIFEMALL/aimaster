- `StudioBar`(프로젝트 이름·저장 상태·저장), `FileDrop`(끌어다 놓기), `Preview`(미리보기 캔버스, 가로 16:9 / 세로 9:16 틀), `Transport`(재생 막대), 프리셋 카드(배경 그라데이션 + 강조색 세로 막대), 칩 선택, 싱크 목록(현재 줄·재생 중 줄 강조).

## 모바일(767px 이하)
- 좌측 메뉴 숨김 → 위쪽 ☰ 메뉴(Sidebar 공통 마크업). 싱크 목록은 3줄 배치(번호·시간·± / 문구 / 버튼), 버튼 최소 44px, 2열 입력은 1열.
- 2026-10-21 운영 주소에서 390px iframe으로 5개 화면 확인: 데스크톱 메뉴 숨김·위쪽 메뉴 표시·가로 넘침 없음(창이 최대화라 창 크기 대신 iframe 방식).

## 검수 증거(2026-10-21, 메인 크롬, 일반 회원 계정)
- 대시보드 입장(부여한 사용기간), 1단계 음악·자막(형식 섞인 .srt 5줄) → 좌측 메뉴 이동 후 상태 유지 → 재생 중 강조 → 가로 MP4 1920×1080·20.01초·H.264+AAC(6초) → 저장 → 새로 열기 후 보관함에서 다시 열기(음악 재선택 안내).
- 로컬: 세로 노래방 채움 절반 표시 확대 확인, 세로 MP4 1080×1920, 밝은 종이 프리셋, 실제 키보드 탭 싱크(2.24·5.25·8.30초).

## 주의
- 메뉴·단계 이동은 `next/link`만(일반 링크는 작업 상태 초기화).
- 미리보기와 내보내기는 같은 `drawFrame` — 화면 모양을 바꿀 때 CSS가 아니라 그리기 함수를 고친다.
