## 범위
| 항목 | 내용 | 파일 |
|---|---|---|
| 내 Suno 곡 목록 | 회원 본인이 음악(SUNO) 자동화에서 만든 **완성된 보컬 곡**(`music_tracks` + 변주 `music_track_variants`)만 서버에서 `user_id`로 걸러 보여 준다. 인스트루멘탈은 가사가 없어 제외 | `src/lib/suno.ts`, `GET /api/suno/tracks` |
| 곡 가져오기 | 변주를 고르면 음악·커버를 **1시간짜리 서명 주소**(비공개 저장소 `music-audio`)로 받아 브라우저에서 `File`로 바꿔 기존 `loadAudio`·`loadCover`에 넣는다. 제목도 채움 | `GET /api/suno/tracks?variant=`, `SunoImportCard.tsx` |
| 시간 가사 자동 받기 | 회원 **본인 Suno 키**(`user_api_keys` provider `suno`, 폴백 없음)로 sunoapi `POST /api/v1/generate/get-timestamped-lyrics`(taskId·audioId) → 단어별 시각(`alignedWords`)을 줄 단위 시간표로 바꾼다. 구간 표시 `[Verse 1]` 제거, 줄바꿈 기준으로 줄 나눔 | `src/lib/sunoAlign.ts`(+시험), `POST /api/suno/timed-lyrics` |
| 실패 시 | 키 없음 → 「음악(SUNO) 자동화 설정에서 본인 키 등록」 안내 + 가사 글만 넣기(시간 없음 → 싱크 화면에서 맞춤). 시간 가사 실패 → 같은 대체 | 같은 화면 |
| 바로 가기 | `/source?suno=<변주 id>`로 열면 자동으로 그 곡을 가져온다(작업 중이면 바꿀지 먼저 확인) | `SourceView.tsx` |
| 곡 카드 링크 | 음악(SUNO) 자동화 곡 카드(보컬·Suno 번호 있는 변주)에 「🎬 가사 영상 만들기 →」(새 창) | `music/components/plannings/TrackCard.tsx` — **다른 세션의 music v1.21 작업이 커밋된 뒤** 진행, music 버전 +0.01 |

## 확인한 사실
- 2026-10-21 시험 계정 본인 키로 1회 호출: 81단어, 실패 0, 단어 안에 `\n`·`[Verse 1]`가 섞여 옴(`"[Verse 1]\n비 "`, `"서서\n"`). 응답 키 `alignedWords·waveformData·hootCer·isStreamed`.
- `music_tracks`↔`music_track_variants` 관계가 2개라 조회 때 `music_track_variants!music_track_variants_track_id_fkey`로 지정해야 한다.
