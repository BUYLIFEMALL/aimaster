> 주인님 결정(2026-10-21): 새 프로그램으로 만들고 이름은 **「AI 가사영상 자동화」**, 1차부터 시작, **권한 부여 방식**(FREE 배지 없음), 2차에 음악(SUNO) 자동화 곡 카드 「가사 영상 만들기 →」 링크 진행.
> 근거 분석: [`docs/analysis-lyricbi-20261021/REPORT.md`](../../docs/analysis-lyricbi-20261021/REPORT.md). 대상: ① AIMaster 운영(DB ref `esgxyikcnnvmlhygjkth`).

## 1. 문제와 목표
- 문제: 음악과 가사로 「가사가 흐르는 영상」을 만드는 기능이 AIMaster 82개 프로그램 어디에도 없다. 참고한 외부 앱(Lyricbi)은 가사 시간 파일(`.srt`)을 사람이 직접 만들어야 하고 Windows 설치형이다.
- 1차 목표: **설치 없이 브라우저에서**, 음악 1곡 + 가사(파일 또는 붙여넣기 후 탭 싱크)로 **가로 16:9 / 세로 9:16 가사 영상 MP4**를 만든다. 유료 API·AI 호출 0회.

## 3. 1차 범위 (v1.01)
| 메뉴 | 기능 |
|---|---|
| 🏠 대시보드 | 사용 순서 4단계 카드, 최근 프로젝트 |
| 1 🎵 음악·가사 넣기 | 음악 파일(mp3·wav·m4a·ogg·flac), 앨범 커버(선택), 제목·아티스트, 가사: `.srt`·`.lrc` 파일 또는 가사 붙여넣기 |
| 2 ⏱️ 가사 싱크 | **탭 싱크**: 재생하면서 스페이스바(또는 버튼)로 줄 시작 찍기, 줄별 ±0.1초·직접 시간 수정·줄 문구 수정, 전체 시간 밀기, 자막 형식 오류에 너그러운 읽기 |
| 3 🎨 디자인 | 프리셋(가로 6·세로 4), 화면비, 서체 6종(Google Fonts 한글), 색, 현재 줄 강조 7종(색·채운 박스·테두리 박스·형광펜·밑줄·앞 막대·노래방 채움), 앞뒤 줄 수, 커버 패널/흐린 배경, 소리 반응 스펙트럼 3종, 진행 바, 움직이는 배경 |
| 4 🎬 MP4 내보내기 | 1080p 가로/세로, 24·30fps, 진행률·취소, 결과 내려받기. 미리보기와 같은 그리기 함수 사용 |
| 🗂️ 내 보관함 | 프로젝트(가사 시간표·디자인·제목) 서버 저장·다시 열기·삭제. 음악·커버 파일은 서버에 올리지 않고 다시 열 때 다시 선택(파일 이름 안내) |
| 📖 연동 & 사용 매뉴얼 | 8대 매뉴얼 템플릿 스타일 + Step 1~4 카드(`docs/MANUAL_AND_INTEGRATION_GUIDELINES.md`) |

1차에서 하지 않는 것(2·3차): Suno 곡 가져오기·시간 가사 자동 받기, 음악(SUNO) 자동화 곡 카드 링크, 노래방 로마자 발음, LP판, 플레이리스트(여러 곡·앨범 카드·챕터), Pexels, 로고·프레임, AI 제목·설명.

## 6. 구현 순서와 확인 방법
1. 뼈대 복사·이름 변경 → `npx tsc --noEmit`
2. 가사 읽기(`.srt`·`.lrc`·붙여넣기) + 단위 시험(`node --test`, 형식 틀린 자막 포함) → 통과
3. 그리기 함수·프리셋 → 로컬 화면에서 미리보기 확인
4. 탭 싱크 편집기 → 로컬에서 실제 음악 파일로 확인
5. MP4 내보내기 → 로컬에서 30초 곡으로 실제 MP4 생성, 소리·가사 시각 일치 확인
6. 보관함 API(권한 확인·같은 출처·본인 `user_id` 조건) → 승인 후 DB 적용
7. `npm run build` → GitHub 커밋·푸시 → Vercel 새 프로젝트·환경변수(기존 프로그램과 같은 Supabase 값)·`vercel domains add lyric-video-studio.buylife.xyz`·`vercel deploy --prod`
8. 크롬 실제 창(메인 크롬)에서 시험 계정으로 로그인 → 4단계 실제 흐름 + 375px 좁은 화면 검수, 관리자 계정으로 카탈로그 확인
9. 메인 사이트 상세 소개(`docs/PROGRAM_DESCRIPTION_STANDARD.md`)·썸네일, 역량 지도 카드, 인수인계 6종 문서, VIP 자동 부여 확인
