## 2. 적용할 디자인 템플릿 — 「크리에이티브 아틀리에 스타일 — 코믹 파스텔 변형」 (새 이름, `DESIGN.md` 카탈로그 등록)
- 카탈로그에서 4컷 만화는 크리에이티브 아틀리에의 대표 예시이고, 현황판 권장 배경은 **파스텔 크림**. 만화 작업은 밝고 경쾌한 분위기가 맞아 다크 대신 라이트 변형으로 한다.
- 컬러 토큰(안): 배경 `#fffaf2`(크림) · 카드 `#ffffff` · 테두리 `#f1e6d6` · 글자 `#1f2430`(먹색) · 메인 포인트 `#ff6b57`(코랄) · 보조 `#ffc94d`(머스타드) · 정보 `#5b8def`(스카이) · 선택 배경 `#fff1ec`.
- 만화 느낌 요소: 카드 테두리 2px 먹선 + 살짝 어긋난 그림자(`3px 3px 0 #1f2430`), 단계 칩을 말풍선 모양으로, 컷 미리보기는 만화 칸처럼 굵은 테두리.
- 모든 화면(만들기·내 작품·설정·매뉴얼·로그인·설치) 같은 배경·카드·테두리로 통일(지침 ⑪).

## 3. 구현 범위 (화면·문구만, 기능 로직은 그대로)
1. `globals.css` 토큰·공통 컴포넌트(카드·버튼·칩·단계·입력) 교체 — 클래스 이름은 그대로 두고 값만 바꿔 `Studio.tsx` 로직을 건드리지 않음.
2. `Sidebar.tsx`: 브랜드 아이콘·단계 표시를 코믹 스타일로, 메뉴 항목·순서·계정 위치(메뉴 바로 아래)는 그대로. 메뉴 이름 `📖 연동 & 사용 매뉴얼`로 표준화.
3. `/studio` 상단에 진행 단계 띠(① 주제 → ② 대본 → ③ 캐릭터 → ④ 컷·말풍선 → ⑤ 저장)를 말풍선 칩으로 정리, 컷 그리드를 만화 칸 모양으로.
4. `/guide` 비주얼 매뉴얼로 재구성(지침 ④·⑦): 캐릭터 말풍선 소개, 5단계 흐름 그림(이모티콘+화살표), 스타일 8종·컷 수·비율 비교 카드, 잘 나오는 요령, 개인정보·비용 주의, FAQ. 기존 안내 내용은 빠짐없이 옮김.
5. `/works`·`/settings`·`/login`·`/setup`: 같은 토큰 적용.
6. 모바일 375~390px: 위쪽 접는 메뉴 유지, 컷 그리드 2열, 말풍선 편집 손잡이 24px 이상(기존 규칙 유지).
