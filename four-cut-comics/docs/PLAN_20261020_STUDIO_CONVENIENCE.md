| # | 기능 | 구현 |
|---|---|---|
| 1 | 단계 칩 이동 | `reached`(가 본 가장 뒤 단계) 상태 + `canJumpToStep` — 가 본 단계는 앞뒤 이동, 지금 단계·생성 중·대본 없음은 막음. 새 대본·다음 화·새 이야기 때 `reached` 초기화 |
| 2 | 저장 전 닫기 경고 | `hasUnsavedWork`(대본이나 그림이 있고 지금 화를 [내 작품]·서버 보관함 어디에도 저장 안 함) → `beforeunload` |
| 3 | 일괄 생성 진행률 | 캐릭터·컷 일괄 생성 루프에서 `progress {done,total}` → 버튼 문구 「그리는 중 2/4」 + 진행 막대(`progressLabel`) |
