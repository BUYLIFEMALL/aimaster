# 개발 플랜 — v1.15 INSTA 자동포스팅으로 넘기기 (2026-10-20, Claude Code 윈도우)

> 대상 ① AIMaster 운영. 백로그 「외부 연계」 1건. 주인님 지시 「4번 백로그 작업 진행해줘」.

| 항목 | 내용 |
|---|---|
| 문제 | 인스타 문구를 만든 뒤 INSTA 포스팅 자동화로 옮기려면 그림 저장·문구 복사·INSTA 열기를 회원이 따로 해야 함 |
| 범위 | `four-cut-comics`만 수정. INSTA(`insta_auto_poster`)는 수정하지 않고, 이미 있는 새 글 화면(`/posts/new?caption=&hashtags=`)과 「이미지 파일 직접 첨부」를 그대로 사용 |
| 동작 | 인스타 문구 칸 [INSTA 자동포스팅으로 올리기] → ① 문구 복사 ② 새 탭으로 INSTA 새 글 화면(주소 6000자 이하면 문구·해시태그 미리 채움, 넘으면 화면만) ③ 바둑판 그림 `4컷만화-인스타.jpg` 내려받기 ④ 「이미지 파일 직접 첨부에 올려 주세요」 안내 |
| 구현 | `src/lib/comic/extras.ts` `INSTA_NEW_POST_URL`·`instaHandoffUrl()`(시험 대상), `Studio.tsx` `sendToInsta()`(팝업 차단을 피하려고 새 탭을 먼저 열고 그림 저장) |
| 검수 | tsc·단위 시험(+1)·빌드 → 배포 → 크롬: 버튼 → INSTA 새 글 화면 문구 채움 확인(게시는 하지 않음) |
| 비용 | 없음(크롬 확인에 인스타 문구 글자 AI 1회 정도) |
| 버전 | v1.15(코드 `src/lib/version.ts` + DB `programs.version`) |
| 왜 이미지 자체는 넘기지 않나 | 프로그램끼리 서로 호출하지 않는 원칙(공용 기준 코드 규칙)과, INSTA가 다른 프로그램의 저장소를 읽지 않는 구조 때문에 회원이 내려받은 그림을 직접 첨부하게 함. 나중에 공용 이미지 넘겨받기 기능이 생기면 교체 |
