- 작성: 2026-10-20 Claude Code(윈도우) · 대상: ① AIMaster 운영 · **DB 구조 변경 없음**(버전만)
- 근거: 「모든 인스타 자동화 프로그램은 자동 포스팅까지」(2026-10-19) → 확대 순서 인플루언서·웹툰 완료 → 4컷. 주인님 「진행해줘」(2026-10-20)

## 문제
v1.15·v1.16의 「INSTA로 넘기기」는 그림을 내려받아 INSTA 새 글 화면에 다시 첨부해야 한다(2단계). 4컷 화면에서 바로 게시하면 한 번에 끝난다. 넘기기 버튼은 INSTA에서 예약·편집하고 싶은 회원을 위해 그대로 둔다.

## 범위
| 항목 | 내용 |
|---|---|
| 형식 | ① 바둑판 합본 1장(피드) ② 컷별 캐러셀(컷 수만큼, 2~10장) |
| 비율 | 인스타 피드 비율(4:5~1.91:1)을 벗어나면 **자르지 않고 흰 여백을 붙여** 맞춤(컷·말풍선 보존) |
| 캡션 | 「인스타 문구 만들기」 결과(문구+해시태그)를 채우고 고칠 수 있음, 2200자 |
| 확인 | 연결 상태(INSTA에서 한 번 연결한 공용 `insta_accounts`), 공개 게시 확인 체크 후 게시, 결과·게시물 보기 |
| 서버 | `/api/instagram`(연결 상태)·`/upload`(서명 업로드 주소)·`/publish`(게시 후 임시 사진 삭제), 공용 `publish.ts` 사본 추가 |
| 저장소 | INSTA 공개 저장소 `insta-post-images/{userId}/fourcut-insta/{묶음}/NN.jpg` — 게시 직후 삭제 |
