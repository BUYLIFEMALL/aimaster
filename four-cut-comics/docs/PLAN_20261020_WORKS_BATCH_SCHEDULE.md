## 범위
| 구분 | 내용 |
|---|---|
| 내 작품 맨 위 「📤 인스타그램 예약」 상자 | 예약 대기 요약(n건·다음 게시) + 최근 30일 게시 기록(예약 취소) |
| 📚 여러 회차 한 번에 예약 | 「이 브라우저」·「서버 보관함」 작품을 체크해 고르면 회차(화) 순서대로, 첫 회차 시각부터 매일·3일·매주·2주 간격으로 예약. 회차마다 바둑판 그림 1장 = 게시물 1개(피드 비율 밖이면 흰 여백), 캡션 = 「제목 N화」+해시태그 |
| 사전 검사 | 회원별 대기 예약 20건·첫/마지막 시각(10분 뒤~60일) 화면에서 먼저 경고·버튼 막음(서버 검사는 그대로) |
| 정리 | 게시 기록 목록을 `InstaPostHistory`로 분리해 게시 칸·내 작품이 같이 사용, 그림 변환·올리기를 `src/lib/instagram/feedRender.ts`로 분리 |

## 순서
1. 순수 함수(`feed.ts`: 간격 계산·작품 정렬·캡션) + 시험 → 2. 분리(feedRender·InstaPostHistory) → 3. 내 작품 상자 → 4. 시험·타입·빌드 → 배포 → DB 버전 → 크롬(작품 2개 넣어 묶음 예약 → 기록 → 취소) → 문서·커밋
