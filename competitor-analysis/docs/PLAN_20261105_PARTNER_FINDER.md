## 0. 한 줄 요약
키워드·주제를 넣으면 **그 주제에 실제로 맞는**(매칭) 블로그·업체·카페·쇼핑몰 채널을 찾고, 그 사람들이 **홍보 목적으로 스스로 공개해 둔 이름(닉네임·아이디)과 연락처(핸드폰 > 일반전화 > 이메일)**를 **회원 PC에서 자동 스캔**해 회원 계정에 모아 내려받게 하는 도구. 우리는 시스템·저장 공간만, 수집은 회원 기기.

## 2. 지키는 선 (어느 단계에서도 그대로)
- **공개된 비즈니스 연락처만**(마케팅 수집 예외 지침 §4, 주인님 10-27 「자동화 프로그램으로 수집해도 되」). 비공개·로그인해야만 보이는 것·**플랫폼이 숨긴 정보(예: 카페 회원 네이버 아이디) ❌**.
- **탐지·차단 우회 ❌** — 사람 같은 속도·상한으로 「안 걸리게」까지만, 보안문자·「제한」 안내가 뜨면 **그날 중지**(주인님 「안 걸리게까지만, 걸렸을 때 뚫기는 안 함」 합의).
- **우리 서버는 채널 페이지에 접속하지 않음**(지침 §3-1) — 서버는 공식 검색 API(회원 키)만, 페이지 읽기는 회원 PC 확장.
- **동의 없는 광고 발송 ❌**(정보통신망법 제50조). 연락은 회원이 공개 목적(제휴·문의) 범위에서 직접.
- ⚠️ **법적 위험 고지**: 이메일을 자동수집 프로그램으로 모으는 것은 정보통신망법 제50조의2 위험(목적 불문, 1년 이하 징역/1천만원 이하 벌금). 주인님 지침 §4 결정으로 진행하되, 켤 때 고지에 명시하고 이메일 수집은 회원이 끌 수 있게(§5-3).
- 회원 본인 키·소유 격리(RLS)·30일 보관(관리자·시험 계정 열외)·공유/판매/AI 학습 ❌(검색 API 약관 2026-09-07).

**흐름**
1. 웹 「스캔 시작」 → 서버가 그 회원의 `scan_status=pending` 매칭 채널 목록을 확장에 줌(기기 토큰)
2. 확장이 회원 PC의 같은 창 전용 탭에서 채널 공개 페이지를 하나씩 열기:

| 채널 종류 | 여는 공개 페이지 | 읽을 자리 |
|---|---|---|
| 블로그 | `blog.naver.com/<id>` 프로필·소개 | 블로그명·별명·소개글·프로필 링크 |
| 업체 | 플레이스 상세(검색 결과 `link` 또는 지도 상세) | 상호·대표 전화(공개된 경우)·홈페이지 |
| 카페 | 카페 대문·소개 | 매니저 공개 연락처·소개 |
| 쇼핑몰 | 스마트스토어 판매자 정보 | 법정 공개 사업자 정보(상호·대표 연락처·이메일) |

3. 화면에 **보이는 글자**에서 추출합니다.
   - 핸드폰 `01[016789]-?\d{3,4}-?\d{4}`
   - 일반전화 `0(2|[3-6][1-5]|70|50\d)-?\d{3,4}-?\d{4}`(050 안심번호 포함)
   - 이메일
   - 이름·아이디
   - 대표 연락처는 **핸드폰 > 일반전화 > 이메일** 순으로 고릅니다. `scoreProfile`로 매칭 점수를 더합니다.
4. 결과를 서버에 보내 저장합니다(`scan_report`). 다음 채널로 넘어갑니다.

**속도·상한**: 페이지 사이 4~9초 무작위, 10곳마다 1~3분 쉼, 하루 상한 기본 300곳(조절), 동작 시간대 09~22시

**멈춤**: 보안문자·로그인 풀림·「제한/비정상」 문구·화면 구조가 다르면 그날 중지, `stopped` 기록, 다시 시도 없음

**읽지 않는 것**: 로그인해야만 보이는 영역, 숨긴 값, 내부 API 우회 응답. 시스템이 「사이트 접근 우회」로 자동 차단한 내부 API 탐색은 다시 하지 않음
