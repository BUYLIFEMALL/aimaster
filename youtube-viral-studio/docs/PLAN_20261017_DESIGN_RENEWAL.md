## 1. 템플릿 (권장안)
**유튜브 다크 콘솔 스타일 — 스튜디오 변형** + 스마트 매트릭스 구성(지표 카드·필터 바·표/그리드 전환).
- 같은 유튜브 계열인 `youtube-auto-reply` v1.09(주인님 「유튜브 느낌」 승인, ✅ 배포)와 **같은 `yt-*` 토큰·부품**을 Tailwind v4(`@theme`)로 이식 → 유튜브 프로그램끼리 통일감.
- 배경 `#0f0f0f` · 카드 `#181818`/`#212121` · 선 `#303030` · 글자 `#f1f1f1`/`#aaaaaa` · 유튜브 레드 `#ff0000` · 링크 `#3ea6ff` · 등급 칩(초대박 레드 / 대박 앰버 / 떡상 초록 / 양호 회색)
- 대안: 현황판 권장 그대로 스마트 매트릭스 다크 슬레이트(`#0f1115` + 블루). 주인님이 고르시면 그대로.

## 2. 현재 문제 (분석)
- 흰 배경 + 하늘색 선택 표시(유튜브 로고만 빨강) — 유튜브 도구인데 유튜브 느낌이 약함. 로그인 화면도 밝음.
- **휴대폰에서 메뉴가 아예 없음** — 사이드바가 `hidden md:flex`이고 위쪽 바·☰가 없어 다른 화면으로 이동 불가(원칙 19 위반, 높음).
- 「대시보드」 메뉴가 실제로는 `/viral-shorts`(1번 메뉴와 같은 화면) — 대시보드가 따로 없음.
- `(dashboard)/layout.tsx`에 `fetchCache = "force-no-store"` 누락(멀티테넌시 원칙 1 — 두 줄 세트). API 라우트는 둘 다 있음.
- 즐겨찾기가 브라우저 `localStorage`에만 저장(기기 바꾸면 사라짐) — 이번 범위 밖, 개선 제안으로 기록.
