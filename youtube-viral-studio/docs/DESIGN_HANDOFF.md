## 1. 템플릿 선정 이유 및 핵심 가치
- 텍스트 위주의 지루한 데이터 테이블 방식에서 탈피하여, 크리에이터가 가장 먼저 반응하는 **대형 비주얼 썸네일 카드 덱**을 전면에 배치.
- 16:9 와이드 및 9:16 쇼츠 비율의 썸네일 위에 **실시간 VPH(시간당 조회수) 오버레이 배지**와 **구독자 수 대비 조회수 역전 배수 배지**를 직관적으로 결합하여, 한눈에 어떤 영상이 진짜 떡상 중인지 1초 만에 판별.

## 2. 디자인 토큰 및 UI 컴포넌트

### 컬러 시스템
- **메인 배경 서피스**: `bg-[#F8FAFC]` (슬레이트 50 캔버스)
- **카드 서피스**: `#FFFFFF` (순백색) + `border-slate-200/80` + `shadow-xs`
- **시그니처 포인트**: 아이코닉 유튜브 레드 (`#EA3323` / `#FF0000`)
- **보조 지표 액센트**: 앰버 골드 (`#F59E0B`), 사이언 블루 (`#0284C7`), 에메랄드 (`#10B981`)
- **텍스트 가독성**: 본문 헤드라인 `#0F172A` (슬레이트 900), 서브 텍스트 `#64748B` (슬레이트 500)

### 3D 엠보싱 버튼 규격
- `.btn-3d-red`, `.btn-create-key`:
  - 배경: `linear-gradient(180deg, #FF1A1A 0%, #EA3323 100%)`
  - 입체 그림자: `box-shadow: 0 4px 0 #B91C1C`
  - 인터랙션: 호버 시 `-1.5px` 부유, 활성 클릭 시 `translateY(4px)` 압축 모션.
