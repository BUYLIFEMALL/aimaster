## 1. 목표
회원이 키워드(또는 기준 채널)를 넣으면 협업할 만한 유튜버 후보를 찾아, **공개 통계 + 채널 운영자가 공개해 둔 연락처**를 한 표로 보여 주고 CSV로 내려받게 한다. 연락·섭외는 회원이 직접 한다(자동 발송 없음).

## 3. 어디서 무엇을 읽나 (공식 API만, 회원 본인 키)
| 정보 | 출처(YouTube Data API v3) | 할당량 |
|---|---|---|
| 후보 채널 | `search`(type=video, 기존 엔진 순서) → 채널 묶기 | 페이지당 100유닛 |
| 채널 통계·설명·핸들 | `channels`(snippet, statistics) | 50개당 1유닛 |
| 최근 영상 설명(연락처가 영상 설명에만 있는 경우) | 이미 검색으로 받은 영상 id → `videos`(snippet) | 50개당 1유닛 |
- 우리 서버는 **공식 API만** 회원 본인 키로 부른다(기존 프로그램과 같은 방식). 유튜브 채널 페이지를 우리 서버가 긁지 않는다 — 마케팅 예외 §3 「서버 고정 IP로 수집 금지」는 화면 수집에 대한 규칙이고, 공식 API + 회원 키는 우리 표준(§2-5 「공식 API가 있으면 공식 API로」).
- 채널 「링크」 칸(정보 탭 하단 링크 목록)은 공식 API에서 빠져 있다 → 이번 범위에서 제외. 필요하면 2단계로 회원 PC 크롬 확장 방식(§7).

## 4. 화면·동작
- 새 메뉴 「🤝 협업 크리에이터 찾기」(`/creator-finder`), 좌측 메뉴 「황금 채널 발굴」 아래.
- 입력: 키워드 · 구독자 범위(최소~최대) · 국가 · 기간 · 「연락처 있는 채널만」 체크.
- 결과 표: 채널(썸네일·이름·핸들 링크) · 구독자 · 평균 조회 · 대표 영상 · 📧 이메일 · 📞 전화 · 🔗 SNS 계정 · 🏠 주소 · 🌐 웹사이트 · 「채널 정보 직접 보기」 · ⭐ 즐겨찾기.
  - 연락처마다 **어디에 적혀 있었는지**(채널 설명 / 영상 「제목」 설명) 작은 표시.
- CSV 내려받기(화면에 보이는 그대로, 회원 PC에 저장).
- **저장**: 검색 결과는 DB에 저장하지 않는다(화면·CSV만). 즐겨찾기한 채널만 기존 회원별 즐겨찾기(30일, 관리자·시험 계정 열외)에 들어간다 → DB 변경 없음.
- **책임 고지**(마케팅 예외 §3): 첫 사용 때와 CSV 내려받기 직전에 「채널 운영자가 공개한 연락처입니다. 광고성 연락은 정보통신망법(수신 동의·표시 의무)을 지켜 회원 본인 책임으로 해 주세요. 대량 무단 발송·재판매는 금지됩니다」 확인 체크 1번.
- 할당량 안내: 검색 1번 약 100~200유닛(하루 기본 10,000유닛) — 화면에 「이번 검색 사용량」 표시(기존 엔진 값).

## 5. 구현 순서·검수
1. `src/lib/youtube/contactExtract.ts`(순수 함수): 이메일·전화·SNS·주소·웹사이트 뽑기 + 중복 제거 + 가짜 패턴 거르기(예: `example.com`, 이미지 파일명). → 시험 먼저(한국어·영어 설명 표본 20개 이상).
2. `src/lib/youtube/creatorFinder.ts`: 공용 엔진 검색 결과 + 채널 설명 + 영상 설명 → 연락처 붙이기.
3. API `src/app/api/youtube/creator-finder/route.ts`(권한 `checkProgramAccessApi`·`force-dynamic`·회원 본인 키, 없으면 등록 안내).
4. 화면 `src/app/(dashboard)/creator-finder/page.tsx` + 좌측 메뉴 + 가이드 한 단락.
5. 검수: 시험·`tsc`·린트·`npm run build` → 배포 뒤 ego(시험 계정 본인 YouTube 키)로 키워드 1번 실제 검색(할당량만, 금액 0원).
