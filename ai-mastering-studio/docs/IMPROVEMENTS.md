# AI 마스터링 스튜디오 — 개선사항 및 제안 (IMPROVEMENTS.md)

- **대상 프로그램**: AI 마스터링 스튜디오 (`ai-mastering-studio`, 77번)
- **작성 일자**: 2026-10-19
- **작성 기준 버전**: `v1.10`

---

## 1. 프로그램 개발 및 유지보수 관점 (기능 / 로직 / 안정성 / 재사용성)
1. **EBU R128 통합 라우드니스 (LUFS) 및 True Peak 실시간 계측 모듈 도입**:
   - 현재 단순 RMS 및 피크 dBFS 계측을 넘어, 스포티파이/애플뮤직 공식 기준인 -14 LUFS 통합 라우드니스와 4x 오버샘플링 True Peak 인터샘플 클리핑을 실시간 측정하는 Web Audio AudioWorklet 모듈 구축.
2. **24-bit / 32-bit Float 무손실 WAV 및 FLAC 포맷 인코딩 지원**:
   - 상업 방송 및 마스터링 음반 납품 규격에 맞는 고해상도 24bit WAV 및 무손실 압축 FLAC 출력 파이프라인 추가.
3. **Audio Worklet 기반의 멀티스레드 오프라인 렌더링 최적화**:
   - 대용량 트랙(10곡 이상 또는 30분 이상) 일괄 렌더링 시 메인 UI 스레드 블로킹을 방지하기 위해 Web Worker 및 AudioWorklet을 통한 백그라운드 렌더링 아키텍처 적용.

---

## 2. 디자인 및 사용자 경험(UX) 관점 (가독성 / 조작성 / 작업 흐름)
1. **인터랙티브 파라메트릭 EQ 주파수 응답 커브 드래그 컨트롤러**:
   - 단순 슬라이더 조작뿐 아니라, 오디오 스펙트럼 비주얼라이저 위에서 노드를 직접 드래그하여 Low/Mid/High 주파수와 게인, Q를 시각적으로 조작할 수 있는 인터랙티브 EQ 그래프 캔버스 제공.
2. **A/B 실시간 바이패스 스위칭 및 음량 매칭 (Level Match A/B)**:
   - 마스터링 전(Original)과 후(Mastered)의 음향을 원클릭으로 비교할 때, 음량이 커져서 소리가 더 좋게 들리는 심리음향 효과를 배제할 수 있도록 동일 피크 레벨 자동 보정 A/B 비교 스위치 구현.
3. **듀얼 다이내믹스 미터 (Gain Reduction & Stereo Correlation Meter)**:
   - 컴프레서의 실시간 게인 리덕션(GR) 미터와 스테레오 위상 상관도(Correlation Meter: -1 ~ +1)를 네온 바 형태로 시각화하여 모노 호환성 확인 편의성 극대화.

## 3. 기존 AIMaster에 없던 구현 가능한 사용자 중심 창의적 자동화 시스템
1. **레퍼런스 트랙 기반 자동 타깃 매칭 (AI Match Mastering)**:
   - 사용자가 자신이 원하는 상용 음원(예: 아이유, 빌리 아일리시 음원)을 '레퍼런스'로 업로드하면, AI와 DSP가 레퍼런스 트랙의 주파수 스펙트럼과 다이내믹스 곡선을 3초 만에 분석하여 내 곡의 5대 랙을 최적의 프로필로 자동 보정하는 **지능형 타깃 매칭 자동화 시스템**.
2. **원클릭 다중 플랫폼 타깃 동시 익스포트 (Multi-Platform Mastering Batch)**:
   - 한 번의 렌더링으로 [유튜브용 -14 LUFS], [클럽/사운드클라우드용 -9 LUFS], [쇼츠/틱톡용 음성 강조 -12 LUFS]를 각각 자동 튜닝하여 3개의 프리셋 버전으로 동시 렌더링 패키징하는 자동화 파이프라인.
3. **스마트 노이즈 플로어 억제 및 자동 보컬 디에싱 (Smart Vocal D-Esser)**:
   - 홈 레코딩 음원의 치찰음(sibilance)과 험 노이즈를 AI가 감지하여 중고역대 대역통과 필터로 지능적으로 정리해 주는 자동 클린업 프리셋 시스템.
