# AI 마스터링 스튜디오 — 사용 매뉴얼

> 대상: 이 프로그램을 쓰는 회원과, 회원 문의를 받는 운영 담당자. (개발·배포 인수인계는 [`AGENTS.md`](AGENTS.md))
> 주소: https://ai-mastering-studio.buylife.xyz · 현재 버전 v1.02 · FREE (가입 회원 누구나, 핸드폰 번호 등록 필수)

## 1. 한 줄 설명
WAV 음원을 올리면 EQ·새추레이션·컴프레서·스테레오 이미저·리미터로 마스터링해 주는 도구입니다. 오디오는 **서버로 전송되지 않고 이 브라우저 안에서만** 처리됩니다.

## 2. 시작 전 준비
1. AIMaster에 가입하고 **핸드폰 번호**를 등록합니다(없으면 프로그램을 쓸 수 없습니다).
2. **AI 로직 생성기**를 쓰려면 왼쪽 메뉴 **API키등록·플랫폼연동**에서 본인의 Gemini(또는 OpenAI·Claude) 키를 등록합니다. 같은 화면의 "📖 연동 매뉴얼"에서 발급 방법을 볼 수 있습니다. AI 비용은 회원님 본인 계정으로 나가며 운영자나 다른 회원의 키는 쓰이지 않습니다. **프리셋·수동 조정·처리는 키가 필요 없습니다.**

## 3. 사용 순서
1. **WAV 올리기**: 끌어다 놓거나 `파일 선택`. 여러 곡 가능(최대 20곡, 파일당 150MB). 올린 곡은 목록에 뜨며 눌러서 비교할 곡을 고릅니다. `초기화`로 모두 지울 수 있습니다.
2. **사운드 프로필**: 범용 · 스트리밍 · 클럽용 · 파이어 · 펀치 · 선명함 · 팟캐스트 · 빈티지 온기 · 테이프 · 내추럴 · 공간감 · 시네마틱 중 하나를 누르면 아래 랙의 값이 바뀝니다.
3. **AI 로직 생성기(선택)**: 모델을 고르고 원하는 소리를 글로 적습니다(예: "선명한 고음과 깊은 저음 펀치감이 있는 현대적인 K-Pop"). `AI 엔지니어에게 문의`를 누르면 설정값이 랙에 채워지고 짧은 설명이 나옵니다. 값은 안전한 범위 안으로 자동 보정됩니다.
4. **정밀 마스터링 랙**: 슬라이더로 직접 조정합니다.
   - **EQ**: 저음(100Hz), 중음(1.5kHz)과 대역폭(Q), 고음(8kHz)
   - **아날로그 새추레이션**: 드라이브, 배음 혼합
   - **컴프레서**: 임계값, 비율, 어택, 릴리즈
   - **스테레오 이미저**: 너비(100% = 원본, 0% = 모노)
   - **최종 리미터**: 입력 게인, 실링(최대 레벨), 릴리즈
5. **전체 일괄 처리**: 올린 모든 곡을 같은 설정으로 처리합니다. 완료되면 오른쪽에 **마스터된 신호**가 나타나 입력과 파형·재생·피크/평균(RMS) 레벨을 비교할 수 있습니다.
6. **저장**: 곡별 `WAV 저장`(16bit PCM), 또는 `전체 다운로드 (ZIP)`. 파일 이름은 `원래이름_mastering.wav`입니다.

설정을 바꾸면 결과 위에 "설정이 바뀌었습니다 — 다시 처리하세요"가 뜹니다.

## 4. 알아두면 좋은 점
- **새로고침하거나 창을 닫으면 올린 곡과 결과가 사라집니다.** 처리 후 꼭 저장하세요.
- 마지막 리미터가 실링(기본 -1.0dBFS) 아래로 최대 레벨을 맞춥니다. 소리가 너무 눌리면 입력 게인을 낮추거나 컴프레서 임계값을 올리세요.
- 이 도구는 보조 도구입니다. 최종 음량·음색은 반드시 직접 들어 보고 판단하세요.

## 5. 자주 묻는 질문 / 문제 해결
| 증상 | 원인과 해결 |
|---|---|
| "○○ API 키 등록이 필요합니다" | AI 로직 생성기를 쓰려면 API키등록·플랫폼연동에서 해당 공급사 키를 등록하거나 이미 등록한 공급사의 모델로 바꾸세요. |
| "오디오를 읽지 못했습니다" | 손상됐거나 지원하지 않는 형식일 수 있습니다. 표준 WAV로 다시 내보내 올려 보세요. |
| "파일 하나는 150MB 이하" | 파일을 나눠서 올리세요. |
| 처리가 오래 걸리거나 멈춤 | 긴 곡을 한꺼번에 많이 올리면 메모리를 많이 씁니다. 곡 수를 줄여 나눠 처리하세요. |
| "사용 한도를 넘었습니다" | 잠시 후 다시 시도하거나 본인 키의 한도·결제를 확인하세요. |
| "핸드폰 번호를 입력 후 사용해주세요!" | 메인 사이트에서 핸드폰 번호를 등록하세요. |

## 6. 운영 담당자 메모
- 오디오를 서버에 올리지 않으므로 저장소·DB 비용이 없습니다. AI 호출만 회원 본인 키로 나갑니다(운영자 비용 없음). FREE 배지로 운영 중이며 관리자 프로그램 편집 화면에서 켜고 끌 수 있습니다.
- 문의 대응 시 확인할 것: ① 핸드폰 등록 여부 ② AI 사용 시 선택 모델 공급사의 키 등록 여부 ③ 브라우저(최신 Chrome/Edge 권장)와 곡 크기·개수.
