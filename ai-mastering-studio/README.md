## 1. 주요 특징
1. **100% 브라우저 기반 Web Audio DSP 엔진**:
   - `OfflineAudioContext`를 활용한 고속 무손실 렌더링 (5분 스테레오 음원 기준 약 0.6초 처리).
   - 음원 파일 외부 서버 유출 우려 원천 차단.
2. **12종 프로페셔널 사운드 프로필 프리셋**:
   - 범용 마스터, 스트리밍 최적화(-14 LUFS), 클럽 펀치, 파이어 하모닉스, 선명한 보컬, 팟캐스트, 빈티지 온기, 테이프 새추레이션, 내추럴 어쿠스틱, 와이드 공간감, 시네마틱 앰비언트, 어그레시브 락.
3. **AI 로직 생성기 (AI Tuning Engineer)**:
   - 원하는 사운드 질감을 한국어 자연어로 입력하면 AI가 정밀 파라미터를 추천.
   - 회원 본인 API 키 원칙 (BYOK: Gemini / OpenAI / Claude).
4. **5대 하드웨어 아날로그 랙**:
   - 3-Band Parametric EQ, 진공관 배음 Saturation, Precision Dynamic Compressor, Stereo Imager, Lookahead 10ms True Peak Limiter (-1.0dBFS 실링 보장).
5. **독립 비주얼 가이드북 (`/guide`)**:
   - 4단계 마스터링 워크플로우 파이프라인, 12종 사운드 프로필 매트릭스, 5대 랙 원리 해설, FAQ 5종 아코디언.
