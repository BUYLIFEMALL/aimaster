참고: https://suno-prompt-manager-six.vercel.app/ (SU-Note v3.6, 공개 자산 v371). 대상: https://suno-music-studio.buylife.xyz/. 기존 v1.02는 독립 프리셋 20개 중심의 초기 구현으로, 원본의 상세 선택 기능과 동등하지 않았습니다.

## 확인 방법과 증거의 범위

실제 Chrome 엔진을 Playwright로 새 격리 브라우저에서 실행했습니다. 원본의 빌더·앨범·프리셋·검색·댄스·가이드·저장 메뉴를 열고, 선택 상자와 버튼을 실제로 조작했습니다. 원본의 회원 키·로그인 세션은 읽지 않았으며 AI 생성·검색·음악 제작 버튼을 통한 공급사 호출은 실행하지 않았습니다. 공개 HTML/JS는 UI 동작 대조용으로 읽었습니다.

작업 원자료: `D:/PDS/suno-comparison-20261012/`. `inventory.json`, `option-results.json`, `extra-results.json`, `palette-results.json`, `metadata.json`, `variants-settings.json`과 선택 실행 스크립트가 있습니다. 저장소에는 필요한 공개 선택 메타데이터와 아래 요약만 남깁니다. 원본 완성 Style·가사 골격의 전체 문장, AI 프롬프트와 실행 코드를 제품에 복제하지 않았습니다.

## 확인한 문제와 보완

1. 원본에서 랩 100% → 0%로 바꾸어도 `singing`, `sung chorus` 같은 제외 문구가 남았습니다. 새 구현은 회원이 직접 작성한 제외 문구와 현재 설정의 자동 제외를 구분해 계산합니다. 설정을 끄면 자동 제외도 사라집니다.
2. 원본 프리셋 로드는 현재 가사를 골격으로 교체합니다. 새 구현은 프리셋 선택·태그 편집 때 현재 제목·가사를 보존하고, 구간 버튼으로 필요한 위치에만 삽입합니다.
3. 이전 앱은 재생성 때 전체 곡을 교체했습니다. 새 서버는 제목·Style·가사 선택에 따라 적용할 필드를 제한하며, 취소·응답 실패에는 기존 내용을 보존합니다. 앨범 순차 작사는 제목·Style을 변경하지 않고 가사만 생성합니다.
4. 기존 Style 영문 검증은 라틴 장르의 악센트 문자와 충돌했습니다. 화면 이름은 원래 이름을 유지하고, 생성 Style의 음악 용어는 ASCII로 정규화했습니다. 전체 661개 기본 레시피와 아티스트의 3방향 모두 검증합니다.
5. 큰 선택 목록·가사 내용을 포함한 라벨은 도구에서 길게 읽히거나 찾기 어려웠습니다. 주요 선택·입력란의 접근성 이름을 고정하여 짧게 제공합니다.
6. 원본의 ‘160~200+’ 표기는 실제 필터가 200 미만인 것과 달랐습니다. 새 앱은 200~320 BPM 필터를 별도로 제공합니다.

## 구현 파일과 유지보수

- `src/lib/studio/catalog-metadata.json`: 공개 이름·유형·시대·그룹·중복 분류·BPM·보컬 구성 힌트. 461개. BPM이 명시되지 않은 2개는 자체 기본 템포를 사용합니다.
- `dance-metadata.json`: 200개 이름·계열·숫자 템포 힌트.
- `tag-metadata.json`: 직접 선택해 확인한 일반 음악 용어를 영문으로 정규화·중복 제거. 효과 확률/보장 배지는 복제하지 않습니다.
- `catalog.ts`: 자체 음악 레시피, 필터, 프리셋 적용, 자동 제외, 제어 설정 병합, 구간 삽입.
- `LibraryPicker.tsx`·`StylePalette.tsx`: 연쇄 선택·미리보기·검색·태그·내 Style 저장.
- `generation.ts`·`prompt.ts`·`api/generate/route.ts`: 선택 생성·컨텍스트·개인 키 호출·출력 검증·선택 병합.
- `validation.ts`·`storage.ts`: 기존 스키마 1의 새 필드를 기본값으로 보완. 손상 백업은 덮어쓰지 않습니다.

원본의 브랜드·다크 테마·브라우저 공용 키 vault는 옮기지 않습니다. AIMaster의 흰색 화면, 공용 인증·권한, 회원 본인 키, 메뉴 바로 아래 계정 위치를 유지합니다. AI 스타일 제안은 실시간 검색 결과가 아니며, 원본의 공급사 웹 검색 기능은 이번 릴리스에 포함하지 않습니다. 새 레시피가 원본 Style 문장·특정 가수 음색·실제 Suno 결과와 같다고 주장하지 않습니다.

### 원본 모델 설정 실측

Claude: `claude-sonnet-4-6`, `claude-haiku-4-5-20251001`; OpenAI: `gpt-5.4-mini`, `gpt-4.1-mini`; Gemini: `gemini-3.5-flash`, `gemini-2.5-flash`. 각 공급사 직접 입력도 선택했습니다. 이는 원본 화면 값이며 현재 사용 가능성·가격을 검증한 결과가 아닙니다. AIMaster는 기존 기본 모델 목록과 공급사별 직접 모델 입력을 제공하며 원본 가격/추천 배지를 복제하지 않습니다. 모델 ID의 공급사 접두어·형식은 검증하지만 실제 이용 가능성은 회원 키의 공급사 응답으로 확인합니다. 모델을 몰래 치환하거나 다른 회원 키로 폴백하지 않습니다.
