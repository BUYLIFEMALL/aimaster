## 원본에서 확인한 개선점

브라우저의 API 직접 호출/로컬 키 vault는 AIMaster 권한 통제를 대체하지 못합니다. Anthropic 원본은 content[0]만 읽으므로 복수 텍스트 블록은 누락 가능. 예외에 공급사 원문을 반환하면 민감 값 노출 위험이 있습니다. 손상 AI JSON을 정규식으로 복구하면 필드가 누락되어도 성공으로 오인할 수 있습니다. 새 앱은 필드·길이·곡 수·BPM 검증 후 적용하고 실패 시 기존 결과를 보존합니다. 설정 변경은 AI 호출하지 않습니다. 모델·키 자동 폴백 및 자동 과금 재시도 없음.

Suno 자동 붙여넣기는 원본 FAQ도 출처 보안 제한 때문에 불가라고 설명합니다. 음악 파일 생성은 기존 music-automation의 별도 유료 프로세스입니다. 새 앱이 생성·발행을 대신 실행한다고 표시하지 않습니다.
