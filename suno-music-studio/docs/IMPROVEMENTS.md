## 1. 향후 기능 고도화 과제 (Feature Roadmap)

### [TASK #1] 원클릭 일괄 복사 플로팅 바 (Floating Quick Copy Bar)
- **개요**: 빌더에서 기획이 완료되었을 때, 하단이나 화면 상단에 플로팅 바를 띄워 `[Title 복사]`, `[Style 복사]`, `[Lyrics 복사]`, `[Suno 바로 열기]`를 한 번에 연속 수행할 수 있는 미니 툴바 추가.
- **예상 효과**: 사용자가 Suno 사이트와 창을 나란히 띄워놓고 작업할 때 스크롤 이동 없이 초고속으로 복사/붙여넣기 가능.

### [TASK #2] Suno v3.5 / v4 / v5 / v6 모델별 글자수 실시간 카운터
- **개요**: Suno 버전별로 Style of Music의 권장 글자수 제한(예: v3는 120자, v4 이상은 1000자 지원 등)이 다름. 현재 입력된 스타일 텍스트의 글자수를 실시간으로 계산하고 권장 한도 초과 시 안내 배지 표시.

### [TASK #3] 오디오 샘플 오디오 프리뷰 (Audio Snippet Preview)
- **개요**: 461개 프리셋 중 주요 장르(City Pop, Synthwave, Lofi 등)에 대해 5초 내외의 가벼운 로컬 웹 오디오 신스 또는 엠비언스 프리뷰 톤을 재생해 볼 수 있는 미니 프리뷰어 연동.

### [TASK #4] 앨범 트랙 간 드래그 앤 드롭 순서 변경 (Drag & Drop Reordering)
- **개요**: 3~12곡 앨범 트랙 구성 시, 마우스 드래그 앤 드롭으로 트랙 순서를 직관적으로 재배치할 수 있는 인터랙션 라이브러리(예: `@hello-pangea/dnd`) 도입.

## 2. 주의사항 및 유지보수 가이드
- **본인 API 키 최상위 규칙**: 기획/작사 생성 시 반드시 회원이 등록한 본인 키(`user_api_keys`)만 사용하며 공용 키 폴백 금지.
- **로컬 스토리지 데이터 보호**: 브라우저 로컬 저장소에 저장되므로, 앨범 기획 완료 시 JSON 백업을 적극 권장하는 토스트 안내 유지.
