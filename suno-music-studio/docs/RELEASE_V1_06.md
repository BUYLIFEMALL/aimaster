# v1.06 빌더·앨범·검색 상세 비교와 기능 확장

2026-10-12 Codex. 운영 주소: https://suno-music-studio.buylife.xyz/.
원본: https://suno-prompt-manager-six.vercel.app/ (SU-Note v3.6).

## 원본 직접 조사

새 Headless Chrome에서 공개 사이트에 들어가 초기 화면, 프리셋 선택 전후, 제어 적용, 골격·초기화, 앨범 설정, 검색 공급사와 웹 검색 체크를 직접 확인했습니다. 시대 14개(빈 선택 포함), 스타일 그룹 244개(빈 선택 포함), 프리셋 462개(빈 선택 포함), 랩 방식 2개, 편곡 8개를 각각 선택해 값과 변경 이벤트를 확인했습니다. 이 730회와 제목 언어·보컬·앨범 분류/시대/흐름 39회를 합쳐 769회입니다. 선택값 불일치 0개입니다.

종속 선택 후 원본이 일부 선택기를 숨기므로 전수 순회에서는 해당 select에 DOM 선택·변경 이벤트를 적용했습니다. 모든 항목이 화면에서 동시에 보인다거나 769번 모두 마우스로 클릭했다고 보고하지 않습니다. 별도의 대표 표본에서는 보이는 화면과 버튼의 결과도 확인했습니다. [직접 조사 요약](assets/reference-v106-options.json). 전체 도구와 원본 관측 기록은 `D:/PDS/suno-comparison-20261012/`에 있습니다.

원본 유료 AI 검색·앨범 생성은 실행하지 않았습니다. 회원 API 키를 복사하거나 운영자 키로 대체하지 않았습니다. 참고 사이트의 음악 문장·93개 가이드 본문 전체를 복제하는 대신 공개 선택 메타데이터와 자체 Style 레시피·설명을 사용합니다.

| 검색 정보 신뢰도 | 원본 결과 화면을 조사; 실제 AI 품질은 미검수 | 본인 모델·본인 키로 최대 2회(검색→분석), 출처 없음/잘림/형식/인덱스/미래 연도/중복 오류는 기존 결과 보존. 실제 곡 정보와 AI 분석 BPM/구조를 구분 |

대표곡 parser는 도구가 반환한 출처 목록에 대한 인덱스·형식·연도를 검증합니다. **출처 페이지에 해당 곡·연도가 실제 적혀 있는지의 의미 검증을 보장하지 않습니다.** 화면에서 출처 연결 후보와 AI 분석으로 표시하고 직접 링크 확인을 안내합니다. 웹 OFF를 실제 대표곡 검색이라고 표시하지 않습니다.

검색 결과의 ‘앨범에 적용’은 앨범의 **참고 Style만** 바꿉니다. 기존 트랙 제목·가사·앨범 컨셉은 유지합니다. 새 앨범 생성에 참고할 수 있고 기존 모든 트랙을 뜻하지 않게 덮어쓰지 않습니다. 빌더 적용도 기존 제목·가사를 보존하고 프리셋 출처 표시를 해제합니다.

## 발견한 문제와 보완

- AI가 새 Style을 생성한 후 오른쪽 기준 Style이 이전 값으로 남던 문제: 빌더 brief와 실제 트랙 Style/BPM/제외어를 함께 갱신합니다.
- 검색에서 같은 공급사 버튼을 눌러 직접 모델이 기본 모델로 바뀌던 문제: 같은 공급사는 변경하지 않습니다. 실패 시 키·모델 폴백은 없습니다.
- 앨범 제목·설명을 빈칸으로 지우며 수정한 뒤 새로고침하면 초안을 읽지 못할 위험: 초안 검증은 일시적 빈칸을 허용하고 AI 생성 결과는 기존 엄격 검증을 유지합니다.
- JSON 파일을 읽는 동안 최신 빌더 편집이 덮어써질 위험: 파일 읽기 후 최신 저장 상태에 앨범만 합칩니다. 1MB·스키마·트랙 ID/수·값을 먼저 검증하고 실패하면 변경하지 않습니다.
- 구간 삽입/복사 중복과 오른쪽 숨은 기본 제어: 가사 태그를 위로 이동, 빌더 Style/Lyrics 복사 버튼 중복 제거, 핵심 체크 항목을 노출합니다.

- 원본과 완전히 동등한 프로그램이라고 주장하지 않습니다. 전체 영문 UI, 다크 테마, 원본 SU-Note JSON 직접 변환, 원본 93개 가이드 본문 전체, Suno 자체 최종 음악 생성은 이번 구현 범위에 없습니다. 흰색 작업 화면·본인 계정/키·AIMaster 로그인은 공통 지침을 유지합니다.
- 원본 AI 실행 품질과 이번 3종 공급사의 실제 회원 모델 웹 검색/대표곡 분석·앨범 작사·운영 회원 파일 선택창은 추가 검수가 필요합니다. 모의 호출과 비로그인 HTTP 성공을 실제 회원 성공으로 바꾸어 기록하지 않습니다.
