# Suno 음악기획 자동화 — 작업대기 목록

등록일: 2026-10-13 · 대상 버전: v1.07

**상태: 주인님 지시로 검수 대기.** “검수는 나중에 할꺼니까 작업대기 리스트로 올려놔” 지시에 따라 아래 항목을 실행하지 않습니다. 주인님이 검수 재개를 지시하면 1번부터 순서대로 진행합니다. 일정을 임의로 정하거나 자동 재개하지 않습니다.

요청된 앨범 레이아웃 구현·자동/모의 검사·커밋·푸시·운영 배포는 완료됐습니다. 아래는 미구현 기능 목록이 아니라 **실제 사용 흐름의 추가 검수 목록**입니다. 완료 증거는 [v1.07 인수인계](RELEASE_V1_07.md)에 있습니다.

## 재개할 때 확인

- 본인 회원 로그인과 유효한 프로그램 사용 권한을 확인합니다. 과거 테스트 계정에 기록된 사용기간을 현재도 유효하다고 간주하거나 임의 연장하지 않습니다.
- 등록된 회원 본인 키만 사용합니다. 없는 공급사 키는 등록 안내 후 해당 공급사 검수를 대기 상태로 남깁니다. 다른 회원·운영자 키로 대체하지 않습니다.
- 소량 검수부터 진행하며 유료 API 대량 호출은 별도 승인 없이 하지 않습니다. Suno 최종 생성은 주인님이 본인 계정에서 실행합니다.
- 가져오기 전에 기존 자료를 JSON으로 백업합니다. 다른 CLI가 사용하는 공유 Chrome 세션을 임의 변경하지 않습니다.
- 항목별 결과·증거·발견한 오류를 기록합니다. 자동/모의 검사와 실제 회원·공급사 검수를 구분합니다. 발견한 오류의 수정·재검수·인수인계는 Codex가 처리합니다.

문서만 갱신했으므로 앱 버전·DB·운영 배포는 v1.07을 유지합니다.
