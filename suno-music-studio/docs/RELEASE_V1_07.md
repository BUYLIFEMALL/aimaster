# v1.07 앨범 작업 레이아웃

2026-10-12 Codex. 대상: https://suno-music-studio.buylife.xyz/?section=album

주인님의 최종 지시인 ‘좌측 메뉴는 건드리지 말고 우측만 맞춰’에 따라 Sidebar.tsx, 메뉴 순서·계정 위치·사이드바 CSS는 수정하지 않았습니다. 프로그램 버전 표시는 공용 버전 규칙에 따라 v1.07로 갱신합니다. 흰색 웹 작업 화면 지침을 유지하고 원본 스크린샷의 배치·순서·간격을 반영합니다.

## 최종 배치

- 우측 작업 화면 안에서 설정 5 : 트랙 목록 7, 간격 20px, 상단 정렬. 좁은 화면은 단일 열입니다.
- 설정 순서: 앨범 컨셉, 상세 의도, 2×2 분류/시대/스타일 그룹/참고 프리셋, 현재 빌더·저장 프리셋 가져오기, 다중 무드, 앨범 흐름, 가사 언어, 생성·곡 수·초기화.
- 저장된 앨범을 설정 아래 별도 카드로 분리했습니다. JSON 가져오기·저장·보관함 불러오기를 유지합니다.
- 빈 트랙 안내는 데스크톱에서 62px 높이 한 줄 카드입니다. 생성 후에는 기존 앨범 메타데이터·트랙 편집·작사·선택·순서 변경 도구가 표시됩니다.
- AI 모델/직접 모델 ID·보컬·랩·악기·제외어·잠금·편곡 기능은 ‘AI 모델·보컬·편곡 세부 설정’에서 펼칩니다. 가사 언어 슬라이더는 중복 없이 한 곳에 표시합니다.

## 참고 선택기의 동작

분류·시대가 바뀌면 종속 그룹/프리셋을 해제하고, 그룹이 바뀌면 프리셋을 해제합니다. 이후 선택한 음악 속성을 앨범 기획에 전달합니다. 참고 프리셋 선택 시 기존 레시피와 잠금 처리를 재사용하면서 앨범 컨셉·의도·다중 무드·곡 수·모델은 유지합니다. 참고 해제는 자연스러운 보컬/자동 장르·악기/잠금 해제로 복원합니다. 선택 상태는 기존 회원별 albumBrief에 저장하므로 별도 저장소·스키마를 만들지 않았습니다.

분류 ‘전체’는 기존 `장르·월드` 값을 사용하고 프리셋 필터를 전체로 표시합니다. 시대 선택 없음은 기존 `global` 값입니다. 빌더에서 가져온 댄스 참고 프리셋도 현재 선택에 표시하며 잃지 않습니다. 원본 Style 본문을 복제하지 않고 기존 자체 레시피를 사용합니다.

## 검수 증거와 한계

새 Headless Chrome에서 원본 공개 사이트의 앨범을 직접 열어 분류 3개·시대 14개·그룹 244개·참고 프리셋 462개(각 빈 선택 포함)와 흐름 6개를 확인했습니다. 이번 작업은 배치 확인과 대표 선택 검수이며 전수 옵션 조사는 이전 v1.06 기록을 따릅니다. 원본 유료 API는 호출하지 않았습니다.

- npm test: 53개 통과. 린트·타입·프로덕션 빌드 통과.
- 실제 React 컴포넌트 모의 화면: 기존 34항목 통과(작사/저장/복원/순서/검색·빌더 보존). API 모의 요청 11회, 실제 유료 호출 0회.
- 신규 배치·선택 검수: 13항목 통과. 카드 분리, 4개 종속 선택기, 15종 무드/6종 흐름, 좌우 상단·폭·순서, 62px 안내, 고급 설정, 컨셉/무드 보존, 새로고침 선택 보존, 계정 간격 유지, 390px 가로 넘침 없음.
- [배치 수치·직접 원본 관측](assets/album-v107-layout-check.json), [빈 화면](assets/album-v107-empty-fixture.png), [모바일](assets/album-v107-mobile-fixture.png), [생성·저장 모의 화면](assets/extended-v107-album-fixture.png).

화면 검수는 실제 컴포넌트 + 인증/라우팅 대체 도구 + 모의 API입니다. 운영 회원 로그인·신규 유료 공급사 생성은 이번에 실행하지 않았습니다. 기존 v1.01 회원 생성 기록을 새 기능 검수로 사용하지 않습니다. Aside 브라우저는 실행 중이 아니었으므로 사용자 Chrome 세션을 변경하지 않고 독립 공개 Headless Chrome을 사용했습니다.
