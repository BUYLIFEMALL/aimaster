| 시작까지 | G마켓 업체 승인(기간·계약·비용 모름), 승인 전 개발·시험 불가 | 바로 시작 — 화면 저장본만 있으면 |

| 판매중지 등록 | 등록 직후 수정 호출로 중지(잠깐 판매중 상태) | 화면에서 판매 상태를 고를 수 있으면 처음부터 중지(저장본으로 확인) |
