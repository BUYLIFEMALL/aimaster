## 다음 첫 단계
1. `dev-requests list --role docbot-prompt` → ACTIVE_WORK·G-4 인수인계/최신 코드 확인. G-1~G-4 코드 검수를 재구현하지 말고 실제 AI·업로드/파싱·방/당시 설정·좁은 화면 미검수를 진행합니다.
2. 새 공급자 키 등록은 나중이라는 결정을 유지합니다. 실제 답변 검수는 시험 회원 본인 Upstage 키 준비 뒤 기존 승인 예산에서 최소 호출합니다. 묶음 배포 때만 버전을 올립니다.
3. 관리자 요청함은 정상입니다. 결과·필요 요청은 `report`/`ask`와 같은 턴 채팅 양쪽에 남깁니다. 이전 파일 대화상자/로그인 차단은 해소됐으며 Edge 실제 제어와 일반 회원 로그인 확인을 마쳤습니다.
4. 디자인은 agy 담당입니다. 기능 변경과 디자인 예약이 겹치면 파일 범위를 대조합니다. 로컬4311은 G-4 빌드이며 재시작은 해당 포트의 본인 프로세스인지 확인한 뒤 합니다.
