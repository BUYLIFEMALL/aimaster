## 1. 한 줄 요약
**어떤 하위 프로그램이든 다음에 배포할 때, 그 프로그램 레이아웃에 위젯 스크립트 한 줄을 함께 넣어 내보낸다.** 이것 때문에 따로 배포하지 않는다(빌드 비용). 남은 프로그램은 나중에 주인님 지시로 모아서 한 번에 처리한다.

## 2. 무엇이 생기나
- 로그인한 회원에게 화면 **왼쪽 아래 「💾 사용량 / 한도」** 작은 표시(누르면 프로그램별 사용량·보관 기간·「다시 계산」·「용량·보관 늘리기」).
- 사용량 **80%·100%**에서 하루 한 번 **저장 구독 안내 팝업**(→ `https://www.buylife.xyz/storage`).
- 관리자·시험 계정은 「무제한」으로만 보이고 팝업 없음. 비로그인이면 아무것도 안 보임.
- 데이터는 메인 사이트 `GET https://www.buylife.xyz/api/storage/me`(본인만, `.buylife.xyz` 로그인 쿠키). 프로그램 쪽 API·DB·환경변수 추가 없음.

## 3. 넣는 법 (Next.js 프로그램)
레이아웃 파일 하나만 고친다 — `app/layout.tsx` 또는 `src/app/layout.tsx`(웹이 `web/` 아래면 그 안).
```tsx
import Script from "next/script";
// …
      <body …>
        {children}
        {/* 💾 회원 저장공간 위젯(메인 사이트 공용) — docs/HANDOFF_20261111_STORAGE_WIDGET_ROLLOUT.md */}
        <Script src="https://www.buylife.xyz/storage-widget.js" strategy="afterInteractive" />
      </body>
```
- 이미 `next/script`를 쓰고 있으면 import는 그대로 둔다. 다른 코드·화면은 건드리지 않는다.
- **버전 +0.01은 따로 올리지 않는다** — 그 배포의 원래 버전 올림에 포함(이 한 줄만을 위한 배포 금지).

## 4. 배포할 때 순서
1. 배포 전 확인: `node scripts/pending-check.mjs <폴더>` → `• [공통] 저장공간 위젯 한 줄 미적용`이 보이면 3번대로 넣는다.
2. 로컬 검사(`tsc`/`npm run build`) → 평소대로 배포.
3. 배포 뒤 확인(1분): 그 프로그램 주소(`<이름>.buylife.xyz`)에서 로그인 상태로 왼쪽 아래 💾가 보이는지. 프로그램 화면의 왼쪽 아래 버튼·채팅 단추와 겹치면 그 프로그램 CSS로 위치를 피하지 말고 이 문서 §7에 적어 알린다(위젯 쪽에서 맞춤).
4. 그 프로그램 `docs/IMPROVEMENTS.md` 변경 이력에 「저장공간 위젯 적용(vX.YY)」 한 줄. 이 문서 §6 표는 고치지 않아도 된다(스크립트가 코드를 보고 셈).

## 5. 넣지 않는 곳
- Next 웹 레이아웃이 없는 것: 크롬 확장(`extension/`), 데스크톱 앱(Electron), 라이브러리 → 스크립트가 자동으로 대상에서 뺀다.
- `labs/`(AIMaster_dev Lab, 회원 체계 다름) — 넣지 않는다.
- 비공개 카테고리(REA 등)·꺼진(비활성) 프로그램 — 넣어도 문제는 없지만 배포할 일이 없으면 억지로 하지 않는다.
- `vercel.app` 주소로만 쓰는 프로그램 — 로그인 쿠키가 없어 위젯이 숨겨진다(넣어도 무해). `<이름>.buylife.xyz` 연결 뒤 동작.
