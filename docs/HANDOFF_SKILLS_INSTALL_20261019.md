## 적용한 방식

- 이번 문서 작업에 `writing-for-agents`의 짧은 상위 규칙·세부 문서 연결 방식을 참고했습니다. 나머지 스킬 전체를 일괄 실행하지 않았습니다.
- 기존 개인 계정/API·운영/Lab 분리·사전 플랜·공동 작업·검수/배포·인수인계 원칙을 유지합니다.
- `handoff` 임시 폴더 기본값은 저장소 인수인계 규칙을 따릅니다. `setup`의 저장소 초기 설정과 이슈/라벨 생성은 이번에 실행하지 않았습니다.
- 프로그램 코드·운영 DB·키·환경변수·배포는 변경하지 않았습니다. 관련 서비스 https://www.buylife.xyz 는 이번 작업의 배포/화면 검수 대상이 아닙니다.

## 검수

설치 목록·실제 파일/고유 이름·루트 세 문서의 공통 블록 일치·문서 링크를 확인했습니다. 문서만 반영하므로 앱 빌드·유료 API·실제 회원 기능 검사는 대상이 아닙니다. Git에는 이번 문서와 전용 블록만 반영하고 원격에 푸시하며 다른 CLI 변경을 보존합니다. 커밋 번호는 본 문서를 추가한 Git 이력에서 확인합니다.

## 미실행·다음 첫 단계

1. 실제 개별 프로그램 업무는 별도입니다. 다음 작업에서 플랜·공통 아이디어 표·해당 프로그램 최신 지침을 읽고 필요한 스킬만 고릅니다.
2. 초기 설정이 필요한 엔지니어링 스킬은 먼저 기존 작업 추적 위치와 요구 설정을 대조합니다. 설치를 새 작업 관리 체계로의 전환 승인으로 해석하지 않습니다.
3. 다른 Codex 계정·Claude Code·Antigravity에 대한 설치/복제는 하지 않았습니다. 필요할 때 해당 환경에서 별도로 확인합니다.
4. 새 세션에서 목록이 보이지 않으면 위 CLI 목록과 실제 설치 파일을 먼저 확인합니다. 기존 실행 중인 세션을 강제 종료하지 않습니다.

새 기능 아이디어 추가는 없습니다. 이번에는 주인님이 확정한 외부 스킬 선택 사용 방침을 공통 지침과 인수인계로 남겼습니다.
