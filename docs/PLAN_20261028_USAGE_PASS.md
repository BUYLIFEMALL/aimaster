## 1. 확정된 전체 결제·접근 정책

| 등급/방식 | 접근 규칙 |
|---|---|
| **일반** | 무료기간(현재 14일) 동안 비프리미엄 전체 사용 → 만료 후 **1개당 월 결제**. 프리미엄은 처음부터 월 결제 |
| **골드(드림팀)** | 관리자가 부여한 프로그램만 무료, 안 한 건 결제. 프리미엄은 결제 |
| **VIP(드림AI팀)** | 비프리미엄 전체 무료 → **프리미엄만 월 결제** |
| **실버** | **미사용·예비**(등급은 남겨 둠, 자동부여·기간 설정 안 함) |
| **프리미엄 프로그램(현재 12개)** | **프리미엄 배지가 「등급 무료 제공」보다 우선** — VIP(전체 무료)·골드(지정 무료)여도 프리미엄 배지 프로그램은 그와 무관하게 별도 월 결제해야 사용(관리자 제외). 이미 DB 트리거 0031로 강제됨. **단 사용권 구매자는 별개**(아래) |
| **사용권(세트) — 신규** | 등급 무관, 유료 묶음 상품. 회원이 **프로그램을 N개 골라 1달 사용**. **10개·30개는 비프리미엄만 선택 / 50개·전체는 프리미엄 배지 프로그램까지 선택 가능**(돈을 낸 상품이라 고른 프리미엄도 기간 내 사용). 전체 이용권은 프리미엄 포함 모든 프로그램 |

- 판정 로직(정지 → 관리자 → 핸드폰 → FREE → 구독/사용권 → 등급+부여(만료 전) → 차단)은 이미 구현됨. 사용권은 「구독/사용권」 경로로 들어간다.
- 점검 결과(2026-10-28): VIP·골드·일반(비프리미엄) 동작은 정책과 일치. 실버는 비워 두기로 확정. 프리미엄 12개 방금 지정됨(결제 연동 전이라 현재 전원 차단 상태 — 아래 §4-3 확인 필요).

## 2. 사용권(세트) 상품 — 핵심

- **상품 4종(매달 결제 · 금액 잠정, 나중 조정):**

  | 상품 | 월 금액(잠정) | 고를 수 있는 개수 | 프리미엄 선택 |
  |---|---|---|---|
  | 10개 사용권 | 20,000원 | 10개 | ✗ 비프리미엄만 |
  | 30개 사용권 | 30,000원 | 30개 | ✗ 비프리미엄만 |
  | 50개 사용권 | 49,000원 | 50개 | ✓ 프리미엄 포함 가능 |
  | 전체 사용권 | 79,000원 | 모든 프로그램 | ✓ 프리미엄까지 전부 |

- **동작**: 구매자는 그 개수만큼 프로그램을 **직접 골라 1달(결제 주기) 동안 사용**한다. 멈추면 만료.
- **프리미엄 규칙**: 10개·30개 목록에는 프리미엄 배지 프로그램이 보이지 않거나 선택 불가. 50개·전체는 프리미엄도 고를 수 있고, 전체 이용권은 프리미엄 포함 전 프로그램이 열린다.
- **등급 변경 없음**: 사용권을 사도 등급은 그대로(실버 승급 안 함). 사용권(구독)만 부여.
- 참고: 개별 프로그램 결제 최저가가 월 10,000원이므로 10개 묶음(2만원)이 그보다 유리하게 설계됨.

## 3. 구현 방향 (기존 구조 재사용 — 플랫폼 크게 안 건드림)

| 부분 | 방법 |
|---|---|
| 사용권 상품 정의 | `pricing_plans`에 세트 상품 추가, 또는 전용 테이블 `usage_passes`(상품·개수상한·가격). 결제 연동 담당이 택1 |
| 회원 프로그램 선택 화면 | 관리자 「접근 권한 설정」의 프로그램 선택 UI를 회원용으로 재사용(공개 프로그램 목록·체크·개수 제한 10/30/전체) |
| 결제 | 페이앱(`/api/payment/*`) 월 결제 흐름에 사용권 상품 추가 |
| 권한 부여 | 결제 성공 시 고른 N개를 `user_program_access`에 `grant_source='pass'`로 부여(만료=결제 주기). 등급 자동부여(0032)와 같은 묶음 부여 로직. 상품별 개수 상한(10/30/50/전체)과 프리미엄 선택 허용 여부(50·전체만)를 부여 시 검증 |
| 판정 | 사용권 부여가 있으면 그 프로그램 열림. **프리미엄도 50·전체 사용권으로 부여되면 열려야 함** — 0031 트리거가 「무료 부여」만 막고 「결제 기반 부여(pass/구독)」는 통과하도록 `grant_source='pass'`를 예외 처리(결제 구독 경로는 이미 예외). 10·30 사용권에는 애초에 프리미엄을 못 담게 입력에서 막음 |

## 4. 결정·확인 필요 (남은 것)

1. **일반·실버 무료기간**: 현재 14일 — 유지할지, 늘릴지(예: 30일). (결제 연동 전 만료자 다수)
2. **자동 갱신**: 사용권 매달 결제를 **페이앱 정기결제(자동 갱신)**로 할지, 매달 수동 재결제로 할지. (앞서 프리미엄은 「매달 수동」으로 정함 — 사용권도 같게 할지)
3. **프리미엄 12개 현재 차단**: 결제 연동 전인데 지금 전원 차단 상태 — 연동 직전까지 둘지, 잠깐 뗄지.
4. **금액 확정 시점**: 지금은 잠정(10개 2만·30개 3만·50개 4.9만·전체 7.9만). 결제 연동 직전에 최종 확정.
5. **프로그램 교체**: 고른 N개를 매달 갱신 때 다시 고르게 할지(기본 제안: 매 결제 주기마다 재선택 가능).
6. **중복 정리**: VIP·골드가 50·전체 사용권을 사면 프리미엄까지 열리므로 의미 있음(기존 등급 무료는 프리미엄 제외). 일반은 「1개씩 vs 사용권」 중 선택 — 화면에서 안내.
