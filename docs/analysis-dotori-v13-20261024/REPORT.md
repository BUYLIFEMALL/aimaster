## 1. 도톨이 AI v1.3 구조

- 형태: Windows/Mac 설치형 데스크톱 앱(PySide6/Qt + Python 3.12), 로컬 SQLite(`%LOCALAPPDATA%\BlogAI`), 무료(후원·유료 컨설팅 안내 있음).
- AI 연결: ① ChatGPT 구독 로그인(내장 Codex CLI 0.156 + `openai_codex` SDK) ② Claude Code CLI(선택). **API 키 방식이 아니라 회원의 구독 계정 로그인**. 이미지 생성은 Codex 내장 이미지 도구만.
- 외부 연동: 네이버 검색광고 API(월간 검색량·연관어), NAVER API HUB 검색 API(블로그·뉴스·웹·이미지·데이터랩·쇼핑인사이트), 네이버 블로그 RSS·공개 글, 내장 Chromium으로 네이버 검색 화면(비로그인). 키는 OS 보안 저장소(Windows 자격 증명·Mac 키체인).
- 동봉 작성 지식: `knowledge.json` — RuleCard 1,660개(이름·적용 조건·좋은/나쁜 예·중요도·알고리즘 사양), 개발자가 PDF에서 추출·승인한 비공개 지식. 공개 가이드 보강 카드 별도(`public_rulecards`).
- 자동 발행 없음(복사·서식 복사까지).
