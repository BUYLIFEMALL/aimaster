## 1. 기능·로직

| 영역 | 내용 |
|---|---|
| 처리 위치 | **전부 회원 PC 브라우저 엔진 안**(`onnxruntime-web`, WebGPU 우선 → 안 되면 WASM), 이미지 외부 전송 없음, 인터넷 없이 동작. 모델 첫 로딩 30초~1분(캐시 후 빠름) |
| 올리기 | 끌어다 놓기·여러 장, **최대 300장**, PNG·JPG·WebP |
| 편집 캔버스 | 브러시로 지울 곳 칠하기(빨간 반투명 마스크) · 지우개 · 크기 · 되돌리기/다시 실행 · 확대·이동 · 「원본으로」(원본 픽셀은 건드리지 않음) |
| **문구 자동 찾기** | PP-OCRv4로 이미지 속 글자(한글·영문·숫자·URL) **위치만** 찾아 마스크에 칠함(읽지는 않음). 남길 글자는 지우개로 걷어냄. 세로쓰기·장식체는 놓칠 수 있음 |
| 워터마크 자동 찾기 | **제미나이 생성 이미지 우하단 ✦ 표식**의 위치를 고정 좌표 → 모양·색 탐색 → 실패 시 비율 기준 강제 위치로 칠함 |
| 지우기 | LaMa 인페인팅(512×512 입력, 마스크 이진화) — 칠한 곳을 주변에 맞춰 자연스럽게 채움 |
| **일괄** | 한 장에 칠한 마스크를 **같은 비율의 여러 장에 복사** → 한 번에 지우기, 진행·남은 시간·중단(처리분 유지)·실패 표시 |
| 내려받기 | 선택한 장을 **ZIP 하나로**, 원본 크기 무손실 PNG 또는 가로 크기 줄이기(기본 1000px)·JPG 품질 85/90/95 |
| 안내 | 사용설명서 14장, 면책(저작권·상표·부정경쟁 책임은 사용자, **AI 생성 표식 제거 시 플랫폼 정책·법령 위반 가능**, 비가시 워터마크 SynthID는 남음) |

## 4. 접목하지 않는 것

| 기능 | 이유 |
|---|---|
| **제미나이 ✦ 워터마크 자동 찾아 지우기** | AI 생성물 표식 제거 — 플랫폼 정책·AI 생성물 표시 의무(국내 AI 기본법 등)와 충돌 위험. 앱 스스로도 면책에서 경고. **권장: 넣지 않음**(주인님 결정 필요, §6). 우리 회원이 API로 만든 이미지는 원래 보이는 표식이 없음 |
| 남의 이미지 워터마크 제거를 홍보하는 안내 | 저작권·상표 문제 — 「본인 권리 이미지에만」 고지 필수로 대체 |
| Electron 포장·이 앱 코드·문구 | 웹이면 충분, 권리 없음 |

## 5. 병합 vs 독립 — 판단

| 기준 | 판정 |
|---|---|
| 같은 일 | ○ 이미지 부분 지우기 = `banana-canvas` 「브러시 부분 삭제」 |
| 같은 사용자 | ○ 이미지 정리가 필요한 회원(쇼핑몰·블로그·카드뉴스) |
| 한 흐름 | ○ 올리기 → 칠하기/자동 찾기 → 지우기 → 내려받기 |
| 다른 점 | 처리 방식(무료 브라우저 vs 유료 Gemini)·일괄·글자 자동 찾기 — **기능 차이이지 결과물이 다르지 않음** |

**의견: 독립 개발 안 함 → `banana-canvas`에 「무료 지우기(내 브라우저)」를 병합하고(C1~C3·C5), 엔진은 공용 기준 코드로 만들어 상세페이지·썸네일 등에 사본 적용(C4).** 기존 Gemini 부분 삭제는 「AI로 다시 그리기(고품질·유료)」로 남겨 두 방식을 고르게 함.

## 6. 주인님 결정이 필요한 것

1. **범위·순서** — 추천: C1 공용 엔진 + C2 글자 찾기 → C3·C5 바나나 캔버스 화면 → C4 다른 프로그램.
2. **제미나이 워터마크 자동 제거** — 추천: **넣지 않음**(AI 생성물 표시 의무·플랫폼 정책 위험). 넣는다면 본인 생성물 한정 고지·확인란.
3. **구현 담당** — 바나나 캔버스(이미지 계열) 담당 세션 지정.
4. 시제품 확인 — 첫 208MB 로딩, WebGPU 없는 PC 속도(장당 수 초), 멀티스레드용 COOP/COEP 머리글이 로그인과 충돌하는지(무료 음성 엔진 인계와 같은 과제 — 한 번 확인한 결과를 같이 쓰기).
