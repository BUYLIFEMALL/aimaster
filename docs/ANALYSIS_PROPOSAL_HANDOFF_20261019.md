## 미완료·착수 전 확인

1. **F-001 운영 DB PUBLIC 전체 허용 정책**: `user_sessions/site_settings/coupons/coupon_usage`, 정책명과 실제 적용 역할이 다릅니다. anon CRUD grant + ALL/public/true가 확인됐습니다. **설정은 그대로 두었고 DB수정 승인 필요**. 역할별 allow/deny·롤백 검증 플랜부터 제시합니다.
2. **F-002/F-003 eBook API 자격·SSRF**: 코드는 보호 미비, 비용없는 빈 입력 응답만 확인. 회원/권한/API 게이트와 공개주소/DNS/redirect/본문상한을 fake fixture로 검증하는 수정이 미실행입니다.
3. **F-004~006/F-016 개인자료·30일**: 쇼핑제휴 전역 네이버 캐시, 쇼츠 직접조회 만료, 포토 로컬 날짜 만료, 기존 경쟁사v1.08 운영 승인 대기는 별개 작업입니다. 무소유 기존 자료 임의귀속/삭제 금지.
4. **F-007~011 CRM·예약 발송**: 중복 선점/부분실패·현재 자격·시간대·비밀 누락 차단 작업 미구현. 실제 메시지 발송0. DB/실제 발송 승인 범위를 확인합니다.
5. **F-012~014 웹툰/오디오**, 도구·문서 일관성·신규 아이디어/병합 구현 미실행.
