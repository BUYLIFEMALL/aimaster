## 항목마다 지킬 완료 조건

1. 착수 직전 ACTIVE_WORK·미커밋·최신 인수인계를 확인하고 **대상 프로그램 하나씩** 진행한다.
2. 코드를 고치기 전에 플랜(문제·범위·순서·검수·비용·버전/배포·산출물)을 주인님께 보이고 해당 프로그램 docs에 남긴다.
3. **실발송·유료 호출은 사전 승인**: 실제 메일·문자·카카오 발송, SerpApi·AI 호출은 무엇을·몇 번·누구 키로·대략 비용을 먼저 보고한다. 실제 고객 명부 캠페인으로 시험하지 않는다.
4. 본인 키·계정만 쓰고 다른 회원·운영자 폴백 금지. 생성 데이터는 회원별·생성일 기준 30일.
5. 작은 수정은 「미배포 대기」로 모았다가 배포하고, 배포 때만 버전을 올린다(코드 `lib/version.ts` + DB `programs.version`).
6. 완료 시 프로그램 `AGENTS.md`·`docs/IMPROVEMENTS.md`, 루트 HANDOFF(`[역할: …]`), [비교표](MARKETING_FEATURE_MATRIX.md) 칸·이력, [프로그램 비교표](PROGRAM_CAPABILITY_MAP.md) 카드, 이 목록을 갱신한다.
