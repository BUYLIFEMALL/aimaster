## 1. 목적과 대상
관심 지역의 **건물(꼬마빌딩·근린생활·다가구 등) 새 매물·가격 변동**을 회원 PC의 크롬 확장이 회원 본인 계정으로 찾아 본인 텔레그램·메일·카톡으로 알려 준다. 대상: 수익형 건물을 찾는 투자자, 건물 전문 중개 실무자, 사옥을 찾는 소규모 사업자.

## 2. 아파트 프로그램과 다른 점
| 부분 | 아파트(`realty-listing-alert`) | 건물(새 프로그램) |
|---|---|---|
| 감시 단위 | 단지 | **지역(시·구·동)** — 건물은 단지가 없다 |
| 조건 | 거래 종류·가격·전용면적 | 가격·**대지면적·연면적**·용도·사용승인 연도 |
| 통계·급매 | 같은 단지·같은 면적 중간값 | 같은 동·같은 용도의 **연면적 평당가** 중간값 |
| 실거래 비교 | 국토부 아파트 매매 | 국토부 **상업업무용 부동산 매매**(활용신청 따로) |
| 엑셀 칸 | 동·층·전용면적 | 주소(지번 일부)·대지/연면적·층수·용도·사용승인 |

## 3. 그대로 가져다 쓸 것 (아파트 프로그램 기준 코드)
- 웹 뼈대: 표준 로그인·권한(`lib/access.ts`)·좌측 메뉴·매뉴얼·대시보드 다운로드 센터
- 설정 화면 표 `SetupTable`·AI 엔진 두 줄 `AiEngineRow`·받는 곳(텔레그램·이메일·카카오) 연결 — 회원 공용 연동값 그대로 재사용(한 번 등록하면 두 프로그램 공용)
- 확장: 웹 연결(`web-bridge`)·예약 타이머·하루 상한·차단 화면이면 그날 멈춤·엑셀 만들기·텔레그램/메일/카톡 보내기·AI 시세 요약·통계/변동 기록(회원 PC 1년 보관)
- 결과 화면: 결과 표 정렬·거르기·변동 기록·여러 번 내린 매물

## 4. 새로 만들 것
1. 지역 단위 감시 대상(시·구·동 버튼 — 아파트 v1.05 지역 고르기 재사용)과 건물 조건 칸
2. 확장의 건물 매물 읽기·정리(건물 전용 칸) — **0단계 사전 검증으로 방식 확정 뒤**
3. 건물 통계(동·용도별 연면적 평당가)·급매 기준
4. 상업업무용 실거래 비교(회원 공공데이터 키, 활용신청 안내 링크 포함)
