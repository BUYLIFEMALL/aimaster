## 0. 주인님 지시 (절대 지시)
- 2026-10-24 「N1·N2 + 현재 매물 검토」로 진행.
- 2026-10-24 **「이 프로그램의 취지는 편하게 네이버에 올라오는 실시간 매물정보를 정리해서 받아보는 거야」** → 본 기능은 **실시간 매물(N3)**, 바로가기(N1)·엑셀(N2)은 보조.

## 1. 목표 (회원이 얻는 것)
1. 관심 아파트 단지를 한 번 등록하면, **새로 올라온 매물·가격이 바뀐 매물·내려간 매물**을 표로 정리해 본다.
2. 새 매물이 생기면 **텔레그램으로 받는다**(이미 연결된 텔레그램 재사용).
3. 정리된 표를 **엑셀로 내려받는다**.
4. 같은 화면에서 그 단지의 **과거 실거래(우리 기존 데이터)와 지금 호가를 나란히** 본다 — 원본 수집기에 없는 우리만의 장점.

## 2. 구조 — 수집은 회원 본인 브라우저, 정리·알림은 웹

| 단계 | 어디서 | 내용 |
|---|---|---|
| ① 관심 단지 등록 | 웹 + 확장 | 회원이 네이버 부동산에서 단지 화면을 연 상태로 확장 버튼 「관심 단지 추가」(주소에서 단지번호 자동 인식) 또는 웹에 단지 주소 붙여 넣기. 최대 **10개 단지** |
| ② 수집 | **회원 크롬의 확장** | 회원 본인이 네이버에 접속한 그 브라우저에서, 네이버 부동산 화면이 쓰는 매물 목록을 **사람 속도로** 읽음(§4 안전 규칙). 우리 서버는 네이버를 부르지 않는다 |
| ③ 전송 | 확장 → 웹 API | 읽은 매물(단지번호·매물번호·거래 종류·가격·면적·층·방향·확인일·중개사 이름)을 회원 계정으로 보냄 |
| ④ 정리 | 웹 | 이전 수집과 비교해 **신규·가격 변동·사라짐** 표시, 단지별·거래 종류별 표, 실거래 평균과 호가 차이 |
| ⑤ 알림 | 웹(서버) | 신규·가격 하락 매물만 회원 텔레그램으로 요약 1통(같은 매물 중복 알림 없음) |
| ⑥ 내보내기 | 웹 | 표 그대로 엑셀(CSV, 한글 깨짐 없게 UTF-8 BOM) |

- 수집 방식 두 가지(회원이 고름):
  - **ⓐ 지금 수집**: 확장 버튼을 누를 때만 1회.
  - **ⓑ 자동 수집**: 크롬이 켜져 있는 동안 **하루 최대 3회**(회원이 고른 시각 근처, 시작 시각 ±15분 무작위). 1분 반복(원본)은 하지 않는다.
- 크롬이 꺼져 있으면 수집하지 않는다(서버가 대신하지 않음) — 화면에 「마지막 수집 시각」 표시.

## 4. 안전 규칙 (구현 필수 — 하나라도 빠지면 배포하지 않음)
1. **우리 서버·운영자 IP에서 네이버를 호출하지 않는다.** 회원 쿠키·토큰을 서버로 보내거나 저장하지 않는다.
2. 요청 간격 **2~5초 무작위**, 단지 사이 10~30초, 1회 수집 최대 단지 10개·단지당 최대 5페이지(약 100건). 상세(중개사 전화 등) 개별 조회는 하지 않는다(원본의 「상세 수집」 제외).
3. 응답이 401·403·429이거나 형식이 바뀌면 **즉시 멈추고** 회원에게 「네이버에서 잠시 막았습니다 — 다음 수집 때 다시 시도」 표시, 그날 자동 수집 중지. 재시도 반복 없음.
4. 네이버 부동산 탭이 열려 있지 않으면 자동 수집 때 **백그라운드 탭을 몰래 열지 않는다** — 회원 설정 「자동 수집 때 네이버 부동산 탭 열기」를 켠 경우만 보이는 탭으로 열고 끝나면 닫는다.
5. 수집 결과는 **회원 본인 것으로만 저장**(다른 회원과 공유·재사용 금지, 같은 단지라도 회원별 행), **30일 뒤 자동 삭제**(최상위 규칙).
6. 화면·매뉴얼에 「네이버 부동산 정보를 회원 본인 브라우저에서 읽어 정리합니다. 개인 참고용으로만 쓰고 다시 배포하지 마세요」 안내.
7. 비공식 화면 구조라 네이버가 바꾸면 멈출 수 있다 — 형식 검사 실패 시 관리자에게 알림(확장 버전 보고).
