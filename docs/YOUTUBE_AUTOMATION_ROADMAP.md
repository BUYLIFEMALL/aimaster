## 📌 Phase 1. 벤치마킹 & 떡상 소재 발굴 엔진 (현재 진행 단계)

소형 채널이라도 알고리즘을 타서 조회수가 폭발한 "검증된 소재"를 발굴하고 벤치마킹하는 핵심 소싱 엔진입니다.

### 1-1. 📊 황금 채널 발굴기 (Golden Channel Explorer)
- [ ] **구독자 대비 조회수 폭발 채널 필터링**: 구독자 1만 명 이하 소형 채널 중 최근 영상 평균 조회수 기여도가 500%~1000% 이상인 알짜 채널 자동 스크리닝
- [ ] 카테고리별 / 키워드별 신생 급성장 채널 탐색
- [ ] 채널 구독자 수, 총 조회수, 최근 업로드 빈도, 영상당 평균 성과 요약 카드
- [ ] 타겟 채널 원클릭 [⭐ 즐겨찾기] 추가

### 1-2. 🔍 조회수 폭발 쇼츠 찾기 (Viral Shorts Hunter)
- [ ] 키워드 검색창 (예: 요리, 운동, 재테크, 꿀팁 등)
- [ ] 다차원 실전 필터:
  - **업로드 일자**: 최근 1주일 / 최근 1개월 / 최근 3개월 / 전체
  - **최대 구독자수**: 제한 없음 / 1만 이하 / 5만 이하 / 10만 이하 (소형 채널 필터링)
  - **조회수 범위**: 1만~5만회 / 5만~10만회 / 10만~50만회 / 50만회 이상
  - **정렬 기준**: 조회수 높은순 / 최신순 / 구독자 대비 조회수 배수(Viral Score) 높은순
- [ ] 떡상 쇼츠 카드 목록 (썸네일, 제목, 채널명, 조회수, 업로드 경과일, 떡상 배수 배지)

### 1-3. 🔥 실시간 터진 영상 모니터링 (Live Trending & VPH Radar)
- [ ] 포맷 필터: [쇼츠] [롱폼] [전체]
- [ ] 정렬 기준: [🔥 급등순] [👀 조회수순] [⏱️ 최신순]
- [ ] 랭킹 변화 배지: [신규] [상승 ↑] [하락 ↓] [유지 -]
- [ ] **VPH(Views Per Hour) 실시간 속도 지표**: 카드 하단에 `+7.5만/h`, `+4.2만/h` 등 시간당 조회수 증가량 시각화
- [ ] 영상별 원클릭 [⭐ 즐겨찾기] 및 [📋 대본/자막 추출] 연동

### 1-4. 🎬 쇼츠 원본 찾기 (Shorts Source Finder)
- [ ] 쇼츠 URL(`https://www.youtube.com/shorts/...`) 입력창
- [ ] 4단계 원본 영상 역추적 알고리즘:
  1. 설명란 / 댓글 링크 / 유튜브 관련 동영상 링크 추출
  2. 동일 채널 내 롱폼 동영상 메타데이터 대조
  3. 제목 및 키워드 기반 원작 롱폼 검색
  4. 쇼츠 자막(대사) ↔ 롱폼 자막 텍스트 일치율 대조 확정
- [ ] 일치하는 원본 롱폼 영상 썸네일, 타임스탬프 구간, 출처 링크 안내

### 1-5. 📈 채널 랭킹 (Channel Leaderboard)
- [ ] 분야별 / 카테고리별 국내/글로벌 인기 유튜브 채널 순위
- [ ] 일간/주간 성장률 높은 급상승 채널 순위표

### 1-6. ⭐ 즐겨찾기 보관함 (Benchmark Vault)
- [ ] [채널 N개] [영상 N개] [키워드 N개] 3단 탭 관리
- [ ] 저장된 항목 메모 및 카테고리 태그 분류
- [ ] 엑셀/CSV 및 마크다운 내보내기

### 1-7. 🔑 본인 API 키 연동 & 이용 가이드
- [ ] Google Cloud Console YouTube Data API v3 키 회원 직접 등록 (`user_api_keys`)
- [ ] AI 키(Gemini, OpenAI, Claude) 등록
- [ ] 메뉴별 사용법 아코디언 가이드

## 📌 Phase 2. AI 분석 & 오리지널 리메이크 엔진 (Why Viral & Remake)

벤치마킹한 성공 소재를 바탕으로, 저작권 이슈 없는 나만의 100% 오리지널 콘텐츠를 재창작하는 AI 엔진입니다.

### 2-1. 📜 원클릭 자막/스크립트 추출기
- [ ] 유튜브 한국어/외국어 자막 1초 추출 (타임스탬프 포함)
- [ ] 자막 미제공 영상 Whisper 음성 인식 텍스트 변환

### 2-2. 🧠 바이럴 후킹 공식 AI 역설계 분석
- [ ] **0~3초 도입부 후킹 기법 분석**: 시청자를 멈추게 한 첫 마디/비주얼 충격 요인
- [ ] **시청 지속(Retention) 구조 분석**: 텐션 유지 장치 및 이탈 방지 패턴 해부
- [ ] **썸네일 & 제목 심리 공식 분석**: 호기심 공백, 손실 회피, 비밀 폭로 등 클릭 유발 요인

### 2-3. ✍️ 100% 오리지널 AI 대본 재창작 (저작권 프리)
- [ ] 원작의 후킹 구조와 성공 논리만 계승하고 내용은 완전히 새로운 오리지널 대본 생성
- [ ] 포맷별 옵션: **숏폼(60초 씬별 대본)** / **미드폼(3~5분)** / **롱폼(8~10분 챕터별)**
- [ ] 톤앤매너 선택: 흥미진진 썰형, 정보성 큐레이션, 충격 실화, 전문 지식 해설

### 2-4. 💬 시청자 반응(댓글) 마이닝 ➔ 다음 영상 글감화
- [ ] 벤치마크 영상 인기 댓글 TOP 100 자동 분석
- [ ] 시청자가 가장 공감한 포인트, 궁금해하는 점, 다음 편 요청 주제 추출

## 📌 Phase 3. 패키징 최적화 & 멀티미디어 에셋 (Packaging & Assets)

클릭률(CTR)과 시청 지속 시간을 극대화하기 위한 패키징 및 비디오 에셋 생성 단계입니다.

### 3-1. 🖼️ 모바일 썸네일 시뮬레이터 & AI 승률 평가
- [ ] 썸네일 시안 2~3장 업로드 시 실제 유튜브 모바일 피드(다크/라이트) 목업 배치
- [ ] AI 썸네일 점수 채점: 텍스트 가독성, 시선 집중도, 배경 대비도, 클릭 유발 심리 피드백

### 3-2. 🎯 고클릭 A/B 테스트용 제목 10종
- [ ] 5대 고효율 후킹 공식 적용 제목 10개 추천 (유튜브 스튜디오 A/B 테스트 최적화)

### 3-3. ⏱️ 원클릭 타임스탬프 챕터 자동 생성
- [ ] 대본/영상 기반 유튜브 설명란용 타임코드 챕터(`00:00 인트로`, `01:23 핵심`) 자동 생성

### 3-4. 🏷️ 검색 알고리즘 SEO 메타데이터 패키지
- [ ] 검색 최적화 설명란 + 상위 노출 해시태그 3개 + 검색 태그 15개 원클릭 생성

### 3-5. 🎨 씬별 AI 이미지/영상 프롬프트 & 자막 파일 내보내기
- [ ] 장면별 이미지 프롬프트(나노바나나/미드저니/Flux) 및 비디오 프롬프트(Runway/Kling)
- [ ] 캡컷(CapCut) 및 프리미어 프로 타임코드 자막(SRT) 파일 원클릭 다운로드

## 📌 Phase 4. 실전 채널 운영 & 수익화 자동화 (Operations & Monetization)

지속 가능한 채널 운영과 빠른 현금 흐름 창출을 위한 비즈니스 자동화 모듈입니다.

### 4-1. 🛒 쇼핑 쇼츠 연계 쿠팡/알리 상품 매칭기
- [ ] 영상 소재 분석 ➔ 쿠팡 파트너스 / 알리익스프레스 연관 상품 자동 매칭
- [ ] 설명란 구매 링크 멘트 및 고정댓글 구매 유도 템플릿 자동 작성

### 4-2. 🛰️ 경쟁 채널 실시간 스파이 레이더
- [ ] 등록한 경쟁 채널의 신규 업로드 실시간 감지
- [ ] 업로드 후 1시간/6시간/24시간 VPH 조회수 추이 비교 알림

### 4-3. 🚀 유튜브 스튜디오 원클릭 예약 업로드 (OAuth)
- [ ] 완성된 영상 파일, 제목, 설명란, 태그, 썸네일, 챕터를 유튜브 채널에 직접 예약 발행
