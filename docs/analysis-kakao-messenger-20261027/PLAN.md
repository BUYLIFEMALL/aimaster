## 1. 무엇을 만드나 (한 줄)

**카카오톡 공식 API가 없는 개인 메신저(친구·대화방)에, 회원이 미리 만들어 둔 메시지를 회원 본인 기기에서 사람이 보내듯 자동으로 보내 주는** 프로그램. 발송 실행은 **PC(카카오톡 PC 앱)와 핸드폰(안드로이드) 둘 다**에서 할 수 있게 한다.

## 2. 왜 「사람 동작 모사」인가 (핵심 성격)

카카오는 개인 메신저용 공식 발송 API를 주지 않는다. 그래서 유일한 방법은 **사람이 카톡 창에서 하는 클릭·타이핑·전송을 그대로 흉내 내는 것**이다 — 우리 네이버 블로그 자동화(공식 발행 API 없음 → 확장·데스크톱 앱이 사람처럼 조작)와 **같은 봇 탐지 회피 패턴**이다. 기법은 이미 저장소에 있다(`naver-blog-auto-poster_app/src/lib/humanInput.js` — 사람 같은 지연·마우스 이동·오타 섞기).

## 3. 두 실행 경로 (둘 다 만든다)

| 경로 | 무엇으로 | 어떻게 | 난이도·주의 |
|---|---|---|---|
| **PC — 카카오톡 PC 앱** | **데스크톱 앱**(Electron + OS UI 자동화) | 회원 PC에 설치. 회원이 카톡 PC에 로그인한 상태에서, 앱이 카톡 창을 찾아 대화방·친구를 사람처럼 클릭→입력→전송. 네이버 블로그 데스크톱 앱과 같은 구조 | 카톡 PC는 네이티브 앱이라 **크롬 확장으로는 불가** → 데스크톱 앱 필수. 중 |
| **핸드폰 — 카카오톡 모바일** | **안드로이드 앱**(접근성 서비스, Accessibility Service) | 회원 폰에 설치. 접근성 권한을 회원이 직접 켜면, 화면의 카톡 UI를 읽어 사람 터치처럼 대화방 열기→입력→전송 | 안드로이드만 가능(**iOS는 접근성 제약으로 사실상 불가** → 1차 제외). 기기·안드로이드 버전마다 UI가 달라 가장 까다로움. 상 |

- **공통(웹 프로그램)**: 대상 목록·메시지 템플릿(「○○님」 변수 치환)·발송 설정·발송 기록은 **웹(AIMaster 프로그램)에서 회원이 만들고 저장**한다(회원별 격리 owner-only). 실제 발송만 회원 기기(PC 앱/폰 앱)에서 한다 — 우리 서버는 카카오에 직접 요청하지 않는다(서버 고정 IP 금지, 위험 분산).
- **기기 연결**: 웹에서 만든 「발송 작업」을 회원의 PC 앱·폰 앱이 받아 실행하고, 결과(보냄·실패·건너뜀)를 웹에 돌려줘 기록한다. 네이버 블로그 자동화의 웹↔기기 연결 방식을 재사용한다.

## 3-1. 발송 대상 (2026-10-27 주인님 확정)

**단톡방(참여 중인 채팅방) + 내 카카오톡에 등록된 친구 모두**에게 보낼 수 있게 한다. 주인님 지시: 「단톡방에 올리는 것이니까 사전 동의 안 된 상태가 되겠지」 · 「혹은 내 카카오톡에 등록된 친구면 다 가능」 · 「단톡방, 내 카카오톡에 등록된 친구 모두 발송 가능하게」. 즉 **「사전 동의한 친구만」으로 한정하지 않는다** — 단톡방은 사전 동의가 없는 상태일 수 있음을 인정하고, 대신 아래 §4의 책임 고지·안정적 리미트로 위험을 다룬다.

## 4. 안전 설계 (마케팅 예외 규칙 그대로)

- **회원 본인 계정·본인 기기에서만**(운영자·타 회원 계정 대리 발송 금지).
- **법 고지는 하되 대상은 제한하지 않는다** — 발송 대상은 §3-1대로 단톡방·등록 친구 전체다. 광고성 정보는 원래 받는 사람 사전 동의가 필요(정보통신망법 제50조)하고 단톡방은 그 동의가 없는 상태일 수 있음을 **화면에 분명히 고지**하되, 대상 제한은 걸지 않고 **발송 여부·책임은 회원 본인**에게 둔다(마케팅 예외 조항 취지).
- **안정적 리미트 기본값**(시간당·하루 상한, 사람 같은 전송 간격·무작위 지연). 회원이 필요하면 VPN·IP 변경을 본인 책임으로 선택.
- **책임 고지(동의 체크)**: 첫 실행·발송 직전에 「카카오 약관 위반·계정 영구 정지·법적 책임 소지가 있으며 발송 책임은 회원 본인에게 있다」를 확인받는다.
- **하지 않는 것**: 수신 동의 없는 무차별 대량 발송 권장, 번호·아이디 긁어 모으기(이 프로그램은 「발송」이 주목적), 보안문자 우회·계정 대량 생성.

## 5. 재사용·출처

- **사람 동작 모사·웹↔기기 연결**: `naver-blog-auto-poster_app`(데스크톱 앱)·`humanInput.js`.
- **대상 목록·메시지 템플릿·발송 기록·변수 치환(「○○님」)**: 기존 `kakao_auto_poster`(공식 채널·SOLAPI)의 웹 화면·데이터 구조를 참고(발송 통로만 다름).
- 원본 koms·B6은 **기능·흐름만 참고**하고 코드는 이식하지 않는다(소스 보호 정책).
