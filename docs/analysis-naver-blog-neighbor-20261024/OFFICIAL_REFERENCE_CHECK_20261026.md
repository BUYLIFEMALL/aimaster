# AI 블로그 이웃 소통 자동화 — 공식자료 확인 (2026-10-26)

확인일: **2026-10-26**. 작성: Codex 공식자료 조사 담당. 적용 스킬: `research`(공식 1차 자료 조사·단일 문서 기록). 조사 범위는 네이버 정책·공개 도움말, Chrome 확장 공식 문서, 기존 모델 목록과 공급자 공식 가격입니다. 기존 플랜·인수인계의 D1~D9는 변경하지 않았습니다. 운영 코드·DB·브라우저 계정·외부 게시·AI 호출·빌드·배포·커밋·푸시는 수행하지 않았습니다. ‘워크스페이스·플래너 작업상태 연결 + 이미지 수정 후 원고 복귀’ 연계는 다른 세션 담당이므로 제외했습니다.

## 1. 먼저 구분해야 할 사항

**신청 20건·공감 100건·댓글 30건은 주인님이 확정하신 앱 자체 최대·기본값입니다. 네이버가 보장한 안전 한도가 아닙니다.** 이번에 확인한 공식 도움말에서는 서로이웃 신청·공감·댓글의 일일 허용량을 확정할 수 없었습니다. 숫자를 더 낮추거나 댓글을 사람이 확인한다고 해서 자동화 방식에 대한 정책 허용이 확보되는 것도 아닙니다. 이는 아래 약관을 대조한 검토 의견이며 네이버의 개별 유권해석을 받은 결과는 아닙니다.

**공식 수치 미확인:** 서로이웃 신청의 하루 몇 건, 공감의 하루 몇 건, 댓글의 하루 몇 건까지 가능하다는 블로그 공식 수치를 이번 조사에서 찾지 못했습니다. 공개 도움말 검색어는 ‘서로이웃 신청 하루/일일/제한’, ‘블로그 공감 횟수’, ‘블로그 댓글 제한’ 등이었습니다. 검색에서 발견되는 비공식 100명 주장이나 다른 네이버 서비스(뉴스·웹툰 등)의 한도는 근거로 사용하지 않았습니다. ‘수치가 공개되지 않았다’ 또는 ‘한도가 없다’는 단정도 하지 않습니다.

**플랜 검토 의견:** D6의 숫자와 D7의 중단 기준은 유지하되, ‘플랫폼 최대치’라는 기존 표현은 추후 수정 승인 시 ‘이 프로그램의 자체 최대치’로 명확히 하는 것이 좋습니다. 자동 공감·신청·댓글과 검색·본문 수집 모두 약관의 자동화 조항과 대조할 대상입니다. 네이버가 이 방식에 허락한 범위는 미확인으로 남겨야 합니다. 대기시간·무작위 입력·일일 상한을 정책 허용 근거로 삼을 수 없습니다.

### 2-1. 허용 예외와 공식 검색 API로 검토할 수 있는 범위

네이버는 자동화 접속·수집의 예외로 **명시적 허용·사전 승낙**, **적법한 클라이언트 ID로 해당 약관을 준수하는 공식 API 이용**, **개발자 가이드·robots.txt 등이 허용한 탐색 범위**를 안내합니다. 따라서 모든 자동화가 일률적으로 금지된다고 요약해서도 안 됩니다. 다만 이 플랜의 개별 수집·등록 동작이 어느 허용 범위에 해당하는지는 별도로 확인해야 합니다. [책임의 한계와 법적 고지 — 서비스 접근 및 이용 관련 안내](https://policy.naver.com/policy/disclaimer.html), 확인 2026-10-26.

**발견 단계의 대안 후보:** 공식 블로그 검색 API는 `GET https://openapi.naver.com/v1/search/blog.json`으로 검색 결과를 반환합니다. 검색어·정확도순/날짜순을 지정할 수 있고, 응답에는 제목·글 주소·요약 패시지·블로그 이름/주소·작성일이 포함됩니다. 문서상 검색 API의 하루 호출 한도는 25,000회이며 사용량은 클라이언트 ID별로 합산됩니다. 비로그인 방식이지만 앱 등록과 클라이언트 ID/시크릿이 필요합니다. 이 한도는 **검색 API 호출 한도**이며 이웃 신청 한도가 아닙니다. [블로그 검색 API 공식 문서](https://developers.naver.com/docs/serviceapi/search/blog/blog.md), 확인 2026-10-26.

검토 의견으로는 키워드로 후보 글/블로그를 찾는 구간을 공식 검색 API로 대체할 여지가 있습니다. 반환되는 `description`은 요약이므로 글 전체 정독이나 서로이웃 관계·공감 상태·댓글 등록 성공 확인까지 이 API로 해결된다고 볼 수 없습니다. 해당 검색 API 문서에는 댓글·공감·서로이웃 신청 쓰기 동작이 설명되어 있지 않습니다. [블로그 검색 API 응답·메서드](https://developers.naver.com/docs/serviceapi/search/blog/blog.md), 확인 2026-10-26.

[네이버 오픈API 종류](https://developers.naver.com/docs/common/openapiguide/apilist.md)도 확인했으나, **이번에 읽은 공개 목록·검색 문서 범위에서는 블로그 댓글·공감·서로이웃 신청용 공식 쓰기 API를 확인하지 못했습니다**(확인 2026-10-26). 모든 제휴/별도 API가 존재하지 않는다고 단정하지 않습니다. 공식 검색 API 사용 가능성은 나머지 자동 입력·등록 방식에 대한 포괄적 허락이 아닙니다. 실제 앱 등록·API 호출·키 발급은 수행하지 않았습니다.

| 상위형 비용 비교 예시: Claude Sonnet 5 | `claude-sonnet-5` | 2.00 | 10.00 | 공식 페이지는 사용 가능하지만 Legacy라고 표시합니다. [Sonnet 5 모델·가격](https://platform.claude.com/docs/en/models/sonnet-5/overview), 확인 2026-10-26 |

공식 모델 단가를 확인한 것과 한국어 댓글 품질·속도를 비교한 것은 다릅니다. ‘상위형’은 비용·모델 선택 화면을 검토하기 위한 후보 구분이며, 이번 조사에서 댓글 품질 우열을 측정하지 않았습니다. 다른 공급자의 기존 모델 ID는 이번 가격표에 포함하지 않았으므로 검증 완료로 표시하지 않습니다.

## 5. 호출 횟수와 토큰에 따른 비용 예시

계산식은 `입력 토큰 합계 ÷ 1,000,000 × 입력 단가 + 과금 출력 토큰 합계 ÷ 1,000,000 × 출력 단가`입니다. 본문·프로필·말투 샘플·지시문·재시도·생성 후 검토가 모두 토큰이나 호출 수를 늘릴 수 있으므로 **댓글 30건 상한은 AI 호출 30회 상한과 다릅니다.**

**가정 A:** 1회에 입력 4,000·출력 300토큰, 캐시·도구·재시도 없음. 실제 토큰 측정치가 아닌 계산용 가정입니다.

| 후보 | 1회 비용 USD | 같은 요청 100회 USD |
|---|---:|---:|
| Groq GPT OSS 20B | 0.00039 | 0.039 |
| Claude Haiku 4.5 | 0.0055 | 0.55 |
| Claude Sonnet 5 | 0.011 | 1.10 |

**가정 B:** 댓글 하나를 위해 ① 분석 입력 4,000·출력 300토큰, ② 작성 입력 1,500·출력 200토큰을 각각 한 번 호출합니다. 매일 댓글 30개를 30일 처리하면 분석 900회+작성 900회, 합계 1,800회입니다.

| 분석 / 작성 모델 | 댓글 1개 USD | 하루 30개 USD | 30일 USD |
|---|---:|---:|---:|
| 모두 Groq GPT OSS 20B | 0.0005625 | 0.016875 | 0.50625 |
| 모두 Claude Haiku 4.5 | 0.008 | 0.24 | 7.20 |
| 모두 Claude Sonnet 5 | 0.016 | 0.48 | 14.40 |
| Groq GPT OSS 20B 분석 / Sonnet 5 작성 | 0.00539 | 0.1617 | 4.851 |

**위 금액은 전체 프로그램 월 운영비가 아닙니다.** 내 블로그 초기 분석·후보 점수·신청 메시지·답글·재생성·자가 검토·추론 출력·다른 앱과의 키 사용량·웹/DB/로그/트래픽 비용은 제외했습니다. 실제 견적에는 단계별 호출 수, 입력/과금 출력 토큰, 실패·재시도 상한과 월 예산을 따로 잡아야 합니다. 환율이나 원화 환산은 사용하지 않았습니다.

## 6. ‘무료’와 ‘운영자 인프라 없음’ 표현 검토

- **Groq 무료는 무제한이 아닙니다.** 공식 문서는 요청·토큰 등 여러 제한이 조직 단위로 적용되고 먼저 닿은 제한이 적용된다고 안내하며, 정확한 값은 해당 계정의 Limits에서 확인하도록 합니다. 같은 키를 다른 앱이 함께 쓰는 경우도 예산에 고려해야 합니다. [Groq Rate Limits](https://console.groq.com/docs/rate-limits), 확인 2026-10-26.
- **OpenRouter 무료 모델에도 계정·요청 제한이 있습니다.** 공식 Limits 페이지에서 무료 모델 사용량과 계정 조건에 따른 제한 구조는 확인했으나, 이번 읽기 결과의 수치 표가 비어 있어 저장소 안내의 ‘하루 50회·분당 20회’를 최신 확정 수치로 재인용하지 않았습니다. 고정 무료 모델의 현재 제공 여부도 별도 미검증입니다. [OpenRouter Limits](https://openrouter.ai/docs/api_reference/limits), 확인 2026-10-26.
- **Cloudflare의 하루 무료 10,000 Neurons는 10,000회 호출이 아닙니다.** 공식 가격은 초과 사용 시 유료 Workers 플랜에서 1,000 Neurons당 $0.011이며 모델별 연산 사용량을 따릅니다. [Workers AI Pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/), 확인 2026-10-26.
- **회원 본인 키로 결제하는 구조는 비용 부담 주체를 구분하는 설계입니다.** 그것만으로 AI 사용료 자체가 0이 되지는 않습니다. 플랜의 ‘운영자 인프라 없음’ 역시 서버·DB·로그 등을 기존 공용 자원에서 쓰는지와 한도 내 추가 과금이 없는지를 확인하기 전에는 확정할 수 없습니다. 이번 조사는 운영 사용량·요금 청구서에 접근하지 않았으므로 ‘총 운영비 0원’은 미확인입니다.
