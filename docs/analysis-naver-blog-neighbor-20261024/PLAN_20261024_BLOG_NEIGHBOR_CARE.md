# 개발 플랜 — 네이버 블로그 이웃 소통 도우미 (2026-10-24, 초안)

작성: Claude Code(윈도우) `claude-win-dotori` [역할: analysis-planning]. 근거: [REPORT.md](REPORT.md)(EXT-BLOG-07 서이추&스댓공 Ai자동화 Ver3.5). 대상: AIMaster 운영(DB ref `esgxyikcnnvmlhygjkth`). **플랜만 — 구현은 담당이 정해진 뒤.**
상태: 초안 — 주인님 결정 대기(§9).

## 0. 목표
회원이 **자기 블로그의 소통(댓글 답글·답방·이웃 새글 공감·이웃 정리)**을 AI 도움으로 빠르게 끝내게 한다. 회원 블로그가 네이버에서 제한받지 않는 범위 안에서.

## 1. 원칙
1. 네이버는 **회원 본인 크롬에서, 회원이 직접 로그인한 상태**로만 다룬다 — 비밀번호를 받거나 입력하지 않는다.
2. AI 초안은 회원 본인 키(`user_api_keys`, `resolveApiKey`, 폴백 없음)로 **서버에서** 만들고 사용 기록을 남긴다(우리 표준). 키 돌려쓰기 없음.
3. **남의 블로그에 남는 글(댓글·대댓글·이웃 신청 메시지)은 회원이 내용을 보고 「등록」을 눌러 나간다**(기본). 공감(하트)만 회원 설정으로 자동 허용 가능.
4. 입력은 `docs/PLATFORM_PATTERNS.md` §20대로 사람처럼(한 글자씩·쉼, 디버거 `Input.insertText` 70~170ms).
5. 하루 상한(회원이 낮출 수 있음): 댓글 30 · 공감 100 · 이웃 신청 0(§9 결정 전) — 네이버 자체 제한·스팸 판정을 넘지 않게 0단계에서 확인해 조정.
6. 숨은 작업·홍보 강제·방문 기록 전송 없음.

## 2. 기능 (단계별)
| 단계 | 기능 | 동작 |
|---|---|---|
| **1단계(핵심)** | 💬 **내 글 댓글 답글** | 확장이 내 블로그 최신글 N개의 댓글을 읽어 웹으로 보냄 → AI 대댓글 초안(글 내용 + 댓글 문맥, 회원 말투 설정) → 웹·확장 목록에서 수정/승인 → 확장이 사람처럼 입력·등록(비밀 대댓글 선택). 이미 답한 댓글은 건너뜀 |
| 1단계 | 🔁 **답방 도우미** | 내 글에 댓글 단 이웃 목록 → 「답방」 누르면 그 사람 최신글을 열고 본문을 읽어 AI 댓글 초안 → 회원이 읽고 「등록」(공감 함께 선택) → 다음 사람 |
| 2단계 | 📰 **이웃 새글 소통** | 서로이웃 새글 피드를 순서대로 열기 → 글마다 공감(자동 허용 가능) + AI 댓글 초안 → 회원 확인 후 등록 · 하루 상한·글마다 최소 체류(회원 설정, 기본 30초) |
| 2단계 | 🧹 **이웃 정리** | 「나만 추가한 이웃」·오래 글 없는 이웃 찾기 → 목록에서 골라 삭제(확인 창) · 받은 서로이웃 신청 수락/거절 목록 |
| 3단계(선택) | ⏰ **예약 준비** | 정해진 시각에 「새 댓글 확인 → 답글 초안 미리 만들기」까지 자동, 텔레그램(회원 본인 봇)으로 「검토할 초안 5개」 알림 → 회원이 열어 승인 |
| 3단계 | 📊 소통 기록 | 답글·답방·공감 수 하루/주 그래프(숫자만) |

원본의 「키워드로 모르는 블로그에 대량 서이추·댓글」 「완전 무인 등록」은 넣지 않는다(§9 결정 1).

## 3. 구조
```
[회원 크롬 · 확장]  네이버 블로그 화면 읽기(댓글·글 본문) · 사람처럼 입력·등록 · 하루 상한·체류
      │ 연결 토큰(Bearer)
      ▼
[AIMaster 웹 · 새 프로그램]  권한·핸드폰 확인 · AI 초안(회원 본인 키) · 검토 목록 · 설정 · 기록(숫자) · 매뉴얼 · 다운로드 센터
```
- 웹에 보관하는 것: 회원 설정, 검토 대기 초안(대상 글 주소·댓글 작성자 닉네임·초안 문구) — **30일 자동 삭제**, 소통 숫자 기록.
- 블로그 원문 전체는 저장하지 않고 초안 만들 때만 서버로 보냄(요약 길이 제한).

## 9. 주인님 결정이 필요한 것
1. **완전 자동 범위**: 추천은 「남의 블로그에 남는 글은 회원 확인 후 등록」. 원본처럼 **키워드로 모르는 블로그에 대량 서이추·AI 댓글을 무인으로** 하려면 — 회원 블로그 제한·저품질과 제3자 스팸 위험을 감수하는 결정이므로 주인님 판단(추천하지 않음).
2. 공감(하트) 자동 허용 여부(추천: 회원 설정으로 허용, 하루 상한).
3. 서로이웃 신청 기능 포함 여부(추천: 2단계 이후, 회원이 고른 블로그에만·메시지 확인 후, 하루 소량).
4. 담는 곳·이름(추천: 별도 기본 프로그램 「AI 블로그 이웃 소통 자동화」 `blog-neighbor-care`, 블로그 카테고리).
5. 구현 담당(추천: 블로그 역할 `blog`).
