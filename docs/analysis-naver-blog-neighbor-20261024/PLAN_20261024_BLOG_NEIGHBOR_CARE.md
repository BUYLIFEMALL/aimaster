## 0. 주인님 지시 (절대 지시, 2026-10-24)
1. **아무 블로그가 아니라**, 사용자 블로그의 콘텐츠 성격에 맞거나 사용자가 원하는 블로그를 **먼저 검색·조회한 뒤 서로 맞는 블로그에만** 이웃 신청·새 글 공감·댓글.
2. **이웃(친구) 추가가 먼저.**
3. 이웃 블로그에 **새 글이 올라오면 정기적으로 공감**.
4. 글을 **최대한 자세히 읽고 분석한 뒤, AI가 아닌 사람처럼** 댓글.
5. **사용자가 AI 모델을 선택** — 상위 모델일수록 더 똑똑하게.
6. 「AI가 아닌 최대한 사람 느낌」을 위한 의견도 준비(§6).
7. ✅ **하루 상한은 우리가 최대치를 정하고, 회원은 그 안에서 설정**: 최대 신청 20 · 공감 100 · 댓글 30(§5).

## 1. 전체 흐름 — 4단계 파이프라인
```
① 내 블로그 이해 ─▶ ② 맞는 블로그 찾기·고르기 ─▶ ③ 서로이웃 신청·수락 관리 ─▶ ④ 이웃 새 글 감시 → 공감 → 정독 분석 → 사람 같은 댓글
   (내 글 분석)        (검색 → 살펴보기 → 맞춤 점수)     (맞춤 신청 메시지)            (회원이 정한 간격·켜기/끄기)
```
수집·입력은 **회원 본인 크롬(직접 로그인한 상태)**의 확장이, 분석·글쓰기는 **회원 본인 AI 키**로 서버가 한다(비밀번호를 받거나 입력하지 않음).

## 2. 단계별 기능

### ① 내 블로그 이해 (블로그 프로필)
- 확장이 회원 블로그 최근 글 10~20개의 제목·본문 일부·카테고리를 읽음 → AI가 **블로그 프로필** 작성: 주제(예: 육아·살림·지역 맛집), 세부 관심사, 독자층, 글 분위기, 자주 쓰는 표현.
- 회원이 프로필을 보고 고침 + **원하는 이웃 조건** 추가: 「꼭 들어갈 주제」 「피할 주제(광고 대행·대출·성인 등)」 「지역」 「블로그 규모(작은 블로그 선호 등)」.
- **회원 말투 샘플**: 회원이 예전에 직접 단 댓글 5~10개를 읽거나 붙여 넣게 함 → 댓글 문체의 기준(§6 핵심).

### ② 맞는 블로그 찾기·고르기
- 검색어: 프로필에서 AI가 뽑은 키워드 + 회원이 넣은 키워드 → 확장이 네이버 블로그 검색 결과를 읽어 **후보 블로그 목록**(같은 블로그 중복 제거).
- 후보마다 확장이 최근 글 3~5개를 살펴봄 → AI가 **맞춤 점수(0~100)**와 이유:
  - 주제 일치(내 프로필과 겹치는 정도)
  - 활동성(최근 30일 글 수, 마지막 글 날짜 — 잠든 블로그 제외)
  - 진정성(광고·대행·복붙 글 비율, 같은 글 반복, 상업 링크 도배 → 감점)
  - 소통 성향(댓글에 답을 다는지, 서로이웃을 받는지)
- 화면: 후보 카드(블로그 이름·주제 요약·점수·이유·최근 글 제목) → 회원이 **「이웃 신청」 체크**(점수 ○점 이상 자동 체크 선택 가능).

### ③ 서로이웃 신청·수락 관리 (친구 추가가 먼저)
- 고른 블로그에만 신청. **신청 메시지는 그 블로그 글을 읽고 맞춤으로**(예: 「○○ 이유식 글 보고 왔어요, 저도 15개월 아기 키우는데 자주 놀러 올게요」 — 정형 문구 금지).
- 상태 관리: 신청함 → 수락됨(서로이웃) / 대기 / 거절·취소. **수락된 이웃만 ④ 대상**(주인님 지시 2). 7일 넘게 대기면 「신청 취소」 제안.
- 하루 상한: 플랫폼 최대 20건 안에서 회원 설정(§5, 네이버 자체 한도는 0단계에서 확인).

### ④ 이웃 새 글 감시 → 공감 → 정독 분석 → 사람 같은 댓글
- **예약**: 회원이 켜기/끄기, 간격 선택(30분·1시간·2시간·3시간…24시간), 동작 시간대(예: 9~23시). `real_estate_sales` 모니터링 설정 화면·판정 함수(`isCollectDue`·`isWithinActiveHours`)를 확장 타이머로 옮김(부동산 매물 알림과 같은 방식).
- 새 글 발견(서로이웃 새글 피드 + 이웃별 최신 글 비교) → **공감**(자동, 하루 상한) → **정독**: 글 전체를 사람 읽는 속도로 스크롤(글 길이에 비례한 체류, 최소 30초) → 본문·소제목·사진 설명(대체 텍스트)·태그를 읽어 분석.
- **분석 결과(댓글 전 내부 메모)**: 글의 핵심 이야기, 글쓴이의 감정·상황, 구체적 디테일 2~3개(가게 이름·아이 나이·여행지 등), 질문을 던졌는지, 댓글로 공감할 지점.
- **댓글 만들기**: §6 규칙으로 회원 말투에 맞춰 1개 → 등록 방식(회원 선택, §10-1): ⓐ 확인 후 등록(목록에서 보고 「등록」) ⓑ 자동 등록. 이미 댓글 단 글·내가 쓴 글·광고 표시 글은 건너뜀.
- 사람처럼 입력: 한 글자씩 70~170ms 간격, 쉼표·마침표 뒤 잠깐 멈춤(`docs/PLATFORM_PATTERNS.md` §20, 디버거 `Input.insertText`).

## 6. 「AI가 아닌 사람 느낌」을 위한 의견 (주인님 요청)
핵심은 **「잘 쓴 댓글」이 아니라 「이 사람이 진짜 읽고 쓴 댓글」**이다. 사람 댓글이 사람다운 이유는 문장 실력이 아니라 ① 구체적이고 ② 짧고 고르지 않고 ③ 내 이야기가 살짝 섞여 있기 때문이다.

### 6-1. 내용 — 진짜 읽은 티
1. **글 속 디테일 1~2개를 꼭 짚는다**(「사진 세 번째 국밥 국물 색이…」, 「돌 지나니 낮잠이 줄었다는 부분」). 글 전체 요약은 금지 — 요약은 AI의 가장 큰 티.
2. **반응은 하나만**: 공감·질문·내 경험 중 한두 가지. 칭찬 + 정리 + 질문 + 인사를 다 넣으면 기계 같다.
3. **글쓴이가 물어본 게 있으면 답한다**(「여러분은 어떻게 하세요?」 → 실제 답).
4. **회원의 실제 상황을 섞을 수 있게**: 프로필에 「아이 15개월」 「서울 마포」 같은 회원 사실을 적어 두면 거기서만 가져온다. **없는 경험은 지어내지 않는다**(거짓 경험담은 들키면 신뢰가 무너짐).
5. 정보 글엔 「저장해 둘게요」 「이건 몰랐네요」처럼 독자 반응, 일상 글엔 감정 반응 — 글 종류별 반응 방식.

### 6-2. 형식 — 고르지 않게
1. **길이를 흔든다**: 1문장 짧은 댓글 30% · 2~3문장 60% · 4문장 10%. 매번 같은 길이가 가장 기계적.
2. **AI 말투 금지 목록**(생성 뒤 검사해 걸리면 다시 생성): 「정말 유익한 글」 「잘 보고 갑니다」만 단독 · 「~에 대해 자세히 알려주셔서」 · 「인상 깊었습니다」 · 「소중한 정보」 · 「함께 응원합니다」 · 목록·번호·따옴표 요약 · 「첫째/둘째」 · 지나친 존칭 반복 · 느낌표 3개 이상.
3. **회원 말투 따라가기**: 말투 샘플에서 끝맺음(「~네요」 「~요ㅎㅎ」 「~했어욤」), 이모티콘·「ㅎㅎ/ㅠㅠ」 빈도, 띄어쓰기 습관을 뽑아 그대로. 회원이 이모티콘을 안 쓰면 AI도 안 쓴다.
4. **완벽한 맞춤법보다 회원 수준**: 회원이 평소 쓰는 정도의 구어체(「넘 맛있어 보여요」)는 허용, 일부러 오타를 넣지는 않는다(어색함).
5. **같은 문장 재사용 금지**: 최근 댓글 100개와 비슷한 문장(첫 5글자·끝맺음 반복)이면 다시 생성.

### 6-3. 행동 — 사람의 리듬
1. **바로 달지 않는다**: 새 글 발견 뒤 수십 분~몇 시간 사이 무작위로(사람은 알림 보자마자 매번 달지 않음).
2. **읽는 시간**: 글 길이·사진 수에 비례해 스크롤·체류, 사진 근처에서 잠깐 멈춤.
3. **모든 글에 달지 않는다**: 공감만 하는 글, 댓글까지 다는 글을 섞는다(기본: 공감은 거의 매번, 댓글은 관심 높은 글 위주 50~70%).
4. **활동 시간대**: 회원이 평소 블로그 하는 시간대에만(새벽 3시 댓글은 이상함).
5. **답글이 달리면 이어 가기**: 이웃이 내 댓글에 답하면 짧게 한 번 더(대화가 이어지는 것이 가장 사람다움) — 2단계 기능.

### 6-4. 품질 루프
1. 처음 2주는 **「확인 후 등록」**으로 시작해 회원이 고친 내용을 말투 샘플에 더한다(고칠수록 회원 말투에 가까워짐).
2. 생성 → **자가 점검**(같은 모델 또는 싼 모델로 「AI 같은지 0~10점」, 7점 이상이면 다시 생성) — 상위 모델일수록 점검이 정확.
3. 회원이 지운 댓글·이웃이 반응한 댓글을 기록해 어떤 댓글이 통했는지 보여 줌.

### 6-5. 솔직한 한계
