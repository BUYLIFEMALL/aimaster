## 2. RSS에서 확인되는 범위와 확인되지 않는 범위

네이버 [검색결과 수집에 대한 정책 §4(4)](https://policy.naver.com/rules/search_policy.html)은 작성자가 RSS 공개를 허용한 콘텐츠에 대해 RSS 경로의 수집·검색을 허용한다고 설명한다. 이는 robots.txt 예외로 명시되어 있다. **이 내용은 기존 조사와 연결되는 보완이며 새로 허가를 받은 것이 아니다.**

RSS를 실제 사용할 때의 적용 범위는 피드에 제공된 콘텐츠다. 네이버 [서치어드바이저 RSS 설명](https://searchadvisor.naver.com/guide/request-feed)은 구독자가 RSS 리더기로 콘텐츠를 소비하는 구조를 설명하고, 예시의 `description`에 전체 또는 일부 내용이 올 수 있음을 보여준다. 또한 검색 제출 가이드로서는 피드 항목에 전체 본문을 담으라고 권장한다. **사이트 운영자에게 전체 본문을 담으라는 제출 권장은 모든 네이버 블로그 RSS가 전문을 반환한다는 보장이 아니다.**

따라서 프로그램이 RSS를 채택하더라도 다음 구분이 필요하다.

- 피드에 들어온 제목·링크·일시·텍스트만 파싱한다. 피드가 일부 본문만 제공하면 그 상태를 일부 자료로 표시한다.
- 빠진 문장을 원문 HTML·로그인 페이지에서 자동 보충하는 기능은 RSS 예외에 포함된 것으로 취급하지 않는다.
- 피드에 없다는 이유로 해당 블로그에 새 글이 없거나 활동이 없다고 판정하지 않는다.
- RSS는 이웃·서로이웃·신청 수락·댓글 허용 상태의 증거가 아니다.
- RSS 수집·열람 조건과 AI 공급자 전송·분석·문장 생성의 이용 범위는 별도로 확인한다. RSS 공개만으로 외부 AI 전송이나 재배포 권한을 확보했다고 표시하지 않는다.

마지막 항목은 정책의 명시적 AI 허용·금지 판정이 아니라 **이번에 확인한 RSS 조항이 그 처리까지 정하지 않는다는 범위 판정**이다. 네이버 [이용약관의 타인 권리 항목](https://policy.naver.com/rules/service.html)은 타인 콘텐츠 이용에 필요한 권리 범위를 구분한다. 프로그램은 기존 회원 본인 자료·사용 권한 확인 자료 및 별도의 AI 전송 동의 경로를 유지한다.

블로그 [게시글 설정 정보 안내](https://help.naver.com/service/5593/contents/15408?lang=ko&osType=PC)는 공식 검색 색인 본문에서 외부 보내기 설정과 RSS 노출의 연계를 안내한다. 다만 이번 직접 페이지 추출은 도움말 본문 없이 메뉴만 반환했으므로, 그 설정의 현재 화면 위치나 모든 조건을 직접 UI 검수한 것으로 기록하지 않는다. RSS 수집 예외의 핵심 근거는 위 정책 원문이다.

## 3. 검색 API와 관계 정보의 경계

[NAVER API HUB 블로그 검색 규격](https://api.ncloud-docs.com/docs/naver-api-hub-search-blog)은 `GET /search/v1/blog`와 응답 필드를 설명한다. `description`은 본문 전문이 아니라 요약 패시지다. 검색 결과는 후보 발견·링크 안내 자료로 쓰고, 요약을 전문 분석 자료로 바꾸지 않는다. 관계 상태를 반환하는 필드도 이 응답 규격에서 확인되지 않았다.

[현재 공개 API 목록](https://developers.naver.com/products/intro/plan/plan.md)의 검색·로그인·회원 프로필·공유하기 등을 확인했으나, 블로그 이웃 목록·서로이웃 수락·로그인 새 글 피드를 읽는 공개 API는 이 조사 범위에서 확인하지 못했다. [공유하기 개발 가이드](https://developers.naver.com/docs/share/share/)의 이웃 새 글 언급은 사용자가 링크를 블로그에 공유하는 흐름의 설명이며, 이웃 새 글 조회 API가 아니다. 과거 블로그 글쓰기 API 소개 자료가 검색되더라도 현재 관계 조회 수단으로 삼지 않는다.

[이웃·서로이웃 도움말](https://help.naver.com/service/5593/contents/15380?lang=ko&osType=COMMONOS)은 서로이웃이 상대방 신청 동의를 통해 성립한다고 설명한다. 양쪽이 일반 이웃으로 등록됐거나 공개 글이 검색된 사실만으로 수락 상태를 만들어서는 안 된다. 기존 수신 목록의 관계 표시는 회원이 확인한 당시 목록으로 보관하고 최신 네이버 관계의 독립 검증과 구분한다.

## 4. 자동 접근 일반 조건

네이버 [서비스 접근·이용 안내](https://policy.naver.com/policy/disclaimer.html)는 자동 접속·수집의 예외로 명시 허용/사전 승낙, 적법한 클라이언트 ID와 해당 약관을 따르는 공식 API, 가이드·robots.txt의 허용 탐색 범위를 설명한다. 따라서 모든 자동화가 불가하다는 결론으로 확대하지 않는다. 동시에 검색·RSS의 예외를 로그인 관계 감시나 외부 쓰기에 전용하지 않는다.

현재 [이용약관](https://policy.naver.com/rules/service.html)은 2026-10-01 시행으로 표시되며 사전 허락 없는 자동 수단을 통한 게시·소통·회원 ID/게시물 수집 및 남용 방지 조치 무력화를 주의사항에 포함한다. 앱 자체 상한·회원 PC에서의 실행·회원 로그인·느린 입력·관리자 개발 승인은 특정 네이버 자동 경로의 허용 근거를 대신하는 자료가 아니다. 이는 확인한 공개 문서와 구현 경계를 대조한 설명이며 법률 자문이나 네이버의 개별 심사 결과가 아니다.
