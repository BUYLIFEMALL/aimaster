1. 묶음마다 플랜 → 기준 앱에 기능 옮기기 → 옛 앱은 기준 앱으로 이동 안내(주소 유지) → 권한 회원 합치기(옛 앱 권한자에게 기준 앱 권한 부여) → 카탈로그에서 옛 앱 숨김 → 백업 폴더·git 태그 뒤 정리.
2. FREE 배지: C는 기준(AI Prompt)이 FREE라 그대로, B는 옛 앱(페르소나)이 FREE이고 기준(글쓰기 에디터)은 아님 → **합친 뒤 배지를 어떻게 할지 주인님 결정 필요**.
3. 순서: A → B → C → D(하나씩 끝내고 다음). 각 묶음 비용은 AI 시험 호출 수 회 수준, 운영 인프라 추가 없음(C만 새 DB 표).
