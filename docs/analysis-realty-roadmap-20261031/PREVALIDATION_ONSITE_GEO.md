# 사전 검증 결과 — 위치 기반 임장 사진 관리 (2026-11-01)

작성: Claude Code(윈도우) `claude-win-realty-docs` [역할: realty]. 플랜: [`PLAN_ONSITE_GEO.md`](PLAN_ONSITE_GEO.md).
방법: 저장소 밖 임시 폴더의 사전 검증 페이지를 주인님 터널로 휴대폰에서 열어 시험. 운영 코드·DB 변경 없음, 비용 없음. 끝난 뒤 서버와 측정값을 지웠고, 주인님 위치 보호를 위해 정확한 좌표·주소는 이 문서에 적지 않는다.
시험 기기: 안드로이드 삼성 폴더블 1대. 환경은 카카오톡 안 브라우저와 크롬 앱 2가지. 한 지역에서 짧게 시험한 소량 표본이다.

## 결론
**안드로이드는 「촬영 순간 웹 위치 + 지도 확정」 방식으로 구현할 수 있다. 사진 속 위치 정보에는 기대지 않는다.**

## 결과
| 확인할 것 | 기준 | 결과 | 판정 |
|---|---|---|---|
| 위치 받기(카카오톡 안) | 5회 중 5회 | 5회 성공 | 통과 |
| 정확도(카카오톡 안) | 중앙값 50m 이내 | 중앙값 16m. 첫 회 100m, 이후 11~26m | 통과 |
| 촬영 때 웹 위치(크롬) | - | 1회 성공, ±15m, 약 13초 걸림 | 동작 |
| 크롬 5회 반복 측정 | 5회 중 5회 | 안 함 | 미확인 |
| 카메라 사진 속 위치 | 있음/없음 | 카카오톡 안 있음(웹 위치와 2m 차이) / 크롬 **없음** | 브라우저마다 다름 |
| 앨범 사진 속 위치 | 있음/없음 | 카카오톡 안 있음 / 크롬 **없음** | 브라우저마다 다름 |
| 좌표 → 주소(OpenStreetMap) | 동까지 일치 비율 | 주인님 확인 1곳 일치. 다른 앨범 사진 주소 1건은 일치 여부 미확인 | 표본 부족 |
| 지도 핀 끌기 | 손가락으로 무리 없이 | 동작하지만 주인님 판단 「불편」 | **미통과** |
| 묶기 반경 50m | 실측으로 판단 | 한 장소 자료만 있음 | 판단 보류 |
| 아이폰 | 5회 중 5회 | 기기 없음 | 안드로이드 구현 뒤 진행(주인님 결정) |

크롬 사진은 파일 정보(EXIF) 자체는 있었지만 그 안에 위치 값이 없었다. 원인은 추정(안드로이드·브라우저의 위치 정보 제거)이며 이번에 확인하지 않았다. 위 결과는 시험한 환경에 한한다.

## 구현 방향
1. **좌표 원본은 촬영 순간 웹 위치**다. 사진 속 위치는 있으면 참고만 한다.
2. **첫 측정값을 바로 쓰지 않는다.** 정확도가 좋아질 때까지 잠시 기다리고 진행 상태와 정확도를 보여 준다(첫 회 100m, 크롬 약 13초).
3. **핀을 끌지 않고 지도를 움직여 가운데에 맞춘다.** 핀 끌기가 미통과여서 바꾸며, 구현 때 주인님 확인을 다시 받는다.
4. **앨범 사진은 위치가 없을 수 있다.** 없으면 지도에서 직접 찍게 안내한다.
5. 카카오톡 안에서 열면 안내 없이도 쓸 수 있지만, 기준 브라우저는 크롬으로 두고 검수한다.
