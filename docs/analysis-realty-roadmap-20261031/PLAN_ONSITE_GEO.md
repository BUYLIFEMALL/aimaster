## 1. 무엇을 만드나
현장에서 사진을 찍으면 좌표가 저장되고 주소가 자동으로 붙으며, 나중에 지도와 행정구역으로 분류·관리하는 기능.

## 2. 위치 원칙
- 원본은 좌표다. 주소는 좌표에서 만든 값이며 다시 계산할 수 있다.
- 좌표 출처를 함께 저장한다: 촬영 때 위치(정확도 m) / 사진 속 위치 정보 / 회원이 지도에서 확정.
- 회원이 핀을 확인·이동해야 「확정」이 된다. 자동 값은 「추정」으로 표시한다.
- 건물 외관만 보고 AI가 주소를 맞히는 방식은 쓰지 않는다.

## 3. 사전 검증 (비용 없음, 운영 코드 수정 없음)
저장소 밖 임시 폴더의 페이지를 내 PC에서 띄우고 임시 HTTPS 터널로 휴대폰에서 연다. 사진은 휴대폰 밖으로 보내지 않고, 주인님이 「결과 보내기」를 누른 측정값만 내 PC로 온다. 끝나면 터널·페이지·측정값을 지우고 결과만 이 폴더의 문서로 남긴다.

| 확인할 것 | 통과 기준 |
|---|---|
| 웹에서 위치 권한·좌표 받기(아이폰·안드로이드) | 야외에서 5회 중 5회, 정확도 중앙값 50m 이내 |
| 웹 카메라로 찍은 사진의 위치 정보 | 있음/없음 기록(없어도 통과, 방식 결정용) |
| 앨범에서 고른 사진의 위치 정보 | 있음/없음 기록. 없으면 「찍어 둔 사진 올리기」는 수동 핀으로 |
| 좌표 → 주소 | 표본에서 동까지 맞는 비율 기록(시험은 OpenStreetMap, 운영 후보 브이월드·카카오는 키 준비 뒤 별도 비교) |
| 지도 핀 옮기기 | 휴대폰에서 손가락으로 무리 없이 이동 |
| 같은 물건 묶기 반경 | 실측 오차로 50m가 적당한지 판단 |

아직 시험하지 않는 것: AI 글자 판독(유료 호출이라 위치 방식 결정 뒤 소량), 저장 용량.

## 8. 구현 플랜 (2026-11-01, 구현 승인 대기)
주인님 「먼저 임장 자동화를 해야지」. 안드로이드 먼저, 아이폰은 구현 뒤.

바뀐 점: 브이월드 Geocoder 1.0 문서가 응답을 DB에 저장하지 못하게 안내한다. 그래서 주소를 자동 저장하지 않는다.

1차 범위(빌드 1회)
1. 메뉴 「📍 임장 노트」, 물건 목록(행정동·방문일·상태 거르기).

2차(빌드 1회): 가까운 사진 묶기·나누기, 내 주변 거리 거르기, 방문 순서, 주소 리포트 연결.

확인 필요: 배경지도 이용 조건, 저장 용량 금액, 시험은 안드로이드 크롬. 검수: 시험, tsc, 빌드, 시험 계정 데스크톱·375px, 주인님 휴대폰 현장 시험.

## 9. 주소 자동 등록 조사 (2026-11-01)
주인님 기준: 사진을 찍으면 사람 손 없이 주소가 등록되어야 한다. 위 8번의 「주소 자동 저장 안 함」은 이 조사 결과로 대체한다.
- 기술은 모두 가능, 저장 정책이 문제다. 브이월드 Geocoder 2.0 문서: DB 저장 불가. 카카오: 개발자 포럼 답변상 응답 저장 불가(약관 원문 미확인).
- 네이버 클라우드: 건당 0.5원 유료, 저장 금지 조항은 찾지 못했으나 약관 원문 미확인. 회원 본인 키 원칙과 비용 부담 검토 필요.
- 추천: 행안부 「도로명주소 위치정보 요약DB」(무료, 공공누리 제1유형, 도로명주소 + 주출입구 좌표). 직접 내려받아 가장 가까운 출입구로 주소를 찾으면 외부 응답 저장 문제가 없다. 신청서·본인확인·이용목적 심사가 필요하고 전자지도류에 목적외 사용 제한 조건이 있어 신청 시 조건 확인. 칸·크기·지번 포함 여부는 파일로 확인. 큰 건물과 출입구가 먼 필지의 정확도는 표본 측정 필요.
- 결정(2026-11-01 주인님): 주소 자동 등록은 행안부 위치정보 요약DB로 진행. 다음: 주인님 이용 신청 → 이용 조건 확인 → 칸·용량·표본 정확도 확인 → 주소 자동 등록을 포함한 구현 플랜 승인.
- 2026-11-01 주인님이 위치정보요약DB(2026.09 전체분, 전국, TXT) 신청, 상태 「처리 중」. 일변동자료는 신청 안 함. 승인되면 칸·용량·표본 정확도 확인.

- 시·군·구 3곳 일치. 행정동은 1곳만 주소 검색으로 일치 확인, 나머지 2곳은 공식 대조 안 함.
- 위치: 지하철 출구 앞 1곳은 주인님 표시 지점과 눈 비교로 몇 미터 안쪽. 상가 앞 1곳은 같은 건물 블록. 실내 1곳은 도로 일치, 건물은 배경지도 이름이 없어 미확인. 미터 단위 측정은 아니다.
- 미확인: 저장까지 기다린 시간, 행정동 경계를 가르는 사례(3곳 모두 같은 동), 아이폰.
- 주소 자동 등록 때 이 3곳을 정답 표본으로 쓴다(주인님이 채팅으로 준 주소, 저장소에 적지 않음).
