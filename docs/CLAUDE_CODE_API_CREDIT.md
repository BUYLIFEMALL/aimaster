# Claude Code API 크레딧 활용 지침 (2026-10-28 주인님 지시, 모든 CLI 공통)

주인님 지시(2026-10-28): 「`buylifemall@gmail.com`이 Claude Max 200 플랜이고, Claude Code용 API 월간 크레딧 $200를 연동했다. API 키로 작업해야 하는 경우가 생기면 이 크레딧을 적극 활용하도록 메인 지침에 추가 등록하고, 다른 CLI들도 적극 활용할 수 있게 인수인계 파일을 남겨라.」

## 1. 무엇인가

- **계정:** `buylifemall@gmail.com` — Claude Max 200 플랜 + **Claude Code용 Anthropic API 월 크레딧 $200** 연동(관리자 계정).
- **용도:** 에이전트(Claude Code·Codex·agy)가 **개발·시험·분석·자동화 구현 과정에서 Anthropic(Claude) API 호출이 필요할 때** 쓰는 운영자용 크레딧이다. 예: 사전 검증 페이지에서 모델 품질·호환 확인, 외부 원본 분석 보조, 프롬프트·기능 시험, 대량 문서 처리 보조 등.

## 2. 적극 활용 (주인님 지시)

- API 키가 필요한 작업이 생기면 **망설이지 말고 이 크레딧을 적극 활용**한다. 무료 방법만 고집하다 작업이 막히지 않게 한다.
- 다만 [테스트 비용 최소화 지침](TEST_COST_POLICY.md)의 순서는 유지한다: **무료 방법·가장 저렴한 모델을 먼저 보되, 품질·기능 검증에 상위 모델이나 유료 호출이 필요하면 이 크레딧으로 진행**한다(상위 모델 사용 이유·횟수는 인수인계에 기록).
- 월 $200 한도이므로 **대량·반복 호출은 사전 보고**한다(비용 사전 보고 의무). 종료 보고의 비용 리포트에 「Claude Code API 크레딧 사용(대략 $·호출 수)」을 적는다.

## 2-1. 기본 AI = Claude (2026-10-28 주인님 지시)

- 주인님: 「api키 여유가 있으니 클로드 api키를 사용해」「앞으로 기본 api키 사용은 클로드야」.
- 새 AI 기능·호출 코드의 기본 제공자는 Claude. 개발·시험 호출은 이 크레딧(또는 관리자 본인 `anthropic` 키), **회원 기능은 회원 본인 `anthropic` 키만**(§3 그대로).
- 모델·방식은 `claude-api` 스킬 기본(`claude-opus-5-5`; 단순 분류는 effort `low` + `json_schema`, 회원 키 호출은 재시도 0). 기존 Gemini·OpenAI 코드는 지시 없이 일괄 교체하지 않는다.
- 첫 적용: `smartstore-register` 상품속성 AI 추천(`src/lib/ai/claude.ts`, 2026-10-28 실제 호출 1회 3.8초).

## 3. 제약 — 최상위 규칙은 그대로 (불변)

- **회원 기능의 AI 호출은 여전히 회원 본인 키**로만 한다([최상위 규칙](TOP_RULE_PERSONAL_ACCOUNT_API.md)). 이 크레딧은 **운영자(주인님)의 개발·시험·분석용**이며, **회원 요청 처리·회원 콘텐츠 생성에 쓰지 않는다.**
- 즉 「엔진 개발·검증은 운영자 크레딧, 회원이 돌리는 연료는 회원 본인 키」 구분을 지킨다. 회원 기능에 운영자 크레딧을 폴백으로 넣지 않는다.

## 4. 다른 CLI 활용 방법

- 이 방침은 **Claude Code·Codex·Antigravity(agy) 공통**이다. 각 CLI가 개발·분석 중 Claude(Anthropic) API가 필요하면 이 크레딧을 쓴다.
- **키 설정:** 키 값은 주인님이 연동했으며 비밀이다(코드·문서·채팅에 적지 않는다). 각 CLI·장비에서 Anthropic API를 직접 호출해야 하면, 그 환경의 API 키 설정(예: `ANTHROPIC_API_KEY` 환경변수)이 이 계정 크레딧에 연결돼 있는지 먼저 확인하고, 없으면 주인님께 설정을 요청한다.
- Claude Code CLI 자체의 토큰 사용은 이 크레딧/플랜에서 나간다. **Vercel 배포 빌드 비용은 별개**(Vercel 과금)이므로 비용 리포트에서 구분해 적는다.
