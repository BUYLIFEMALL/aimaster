# 디자인 템플릿·연동 및 사용 매뉴얼 요약

[분야별 색인](README.md) · 프로그램 화면 템플릿과 매뉴얼 템플릿은 적용 대상이 다릅니다.

## 프로그램 화면 템플릿

- [공식 템플릿 카탈로그](../DESIGN_TEMPLATE_CATALOG.md)에서 프로그램 목적과 작업 흐름에 맞는 기존 기준을 먼저 찾습니다.
- 카탈로그의 큰 분류는 포커스 스튜디오/에디터, 미디어/사운드/콘솔, 크리에이티브/아트/캔버스, 스마트 매트릭스/데이터분석, 플로우 위저드/단계별 파이프라인, 소셜 바이럴/SNS 운영입니다. 구체적인 공식 스타일명·적용 프로그램·토큰은 카탈로그에서 확인합니다.
- `DESIGN_HANDOFF.md`로 레이아웃·색상·부품이 검증된 기준을 재사용합니다. 색상이나 일부 골격 조정으로 해결되면 기존 템플릿의 변형으로 기록합니다.
- 골격과 색상 토큰 모두 기존 스타일과 크게 다른 경우에 새 스타일명을 붙이고 카탈로그·프로그램 지침·디자인 인수인계에 등록합니다.

## 연동·사용 매뉴얼 템플릿

신규 개발·업그레이드·리뉴얼에서 [연동 및 사용 매뉴얼 원문](../MANUAL_AND_INTEGRATION_GUIDELINES.md)의 **8대 매뉴얼 템플릿 스타일**과 **Step 1~4 시각화 카드 규격**을 레퍼런스로 사용합니다. 다음 구성의 누락 여부를 확인합니다.

| 구성 | 확인할 내용 |
|---|---|
| 헤더 메타데이터 | 아이콘·소요시간·직링크 |
| 개요 히어로 카드 | 목적·준비물·전체 흐름 |
| 4단계 시각 카드 | 단계·행동·결과를 빠르게 파악하는 카드 뷰어 |
| 상세 단계 | 따라 할 절차·필요 코드·1초 복사 |
| 팁 배너 | 사용 편의와 좋은 활용 방법 |
| 함정 방지 배너 | 실패하기 쉬운 조건과 해결 방법 |
| 콘솔 직링크 버튼 | 실제 등록·설정 화면으로 이동 |

단순 텍스트 나열로 끝내지 않습니다. 프로그램과 같은 테마를 유지하고 실제 콘솔 링크·복사·단계 이동을 확인합니다.

## 연동 화면과 검수

- 운영 프로그램 설정 메뉴는 `API키등록·플랫폼연동`을 기준으로 하며, 하단 `📖 연동 매뉴얼`에서 기존 `platform_guides` 문서를 찾아 재사용합니다. 필요한 매뉴얼이 없으면 해당 플랫폼/값의 설정 절차를 작성합니다.
- 기존 매뉴얼 팝업·콘솔 직링크 등 사용자 흐름을 보존합니다. 회원 본인이 준비할 앱·키·계정·ID를 정확히 안내합니다.
- 원문에는 Microsoft Edge 포그라운드 검수 요구가 있습니다. CLI 기본 브라우저·주인님의 세션 지정·기존 사용 중인 창의 관계는 [CLI 협업](COLLABORATION.md)을 함께 대조하고 실제 사용 브라우저를 기록합니다. 다른 CLI가 사용하는 창을 임의로 조작하지 않습니다.
- 검수 결과·미확인·적용한 공식 스타일명과 변형을 해당 프로그램의 디자인/개선 인수인계에 남깁니다.
