## 2. 집계 기준

- **전체 시간**: 실행 파일 시작부터 종료까지(`results*.csv`의 `seconds`). 모델 읽기·PNG 저장 포함. 시험 도구가 실행 전에 하는 해시 재대조 시간은 포함하지 않는다. 4절의 p50·p95는 이 값이다.
- **생성 시간**: 실행 기록의 `generate_image completed` 값(글 이해 + 샘플링 + VAE 복원). 3절 Arc의 단계별 값이 이것이다. 전체 시간과 같은 값으로 보지 않는다.
- **p50·p95**: 같은 장비·모델·양자화의 성공 건으로 계산(선형 보간)하고 표본 수를 함께 적는다. 표본이 20건보다 적으면 p95를 적지 않는다.
- **성공**: 종료 코드 0이고 PNG가 저장됐다. 그 밖은 실패로 세고 기록 마지막 줄을 원인으로 적는다.
- **메모리**: 프로세스 최대 작업 집합, 그래픽 메모리는 NVIDIA `nvidia-smi` 사용량 최댓값 / Arc는 윈도우 성능 카운터 공유 메모리 최댓값. 둘 다 카드 전체 사용량이라 다른 프로그램 사용분이 들어 있다.
- **첫 실행·이후 실행**: 실행 파일을 장마다 새로 띄우므로 모든 건이 모델을 다시 읽는다. 운영체제 파일 캐시가 찬 뒤의 값이 「이후 실행」에 해당한다.

## 6. 지금까지 확인된 사실과 미검증

- RTX 5080에서 두 모델 Q8 구성이 세 크기(1:1·7:4·4:7) 96건을 실패 없이 그렸다. 1장 전체 시간은 FLUX 약 8초, Z-Image 약 14초다.
- Q8 구성의 그래픽 메모리 최댓값은 FLUX 약 9.8GB, Z-Image 약 10.3GB다(카드 전체 사용량 기준). 이 값보다 그래픽 메모리가 작은 카드에서 Q8이 되는지는 재지 않았다.
- 내장 그래픽(Arc, Vulkan)에서도 두 모델 Q4 구성이 1024×1024 1장을 끝까지 그린다. 다만 FLUX 약 3분 20초, Z-Image 약 8분 20초로 느리다. 같은 장비에서 Z-Image는 FLUX의 약 2.5배 시간이 든다.
- 고정 실행 파일 도움말에 참조 이미지 옵션(`-r, --ref-image`)이 있다. 실제 FLUX.2 klein 참조 편집 동작은 미검증(P2).
- ERNIE-Image-Turbo는 고정 릴리스 도움말에서 지원 표시를 찾지 못했다. 대조군 실행은 미검증.
- 미검증: 96장 전체 품질과 사용 가능률(관찰은 13번·18번 두 쌍뿐), 정확한 16:9·9:16 크기 생성, Q4와 Q8의 품질·속도 차이(같은 장비), 4·6·8·12GB 구간별 지원 여부(실측 장비는 16GB급 한 대와 내장 그래픽 한 대), Arc의 비율 시험·묶음 실행, 오프라인 생성, 취소·재시작 뒤 중복 파일, 24장 묶음을 대기열로 돌릴 때의 동작(이번 시험은 장마다 실행 파일을 따로 띄움).
