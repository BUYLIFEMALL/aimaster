## 0. 어떻게 「우리 방식」으로 바꾸나 (공통 원칙)

원본들은 모두 **여러 계정 돌려 쓰기 + IP 변경 + 화면 자동 긁기/발송**이라 플랫폼 제한 회피에 가깝다. 우리는 아래로 바꾼다.
- **수집·발송 상한**(✅ 2026-10-27 주인님 확정): 기본은 **안정적인 리미트**(하루·시간당 상한, 사람 같은 속도)로 플랫폼 제재를 피한다. **회원이 필요하면 VPN·IP 변경 서비스를 본인 책임으로 연동**해 상한을 넓힐 수 있다(선택, 기본 꺼짐). 계정은 회원 본인 것만.
- **수집**: 공식 API가 있으면 공식 API(회원 본인 키), 없으면 **회원 본인 PC 크롬 확장**이 회원이 직접 로그인한 상태에서 공개 화면만 읽는다(우리 서버가 대신 긁지 않음, 봇 탐지 원칙 §20).
- **개인정보 최소화**: 이메일·전화는 기본으로 **모으지 않고**, 공개 아이디·업체명·주소·공개 통계만. 연락처가 꼭 필요하면 화면에 「사전 동의 필요」를 크게 고지하고 회원 책임으로.
- **발송**(✅ 2026-10-27 주인님 확정): 우리 서버가 대신 대량 발송하지 않는다. **수집 후 발송 여부는 회원 각자 책임**이며, **회원 본인 PC·핸드폰에서 회원이 직접 발송**하는 형태로 설계해 위험을 분산한다(예: 확장/앱이 회원 로그인 상태에서 회원이 누를 때 하나씩, 또는 회원 본인 발송 계정). 광고성 정보 사전 동의 고지는 화면에 넣고 발송 책임은 회원에게.
- **격리·보관**: 수집 결과는 회원 본인 소유(RLS), 보관 §0 기준.

## 2. 묶음 정리 (제안)

1. **지역 업체 조사**(A1·B2·B1): `competitor-analysis`에 탭 추가. 공개 업체 정보 중심 → 위험 낮음. 발송은 리스트까지.
2. **카페 마케팅**(B3·A5·B4): 새 프로그램 후보. ✅ **범위 확정(2026-10-27 주인님): 회원이 「운영·가입한 카페」와 「동의 범위」 안에서만 회원 아이디 수집·초대**. 내가 운영·가입하지 않은 남의 카페 전수 수집은 하지 않는다.
3. **협업 크리에이터 찾기**(B5·A2·A4): 공개 통계만으로 섭외 대상 찾기. 이메일·전화는 빼는 방향 권장. `insta_auto_poster`·유튜브 계열과 연계.
4. **이메일 마케팅**(A3): 법상 수집이 가장 위험. 발송은 회원 본인 PC에서 직접(위 확정)으로 분산하되, **이메일 자동 수집 자체(제50조의2)**는 남아 있어 「수집」 범위를 주인님이 정해야 함(보류).

## 3. ⚠ 주인님께 — 방향 확인이 필요한 것
1. **이메일·전화 수집(A2·A3·A4·B5)**: 정보통신망법상 자동 수집이 막혀 있습니다. 「공개 통계·공개 아이디만 모으고 연락처는 빼기」로 가도 될까요? (A3는 이메일이 핵심이라 거의 남는 기능이 없어집니다 — 성격 변경 또는 보류 권장)
2. ~~남의 카페 회원 대량 수집(B3·A5)~~ → ✅ **주인님 확정(2026-10-27): 「내가 운영·가입한 카페, 동의 범위」로 제한.** 여러 카페 전수 수집은 하지 않는다.
3. ~~발송(B1·B4)~~ → ✅ **확정(2026-10-27): 발송은 회원 본인 PC·핸드폰에서 회원이 직접**(우리 서버 대량 발송 ❌), 위험은 회원에게 분산, 사전 동의 고지.
4. ~~여러 계정·IP 변경~~ → ✅ **확정(2026-10-27): 기본은 안정적 리미트, 필요하면 회원이 VPN·IP 변경 서비스를 본인 책임으로 연동(선택).** 계정은 회원 본인 것만, 약관·제재 위험 고지.

방향을 정해 주시면 묶음별로 플랜을 쓰고 담당(마케팅/블로그/인스타/유튜브)을 배정하겠습니다.
