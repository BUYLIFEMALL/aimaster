### 0-1. 핵심 기능 (앱 안 사용 설명서 17개 장 + 서버 코드로 확인)

1. **두 가지 모드**: 단일 곡 / 플레이리스트(폴더째 불러와 같은 이름의 `mp3`·`srt`·`jpg`를 한 곡으로 자동 짝짓기, 자연 정렬, 곡마다 다른 프리셋을 무작위로).
2. **자막 읽기가 너그러움**: 번호 빠짐·화살표 공백 없음·`00:01.000` 형식·줄바꿈 섞임도 읽음, 간주 자동 감지, 읽지 못한 곡은 ⚠로 곡 이름까지 표시(렌더는 계속). `.srt`와 Remotion `Caption[] .json`을 받음.
3. **프리셋**: 가로형 28종 + 세로형(9:16 쇼츠) 8종 + 낱개 디자인 15종. 고르면 화면비도 따라 바뀜.
4. **가사 연출**: 현재 줄 강조 10종(색·형광펜·채운 박스·테두리 박스·밑줄 그어지기·세로 바·점·「」 등), 줄 뒤 배경 판, 정렬, 앞뒤로 보여 줄 줄 수.
5. **노래방 디자인 2종**: 왼쪽→오른쪽 채움, **한글 발음을 로마자로 위/아래 표기**(`romanize.ts` — 한글 음절을 초성·중성·종성으로 나눠 규칙으로 변환, AI 아님), 간주 때 시작 화면.
6. **화면 요소**: 앨범 커버 패널(테두리 9종·그림자 5종), 뒤에서 도는 LP판, 소리 반응 스펙트럼 9종·색 8종, 진행 바, 앰비언트 배경 12종, 화면 외곽 6종, 요소별 위치·크기 조절, 프레임레이트 24·30·60.
7. **글자**: 한글 서체 15~16종(Google Fonts), 굵기 7단계, 항목별(현재 가사·지난/다음 가사·제목·아티스트·재생 시간·트랙 번호) 색·외곽선·그림자·글로우 따로.
8. **플레이리스트 전용**: 오프닝 앨범 카드(스타일 5종·배경 그라데이션·자켓 배치), 구석 앨범 표시, 곡 사이 여백·전환 페이드, 트랙 번호 「01 / 12」, **유튜브 챕터 타임라인 복사**.
9. **로고·프레임**: 로고 크기·투명도·위치·검은/흰 배경 지우기, 채널 아트 프레임을 뒤에 깔거나 앞에 덮기.
10. **Pexels**: 곡 제목의 한국어 심상을 영어 검색어로 바꾸는 사전(「소나기→summer rain shower」 등 약 90개), 디자인별 분위기 단어, 결과가 없으면 분위기만으로 재검색, 전곡 일괄 적용 때 같은 그림 겹침 방지, 영상은 짧게 반복 + 이음새 디졸브.
11. **두 가지 렌더**: ① Remotion 서버 렌더(헤드리스 크롬으로 프레임 캡처 → x264, GPU 실패 시 소프트웨어 재시도, 긴 재생목록 구간 병렬 옵션) ② **「고속 렌더(외장 GPU)」** — 화면 안 WebCodecs 하드웨어 인코딩, 결과를 위치 지정 쓰기로 디스크에 바로 저장(긴 영상도 메모리 부족 없음).
12. **환경 진단·오류 기록**: 저장 폴더 실제 쓰기 시험, OneDrive 같은 동기화 폴더 경고, 디스크·메모리, 긴 경로, 7일치 로그 복사·저장·인쇄.

**C안에서 가져올 것(장점은 더하고)**

| 가져올 장점 | 어디서 | 방법 |
|---|---|---|
| 브라우저 MP4 인코딩(H.264+AAC, 디스크 직접 저장) | 공용 `browser-mp4-encoder`(기준 `shorts-onestop-studio`) | `check-shared-modules.mjs --sync` 사본, 그리기 함수만 새로 |
| 소리 반응 스펙트럼·파티클 | `playlist-channel-studio/src/lib/render/` | 그리는 방식 참고(가로 고정값만 비율로 바꿔 새로 작성) |
| LP 회전·디스크 질감 | `vinyl-lp-studio` | 같은 방식 참고 |
| 곡·가사·Suno ID | `music-automation`의 `music_tracks`(본인 행만) | 「내 Suno 곡 가져오기」 목록 → 오디오 주소·가사·시간 가사 |
| 본인 키·권한·공용 연동 | 루트 공통(`user_api_keys`, `requireProgramAccess`) | 표준 그대로, Pexels 키는 공용 연동 항목으로 추가(한 번 등록 → 재사용) |

**버릴 단점(이렇게 해결)**

| Lyricbi 단점 | 해결 |
|---|---|
| `.srt`를 직접 만들어야 함 | ① Suno 곡: sunoapi `get-timestamped-lyrics`(단어별 `startS`·`endS`)로 자동 ② 내 노래: 가사 붙여넣기 + **탭 싱크 편집기**(재생하며 스페이스바로 줄 시작 찍기, 무료·AI 없음) ③ 선택: 회원 본인 OpenAI 음성 인식(단어 시간)으로 초안 |
| 저장 없음 | 프로젝트 설정·가사 시간표는 서버 표(회원별 RLS), 결과 MP4는 회원 PC에 바로 저장(서버에 큰 영상 안 올림), 업로드 음악은 30일 자동 삭제 |
| Windows 설치형 | 웹 + 크롬·엣지 WebCodecs(설치 없음). 미지원 브라우저는 안내만 |
| Remotion(라이선스·서버 렌더) | 쓰지 않음 — Canvas로 그리고 공용 인코더로 만듦(서버 렌더 비용 0) |
| AI 없음 | 선택 기능으로 본인 키: 유튜브 제목·설명·챕터 문구, 배경 이미지(이미지 연동은 `ai-image-studio` 기준) |
| 월간 코드 판매 | AIMaster 등급·사용기간·FREE 배지 판정 그대로 |

## §3 독립으로 남길(그대로 둘) 프로그램

| 프로그램 | 남기는 이유 | 겹쳐 보이는 점과 다른 점 | 제안 |
|---|---|---|---|
| `playlist-channel-studio` | 기획(제목·Suno 프롬프트·설명·썸네일) + 비주얼라이저 영상이 고유 | 여러 곡 영상은 겹치지만 가사가 없음 | 그대로. 나중에 「가사 영상은 리릭비디오에서」 안내 링크만 |
| `music-automation` | 실제 곡 생성·보관이 고유, 사용 기록 최다 | 가사 글은 있지만 영상 없음 | 곡 카드에 「가사 영상 만들기 →」 링크(새 앱 주소 + 곡 ID)만 추가 |
| `vinyl-lp-studio` | 앨범 아트·LP 질감 영상이 고유 | LP 회전만 겹침 | 그대로 |
| `music-video-studio` | AI 장면 영상(Veo)이 고유 | 가사는 쓰지만 자막 영상 아님 | 그대로 |
| `ai-audio-analyzer`·`music-player`·`suno-music-studio` | 분석·재생·기획 전용 | 소리를 다루는 것만 같음 | 그대로 |

근거(저장소 코드 집계): 위 후보 9개 폴더에서 `.srt`/`vtt` 처리 0건, 노래방 0건, 단어 시간 가사(`timestamped`·`aligned`) 0건. `playlist-channel-studio` 렌더러는 `1920×1080`/`1280×720` 고정이고 `fillText`(글자 그리기)가 없습니다.

## §4 진행 방식(승인 후)

1. **이름·주소 확정**(아래 후보) → 개발 플랜 문서 `lyric-video-studio/docs/PLAN_YYYYMMDD_*.md`.
2. **1차(핵심, 무료로 시험 가능)**: 단일 곡 + `.srt`/가사 붙여넣기 + 탭 싱크 편집기 + 가로·세로 프리셋 8~10종 + 강조 6종 + 커버·스펙트럼·진행 바 + 브라우저 MP4. 유료 API 0회로 개발·검수 가능.
3. **2차**: 「내 Suno 곡 가져오기」 + 시간 가사 자동 받기(회원 본인 Suno 키, 시험은 지정 일반 회원 키로 최소 1~2회), 노래방(발음 로마자 표기), LP판.
4. **3차**: 플레이리스트(폴더째·앨범 카드·챕터), Pexels(본인 키), 로고·프레임, 선택 AI(제목·설명).
5. 매 단계 버전 +0.01, 크롬 실제 창 검수(데스크톱·375px), 역량 지도 카드·인수인계 갱신. 새 표: `lyric_projects`(설정·가사 시간표, 회원별 RLS) 1개 예상 + 업로드 음악 저장소(30일 삭제).

**이름 후보**(카드 한 줄 요약 예: 「음악과 가사만 넣으면 가사가 흐르는 유튜브·쇼츠 영상을 브라우저에서 바로 만드는 도구」)

| 1(추천) | AI 리릭비디오 자동화 | `lyric-video-studio` | 「리릭비디오」가 업계 용어라 기능이 한 번에 설명됨, 기존 slug와 겹치지 않음, 원본 이름(Lyricbi)과 다름 |

## §5 확인 필요(주인님 결정)

1. **방향**: C안(새 프로그램 + 엔진 사본 + 음악(SUNO) 자동화 연결)으로 진행할지.
2. **이름**: 「AI 리릭비디오 자동화」(`lyric-video-studio`)로 할지, 다른 후보로 할지.
3. **범위·순서**: 1차(단일 곡·탭 싱크·세로 포함)부터 하고 플레이리스트는 3차로 미룰지.
4. **배지·권한**: 처음에 FREE로 열지, 일반 권한 부여 방식으로 할지(VIP는 규칙대로 자동 부여 확인). 브라우저 렌더라 운영자 실비가 거의 없어 프리미엄 후보는 아니라고 판단했습니다.
5. **음악(SUNO) 자동화 연결**: 곡 카드에 「가사 영상 만들기 →」 링크를 넣는 작은 변경(버전 +0.01)을 2차에 함께 할지.
6. **권리**: Lyricbi는 남의 상용 앱이라 코드는 옮기지 않고 기능·화면 흐름만 참고해 새로 만듭니다(REA 지침). 한국어 제목→영어 검색어 사전·프리셋 이름도 그대로 베끼지 않고 새로 만듭니다.
