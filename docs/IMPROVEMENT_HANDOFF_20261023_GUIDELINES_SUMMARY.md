# 최상위 공통 지침 분야별 요약 인수인계

## 요청·결과·보존 범위

주인님 요청은 반복된 지침을 다른 CLI가 빠르게 찾도록 큰 영역별로 요약하는 것입니다. 후속 지시 **「삭제하라는 게 아니라 중복되는 내용만 다시 검토해서 요약 정리」**를 적용했습니다.

- 진입점: [최상위 지침 요약 색인](guidelines/README.md).
- 10개 분야: 최상위 공통, 개발, 디자인, 디자인 템플릿/매뉴얼, 서브프로그램 개발·운영, 비용·배포, CLI 협업, 한국어 소통, 병합·독립 유지, 에러 처리.
- 작업 시작 시 원문 `AGENTS.md`·`CLAUDE.md`·`GEMINI.md`는 총 1,915줄이었습니다. 기존 본문과 다른 CLI가 동시 추가한 최상단 사고 방지 지침까지 보존하고, 같은 색인 안내만 상단에 추가합니다. 기존 협업 상세에는 새 멀티세션 규칙의 연결만 추가하며 나머지 프로그램별 지침·상세 정책은 편집하지 않습니다.
- [중복·상충 검토표](guidelines/REVIEW_20261023.md)에 반복 주제의 원문 위치와 요약 영역, 과거/최신 조건 비교를 남겼습니다. 이 요약이 원문의 정책·예외를 대체하지 않습니다.
- 후속 환경 설명 반영: 윈도우 메인·맥미니 원격 보조 PC의 AGY/CODEX/CLAUDE CODE 멀티세션을 협업 요약 첫 부분에 정리했습니다. 장비+CLI+세션/작업명으로 담당/커밋을 구분하고, 공유 파일/인덱스·브라우저 충돌·맥미니→윈도우 인계 조건을 기존 원문과 연결했습니다.
- 별도 후속 요청에 따라 [멀티에이전트·멀티세션 공동 작업 규칙](MULTI_AGENT_SESSION_RULES.md)을 등록했습니다. 폴더/공용 자원 예약, 문서 수정, 공유 Git/인덱스, 소유자/행/기대 상태 조건의 DB 수정, 자동 발행 중복 방지, 배포·환경변수 담당, 맥미니 인계, 충돌/담당 전환을 명시했습니다. 이는 기존 내용의 요약 외에 주인님이 명시적으로 요청한 규칙 보완입니다.
- [사전 플랜](PLAN_20261023_GUIDELINES_SUMMARY.md), [원문 비교 기준](guidelines/evidence/source-baseline.json), [검수 결과](guidelines/evidence/summary-checks.json)를 연결합니다.

## 다음 CLI의 읽는 순서와 관리 방법

1. 색인 → 공통 원칙·CLI 협업 → 이번 작업에 필요한 분야 요약을 읽습니다.
2. 요약에 연결된 상세 원문과 대상 프로그램의 최신 AGENTS/README·개선/인수인계를 확인합니다.
3. 정책이 바뀌면 기존 상세 원문을 먼저 갱신하고 해당 요약을 맞춥니다. 루트 세 파일의 요약 안내는 같은 내용으로 유지합니다.
4. 프로그램 현재 버전·담당·완료 상태는 최신 현황판/프로그램 문서에서 대조합니다. 이 요약을 새 현황 캐시로 사용하지 않습니다.
5. 원문에는 아직 중복·과거 설명이 남아 있습니다. 삭제하지 말라는 이번 지시를 지키기 위해 보존한 것이며, 적용 조건은 검토표와 최신 확정 지시로 확인합니다.

## 검수와 한계

- 로컬 문서 검사: `node docs/guidelines/check-summary.mjs --check-preservation --write-report`.
- 검사 범위: 10개 분야/색인 존재, 이번 요약의 상대 링크, 루트 세 안내 일치, 안내를 제외한 원문 SHA-256·바이트 일치.
- 검사 결과: **통과**. 문서 15개·상대 파일 링크 167개, 루트 세 안내 일치, 최신 기존 본문 총 1,942줄(동시 추가 지침 포함)의 SHA-256/바이트 일치. 기존 협업 상세 본문도 별도 비교로 바이트 일치를 확인했습니다. 수정 diff는 루트 각 5줄·협업 상세 4줄 추가, 기존 줄 삭제 0입니다.
- 이는 문서 구조/보존 검사입니다. 모든 과거 정책의 제품 구현 상태·전체 상세 원문 링크·운영 서비스·실제 브라우저를 재검수한 결과가 아닙니다.
- 제품 화면을 변경하지 않아 브라우저 실세션 검수·앱 빌드·프로그램 버전 증가·배포는 해당 없음입니다.
- `--check-preservation`은 이번 2026-10-23 요약 작업의 원문 보존 검증용입니다. 이후 정당한 원문 수정이 있으면 실패할 수 있으므로 일반 연결 검사는 옵션 없이 실행합니다.

## Git 특이사항과 협업

작업 중 기존 커밋 `c2e7c4db2`의 대량 삭제 때문에 루트 지침이 잠시 미추적 상태였습니다. 로컬 원문을 보존하고 관계없는 복구/삭제/스테이징 정리를 하지 않았습니다. 이어 다른 CLI가 `237741cc3`으로 복구하고 `5b6a6b95f`로 재발 방지 지침을 추가했습니다. 첫 보존 검사가 이 차이를 잡아 편집 전에 중단했고, 최신 추가 내용까지 포함해 기준을 갱신했습니다. 해당 복구·보호 장치 구현은 이 작업의 성과로 집계하지 않습니다. 최신 HEAD를 다시 읽고 안전 커밋 도우미로 이번 문서만 반영합니다.

커밋·푸시 결과는 이 문서 및 루트 HANDOFF의 Git 이력에서 확인합니다. 다른 CLI의 진행 중 앱 작업·미커밋·스테이징은 보존합니다. 이 문서화 작업은 루트 공용 문서 작업이므로 기존 규칙대로 다른 프로그램의 ACTIVE_WORK 행을 추가/해제하지 않습니다.
