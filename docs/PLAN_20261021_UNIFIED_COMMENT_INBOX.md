## 1. 문제

인스타 댓글·DM, 쓰레드 댓글, 유튜브 댓글을 응대하려면 프로그램 3개(`instagram-comment-reply`·`threads-comment-reply`·`youtube-auto-reply`)에 따로 들어가야 한다. 급한 DM(24시간 답장 창)과 오래된 댓글을 한눈에 비교할 수 없다.

## 2. 이미 준비된 것 (2026-10-21)

| 준비 | 내용 |
|---|---|
| 같은 목록 형식 | 세 대시보드의 「검토를 기다리는 ○○」이 공용 기준 코드 `pending-review-list` 하나(기준 `instagram-comment-reply/components/PendingReviewList.tsx`) |
| 같은 이동·강조 | 항목 → 검토 화면 묶음(`#media-`·`#conv-`·`#post-`·`#video-`) + `hash-highlight` 2초 강조 |
| 같은 데이터 모양 | `ig_comments`·`dm_messages`·`th_comments`·`ytreply_comments` 모두 작성자·본문·AI 초안(`generated_reply`)·`status='pending_review'`·`user_id` |
| 공용 연결 토큰 | `member_platform_accounts`에 instagram·threads·youtube 연결이 회원별로 있음(`lib/memberIntegrations.ts`) |

| 안 | 장점 | 단점 / 규칙 |
|---|---|---|

## 4. 단계 (A안 기준)

1. **1단계 — 읽기 전용 받은편지함**: 세 플랫폼의 `pending_review`를 회원 본인 것만(서비스 롤 + `user_id` 필터) 모아 급한 순(DM 남은 시간 → 오래된 댓글)으로 보여 주고, 항목을 누르면 **원래 프로그램의 검토 화면 묶음으로 이동**(지금 만든 `#…` 주소). 게시·발송은 원래 프로그램에서 → 위험 낮음, 비용 없음.
2. **2단계 — 받은편지함에서 바로 승인**(선택): 각 플랫폼 게시 코드를 공용 기준 코드로 떼어 새 프로그램에 사본으로 넣고 `member_platform_accounts` 토큰으로 게시. 프로그램끼리 직접 호출하지 않음. 실제 공개 게시라 사전 승인·실검수 필요.
3. 권한: 새 프로그램 slug로 `requireProgramAccess`. 세 원본 프로그램 권한이 없는 회원에게 그 플랫폼 항목을 보여 줄지는 주인님 결정(기본안: 원본 프로그램 권한이 있는 플랫폼만 표시).
