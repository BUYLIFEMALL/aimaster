# 드림AI 바이브코딩 창업 클래스 보완안 2판 (2026-10-31)

작성: Claude Code(윈도우) `claude-win-20261029-statusbar` [역할: 미지정]. 상태: **강사 검토용 초안.** 운영 프로그램·DB와 무관한 교육 자료다.
바뀐 점: 주인님 지시 「교육이 중심이고 부가 자동화 웹/앱 개발이야」에 따라 1판의 창업 프로젝트형 구성(통과 기준·중단 판정)을 없애고 **원안의 강의 순서와 내용을 기준으로 다시 썼다.**

## 1. 구성 원칙
- **중심은 교육이다.** 수강생은 바이브코딩의 개념, AI 도구 사용법, 비즈니스 활용법을 배운다.
- **자동화 웹/앱은 부가 실습이다.** 배운 내용을 자기 아이디어에 적용해 보는 결과물이며, 완성도나 사업 성과를 수료 조건으로 삼지 않는다.
- **창업 내용은 각 강의에 짧게 넣는다.** 원안 내용을 대체하지 않는다.

## 2. 커리큘럼
원안에 「3강」이 두 번 있어 뒤의 것을 4강으로 옮겼다. 그래서 7강이 된다. 6강으로 유지하려면 3·4강을 합치고 도구 내용을 부록으로 뺀다.

| 강의 | 교육 내용(원안 유지) | 부가 실습 | 추가할 창업 내용(10~20분) |
|---|---|---|---|
| 1강 사업 기획 | 타당성 조사, 마인드맵 아이디어 정리, 사업성 검토, 개발 플랜 | 내 아이디어 정리 1장 | 고객 정의, 고객에게 묻는 법, 간단한 비용·가격 계산 |
| 2강 바이브코딩 기초 | 개념과 트렌드, 사람·LLM·에이전트 역할, AI 엔지니어링, 도구·모델 비교, 작업 환경 설정, 1:1 컨설팅 | Stitch로 블로그 사이트, 게시판 | 아이디어를 기능 요구사항으로 바꾸는 법(PRD 1장) |
| 3강 바이브코딩 시작 | 프로젝트 만들기, 지침 파일, Codex·Claude Code·Antigravity, AI 디자인, 디자인 용어, 플랫폼 연동 | 홈페이지, 랜딩페이지, 블로그 사이트 | 랜딩페이지로 관심도 확인하는 법 |
| 4강 수익형 웹/앱과 작업 환경 | 사업 기획, 기존 프로젝트 벤치마킹, 멀티 에이전트·멀티 PC, 원격 작업, 수익 모델(광고·제휴·대행·판매) | 나만의 웹/앱 첫 기능 | 수익 모델 고르는 법, 작게 시작하는 범위 정하기 |
| 5강 바이럴 채널 자동화 | Threads·인스타·네이버 블로그·티스토리·워드프레스·구글 블로거, 메타 앱·구글 인증, 이미지 플랫폼 | 쓰레드·인스타 자동화, 웹/앱 중간 점검 | 플랫폼 정책과 자동화 주의점 |
| 6강 마케팅 자동화 | CRM, 고객 모집·관리, 퍼널, 네이버 마케팅, 카카오·유튜브 연동 | CRM·마케팅 자동화, 핵심 기능 1개 완성, 지인 3명 피드백 | 고객 개인정보 수집 동의와 보관 |
| 7강 수익화 시작 | 도메인·반응형, 검색 등록, 애드센스, 크롬 스토어, 웹/앱/PC 프로그램 판매 | 웹/앱 최종 점검, 발표 | 사업자등록, 결제 준비, 약관·환불 안내, 세금 기초 |

선택 실습과 세분화 클래스(쇼핑몰, SNS 자동화, CRM·마케팅, 수익형 비즈니스 사이트, 영상 편집, PC·모바일 앱)는 원안대로 둔다.

## 3. 강의별로 짧게 더할 내용
- **보안(2강부터 반복):** 키는 환경변수에만, `.gitignore` 확인, 회원별 권한, 유료 API 사용 한도.
- **비용 안내(1강 전):** AI 구독, Vercel, Supabase, 도메인, 문자 비용을 표로 알리고 월 상한을 정한다. 계정·키는 수강생 본인 것을 쓴다.
- **결제 일정(4강 안내):** 결제까지 다룰 수강생은 PG 심사(보통 영업일 7~10일, PG마다 다름)를 7강보다 일찍 시작하도록 안내한다.
- **운영 기초(7강):** 백업, 오류 확인, 고객 문의 처리.
- **지원사업(7강 또는 특강):** PSST 사업계획서 구조와 정부 창업 지원사업 소개. 사업자등록 전에 예비창업자 대상 사업의 자격부터 확인하게 한다.

법·세금 내용은 안내 수준으로 다루고, 현행 법령 대조와 전문가 검토 뒤 자료를 확정한다.

## 4. 원안에서 고칠 점
| 위치 | 문제 | 수정 |
|---|---|---|
| **전체** | **실제 키·비밀번호·토큰 포함** | 수강생 자료에서 전부 제거, 값은 `<본인 키>`로 교체, 노출 키 교체(§6) |
| 강의 번호 | 「3강」 중복 | 7강 구성 또는 합치기 |
| Orca·OpenClaw | 같은 내용이 두 번 반복 | 한 곳으로 합치기 |
| 설치 항목 | Claude Code 항목에 Codex 설치 명령, agy 항목에 `gemini` 확인·삭제 명령이 섞임 | 개강 전 실제 설치로 재검증 |
| 권한 설정 | 초보에게 전체 허용(Always Proceed, Full access) 안내 | 기본은 검토 모드, 자동 실행은 위험 설명 뒤 |
| Git | `git add .` 안내 | `.env` 제외 확인을 먼저 가르침 |
| 요금표·모델 | 가격과 모델명이 빨리 바뀜 | 표마다 확인일과 공식 링크, 개강 전 재확인 |
| 수익 금액 | 확정 수익처럼 보일 수 있음 | 사례로 표시, 결과 보장 문구 금지 |
| 크롬 스토어 | 등록 개수 제한 설명 없음 | 2026-08-20부터 계정 기본 슬롯 2개 안내 |
| 웹사이트 복제 도구 | 권리 문제 소지 | 구조 학습용으로 제한 |

## 5. 수업 운영
- 1분 면담은 유지하되, 시간이 부족하면 사전 설문을 더한다.
- 설치는 사전 과제나 배포 키트로 줄여 수업 시간을 아낀다.
- 수업 진도는 교육 내용 기준으로 가고, 개인 웹/앱은 1:1 컨설팅에서 범위를 조절한다.
- 수료는 출석과 실습 제출 기준으로 한다. 매출·수익은 보장하지 않는다.
