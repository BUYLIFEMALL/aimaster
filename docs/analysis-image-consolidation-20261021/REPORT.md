### 8-2. 병합 판단 (9개 → 9개 유지, 카테고리 간 후보 2개는 별도 분석)
지난 병합(A·B)으로 「같은 일」 묶음은 이미 정리됐습니다. 남은 조합을 매뉴얼 §4-1(같은 일·같은 사용자·한 흐름) / §4-4(독립 조건)로 다시 봤습니다.

| 검토한 조합 | 겹치는 부분(코드 근거) | 판단 | 이유 |
|---|---|---|---|
| 바나나 캔버스 ↔ 이미지 스튜디오 | 텍스트로 이미지 생성(banana `generate` ↔ 스튜디오 전체), 화풍 프리셋 | **독립 유지 + 연결(완료)** | 스튜디오 = 여러 회사 엔진 33종·**이미지 모델 연동 기준 프로그램**(루트 지침), 바나나 = Gemini 편집 작업대. 합치면 기준 프로그램 역할이 흐려짐(§4-4의 1·4) |

| **AI 4컷 만화 ↔ AI 웹툰(다른 카테고리)** | 컷 만화 생성·캐릭터 일관성·인스타 게시(4컷의 인스타 코드가 웹툰 기준 사본) | **카테고리 간 병합 후보 — 별도 분석 필요** | 같은 일 중간·같은 사용자 큼·한 흐름 큼. 웹툰 키 저장 문제를 먼저 고친 뒤 비교 |
| **감성 글귀 이미지 ↔ 카드뉴스(다른 카테고리)** | 배경 + 한글 문구 합성 이미지 | **카테고리 간 병합 후보 — 별도 분석 필요** | 같은 일 중간~큼·같은 사용자 큼. 카드뉴스 공개 여부·인스타 분야 판단과 함께 |
