## 3. 이어받는 CLI 주의사항
- 운영 DB SQL은 크롬 Supabase SQL 편집기(PRODUCTION 표시 확인)로 실행했다. 편집기에 긴 SQL은 `window.monaco.editor.getModels()[0].setValue(...)`로 넣으면 괄호 자동 완성으로 꼬이지 않는다. 「RLS 없이 표를 만든다」 경고가 행 넣기 SQL에 잘못 뜨면 「Run without RLS」(작성 그대로)를 고른다 — 「Run and enable RLS」는 다른 표 설정을 바꿀 수 있다.
- 공유 문서에 다른 CLI의 미커밋 변경이 있으면 `git hash-object -w` + `git update-index --cacheinfo`로 내 단락만 커밋한다(쇼핑제휴 `AGENTS.md` 사례).
- 메인 사이트는 푸시 자동 배포 — 다른 세션의 프로그램 전용 푸시는 「Canceled」로 보일 수 있으니 `vercel inspect`로 직전 배포의 Ready를 확인한다.
- 진행 설명은 처음부터 끝까지 한국어(0순위 규칙). 이 세션에서 영어 재발이 여러 번 있었다.
