# 최상위 지침 분야별 요약 정리 플랜

2026-10-23 · Codex(윈도우) · AIMaster 공통 문서 작업.

## 요청과 범위

주인님 요청은 기존 지침을 삭제하는 작업이 아니라, 중복 내용을 검토해 다른 CLI가 빠르게 이해하도록 분야별로 요약하는 작업입니다. 후속 지시로 개발·디자인·서브프로그램 개발 및 운영·한국어·비용 및 배포·디자인 템플릿·프로그램 병합 및 독립 유지·에러 처리를 포함합니다.

- `AGENTS.md`·`CLAUDE.md`·`GEMINI.md`의 기존 본문은 그대로 보존합니다. 상단에 같은 요약 색인 안내만 추가하며 다른 CLI의 최상단 사고 방지 지침은 그 위에 유지합니다.
- 분야별 요약은 `docs/guidelines/`에 작성합니다. 각 요약에 기존 상세 지침을 연결하며 원문을 대체하지 않습니다.
- 기존 프로그램 문서·운영 코드·계정·키·DB·환경변수·프로그램 버전·서비스 공개 상태는 변경하지 않습니다.
- 최신 지시로 적용 조건이 바뀐 항목은 날짜·원문·적용 조건을 비교해 적습니다. 판단이 필요한 충돌을 임의로 정책 변경하지 않습니다.

## 순서와 완료 조건

1. 세 루트 지침과 분야별 원문을 비교합니다. 중복 묶음·예외·상충 이력을 검토표에 남깁니다.
2. 분야별 요약과 읽기 색인을 작성합니다. 개발·디자인·배포 등 작업별 첫 문서가 명확해야 합니다.
3. 루트 세 파일에 동일한 안내를 추가합니다. 추가 안내를 제외한 기존 본문의 바이트가 작업 전과 같아야 합니다.
4. 상대 링크·세 파일 안내 일치·원문 보존·원래 Git 변경과 이번 변경의 분리를 검사합니다.
5. 검수 결과·제약·다음 관리 방법을 인수인계와 루트 HANDOFF에 남기고, 이번 문서만 안전 커밋합니다.

## 비용·배포·산출물

- 비용: 문서 작성·로컬 검사만, 배포 빌드 0회·외부 AI/API 호출 0회.
- 버전·배포: 해당 없음. 프로그램 기능을 바꾸지 않으므로 버전 증가·Vercel 배포를 하지 않습니다.
- 산출물: 분야별 색인/요약, 중복·상충 검토표, 원문 보존 검사 결과, 날짜별 인수인계.
- 적용 스킬: `mattpocock-skills:writing-for-agents`. 기존 사용자 지시와 `docs/EXTERNAL_SKILLS_POLICY.md`를 우선합니다.

## 후속 요청으로 추가된 범위

주인님이 윈도우 메인/맥미니 원격 보조 PC의 AGY·CODEX·CLAUDE CODE 멀티세션 환경을 확인하고 충돌 방지·주의사항·데이터 수정 규칙을 별도로 등록하도록 요청했습니다. 이에 `docs/MULTI_AGENT_SESSION_RULES.md`를 작성하고 세 루트 문서와 기존 협업 문서에 짧은 연결을 추가합니다. 기존 원문 보존 범위는 유지하며, 새 규칙의 근거를 단순 요약과 구분합니다. 정책 문서만 작성하고 실제 파일 잠금/DB 잠금 시스템·계정 변경·제품 코드는 구현하지 않습니다. 비용 없음입니다.

## 작업 전 Git 특이사항

확인 시 HEAD `93ce9f27a`에서 세 루트 지침은 추적되지 않았으나 로컬 파일은 존재했습니다. 앞선 `c2e7c4db2`에 이번 요청과 무관한 대량 삭제 기록이 있었고 origin/master도 같은 후속 HEAD였습니다. 원인은 이번 작업에서 확정하지 않았습니다. 로컬 원문은 비교용 사본과 SHA-256으로 보존했으며, 다른 프로그램 복구·삭제·인덱스 전체 정리는 수행하지 않습니다. 커밋 직전에 최신 HEAD와 다른 CLI의 처리 상태를 다시 확인합니다.
