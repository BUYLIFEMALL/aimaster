# 이커머스 외부 도구 분석 비교표 (2026-10-24)

작성: Claude Code(윈도우) `claude-win-dotori` [역할: analysis-planning]. 주인님 지시: 「이커머스 관련 프로그램 링크를 줄 테니 각각 자세히 분석한 후, 기존 이커머스 자동화 프로그램으로의 병합과 이 프로그램들을 묶어서 쇼핑몰 비즈니스에 최적화된 프로그램으로」 · 「각각 하나씩 분석해서 분석 비교표를 만들어」.
**분석만 — 코드·DB·배포 변경 없음.** 원본은 모두 공개 페이지를 내려받아 코드로 확인했고(실행·로그인·결제 없음), 코드는 옮겨 쓰지 않는다(기능만 참고).

우리 기존 이커머스 프로그램: 상품소싱 자동화 `trending-product-finder` v1.25 · AI 상세페이지 자동화 `shop-detail-page` v1.32.
쇼핑몰 업무 단계: ① 소싱·시장 조사 → ② 상품 준비(사진·상세페이지·문구) → ③ 등록·가격(수수료·마진) → ④ 홍보(블로그·쇼츠·SNS·메일) → ⑤ 판매 후(주문·배송·리뷰·실적).
