## 1. 기능 (마켓별)

### 공통 뼈대
- 모든 계산기는 **브라우저 안에서만 계산**(서버 전송 없음, 11번가·로켓그로스는 화면에 명시). 로그인·저장·기록 없음, 입력마다 즉시 다시 계산.
- 구성: 왼쪽 입력 폼 + 오른쪽 결과(「예상 이익액」 큰 숫자 + 이익률, 「총 수수료」·「총비용」, 「비용 상세」 목록, 공식 한 줄, 「계산 기준」 안내). 손실이면 빨간 카드(`is-loss`).
- 「예시」 버튼(기본/쿠폰/유료배송 등)과 「입력 초기화」. 카테고리 검색창(한글 정규화 부분 일치) + 선택 상자(검색어 있으면 2~7줄 펼침). 카테고리를 고르면 요율이 채워지고, 요율을 직접 고치면 「수수료율 직접 입력」으로 표시.
- 한국어·영어·중국어 3개 언어(카테고리 이름까지 3개 언어 라벨 보유).

### 1-1. 11번가 (`mount11stFees`) — 가장 정교
- **입력**: 판매가(할인 전) / 상품 원가(선택) / 카테고리 검색·선택 / 판매 수수료율(VAT 포함, 소수 2자리) / 배송 방식(무료·선결제·착불) / 고객 선결제 배송비(선결제일 때) / 실제 판매자 부담 배송비 / 제휴채널 이용료(미적용 0% · 네이버 등 제휴 2%) / 쿠폰 적용 후 상품금액(선택) / 전월 구매확정액(선택) / 월 예상 판매 건수(선택).
- **결과**: 주문 1건 예상 이익·이익률, 주문 수수료 합계, 주문 총비용, 상세(판매가·쿠폰 할인액·판매 수수료·제휴 2%·선결제 배송비 수수료 3.3%·쿠폰 판매자 부담 20%·예상 정산금·원가·실제 배송비), 「쿠폰 부담 상한 적용」 알림, **월 서버 이용료 77,000원**과 서버비 차감 후 월 예상 이익.
- 예시: 기본(5만 원/원가 3만/13%/무료배송, 문구·사무 카테고리), 쿠폰 예시(12.5만 원/원가 8만/7%/제휴 2%/쿠폰 후 116,370원, 「라벨프린터」 카테고리).

### 1-2. 스마트스토어 (`mountSmartstoreFees`) — 카테고리표 없음, 사업자 등급 기준
- **입력**: 배송 방식(유료·무료) / 판매가 / 원가 / 배송비(유료=고객에게 받는 배송비, 무료=판매자 부담 배송비) / **사업자 등급**(영세·중소1·중소2·중소3·일반) / 기본 수수료율(VAT 포함, 등급 고르면 자동) / **판매자 마케팅 여부**(Y 1% · N 3%) / 판매 수수료율 / **쇼핑커넥트**(Y·N) / 쇼핑커넥트 수수료율(기본 7.7%).
- **결과**: 예상 이익·이익률, 총 수수료·총비용, 상세(원가·기본 수수료·판매 수수료·쇼핑커넥트 수수료·배송비 비용·배송비 수수료). 「기본 요율 적용 중 / 직접 수정한 요율 적용 중」 표시.
- 예시: 유료배송(47,800원/원가 4만/배송비 3,000/영세/마케팅 Y/쇼핑커넥트 Y), 무료배송(배송비 2,500/마케팅 N).

### 1-3. 지마켓 / 1-4. 옥션 (`mountEsmFees`, 같은 코드·다른 표)
- **입력**: 판매가(할인 전) / 판매자 부담 할인 / 원가 / 카테고리 검색·선택 / 판매 수수료율(VAT 포함, 소수 6자리) / 배송 방식(무료·선결제·착불) / 구매자 선결제 배송비 / 실제 판매자 부담 배송비(착불이면 「착불 시 판매자 추가 부담」으로 바뀌고 0으로 초기화) / **제휴채널 이용료**(미적용 0% · 네이버 등 2%) / **프로모션 이용료**(대상 아님 0% · 「빅스마일데이 등」 대상 3%) / 전월 해당 판매자 ID 구매확정액 / 월 예상 판매 건수.
- **결과**: 주문 1건 이익(월 서버비 제외)·이익률, 수수료 합계·총비용, 상세(판매가·할인 차감 금액·배송비 포함 수입·원가·실제 배송비·판매 수수료·제휴 2%·선결제 배송비 3.3%·프로모션 3%·예상 정산금), **월 서버 이용료 55,000원**·월 예상 이익.
- 공식 안내 링크 4개: ESM 판매·배송·서비스 이용료 안내(마켓별 주소), 지마켓 프로모션 정책 공지, 제휴 항목 안내(`etapi.gmarket.com/41`), 제휴채널 이용료 안내(`cs.esmplus.com`).
- 예시: 기본(5만/할인 0/원가 3만/배송비 2,500), 프로모션 예시(할인 5천/전월 500만/월 100건). 예시 카테고리: 지마켓 `gmarket-47`, 옥션 `auction-51`.

### 1-5. 쿠팡 일반 판매 (`mountCoupangFees`) — 가장 단순
- **입력**: 배송 방식(무료·유료) / 상품명(선택, 계산에 안 씀) / 판매가 / 원가 / 배송비(무료=판매자 부담, 유료=고객에게 받는 배송비) / 카테고리 검색·선택 / 판매 수수료율(VAT 포함) / 배송비 수수료율(VAT 포함, 기본 3.3%, 유료일 때만).
- **결과**: 예상 이익·이익률(소수 2자리), 총 수수료·총비용, 상세(원가·판매 수수료·배송비 비용·배송비 수수료), 공식 한 줄.
- 안내: 「첨부 엑셀 요율 사용, 자동 갱신 안 됨, 월정액·광고비·반품비 미포함」.

### 1-6. 쿠팡 로켓그로스 마진 (`mountRocketGrowth`) — 물류비 분해
- **입력(상품 1개 기준, 모두 VAT 포함)**: 최종 판매가 / 원가 / 판매수수료 카테고리(쿠팡 일반과 같은 표) / 요율 / **상품 사이즈 유형 6단계**(극소형~특대형, 크기·무게 기준표 접기) / **입출고·고객 배송비 합계**(WING에서 확인한 값 입력, VAT 별도면 ×1.1 안내) / **예시 요금표**(컴퓨터/디지털 > 노트북/데스크탑, 판매가 11구간 × 사이즈 6단계)와 「현재 판매가·사이즈로 예시 비용 넣기」 / **창고 발송비**(이번 발송 총 물류비 ÷ 입고 수량) / **세이버 가입 여부** / 접기 메뉴 「그 외 비용·부가서비스」: 판매까지 보관 일수, 무료 보관 기간(일반 30·의류/신발/액세서리 45·없음), 무료 기간 이후 개당 일 보관비, 반품 회수비·재입고비 개당 배분액, 재고 반출비 배분액, 세이버 가입비 개당 배분액, 바코드 서비스(부착·오류 수정), 리뷰 이벤트(2,420원), 재고 반출 배송 박스 유형 A~G와 박스 안 수량.
- **결과**: 상품 1개 예상 이익·마진율, 총비용(원가 포함), 창고 발송비 개당, 비용 상세 12줄(원가·판매 수수료·입출고/배송·창고 발송·보관·반품 회수·재입고·반출·바코드·리뷰·반출 배송·세이버 배분), 세이버 가입비 미배분 경고.
- 3단계 안내: ① 쿠팡 공식 비용 안내 열기 ② WING에서 카테고리 선택 ③ 확인한 비용 입력 — 링크로 연결.

### 1-7. 쿠팡 로켓그로스 정책 (`mountRocketPolicy`) — 계산기 아님
- 같은 묶음의 별도 화면. 제목·소개 한 문단 + **링크 3개**(쿠팡 공식 로켓그로스 정책, WING 입출고/배송 요금 상세, 세이버 혜택·가입비). 계산·데이터 없음.

## 2. 계산 공식·데이터표

> 표기: `⌊ ⌋` = 원 미만 버림(0 방향). 요율은 모두 VAT 포함 값으로 입력·계산.

### 2-1. 11번가
```
총판매가 G = 판매가 (+옵션, 화면에선 0)            할인 후 N = G − 판매자 할인(화면에선 0)
쿠폰 할인액 C = N − 쿠폰 적용 후 상품금액(없으면 0)
판매 수수료 F = ⌊G × 요율⌋                        ← 할인 전 판매가 기준
제휴 이용료 A = 제휴 적용 시 ⌊G × 2%⌋
쿠폰 판매자 부담 K = min(⌊C × 20%⌋, F)              ← 부담 20%, 판매 수수료를 상한으로
선결제 배송비 수수료 S = ⌊고객 선결제 배송비 × 3.3%⌋
주문 수수료 합계 = F + A + K + S
예상 정산금 = G + 선결제 배송비 − (F + A + K + S)   ← 플랫폼 쿠폰은 지원금으로 전액 상계(정책 동의 가정)
이익 = 정산금 − 원가 − 실제 배송비                   (원가 비우면 "원가 입력 시 계산")
이익률 = ⌊이익 × 100 ÷ (판매가 + 선결제 배송비)⌋ %   ← 분모에 배송비 포함
월 서버 이용료 = 전월 구매확정액 ≥ 500만 원이면 77,000원, 아니면 0
월 예상 이익 = 이익 × 월 건수 − 월 서버 이용료
```
- **숨은 엔진**: 내부 계산 함수는 화면보다 넓다 — 수량×단가 모드, 옵션 금액, 배송비 제휴료(2%), 후불 광고비(총액 또는 개당), 기타 공제, 추가 정산금, 포장비, 외부 비용, **실제 정산금 입력 시 차이 계산**, 쿠폰 정책 미동의 시 「보류」 상태, 정산 확인 필요 표시(쿠폰 부담 ≥ 판매 수수료 또는 서비스료 음수). 화면에는 일부만 연결돼 있다. 금액은 `BigInt`로 계산해 넘침을 막는다.
- **데이터표**: `categories` 217행(대분류 185개) + `changes` 45행(변경 전·후 요율) → `대분류|중분류`로 합쳐 선택 목록 생성. 기준 날짜 `effectiveDate 2025-04-01`, `checkedAt 2026-09-30`, 관찰 기간 2026-09-08~09-29, 검증 표본 24행(상품 17·배송 7, 주문 13건). 요율 분포: 13% 132행, 9% 34, 7% 17, 12% 12, 11% 8, 8% 4, 10% 3, 5% 2, 15%·4%·3%·2%·1% 각 1행.
  - 예시: 브랜드·패션·뷰티·식품 대부분 13% / 도서·음반 15%(eBook 5%, 중고도서 10%) / e쿠폰·상품권 8%(외식·편의점 등 4%, 모바일·지류 상품권 2%) / 국내·해외 항공권 3% / 프린터·카메라·냉장고 7% / 렌털·구독 서비스 1%(정액 요금 별도 확인 표시 `fixed`).
  - 변경 예시(`changes`): 디자이너 남성·여성의류·잡화 20%→13%, 휴대폰 SKT 20%→9%, e쿠폰 외식류 8%→4%, 화장지류 10%→9%.

### 2-5. 로켓그로스 마진
```

창고 발송비 = ⌊이번 발송 총 물류비 ÷ 입고 수량⌋
보관비 = 보관일수 > 무료기간(세이버면 60일, 아니면 30/45/0) 이면 ⌊초과일수 × 개당 일 보관비⌋
반품 회수비·재입고비 = 세이버면 0, 아니면 입력한 개당 배분액
바코드 = 부착 125·125·175·250·250·250 / 오류수정 400·400·500·700·700·700 (사이즈별, ×1.1 후 버림 → 137·192·275 / 440·550·770)
리뷰 이벤트 = 2,420원(200 + 2,000, VAT 포함)
반출 배송 = ⌊박스 요금 ÷ 박스 안 수량⌋, 박스 A~G = 2,420·2,420·3,080·4,180·5,500·8,800·12,100원 (80~200cm / 6~25kg)
총비용 = 원가 + 판매 수수료 + 입출고·배송 + 창고 발송 + 보관 + 회수 + 재입고 + 반출 + 바코드 + 리뷰 + 반출 배송 + 세이버 배분
이익 = 판매가 − 총비용             마진율 = 이익 ÷ 판매가 × 100 (소수 2자리 버림)
```
- **데이터표**: 사이즈 6단계 기준(세 변 합 ≤80/100/120/140/160/250cm, 무게 ≤2/5/10/15/20/30kg). **입출고+배송 예시 요금표** 판매가 11구간(5천 미만 ~ 10만 이상) × 사이즈 6단계 = 66칸, VAT 별도 값 저장 후 ×1.1(예: 5천 원 미만·극소형 2,700 → 2,970원, 10만 이상·특대형 8,700 → 9,570원). 기준 「2026-09-30 제공 자료」, 카테고리는 노트북/데스크탑 예시 1개뿐(다른 카테고리는 WING 확인 안내). 판매수수료 카테고리는 쿠팡 일반 125행 표 재사용.

## 4. 장점·단점

**장점**
1. 마켓별 **실제 정산 구조**를 따로 모델링 — 11번가 쿠폰 20% 부담·판매 수수료 상한, ESM 제휴 2%·프로모션 3%, 스마트스토어 등급·유입·쇼핑커넥트, 쿠팡 배송비 수수료 3.3%, 로켓그로스 물류 12항목.
2. **월 서버 이용료**(11번가 77,000원·ESM 55,000원, 전월 500만 원 기준)를 주문당이 아니라 월 이익에서 한 번만 빼는 정확한 처리.
3. 카테고리 수수료표 내장(11번가 217+45행, 지마켓 118, 옥션 116, 쿠팡 125)과 한글 검색, 기준 날짜·출처 링크 명시.
4. 원 단위 버림·`BigInt` 계산·입력 검증이 꼼꼼하고, 계산 기준을 화면에 문장으로 설명.
5. 로그인 없이 즉시 사용, 3개 언어, 모바일 대응, 서버 전송 없음.

**단점**
1. **저장·비교·일괄 처리 없음** — 상품 하나씩 손으로 입력, 마켓끼리 한 화면 비교 불가, 결과 내보내기 없음.
2. 요율 **자동 갱신 없음**(정적 표), 쿠팡 표는 출처가 외부 엑셀이고 기준 날짜 없음, 스마트스토어 등급 요율도 날짜 없음.
3. 로켓그로스 입출고·배송비는 결국 **WING에서 직접 찾아 입력**해야 한다(예시표는 노트북/데스크탑 1개 카테고리뿐).
4. 원가 쪽이 단순 — 해외 소싱의 관세·부가세·해외 운송비, 광고비(11번가 엔진에만 숨어 있음), 반품률은 다루지 않는다.
5. 계산기마다 반올림·이익률 분모가 다르다(쿠팡 일반은 버림 없음, 11번가·ESM은 배송비 포함 수입이 분모) — 마켓 간 숫자를 그대로 비교하면 오해 소지.
6. 화면에 쿠팡 파트너스 광고 iframe이 붙는다.

## 6. 우리에게 없는 것·가져올 것·하지 않을 것

**우리에게 없는 것**
- 마켓 선택과 마켓별 정산 공식(쿠폰 부담·제휴 2%·프로모션 3%·배송비 3.3%·월 서버비·스마트스토어 등급/유입/쇼핑커넥트).
- 카테고리 선택 → 요율 자동 채움(우리 `/fees`는 읽기 전용 참고표).
- 배송 방식 3종(무료·선결제·착불)에 따른 비용·수수료 분기.
- 로켓그로스 물류비 분해.
- 마켓 간 이익 비교.

**가져올 것(기능·공식만, 데이터는 공식 안내에서 다시 확인)**
1. `lib/margin.ts`에 **마켓 프로필**(쿠팡·스마트스토어·11번가·지마켓·옥션·로켓그로스) 개념 — 마켓별 추가 수수료 함수만 얹고, 기존 「최종 수입 단가」 계산은 그대로 둔다.
2. **카테고리 검색 → 요율 자동 채움**: `/fees` 표를 계산기와 연결(표 자체는 공식 안내 기준으로 다시 작성, 기준 날짜·출처 링크 표기).
3. 배송 방식 분기와 배송비 수수료 3.3%, 판매자 할인·쿠폰(11번가 20% 부담·판매 수수료 상한), 제휴채널 2%.
4. **월 서버 이용료를 월 이익에서 한 번만 차감**하는 방식(전월 구매확정액·월 건수 입력).
5. 로켓그로스는 사이즈 6단계와 「WING에서 확인한 값 입력」 안내 + 보관·반품·세이버 항목(요금표는 회원 직접 입력 원칙).
6. **한 상품을 여러 마켓에 동시에 넣어 이익 비교**하는 표 — KDP에 없는 우리만의 확장(소싱 후보 → 어느 마켓에 올릴지 결정). 일괄 마진 CSV에도 마켓별 열 추가.
7. 계산 기준 문장 안내와 원 단위 버림·VAT 포함 표기.

**하지 않을 것**
- KDP 요율표·코드를 복사하지 않는다(공식 안내에서 직접 확인해 작성).
- 쿠팡 파트너스 광고 iframe·제휴 링크 삽입(운영자 제휴 수익 구조는 우리 회원 서비스 원칙과 맞지 않음).
- 로그인 없는 공개 계산기 별도 페이지(최상위 규칙 — 로그인 회원만 사용).
- 운영사 자사 상품 프리셋 같은 판촉 데이터.
- 요율을 실시간 크롤링해 자동 갱신(마켓 판매자센터 로그인 필요, 봇 탐지 위험) — 기준 날짜를 표시하고 회원이 수정하는 방식 유지.

## 7. 판단 제안

**제안: 새 프로그램을 만들지 않고 `trending-product-finder`(상품소싱 자동화)의 마진 계산을 확장한다.**

| 선택지 | 판단 |
|---|---|
| ① `trending-product-finder`에 병합 (추천) | 이미 마진 계산(`lib/margin.ts`)·일괄 마진 CSV·수수료 참고표(`/fees`)·소싱 원가 자동 입력이 있다. 빠진 것은 「마켓별 정산 공식 + 카테고리 요율 연결 + 마켓 비교」뿐이라 같은 화면에 얹는 것이 자연스럽다. 이커머스 기능 상세 비교표에서도 마진 계산 기준 코드가 `calcMargin`으로 지정돼 있다. |
| ② `shop-detail-page`에 추가 | 상세페이지 생성 전용이라 맞지 않는다. 다만 상세페이지로 넘길 때 「선택한 마켓·예상 이익」을 함께 넘기는 연계는 가능. |
| ③ 새 「오픈마켓 수수료 계산」 프로그램 | KDP처럼 단독 계산기는 만들기 쉽지만, 소싱 원가·일괄 처리와 떨어져 가치가 작고 비슷한 기능이 두 곳에 생긴다(공용 기준 코드 규칙 위반 소지). 비추천. |

**진행 순서 제안(구현은 담당 세션, 착수 전 개발 플랜 보고)**: ⓐ 6개 마켓 공식 수수료 안내를 다시 확인해 `/fees` 표 재작성(현재 표와 KDP 표 불일치 해소) → ⓑ `calcMargin`에 마켓 프로필·추가 수수료 함수 추가(기존 결과는 「직접 입력」 프로필로 그대로 유지, 테스트 먼저) → ⓒ 계산기 화면에 마켓·카테고리·배송 방식 선택 → ⓓ 여러 마켓 비교 표와 일괄 CSV 마켓 열 → ⓔ 로켓그로스 물류 항목(회원 직접 입력). 비용: 개발 중 유료 API 호출 없음(로컬 계산), 배포는 모았다가 1회.

**위험·제약**: 요율은 수시로 바뀌므로 기준 날짜·출처 표기와 「직접 수정」 칸이 필수다. 우리 현재 `/fees` 표의 11번가·ESM 숫자가 KDP·공식 안내와 다를 수 있어 회원이 잘못된 마진을 볼 위험이 있다 — 이 점은 다음 작업 전에 담당 세션이 먼저 확인할 것.
