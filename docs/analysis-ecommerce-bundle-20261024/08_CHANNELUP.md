## 판정 먼저

**채널업은 유튜브 채널 성장·분석 서비스가 아니다.** 첫 화면 제목부터 「카카오톡 채널친구 늘리기, 채널친구 추가 | 10명 무료체험」이며, 11개 플랫폼 36개 상품에서 **친구·팔로워·좋아요·찜·리뷰·조회수·라이브 시청자 수를 돈을 받고 인위적으로 늘려 주는 판매 사이트**(이른바 SMM 패널·「작업」 판매)다. 운영자가 가진 「여러 실제 계정」으로 고객이 지정한 주소에 반응을 넣는다고 스스로 밝힌다. 유튜브는 「라이브 시청자 늘리기」「좋아요 늘리기」 두 상품뿐이다.

- 쇼핑몰 홍보와의 관계: **커머스 반응 조작이 핵심 상품군이다** — 에이블리 마켓찜·상품찜·「구매중」·리뷰 좋아요, 오늘의집 상품찜·리뷰 도움돼요, 크몽 상품찜, 카카오맵 **별점 5점 리뷰 대리 등록**. 공개 화면에는 아직 없지만 스크립트에는 **쿠팡 상품찜·브랜드찜·장바구니 담기·리뷰** 상품, 지그재그·틱톡·팬더라이브 상품이 준비돼 있다.
- **결론: 우리 플랫폼에서는 만들지 않는다(제외).** 플랫폼 이용약관 위반이고, 가짜 리뷰·가짜 구매 신호는 국내 표시광고 규제 대상이며, 회원 본인 계정·본인 키 최상위 규칙과도 구조가 정반대다(운영자 계정 묶음으로 남의 주소에 반응을 넣는 구조). 가져올 것은 「화면 구성·안내 방식」 몇 가지뿐이다(§6).

| 국내 법 위험 | 방문·구매하지 않은 사람 명의의 **별점 5점 리뷰 대리 등록**, 「구매중」·장바구니 신호 조작은 표시광고법상 기만적 표시광고(공정위 「추천·보증 등에 관한 표시·광고 심사지침」의 가짜 후기)와 전자상거래법 위반 소지가 크고, 플랫폼 순위·검색을 속이는 행위는 판례상 위계에 의한 업무방해로 다뤄진 사례가 있다. **의뢰한 판매자도 책임 주체가 될 수 있다** |
| 고객 피해 | 유튜브 좋아요·라이브 시청자는 A/S 없음, 카카오맵 자동 리뷰는 삭제 불가, 채널이 차단되면 보충 없음. 포인트 선충전(최대 5천만 원)·계좌이체·숨은 테더 입금은 환불 분쟁 시 회수가 어렵다 |
| 효과 | 숫자만 늘고 실제 고객은 늘지 않는다(해외 계정·작업 계정). 알고리즘이 비정상 반응을 걸러 오히려 노출이 떨어질 수 있다 |
| 보안·구조 | 관리자 화면 스크립트가 공개 묶음에 포함(메뉴·API 이름 노출). 리셀러 키로 재판매되므로 실제 작업 출처가 불투명 |

## 5. 우리 프로그램과 비교표

우리 쪽은 `docs/PROGRAM_CAPABILITY_MAP.md`(프로그램 비교표) 카드 기준. **같은 목적(채널·상품을 키운다)이지만 방법이 정반대**다 — 우리는 회원 본인 계정·본인 키로 「진짜 콘텐츠·진짜 응대」를 자동화하고, 채널업은 운영자 계정으로 「숫자」를 산다.

| 채널업 상품 | 쇼핑몰 업무 단계 | 우리 쪽 비슷한 프로그램(정상 방식) | 겹침 |
|---|---|---|---|
| 유튜브 좋아요·라이브 시청자 | 유입·신뢰 | `youtube-viral-studio`(트렌드 분석), `youtube-channel-consultant`(채널 진단), `thumbnail-master`·`seo-thumbnail-pro`(썸네일·SEO), `shorts-viral-studio`·`shorts-onestop-studio`·`auto-shorts-posting`(쇼츠 제작·발행), `yt-playlist-studio`, `youtube-auto-reply`(본인 채널 댓글 응대) | 목적만 겹침, 방법 겹침 없음 |
| 인스타 팔로워·좋아요·조회수 | 유입·신뢰 | `auto-instagram-posting`(포스팅), `instagram-comment-reply`·`instagram-dm-reply`(응대) | 〃 |
| 카카오채널 친구 | 고객 모으기 | `kakao-auto-posting`(카카오톡 채널 뉴스레터), SOLAPI 알림톡 계열 | 〃 |
| 카카오맵 리뷰·저장·검색 트래픽 | 지역 매장 신뢰 | 없음(만들지 않음) | 없음 |
| 에이블리·오늘의집·크몽·쿠팡 찜·리뷰 좋아요·구매중·장바구니 | 상품 상세·전환 | 상세페이지(`shop-detail-page` 등)·리뷰 분석 계열은 「실제 리뷰를 읽어 개선」하는 방향 | 없음 |
| 티스토리 조회수·공감·구독 | 블로그 유입 | 블로그 8개 프로그램(`docs/BLOG_FEATURE_MATRIX.md`) — 진짜 글 작성·발행 | 목적만 겹침 |

**07번(prohubstart) 문서와 겹치는 점**: 07의 「유튜브 분석·성장 대시보드」는 무작위 숫자의 **가짜 화면**이고, 채널업은 진짜로 숫자를 **사서 넣는** 서비스라 성격이 다르다. 공통 결론은 같다 — 둘 다 유튜브 실제 지표는 채널 주인 본인 OAuth(YouTube Analytics)로만 정직하게 얻을 수 있다. 07의 오픈채팅 디렉토리와 채널업의 오픈채팅 인원 늘리기는 대상이 같지만, 둘 다 우리 쪽에서 만들지 않는 쪽으로 판단된다.

## 6. 우리에게 없는 것 · 가져올 것 · 하지 않을 것

| 구분 | 내용 |
|---|---|
| 우리에게 없는 것 | 카카오맵 장소 관리, 에이블리·오늘의집·크몽·쿠팡 「찜·리뷰 반응」 관련 기능 전부 — 의도적으로 없는 것이 맞다 |
| 가져올 것(화면·안내 방식만) | ① **주소 붙여 넣기 → 현재 수치 자동 조회 카드**(이름·프로필 사진·현재 숫자): 우리 프로그램에서는 회원 **본인** 채널·상품의 현재 상태를 보여 주는 첫 단계로 응용 가능(예: 본인 유튜브·인스타 OAuth 조회 결과 카드) ② 상품마다 「되는 것/안 되는 것·제외 사항」 표 — 우리 `/guide`의 ⚠️ 함정 배너와 같은 결 ③ 「AI 요약」 블록 + FAQ 구조화 데이터 + AI 검색 봇 허용 robots — 메인 사이트 프로그램 상세 페이지의 검색 노출 아이디어(공통 아이디어 표 후보) ④ 무료 체험 부정 사용 방지(계정·기기·대상 단위 1회) — FREE 배지 체험 설계 때 참고 |
| 하지 않을 것 | 팔로워·구독자·좋아요·조회수·라이브 시청자·친구 수 인위 증가, 리뷰 대리 작성·별점 조작, 찜·장바구니·「구매중」 신호 조작, 검색 트래픽 생성, 운영자 계정 묶음 운영, 리셀러 API·암호화폐 충전. **외부 프로그램 개발분석표 §4 「공통으로 하지 않기로 한 것」에 「참여·리뷰·구매 신호 인위 조작(SMM 패널형)」으로 올릴 것을 제안** |

## 7. 판단 제안

| 선택지 | 판단 |
|---|---|
| 기존 프로그램에 병합 | **하지 않음** — 병합할 「좋은 기능」이 조작 행위 자체라 가져올 것이 없다. 화면 아이디어(§6 ①~④)만 각 담당 세션이 필요할 때 참고 |
| 쇼핑몰 홍보 묶음에 포함 | **하지 않음** — 판매자가 쓰면 플랫폼 제재·법적 책임이 판매자에게 돌아온다. 쇼핑몰 홍보 묶음에는 오히려 「사지 말아야 할 것」 안내로 한 줄 넣는 것을 권장 |
| 제외 | **추천 — 제외.** 외부 프로그램 개발분석표에 카드 1장(「결정: 제외, 사유: 플랫폼 정책·표시광고 위반, 최상위 규칙과 반대 구조」)과 §4 금지 항목 1줄을 추가하는 것으로 마무리 |

- 남은 결정(주인님): 개발분석표 §4에 「SMM 패널형 수치 조작은 다시 제안하지 않음」을 공식 항목으로 둘지 여부.
