### AI 숏폼(v0.3.3) 핵심 동작
- 상품 자료: 상품 주소 직접 수집 / 크롬 확장 → 클립보드로 앱에 전달 / 사진+상품명·설명·가격혜택 직접 입력. 처음 1회 권리·사실확인 동의.

- 렌더: AI가 장면 기획(훅·고민·장점·근거·혜택) + **HTML 모션 코드** → 화면 밖 WebView 캡처(CDP) → WebCodecs H.264 1080×1920 MP4.
- 소리: Supertone `supertonic-3` 내 PC 음성 10종(우리 원스톱 v1.42와 같은 모델), 내레이션 자막 5종(단어 색·팝·박스 강조·한 단어씩 크게·차례로), CC0 배경음악 8곡 + 내 음악, 효과음(whoosh·pop·impact·chime·cash·typing 등)을 **배경음악 박자에 맞춰** 배치.

## 3. 할 일 (추천안 — 착수 전 주인님 결정)

### M3-① 광고 고지·AI 표기·안전 영역 (원스톱, **가장 먼저** — 법적 위험)
- 광고 고지 켜기 + 종류 3개(쿠팡파트너스 / 제휴 링크 수수료 / 협찬·제품 제공) + 직접 입력. 켜면 영상 처음부터 끝까지 위쪽에 표시. 문구는 우리가 공정위 「추천·보증 등에 관한 표시·광고 심사지침」 기준으로 새로 쓴다.
- AI 제작 표기(기본 켬) — 무료 음성 사용 시 합성음 표기는 끄지 못하게(OpenRAIL-M 조건 재확인). MP4 메타데이터 메모는 `browser-mp4-encoder`에 선택값으로 넣을 수 있는지 검토(공용이면 기준만 고치고 `--sync`).
- 미리보기에 플랫폼 버튼 겹침 안전 영역 겹쳐 보기(이미 세이프에어리어가 있으면 확장).
- 유튜브 업로드 때 제목/설명 첫 줄에 같은 고지 자동 삽입 + 「게시 전 확인」 체크 목록.

### M2 사진→상품 영상·상세페이지 움짤 (키·AI 없음) — 위치 추천 `video-to-gif`
- 새 탭 「🛍 상품 사진 영상」: 사진 1~6장(순서 바꾸기), 템포 3종, 카메라 무빙·전환(**우리 디자인으로 이름·종류 새로 정함**), 문구 3층, 9:16/1:1, MP4(`browser-mp4-encoder` 사본) / 애니메이션 WebP(10MB 이내, 기존 8MiB 사다리 방식 재사용·확장).
- 음악: `/fms-bgm` 또는 CC0만 기본 제공, 내 음악은 「상업 이용 조건 확인」 안내.
- 여러 상품: 파일 이름 `상품코드_1~6`으로 묶어 하나씩 순서대로 생성(동시 처리 금지·중단 버튼·실패만 다시).
- 결과: 상품코드 이름 ZIP, 「🛍 상세페이지로」 기존 연결 재사용.
- 브라우저만으로 안 되는 것(WebP 애니메이션 인코딩 등)은 사전 검증 페이지로 먼저 확인 → 안 되면 로컬 렌더러 명령으로.

### M3-② 원스톱 「상품 숏폼」 고도화
1. 모션 템플릿 4종 신규(우리 디자인). **AI는 JSON 장면 기획만**(훅·고민·장점·근거·혜택 + 장면별 문구·사진 id·길이·효과음 이름) → 우리 캔버스 템플릿이 그린다. AI가 쓴 HTML/JS 실행은 하지 않는다.
2. 단어 강조 자막 3~5종(지금 문장 길이 기반 시각 → 낱말 단위 추정으로 확장. `whisper-1` 종료 대비 계획 `docs/PLAN_20261111_WORD_TIMING_AFTER_WHISPER.md`와 맞춤).
3. 효과음 라이브러리(CC0만, 출처·라이선스 표 `NOTICE`에) + 장면 전환에 배경음악 박자 맞춰 자동 배치.
4. 다시 설계 없이 고치기(문구·자막·사진·음악·목소리 즉시 반영) + 버전 기록·되돌리기.
5. AI 결과 검증(글자 수·장면 수·사진 id·사실 문구가 입력에 있는지) → 어기면 **재작성 1회까지**(회원 키 이중 과금 방지, 그래도 어기면 사람이 고치도록 표시).
6. 가격·평점·리뷰 수는 입력에 있을 때만 쓰도록 시스템 지시(지어내기 금지).
- AI 엔진: 회원 본인 키, 기본 Claude(최상위 규칙). 시험은 시험 계정 키 + Haiku 5.5 최소 횟수.
