## 2. 상세

### V1 — 긴 영상 → 쇼츠 (`ai-video-studio`)
- alphacut이 실제로 하는 것(공개 범위 확인, [09](09_ALPHACUT.md) §2): 유튜브 링크·파일 → AI 하이라이트 구간 선택 → 단어 단위 자막·SRT → 제목·템플릿 → 세로 쇼츠 여러 편(원본 2분당 약 1편), 무음 제거·화자 추적(Pro), 롱폼 컷편집, 5개 SNS 예약 업로드, Premiere·DaVinci·Final Cut 파일 내보내기. 음성 인식은 WhisperX·ElevenLabs Scribe 선택 흔적, 처리는 서버 렌더(운영자 키·분 이용권).
- **우리 방식**: 회원 본인 파일만 → 회원 본인 키 받아쓰기(공용 텍스트 AI/음성 인식 공급자) → LLM 구간 선택(점수·이유 표시, 회원이 고침) → 무음 제거 → **브라우저 렌더**(공용 `browser-mp4-encoder`·영상 합치기 엔진) → SRT·MP4. 화자 추적 세로 재구성은 2단계(얼굴·사람 감지 브라우저 모델).
- **하지 않음**: 남의 유튜브 링크를 서버가 내려받기, 가상 댓글 쇼츠(후기 조작), 운영자 키·공용 OAuth.
- 첫 단계: **사전 검증 페이지 1회**(받아쓰기 → 구간 선택 품질, 시험 계정 본인 키, 수십 원 — 실행 전 주인님께 보고).

### V2 — 내 소재 다시 편집 (본인 사용판)
- mixxxi가 판매 페이지에 내세운 기능 중 **회원 본인 소재일 때만 의미 있는 것**만([11](11_MIXXXI.md) §6): ① 5개 언어판(번역 대본 + 목소리) ② 롱폼 → 하이라이트(V1 엔진 재사용) ③ 해설 교차편집(내 해설 녹음 + 내 촬영본 컷 교차) ④ 각색 강도 슬라이더(대본 다시 쓰기 정도) ⑤ 캡컷 내보내기(프로젝트 파일 또는 컷 목록).
- 공통 장치(§0) 필수. 「똑같은 영상 없음」 식 픽셀 변형·대량 양산 루프는 넣지 않음.

### V3 — 상품 홍보 쇼츠 (`shorts-onestop-studio`)
- 구성: 15초 6비트(결과 먼저 → 비포 → 제품 → 시연 → 결과 → 루프, `product-shorts-studio` 구성 참고 — 문장은 새로 작성) · 4단 대본·CTA(prohubstart 설명 화면 아이디어) · 제품 외형 일치 점검(생성 장면이 실제 상품과 다르면 경고).
- **넘기기(받는 쪽)**: 이커머스 담당이 `shop-detail-page`에 「쇼츠로 만들기」 버튼을 만든다(E9). 영상 담당은 **받는 화면과 값 형식**(상품명·핵심 문구 3개·대표 사진 주소·상세 이미지 주소, 길이 제한)을 정해 이커머스 담당과 맞춘다 — 기존 `trending-product-finder/lib/shopDetailLink.ts` 방식(주소로 짧은 값만, 도매가·원가는 넘기지 않음) 그대로.
- 하지 않음: 「과장 200%」·품절 대란식 대본(허위·과장 광고), 남의 상세 사진 수집, 출처 불명 기본 목소리.

### V4 — 화면 녹화 → GIF (`video-to-gif`)
- `getDisplayMedia` → 영역 지정 → 최대 15초 → GIF(브라우저 안). 기존 GIF 변환 엔진에 「화면에서 바로 녹화」 입력 경로만 추가. PC 전용(휴대폰은 안내).

### V5 — 내 영상의 내 로고 지우기 (본인 사용판)
- 원본은 ffmpeg.wasm `delogo`·참조 영역 복사, H.264/AAC 재인코딩, 60초·100MB·1080p([05](05_KDP_WORK_TOOLS.md) §8). 우리: 같은 방식(브라우저 안) + 공통 장치(§0) + 「다른 사람의 워터마크·출처 표시·AI 생성 표시는 지우지 마세요」 안내. ffmpeg 코어 빌드 라이선스(LGPL/GPL) 확인 필요.

## 3. 독립 사용 + 유기적 연결 (주인님 D2)
- 각 기능은 **영상 프로그램 안에서 단독으로 완결**(파일 올리기부터 내려받기까지).
