## 1. 이미지 편집 도구 (`/image/`)

### 1-1. 화면 입력
- 사진 추가: 파일 선택·끌어 놓기·**Ctrl+V 캡처 붙여넣기**·「붙여넣기」 버튼(클립보드 읽기 권한). 한 번에 **최대 30장, 한 장 25MB·4천만 화소 이하**.
- 목록 썸네일(각 사진의 「원본 크기 → 출력 크기」 표시), 사진별 편집·삭제, 전체 삭제.

### 1-2. 전체 사진 공통 설정(모든 장에 한꺼번에)
| 묶음 | 기능 |
|---|---|
| 크기·모양 | **세로 크기 맞춤**(기본 800px, 1~4096px, 비율 유지 — 가로가 4096px을 넘으면 오류로 막음) · 테두리(0~100px·색) · 좌우 반전 · **랜덤 크롭**(가로·세로 1~30%를 사진마다 다른 위치로 잘라 냄, 「위치 다시 섞기」 버튼) |
| 화질·보정 | 밝기 20~200% |
| 워터마크 | 이미지 로고(출력 너비 px 지정, 투명 PNG 합성) 또는 문자(최대 60자, 글꼴·크기 2~12%·색) · 위치 9곳 · 농도 0~100% · 여백 |
| 저장 | JPG(품질 30~100%, 투명 부분 흰색) 또는 PNG · 1장은 그 파일, 여러 장은 `KDP_이미지.zip` |

### 1-3. 사진별 정밀 편집(더블클릭, 별도 묶음 `photo-editor` → `chunk-6A7FIRK3.js`)
- 도구: 선택·이동 / 자르기(자유·비율, 좌표 직접 입력) / 모자이크(거친 픽셀·부드러운 블러·랜덤 픽셀, 네모·원) / 형광펜 / 직선(실선·파선·점선) / 화살표(4종 모양·화살촉 크기·방향 뒤집기) / 사각형·원(채우기·모서리 둥글기) / 텍스트 상자(글꼴·굵게·정렬·배경·외곽선).
- 도형 안을 **이미지로 채우기**(최대 5MB, 한 사진 12개까지), 객체마다 회전·크기·불투명도, Shift로 15도·수평·수직 고정.
- 사진 전체: 90도 회전·좌우/상하 반전·미세 각도·크기 변경(비율 유지)·확대 보기.
- 실행 취소/다시 실행(**한 사진 100단계**), 원본 복원. 적용하면 결과를 PNG로 다시 만들어 목록에 넣는다(25MB 넘으면 거부).
- 글꼴: 기본 5종(고딕·명조·굴림·궁서·고정폭) + **내 PC 설치 글꼴 목록**(데스크톱 Chrome·Edge의 `queryLocalFonts`, 권한 요청) + 글꼴 파일 직접 추가(20MB 이하, `FontFace`로 이 브라우저에서만 사용).

### 1-4. 처리 방식(코드로 확인)
- 사진은 `createImageBitmap`(EXIF 회전 반영)으로 읽어 **캔버스에 다시 그린 뒤 `toBlob`으로 새로 저장** → 촬영 정보·GPS·작성자 같은 **메타정보가 자동으로 빠진다**(안내 문구 「EXIF·GPS·XMP·IPTC 제거」와 일치).
- ZIP은 브라우저 안 압축 라이브러리(fflate 계열, 웹 워커 사용)로 만든다.
- 서버 업로드 없음(§0 근거). 페이지를 닫으면 작업이 사라진다.

## 2. 사진·문서 서명 도구 (`/signature/`)

### 2-1. 화면 입력
- 파일 한 개: **사진·PDF·Word(DOCX)**, 30MB 이하, 문서는 **20페이지 이하**, 사진 1,200만 화소 이하. 암호 걸린 PDF·옛 DOC는 거부(「Word에서 DOCX나 PDF로 저장 후 가져오세요」 안내).
- 페이지 넘기기·확대·화면 맞춤.

### 2-2. 서명 만들기(3가지)
| 방식 | 내용 |
|---|---|
| 이름 입력 | 40자 이하, 한글 손글씨 글꼴 2종(「감자꽃·손글씨」, 「나눔손글씨 펜」 — 사이트 자체 보관 글꼴) |
| 직접 쓰기 | 마우스·터치·펜 입력(`pointer` 이벤트), 펜 두께, 한 획 취소·다시 쓰기 |
| 이미지 | 10MB 이하 서명 사진, **「흰 배경을 투명하게」** 처리 |
- 공통: 서명 색상, 「선택 서명을 이 스타일로 바꾸기」.

### 2-3. 배치·조절
- 드래그 이동, 모서리 크기 조절, 위 손잡이 회전, 너비(페이지 대비 %)·회전·불투명도 숫자 입력, 복제·삭제(Delete), 실행 취소/다시 실행.
- **「모든 페이지 같은 위치에 복사」**(계약서 간인·각 장 서명에 해당), 한 문서 서명 **최대 100개**, 페이지별 서명 목록.

### 2-4. 저장 형식
| 형식 | 방식 |
|---|---|
| 전체 페이지 PDF | 가져온 것이 PDF면 **`pdf-lib`로 원래 페이지 위에 서명 PNG만 얹는다**(`embedPng`) — 원본 글자 보존. 사진·DOCX면 페이지 이미지를 PDF로 묶음 |
| Word(DOCX) | **페이지 전체를 이미지로 담은 DOCX**(`docx` 라이브러리 `Packer`) — 배치는 유지, 본문 편집 불가 |
| PNG·JPG | 현재 페이지 1장, 또는 전체 페이지 ZIP |

### 2-5. 처리 방식(코드로 확인)
- PDF 읽기·미리보기: **pdf.js 5.4.624**(웹 워커 + WebAssembly 디코더, 모두 `/vendor/pdf/` 자체 보관). PDF 쓰기: **pdf-lib**. DOCX 미리보기: **docx-preview**(+ JSZip로 압축 해제, 「압축을 푼 Word가 너무 크면 거부」 방어) → **html2canvas**로 페이지를 그림으로 만든다. DOCX 쓰기: **docx**.
- DOCX는 브라우저 글꼴·줄바꿈으로 다시 그리므로 원본과 다를 수 있다고 스스로 안내한다(복잡한 단 나눔·한 페이지보다 큰 표는 거부).
- **인증서 기반 전자서명·본인 인증이 아니다**(화면·FAQ에 명시). 법적 효력은 「눈에 보이는 서명 그림」 수준.
- 서버 업로드 없음(§0 근거).

## 6. 우리에게 없는 것·가져올 것·하지 않을 것

### 우리에게 없는 것
1. 사진 위 **화살표·도형·텍스트·형광펜·모자이크 주석**(상품 설명 사진·CS 안내 사진용)
2. **로고·문자 워터마크 일괄 적용**(내 상품 사진 도용 방지)
3. **여러 장 같은 높이로 맞추기**(블로그·상세페이지 이어 붙이기 전 준비)
4. **캡처 Ctrl+V 붙여넣기 입력**
5. 메타정보 제거를 **명시 기능으로** 안내(촬영 위치 노출 방지)
6. **문서 서명 전체**(사진·PDF·DOCX 위 서명 배치, 모든 페이지 같은 위치 복사, PDF 원본 위에만 얹기)

### 가져올 것(기능만, 코드는 새로 작성)
| 우선 | 기능 | 넣을 곳 | 이유 |
|---|---|---|---|
| 1 | 워터마크(로고·문자, 위치 9곳·농도·여백) 일괄 | `image-convert-studio` 일괄 변환 설정 | 이미 300장 일괄·ZIP 구조가 있어 설정 한 묶음 추가로 끝남. 셀러 사진 도용 방지 수요 큼 |
| 2 | 「세로(또는 가로) 크기 맞춤」 + 메타정보 제거 안내 | `image-convert-studio` | 기존 최대 너비·높이 제한을 「정확히 맞춤」으로 확장. 메타정보 제거는 실제로 빠지는지 먼저 검수 후 문구만 추가 |
| 3 | 캡처 붙여넣기(Ctrl+V) 입력 | `image-convert-studio`(필요하면 `shop-detail-page` 사진 입력도) | 작은 작업으로 입력 편의 큼 |
| 4 | 사진 위 주석(화살표·텍스트·도형·모자이크) 정밀 편집 | `image-convert-studio`의 새 「편집」 탭 | 상품 설명·CS 안내 사진. 범위가 커서 2단계로 |
| 5 | 문서 서명(사진·PDF 우선, DOCX는 나중) | 쇼핑몰 업무 묶음의 새 도구(또는 문서 계열 프로그램) | 거래처 계약서·발주서·견적서 확인 서명. 브라우저 처리·키 불필요라 FREE 유입용으로도 적합 |

### 하지 않을 것
- **랜덤 크롭·좌우 반전으로 같은 사진을 「다른 사진처럼」 만드는 기능** — 마켓 중복 이미지 정책 회피 도구로 쓰일 수 있음(§3 추정).
- **「법적 전자서명」·「본인 인증」처럼 보이는 표현** — 보이는 서명 그림일 뿐임을 KDP처럼 분명히 안내한다. 인증서 서명·서명 요청 메일·감사 로그는 범위 밖(필요하면 외부 전자계약 서비스 연동을 별도 검토).
- DOCX를 이미지로 만든 Word 출력 — 편집 불가 Word는 혼란만 주므로 PDF·이미지 출력으로 충분.
- 쿠팡 파트너스 광고 배너 방식 — 우리는 회원 서비스라 같은 수익 구조를 쓰지 않는다.
- WebMCP 상태 도구 등록 — 지금 필요 없음.

## 7. 판단 제안

| 원본 | 제안 | 근거 |
|---|---|---|
| **KDP 이미지 편집** | **기존 프로그램 병합 — `image-convert-studio`에 기능 추가**(1~3순위 먼저, 4순위 주석 편집은 다음 단계) | 같은 「브라우저 처리·키 불필요·일괄·ZIP」 구조라 겹치는 부분이 많고, 우리에게 없는 것은 워터마크·주석·높이 맞춤·붙여넣기뿐. 새 프로그램을 만들 이유가 없다. 쇼핑몰 묶음에는 「상품 사진 준비 단계(②)」 바로가기로 연결 |
| **KDP 사진·문서 서명** | **쇼핑몰 업무 묶음에 새 도구로 넣기**(사진·PDF 서명부터) | 비슷한 우리 프로그램이 없고, 이미지 프로그램에 넣기에는 성격(문서·계약)이 다르다. 거래처 계약서·발주서·견적서 서명은 쇼핑몰 운영 ⑤단계(판매 후·거래처 관리) 업무. 브라우저 처리라 운영 비용·회원 키가 필요 없다 |

- 공통 조건: 코드는 옮기지 않고 새로 만든다(`pdf-lib`·`pdfjs-dist`는 공개 라이브러리로 직접 사용). 작업 전 개발 플랜·비용(빌드 1회 이상) 사전 보고 규칙을 따른다. 결정은 주인님이 한다.
