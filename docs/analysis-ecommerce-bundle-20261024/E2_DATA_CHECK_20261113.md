## 2. 없는 자료·막힌 자료

| 자료 | 상태 | 근거 |
|---|---|---|
| 네이버 쇼핑 검색 API(경쟁 상품 수·검색 결과 목록) | **종료, 공식 대체 없음** | `trending-product-finder/AGENTS.md` 「네이버 API 발급 경로 변경 이력」(2026-08-31 기록) |
| 네이버 쇼핑 자동완성·연관 태그 | API 없음(화면에서만 보임) | 확장으로 읽으려면 권한·약관 검토 필요 → 이번 범위 밖 |
| 쿠팡 검색 결과 API | 없음(확장 화면 읽기만, 2026-11-01 지정 범위 = 상품명·가격·리뷰 수·주소) | `docs/TOP_RULE_PERSONAL_ACCOUNT_API.md` §8 |
| 표본의 카테고리 경로 | 지금 안 읽음 | `parse.js` |
| 소싱 → 상세 → 등록기 사이의 키워드·태그 전달 칸 | 없음(이름·원본 정보·가격만) | `trending-product-finder/lib/shopDetailLink.ts`, `shop_products`에 태그 칸 없음 |

**외부 현황은 다시 확인하지 않았다.** 위 종료·발급 경로는 저장소 기록(2026-08-31) 기준이고 30일이 넘었다 — E2-1을 시작하기 전에 공식 문서(검색광고 API·NAVER API HUB)를 다시 확인하고, 회원 본인 키로 1회 호출해 응답 칸을 대조해야 한다(무료 호출, 시험 계정 본인 키).

## 3. E2에서 「근거」로 쓸 수 있는 조합(판정)

| 기능 | 자료 | AI | 지금 가능한가 |
|---|---|---|---|
| 많이 쓰인 낱말·가격 분포·광고 비율 카드 | 이미 모은 검색 표본 | 0 | **가능**(확장 변경 없음, 브라우저 계산) |
| 연관 키워드·검색수 표 | 검색광고 키워드도구(회원 키) | 0 | **가능**(기존 함수 재사용, 키 없는 회원은 등록 안내) |
| 카테고리 분포 | 표본의 카테고리 경로 | 0 | **확장 수정 필요**(한 칸 더 읽기 → 확장 새 버전·ZIP·DB) |
| 상품명·태그 초안 | 위 낱말·연관어 + 상품 정보 | 회원 본인 Claude 1회(선택, 비용 안내·회원이 켬, 재시도 0) | 새 연결 필요(`anthropic` provider, 구조화 응답) |
| 초안 검사(길이·금지어·상표·중복·광고 문구) | 규칙표 | 0 | 태그 길이 검사만 있음 → 규칙표 작성 필요 |
| 등록기까지 넘기기 | — | 0 | 전달 칸·DB 칸 결정 필요 |

## 4. 다음 단계 제안(각각 별도 플랜·결정)

1. **E2-1(추천 첫 구현, AI 0·확장 변경 0)**: 소싱 결과 화면에 「많이 쓰인 낱말·가격 분포·광고 비율」 카드 + 「연관 키워드·검색수」 표(회원 검색광고 키). 표본 크기·조사 시각·광고 포함 여부를 함께 표시.
2. E2-2: 상품명·태그 초안(회원 본인 Claude, 선택) + 규칙 검사.
3. E2-3: 확장 카테고리 경로 읽기(확장 새 버전) → 분포 카드.
4. E2-4: 소싱 → 상세 → 등록기 전달 칸(DB 결정).

## 5. 지킬 것
- 회원 본인 키만(검색광고·Claude). 운영자 키 폴백 없음, 키가 없으면 등록 안내.
- 표본은 회원 본인 소유·30일. 마켓별 분류 ID를 하나로 합치지 않는다. 표본 크기·조사 시각 없는 수치는 보여 주지 않는다.
- 네이버 쇼핑 자동 검색·수집 보류는 그대로. 확장으로 마켓 사진 받기는 하지 않음(주인님 결정 1).
- 소싱 폴더(`trending-product-finder/`) 작업 전 작업 중 표와 `claude-win-sdp`(이커머스 담당) 확인.
