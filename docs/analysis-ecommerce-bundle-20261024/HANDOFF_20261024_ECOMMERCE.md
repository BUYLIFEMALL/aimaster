## 2. E0 — 수수료 참고표 재확인 (긴급, 회원 영향)
- ✅ **처리됨 2026-10-25 (`claude-win-sdp`, 상품소싱 v1.26, 커밋 `861260d60`)**: G마켓·옥션 ESM 공식 표 값 교체, 쿠팡·11번가·스마트스토어는 공식 미확인 표시+확인 경로(11번가 숫자 삭제). 판매자 센터 로그인 대조는 주인님 확인 대기. 상세 `trending-product-finder/AGENTS.md` v1.26.
- **문제**: `/fees` 참고표(쿠팡 14행·스마트스토어 등급 5행·11번가/옥션/G마켓 대분류 9행, `OPENMARKET_HEADERS = ["카테고리","11번가","옥션","G마켓"]` 37행)의 11번가·ESM 값이 KDP 계산기 내장 표와 크게 다르다. 우리 표는 「옥션·G마켓 동일」로 적었으나 KDP 표는 **31개 카테고리가 다르다**(근거 [01](01_KDP_MARKET_FEES.md) §5 215행·「지마켓 vs 옥션 차이」 116행). 스마트스토어 등급 요율도 KDP(1.947~3.63%)와 우리(1.87~3.74%)가 다름 — 부가세 포함 여부 차이일 수 있음.
- **할 일**: 마켓 공식 판매자 안내(11번가 셀러오피스·ESM PLUS·쿠팡 WING·스마트스토어 센터 공지)로 각 값을 확인 → 표 수정 + **표마다 「기준 날짜·부가세 포함 여부·출처(공식 안내 이름)」 표시** + 「실제 요율은 판매자 센터에서 다시 확인하세요」 안내. KDP 값은 대조용으로만(복사 금지).
- 회원에게 잘못된 숫자가 보이는 문제이므로 **배포 규칙상 즉시 배포 대상**(빌드 1회 사전 승인).

## 3. E1 — 마켓별 정산 공식 (상품소싱 마진 계산 확장)
- **지금**: `lib/margin.ts` `calcMargin()`(31행)·`MARGIN_DEFAULTS`(48행)·`DOMESTIC_MARGIN_DEFAULTS`(64행) — 관세·부가세·해외운송·원가 자동 입력·일괄 CSV가 강점, 수수료는 한 칸 입력. 수수료표와 계산기가 연결되지 않음.
- **넣을 것**(근거 [01](01_KDP_MARKET_FEES.md) §1~4·§8): ① 마켓 선택(11번가·스마트스토어·지마켓·옥션·쿠팡·로켓그로스) ② 카테고리 고르면 요율 자동(E0에서 만든 표 사용, 한 파일 `lib/marketFees.ts`로 모아 화면·계산 공용) ③ 마켓별 규칙: 11번가 쿠폰 판매자 부담 20%(판매 수수료 상한)·제휴 2%·선결제 배송 3.3%·전월 500만 원 이상 월 서버비 · 지마켓/옥션 판매자 할인·제휴 2%·프로모션 3%·월 서버비 · 스마트스토어 등급 기본요율+유입 1%/3%+쇼핑커넥트 · 쿠팡 유료배송 3.3% · 배송 방식 3종(무료·선결제·착불) ④ 로켓그로스: 사이즈 6단계·입출고·배송·보관(무료 30/45/60일)·반품·반출·바코드 등 12항목 ⑤ 여러 마켓 이익 나란히 + 손익분기점 + 포장비 칸(prohubstart 마진 아이디어 [06]) ⑥ 일괄 CSV에 마켓 열.
- 요율 숫자는 **반드시 공식 안내로**, 표에 기준 날짜. 요율 상수는 한 파일에서만.
