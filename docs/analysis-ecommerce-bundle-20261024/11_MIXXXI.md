## 4. 장단점·위험

### 장점(주장 기준)

- 소재 발굴 → 원본 확보 → 자막 제거 → 대본 → 편집 → 다국어 → 다작이 **한 프로그램**에 있다는 점이 강한 판매 포인트.
- 「해설 자동 교차편집」(내 내레이션과 원본 장면을 번갈아 붙이고 장면별 자막)·「롱폼 하이라이트 추출」·「5개 언어 문화 각색」은 우리에게 없는 편집 자동화 아이디어.
- 캡컷 타임라인 내보내기로 「자동 + 손편집」을 이어 준다.
- 설치형이라 영상 처리 비용이 사용자 PC에서 끝난다(서버 비용 없음).

| 구분 | 내용 |

이커머스 기능 표(`docs/ECOMMERCE_FEATURE_MATRIX.md`) 기준으로는 **「홍보(쇼츠·인스타 판매 전환)」 단계**에 해당한다. 소싱·상세페이지·고객 관리(주문·CS) 기능은 없다(DM 자동응대만 고객 응대에 걸침).

## 6. 가져올 것·하지 않을 것

### 가져올 것(기능 아이디어만, 회원 본인 소재 전제)

1. **해설 교차편집 틀** — 「회원 본인이 올린 상품 영상·이미지 장면 ↔ 회원 내레이션 ↔ 장면별 자막」을 번갈아 자동 배치. 기준 코드는 우리 공용 `video-edit-*`(AI 영상 스튜디오)·`shorts-onestop-studio`. 쇼핑 리뷰 쇼츠에 바로 쓰임.
2. **다국어 판(5개 언어) 자동 생성** — 완성한 내 쇼츠의 대본을 번역·현지화하고 TTS·자막을 언어별로 다시 입혀 여러 판을 내보내기. 해외 판매(아마존 등) 회원에 유용.
3. **롱폼 → 하이라이트 구간 후보** — 회원 본인 라이브커머스·리뷰 롱폼에서 말소리·반응이 큰 구간을 골라 쇼츠 후보로. 처리 위치는 브라우저 또는 회원 키.
4. **각색 강도 슬라이더** — 대본 생성 시 「원문 충실 ↔ 자유 창작」 정도를 회원이 고르게(우리 대본 도구에 작은 추가).
5. **캡컷으로 내보내기** — 자동 결과를 손편집 도구로 넘기는 출구(형식 조사 필요).
6. **노래 쇼츠(TTS → 노래)** — 음악 담당 세션 검토 후보.
7. 쇼핑 회원용 **멀티링크 페이지** — 인스타 프로필 링크 한 곳에 상품 여러 개(별도 아이디어 표 등록 후보).

### 하지 않을 것

- 남의 영상 다운로드·원본 짜깁기·**자막/워터마크 제거**·**탐지 회피용 픽셀 변형**·「하루 100편」 양산 루프 — 저작권·플랫폼 약관·최상위 규칙(회원 본인 계정 보호) 위험.
- 제3자 DM 대행 서비스 경유 — 우리는 회원 본인 Meta 앱·계정 연동(`instagram-comment-reply`)을 유지.
- 매달 리셋되는 가짜 마감 카운트다운, 다운로드 즉시 환불 불가 같은 판매 방식.
- 윈도우 설치형으로의 전환(우리는 웹 + 브라우저 처리 기본).

## 7. 판단 제안

- **판단: 새 프로그램으로 만들지 않음 · 병합 대상 아님 · 기능 아이디어만 기존 영상/쇼츠 프로그램 후보로 등록.** 믹시의 중심 가치(남의 바이럴 원본 재가공 양산)는 우리 원칙과 정면으로 맞지 않는다. 반면 「해설 교차편집」·「다국어 판 생성」·「롱폼 하이라이트」·「각색 강도」·「캡컷 내보내기」는 **회원 본인 소재**로 바꾸면 쓸 만하다.
- 적용 대상 후보: `shorts-onestop-studio`(다국어 판·각색 강도), AI 영상 스튜디오 공용 편집(`video-edit-*`, 교차편집·하이라이트), 쇼핑 쇼츠 기획(07·12번 문서와 묶어 「내 상품 영상 → 리뷰 해설 쇼츠」).
- 다음 단계: 개발분석표 `docs/EXTERNAL_PROGRAM_ANALYSIS_REGISTRY.md`에 카드 1장 추가(영상·쇼츠 분류, 「하지 않을 것」에 원본 다운로드·자막 제거·탐지 회피 변형 명시)와 공통 아이디어 표 등록은 담당 세션이 처리. 실제 프로그램 동작 검증이 필요하면 구매가 필요하므로(연 126만 원) 주인님 판단 사항.
