### 6-3. 하지 않을 것

- **남의 유튜브 링크를 받아 서버가 영상을 내려받는 기능** — 유튜브 약관·저작권 위험, 회원 본인 파일만 받는다.

- **운영자 키·운영자 공용 OAuth 앱으로 처리하고 분 단위로 파는 구조** — 최상위 규칙(회원 본인 계정·본인 키) 위반.
- **서버 GPU 렌더·자체 STT 서버(WhisperX 운영)** — 운영자 인프라 비용·Vercel 300초 제한. 렌더는 브라우저·내 PC로 한다.
- 「바이럴 확률 73% 증가」 같은 검증 안 된 효과 문구.
- 광고 픽셀 대량 삽입.

**권장 진행 순서(모두 주인님 승인 뒤)**
1. **사전 검증 페이지**(저장소 밖 임시 폴더, 내 PC 전용 주소): 10분짜리 시험 영상 1개로 ① 브라우저 음성 추출 ② 본인 키 받아쓰기 1회 ③ LLM 구간 선택 1회 ④ 무음 제거 컷 ⑤ 브라우저 렌더까지 되는지·품질만 확인. 예상 비용: 시험 계정 본인 키 받아쓰기 10분 + LLM 1~2회(수십 원 수준, 실행 전 다시 보고).
2. 결과가 좋으면 `ai-video-studio` 확장 플랜(`docs/PLAN_YYYYMMDD_*.md`) 작성 → 영상 담당 세션이 구현.
3. 여러 SNS 예약(E)은 TikTok·Facebook이 새 연동이라 별도 플랜(회원 본인 앱 등록·심사 필요 여부 먼저 조사).
4. [외부 프로그램 개발분석표](../EXTERNAL_PROGRAM_ANALYSIS_REGISTRY.md)에 이 카드 한 줄 추가(이 문서는 분석 보조 작업이라 등록은 담당 세션이 함).
