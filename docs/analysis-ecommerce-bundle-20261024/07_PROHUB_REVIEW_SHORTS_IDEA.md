## 1. 리뷰 수집기 (`/review_collector`)

- **입력**: 상품명, 카테고리 6종, 수집 기간(7일~1년), 수집 마켓 9곳(스마트스토어·쿠팡·G마켓·옥션·11번가·위메프·티몬·인터파크·롯데온).
- **처리(표방)**: 「마켓별 리뷰를 자동 수집하고 키워드·감성을 AI로 분석」. **실제**: 수집 없음(서버·브라우저 수집 모두 없음). 고정 리뷰 15건으로 총 리뷰 수·평균 별점·긍정/부정 비율·수집 마켓 수 계산, 키워드 빈도 상위 10개 막대, 마켓별 분포 막대, 리뷰 카드 목록.
- **출력**: 화면 + `리뷰수집결과.csv`(마켓·별점·리뷰·키워드·감성, BOM 포함 한글 CSV).
- **AI·키**: 없음. **요금·로그인**: 없음. **외부 통신**: 없음.
- **쓸 만한 아이디어**: 리뷰 대시보드 구성(별점 평균·감성 막대·키워드 빈도·마켓 분포·부정 키워드 빨간 표시·CSV 내보내기). 「상품 개선 포인트(부정 키워드)」를 상세페이지·FAQ로 넘기는 흐름의 출발점이 될 수 있다.
- **위험**: 실제로 만들려면 마켓별 리뷰 수집이 문제 — 대부분 공식 리뷰 API가 없고(판매자 본인 상품은 각 마켓 판매자센터 기능 범위), 남의 상품 리뷰 대량 수집은 이용약관·봇 탐지 위험(우리 지침 `PLATFORM_PATTERNS.md` §20). 위메프·티몬은 영업 상태부터 확인 필요.

## 13. 우리에게 없는 것 · 가져올 것 · 하지 않을 것

**가져올 것(아이디어·화면 구성만, 실제 기능은 새로 설계)**
1. **쇼핑 쇼츠 전용 흐름** — 상품 주소/상세 정보 → 4단 대본(후킹·공감·스펙·CTA, 초 단위·글자 수 표시) → TTS 배속 → 자막 → 썸네일 문구 → 제휴 링크 고정 댓글/프로필 문구. 영상 소재는 **회원 본인 촬영·본인 상품 사진·AI 생성 장면**만.
2. **CapCut(또는 일반 편집기)용 초벌 묶음 내보내기** — 장면 영상 + 나레이션 + SRT를 ZIP으로.
3. **리뷰 인사이트 대시보드** — 회원이 **본인 판매자센터에서 내려받은 리뷰 파일을 올리거나 붙여 넣으면** 별점·감성·키워드·부정 포인트를 정리하고 상세페이지 FAQ·개선점으로 넘김(수집이 아니라 업로드 방식).
4. 이메일 **수신 동의 구독 폼** + 동의 일자 기록 + 수신거부 링크·(광고) 표시 자동 처리(우리 `stepmail`에 있는지 먼저 확인).
5. 해시태그 **인기/중간/니치 3단 표시**, 아이디어 카드의 유형·난이도 표시, 「48시간 CTR 확인 후 교체」 안내 문구.
6. **통합 콘텐츠 달력** — 회원의 여러 프로그램 예약 글(쓰레드·인스타 등)을 읽기 전용으로 한 달력에 모아 보기(각 프로그램 예약 표를 회원 본인 것만 조회).

**하지 않을 것**
- 남의 영상을 받아 반전·배속으로 **중복 판정을 피해 재업로드**(저작권·플랫폼 정책).
- 남의 상품 리뷰를 서버가 대량 수집(약관·봇 탐지, 지침 §20).
- **오픈채팅방 목록 수집·재배포**, 오픈채팅 대량 홍보(카카오 운영정책 스팸).
- 무작위 숫자를 진짜 분석처럼 보여 주는 화면, 「승률 96%」「도달 100%」 같은 근거 없는 수치.
- 운영자 공용 메일 서버로 회원 메일 발송(최상위 규칙 — 회원 본인 계정·키).
