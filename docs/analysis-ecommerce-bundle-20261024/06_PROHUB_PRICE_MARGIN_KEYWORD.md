## 1. 상품 가격 비교 모니터링 (`price_monitor`) — 시연

- **화면 문구**: 「경쟁사 가격을 실시간 추적하고 최저가·시세 트렌드를 분석합니다」, 배지 「챌린지 & 쇼핑몰 자동화」
- **입력**: 상품명, 내 판매가(원), 모니터링 기간(7·30·90일) → 「📡 가격 모니터링 시작」
- **처리**: 코드 안 고정 배열(스마트스토어·쿠팡·G마켓·옥션·11번가·위메프·티몬·인터파크·롯데온 — 판매가·배송비·리뷰 수)로 계산. 총가격 = 판매가 + 배송비. 최저·최고·평균·편차, 「내 가격 순위」 = 내 가격보다 싼 마켓 수 + 1. 내 가격 ≤ 평균이면 「양호」, 아니면 「주의」.
  - 상품명·기간 입력은 **무시**됨(어떤 상품을 넣어도 같은 결과).
  - 「30일 가격 추이」는 평균가 ±10% 난수 막대 30개.
  - 조회 주기·알림·서버 수집·브라우저 수집 **모두 없음**. 이미 서비스가 끝난 위메프·티몬도 목록에 남아 있음.
- **출력**: 요약 카드 5개, 마켓 순위 표(총가격 순), 추이 막대그래프.
- **AI·키**: 없음. **요금·로그인**: 없음. **외부 통신**: 없음.
- **장점(아이디어)**: 「배송비 포함 총가격」 기준 순위, 내 가격 위치 한 줄 판정, 평균 대비 색 구분.
- **단점**: 실제 수집이 없어 업무에 쓸 수 없음. 실시간이라는 표현과 실제 동작이 다름.

## 2. 셀러 마진 계산기 Pro (`seller_margin_calc`) — 실제 동작(단순)

탭 4개: 마진 계산기 / 손익분기점 / 경쟁가 비교 / 계산 이력.

- **입력(마진)**: 상품명, 원가(매입가), 판매가, 판매자 부담 배송비, 포장비, 1건당 광고비.
- **처리(공식)** — 마켓마다:
  - 수수료 = 판매가 × 마켓 수수료율(코드 고정: 스마트스토어 5.0·쿠팡 10.8·11번가 8.0·G마켓 12.0·옥션 12.0·인터파크 10.0·카카오쇼핑 8.5·롯데ON 9.0·위메프 9.5 %, 주석 「2024~2026 기준」)
  - 정산액 = 판매가 − 수수료, 순이익 = 정산액 − (원가 + 배송비 + 포장비 + 광고비), 마진율 = 순이익 ÷ 판매가
  - **부가세·카테고리별 수수료·결제수수료·반품률·쿠폰은 반영하지 않음.** 9개 마켓 평균 순이익·평균 마진율·최고 수익 마켓 표시.
- **손익분기점**: 월 고정비 ÷ 1개당 순이익 = BEP 수량(올림), BEP 매출 = BEP × 판매가, 현재 판매량 달성률. 마진 탭의 최고 수익 마켓 순이익이 자동으로 들어감.
- **경쟁가 비교**: 5개 마켓 가격과 내 판매가를 **직접 입력** → 최저·평균 대비, 평균보다 비싸면 「평균 3% 할인가」 추천(수집 없음).
- **계산 이력·CSV**: 메모리 배열에만 쌓고 CSV(BOM 포함) 내려받기. 새로고침하면 사라짐.
- **AI·키·요금·외부 통신**: 없음.
- **장점**: 9개 마켓을 **한 표에 나란히** 보여 줌, BEP 탭과 자동 연결, CSV.
- **단점**: 수수료가 마켓당 한 숫자뿐(실제는 카테고리마다 다름), 부가세·관세 없음, 이력 저장 안 됨.

## 3. 상품 키워드 분석기 Pro (`keyword_analyzer`) — 시연

탭 4개: 키워드 개요 / 연관 키워드 / 실시간 트렌드 / 상품명 생성.

- **입력**: 키워드 1개.
- **처리**: 코드 안 사전에 3개 키워드(쏘팔메토·오메가3·루테인)만 월간 검색량·경쟁 강도·CPC·추천 점수·카테고리·연관 키워드 10개를 박아 둠. **그 밖의 키워드는 검색량(2만~10만)·경쟁도·CPC·점수가 난수**이고(난수는 페이지를 열 때 한 번만 뽑아 모든 미등록 키워드에 같은 값), 연관 키워드는 건기식 이름 15개 중 10개를 그대로 붙임. 「실시간 트렌드 TOP 15」는 고정 목록 + 난수 증감률.
  - 네이버 검색광고 API·데이터랩·쇼핑인사이트 등 **데이터 출처가 전혀 없음**.
- **출력**: 지표 4개, 연관 키워드 표·키워드 클라우드(누르면 그 키워드로 재분석), 트렌드 목록, 상품명 후보 5개(「[인기순위1위]」「식약처인증」「최저가」 같은 고정 꾸밈말을 붙인 템플릿, 눌러서 복사).
- **AI·키·요금·외부 통신**: 없음.
- **장점(아이디어)**: 개요→연관→트렌드→상품명으로 이어지는 화면 흐름, 키워드 클라우드 클릭 재분석.
- **단점**: 수치가 지어낸 값. 상품명 템플릿의 「인기순위1위」「식약처인증」은 근거 없이 붙이면 표시광고·건강기능식품 광고 규정 위험.

- **단점**: 실데이터 없음. 「자동」「실시간」 표현과 실제 동작이 다름.

## 6. AI 상품 카피라이팅 생성기 (`product_copy_generator`) — 시연(고정 템플릿)

- **입력**: 상품명, 카테고리(6종 — 결과에 거의 안 쓰임), 핵심 키워드(쉼표), 가격, 혜택/프로모션, 타겟 고객, 특장점(자유 기술), 톤 5종(프리미엄·긴급/할인·건강/신뢰·친근한·데이터형).
- **처리**: AI 호출이 아니라 입력값을 정해진 문장에 끼워 넣는 템플릿. 페이지를 열면 기본값으로 한 번 자동 생성.
- **출력 종류**: 톤별 상품명 3개 / 상세페이지 본문(입력 나열 + 「※ 식약처 인증 건강기능식품입니다」 고정 문구) / SNS 홍보 문구 2종(해시태그 포함) / **「자연스러운 구매 후기 예시」**(별 5개 후기를 지어냄). 각 블록 복사 버튼.
  - **마켓별 글자 수 제한·금지어·과장광고 필터 없음.** 오히려 「데이터형」 톤은 「누적판매 50,000개」「만족도 97.2%」「임상시험 결과 개선 효과 89%」「3,847명이 선택」「재구매율 92%」를 근거 없이 넣고, 「긴급/할인」은 「한정수량」「오늘만」「재입고」를, 「건강/신뢰」는 「[임상검증]」을 넣음.
- **AI·키·요금·외부 통신**: 없음(화면은 「AI」라고 표기).
- **장점(아이디어)**: 톤 선택, 결과 블록별 복사, 상품명·본문·SNS를 한 번에.
- **단점(위험)**: 지어낸 판매량·만족도·임상 수치·가짜 후기는 표시광고법·전자상거래법상 기만 광고, 건강기능식품은 별도 광고 규정 위반 소지가 크다. **우리 쪽에서 절대 따라 하지 않을 기능**이다.

## 8. 우리에게 없는 것 · 가져올 것 · 하지 않을 것

### 가져올 것(후보 — 구현은 주인님 결정 뒤)
1. **마켓별 수수료 나란히 비교** → `trending-product-finder` 마진 계산기에 「마켓별 비교」 보기 추가. 우리에게는 이미 **카테고리별 수수료 참고 화면** `app/(dashboard)/fees/page.tsx`(쿠팡 카테고리별, 스마트스토어 매출 구간별, 11번가·옥션·G마켓 카테고리 표)가 있으므로, 새 수수료표를 만들지 말고 그 표 값을 계산기에서 불러 마켓별로 나란히 계산하면 된다(지금은 참고 링크만 있고 계산은 한 칸 입력). 확인 날짜를 보여 주고 회원이 고칠 수 있게. (원본처럼 부가세·결제수수료를 빼먹지 않도록 우리 `calcMargin` 공식을 그대로 재사용)
2. **포장비 칸·손익분기점(BEP) 계산** → 같은 마진 화면에 작은 탭으로. 순수 계산이라 AI·비용 없음.
3. **판매처 경쟁가 위치(내 가격 순위)** → 단, 실제 수집이 필요. 네이버 쇼핑 검색 API(회원 본인 키, 공식) 정도가 현실적인 출처. 쿠팡 등은 공식 조회 API가 없어 화면 수집이 필요하고 봇 탐지·약관 위험이 크다 → 1단계는 네이버 쇼핑만 검토.
4. **배송·교환·환불 안내 블록** → `shop-detail-page` HTML 내보내기·섹션 템플릿에 「회원이 직접 쓰는 안내 블록」(AI가 지어내지 않음).
5. **톤 선택 + 상품명/한 줄 소개/SNS 문구 한 번에 복사** → `shop-detail-page` 분석 결과 화면의 작은 보강(회원 키 AI 1회). 마켓별 상품명 글자 수 한도(예: 스마트스토어 상품명 길이)는 확인 후 경고만.
6. **(보류) 자기 재고 소진 예측** → 마켓 주문·재고 연동(스마트스토어 커머스 API·쿠팡 Wing, 회원 본인 계정)이 먼저 있어야 함. 로드맵 3차 「판매 후 운영 분석」 기획 때 함께.

### 하지 않을 것
- 지어낸 판매량·만족도·임상 수치·구매 후기 생성(카피 생성기 「데이터형」·「후기 예시」, 편집기 기본 문구) — 허위·기만 광고 위험. 우리 v1.17·v1.18 결정과 같음.
- 근거 없는 「한정수량·오늘만·식약처인증·인기순위1위」 꾸밈말 자동 부착.
- 수집 없이 난수·고정값으로 「실시간」 그래프를 보여 주는 화면.
- 이미지 URL만 받는 수동 편집기를 새 프로그램으로 따로 만드는 것(우리 상세페이지가 이미 상위 호환).
- 종료된 마켓(위메프·티몬)을 고정 목록에 넣는 것.
