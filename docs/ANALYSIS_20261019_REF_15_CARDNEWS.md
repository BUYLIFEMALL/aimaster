# 참고 원본 분석 — `nam-ai-trend/15_cardnews` ↔ AIMaster 기존 프로그램 비교 (2026-10-19, Claude Code 윈도우)

> 주인님 요청: "이거 한번 개발해보게 기존 자동화 프로그램과 비교 분석해줘". 루트 CLAUDE.md 핵심 원칙 14(레퍼런스 전수 분석)·23(역량 지도 기준 비교)에 따라 저장소 전체(76개 파일, 마지막 커밋 c661ed0 2026-10-03)를 받아 코드·프롬프트·디자인 명세·결과물을 읽었다. **구현은 아직 하지 않았다(주인님 방향 결정 대기).** 원본 코드는 옮기지 않고 기능·동작만 참고한다(원칙 21).

## 1. 원본 프로그램 요약
- **정체**: 「RealEstate & Finance CardNews Studio」 — 부동산·재테크 주제의 인스타 떡상 콘텐츠를 모아 역분석하고 1080×1350 카드뉴스로 다시 만드는 **1인용 로컬 도구**(Node/Express + 정적 HTML, `node server.js`).
- **흐름**: ① 수집 → ② 4대 심층 분석 + 7대 떡상 관점 TOP 3 → ③ 관점·장수(4~10장) 골라 슬라이드 대본(JSON) → ④ `report.md` 저장 → ⑤ **Antigravity 채팅 스킬**(`/cardnews-creator`)이 이미지 생성 + HTML 템플릿 + Playwright 캡처로 PNG 완성.

## 3. 기존 프로그램과 비교
| 항목 | 원본 15_cardnews | cardnews-studio (v1.15) | insta_auto_poster (v1.24) | shorts-viral-studio |
|---|---|---|---|---|
| 시작점 | **떡상 콘텐츠(릴스·카드·뉴스)** | 주제 입력(AI 추천) | URL·RSS·Perplexity 주제 수집 | 떡상 쇼츠 |
| 떡상 역분석 | ✅ 음성·이미지 글자·캡션·지표 | ❌ | ❌ | ✅(영상) |
| 관점 추천 | ✅ 7대 관점 TOP 3 + 줄거리 | 어조 5종 | ❌ | 공식 분석 |
| 장수 | 4~10 가변(항목 수 기준) | 4·6·8·10 고정 선택 | 1장·4장 | – |
| 레이아웃 | 5종(표지·목록·VS·빅넘버·CTA) | 배경+글자 디자인 자유 조절 | 이미지 위주 | – |
| 디자인 조절 | 템플릿 고정 | ✅ 글꼴·배치·그림자·형광펜 실시간 | 이미지 재생성 | – |
| 저장·게시 | PNG(로컬) | PNG·ZIP + 캡션 | ✅ 예약·즉시 게시 | – |
| 회원·본인 키 | ❌ | ✅ | ✅ | ✅ |

**결론**: 원본의 진짜 가치는 **「떡상 콘텐츠를 역분석해 7대 관점으로 더 나은 카드뉴스를 기획하는 앞단」** 과 **「정보 누락 없는 가변 장수 + 데이터형 레이아웃(VS·빅넘버)」** 이다. 카드 그리기·저장·캡션은 cardnews-studio에, 게시는 insta_auto_poster에 이미 있다.

## 4. 개발 방향 (주인님 결정 필요)
- **A안(추천) — cardnews-studio 확장**: 기획 단계 앞에 「🔥 떡상 리메이크」 시작 방식을 추가(레퍼런스 URL·이미지·뉴스 → 분석 → 7대 관점 TOP 3 → 가변 장수 대본) + 레이아웃 2종(VS·빅넘버) 추가. 카드뉴스 프로그램이 둘로 갈라지지 않고 디자인·저장·캡션을 그대로 재사용. 디자인은 AGY v1.15 리뉴얼 결과를 유지.
- **B안 — 새 프로그램**: 떡상 분석 전용 앱을 따로 만들고 카드 렌더링은 cardnews-studio 코드를 공용 기준 코드로 사본 사용. 카탈로그에 카드뉴스 프로그램이 셋(카드뉴스·인스타 포스팅·신규)이 되어 회원이 헷갈릴 수 있음.

## 6. 주의 (법·약관)
- 인스타 수집(Apify)은 인스타그램 약관상 회색 지대 — 회원 본인 계정·토큰 책임, 기본은 **URL 직접 입력·이미지 업로드**로 동작하고 자동 수집은 선택 기능으로.
- 다른 크리에이터의 문장·이미지는 재사용하지 않고 「무엇이 왜 터졌는지」만 분석해 새로 만든다(화면에 안내).
