### 3-2. 「독립 프로그램 분리」 검토
- 음악(SUNO)자동화(표 8개·리믹스 스튜디오 포함)는 기능이 많지만 모두 「Suno 곡 만들기 → 후가공」 한 흐름이고 같은 Suno 키·같은 보관함을 쓴다 → **쪼개면 오히려 보관함이 나뉘어 불편**. 분리 대상 없음.
- 병합 M1 뒤 메뉴가 늘어나므로, 분리 대신 사이드바를 「① 기획(빌더·앨범·프리셋) → ② 생성·보관함 → ③ 후가공(리믹스·MR·WAV)」 3단계로 묶는 것을 제안.
- 관련 신규 제안(별도 결정 대기): 같은 날 [리릭비 분석](../analysis-lyricbi-20261021/REPORT.md)이 새 「AI 리릭비디오 자동화」(가사 영상)와 공용 `browser-mp4-encoder` 사본을 추천했다. 이 보고서의 「공용 브라우저 렌더 부품」 제안과 같은 부품이므로 함께 결정하면 중복 작업이 줄어든다.
- 독립 4개는 위 표대로 각자 유지하되 **음원을 넘겨받는 연결**로 한 흐름처럼 쓰게 한다(기획·생성 → 마스터링 → LP 영상/뮤직비디오).
