## 0. 한 줄 요약
상세페이지(`shop-detail-page`)에서 만든 상품을, **회원 본인 크롬에서 본인이 로그인한 ESM+ 「상품등록 2.0」 화면**에 확장이 칸마다 채워 넣는다. 한 번 등록으로 G마켓·옥션 둘 다. 회원 비밀번호·API 키 불필요. 나중에 트랙 2(API 키)가 승인되면 같은 웹 화면에서 「보내는 방법」만 API로 바꾼다.

## 3. 확장이 칸을 채우는 순서 (분석표 기준, 순서 중요)
1. `item.esmplus.com/goods/new` 새 탭(같은 사이트 탭이 있으면 재사용, 새 창 금지) → 로그인 풀림이면 멈추고 「ESM+에 로그인해 주세요」.
2. 판매사이트 체크(G마켓·옥션, 기본 둘 다) → 상품명·판매자 관리코드(= 우리 작업 id 앞부분, 결과 대조용).
3. **카테고리 먼저**: 검색칸에 키워드 → 결과 목록에서 회원이 고른 경로와 같은 줄 클릭(없으면 멈추고 후보를 결과로 보냄). 고른 뒤 G마켓·옥션 노출 카테고리·**수수료 %**를 읽어 기록.
4. 판매가·할인 설정안함·판매기간(기본값)·부가세 → 스타배송 사용안함 → 재고(G마켓·옥션).
5. 옵션: 없으면 설정안함 / 있으면 선택형·직접 입력·조합형·옵션명·값 → 「옵션 목록으로 적용」.
6. 사진 15장까지 한 번에 → 상세설명 HTML 탭 붙여넣기.
7. 브랜드(없으면 「브랜드 없음」) → 인증정보 「인증대상이 아님」 기본(영업허가 칸이 생기면 「허가 대상이 아님」 기본, 대상 상품은 회원이 화면에서) → 판매방식 기본값.
8. 고시: 상품군(카테고리별 기본 + 회원 변경) → 「상세설명 참조로 전체 입력」 → 회원이 적은 항목 덮어쓰기.
9. 배송: 택배·택배사·발송정책·출고지·묶음배송·배송비 정책을 기본값 글자로 고름 → 반품지·반품비.
10. 원산지(기본 「상품 상세설명 참조」) → 노출 채널 기본(외부제휴채널 「등록함」이면 주문의 2% 이용료 — 화면 고지).
11. 회원이 고른 방식: **입력만**(여기서 멈춤, 회원이 확인 후 직접 저장) / **임시저장** / **등록하기**.
12. 결과 보고: 칸마다 성공·실패 목록, 실패한 칸은 「어느 구역 어느 칸」. 등록하기면 결과 화면의 상품번호(G마켓·옥션) — **결과 화면 모양은 아직 못 봄(§8 결정 3)**. 결과가 불확실하면 다시 등록하지 않는다.

## 5. 시험 계정 문제
일반 회원 시험 계정 `buylifemall@naver.com`에는 ESM+ 판매자 계정이 없을 수 있다. ESM+ 쪽은 주인님 `buylife` 마스터 계정으로만 시험할 수 있고, 우리 프로그램 쪽은 시험 계정으로 로그인한다(회원 본인 계정 규칙: ESM+ 로그인은 주인님이 직접). 상품 데이터는 시험 계정의 상세페이지 상품.
