# 자동화 프로그램의 기능 구현과 동작 조건 — 최소 설정·최소 조작으로 사용자 대신 자동으로 동작한다 (2026-11-04 주인님 지시, 모든 CLI·모든 프로그램 공통)

## 0. 주인님 지시 (원문)
- 「이젠 어느정도 데이터가 모였으니까 최대한 자동화되는 처리 흐름으로 사용자는 최소한의 설정만으로 자동화운영이 가능하도록 되어야되」
- 「자동화를 구현한다는건 최소한의 설정,동작으로 사용자 대신 자동으로 동작하는 프로그램이어야해」
- 「이부분 메인 핵심지침 자동화 프로그램의 기능구현과 동작 조건으로 최상단 지침에 등록하고 인수인계문서로 남겨」
- 계기: `blog-neighbor-care`(블로그 이웃 소통 자동화) 분석 — 댓글 1건에 화면 3곳 + 확장 팝업, 동의 4번, 클릭 약 20번이 필요했다([플랜](../blog-neighbor-care/docs/PLAN_20261104_SIMPLIFY_FLOW.md)).

## 1. 정의
**자동화 프로그램 = 사용자가 처음에 최소한으로 설정하면, 그 뒤에는 사용자 대신 프로그램이 스스로 동작하는 프로그램이다.** 사용자가 매번 화면을 돌며 버튼을 누르고 동의를 반복해야 하는 것은 「도구」이지 자동화가 아니다. 사용자의 일은 **처음 설정 · 결과 확인 · 예외 처리** 세 가지로 줄인다.

## 2. 기능 구현 조건 (새 프로그램·개선·리뉴얼 모두)
1. **처음 설정은 한 화면 「시작하기」 3~5단계 안에서 끝난다.** 기본값을 미리 채워 두고(모델·상한·시간대·주기 등), 사용자는 바꾸고 싶은 것만 바꾼다.
2. **이미 등록한 값은 다시 묻지 않는다.** AI 키·플랫폼 계정은 공용 저장소(`user_api_keys`, `member_platform_accounts`)에서 가져오고, 없을 때만 「한 번 연결해 주세요」로 안내한다(회원 연동 정보 공용 저장 규칙).
3. **동의는 처음 한 번에 모아서 받는다.** 기능마다 같은 내용을 다시 묻지 않고, 범위가 넓어질 때(새 동작 추가·새 기기 등)만 다시 묻는다.
4. **설정 이후의 실행은 사람 클릭 없이 돈다** — 예약(cron-job.org 회원 키, [예약 기능 지침](SCHEDULER_POLICY.md)), 새 자료 감지, 확장의 반복·순회 실행으로. 「버튼을 눌러야 다음 단계로 가는」 흐름은 자동 흐름으로 잇는다.
5. **매일 보는 화면은 하나**: 첫 화면에 「오늘 한 일 · 결과 · 확인이 필요한 것」만. 같은 설정은 한 곳에만 두고(중복 칸 금지), 자주 안 쓰는 설정은 「고급」으로 접는다.
6. **수동 단계는 사용자가 고르는 선택으로만 남긴다**(예: 「검토 후 실행」 모드). 기본값은 자동 운영이 되도록 설계하되, 아래 3절의 안전 조건과 블로그 핵심 지침의 「회원이 고른 포스팅 방식」은 그대로 지킨다.
7. **확장 팝업도 최소화** — 지금 탭에 맞는 큰 버튼 하나 + 상태 + 중단. 기능 목록을 늘어놓지 않는다.
8. **개발 플랜·완료 보고에 숫자로 적는다**: 「처음 설정 ○단계 · 매일 사용자 조작 ○번 · 동의 ○번」. 목표는 처음 설정 5단계 이하, 매일 조작 0~3번. 검수 때 실제 화면으로 센다.

## 3. 동작 조건 (자동으로 돌 때 반드시 지킬 것 — 자동화의 전제)
1. **회원 본인 계정·본인 키**(최상위 규칙, 운영자·다른 회원 키 폴백 금지).
2. **상한과 시간대**: 하루·회당 상한, 동작 시간대, 사람처럼 간격을 둔 속도(플랫폼 제한·봇 탐지 회피 원칙, `docs/PLATFORM_PATTERNS.md` §20).
3. **결과가 불확실하면 자동으로 다시 실행하지 않는다.** 멈추고 기록하고 알린다.
4. **막히면 멈추고 알린다**: 로그인 풀림·보안문자·계정 불일치·화면 구조 변경은 우회하지 않는다(비밀번호 입력·보안문자 우회 금지). 사용자에게 무엇을 하면 되는지 한 줄로 알린다.
5. **모든 자동 동작은 기록**한다(무엇을·언제·결과). 사용자는 결과 화면 하나에서 확인한다.
6. **언제든 한 번에 멈출 수 있다**: 전체 일시정지 버튼 하나.
7. **비용이 드는 자동 동작은 사용자가 알고 켠다**: 회원 키로 유료 AI를 자동 호출하는 기능은 「시작하기」에서 비용 안내와 함께 켜고 끌 수 있게 하고, 상한을 둔다.
8. 데이터 보관 규칙(30일·열외 계정·지정 프로그램 기간)은 그대로.

## 4. 적용 순서
- **새 프로그램**: 기획 플랜에 2·3절 조건과 「처음 설정 ○단계 · 매일 조작 ○번」을 처음부터 넣는다.
- **기존 프로그램**: 손댈 때(개선·리뉴얼) 그 프로그램의 설정·메뉴·동의 수를 세어 이 기준과 비교하고, 줄이는 방안을 플랜에 넣는다. 전 프로그램 일괄 수정은 하지 않는다(안정화 우선 원칙).
