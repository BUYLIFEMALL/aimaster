# VIP 가입일 기준 사용기간 전환 완료

2026-10-16 Codex(Windows). 맥미니 인수인계의 주인님 승인과 이번 "확인 비교해보고 작업 진행해" 지시를 확인하고 0036을 적용했습니다.

- 적용 전 실측은 과거 문서와 달랐습니다: VIP 138명, 전체 권한 11,226건, 등급 10,698건, 수동 528건. 과거에 보고된 오늘 만료 20명은 이번 재조회에서 0명이었습니다.
- 수동 528건·등급 10,698건을 RLS 활성화·일반 회원 조회 불가 백업 테이블에 보관했습니다.
- 등급 프로그램에 포함된 수동 480건만 **삭제 없이 같은 행을 등급 부여로 전환**했습니다. 누락 행 0건, VIP 등급 11,178건(138×81), 만료·가입일 기준 불일치 모두 0건입니다.
- VIP의 기준은 signup + 365일, 골드는 기존 grant + 180일을 유지합니다. 기존 VIP 행 ID 전부 보존, 대상 밖 수동 48건과 비VIP 3,566건은 전후 내용 지문 일치. 프리미엄 정지 행은 현재 0건이며 기존 프리미엄 가드는 유지했습니다.
- 새 계산 함수는 SECURITY INVOKER·빈 search_path·public.profiles 한정, 일반/익명 실행 금지. 기존 apply_grade_programs의 서비스 역할 전용 ACL도 보존했습니다. 비VIP·대상 밖 권한·원래 행·만료일 검증이 실패하면 마이그레이션 전체가 롤백되도록 가드를 추가했습니다.
- 적용 파일: [0036](../supabase/migrations/0036_vip_signup_based_expiry.sql). [전후 검수 증거](vip-signup-expiry-20261016.json). 신규 관리자/키/로그인 우회·회원 API 대행 호출·유료 호출 없음.
- 실제 DB 검증 완료이며, 메인 프리미엄 안내 문구는 이번 최신 메인 배포와 함께 별도로 검수합니다. 관리자 정책의 이전 미조치 수치는 당시 이력이며 이 문서의 적용 결과가 최신입니다.
- 다음 CLI: 루트 지침 → 관리자 정책 최신 적용 절 → 이 문서 → 0036. 동일 전환을 반복하거나 기존 백업을 덮어쓰지 말고, 새 회원은 바뀐 기준과 트리거로 처리되는지 먼저 확인합니다.

함수 실행 권한 근거: [Supabase 공식 함수 보안 안내](https://supabase.com/docs/guides/database/functions#function-privileges).
