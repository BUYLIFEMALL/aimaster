| 함께 볼 것 | 1차 분석의 **NB1 내 글 댓글에 AI 대댓글 초안**도 플랜 2판에서 같이 빠졌다(05 원본에는 없는 기능). 답방을 다시 넣을 때 함께 결정하면 좋음 |
| 가져오지 않는 것 | 비밀번호 자동 로그인, TXT 목록 수동 불러오기(우리는 확장이 내 글 반응을 직접 읽음), 확인 없는 자동 등록 기본값, 고정 대기·지시문 한 줄 댓글·구형 모델 |
| 왜 결정이 필요한가 | 플랜 2판이 주인님 지시(「맞는 블로그를 먼저 찾아 이웃 신청 → 이웃 새 글 소통」)를 중심으로 다시 쓰이며 답방이 빠졌다. 의도적으로 뺀 것인지 확인되지 않아, 다시 넣는 것은 주인님이 정한다 |
| 비용 | 회원 본인 키로 댓글 초안 생성(플랜 단계 4와 같은 단가). 운영자 비용 없음 |

### 5-5. 담당
- 개발: `blog`(`blog-neighbor-care`) · 디자인: 「답방 후보」 목록 화면이 새로 생기므로 첫 동작 버전 뒤 `design`이 다듬기(블로그 계열 템플릿 유지).
- 상태: ✅ **주인님 결정(2026-10-27)**: 「댓글을 남긴 블로거에게 해당 댓글들을 토대로 답방가는 자동화는 필요할 것 같아 추가해줘」 + AI 대댓글 「추가」 → 본 개발 포함(플랜 §2-⑤·⑥, §8 「4-1」). 공감만 누른 사람은 답방 대상에서 뺌(지시가 「댓글을 남긴 블로거」).
