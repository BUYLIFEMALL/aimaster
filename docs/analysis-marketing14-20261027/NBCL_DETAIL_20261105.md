## 1. 한 줄 요약
**블로그 계정 여러 개를 돌아가며, 계정마다 IP를 바꿔 로그인한 뒤, 주소 목록의 글마다 공감을 누르고 미리 써 둔 같은 댓글을 다는 윈도우 프로그램.** 이미 같은 계정이 댓글을 단 글은 건너뛴다. AI는 쓰지 않는다.

## 2. 기술 구성

## 4. 동작 흐름 (시작 버튼 → 끝)
```
시작 버튼
 └ 별도 스레드에서 Start 반복
    계정 목록의 체크된 계정마다:
     1. IP 방식 창 → GetChrome: IP 바꾸기(ADB 껐다 켜기 / 프록시 무작위 / 없음) → IP 확인 → 새 시크릿 크롬
     2. Login: naver.com → 로그인 버튼 → 아이디 칸·비밀번호 칸에 값 직접 넣기(자바스크립트) → 비밀번호 칸에 키 입력 → 로그인 버튼
        → 주소가 www.naver.com 이면 성공, nid 가 남아 있으면 실패(보안문자·2단계 등)
     3. 성공: 목록 줄 색 바꾸고 「로그인 성공」, 메인 화면 내 정보에서 **내 닉네임**을 읽어 둠
        주소 목록의 글마다 BlogWork(공감?, 댓글?)
        실패: 「로그인 실패」 기록 후 다음 계정
     4. VPN 방식이면 ESVPN 연결 해제 → 10초 대기 → 로그아웃 → 5초 대기
     5. 최소~최대 사이 무작위 초 대기 → 다음 계정
 └ ChromeDriverReset: 쿠키 모두 지우고 naver.com 다시 열기(알림창 있으면 확인)
```

### 4-1. 공감 (`BlogWork` 앞부분)
1. 글 주소로 이동 → 잠깐 대기
2. 블로그 본문 틀 `mainFrame`(iframe)으로 들어감
3. 공감 버튼 `u_likeit_list_btn` 개수를 세고, 각 버튼의 속성으로 **버튼 종류인지·이미 눌렸는지(`false`=아직 안 누름)** 확인
4. 안 눌린 버튼이면 자바스크립트 `click()` → 대기
5. 브라우저 알림창이 뜨면(`IsAlert`) 확인을 누르고 「공감 누르기 실패」(네이버 제한 안내로 추정), 안 뜨면 「공감 누르기 성공」
6. 버튼이 없으면 「공감 누르기 실패(버튼없음)」

### 4-2. 댓글 (`BlogWork` 뒷부분)
1. 다시 `mainFrame`으로 들어감
2. 댓글 열기 버튼 `btn_comment`를 자바스크립트로 누름 → 대기
3. 댓글 목록 `u_cbox_list`의 글자에 **내 닉네임이 있으면 「중복 댓글」로 건너뜀**
4. 댓글 입력칸 `u_cbox_text`의 `innerHTML`에 문장을 **한 번에 넣음**(타자 치기 아님, 줄바꿈 `<br>`)
5. 등록 버튼 `u_cbox_btn_upload` `click()` → 대기
6. 알림창이 뜨면 확인 후 「댓글 작성 실패」 또는 「댓글 작성 실패(입력막음)」, 안 뜨면 「댓글 작성 성공」

## 7. 위험·문제점
| 항목 | 내용 | 우리 지침 |
|---|---|---|
| 여러 계정 돌리기 | 계정 파일에 아이디·비밀번호를 적어 순서대로 로그인 | ❌ 회원 본인 계정 하나, 비밀번호는 다루지 않음 |
| IP 바꾸기 | 계정 바꿀 때마다 테더링·VPN·프록시 | ❌ 기본 꺼짐, 회원이 본인 책임으로 켤 때만 |

## 9. 개발에 쓸 것 / 쓰지 않을 것
### 쓸 것 (아이디어·확인 항목)
1. **대상 글 주소 목록 붙여넣기**(검토 대기, [`PROGRAM_IDEA_BACKLOG.md`](../PROGRAM_IDEA_BACKLOG.md)에 올릴 후보): 회원이 직접 고른 글 주소를 여러 줄로 넣으면 「공감 준비」 작업을 한꺼번에 만든다. 같은 글 중복 차단·하루 상한·검토 완료 단계는 그대로.
2. **댓글 중복 확인을 화면에서도 한 번 더**: 우리는 DB로 막지만, 다른 기기·직접 단 댓글은 모른다. 댓글을 달기 직전에 댓글 목록에 **내 블로그 닉네임 댓글이 이미 있으면** 쓰지 않고 「이미 댓글 있음」으로 기록하는 확인을 넣을 만하다(원본 4-2의 3번 착안, 우리 방식은 정독 단계에서 읽기).
3. **알림창 감지**: 공감·댓글 뒤 네이버가 띄우는 브라우저 알림창(제한·차단 안내)을 결과 판정에 넣는다 — 뜨면 실패가 아니라 **「제한 안내 · 그날 중지」**로 처리(원본은 계속 진행).
4. 화면 요소 목록(§5)은 확장 선택자를 고칠 때 비교 자료로 쓴다(현재 화면과 다를 수 있음).

### 쓰지 않을 것
여러 계정·비밀번호 파일·자동 로그인 · IP 바꾸기(테더링·VPN·프록시) · 같은 댓글 반복 · `innerHTML` 붙여넣기·자바스크립트 `click()` · 제한 안내 뒤 계속 진행 · 원격 사용 허가 서버.
