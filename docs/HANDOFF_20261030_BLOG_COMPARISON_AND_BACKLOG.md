## 2. 배포 키트(수업용) 판단

- **현재 키트가 있는 프로그램은 Threads·인스타 4개뿐**(`threads-content-ops`·`threads-affiliate-poster`·`threads-easy-planner`·`insta_auto_poster`의 `KIT/`). 블로그 프로그램 키트는 없다.
- **추천: 네이버 블로그 에이전트** — 세 가지 발행 방식·결과 기록까지 갖춘 네이버 프로그램이 이것뿐이다. 대안은 포스팅 자동화(FREE, 가장 단순하지만 자동 발행 시연 불가).
- 필요한 작업(지침 [`DISTRIBUTION_KIT_GUIDE.md`](DISTRIBUTION_KIT_GUIDE.md) §2·§3·§6): 독립 모드 스위치 → DB 설치 파일 → 확장의 서버 주소를 수강생 주소로 → 패키지 설치마법사 포장 → Lab 리허설. 에이전트는 기능이 많아 몇 시간 이상 걸릴 것으로 본다.
- **주인님 결정 대기**: 키트 대상 프로그램, 수업 시작 시각, 「수강생 계정에 이식」의 범위(수강생 본인 Supabase·Vercel에 설치를 함께 진행하는지).
