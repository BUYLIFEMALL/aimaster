상태: **플랜(승인 대기)**. 코드·DB 변경 없음.

## 0. 무엇을 하나 (한눈에)
키워드(예: 「공동구매」)로 그 주제의 **비즈니스 채널**(블로그·업체·쇼핑·카페글, 이후 유튜브·인스타·쓰레드·밴드)을 찾아, **그 채널이 홍보 목적으로 공개해 둔 비즈니스 연락처(전화·이메일)**를 회원 본인 참고용으로 정리해 준다. 회원은 그 공개 목적(제휴·문의) 범위에서 **직접** 연락한다.

## 1. 하는 것 / 하지 않는 것
| 하는 것 | 하지 않는 것 |
|---|---|
| 키워드로 채널 찾기(공식 검색 API, 회원 키) | 숨긴 회원 아이디·비공개 정보 추출(§4 제외, 우회 ❌) |
| **당사자가 프로필·채널에 공개한** 비즈니스 전화·이메일 수집 | 사적·미공개 연락처 수집 |
| 사람 같은 속도·상한 안에서 | 네이버 탐지·차단 **우회**(걸리면 그날 중지) |
| 회원이 그 공개 목적 범위에서 **직접** 연락 | **동의 없는 광고 대량 발송**(제50조, 발송은 회원 책임·수동) |
| 결과를 회원 본인 소유로 격리·30일 보관 | 데이터 재판매·공유·AI 학습(검색 API 약관 2026-09-07) |

## 2. 화면 고지 (필수, §4 그대로 — 켤 때 동의)
> 「이 기능은 **당사자가 홍보·연락 목적으로 공개해 둔 비즈니스 연락처**만 모읍니다. 수집·이용은 그 **공개 목적(제휴·문의) 범위**에서, **회원 본인 참고용**으로만, **회원 본인 책임**입니다. 동의 없는 광고 전송은 정보통신망법 제50조 위반입니다. 비공개·사적 정보는 모으지 않습니다.」
- 처음 켤 때 동의 1번, 수집·연락 전에 한 번 더 요약 표시.

## 3. 엔진 (두 겹 + 단계 확장)
### 3-1. 1겹: 채널 찾기 (공식 API, 안전)
- 키워드 → 블로그·지역(업체)·카페글·쇼핑 검색(회원 본인 네이버 검색 키, 일일/월 쿼터). 결과: 이름·주소·요약·업체 링크.
- 주제 관련도·최신·활동으로 정렬. 이미 있는 `competitor-analysis` 검색 패턴 재사용.
### 3-2. 2겹: 공개 연락처 확인 (회원 브라우저·공개 페이지만)
- 각 채널의 **공개 프로필·소개·업체 상세 페이지**를 회원 로그인 세션에서 사람처럼 열어, 그 자리에 **공개된** 전화·이메일·문의 링크만 읽는다.
- 공개 연락처가 없으면 「연락처 공개 안 함」으로 두고 넘어감(추측·우회 ❌).
- 속도: 페이지 4~9초 간격, 10개마다 쉼, 동작 시간대, 하루 상한(기본 1000, 조절). 보안문자·로그인 풀림·제한 뜨면 **그날 중지**.
### 3-3. 단계 (주인님 「기본 먼저, 잘되면 확장」)
| 단계 | 채널 |
|---|---|
| 1차(기본 엔진) | 네이버 블로그 · 플레이스(업체) · 카페글(공개) |
| 2차 | 쇼핑/스마트스토어 · 지식iN · 모두 홈페이지 |
| 3차(밖) | 유튜브 · 인스타 · 쓰레드 · 밴드 |

## 4. 저장·소유 (최상위 규칙)
- 회원 본인 키·본인 세션. 결과는 **그 회원만** 보는 저장소(owner-only RLS). 공유·판매 ❌. 30일 보관(관리자·시험 계정 열외).
- 회원 참고용 조회·엑셀 내려받기. AI 학습·재판매 금지.

## 6. 테스트로 할 수 있는지 (사전 검증, 비용 거의 없음)
- 시험 계정 네이버 검색 키로 블로그·지역·카페글 **소량 호출** → 목록·업체 링크가 오는지(무료 쿼터, AI 비용 없음).
- 공개 프로필·업체 페이지를 회원 브라우저로 열어 **연락처가 어디에 공개되는지** 눈으로 확인(저장 없이).
- 이 두 가지로 「실제로 되는지」를 코드 전에 확인.

## 7. 어디에 만들까
- 이미 `competitor-analysis`가 키워드로 채널을 찾는다 → **확장**이 자연스러울 수 있음(검색·회사 조사 재사용). 다만 「연락처 수집·제휴 타깃」은 성격이 달라 **새 프로그램**도 후보.
- 플랜 승인 때 함께 정함.

## 8. 비용·분담
- 비용: 검색 API 무료(쿼터 안)·회원 키. 빌드만. AI 호출 없음(정렬은 규칙 기반, 필요시 회원 키 AI는 선택·비용 고지).
