# 블로그·티스토리 자동화 완성 기준

2026-10-21 주인님 지시: 「모든 블로그 자동화, 티스토리 자동화는 확장프로그램을 통한 자동포스팅까지 이어지는 자동화 프로그램이 되어야 돼. 지침에 추가해 줘」.

## 적용 범위와 목표

모든 블로그·티스토리 자동화 프로그램의 신규 개발·업그레이드·병합 비교에 적용한다. 완성 목표는 **자료 입력/수집 → 원고 생성 → 편집·검수 → 확장프로그램 전달 → 해당 플랫폼 편집기 입력 → 자동 포스팅 → 발행 결과 확인·기록**까지 이어지는 흐름이다. 원고 생성·복사·내보내기·편집기 입력까지만 구현된 상태는 전체 자동화 완료와 구분하여 미완료 단계를 명시한다.

각 프로그램에 확장프로그램을 별도로 중복 개발할 필요는 없다. 해당 플랫폼에서 검증된 공용 기준 확장 기능과 프로그램별 연결부를 사용할 수 있으며, 네이버와 티스토리의 계정·편집기·발행 동작 차이를 실제 코드와 화면으로 확인한다. 회원 본인 계정·본인 API 키, 회원별 데이터 격리·30일 보존, 운영/Lab 분리 규칙을 유지한다.

## 개발·비교·완료 보고

1. 플랜과 프로그램 비교표에 확장 연동 여부, 대상 플랫폼, 입력/발행 단계, 자동 포스팅까지 남은 작업을 적는다. 단순 카테고리 이동이나 원고 기능의 유사성만으로 병합 완료를 판단하지 않는다.
2. 회원이 선택한 대상 계정·카테고리·공개 범위·예약 설정을 확장에 전달하고, 본문·사진 순서·대표 이미지가 이어지는지 검수한다. 실패·재시도 시 중복 발행을 방지하고 회원에게 진행 상태와 복구 방법을 안내한다.
3. Edge 포그라운드 실세션에서 해당 플랫폼의 전체 흐름을 검수한다. 실제 발행 시험은 해당 시험에 승인된 원고·계정·공개 범위로 수행하고, 기존 준비 탭이나 원고를 임의로 발행하지 않는다.
4. 인수인계에는 생성/편집, 확장 전달, 편집기 입력, 실제 발행, 결과 URL/상태 기록의 검수 결과를 각각 남긴다. 모의 시험·발행 준비·실제 발행을 구분하고, 확인하지 못한 단계는 미검수로 적는다.

## 이번 지시의 반영 상태

이 문서와 루트 `AGENTS.md`·`CLAUDE.md`·`GEMINI.md`, 프로그램 비교 분석 매뉴얼에 공통 기준을 반영한다. **기준 등록은 기능 구현 완료를 뜻하지 않는다.** 진행 중인 BLC 작업과 이후 SEO 블로그 스튜디오 비교에서 남은 자동 포스팅 단계를 이 기준으로 대조한다. 이번 문서 반영으로 운영 코드·DB·권한·서비스 공개 여부는 변경하지 않는다.
