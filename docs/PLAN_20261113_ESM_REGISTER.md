# 플랜 — AI G마켓·옥션 상품 자동등록기 (2026-11-13, [역할: ecommerce-image] `claude-win-sdp`)

주인님 지시: 「순서대로 진행해」(11번가 4단계 → 묶음 배포 → **G마켓·옥션 등록기 플랜**), 2026-11-13 「진행해」.
근거 검토: [`docs/REVIEW_20261111_GMARKET_AUCTION_REGISTER.md`](REVIEW_20261111_GMARKET_AUCTION_REGISTER.md) — **2안 확정(회원 각자 ESM Trading API 신청 → 본인 키 등록)**, 프로그램 안에서 신청 방법 안내, 시범 신청 없이 진행.
**이 문서는 플랜이다 — 아래 「결정 항목」 답을 받은 뒤 구현한다(코드·DB·배포 없음, 비용 없음).**

## 1. 목표
AI 상세페이지 자동화에서 검토 완료한 상품을 **ESM Trading API 2.0 통합상품 등록**(`POST https://sa2.esmplus.com/item/v1/goods`)으로 **G마켓·옥션에 한 번에**(한쪽만도 가능) 등록하고, 등록 직후 판매중지를 걸어 둔다. 11번가 등록기(v1.05)와 같은 흐름·같은 화면.

## 4. 단계
| 단계 | 내용 | 빌드 | 막히는 조건 |
|---|---|---|---|
| 0 | ESM Trading API 명세 읽기(인증 JWT `kid`·`ssi`, 카테고리·출하지·반품지·발송정책·고시 조회, 등록·판매상태 수정, 오류 코드) → `esm-register/docs/API_SPEC_NOTES.md` | 0 | 없음(공개 문서) |
| 1 | 뼈대 + **신청 안내 화면**(신청 단계 카드·신청 메일 초안 1초 복사·승인 뒤 키 등록 순서·「지마켓 답변에 따라 다를 수 있음」) + DB 등록(비공개)·기록 표 | 1 | 없음 |
| 2 | 키 등록·연결 시험(읽기만: 출하지·반품지 목록) | 1 | **승인된 키가 있어야 실제 확인 가능** |
| 3 | 등록 화면·검사하기(보내지 않음) | 1 | 2와 같음 |
| 4 | 보내기·직후 판매중지·배지·정리 | 1 | 2와 같음 |
| 5 | 관리자 계정 실제 등록 1건 → 공개 | 0 | 2와 같음 |
- 1단계까지는 키 없이 끝낼 수 있다. 2단계부터는 **누군가(관리자 계정) 승인된 ESM 키가 있어야** 화면 확인이 된다 — 결정 2.

## 5. 처음 설정·매일 조작 (자동화 최소 설정 지침)
처음 설정 **3단계**(ESM API 신청 → 승인 메일의 마스터 ID·Secret Key 등록 → 연결 시험) · 매일 조작 **상품당 2번**(검사하기·보내기) · 동의 **1번**(보내면 바로 상품이 생긴다는 확인).

## 6. 비용
| 항목 | 비용 |
|---|---|
| 개발·시험 | Vercel 빌드 약 4~5회(단계마다 1회, 작은 수정은 모아서), AI 호출 없음 |
| 운영자 인프라 | 새 Vercel 프로젝트·도메인 `esm-register.buylife.xyz`(추가 비용 없음), 상세 사진 보관은 유료 회원만(3안) |
| 고정 IP | **ESM이 허용 IP를 요구하면** 서울 고정 IP가 필요할 수 있음(11번가는 필요 없었음) — 미확인, 결정 3 |
| 회원 부담 | ESM API 사용료는 공개 문서에 없음(미확인) |

## 7. 결정 항목 (주인님 답 필요)
1. **이름**: ✅ **확정(2026-11-13 주인님 「AI G마켓·옥션 상품 자동등록기 이걸로 해」)** — 「AI G마켓·옥션 상품 자동등록기」, slug·폴더 `esm-register`, 주소 `esm-register.buylife.xyz`.
2. **시험용 키**: 관리자 계정(주인님 ESM 판매자 ID)으로 ESM Trading API를 **주인님이 직접 신청**하실지. 신청 메일 초안은 1단계 안내 화면 문구로 제가 만들어 드림. 신청하지 않으면 2단계부터는 첫 회원 승인 때까지 멈춤.
3. **허용 IP를 요구할 때**: 서울 고정 IP(유료 프록시 등)를 둘지, 요구하지 않을 때까지 미룰지 — 승인 답변을 보고 다시 여쭘(지금은 기록만).
4. **진행 범위**: 지금 0·1단계(명세 정리 + 뼈대·신청 안내 화면, 빌드 1회)까지 진행하고 2단계부터는 키 승인 뒤 / 또는 키가 나올 때까지 착수 보류.

## 8. 하지 않는 것
운영자 셀링툴 키(1안, 최상위 규칙 예외 필요) · ESM PLUS 화면 자동 입력(3안, 약관 미확인) · 회원 대신 신청 메일 발송.
