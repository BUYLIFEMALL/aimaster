- Spectrum은 이미 승인돼 반쯤 진행됐고, 원본 파생 코드를 바꿨으므로 **빨리 배포해 권리 위험을 없애는 게 먼저**입니다.
- Lyricbi는 작고 위험이 낮은 기능 묶음이라 두 번째로 둡니다. 대기 중인 `?remix=`도 이 묶음 배포 1에 함께 나갑니다.
- 무료 음성 엔진은 주인님이 「먼저 진행」으로 정한 방향이지만, 시제품 확인(400MB 내려받기·격리 머리글·한국어 음질)과 OpenRAIL 상업 이용 답이 있어야 범위가 정해집니다. 그래서 **결정 질문을 먼저 여쭙고, 답을 받는 동안 1·2를 진행**하는 순서를 추천합니다. 주인님이 음성 엔진을 먼저 하라고 하시면 Spectrum 1차 배포 직후로 앞당깁니다.

## 3. 무료 음성 엔진 — 개발 플랜 초안 (승인 전)

### 3-1. 공식 예제 확인 결과 (`github.com/supertone-inc/supertonic/web`, MIT)
| 항목 | 공식 예제 | 우리 설계 |
|---|---|---|
| 실행 장치 | WebGPU 먼저 시도 → 실패하면 WASM | 인계 기록대로 **WASM 기본**(WebGPU 음질 깨짐 사례), WebGPU는 선택지로 |
| 모델 위치 | 같은 서버 `assets/onnx`(약 398MB) | **회원 브라우저가 허깅페이스 `Supertone/supertonic-3`에서 직접** 받기(운영자 서버·트래픽 0) |
| 저장(캐시) | 없음(새로 열 때마다 다시 받음) | 브라우저 Cache API에 보관 → 두 번째부터 즉시, 진행률·취소·다시 받기 |
| 화면 멈춤 | 작업자 없이 화면 쪽에서 실행 | **작업자(worker)** 안에서 실행 |
| 격리 머리글 | 설정 없음(단일 스레드) | 시제품에서 멀티스레드용 COOP/COEP가 로그인·외부 이미지에 주는 영향 확인 → 안 되면 단일 스레드 |
| 입력·출력 | `TextToSpeech.call(text, lang, style, totalStep, speed, silenceDuration)` → `{ wav, duration }`, 한국어는 120자씩 나눠 이어 붙임, `writeWavFile`(16bit 모노) | 같은 경계 + **문장별 길이(`duration`)를 돌려받아 자막 시각**으로 씀(유료 받아쓰기 없음) |

### 3-3. 주인님께 여쭐 것
1. **상업 이용**: 모델 가중치 라이선스가 OpenRAIL(용도 제한)입니다. 회원이 만든 쇼츠를 유튜브 수익화 등 상업적으로 써도 되는지 원문 확인이 필요합니다. 확인 전에는 화면에 「모델 라이선스 조건 확인 · 실존 인물 사칭 금지 · 합성음 표기 권장」 고지를 넣고 진행할지 정해 주세요.
