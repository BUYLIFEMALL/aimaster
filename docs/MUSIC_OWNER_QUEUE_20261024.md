### 3-1. 공식 예제 확인 결과 (`github.com/supertone-inc/supertonic/web`, MIT)
| 항목 | 공식 예제 | 우리 설계 |
|---|---|---|
| 실행 장치 | WebGPU 먼저 시도 → 실패하면 WASM | 인계 기록대로 **WASM 기본**(WebGPU 음질 깨짐 사례), WebGPU는 선택지로 |

| 저장(캐시) | 없음(새로 열 때마다 다시 받음) | 브라우저 Cache API에 보관 → 두 번째부터 즉시, 진행률·취소·다시 받기 |

| 방식 | 문장당 만든 시간 | 속도 비율(만든 시간 ÷ 음성 길이) |
