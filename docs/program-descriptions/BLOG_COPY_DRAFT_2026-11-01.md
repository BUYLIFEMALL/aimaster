<p>📝 글감을 모으거나 주제를 직접 넣으면 검색에 맞춘 원문·이미지·태그를 만들어 내 보관함에 저장합니다.</p>
<p>🧩 확장이 제목·본문·이미지·카테고리·태그를 사람이 치듯 입력하고, 소제목·목록·인용·표 서식도 최대한 그대로 옮깁니다. 태그까지 실제로 등록돼야 완료로 처리합니다.</p>
<p>📅 원고마다 발행 방식을 고릅니다. 발행 전까지는 입력만 하고, 즉시 발행은 마지막 버튼까지 눌러 글 주소를 기록하며, 예약은 날짜·시간까지 맞춰 두면 마지막 예약 버튼만 누르면 됩니다.</p>
<p>🔑 회원 본인의 AI API 키와 크롬 확장을 사용하며, 티스토리는 회원 크롬에 로그인돼 있어야 합니다. 글은 본인만 보고 30일 뒤 자동 삭제됩니다.</p>

**사용 순서 4단계**: 주제 수집(글감을 모으거나 주제를 직접 넣습니다) → AI 글쓰기(원문·이미지·태그를 만듭니다) → 게시글 관리(보관함에서 고치고 발행 방식을 고릅니다) → 티스토리 올리기(확장이 입력하고 고른 방식으로 올립니다)

**추천 대상 3개**
| 이모지 | 대상 | 이유 | 효과 |
|---|---|---|---|
| 💰 | 티스토리로 수익을 내는 블로거 | 검색에 맞춘 원문과 태그를 만들고 즉시 발행까지 확장에 맡깁니다. | 글 올리는 시간 단축 · 꾸준한 발행 |
| 🧩 | 서식 옮기기가 번거로운 분 | 소제목·목록·표를 티스토리 화면에 그대로 옮겨 다시 꾸밀 일이 줄어듭니다. | 서식 유지 · 손작업 감소 |
| 🗓️ | 미리 써 두고 나눠 올리는 분 | 예약 날짜·시간을 원고마다 맞춰 두고 마지막 버튼만 누릅니다. | 발행 일정 정리 · 나눠 올리기 |

## 5. 블로그 포스팅 자동화 (`ai-auto-blog`)

**한 줄 요약**: 요즘 이슈를 고르면 글·이미지를 한 번에 만들고 확장이 네이버에 입력해 주는, 처음 쓰기 쉬운 블로그 도구

**상세 설명**
```html
<p>📰 <strong>요즘 뜨는 이슈를 고르기만 하면 블로그 글과 이미지를 한 번에 만들고, 크롬 확장이 네이버 글쓰기 화면에 넣어 주는 쓰기 쉬운 블로그 자동화 프로그램입니다.</strong></p>
<p>🔰 블로그 자동화가 처음이어도 메뉴 순서대로 따라가면 됩니다. 실시간 이슈·유튜브 쇼츠·참고 주소에서 글감을 고르면 AI가 본문·해시태그와 실사 이미지를 만들어 줍니다.</p>
<p>📚 만든 글은 게시글 관리에서 보고 고칠 수 있고, 네이버 블로그 카테고리를 불러와 글마다 지정할 수 있습니다.</p>
<p>🧩 [네이버 입력기로 보내기]를 누르면 확장이 제목·본문·이미지를 사람이 치듯 순서대로 입력하고, 마지막 발행 버튼은 회원이 직접 누릅니다.</p>
<p>🔑 회원 본인의 AI API 키를 사용합니다. 확장은 새 버전이 나오면 다시 받아 덮어쓰면 됩니다.</p>
```

**핵심 특징 4개**
| 이모지 | 제목 | 설명 |
|---|---|---|
| 🔰 | 처음 써도 쉬운 흐름 | 글감 고르기 → 글쓰기 → 관리 → 보내기, 메뉴 순서대로 따라갑니다. |
| 📰 | 이슈·쇼츠 글감 | 실시간 이슈와 유튜브 쇼츠에서 바로 쓸 글감을 고릅니다. |
| 🖼️ | 글·이미지 한 번에 | 본문·해시태그와 실사 이미지를 한 번에 만듭니다. |
| 🧩 | 확장이 대신 입력 | 네이버 글쓰기 화면에 순서대로 넣고, 발행은 직접 누릅니다. |

**사용 순서 4단계**: 주제 수집(이슈·쇼츠·주소에서 글감을 고릅니다) → AI 글쓰기(본문·이미지를 한 번에 만듭니다) → 게시글 관리(고치고 카테고리를 지정합니다) → 네이버로 보내기(확장이 입력하고 발행은 직접 누릅니다)

**추천 대상 3개**
| 이모지 | 대상 | 이유 | 효과 |
|---|---|---|---|
| 🔰 | 블로그 자동화가 처음인 분 | 메뉴 4단계만 따라가면 글감부터 네이버 입력까지 끝납니다. | 배우기 쉬움 · 첫 글 바로 완성 |
| 📰 | 이슈 글로 방문자를 모으는 분 | 실시간 이슈와 쇼츠 글감으로 지금 찾는 주제를 빠르게 씁니다. | 빠른 이슈 대응 · 글감 걱정 줄이기 |
| ✋ | 발행 전에 직접 다듬고 싶은 분 | 확장은 입력까지만 하고, 마지막 확인과 발행은 직접 합니다. | 내 손으로 마무리 · 실수 방지 |
