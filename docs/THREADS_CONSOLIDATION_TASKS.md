## 현재 위치와 읽는 순서

**기준 문서:** 쓰레드 5개의 현재 기능 표·장단점·기준 코드 위치·로드맵은 [쓰레드 기능 상세 비교표](THREADS_FEATURE_MATRIX.md), 끝났다고 말할 조건은 [쓰레드 완성 기준](THREADS_COMPLETION_POLICY.md)에 있다. 이 작업목록의 항목을 시작하기 전에 두 문서를 먼저 읽고, 배포한 기능은 비교표 칸을 고친다.

**2026-10-24 현재:** 통합 분석의 결정 3건(묶음 A·상품 연동 공용 코드·댓글 자동 수집 회원 선택)과 바로 고칠 문제 1번(댓글 AI 지시문)은 운영 배포까지 끝났다. 남은 것은 쇼핑제휴 캐시 회원별 격리(DB 승인 필요)와 포스팅 NewsBlur 비밀번호 암호화, 그리고 낮은 우선순위 정리 항목이다. **쓰레드 담당 역할은 아직 지정되지 않았다**([카테고리 지침 지도](CATEGORY_GUIDE_MAP.md)).
