## 2. 방향 — 「생성은 AI 음악 스튜디오 한 곳, 다른 프로그램은 가져다 쓰기」
모델 연동 코드를 여러 프로그램에 복사하면 공급자·저장·웹훅·비용 기록을 프로그램마다 따로 관리해야 한다(유지보수 부담). 대신:
- **가져오기(권장)**: 다른 프로그램은 회원 본인 `ams_generations`(완성곡)를 읽어 고르기만 한다 — 가사영상·플레이리스트에서 검증된 방식(공용 모듈 `ams-timed-lyrics` + 서명 주소).
- **자동 파이프라인(shots)만** 곡을 자동으로 만들어야 하므로, 모델 연동은 공용 기준 코드로(이미 `suno-api-client` 공용 모듈 존재 — V6 지원).
