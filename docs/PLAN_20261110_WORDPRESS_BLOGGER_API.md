## 1. 결정된 것
- 워드프레스·구글 블로그는 크롬 확장 대신 **공식 API로 서버가 직접 발행**한다(루트 `CLAUDE.md` 블로그 핵심 지침 예외 줄, 2026-11-10).
- 그대로 지킬 것: 글·이미지는 웹에서 완성 → 회원이 고른 방식(발행 전까지=초안 / 바로 발행 / 예약) → 결과(글 주소·예약 시각·실패 사유) 기록 → 결과가 불확실하면 다시 발행하지 않음. 회원 본인 계정·본인 키.

## 2. 현재 상태(확인 결과)
- AIMaster 코드에 워드프레스·블로거 발행 기능은 **없다**(검색 결과 `blogger` 글자는 네이버 검색 응답 칸뿐).
- 가장 가까운 기존 프로그램: `tistory-auto-blog` v1.93 — 네이버 외 플랫폼 전용, 글감 수집 → AI 원고 → 발행 설정(카테고리·공개 범위·즉시/예약) → 결과 기록 흐름이 이미 있다(발행만 확장 방식).
- 회원 구글 연동: 공용 연동 표에 `youtube`(회원 본인 구글 OAuth 앱, 갱신 토큰은 같은 앱으로만)가 있다 → 블로거도 같은 회원 구글 앱에 범위만 더해 재사용 가능.

## 3. 두 플랫폼 공식 API 요약
| 항목 | 워드프레스(설치형) | 구글 블로그(Blogger API v3) |
|---|---|---|
| 회원 인증 | 사이트 주소 + 사용자명 + **응용 비밀번호**(WP 5.6+ 기본 기능) | 회원 본인 구글 OAuth 앱 → 「구글 연결」 → 블로그 고르기 |
| 발행 전까지 | `status=draft` | `isDraft=true` |
| 바로 발행 | `status=publish` | `posts.insert` 후 공개 |
| 예약 | `status=future` + `date` — **워드프레스가 직접 예약 실행** | 초안 저장 → `posts.publish(publishDate)` — **구글이 직접 예약 실행** |
| 이미지 | `/wp/v2/media`로 회원 사이트 미디어에 업로드(영구) | **업로드 API 없음** — 이미지 주소를 본문에 넣어야 함(아래 결정 3) |
| 카테고리·태그 | 카테고리·태그 ID | 라벨(labels) |
| 결과 | 글 ID·주소·상태 응답 | 글 ID·주소·상태 응답 |

→ 두 플랫폼 모두 **예약을 플랫폼이 직접 실행**하므로 cron-job.org 같은 예약 장치가 필요 없다(회원 PC·브라우저가 꺼져 있어도 됨).

## 4. 어디에 만들지 — 안 3개
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **가(추천)** 새 프로그램 | 「AI 워드프레스·구글블로그 자동화」 하나에 두 플랫폼. 뼈대는 `tistory-auto-blog` 흐름 재사용, 발행 엔진은 공용 기준 코드로 | 구글 검색용 글 구성(메타 설명·주소 슬러그·제목 구조)을 처음부터 맞춤. 네이버 프로그램을 건드리지 않음 | 프로그램 1개 늘어남, 새 Vercel 프로젝트 |
| 나 | 네이버 블로그 에이전트에 「다른 블로그로도 발행」 추가 | 이미 만든 원고를 그대로 재사용 | 네이버용 글을 구글 블로그에 그대로 올리게 됨, 기준 프로그램이 무거워짐 |
| 다 | 티스토리 프로그램을 「티스토리·워드프레스·구글블로그」로 확장 | 네이버 외 플랫폼을 한곳에 | 티스토리는 확장, 둘은 API라 발행 구조가 두 갈래로 섞임 |

추천 근거: 발행 엔진(`wordpress.ts`·`blogger.ts`)을 처음부터 **공용 기준 코드**로 만들면, 가안으로 시작해도 나중에 에이전트·티스토리에서 사본으로 가져다 쓸 수 있다(안 나·다의 장점도 뒤에 얻음).

## 6. 기능 범위(가안 1차)
1. 연결 설정(공용 연동 항목 `wordpress`·`blogger` 새로 추가 → 다른 프로그램도 재사용)
   - 워드프레스: 주소·사용자명·응용 비밀번호 → 「연결 확인」(본인 정보 조회로 검증)
   - 구글 블로그: 회원 구글 앱(유튜브용으로 등록돼 있으면 그대로) → 「구글 연결」 → 내 블로그 목록에서 고르기
2. 원고: 글감(주제·URL·키워드) → 회원 본인 Claude 키로 구글 검색용 원고(제목·메타 설명·슬러그·소제목·태그/라벨) → 편집 → 이미지(회원 본인 키, ai-image-studio 연동 방식)
3. 발행: 원고별 방식 선택(발행 전까지 / 바로 / 예약 시각), 카테고리·태그(라벨), 결과 기록(글 주소·예약 시각·실패 사유), 실패·불확실은 자동 재시도 없음
4. 보관함: 원고·발행 결과 목록, 플랫폼 글로 바로 가기

처음 설정: 워드프레스 3단계 · 구글 블로그 4단계 / 매일 조작: 원고 확인 후 발행 버튼 1번(예약이면 0번) / 동의: 구글 연결 1번.
