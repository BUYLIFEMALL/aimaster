# 검토 — G마켓·옥션 상품 자동 등록기 개발 가능성 (2026-11-11, [역할: ecommerce-image] `claude-win-sdp`)

주인님 지시: 「지마켓,옥션 상품자동 등록기도 개발 가능한지 자세히 검토하고 알려줘」. 조사만(코드·DB·배포 없음, 비용 없음). 확인 날짜 2026-11-11.

## ✅ 주인님 결정 (2026-11-11 채팅: 「사용자들도 안내해서 사용자별로 등록해서 사용하게 하면되잖아」)
**2안 채택 — 회원이 각자 ESM Trading API를 신청해 본인 키(마스터 ID·Secret Key)를 등록해 쓴다.** 운영자 셀링툴 키(1안)는 쓰지 않는다. 프로그램은 신청 방법을 단계별로 안내(신청 메일 초안 1초 복사 포함)하고, 키는 공용 `user_api_keys`에 회원별 저장.
- 남은 확인: 개인 판매자 승인이 실제로 나오는지·걸리는 기간·IP 등록 요구 → **주인님 계정으로 먼저 1건 신청해 확인**(시범). 승인 결과에 따라 안내 문구를 확정.
- 개발은 11번가 등록기 4단계 뒤 순서대로.

## 결론: 공식 API 방식은 「조건부 가능」
- 공식 API **ESM Trading API**(https://etapi.gmarket.com/ , 주식회사 지마켓, 문의 etapihelp@gmail.com) 운영 중(공지 2026-10-13·10-07, Q&A 2026-11-10).
- 2.0 통합상품 API: `POST https://sa2.esmplus.com/item/v1/goods` — **한 번에 G마켓·옥션 동시 등록**(한쪽만도 가능), 응답에 마스터 상품번호 `goodsNo` + 사이트별 상품번호.
- **키를 판매자가 화면에서 바로 받는 구조가 아님** — 메일 신청 → 심사(ESM 마스터 ID·서비스 주소·최근 3개월 매출·셀링툴이면 판매자 수) → 테스트 확인 → 운영 승인. 지마켓 재량, 거절·무응답 가능(https://etapi.gmarket.com/pages/API-가이드).
- 인증: JWT(HS256), `kid`=마스터 ID(셀링툴사는 자기 ID), payload `ssi="A:옥션ID,G:지마켓ID"` → **셀링툴 한 곳의 키로 여러 판매자를 판매자 ID만 바꿔 호출**. 허용 서버(IP) 확인 있음.
- 상용 솔루션(불사자·카페24·CJ 등)은 모두 「판매자가 ESM+ 판매자 정보 › 셀링툴 관리에서 업체 선택 + 솔루션에 ID 입력」 방식(업체 안내 문서 기준).

## 우리 원칙과 부딪히는 점 (주인님 결정 필요)
최상위 규칙은 「회원 본인 계정·본인 키」. ESM은 **셀링툴 키가 우리(운영자) 소유**이고 회원은 ESM+에서 「이 업체에 권한 위임」을 고르는 구조 → 운영자 키로 회원 요청을 처리하는 형태라 **규칙 해석이 필요한 회색 지대**. 회원 각자 신청(2안)은 원칙엔 맞지만 개인 판매자 승인 사례 미확인·신청 요건이 개발사 기준이라 현실성이 낮음(추정).
