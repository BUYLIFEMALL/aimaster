# 분석 중 다른 CLI의 최신 변경과 대조한 내용

분석 기준 `b3eab74b1e092d5eab4840bf30fdcbc084f6e0f1` 이후에도 다른 CLI가 기능·디자인을 갱신하고 있습니다. 참조 파일 변경은 `source-drift.json`의 비교 커밋 기준이며 전 프로그램 변경을 빠짐없이 실시간 감시하는 기록이 아닙니다.

| 변경 | 대조 결과 | 이 분석의 처리 |
|---|---|---|
| 카드뉴스 문구 API: 일반 기획 외 리메이크 분석/관점 분기 추가 | 최신 `copy/route.ts`는 일반 `parseCopy`와 `parseRemakeCopy`를 구분해 페이지 수를 검사합니다 | D-23-01의 기존 응답 검증 장점은 유지. 입력/문구 변경과 이미지/렌더 버전 연결은 별도 검토 후보입니다 |
| 카드뉴스 v1.18/v1.19: 회원 인스타 연결값 재사용·즉시 게시·예약/이력 | 최신 HANDOFF와 커밋 `b8abaa0a`, `2eff4d2f`에서 신규 작업을 확인했습니다 | 이를 미구현이라고 제안하지 않습니다. 이 분석의 타래 변환/사실 검토 후보와 구분합니다. 해당 CLI 기록을 보존합니다 |
| 인스타 공용 `instagram-publish` 기준/사본 분리 | 최신 INSTA AGENTS에 같은 회원 연결값을 재사용하는 구조와 기준/사본 점검을 기록했습니다 | 직접 앱 런타임 호출 없이 기준과 사본을 관리하는 원칙과 일치. 사용자별 생성물 공유 금지와 같은 회원 연동값 재사용은 구분합니다 |
| GIF 변환기: 화면 전면 개편·인라인 미리보기·상태 문구 | 최신 `ConverterWorkspace.tsx`를 다시 읽었습니다. `loadingRef`의 실패 후 초기화, 변환 예외 때 임시 파일/리스너 정리, 큰 파일의 filter/slice 처리 조건은 여전히 남습니다 | D-47-01/02의 재현 과제 유지. 새 미리보기 기능 자체를 미구현으로 제안하지 않습니다. 외부 API/실제 변환은 실행하지 않았습니다 |
| 이미지 업로드 공용 검사 추가(인플루언서/4컷/올인원 등) | 최신 개선 원장에 처리 버전이 추가됐습니다 | 이미 고친 깨진 사진 문제는 다시 결함으로 등록하지 않으며 회귀 검사 대상으로 유지합니다 |
| 마스터링/오디오/eBook의 디자인·가이드·README 갱신 | 최신 완료 문서와 기준 참조의 차이를 확인했습니다 | 디자인 완료와 본 분석의 입력/권한/복구 후보를 분리합니다. 예전 README 문구를 현재 화면 설명으로 단정하지 않습니다 |
| 부동산 오래된 개선 원장과 v1.12~1.15 코드/기록 | 개인 캐시·명시적 상세 분석·예약 알림 선택·체크박스 저장 반전 수정이 이미 있음 | 공유 AI 캐시나 상세 자동 분석을 현재 결함으로 다시 제안하지 않습니다. 동시 유료 호출·저장 오류·운영 증거 보강만 검토합니다 |

후속 CLI는 이 표가 작성된 뒤 완료된 작업도 있을 수 있으므로 최신 커밋·프로그램 원장·ACTIVE_WORK를 다시 확인합니다. 다른 CLI 작업을 되돌리거나 완료 기록을 삭제하지 않습니다.
