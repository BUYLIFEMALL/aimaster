## 현재 기능과 보존할 장점

엑셀(.xlsx·.xls·.xlsm)과 CSV를 머리글 이름 기준으로 한 표에 이어 붙입니다. 열 순서가 달라도 같은 열끼리 맞추고, 남길 열·순서 선택, 같은 행 제거, 원본 파일·시트 표시 열 추가를 지원합니다. / 엑셀은 시트별·특정 열 값별·N행씩 나눠 ZIP으로 저장하고, 원본 서식 유지를 켜면 합치기·나누기 결과에 글꼴·색·테두리·열 너비가 그대로 남습니다. / 텍스트는 순서·구분자를 정해 합치고, 긴 글은 글자 수·조각 수·문장 수 기준으로 문단 경계를 지켜 나눕니다. 한글(ANSI)·UTF-8 인코딩도 자동으로 알아봅니다.

**보존할 장점:** 헤더 정합·중복 제거·서식 유지

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
