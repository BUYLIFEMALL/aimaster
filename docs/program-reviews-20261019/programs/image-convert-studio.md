## 현재 기능과 보존할 장점

이미지를 최대 300장 올려 WebP·PNG·JPEG·AVIF로 한꺼번에 변환하고, 최대 너비·높이를 정해 크기를 제한한 뒤 결과를 ZIP으로 받습니다. / 0.5배~4배로 확대·축소하고, 선명도 보정을 켜면 확대해도 또렷함을 유지합니다. / 여러 장을 격자·가로·세로 레이아웃의 한 장 콜라주로 합쳐 저장합니다. 화면은 한국어와 English를 지원합니다.

**보존할 장점:** 브라우저 이미지 변환·압축

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
