## 현재 기능과 보존할 장점

키워드를 넣고 네이버 또는 구글을 고르면 검색 결과를 분석합니다. 네이버는 자연검색·연관검색어·뉴스·쇼핑·동영상·인플루언서를, 구글은 자연검색·사람들이 묻는 질문·연관검색어를 봅니다. / AI가 연관 키워드를 고르고 관련도 점수를 매긴 뒤, 그 아래로 롱테일 키워드를 다시 확장합니다. 키워드마다 따로 저장되어 섞이지 않습니다. / 전체를 종합해 블로그 담당자에게 바로 전달할 「이번에 무엇을 써야 하는지」 작업 지시문을 만들어 줍니다.

**보존할 장점:** 키워드 확장과 담당자용 작업 지시

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
