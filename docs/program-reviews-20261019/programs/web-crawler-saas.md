## 현재 기능과 보존할 장점

상품명·가격·평점 같은 원하는 항목을 적으면 AI가 페이지 구조를 살펴 그 항목이 있는 위치를 자동으로 찾아냅니다. / 같은 사이트는 이전에 파악한 구조를 재사용해 빠르고 비용이 적게 들고, 수집이 끝나면 결과를 엑셀 파일로 바로 내려받습니다. / robots.txt에서 막은 곳은 수집하지 않고, 자동 접근 차단(CAPTCHA·방화벽)이 감지되면 멈춘 뒤 계속할지 회원이 직접 정하게 합니다.

**보존할 장점:** AI 기반 구조 탐색과 표 데이터 수집

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
