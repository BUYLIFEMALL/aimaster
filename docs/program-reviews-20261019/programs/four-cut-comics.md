## 현재 기능과 보존할 장점

AI가 대본과 등장인물을 만들고, 인물별 캐릭터 그림을 모든 컷에 참고해 같은 인물이 같은 모습으로 나오게 그립니다. 컷 비율·그림 스타일 8종·장르 11종·단편/연재를 고릅니다. / 대본의 장면·대사를 고치고 캐릭터나 컷 단위로 다시 그리며, 한글 대사는 컷의 빈 곳에 말풍선으로 자동 배치됩니다. 말풍선은 끌어서 옮기고 크기·꼬리·색을 바꿉니다. / 인스타그램 게시 문구와 해시태그를 만들고, 같은 인물로 다음 화를 이어 만들어 한 장 이미지나 컷별 ZIP으로 저장합니다.

**보존할 장점:** 4컷 스토리·캐릭터·합성

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
