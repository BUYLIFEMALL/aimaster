## 현재 기능과 보존할 장점

주제를 넣거나 [오늘 뭐 쓰지?]로 업종·타깃별 추천 주제 10개를 받고, 가전·살림 주부형·자취생형·워킹맘형 같은 상황별 페르소나 버튼을 누르면 생생한 1인칭 글이 바로 나옵니다. / 피드를 멈추게 하는 첫 문장 훅(자책·부정 명령·썰·논쟁·반전), 4단계 공감 본문, 첫 댓글 CTA, 이어 쓸 후속 아이디어 5개까지 한 번에 완성합니다. / 「더 자극적으로」「더 자연스럽게」 같은 7종 원클릭 다시 쓰기로 문장을 빠르게 바꿔 보고, 휴대폰에서도 같은 흐름으로 씁니다.

**보존할 장점:** 페르소나·훅·본문·CTA 기획

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.

1. 최신 공통 지침·ACTIVE_WORK·이 프로그램 AGENTS/README·개선 원장을 읽고 다른 CLI 변경과 대조합니다.
2. 위 첫 항목부터 실제 남은 문제인지 확인하고, 이미 완료됐으면 완료 증거를 연결합니다. 수정 전 개발 플랜을 제시합니다.
