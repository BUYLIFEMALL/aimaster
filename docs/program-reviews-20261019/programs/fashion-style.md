## 현재 기능과 보존할 장점

인물 사진을 올리고 면접·데이트·공항 패션 같은 상황을 적으면 의상과 액세서리를 추천하고 아이템 이미지를 만들어 내 옷장에 담아 줍니다. / 아이템을 사진 위로 끌어다 놓거나 눌러서 입혀 보고, 겹쳐 입기·갈아입기, 배경 유지 또는 상황에 맞게 변환을 고릅니다. 되돌리기와 원본 비교로 결과를 확인합니다. / AI 뷰티 스튜디오가 얼굴과 스타일을 분석해 메이크업·헤어스타일을 제안하고 적용해 주며, 결과는 PNG·JPEG로 저장합니다.

**보존할 장점:** 인물/의상 중심 스타일 제작

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
