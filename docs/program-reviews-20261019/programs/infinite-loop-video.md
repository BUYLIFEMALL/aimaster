## 현재 기능과 보존할 장점

영상을 올리면 프레임을 비교해 이음새가 가장 자연스러운 구간을 자동으로 찾아 줍니다(스마트 루프). / 크로스페이드로 이음새를 감추거나, 전체를 1초 겹치거나(강제 오버랩), 앞뒤로 왕복(바운스)시키는 방식도 고를 수 있습니다. / 시작·종료 지점을 0.01초 단위로 다듬고 반복 횟수를 1~200회로 정해 MP4·WebM(소리 유지)·GIF로 저장합니다.

**보존할 장점:** 무료 로컬 루프 분석·크로스페이드

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
