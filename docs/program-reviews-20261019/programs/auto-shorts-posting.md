## 현재 기능과 보존할 장점

뉴스 URL·RSS·실시간 트렌드 검색으로 쇼츠 주제를 모으면, AI가 스토리와 6장면의 대사·이미지 프롬프트를 만들어 줍니다. / 장면별 이미지는 나노바나나로, 배경음악은 Suno로 만들고, 단계마다 결과를 검토하고 고치며 진행합니다. / 완성된 소재를 내레이션·자막과 합쳐 최종 영상으로 만든 뒤 유튜브 쇼츠와 인스타그램 릴스에 올립니다.

**보존할 장점:** 스토리·장면·음악·영상·게시 흐름

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
