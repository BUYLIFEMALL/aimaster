## 현재 기능과 보존할 장점

분야와 핵심 주제(AI 추천 가능), 어조(일반·진지·국뽕·유머·넉살), 페이지 수(4·6·8·10장), 비율(4:5·1:1)을 정하면 AI가 페이지별 제목·보조 문구·카드 아이콘을 씁니다. / 화풍(실사·디지털 아트·3D·수채화)·구성·테마 컬러에 맞춰 배경 이미지를 만들고, 글꼴·배치·그림자·외곽선·형광펜 효과를 실시간 미리보기로 조절합니다. / 완성한 카드는 PNG나 ZIP으로 저장하고, 후킹 카피·본문 요약·CTA·해시태그가 담긴 피드 캡션도 만듭니다. 프로젝트는 보관함에 자동 저장됩니다.

**보존할 장점:** 본문 기획·타이포·다중 카드 렌더

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
