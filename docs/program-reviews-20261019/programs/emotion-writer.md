## 현재 기능과 보존할 장점

명언·좋은 글, 건강·행복 기원, 카톡·밴드 공유 문구 중 주제를 고르면 AI가 글귀 5개를 만들고, 직접 쓴 문구를 그대로 써도 됩니다. / 배경은 나노바나나로 만들거나 Pixabay·Pexels 사진 중에서 고르며, 9:16·1:1·3:4 비율을 지원합니다. / 한글 글꼴·글자 색·배치·줄 수를 조절해 문구를 배경 위에 합성하고 PNG 또는 JPG로 저장합니다.

**보존할 장점:** 직접 타이포 합성·여러 비율

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
