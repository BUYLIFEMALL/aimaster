## 현재 기능과 보존할 장점

촬영 목적을 고르면 비율·조명·배경·복장·포즈·필름 룩이 한 번에 맞춰지고, 항목을 직접 조합하거나 입꼬리·어깨·잔머리·눈높이를 다듬을 수 있습니다. / 한 번에 2~4장의 후보를 만들어 확대 비교로 고르고, 같은 설정으로 여러 장을 일괄 생성해 ZIP으로 저장합니다. / 한국·미국·영국·일본 등 공식 안내 기준 규격 21종으로 저장하고, 순백 배경 정리와 머리 비율 검사를 지원합니다. 공식 서류 통과를 보장하지는 않습니다.

**보존할 장점:** 규격 저장·로컬 얼굴/품질 점검

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
