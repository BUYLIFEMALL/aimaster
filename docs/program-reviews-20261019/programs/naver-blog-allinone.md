## 현재 기능과 보존할 장점

경험·전문성·권위·신뢰(E-E-A-T)를 기준으로 5가지 방향의 주제를 발굴하고, 최신 뉴스와 자동완성 키워드로 경쟁 키워드를 비교합니다. / 올린 사진을 바탕으로 홈판 노출용 감성 스토리나 정보형 SEO 글 중 원하는 모드로 원고를 씁니다. / 네이버 스마트에디터 ONE에 맞는 서식 HTML과 티스토리·워드프레스용 마크다운을 함께 만들고, 전용 크롬 확장으로 글쓰기 화면에 제목과 본문을 입력합니다.

**보존할 장점:** 네이버 작업 흐름을 한곳에서 조합

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
