## 현재 기능과 보존할 장점

구글 검색 결과를 자연 검색·광고·사람들이 묻는 질문(PAA)·지역 결과로 나눠 보여 줍니다. 광고는 돈을 써서 경쟁하는 곳, 질문은 아직 다뤄지지 않은 콘텐츠 기회입니다. / 검색에 나온 사이트마다 어떤 회사인지 AI가 조사해 정리하고, 같은 사이트는 저장된 정보를 재사용해 비용을 아끼며, 내 경쟁사로 표시해 계속 지켜봅니다. / AI가 경쟁사의 강점·차별점(USP)·내가 쓸 콘텐츠 아이디어를 담은 리포트를 만들고, 보기 좋은 HTML 리포트로 바꿔 줍니다.

**보존할 장점:** 키워드/경쟁사 리서치·보고서

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
