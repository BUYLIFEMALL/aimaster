## 현재 기능과 보존할 장점

주제·분위기, 보컬 성별(선택), 언어를 넣으면 AI가 장르 스타일과 제외할 스타일, 「한글 제목(English Title)」 형식의 제목과 설명을 기획합니다. / 보컬 버전과 연주곡 버전을 골라 생성하면 보컬은 AI가 가사 전체를 쓰고, 연주곡은 배경음악 프롬프트를 만들어 Suno에 요청합니다. 완성되면 음악과 커버 이미지가 내 보관함에 저장됩니다. / 보컬 곡의 가사를 직접 고친 뒤 [수정해서 재생성]을 누르면 스타일·제목은 그대로 두고 새 가사로 다시 만들며, 이전 결과도 남습니다.

**보존할 장점:** 본인 음악 서비스 키·곡 생성/관리

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
