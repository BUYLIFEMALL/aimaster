## 현재 기능과 보존할 장점

이미지를 올리면 AI가 카메라(앵글·샷·렌즈·심도), 조명(시간대·방향·대비), 실제 픽셀로 계산한 색상 팔레트, 스타일 핵심 요소를 분석해 영어·한국어 프롬프트를 만듭니다. / [스타일 복제]는 원본의 구도와 화풍을 그대로 재현하고, [스타일 변형]은 강도(0~100%)와 추가 지침에 맞춰 새롭게 재해석합니다. / 프롬프트를 바로 다듬고, 원하는 피사체로 실제 이미지를 만들어 원본과의 색감 일치율(%)을 비교합니다. 분석 결과는 보관함에 자동 저장됩니다.

**보존할 장점:** 실측 팔레트+이미지 스타일 역분석

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
