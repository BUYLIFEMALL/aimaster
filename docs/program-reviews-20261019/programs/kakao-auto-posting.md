## 현재 기능과 보존할 장점

주제(키워드 최대 10개)를 등록하고 [지금 생성]을 누르면 Perplexity가 최근 1~2주의 뉴스·정책·트렌드를 찾고, AI가 제목·카카오톡용 짧은 요약(300자 이내)·웹 리포트 본문으로 정리합니다. / SOLAPI를 거쳐 내 카카오톡 채널(친구톡·브랜드메시지)로 보내고, 리포트는 웹 화면에서 보며 카카오톡 공유로 원하는 채팅방에도 보낼 수 있습니다. / 카카오 오픈채팅방에는 공식 자동 게시 기능이 없어, 공식 API가 지원하는 카카오톡 채널 발송과 공유 방식만 씁니다.

**보존할 장점:** 뉴스 수집·요약·채널 발송

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
