## 현재 기능과 보존할 장점

30종 피부 텍스처를 조합해 외형을 꾸미고, 인물·장소 레퍼런스 이미지를 넣어 모든 컷에서 같은 모습이 유지되게 합니다. / 20대 K-인플루언서의 하루를 5개 타임라인으로 AI가 기획하고, 표정·포즈·앵글을 정해 컷마다 화보를 만듭니다. / 광고·공동구매 제품을 합성한 PPL 컷을 만들고 어색한 부분은 2중 보정으로 다듬으며, 분위기가 다른 캡션 3종과 해시태그를 함께 생성합니다.

**보존할 장점:** 외형·일상 콘티·PPL 컷 제작

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
