## 현재 기능과 보존할 장점

블로그 주소로 최신 글을 모아 어조·문장·구성·독자를 분석하고, 승인한 스타일과 주제로 검색어 후보를 찾아 월간 검색량·블로그 문서수로 골드·실버 등급을 매겨 보관합니다. / 최신 뉴스·웹 자료에서 새 용어를 찾아 검색 급상승 여부를 확인하고, 같은 주제 블로그의 최근 글 주제와 제목 방식도 분석합니다. / 고른 검색어의 상위 글 5개에서 근거가 확인된 정보만 정리해 직접 승인하면, 그 자료로 제목·구성을 만들고 구간별로 초안을 씁니다. / 문체·작성 원칙·사실·경험 표현·유사 표현·과장 표현을 검수해 최종본을 복사·TXT로 저장하고, 문단에 맞춘 대표·본문 이미지도 만듭니다.

**보존할 장점:** 글/이미지를 편집하는 집중형 작업실

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
