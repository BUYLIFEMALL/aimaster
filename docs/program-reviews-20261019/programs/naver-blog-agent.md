## 현재 기능과 보존할 장점

기획 → 작성 → 윤문으로 이어지는 에이전트가 글을 완성하고, 대표 이미지를 포함해 1~5장의 이미지를 만들어 컷별로 다시 만들거나 교체합니다. / 서식과 이미지가 반영된 화면에서 글을 확인·수정하고 [최종원고 수정 및 확인 완료]를 체크해야 다음 단계로 넘어가, 확인하지 않은 글이 나가지 않습니다. / 확장이 네이버 스마트에디터에 제목·본문·이미지를 사람이 치듯 입력하고 카테고리·태그·공개 설정을 맞춥니다. 준비 모드를 고르면 발행 직전까지만 입력해 두고 직접 발행합니다.

**보존할 장점:** 수집·개인 글쓰기·발행 연계

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
