## 플랫폼별 API 인벤토리 (요약)

**NAVER 개발자센터 Open API** — 검색 API(뉴스/블로그/쇼핑 등 8종, 일 25,000회), 데이터랩
검색어 트렌드/쇼핑 인사이트(일 각 1,000회, 절대값 아닌 상대값), 네이버 로그인/회원 프로필/공유하기
(OAuth, 무제한), 캘린더(OAuth, 일 5,000회), 카페 가입/글쓰기(OAuth, 일 50회/200회).

**NAVER Cloud Platform** — SENS(SMS/LMS/MMS/알림톡, Access/Secret Key HMAC-SHA256, SMS 1회
최대 100건·90바이트, 요청-서버 시간차 5분 초과 시 인증 실패), Cloud Outbound Mailer(동일 인증),
CLOVA Studio(Bearer API Key, 실서비스는 서비스 API 키·앱 등록 필요), CLOVA OCR(Invoke URL+
X-OCR-SECRET), CLOVA Speech(Invoke URL+Secret, 단문 60초/실시간 스트리밍), Maps/Papago(Client
ID/Secret 헤더, HMAC 불필요).

**카카오 API** — 카카오 로그인/카카오싱크(OAuth), 메시지(나에게/친구에게, Bearer Token, 같은
서비스 로그인 사용자 간 전용), 알림톡/브랜드 메시지(REST API 키, **딜러사 경유 필수** — 카카오
키로 직접 호출 불가, NCP SENS 등), 카카오톡 채널(고객파일/웹훅), 톡캘린더(OAuth, 별도 동의+
권한 심사).

**부동산 공공데이터** — 국토교통부 실거래가(공공데이터포털, 일 10,000건 개발계정), 건축HUB
건축물대장, VWorld 공간정보, 한국부동산원 R-ONE(인증키 발급 후 REST JSON/XML).

## 핵심 리스크 (착수 전 반드시 확인)

1. **네이버 카페 자동 가입·글쓰기는 매크로성 자동 홍보로 계정 정지 소지가 크다.** 일 가입
   50회·글쓰기 200회 한도도 사업 규모에 비해 낮음 — 착수 비권장.
2. **카카오 알림톡/브랜드 메시지는 카카오 API 키만으로 발송할 수 없다.** NCP SENS, 알리고,
   솔라피 등 공식 딜러사를 반드시 경유해야 한다.
3. **데이터랩 트렌드·쇼핑인사이트 수치는 절대 검색량·매출이 아니다.** 최댓값을 100으로 둔
   상대지표다.
4. **부동산 자동 분석 리포트는 실거래가(과거 신고가)일 뿐 현재 호가가 아니며, 권리관계는
   건축물대장으로 확인되지 않는다.** "감정평가·법률 상담 아님, 참고용"임을 결과물에 명시할 것.
5. **CLOVA Studio·SENS 알림톡 등 다수 API가 사업자 등록과 서비스용 키 별도 심사를 요구한다.**
   테스트 키로 프로토타입은 가능하나 실서비스 전환 승인 소요 기간을 로드맵에 반영할 것.

   검토한다(멀티테넌시 원칙, 프로그램 카탈로그 단위와도 맞음).
