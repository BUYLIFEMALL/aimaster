## 5. 병합 vs 독립 — 판단

| 기준 | 판정 |
|---|---|
| 같은 일 | ○ 음악 + 배경 + 스펙트럼 → 유튜브 플레이리스트 MP4 = `playlist-channel-studio` 영상 만들기 |
| 같은 사용자 | ○ 플레이리스트·BGM 채널 운영자 |
| 한 흐름 | ○ 곡 준비 → 꾸미기 → 렌더 → 유튜브 |
| 독립 조건 | 해당 없음(데스크톱이라는 구현 방식 차이뿐). 같은 원본의 웹 버전이 이미 `yt-playlist-studio` → `playlist-channel-studio`로 병합 완료 |

**의견: 독립 개발 안 함 → 좋은 기능만 `playlist-channel-studio` 「영상 만들기」에 병합.** S2(인코딩 안정화)는 공용 기준 코드라 쇼츠 등 다른 영상 프로그램에도 함께 이득.
