## 1. 추천 결론

**7개를 전부 하나로 합치기보다, 역할이 다른 4개를 남기고 중복 제작기 3개의 장점을 이관하는 방향을 추천합니다.**

| 남길 역할 | 기준 후보 | 흡수할 기능 | 이관 후 별도 신규 개발 중단 후보 |
|---|---|---|---|
| 네이버 일반 콘텐츠 제작·발행 준비 | 네이버 블로그 에이전트 | BLOG의 자료 수집/서식 편집/이미지 배치, 올인원의 사진 후기/템플릿 | BLOG(원문)생성 자동화, 네이버 블로그 올인원 |
| 키워드·트렌드·경쟁 기회 분석 | AI 블로그 키워드 자동화 | 작업실의 키워드 등급/추이 계산 중 검증된 부분 | 중복 ‘키워드 파인더’ 전체를 별도 제품으로 유지할 필요 없음 |
| 근거 중심 정밀 집필·기존 글 리뉴얼 | 네이버 블로그 SEO 스튜디오 | 작업실의 내 문체·자료 승인·구간별 집필·검수 이력·이미지 노드 | AI 블로그 작업실 자동화 |
| 티스토리 콘텐츠 제작·발행 준비 | 티스토리(원문)생성 자동화 | 안정된 수집/AI 호출 부품만 공용 기준/사본으로 정리 | 별도 중단하지 않음 |

**이것은 제품 구성 추천입니다. 에이전트/SEO가 모든 면에서 이미 더 안정적이라는 판정은 아닙니다.** 에이전트의 옛 원고 자동 발행 기본값, 올인원의 부분 입력 성공 판정, 공개 이미지 경로와 30일 만료 점검을 먼저 해결/검증해야 기준 프로그램을 확정할 수 있습니다.

‘개발 중단’은 우선 **독립 신규 기능 개발을 멈추는 것**입니다. 기존 회원 접근 차단·사이트 삭제·권한 이전·데이터 이전·확장 폐기·도메인 삭제를 지금 실행한다는 의미가 아닙니다.

## 3. 프로그램별 기능·동작 방식·고유 가치

### 3-1. 네이버 블로그 에이전트 — 운영 중심의 메인 제작기 후보

| 구분 | 분석 |
|---|---|
| 기준 버전/주소 | v1.96 · https://naver-blog-agent.buylife.xyz |
| 입력 | 주제·카테고리·키워드·페르소나·분량·본문 AI/이미지 모델, 글감 후보, 쇼핑 링크, 본인 블로그 |
| 작동 | 글감 수집 → 기획 → 본문 → 윤문 → AI 검수 → 이미지 → 원고 보관/회원 확인 → 대기열 → 본인 확장이 1건 선점 → 네이버 입력/발행 설정 → 선택 모드에 따른 준비 또는 발행 |

| 겹치는 부분 | 주제·키워드·본문·이미지 생성은 BLOG/올인원/SEO와 겹침. Research라는 단계 명칭만으로 실제 외부 자료 조사가 되는 것은 아님 |

| 유지 판단 | **조건부 유지·기능 확장 중심 후보.** 이미 준비된 흐름을 새로 만드는 것보다 기존 큐/안전 게이트를 보존하며 부족한 기능을 흡수하는 편이 합리적 |

사진 작성량이 실제 이용 통계에서 매우 크고, 독립적으로 자주 쓰이는 간단한 사진 도구 수요가 확인되면 보조 앱 유지도 가능합니다. 현재는 그 통계를 조사하지 않았으므로 독립 유지의 근거로 삼지 않았습니다.

| 주의 | 근거 구절/문자열 일치는 모든 문장 사실 확인이나 법적 표절 판단이 아님. 저장 개수 제한과 30일 만료는 별개, 공개 이미지 경로/삭제 연계 확인 필요 |
| 처리 추천 | 기능 자체를 버리지 말고 **SEO 스튜디오의 ‘자료부터 정밀 집필’ 모드로 흡수**. 섹션별 저장·승인 상태를 보존한 뒤 독립 신규 개발 중단 후보 |

이관이 길어지면 작업실은 당분간 별도 전문 도구로 유지합니다. 핵심 기능을 옮기기 전에 먼저 중지하면, 이번 7개 중 근거 중심 집필 기능을 가장 크게 잃게 됩니다.

## 6. 우선 해결·확인할 문제

P0=통합/공개 전 우선 안전 점검, P1=이관 품질/데이터 일관성, P2=편의·유지보수. 점검 후보와 운영 재현 결함을 구분합니다.

운영 개발에서는 작업실의 구간 수만큼 글 호출이 생길 수 있고, 에이전트/올인원은 기획·작성·윤문·검수, SEO는 짧은 본문 보강 최대 2회, 이미지와 검색은 별도 호출입니다. 통합한다고 모든 경로를 연달아 호출하면 비용이 오히려 늘어납니다. 기본 빠른 작성/사진 후기/정밀 집필 모드를 분리하고 예상 호출과 필요한 본인 키를 실행 전에 안내해야 합니다.

추가 개발 제안(미구현): **회원 개인 콘텐츠 작업 묶음**. 선택한 키워드의 근거·주제·자료·검수·원고·사진을 본인 작업 ID로 이어, 다른 화면으로 이동해도 다시 검색/생성하지 않고 필요한 단계만 실행합니다. 같은 회원/같은 권한 범위·원래 30일 만료 유지가 전제입니다. 화면 하나로 모든 기능을 모으는 것보다 반복 입력과 재과금을 줄이는 방향입니다.

승인 시 첫 개발 단위 추천: 다른 CLI의 에이전트 v1.97를 인수·검수한 다음, **에이전트 ‘사진으로 후기 쓰기’ 모드**를 올인원과 기능 대조표를 작성해 작은 범위로 이관합니다. 동시에 나머지 프로그램을 중단하지 않습니다.
