## 재개 시 반드시 보존할 것

- 기존 네이버 준비 탭과 미발행 원고를 임의로 새로고침/발행하지 않는다. 직전 검수는 7개 탭 보존 이력이며 재개 시 현재 창·탭·실행 중 작업을 다시 확인한다. Edge PID/HWND/요소 인덱스는 재사용 가능한 상수가 아니다.
- 회원 원본 사진·생성 원고·출처의 소유자와 최초 생성/수집 기준 30일 만료를 보존한다. 실제 키/토큰·회원 본문·원시 화면 덤프를 문서/커밋에 넣지 않는다.
- SEO/키워드/티스토리 독립 유지와 BLOG/올인원/작업실의 조건부 기능 이관 추천을 서비스 폐기 승인으로 해석하지 않는다. 실제 계정/권한·도메인·자료 전환은 해당 실행 범위를 확인한다.
- 다른 CLI의 폴더·공통 문서·미커밋·스테이징은 보존한다. 이 인수인계는 담당 폴더 잠금을 이전하지 않으며, 시작 전 ACTIVE_WORK와 Git 상태를 다시 확인한다.
