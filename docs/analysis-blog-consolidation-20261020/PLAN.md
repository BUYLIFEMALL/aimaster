# 블로그 자동화 프로그램 비교·통합 개발 제안 분석 계획

- 요청일: 2026-10-20. 대상: ① AIMaster 운영 프로그램. 운영 DB ref `esgxyikcnnvmlhygjkth`(이번 분석에서 쓰기 없음).
- 목표: 화면의 7개 프로그램을 실제 코드로 비교해 기능·동작 방식·중복·차별점·안정성·통합 후보·개발 유지/중단 후보를 근거와 함께 제시합니다.
- 범위: 티스토리 원문생성(`tistory-auto-blog`), AI 블로그 키워드(`blog-keyword`), BLOG 원문생성(`ai-auto-blog`), 네이버 블로그 에이전트(`naver-blog-agent`), 네이버 블로그 올인원(`naver-blog-allinone`), AI 블로그 작업실(`blog-workroom`), 네이버 블로그 SEO 스튜디오(`naver-blog-seo-studio`). 옛 전송 도구 `naver-blog-auto-poster_web`는 확장/대체 경로 참고 자료로 추가 조사합니다.
- 순서: 최신 지침·작업 중 표·Git 상태 확인 → 프로그램별 문서와 소스/확장/스키마 추적 → 기능표/동작 흐름/중복과 고유 가치 대조 → 통합 기준·기능 이관표·위험/검수 기준·단계별 중단 조건 → 제안서/인수인계/아이디어 원장 기록.
- 조사 방법: `research` 스킬. 읽기 전용 배경 조사와 담당 파일별 증거 문서를 분리하고 최종 비교는 하나로 합칩니다. 운영 소스·공유 스테이징은 수정하지 않습니다.
- 주의: `naver-blog-agent`는 다른 Claude CLI가 v1.95를 개발 중입니다. 읽기만 하며 현재 HEAD 확정 상태와 미커밋 개발 중 기능을 구분합니다. 그 프로그램의 문서를 수정하거나 빌드/실행하지 않습니다.
- 검수: 모든 주요 기능을 진입 화면 → 서버/엔진 → 저장 → 확장/출력 코드에 연결하고, 문서 표현과 실제 구현의 차이를 명시합니다. 문서의 과거 테스트 기록·이번 분석에서 실제 실행한 검사·운영 검수 미실행을 구분합니다.
- 비용/변경: 유료 AI 호출 0, 실제 블로그 발행 0, 프로그램 통합/중단/데이터 이전/스키마·키·환경변수 변경/배포 없음. 분석 제안은 개발 승인으로 간주하지 않습니다.
- 산출물: 프로그램별 소스 근거 3개 문서, 전체 비교 제안서, 표를 보기 쉽게 읽을 HTML 보고서, 다음 CLI 인수인계와 공통 아이디어 원장 요약. 앱 버전은 올리지 않습니다(동작 코드 변경 없음).
