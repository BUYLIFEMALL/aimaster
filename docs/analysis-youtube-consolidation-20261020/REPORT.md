결과: 유튜브 관련 10개 → **7개**(C·D·E 후), F 진행 시 6개.

## 4. 진행 순서 제안
1. 병합 C(분석 2개) — 가장 쉽고 효과 큼. 1단계 화면·기능 이식 → 2단계 대시보드·중복 기능 정리(공략 채널 하나로) → 3단계 옛 주소 이동·노출 중지(주인님 확인).
2. 병합 D(썸네일 2개) — 마스터에 SEO 메타데이터 단계 이식, 프로의 브라우저 키 문제 해소.
3. 병합 E(플레이리스트 2개) — 렌더 앱에 기획 화면 이식, 분야 변경.
4. F는 엔진 공유(업로드·브라우저 렌더)부터.
각 병합은 인스타 때처럼 플랜 → 승인 → 단계별 배포, 요금·권한은 그대로(회원 본인 계정·키 최상위 규칙 유지), 병합 전 DB `programs` 줄 백업.
