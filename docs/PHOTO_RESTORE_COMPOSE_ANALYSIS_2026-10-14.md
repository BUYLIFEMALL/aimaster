조사일: 2026-10-14. 요청 범위는 상세 분석, AIMaster 기존 프로그램과 비교, 프로그램 이름 추천입니다. 구현·프로그램 등록·환경변수/DB 변경·배포는 수행하지 않았습니다.

## 1. 판단

참고 앱은 사진에 글귀를 얹는 도구가 아니라 **사진 합성 + 오래된 사진 복원·컬러화** 도구입니다. 기존 **AI 바나나 캔버스 자동화 v1.03**에 합성·복원·컬러화·2배/4배 확대·AI 합성 지시 제안이 모두 구현되어 있습니다. 기능 단위로는 상당히 중복됩니다. 원본에는 새로운 전용 복원 모델이나 별도 합성 엔진이 없으며 Gemini 이미지 모델에 작업별 지시문을 전달합니다.

권장 방향은 기존 바나나 캔버스에 초보자용 복원·사물 합성 화면과 세부 프롬프트를 보강하는 것입니다. 별도 프로그램을 만든다면 가족사진·추억사진 복원에 특화하고, 전후 비교·얼굴 보존·실제 출력 크기 확인·간단한 단계별 화면을 차별점으로 두는 것이 좋습니다. 별도 개발은 주인님의 후속 지시 범위에서 진행합니다.

## 3. 원본 기능과 작업 흐름

### 이미지 합성

1. 인물/배경이 들어 있는 기본 사진 1장을 올립니다.
2. 착용하거나 사용할 사물 사진을 여러 장 추가합니다. 개별 삭제는 가능하지만 코드에 최대 장수 제한은 없습니다.
3. 사용자가 합성 지시를 입력하거나 AI 프롬프트 제안을 받습니다.
4. AI 제안은 모든 사물을 분석해 첫 번째·두 번째 사물별 착용/사용 동작을 한국어로 작성하도록 요구합니다.
5. 최종 생성 전에 한국어 지시를 영어로 번역합니다.
6. 기본 사진 → 모든 사물 사진 → 통합 지시 순서로 Gemini 이미지 모델에 전달합니다.
7. 생성 이미지 표시, 다운로드, 최근 작업 목록 추가로 이어집니다.

합성 지시의 핵심은 모든 사물 포함, 사물 디자인·색·모양·질감 유지, 손/착용 위치의 자연스러운 변화, 조명·그림자·원근 일치입니다. 고정 프롬프트에 얼굴 동일성 보존 지시는 없습니다.

### 사진 복원·컬러화

- 기본값: 손상 복원 켬, 자동 컬러화 켬, 확대 2x.
- 복원 선택: 긁힘·찢어짐·빛바램 복원 및 선명화 지시.
- 컬러화 선택: 세피아/단색 필터를 피하고 피부·옷·하늘·사물에 현실적인 색을 적용하도록 지시.
- 확대 선택: 없음 / 2x / 4x.
- 옵션 변경 시 지시문을 로컬에서 다시 만듭니다. 옵션 변경 자체는 AI 호출이 아닙니다.
- 복원 화면의 AI 프롬프트 제안 버튼도 로컬 문자열 조합입니다. 합성 화면의 제안 버튼과 달리 AI를 호출하지 않습니다.
- 직접 수정한 지시문은 다음 옵션 변경 때 자동으로 덮어써집니다.

### 결과·기록·화면

- 사진 클릭 업로드와 드래그 업로드, 미리보기, 로딩 문구, 오류 표시, 다운로드가 있습니다.
- 최근 작업은 React 메모리 상태에 최대 10개를 보관합니다. 영구 보관이 아니며 새로고침하면 사라집니다.
- 기록 카드에는 재편집·별도 다운로드·삭제 핸들러가 없습니다.
- 홈으로 돌아가 작업 화면을 다시 열면 해당 화면의 입력·결과 상태가 초기화됩니다.
- 출력 형식 선택, 실제 해상도 설정, 전후 비교 슬라이더, 일괄 복원, 마스크 부분 복원은 구현되어 있지 않습니다.
- 화면은 흰색 카드·옅은 stone 배경·rose 포인트입니다. 상단 홈 메뉴와 합성/복원 진입 카드로 구성됩니다.

## 4. 기술 구조·AI 호출

원본은 React 19 + TypeScript + Vite 기반 클라이언트 앱입니다. Tailwind CDN과 Google Fonts를 사용하며 별도 회원 서버·DB·앱 API route는 없습니다. `services/geminiService.ts`에서 `@google/genai`를 호출합니다.

| 동작 | 원본 소스에 지정된 모델 | 호출 수 |
|---|---|---|
| 합성 AI 제안 | `gemini-3-flash-preview` | 제안 버튼마다 1회 |
| 한국어 지시 영어 번역 | `gemini-3-flash-preview` | 지시가 있으면 생성마다 1회 |
| 이미지 합성 | `gemini-3-pro-image-preview` | 생성마다 1회 |
| 사진 복원 | `gemini-3-pro-image-preview` | 생성마다 1회 |
| 복원 옵션 지시문 만들기 | 로컬 문자열 조합 | 0회 |

따라서 일반적인 합성/복원 실행은 번역 1회 + 이미지 생성 1회입니다. 합성 AI 제안을 먼저 누르면 총 3회입니다. 이는 코드상 정상 경로 분석이며 이번 조사에서 실제 공급사 요청은 보내지 않았습니다. 모델명이 소스에 있다는 사실을 현재 모든 계정에서 호출 가능하다는 의미로 해석하지 않습니다.

## 5. 그대로 도입하면 안 되는 부분

1. **키 전달 구조**: `vite.config.ts`가 환경변수 Gemini 키를 `process.env.API_KEY`로 클라이언트 코드에 치환합니다. 키가 들어 있는 일반 배포에서는 브라우저 번들에 키가 포함될 수 있습니다. AIMaster에는 로그인 회원 본인 키를 서버에서 조회하는 구조로 구현해야 합니다. AI Studio 운영 프록시의 실제 자격증명은 조사하지 않았습니다.
2. **회원 권한 부재**: 회원 인증·프로그램 사용기간·소유자 확인이 없습니다. 통합 AIMaster 권한 관문을 재사용해야 합니다.
3. **확대 보장 없음**: 2x/4x는 프롬프트 문구뿐입니다. 결과 픽셀을 읽어 원본 대비 확대하거나 검증하지 않습니다.
4. **확장자 불일치 가능성**: 공급사 반환 MIME을 그대로 data URL에 넣으면서 다운로드 파일명은 항상 `.png`입니다. JPEG 등 반환 시 파일 내용과 확장자가 다를 수 있습니다.
5. **원본 이미지 그대로 전송**: 용량·픽셀 한도와 축소 처리 없이 FileReader로 base64 변환해 전송합니다. 사물 개수도 제한하지 않아 요청 크기·메모리 문제 가능성이 있습니다.
6. **메모리 관리**: 미리보기 object URL의 해제 코드가 없습니다.
7. **복원 동일성**: 얼굴/나이/표정/구도 보존을 명시하지 않아 실제 품질 검수가 필요합니다. 손상된 부분의 복원은 사실 재현 보장과 구분해야 합니다.
8. **연도**: 푸터가 2024년 고정이며 동적 현재 연도 처리가 없습니다.
9. **접근성**: 홈 기능 카드는 클릭 가능한 div이며 키보드 button 의미가 없습니다.

### 바나나 캔버스 코드 근거

- `banana-canvas/src/lib/bnc/styles.ts`: `restore`, `colorize`, `upscale` 프리셋.
- `banana-canvas/src/lib/bnc/tasks.ts`: 복원·컬러화·확대 복합 실행, 확대 factor 2/4, `synthesis` 작업 분기.
- `banana-canvas/src/lib/bnc/types.ts`: 소스 이미지 최대 5장.
- `banana-canvas/src/lib/bnc/prompts.ts`: 얼굴 동일성 고정, 배경/조명 통합, 합성 AI 제안.
- `banana-canvas/src/lib/files.ts`: AI 출력 후 실제 Lanczos3 확대, 긴 변 8,192px 상한, 출력 MIME/크기 처리.
- `banana-canvas/src/components/studio/Studio.tsx`: 처리 옵션·소스 추가·AI 제안·합성 실행 화면.

원본의 사물별 모든 객체 포함·상품 원형 보존 지시는 기존보다 구체적입니다. 반면 기존 바나나 캔버스에는 얼굴 동일성 보존 지시, 실제 픽셀 확대, 회원별 결과 저장·기록이 있습니다. 기존 합성 제안은 배경 변경을 권하는 문구가 있어 원본 배경 유지형 합성과 차이가 있습니다. 따라서 사물 원형 보존과 배경 유지 선택을 보강할 실질적인 여지는 있습니다. 이 비교는 코드상 기능/지시 비교이며 두 모델 결과의 품질 우열을 판정하지 않습니다.

## 7. 진행 방향 추천

### 우선안: 기존 프로그램 보강

- 바나나 캔버스에 사진 복원·사물 합성 간편 진입을 추가합니다.
- 복원에서 손상·컬러·확대 옵션, 얼굴/구도 보존, 전후 비교, 실제 픽셀 크기를 명확히 표시합니다.
- 합성에서 사물마다 착용/사용 위치를 지정하고, 모든 사물 포함·원형 유지·배경 유지/변경을 구분합니다.
- 인증·개인 API 키·이미지 저장·작업 기록 등 이미 있는 구조를 재사용합니다.

### 별도 프로그램을 만들 경우

가족사진·오래된 추억사진 복원에 초점을 둔 간단한 도구로 차별화합니다. 원본의 두 기능만 그대로 복제하면 바나나 캔버스와 역할이 겹칩니다. 기본 설계는 통합 회원 권한, 회원 본인 Gemini 키, 표준 흰색 화면·모바일 접는 메뉴, 사진 동의·저장 선택, 다운로드 내용과 확장자 일치, 실제 크기 확인을 포함합니다. 이 목록은 개발 제안이며 구현된 기능이 아닙니다.
