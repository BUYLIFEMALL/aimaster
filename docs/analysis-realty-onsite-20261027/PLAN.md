## 1. 무엇을 만드나 (한 줄)

**임장(현장 답사) 중에 휴대폰으로 그 건물·단지의 사진을 찍거나 주소를 넣으면, 그 물건의 과거 시세와 지금 시세를 비교해 투자가치를 즉석에서 평가해 주는** 프로그램.

## 2. 기존 프로그램과의 차이 (왜 따로)
| 프로그램 | 성격 |
|---|---|
| `real-estate-sales`(부동산 실거래 투자분석) | 관심 「지역」의 새 실거래가를 모아 알림 + AI 분석 (지역 단위·알림 중심) |
| `realty-listing-alert`(매물 알림) | 네이버 매물(호가) 변동 알림 (회원 PC 확장) |
| **이번(임장 투자가치 평가)** | **현장에서 「이 물건 하나」를 즉석 평가** (사진·주소 입력 → 단건 투자가치 리포트) |
- 셋 다 부동산이지만 입력·사용 상황이 다르다(지역 모니터링 vs 현장 단건 평가). 기존 두 개의 **시세 조회·AI 분석 부품을 재사용**하되, 화면·흐름은 임장용으로 새로 만든다. → 새 기능(또는 `real-estate-sales` 안 「📍 임장 평가」 탭). §0 결정.

## 0. 어디에 (결정 필요)
- **안 A**: `real-estate-sales`에 「📍 임장 평가」 탭 추가(시세·AI 분석 부품 재사용, 빠름).
- **안 B**: 새 프로그램 `onsite-realty-valuation`(가칭) — 현장·모바일 중심이라 독립. 이름 후보는 승인 후.
- 제안: 부품 재사용이 많아 **안 A로 시작**, 모바일 사용이 커지면 분리. 주인님 결정.

## 3. 흐름
```
① 입력: 사진 찍기(건물 외관·주소판·등기·매물 전단) 또는 주소·단지명 직접 입력
   → ② AI 비전이 사진에서 주소·단지·동호수·면적 읽기(OCR, 회원 본인 키) → 회원 확인·수정
   → ③ 시세 조회: 그 물건의 과거 실거래가(국토부 API) + 현재 호가(네이버 매물) 비교
   → ④ 투자가치 평가 리포트: 시세 추이·고점 대비·주변 대비·전세가율·AI 총평
```

## 4. 기능
| 영역 | 내용 |
|---|---|
| 사진 입력 | 휴대폰으로 외관·주소·전단·등기부 사진 → AI 비전(회원 Gemini/OpenAI 키)으로 주소·단지·면적·층 추출 → 회원 확인 |
| 주소 입력 | 주소·단지명·동호수 직접 입력(사진 없이도) |
| 과거 시세 | 국토교통부 실거래가 공개 API(공공데이터, 무료 — 관리자 지정 공용 키 §8 또는 회원 본인 키)로 그 단지·면적의 거래 이력·추이 |
| 현재 시세 | 네이버 매물 호가(회원 PC 확장으로, `realty-listing-alert` 방식 — 우리 서버 긁지 않음) 또는 회원 입력 |
| 비교·평가 | 과거↔현재 비교(고점 대비 %·최근 추세), 주변 단지 대비, 전세가율, 최근 거래 빈도 → AI가 투자 매력도·주의점 총평(회원 키) |
| 결과 | 물건별 평가 리포트 저장(회원별), 임장 목록(여러 물건 비교), PDF·공유 |

## 5. 재사용·안전
- **재사용**: `real-estate-sales`의 국토부 실거래 조회·AI 분석, `realty-listing-alert`의 확장 호가 수집·중개사 정보. 이미지 OCR은 이미지 공용 어댑터.
- **데이터**: 회원별 격리(owner-only). 부동산은 관리자 지정으로 보관 1년(최상위 규칙 §8). 중개사 전화 등 제3자 정보 취급은 기존 부동산 규칙 따름.
- **키**: AI는 회원 본인 키. 국토부 공공 키는 무료라 관리자 지정 공용 키 가능(§8, `real_estate_sales` 선례) 또는 회원 키.
- **주의**: 투자가치 평가는 **참고용이며 투자 책임은 회원에게** 있음을 화면에 고지(투자 권유·수익 보장 아님).

## 6. 순서·검수·배포
1. §0 결정 → 화면 뼈대(입력·결과) · 2. 주소/사진 입력 + AI 비전 추출 · 3. 과거 실거래 조회·추이 · 4. 현재 호가 비교 · 5. AI 투자가치 리포트 · 6. 임장 목록·PDF. 묶어 배포 1회·버전·크롬(모바일 폭) 확인. DB 새 표(임장 물건·평가)는 사전 승인.
