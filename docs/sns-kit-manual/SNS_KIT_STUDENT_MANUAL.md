> 이 매뉴얼 하나로 **내 계정에 나만의 Threads·인스타 자동 포스팅 사이트**를 만듭니다. 코딩 지식은 필요 없습니다.
> 화면 캡처 자리(📷)는 리허설 때 채웁니다. 각 프로그램의 자세한 안내서는 압축 안 `<프로그램>/KIT/README.md`, 플랫폼 키 발급은 `KIT/PLATFORMS.md`에 있습니다.

## 3. 패키지 설치마법사 — 더블클릭 한 번

설치하려는 프로그램 폴더를 열고 **맨 위의 실행 파일을 더블클릭**합니다.

| 컴퓨터 | 더블클릭할 파일 | 처음 한 번 막히면 |
|---|---|---|
| 윈도우 | `패키지설치마법사.cmd` | 파란 「Windows의 PC 보호」 창 → **[추가 정보] → [실행]** |
| 맥 | `패키지설치마법사.command` | 「확인되지 않은 개발자」 창 → 파일을 **마우스 오른쪽 클릭 → [열기] → [열기]** |

검은 창(마법사)이 열리고 8단계를 차례로 안내합니다. **필요한 화면은 마법사가 브라우저로 열어 주고, 붙여 넣을 내용은 클립보드에 복사해 둡니다.** 📷

> 🔁 **중간에 창을 닫아도 괜찮습니다.** 다시 더블클릭하면 「이어서 할까요?」라고 묻고, 끝난 단계는 건너뜁니다.
> 🔒 키를 입력하면 **화면에 아무것도 안 보이는 것이 정상**입니다(붙여넣기: 윈도우 마우스 오른쪽 클릭, 맥 ⌘V → Enter).

### ① Node.js 확인
- 마법사가 버전을 확인합니다. 없으면: 윈도우는 「자동으로 설치할까요?」 → `y`, 맥은 설치 화면이 열리면 macOS 설치 파일(.pkg)로 설치.
- 설치 후 **마법사 창을 닫고 다시 더블클릭**합니다.

### ② Supabase 프로젝트 만들기
- 마법사가 Supabase **새 프로젝트** 화면을 엽니다(처음이면 가입).
- 입력: **Project name** 아무 이름 · **Database Password** → [Generate] 후 메모장에 저장 · **Region** → **Northeast Asia (Seoul)** (안 보이면 「Need a specific region?」)
- [Create new project] → 1~2분 뒤 프로젝트 화면이 열리면 **브라우저 주소창 주소 전체를 복사**해 마법사에 붙여 넣습니다. 📷
- ⚠ 「연결되지 않습니다」 → 프로젝트가 아직 만들어지는 중입니다. 1분 뒤 다시 붙여 넣으세요.

### ③ Supabase 키 등록
- 마법사가 **API Keys** 화면을 엽니다. 📷
- ① **Publishable key**(`sb_publishable_…`) 복사 → 붙여넣기 → ② **Secret key**(`sb_secret_…`, 눈 아이콘·복사 버튼) 복사 → 붙여넣기
  - 화면에 없으면 **Legacy** 탭의 `anon`(①)·`service_role`(②)
- 마법사가 **맞는 키인지 스스로 확인**합니다. 순서를 바꿔 넣으면 알려 줍니다.

### ④ DB 만들기
- 마법사가 설치 SQL을 **클립보드에 복사**하고 **SQL Editor**를 엽니다. 📷
- 빈 편집 칸을 클릭 → **Ctrl+V**(맥 ⌘V) → 오른쪽 아래 **[Run]**
  - 「Potential issue detected / destructive operation」 창 → **[Run this query]** (새 프로젝트라 안전)
  - 「Snippets…」 안내 창 → **Understood**
- 아래에 「Success」가 보이면 마법사 창으로 돌아와 **Enter** → 마법사가 **DB가 만들어졌는지 확인**합니다.
- ⚠ 「아직 DB가 만들어지지 않았습니다」 → 빨간 오류 문장을 메모하고 한 번 더 붙여 넣어 Run.

### ⑤ 이메일 확인 끄기
- 마법사가 **Sign In / Providers** 화면을 엽니다 → **Email** 항목 → **Confirm email 끄기** → **Save** → 마법사에서 Enter. 📷
- (끄지 않으면 내 사이트 가입 때 확인 메일을 기다려야 합니다)

### ⑥ 내 사이트 설정
- **사이트 이름**(영문 소문자·숫자·`-`): 주소가 됩니다 → `https://이름.vercel.app`. 기본값(예: `my-insta-381`) 그대로 Enter 해도 됩니다.
- **화면에 표시할 내 이름/브랜드**: 예 `홍길동 마케팅` (사이트 제목·메뉴에 표시, 비워도 됨)

### ⑦ 설치·빌드 (3~5분)
- 기다리면 됩니다. 글자가 많이 지나가는 것이 정상입니다.
- ⚠ `file is too long` / `TurbopackInternalError` → 폴더 경로가 깁니다. 짧은 곳(`D:\work`)으로 옮겨 다시 더블클릭.
- ⚠ `JavaScript heap out of memory` → 다른 프로그램을 닫고 다시 더블클릭.

### ⑧ 인터넷에 올리기(Vercel)
- 브라우저가 열리면 **Vercel 로그인**(처음이면 무료 Hobby 가입) → 마법사가 연결·설정·배포를 합니다.
- 배포가 끝나면 마법사가 **실제 사이트 주소를 스스로 확인**하고, 다르면 맞춰서 한 번 더 올립니다.

### 끝 — 설치 완료 화면
- 내 사이트가 열리고, **Meta 앱에 등록할 콜백 주소가 클립보드에 복사**돼 있습니다.
- 프로그램 폴더에 **`설치결과.txt`**(내 사이트·콜백 주소·Supabase 주소 — 비밀값 없음)가 생깁니다. 📷

## 5. Threads 연결 · 첫 게시 (`threads-content-ops`)

**5-1. Meta(Threads) 앱 만들기** — 자세히: `KIT/PLATFORMS.md` 1번 📷
1. developers.facebook.com → **앱 만들기** → 이용 사례 **「Threads API에 액세스」** → 앱 이름(예: `홍길동 포스팅`, 「Threads」·「Meta」 같은 상표는 거부될 수 있음)
2. 비즈니스 포트폴리오 단계는 **「아직 연결하고 싶지 않음」**, 마지막 [앱 만들기]는 약관 동의
3. 이용 사례 → Threads API → **권한**: `threads_basic`, `threads_content_publish` 추가
4. **설정 → 리디렉션 콜백 URL**: 마법사가 복사해 둔 주소(`https://내주소/api/threads-content-ops/callback`) 붙여넣기 → **Enter가 아니라 아래에 뜨는 제안 항목을 클릭** → 저장. (제거·삭제 콜백 칸에는 `https://내주소`)
5. **앱 역할 → 역할 → Threads 테스터**에 내 Threads 계정 추가 → Threads 앱 **설정 → 계정 → 웹사이트 권한 → 초대 → 수락**
6. **앱 설정 → 기본 설정 맨 아래**의 **Threads 앱 ID / Threads 앱 시크릿 코드** 복사 (⚠ 맨 위 「앱 ID」 아님)

**5-2. 내 사이트에 등록**
1. 좌측 **API키등록·플랫폼연동** → Threads 앱 ID·시크릿 저장 → **Threads 계정 연결하기** → 로그인·허용
2. **OpenAI API 키** 저장(글 생성). Claude·Gemini도 쓸 수 있음

**5-3. 첫 게시**: **콘텐츠 생성** → 주제 입력 → 글 생성 → 초안 저장 → **콘텐츠 보관함 → 지금 발행** → 내 Threads에 올라오면 완료 🎉

## 6. 인스타 연결 · 첫 게시 (`insta_auto_poster`)

**6-1. Meta 앱 만들기(Instagram 로그인 방식)** — 자세히: `KIT/PLATFORMS.md` 1번 📷
1. developers.facebook.com → **앱 만들기** → 이용 사례 **「Instagram에서 메시지 및 콘텐츠 관리」**
2. 이용 사례 → 맞춤 설정 → **Instagram 로그인이 포함된 API 설정**
   - **4. Instagram 비즈니스 로그인 설정 → OAuth 리디렉션 URI**: `https://내주소/api/instagram/callback/byok` → 저장
   - 같은 화면 위쪽 **Instagram 앱 ID / Instagram 앱 시크릿 코드** 복사 (⚠ 앱 화면 맨 위 「앱 ID」와 다름)
3. **앱 역할 → 역할 → Instagram 테스터**에 내 인스타 계정 추가 → 인스타 **설정 → 앱 및 웹사이트 → 테스터 초대 → 수락**
4. **앱 설정 → 기본 설정 → 앱 도메인**: 내 주소의 도메인(예: `my-insta-381.vercel.app`) → 저장
> 내 사이트 **API키등록·플랫폼연동** 맨 위 「내 Meta 앱에 등록할 주소 한눈에 보기」 카드에 내 주소가 복사 버튼과 함께 나옵니다.

**6-2. 내 사이트에 등록**
1. **Instagram 앱 ID / 시크릿** 저장 → 초록색 **Instagram 로그인 방식으로 연결하기** → 인스타 로그인·허용
2. **Gemini API 키**(이미지), **OpenAI 또는 Claude 키**(캡션) 저장 · (선택) Perplexity(실시간 주제 수집)

**6-3. 첫 게시**: **게시글 관리 → + 새 게시글 작성** → 주제 → 캡션·이미지 생성 → **즉시 게시** → 내 인스타 피드에 올라오면 완료 🎉
   - 💡 **내가 만든 이미지로 올리기**(v1.02~): 「이미지 파일 직접 첨부」 칸에 이미지를 넣고 캡션을 쓰면 AI 생성 없이 그대로 저장·예약·게시됩니다. 카드뉴스는 4장을 **한 번에 선택**하면 파일 이름순(`1.png`~`4.png`)으로 올라갑니다.

## 7. 예약 게시 (정해진 시각에 자동으로 올리기)

예약 게시는 「1분마다 올릴 시각이 된 글이 있는지」 확인해 주는 곳이 필요합니다. Vercel 무료는 하루 1번만 자동 실행되므로, **기본 방식은 내 무료 cron-job.org**입니다.

1. https://console.cron-job.org/signup → 무료 가입 → 이메일 인증 → 로그인
2. 콘솔 **Settings → API → Create API key** → 키 복사 (**IP 제한은 켜지 마세요**) 📷
3. 내 사이트 → **API키등록·플랫폼연동 → ⏰ 예약 발행** → 실행 방식 「**내 cron-job.org · 기본값**」 확인 → **cron-job.org API 키** 칸에 붙여넣고 저장 → 끝
4. 이제 글을 **예약**하면 프로그램이 내 cron-job.org에 확인 작업을 **자동으로 만들고 켭니다**. 남은 예약이 없으면 **자동으로 끕니다**(콘솔에서 작업이 켜졌다 꺼졌다 하는 것이 정상).
5. 글 목록 위 「⏰ 예약 발행」 줄에서 **실행 중 / 대기 / 일시정지됨**을 보고 **전체 일시정지·재개**를 할 수 있습니다.

- ❌ cron-job.org에 직접 작업을 만들거나 사이트 비밀값(`CRON_SECRET`)을 넣지 마세요. 프로그램이 알아서 합니다.
- 예약 시각이 **24시간 넘게 지난 글은 자동으로 올리지 않습니다**(오래된 글이 한꺼번에 올라가는 것을 막음).
- Vercel 유료(Pro)를 쓰면 `KIT/README.md` 6장 A로 「Vercel 예약 호출」도 고를 수 있습니다(선택).

| 「이 프로젝트의 키가 아닌 것 같습니다」 | API Keys 화면에서 **복사 버튼**으로 다시 복사(앞뒤 공백·일부만 복사된 경우) |
| 로그인 때 「가입 확인 메일」 안내 | 마법사 ⑤단계(Confirm email 끄기)를 다시 확인 |
| Threads 연결 「앱 ID를 인식할 수 없습니다」/4476002 | **Threads 앱 ID**(기본 설정 맨 아래)를 넣었는지 |
| 「리디렉션 URI」 오류 | Meta 콜백 주소가 `설치결과.txt`의 주소와 **글자 하나까지** 같은지 |
| 「테스터가 아닙니다」 | 테스터 초대를 **수락**했는지(Threads/인스타 앱 설정) |
| 글 생성 「API 키 등록 필요」 | API키등록·플랫폼연동에 AI 키 저장 |
| 예약 글이 안 올라감 | ⏰ 예약 발행에 cron-job.org 키 「등록됨」, 상태 줄이 「일시정지됨」이 아닌지, cron-job.org 콘솔에서 작업 최근 실행이 성공인지 |
| 설치를 처음부터 다시 하고 싶음 | 마법사가 「이어서 할까요?」 물을 때 `n` |

막히면 **마법사 창의 문구를 그대로 캡처**해서 강사에게 보내 주세요(키가 보이는 화면은 가리고).

## 10. 비용·보안 수칙

- Supabase·Vercel·Meta·cron-job.org: **무료**로 시작합니다.
- AI 요금은 **내 키로 쓴 만큼** 각 회사가 청구합니다. 이미지 생성은 글보다 비쌉니다 — 각 회사 사용량 화면에서 한도를 정해 두세요.
- **Secret key·service_role 키·AI 키는 절대 공개 금지.** 프로그램 폴더의 `.env.local` 파일에 들어 있으니 폴더째 남에게 보내지 마세요.

## 11. 새 배포판이 나오면

- 배포판은 `v1.01 → v1.02 …` 번호로 나옵니다. 새 번호를 받으면 **예전 폴더 옆(같은 상위 폴더)에 새로 풀고** 새 폴더의 `패키지설치마법사`를 더블클릭합니다. 예: `D:\work\SNS_Auto_Posting_Kit_v1.01` 옆에 `D:\work\SNS_Auto_Posting_Kit_v1.03`
- **v1.03부터 마법사가 예전 설치를 스스로 찾아 「업데이트할까요?」라고 묻습니다** → `y`를 누르면 예전 사이트·DB·키를 그대로 쓰고 **새 코드만 다시 올립니다**(Supabase·키·DB·사이트 이름 질문 없음, 몇 분이면 끝). 예전 폴더를 다른 곳에 두었다면 마법사가 묻는 칸에 그 폴더 경로를 붙여 넣으세요.
- 예전 폴더는 업데이트가 끝난 뒤 지워도 됩니다(설정은 새 폴더로 복사됨). 단, 그 안의 `.env.local`에는 키가 있으니 휴지통도 비우세요.
- DB 변경이 있는 업데이트는 그 프로그램 `KIT/README.md` 맨 아래 「업데이트 내역」과 `KIT/upgrade-날짜-내용.sql`을 확인해 SQL Editor에서 한 번 실행합니다.
