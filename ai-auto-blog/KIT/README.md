# 블로그 포스팅 자동화 — 설치 안내서 (독립 운영판)

> 수강생 배포 키트 · 2026-11-16(확장 포함판) · 윈도우·맥 공통 (폴더 이름은 `ai-auto-blog`)
> 내 컴퓨터에 압축을 풀고 → **패키지 설치마법사**를 더블클릭해 내 계정(Supabase·Vercel)으로 설정하면 → **내 사이트에서 블로그 글감 수집·AI 글과 이미지 만들기·게시글 관리·네이버 블로그 자동 입력**까지 씁니다.
> 다른 사이트와 연결되는 부분은 없습니다(키트에는 키·비밀번호·데이터가 하나도 들어 있지 않습니다). 모든 계정·키·데이터는 수강생 본인 것입니다.

**이 프로그램이 하는 일**
- **글감(데이터) 수집**: 웹 주소(URL)·RSS 피드·실시간 트렌드 검색(Perplexity)·유튜브 쇼츠 떡상 분석으로 블로그 주제 후보를 모읍니다
- **콘텐츠 만들기**: 주제를 넣으면 AI가 SEO 블로그 글(제목·요약·소제목 4개·본문)과 **이미지 1~5장**을 만들어 본문 사이사이에 넣어 줍니다
- **운영·관리**: 만든 글을 **게시글 관리(보관함)**에서 카테고리로 정리하고, 편집기로 고치고, 지웁니다(30일 지난 글·이미지·글감은 매일 자동 정리)
- **네이버 블로그 자동 입력(크롬 확장)**: 글 보기 화면의 **🧩 네이버 입력기로 보내기**를 누르면, 내 사이트에서 받은 크롬 확장이 네이버 블로그 글쓰기 화면을 열고 제목·본문·이미지·링크·카테고리·태그를 **사람처럼 입력해 발행 직전까지** 준비합니다. **마지막 [발행] 버튼은 직접** 누릅니다
- **복사해서 붙여넣기도 그대로**: 글 보기 화면의 **📋 본문 복사하기** → 티스토리 등 다른 블로그 글쓰기 화면에 **Ctrl+V**
- 확장은 **내 사이트에서 내려받은 것만** 내 사이트에 연결됩니다(사이트 주소가 확장 안에 자동으로 들어감). 플랫폼 개발자 앱·예약 설정은 필요 없습니다

1. 압축 파일을 풉니다(윈도우: 마우스 오른쪽 → [압축 풀기]). 이 프로그램은 `ai-auto-blog` 폴더입니다.
2. 원하는 곳으로 옮깁니다. 예: 윈도우 `D:\work\blog`, 맥 `~/work/blog`
   - **경로에 한글·공백 없이, 짧게**(윈도우는 경로가 길면 빌드가 실패합니다). **GitHub 저장소 폴더 안에는 풀지 마세요.**

## 2. 패키지 설치마법사 실행 (DB 만들기부터 인터넷에 올리기까지 한 번에)

프로그램 폴더 맨 위에 있는 실행 파일을 **더블클릭**합니다.

- **윈도우**: `패키지설치마법사.cmd` 더블클릭 (「Windows의 PC 보호」 창이 뜨면 [추가 정보] → [실행])
- **맥**: `패키지설치마법사.command` 더블클릭 (「확인되지 않은 개발자」 창이 뜨면 마우스 오른쪽 클릭 → [열기] → [열기], 처음 한 번만)

마법사가 8단계를 차례로 안내합니다. **필요한 화면은 마법사가 브라우저로 직접 열어 주고, 붙여 넣을 내용은 클립보드에 복사해 둡니다.**

| 단계 | 마법사가 하는 일 | 내가 할 일 |
|---|---|---|
| 1. Node.js | 설치돼 있는지 확인(윈도우는 없으면 자동 설치 제안) | 설치 후 마법사 다시 실행 |
| 2. Supabase 프로젝트 | 프로젝트 목록 열기(이미 조직이 있으면 그 조직의 [New project] — 새 조직 만들지 않기) | 이름·DB 비밀번호(Generate 후 메모)·지역 **Northeast Asia (Seoul)**(Need a specific region? 누르면 보임) → 생성 → **주소창 주소 붙여넣기** |
| 3. Supabase 키 | API Keys 화면 열기, **맞는 키인지 자동 확인** | Publishable key → Secret key 순서로 붙여넣기(화면에 안 보임) |
| 4. DB 만들기 | 설치 SQL을 **클립보드에 복사**하고 SQL Editor 열기, 끝나면 **성공 여부 자동 확인** | 빈 칸 클릭 → 붙여넣기 → [Run] |
| 5. 이메일 확인 끄기 | Sign In / Providers 화면 열기 | 맨 위 User Signups 칸의 **Confirm email 끄기** → Save |
| 6. 내 사이트 설정 | 주소·비밀값 자동 생성 | 사이트 이름(영문 소문자, 주소가 됨) · 화면 위쪽(탭 제목)에 보일 내 이름/브랜드 |
| 7. 설치·빌드 | 프로그램 설치·확인(3~5분) | 기다리기 |
| 8. 인터넷에 올리기 | Vercel 연결·설정 등록·배포, **실제 주소 자동 확인**, 로그인 주소 설정 화면 열기 | 브라우저에서 Vercel 로그인(처음이면 무료 가입) · 마법사가 연 Supabase URL Configuration에 주소 붙여넣기 |

- 중간에 창을 닫아도 **다시 더블클릭하면 이어서** 진행합니다(처음부터 하려면 질문에 `n`).
- 끝나면 내 사이트가 열리고, 프로그램 폴더에 **`설치결과.txt`**(내 사이트 주소·다음에 할 일)가 생깁니다.

## 3. 설치 확인

- Supabase **Table Editor**에 `blog_posts`·`blog_candidates`·`newsblur_accounts`가 보이고, `https://내주소/auth`에서 **[회원가입] 탭 → 가입 → 로그인**이 되면 설치 성공입니다.
- 5단계에서 Confirm email을 끄지 않았다면 가입 확인 메일의 링크를 눌러야 로그인됩니다.
- 이 프로그램은 관리자 전용 화면이 없습니다(가입한 사람은 각자 자기 글만 봅니다).

> 마법사가 안 될 때만(고급): `KIT/env.example`을 `.env.local`로 복사해 값을 채우고 `npm install` → `npm run build` → `npx vercel@latest deploy --prod` 후 Vercel **Settings → Environment Variables**에 같은 값을 넣고 다시 배포합니다. **AI 코딩 도구에 설치를 맡기지 말고** 마법사를 직접 실행하세요(마법사는 사람이 답을 입력하는 방식입니다).

## 4. 크롬 확장 프로그램 설치·연결 (네이버 블로그 자동 입력) — 네이버 개발자 앱은 필요 없습니다

1. 내 사이트 좌측 **⬇ 확장 프로그램 받기**(또는 **🔑 API키등록·플랫폼연동 → 크롬 확장 프로그램**)에서 ZIP을 받습니다.
   - 이 ZIP은 **내 사이트 주소가 들어간 확장**입니다. 다른 사람 사이트에서 받은 확장은 내 사이트에 연결되지 않습니다.
2. ZIP을 **알기 쉬운 폴더에 압축 풀기**(예: `D:\work\blog-extension`) — 이 폴더는 지우지 마세요(크롬이 계속 씀).
3. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 2의 폴더 선택
4. 크롬 오른쪽 위 퍼즐 아이콘에서 확장을 **고정**하고 누르면 오른쪽에 사이드패널이 열립니다.
5. 사이드패널의 **자동 연결** → 새 탭에서 내 사이트 로그인(이미 로그인했으면 바로) → 「연결됨」이 보이면 끝(연결 코드를 복사할 필요 없음)
6. 사이드패널에 **내 네이버 블로그 ID**(blog.naver.com/**아이디**)를 저장합니다 — 저장 전에는 자동 입력이 시작되지 않습니다.
7. 크롬에서 **네이버에 로그인**해 둡니다(로그인·비밀번호는 확장이 입력하지 않음).

> 새 배포판으로 업데이트하면 확장도 새 ZIP으로 다시 받아 **같은 폴더에 덮어쓰고** `chrome://extensions`에서 새로고침합니다(크롬은 압축해제 확장을 스스로 업데이트하지 않음). 사이드패널이 「새 버전이 있습니다」로 알려 줍니다.

## 5. AI 키 등록 · 첫 글 만들기

내 사이트 → 좌측 **🔑 API키등록·플랫폼연동**
1. **Google (Gemini — 이미지 자동생성)** 칸에 Gemini 키를 저장합니다(발급 방법: `KIT/PLATFORMS.md` 1장). 이것 하나면 글과 이미지를 모두 만듭니다.
2. (선택) 실시간 트렌드 수집은 Perplexity 키, 쇼츠 분석은 YouTube 키가 필요합니다.

**글감 모으기 → 글 만들기 → 관리 → 붙여넣기**
1. 좌측 **🔍 게시글 주제 수집** — 웹 주소·RSS·트렌드 검색·유튜브 쇼츠 중 하나로 글감을 모읍니다 → 마음에 드는 글감의 **이 주제로 글쓰기**
2. **✍️ AI 글쓰기** — 주제·문체·목표 글자 수를 정하고, 「본문 생성 설정」의 플랫폼이 **Google Gemini**인지 확인 → 「이미지 생성 설정」에서 장수(처음엔 1~2장)를 고르고 → **AI 블로그 포스트 생성** (1~3분)
3. 완성된 글이 화면에 펼쳐집니다. **빠른 내용 수정** 탭에서 제목·문단을 고치고 저장할 수 있습니다.
4. 좌측 **게시글 관리** — 만든 글이 모두 모입니다. 카테고리로 정리하고, 글을 눌러 **✏️ 수정**(상세 편집기)·삭제합니다. 글마다 「N일 후 자동삭제」가 표시됩니다(30일 보관).
5. **네이버 블로그**: 글 보기 화면에서 네이버 카테고리를 고르고(**카테고리 불러오기**) **🧩 네이버 입력기로 보내기** → 30분 안에 확장이 네이버 글쓰기 탭을 새로 열어 제목·본문·이미지·카테고리·태그를 입력 → 크롬 알림 「발행 직전 준비 완료」 → 화면을 확인하고 **직접 [발행]**
   - 입력 중에는 그 탭을 닫거나 다른 글을 쓰지 마세요. 입력이 막히면 안전하게 멈추고(입력한 내용은 보존), 다시 보내면 새 탭에서 처음부터 합니다.
6. **다른 블로그(티스토리 등)**: 글 보기 화면의 **📋 본문 복사하기** → 글쓰기 화면에 **Ctrl+V** → 직접 발행

> 사용 순서 전체는 내 사이트의 **📖 연동 & 사용 매뉴얼** 화면에도 있습니다.
> **이미지는 꼭 내 블로그에 직접 올려 두세요.** 이미지는 만든 날부터 30일 뒤 지워지므로, 붙여 넣기만 하면 주소가 내 사이트를 가리키는 경우 한 달 뒤 블로그에서 안 보일 수 있습니다. 글 화면에서 이미지를 내려받아 블로그 편집기의 사진 올리기로 바꿔 넣으세요.
> **티스토리**는 붙여 넣은 이미지 자리에 「전기통신사업법 및 시행령에 따라 불법촬영물등 여부를 검토중입니다」가 보일 수 있습니다. 프로그램 오류가 아니라 티스토리의 검토 안내입니다. 잠시 뒤 새로고침해 보고, 계속 보이면 이미지를 내려받아 직접 올리세요.

## 7. (선택) 내 도메인 연결

1. Vercel → 프로젝트 → **Settings → Domains → Add** → 내 도메인 입력(예: `blog.hong.com`)
2. 안내대로 도메인 회사 DNS에 기록 추가(보통 `CNAME` → `cname.vercel-dns.com`, 루트 도메인은 `A` → `76.76.21.21`) → Vercel에서 **Valid** 확인
3. 주소가 바뀌었으니 아래를 **새 주소로** 고칩니다.
   - Vercel **Environment Variables**의 `NEXT_PUBLIC_SITE_URL` → 수정 후 **Redeploy**
   - Supabase **Authentication → URL Configuration**: Site URL을 새 주소로, Redirect URLs에 `https://새주소/**` 추가
   - 내 컴퓨터 `.env.local`의 `NEXT_PUBLIC_SITE_URL`

| 확인 메일 링크를 눌렀더니 `localhost`로 감 | Supabase **Authentication → URL Configuration**에 Site URL = 내 주소, Redirect URLs = `내주소/**` |
| 「API 키 등록이 필요합니다」 | 좌측 **API키등록·플랫폼연동**에서 키 저장. 글 쓰기 플랫폼(Gemini·OpenAI·Claude)의 키와 이미지용 Gemini 키가 모두 있어야 합니다 |
| 「키가 올바르지 않거나 인증에 실패」 | 키 앞뒤 공백 없이 다시 복사해 저장 |
| 이미지 만들기에서 「사용량·결제」 오류 | Google AI Studio **Billing**에서 결제 수단 연결, 또는 이미지 장수를 1장·화질 1K로 |
| 이미지 생성이 시간 초과 | 바로 다시 누르지 말고 Google AI Studio 사용량(https://aistudio.google.com/usage)을 먼저 확인 — 이미 만들어져 요금이 나갔을 수 있습니다 |
| 마법사 7단계 빌드 실패 | 폴더 경로가 길거나 한글·공백이 있는지 확인 → 짧은 영문 경로로 옮긴 뒤 다시 실행 |
| 사이트가 다른 주소로 이동함 | Vercel 환경변수 `NEXT_PUBLIC_STANDALONE_MODE`가 정확히 `true`인지 확인 → Redeploy |
| 확장 「연결 실패」·사이드패널이 내 사이트를 못 찾음 | 확장을 **내 사이트에서 받았는지**, `NEXT_PUBLIC_SITE_URL`이 실제 주소인지(바꿨다면 Redeploy 후 ZIP을 다시 받아 덮어쓰기) |
| 「네이버 입력기로 보내기」 뒤 아무 일도 없음 | 사이드패널에 **네이버 블로그 ID 저장**·연결됨 상태인지, 보낸 지 30분이 지났으면 다시 보내기, 크롬이 켜져 있는지 |
| 입력 중 멈춤 | 사이드패널 진행 상태의 오류 문구 확인(네이버 안내 창·로그인 풀림 등). 네이버 화면을 정리하고 다시 보내기 |
| 붙여 넣은 이미지가 한 달 뒤 블로그에서 안 보임 | 5장 마지막 안내대로 이미지를 블로그에 직접 올려 두기 |
| 티스토리 이미지 자리에 「불법촬영물등 여부를 검토중」 | 티스토리의 검토 안내입니다. 잠시 뒤 새로고침, 계속 보이면 이미지를 내려받아 직접 올리기 |
| 8단계에서 메일 코드 입력 창(Reauthenticate) | Vercel 본인 확인입니다. Send Code to Email → 메일의 코드 입력 |
| 8단계에서 팀을 고르라고 함 | 「무료」 표시를 고르세요. 「유료 팀」을 고르면 빌드 비용이 그 팀에 청구될 수 있습니다 |
