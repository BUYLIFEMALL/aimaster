## 1. 무엇을 만드나
상품 사진 여러 장을 **한 번에** 같은 규칙으로 손질해 ZIP으로 받는 화면. 쇼핑몰 판매자가 마켓에 올리기 전에 매번 하는 일(크기 맞추기·로고 넣기·촬영 정보 지우기)을 한 번에 끝낸다.
- **모두 회원 브라우저 안에서 처리**: 사진을 서버로 보내지 않음 → 운영 비용·AI 비용·키 없음, 개인정보(GPS 등) 노출 걱정 없음.
- 위치: 좌측 메뉴에 **「🖼 사진 일괄 손질」**(새 화면 `/batch`), 「🧽 무료 지우기」 바로 아래.

## 2. 기능 (1차 = 이번 배포)
| 묶음 | 기능 | 세부 |
|---|---|---|
| 사진 넣기 | 파일 고르기·끌어 놓기·**Ctrl+V 붙여넣기** | 최대 50장(무료 지우기와 같은 상한), 한 장 25MB 이하, 목록에 「원본 → 결과 크기」 표시, 개별·전체 삭제 |
| 크기 | **세로 높이 맞춤**(비율 유지) | 기본 860px(상세페이지 폭 기준과 맞춤), 직접 입력 100~4096px, 「원본 크기 그대로」 선택 가능, 가로가 4096px을 넘으면 그 사진만 경고 |
| 워터마크 | **로고 이미지**(투명 PNG) 또는 **문자** | 위치 9곳(3×3 버튼), 크기(사진 너비의 %), 농도 0~100%, 여백(px), 문자 색·굵기, 미리보기에서 바로 확인 |
| 테두리 | 두께 0~50px·색 | 선택 |
| 사진 정보 지우기 | 촬영 정보·GPS·기기 정보 제거 | 캔버스에 다시 그려 새로 저장하면 정보가 자동으로 빠짐 — 화면에 「✅ 촬영 정보·위치 정보 제거됨」 표시 |
| 저장 | JPG(품질 60~100, 투명은 흰색) / PNG | 1장은 그 파일, 여러 장은 ZIP(`사진손질_N장.zip`), 파일 이름 앞붙임·순번 선택 |
| 미리보기 | 첫 장(또는 고른 장)을 결과 그대로 표시 | 설정을 바꾸면 바로 다시 그림 |
| 설정 기억 | 워터마크·크기·저장 형식 | 이 브라우저에만 저장(로고 이미지 포함, 지우기 버튼) |

**넣지 않는 것**: 원본의 「랜덤 크롭·좌우 반전」(마켓의 중복 이미지 판정을 피하려는 용도로 추정 — 인계 문서에서 제외 결정), 밝기 일괄 조절(필요하면 2차).

## 3. 2차 (다음 배포, 별도 승인)
- **사진별 주석 편집**: 화살표·네모/원·글자·형광펜·모자이크(네모/원), 실행 취소. E5의 「얼굴 자동 모자이크」와 모자이크 코드를 같이 쓰므로 **E5와 묶어서** 만드는 것이 효율적.

## 4. 만드는 방법
| 파일(새) | 하는 일 |
|---|---|
| `src/app/(workspace)/batch/page.tsx` | 화면(권한 확인은 기존 레이아웃 그대로) |
| `src/components/batch/BatchPhotoBoard.tsx` | 목록·설정 패널·미리보기·ZIP 받기(무료 지우기 화면 구조를 본떠 같은 색·버튼) |
| `src/lib/batch/layout.ts` | 순수 계산: 높이 맞춤 크기, 워터마크 위치·크기(9곳·여백), 파일 이름 — **시험 대상** |
| `src/lib/batch/render.ts` | 캔버스에 그리기(`createImageBitmap`로 사진 방향 반영 → 크기 → 테두리 → 워터마크 → JPG/PNG) |
| `src/components/layout/Sidebar.tsx` | 메뉴 한 줄 추가 |
| `/guide` | 「사진 일괄 손질」 사용 4단계 카드·FAQ(매뉴얼 지침) |
- ZIP은 이미 쓰는 `jszip` 그대로(새 라이브러리 없음).
- 큰 사진 여러 장은 한 장씩 차례로 처리해 브라우저 메모리를 아낌(진행 표시 「12/30」).

## 5. 검수
- 단위 시험(`layout.ts`): 높이 맞춤 비율, 9곳 위치 좌표·여백, 워터마크 크기 %, 4096px 초과 경고, 파일 이름 규칙.
- 크롬 실제 창(시험 계정, 포그라운드): 사진 3장(가로·세로·휴대폰 사진) → 높이 860 → 로고·문자 워터마크 위치 바꿔 보기 → ZIP 받아 열어 크기·워터마크 확인 → **휴대폰 사진의 위치 정보가 결과 파일에서 빠졌는지** 파일 정보로 확인.
- 휴대폰 폭 390px 넘침 없음, 콘솔 오류 없음.
