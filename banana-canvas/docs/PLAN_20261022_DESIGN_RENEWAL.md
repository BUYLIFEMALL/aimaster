# 디자인 리뉴얼 플랜 — 나노바나나 크림 팝 스타일 (v1.20, 2026-10-22)

> 작성: Claude Code(윈도우). 대상 ① 운영 AIMaster. 주인님 지시: 「배경은 연한 노란색 바탕을 베이스로 그 컨셉과 어울리게 나노바나나 느낌으로, 디자인 템플릿 지침을 확인한 후 기준에 맞추어 새로운 템플릿을 생성하고 디자인 적용」 + 「사용자 가독성 높게」.
> 승인(2026-10-22): 새 템플릿 이름으로 등록(독립 템플릿 11번), 비용 = 빌드 1회(실패·보정 시 최대 2회).

## 분석
- 현재 v1.08 「크리에이티브 아틀리에 스타일 — 바나나 팝 차콜 변형」(Antigravity, 다크). 구조 = 흰색·남색 기본 CSS(골격) + `globals.css` 맨 끝 다크 덮어쓰기. 기능 컴포넌트는 클래스만 쓰고 색은 거의 CSS에 있음(화면 파일 직접 색 3곳).
- 지침 확인: DESIGN.md 원칙 6(플랜 먼저), 13(전 페이지 같은 바탕), 19(좁은 칸 버튼 꺾임 검수), §1 새 이름 기준(골격 동일·색만 변경이면 변형) → 주인님께 차이를 알리고 「새 템플릿」으로 결정받음.

## 컨셉과 토큰
연한 바나나 크림 바탕(`#fff8d6`) + 바나나 반점 갈색 먹선(`#2b2410`) + 바나나 옐로(`#ffd43b`) 버튼 + 잎 초록(`#2f8a3b`) 포인트. 카드 위 바나나 껍질 띠(노랑→연두 4px), 18px 둥근 모서리, 스티커 팝 버튼(2px 먹선 + `2px 2px 0` 그림자, 누르면 눌림).
가독성: 본문 14→15px, 안내·라벨 13px, 보조 글자 `#5f5028`(크림 바탕 대비 7.4:1), 노란 바탕 위 글자는 먹선색(10.8:1), 노랑 계열 글자는 진한 바나나 `#7a5200`(6.8:1).

## 구현 순서
1. `globals.css` 맨 위 토큰 교체, v1.08 덮어쓰기 블록을 새 템플릿 블록으로 교체(골격·기능 CSS는 그대로).
2. 화면 파일의 `color: var(--brand)` 3곳 → `--brand-text`/노란 칩, 기록 상세 오류 글자 → `var(--danger)`.
3. 실화면 검수 후 보정: 잠긴 카드 흐림 완화, 아이콘 위 🍌 또렷하게(크림 바탕), 버튼 줄 가운데 정렬, 560px 이하 버튼 한 열.

## 검수
크롬(시험 회원) 스튜디오·매뉴얼·API 설정 화면, 휴대폰 폭은 창 최대화로 줄일 수 없어 390px 틀(iframe)에서 규칙 확인(위쪽 메뉴 전환·가로 넘침 0·잘림 0·꺾인 버튼 확인 후 보정).
