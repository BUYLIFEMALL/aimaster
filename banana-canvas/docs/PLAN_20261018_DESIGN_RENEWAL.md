## 2. 적용할 디자인 템플릿 — 「크리에이티브 아틀리에 스타일 — 바나나 팝 차콜 변형」 (새 이름, `DESIGN.md` 카탈로그 등록)
**이렇게 하려는 이유**
- 현황판 권장은 다크(차콜). 여러 도구를 한 화면에 늘어놓는 "작업대(도구함)"라 어두운 바탕이 결과 이미지를 돋보이게 하고, 카드가 많아도 눈이 덜 피곤합니다.
- 프로그램 이름(바나나)에서 따온 **바나나 옐로 + 잎사귀 그린**으로 한눈에 알아보게 합니다. 바탕은 노랑이 잘 어울리는 **따뜻한 차콜**(살짝 갈색 기운).
- 겹치지 않음: AI 이미지 스튜디오(검정+골드)보다 밝고 경쾌한 노랑에 초록 보조색, 인물사진(중립 회색+하늘색), 4컷 만화(크림 라이트)와 구분.

**바나나 느낌 요소**: 브랜드 아이콘 🍌 배지, 작업 카드 머리에 그룹 색 띠(생성·편집=옐로, 합성=그린, 빠른 작업=오렌지, 스페셜=보라 톤 한 가지), 결과 카드는 은은한 옐로 테두리 빛. 작업마다 달랐던 버튼 색(청록·빨강·보라)을 토큰 3가지로 정리.
모든 화면(작업·기록·설정·매뉴얼·로그인·설치·열기) 같은 배경·카드·테두리(지침 ⑪).

## 3. 구현 범위 (화면·문구만, 기능 로직은 그대로)
1. `globals.css` 토큰·공통 컴포넌트 값 교체 — **클래스 이름은 그대로**(인물사진 v1.22와 같은 방식: 맨 위 토큰 + 맨 끝 덮어쓰기 묶음). `Studio.tsx`·`MaskEditor.tsx` 로직 무변경.
2. `Sidebar.tsx`: 브랜드 아이콘을 바나나 배지로, 메뉴 항목·순서·계정 위치(메뉴 바로 아래)는 그대로. 메뉴 이름 `📖 연동 & 사용 매뉴얼`로 표준화.
3. `/studio`: 맨 위에 **작업 지도 칩 띠**(🖼️ 원본 · ✨ 생성·편집 · 🧩 합성 · ⚡ 빠른 작업 · 📚 스페셜 · 🌟 결과 — 누르면 해당 카드로 이동, 카드에 `id`만 추가). 카드 머리 그룹 색 띠. 3열 배치·버튼 위치·동작 유지.
4. `/guide` 비주얼 매뉴얼로 재구성(지침 ④·⑦): 바나나 캐릭터 말풍선 소개, 3단계 흐름 그림(원본 → 작업 카드 → 결과·계속 편집), **작업 지도 카드**(그룹별 이모티콘·하는 일·필요한 입력), **스타일 20종 칩**(`STYLES`에서 직접 읽음 — 프리셋을 바꾸면 매뉴얼도 자동 반영), 배경 제거·부분 삭제 원리 그림(CSS 도형), 개인정보·비용 주의, FAQ. 기존 6절 내용은 빠짐없이 옮김.
5. `/history`·`/settings`·`/login`·`/setup`·`/open`: 같은 토큰 적용.
6. 모바일 375~390px: 위쪽 접는 메뉴 유지, 작업 지도 칩 가로 줄바꿈, 1열(결과 먼저 — 기존 규칙), 빠른 작업 1열, 마스크 브러시 영역 터치 유지.

## 4. 하지 않는 것
- 이미지 생성 프롬프트·모델·호출·스타일 목록·저장 방식, 권한 판정, API 라우트 — 변경 없음.
- 좌측 메뉴 2·3번 현재 위치 표시 개선(기록만), 기능 추가.
