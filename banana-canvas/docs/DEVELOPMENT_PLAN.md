# AI 바나나 캔버스 자동화 (banana-canvas) — 분석 및 개발 플랜 (2026-10-14, 승인 대기)

> 상태: **분석·플랜 단계. 코드 미착수.** 참고 앱: Google AI Studio "Banana Canvas" (`aistudio.google.com/apps/8a6f8974-d950-4cff-bc74-c28337f45f52`, 설명 "'Nano Banana' 을 이용한 이미지 생성,편집 도구").

## 1. 원본 분석

### 1-1. 한 줄 요약
이미지 한 장(또는 텍스트 아이디어로 생성한 이미지)을 올려 **Nano Banana(`gemini-2.5-flash-image`)로 편집·변환·합성**하는 단일 페이지 "사진 변환 도구함"이다. 편집 계열마다 **프롬프트 제안(한국어 프롬프트 엔지니어링 LLM 호출)** 버튼이 있고, 결과는 오른쪽 패널에 표시된다. 서버 없이 브라우저에서 AI Studio가 주입한 키로 호출하며 저장·기록은 없다.

### 1-4. 결함·한계 (우리 버전에서 해결)
1. **오류를 문자열로 판별**: 응답 텍스트에 "error"/"오류"가 있으면 실패로 간주 — 모델이 정상 설명에 그 단어를 쓰면 오판. 우리: 서버에서 응답 구조(이미지 파트 유무·차단 사유)로 분류.
2. **한 번의 응답에 8컷/레시피 전부 요구**: 컷 수·텍스트-이미지 쌍이 어긋나도 검증하지 않음. 우리: 컷 수를 검증하고 부족하면 안내·부분 재생성.
3. **결과가 저장되지 않음**: 새로고침하면 소실, 결과를 다시 원본으로 쓰는 "이어서 편집" 없음. 우리: 결과 기록(최대 30건)과 [이 결과를 원본으로 계속 편집].
4. **큰 base64를 브라우저 메모리에서 반복 전송**: Vercel 4.5MB 본문 한도에 맞지 않음. 우리: 비공개 Storage 업로드 후 서버가 읽음.
5. **불필요한 번역 호출**: 한국어 프롬프트를 영어로 번역하는 LLM 호출이 매번 추가되어 느리고 의미가 변질됨(인생 앨범은 긴 한국어 지시문까지 번역). 우리: 이미지 모델이 한국어를 이해하므로 고정 템플릿은 영어로 직접 작성하고 사용자 입력만 그대로 전달(번역은 옵션).
6. **Imagen 의존**: `imagen-4.0-generate-001`은 결제·권한이 필요하고 계정별 사용 불가 가능. 우리: Gemini 이미지 모델(`gemini-3-pro-image-preview` → `gemini-2.5-flash-image`)로 통일하고 모델 표기·폴백.
7. **얼굴 보존·초상**: 증명사진·인생 앨범·합성이 실제 인물 사진을 다루지만 동의·주의 문구가 없음. 우리: 업로드 화면과 매뉴얼에 본인/동의 받은 사진만 사용하라는 안내, 업로드 원본 1시간 자동 삭제.
8. **UX**: 모든 기능이 한 화면에 섞여 어디서 무엇을 하는지 불명확, 모달 중심, 어두운 테마. 우리: 작업 탭(만들기·편집·합성·빠른 작업·스페셜)으로 분리한 흰색 표준 UI.
9. **업스케일 오해**: 클라이언트 canvas 확대는 해상도만 키움. 우리: 서버 `sharp`(Lanczos3) 확대 + AI 선명화 단계를 분리하고 안내 문구로 한계 명시, 출력 상한(긴 변 8192px).
10. **연도 규칙·접근 정책 없음**: 프롬프트에 기준 연도가 없고 접근 제어·본인 키 저장이 없음. 우리: 핵심 원칙 8번·최상위 규칙 적용.

## 3. 기능 범위

### v1.01 (원본 동등 + 결함 해결)
1. **만들기**: 아이디어 → 카테고리 11종 프롬프트 제안 → 이미지 생성(종횡비 5종), 결과를 바로 원본으로 편집.
2. **편집**: 처리(복원·컬러화·채색·업스케일 2x/4x) 복수 선택 + 스타일 17종 + 추가 요청 + 프롬프트 제안(재질 지침 포함), 배경 자동 판정.
3. **합성**: 소스 최대 5장, 합성 설명, 종횡비(원본·5종) 확장, 프롬프트 제안, 얼굴 정체성 고정 규칙.
4. **빠른 작업**: 배경 제거(서버 `sharp` 알파 합성, PNG 투명 배경 다운로드), 부분 삭제(브러시 마스크), 증명사진(3:4), 평면도 3D(종횡비 3종).
5. **스페셜**: 인생 앨범(나이·비율), 만화 패널(3스타일·언어·대사·비율), 연속 스토리 8컷, 이미지 레시피, 이미지에서 아이디어/요리명 제안.
6. **결과**: 큰 보기(해상도 표시), 다운로드(PNG/JPG), "이 결과로 계속 편집", 기록 30건·즐겨찾기·삭제.
7. 오류 분류(키·한도·안전 필터·이미지 미반환·시간 초과), 취소, 사용 매뉴얼·키 등록 매뉴얼.

### 후속
브러시 아웃페인팅 영역 지정, 결과 비교 슬라이더, 일괄 처리(여러 장 같은 스타일), 사용자 정의 스타일 프리셋, 영어 UI.

## 4. 아키텍처
- Next.js 16 App Router + TS, 순수 CSS. `reverse-prompt`·`thumbnail-master` 골격(접근 판정·사이드바·키 관리·`/open`·SSO 쿠키)과 `reverse-prompt`의 서명 업로드 방식을 그대로 재사용.
- `src/lib/bnc/`(순수 로직, 단위 테스트): `styles`(스타일 17종 프롬프트·재질 지침), `categories`(생성 카테고리 11종 템플릿), `prompts`(편집·합성·증명사진·평면도·인생 앨범·만화·스토리·레시피·제안 프롬프트 조립, 연도 주입, 한국인 기본), `modes`(작업 종류·종횡비·입력 검증), `validate`(경로·크기·옵션).
- 서버 API(전부 `checkProgramAccessApi` + `force-dynamic`): `POST /api/upload`(서명 URL), `POST /api/suggest`(프롬프트/아이디어/요리명 제안), `POST /api/generate`(텍스트→이미지), `POST /api/edit`(작업 종류별: 편집·합성·빠른 작업·스페셜, 입력 이미지 경로 + 옵션), `GET/PATCH/DELETE /api/history`, `/api/keys`. 응답은 항상 Storage 저장 후 서명 URL(이미지를 응답 본문에 싣지 않음).
- `src/lib/image.ts`(서버, `sharp`): 마스크 알파 합성, 업스케일(Lanczos3, 긴 변 8192px 상한), JPEG/PNG 변환, 종횡비 검증.
- DB: `banana_canvas_results(id, user_id, kind, title, prompt, options jsonb, input_paths jsonb, outputs jsonb[{path, mime, w, h, text?}], model_used, favorite, created_at)` + RLS owner-only(서버는 service role + `user_id` 필터), 최대 30건. Storage 비공개 `banana-canvas-tmp`(입력, 1시간 정리)·`banana-canvas-results`(결과), 첫 폴더 = uid.
- 환경변수 새로 추가 없음(공용 Supabase 3종만). Vercel 프로젝트·도메인은 신규.

## 7. 리스크
1. **이미지 생성 비용**: 기능마다 이미지 1~8건이 본인 키 사용량으로 계산됨(스토리 8컷·레시피 다수) — 화면에 예상 건수 안내, 확인 후 실행.
2. **모델 응답 변동**: 8컷/레시피가 부족하게 오는 경우가 있음 → 컷 수 검증, 부족 시 안내와 이어서 생성.
3. **얼굴 동일성·초상권**: 모델이 얼굴을 바꿀 수 있고 타인 사진 악용 우려 → 규칙 프롬프트 + 안내 문구 + 원본 1시간 삭제.
4. **안전 필터**: 인물 사진 편집이 차단될 수 있음 → 오류 분류와 우회 안내(다른 사진·표현).
5. **응답 한도·시간**: 스토리 8컷은 응답이 커서 Storage 저장 필수, 시간 초과 시 컷 단위로 나눠 호출(`maxDuration 300`).
6. **기존 프로그램과 중복 인식**: 카탈로그 설명에 "사진 한 장 변환 도구함(복원·스타일·합성·증명사진·인생 앨범)"으로 구분.
7. **모델명 변동**: 체인 상수화, 화면에 실제 사용 모델 표시.

## 8. 승인 요청 사항
위 플랜대로 구현을 시작해도 되는지 확인이 필요합니다("진행해줘"). 구현 시 새로 하는 외부 영향 작업: 비공개 Storage 버킷 2개와 결과 테이블 1개 생성, Vercel 프로젝트·도메인 신규, 카탈로그 썸네일 생성(Gemini 이미지 1회)과 실호출 검수용 이미지 생성 여러 건(운영자 본인 키 비용).
