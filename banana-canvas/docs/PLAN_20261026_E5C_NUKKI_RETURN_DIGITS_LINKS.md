# E5-3 누끼 되돌려 넣기 · 숫자 자리만 가리기 · 개인정보 가리기 바로가기 (2026-10-26)

상태: **주인님 승인 대기** (코드 없음)
작성: Claude Code 윈도우 `claude-win-sdp` [역할: ecommerce-image]
근거: v1.41 결과 보고의 추가 개선 제안 3가지(주인님 진행 지시)

## 1. 범위
| # | 프로그램 | 할 일 | 방식·근거 |
|---|---|---|---|
| ① | 바나나 `/tools` + 상세페이지 | 상세페이지 「✂ 누끼」로 연 창에서 결과 위에 **「↩ 상세페이지 #01 섹션에 넣기」** 버튼 → 결과 PNG를 상세페이지 창으로 되돌려 보내고, 상세페이지가 그 섹션에 **새 버전으로 저장**(기존 「📤 직접 등록」과 같은 저장 길, 원본은 버전 목록에 남음) | 공용 `nukki-handoff`에 반대 방향 메시지(결과)·검사 함수 추가 → 기준만 고치고 사본 동기화. 상세페이지 창이 닫혔으면 「받아서 직접 등록」 안내 |
| ② | 바나나 `/tools` 얼굴 가리기 | 「🔢 글자 자리 가리기」에 **「숫자가 많은 자리만」** 선택(송장·전화번호·주문번호) | 글자 읽기 모델 `ch_PP-OCRv4_rec`(약 10.9MB, Apache-2.0, 지금 쓰는 저장소와 같은 커밋 고정 주소)로 각 글자 자리를 읽어 숫자 비율·개수로 거름. 선택했을 때만 받음(처음 1회). 글자 목록은 모델 안 메타데이터를 쓰고, 없으면 PaddleOCR 공개 사전(약 26KB)을 프로그램에 둠 |
| ③ | 주문 리포트 `shop-order-report` · 라벨·서류 `seller-label-docs` | **「🙈 사진 속 개인정보 가리기 ↗」 바로가기 카드** → 바나나 `/tools?tab=face` 새 탭(얼굴 가리기 탭이 바로 열림) | 확인 결과 세 프로그램(상품소싱·주문 리포트·라벨)에는 송장·후기 **사진**을 올리는 화면이 없음(상품소싱 사진은 상품 이미지, 리뷰 분석은 글 파일) → 사진을 넘기는 대신 바로가기. 위치: 주문 리포트 홈·「리뷰 분석」 화면, 라벨·서류 홈 도구 카드 |

## 2. 순서·검수
1. 바나나: `?tab=face` 받기, 결과 되돌려 보내기 버튼, 숫자 거르기(순수 함수 시험: 숫자 비율·개수 판정, 글자 디코딩) → 로컬 임시 페이지 확인
2. 상세페이지: 결과 받기 → 새 버전 저장(시험 계정 시험 상품 1장, 확인 뒤 원본 버전 다시 선택)
3. 주문 리포트·라벨: 바로가기 카드
4. 배포 순서: 바나나 → 상세페이지 → 주문 리포트 → 라벨·서류(한 번에 하나, Ready 확인) → 운영 크롬 앞 탭 검수 → 문서·요청함
