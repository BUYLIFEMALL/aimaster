## 단계

| 단계 | 기능 | 구현 방향 | 주의 |
|---|---|---|---|
| C-1 | **공용 「브라우저 무료 지우기」 엔진** | 새 공용 기준 코드(예: `browser-inpaint`): 모델 받기(허깅페이스 직접, 진행률·취소·Cache API 캐시) → `onnxruntime-web` 세션(WebGPU 우선 → WASM) → 작업자(worker)에서 추론. LaMa 입력 `image` float32[1,3,512,512](0~1) · `mask` float32[1,1,512,512](0/1) → `output` 0~255(**0~1 아님**). 큰 이미지는 마스크 주변 잘라 512로 줄여 처리 후 원래 크기로 합성 | 입출력 규격은 **세션을 만들어 직접 측정해 확인**(파일 바뀌면 다시). `SHARED_MODULES.md`·`SHARED_FEATURE_MAP.md` 등록 |
| C-2 | **글자 자동 찾기** | PP-OCRv4 위치 검출 → 글자 상자를 약간 넓혀 마스크로. 읽지 않고 위치만 | 세로쓰기·장식체는 놓칠 수 있다는 안내, 남길 글자는 지우개로 |
| C-3 | **「무료 지우기」 화면** | 바나나 캔버스 새 메뉴: 여러 장 올리기(상한은 회원 PC 메모리 고려해 정함, 예: 50~100장) → 작업 목록(체크·썸네일·마스크 표시·완료 배지) → 캔버스(`MaskEditor` 확장: 지우개·되돌리기·확대/이동·「원본으로」) → 「문구 찾기」(현재 장 칠하기만) / 「지우기」 | 원본 픽셀은 건드리지 않고 결과를 따로 보관 |
| C-4 | **일괄·내려받기** | 한 장 마스크를 **같은 비율 여러 장에 복사**(비율 다르면 안내·「같은 비율만 선택」) → 선택 장 일괄 지우기(진행·남은 시간·중단 시 처리분 유지·실패 표시) → **ZIP 내려받기**(원본 무손실 PNG / 가로 크기·JPG 품질 85·90·95) | 서버 업로드 없음 — 기존 「1시간 뒤 삭제」 임시 저장소와 무관 |
| C-5 | 기존 방식과 나란히 | 「무료 지우기(내 브라우저)」와 「AI로 다시 그리기(Gemini·유료·고품질)」를 회원이 고르게 안내 | 사용 매뉴얼(`/guide`) 갱신 |

순서 추천: **사전 검증 페이지(엔진만, 머리글·속도 확인 — 저장소 밖·내 PC 주소, 필요 시 Lab)** → C-1·C-2 → C-3 → C-4 → C-5 → 배포 1회. 배포할 때만 버전 +0.01(코드·DB).

## 사전 검증 페이지에서 먼저 확인할 것

1. **COOP/COEP 머리글** — `onnxruntime-web` 멀티스레드에 필요(`crossOriginIsolated`). 켜면 로그인(SSO)·외부 이미지(Supabase 저장소·허깅페이스)·다른 창 연동이 깨질 수 있음 → 「무료 지우기」 경로에만 적용 가능한지, 안 되면 단일 스레드(느림)로. **음악 담당의 「브라우저 무료 음성」 엔진 인계(`docs/analysis-supertonic-tts-20261024/HANDOFF_20261024_MUSIC_OWNER.md`)와 같은 과제 — 먼저 확인한 쪽 결과를 공유.**
2. 첫 208MB 내려받기 시간·캐시 재사용, WebGPU 없는 PC에서 장당 처리 시간.
3. 한국어 글자(가로·작은 글씨) 검출 품질.
