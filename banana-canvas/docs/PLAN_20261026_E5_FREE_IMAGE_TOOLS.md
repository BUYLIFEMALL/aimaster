# E5 무료 이미지 도구 — 배경 지우기·얼굴 가리기·사진 나누기 개발 플랜 (2026-10-26)

상태: **주인님 승인 대기** (코드 없음)
작성: Claude Code 윈도우 `claude-win-sdp` [역할: ecommerce-image]
근거: `docs/analysis-ecommerce-bundle-20261024/HANDOFF_20261024_ECOMMERCE.md` §6 E5, `05_KDP_WORK_TOOLS.md` §4~6, 공용 컴포넌트 `browser-free-erase`(`docs/SHARED_MODULES.md`)

## 1. 문제와 목표
- 쇼핑몰 셀러는 상품 누끼, 후기·택배 사진의 얼굴 가리기, 긴 사진 나누기를 외부 사이트에서 따로 한다(파일 왕복).
- 바나나 캔버스 안에서 **API 키·비용 없이 브라우저에서** 세 가지를 하게 한다. 사진은 서버로 보내지 않는다.

## 2. 범위 (화면 하나, 탭 3개)
새 화면 `/tools` 「🧰 무료 이미지 도구」(좌측 메뉴 「AI 보조 도구 & 유틸리티」, 사진 일괄 손질 아래)

| 탭 | 하는 일 | 방식 |
|---|---|---|
| ✂ 배경 지우기 | 자동 누끼 → 투명·흰색·단색 배경, **지우기·되살리기 붓**으로 경계 보정, PNG(투명)/JPG | U²-Net 경량판 `u2netp.onnx`(약 4.7MB, Apache-2.0), 320×320 계산 후 원본 크기 마스크 |
| 🙈 얼굴 가리기 | 얼굴 자동 찾기 → 모자이크/흐리게, 강도 조절, **네모를 손으로 추가·삭제**(못 찾은 얼굴·이름표·송장 번호 가리기) | 경량 얼굴 찾기 ONNX 모델(UltraFace RFB-320 약 1.2MB 또는 YuNet 약 0.3MB — 구현 때 라이선스·커밋 고정 주소 확인 후 하나) |
| ▦ 사진 나누기 | 2·3·4·6·8·16조각(가로·세로·격자), 분할선 끌기, 조각별/ZIP | 캔버스만(모델 없음) |

공통: 여러 장 넣기·Ctrl+V, 촬영 정보·위치 정보 제거(E4와 같은 방식 — 캔버스에 새로 그림), ZIP은 기존 `jszip`, 결과를 「사진 일괄 손질」로 넘기기 버튼.

**하지 않는 것**: 워터마크 자동 제거(공용 컴포넌트 규칙), 서버 계산, 유료 모델. 경량 모델이라 머리카락·투명 물체 경계가 약하므로 화면에 「더 정교한 누끼는 🪄 AI 작업 카드(본인 키)」 안내를 둔다.

## 3. 구현 방법 (기존 코드 재사용)
- 모델 받기·Cache API 저장·작업자 계산·WebGPU 우선→WASM 전환: **기준 `src/lib/freeErase/`(`browser-free-erase`)에 모델 종류 2개(`bg`·`face`)와 전·후처리 순수 함수를 추가**한다. 사본 `shop-detail-page/lib/freeErase/`는 `node scripts/check-shared-modules.mjs --module browser-free-erase --sync`로 맞추고, 상세페이지는 새 기능을 쓰지 않으므로 **사본은 미배포 대기**(다음 상세페이지 배포 때 함께). 동기화 직전 `ACTIVE_WORK`에서 `shop-detail-page` 작업 중인지 확인한다.
- 모자이크·나누기·마스크 합치기 계산은 `src/lib/freeTools/`의 순수 함수(시험 가능)로, 화면은 `src/components/freeTools/`.
- **꾸밈은 `globals.css` 전용 규칙(`ft-` 접두사)만** — 이 프로그램은 테일윈드가 없다(E4 교훈).
- 계산 라이브러리 `onnxruntime-web@1.23.0`(기존 `/ort/`) 그대로.

## 4. 순서와 검수
1. 순수 함수 + 시험(마스크 크기 맞춤·알파 합치기, 얼굴 상자 후처리·겹침 제거, 나누기 좌표, 모자이크 블록) → `npm test`
2. 기준 `freeErase`에 모델 2종 추가 → 사본 동기화 → `tsc`
3. 화면 3탭 + 메뉴 + `/guide#free-tools` 카드(4단계·FAQ)
4. 로컬 `npm run dev` 화면으로 배치 확인(첫 배포 전에 배치 깨짐 방지) → `npm run build`
5. 배포 1회(v1.40, E4 미배포 대기 80px CSS 함께) → 크롬 운영 검수: 시험 사진(상품·사람 얼굴 포함 무료 생성 그림)으로 누끼 PNG 투명 확인, 얼굴 상자 위치, 4분할 크기, 결과 Exif 0건, 390px 폭
6. 문서(AGENTS·IMPROVEMENTS·비교표 카드·이커머스 기능 표·SHARED_MODULES·역할 파일·HANDOFF) + 요청함 결과
