## 문제
- 연속 스토리 8컷은 장면 계획 → 앞 컷 그림을 참고해 순서대로 그린다. 등장인물 설명을 저장하지 않아, 한 컷만 마음에 안 들어도 8컷 전체(이미지 8장 비용)를 다시 만들어야 했다.
- 편집 설정(처리·스타일·추가 요청·확대 등)을 다른 사진에 다시 쓸 방법이 없었다.

## 구현
| 항목 | 내용 |
|---|---|
| DB | `banana_canvas_presets`(회원별 RLS, kind = edit/restore/comic, 이름 1~30자) + `banana_canvas_results.busy_until`(선점 칸) — `supabase/migrations/20261022_v1_18_presets_and_recut.sql` |
| 순수 함수 | `src/lib/bnc/presets.ts`(허용 값만 남기기·기록에서 레시피 만들기), `src/lib/bnc/recut.ts`(다시 만들 계획·한 칸 바꾸기) |
| 서버 | `api/presets`(GET·POST·DELETE, 회원당 20개), `api/run/recut`(guardAi → busy_until 선점 → 이미지 1장 → 한 칸 저장·옛 파일 삭제, 실패 시 선점 해제) |
| 실행기 | 새 스토리는 `options.storyCharacter`, 새 레시피는 `options.stepPrompts` 저장(옛 기록은 앞 컷·단계 설명만으로 다시 만듦) |
| 화면 | 편집·복원·만화 카드에 「📌 내 작업 레시피」 줄(불러오기는 값만 채움 — 실행은 회원이), 결과·기록 상세의 스토리 컷·레시피 단계마다 「이 컷만 다시/이 단계만 다시」, 기록 상세 「이 설정을 레시피로 저장」 |
