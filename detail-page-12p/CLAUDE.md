## 1. 최상위 절대 불변 규칙 (Rule 00)
- 회원은 본인의 Google Gemini API 키(`user_api_keys.provider = 'gemini'`)를 직접 등록하여 연동한다.

## 2. 핵심 기능 및 구조
- **플랫폼 규격 최적화**:
  - `coupang`: 쿠팡 로켓배송 모바일 860px 규격 12장면 풀 시퀀스
  - `smartstore`: 네이버 스마트스토어 감성 리뷰형 9장면 시퀀스
- **1초 스펙 자동검색**:
  - 제품명 기반 핵심 스펙 4종, 설명, 타겟 고객, 할인율, 3대 후킹 포인트 자동 추출
- **사양서 및 다각도 제품 사진 파싱**:
  - PDF, TXT, MD 파일 내용 파싱 및 #FFFFFF 누끼 실물 사진 다각도 분석 렌더링
- **Nano Banana AI 렌더링**:
  - `⚡ Nano Banana` (Gemini 2.5 Flash 기반 고속 상업용 렌더링)
  - `✨ Nano Banana2` (Gemini 3 Pro / Imagen 기반 고해상도 질감 렌더링)
- **860px 세로 긴 통상세페이지 자동 합성 & 원클릭 다운로드**:
  - HTML5 Canvas를 활용하여 12개 장면을 긴 세로 통상세페이지로 합성하여 다운로드 지원
- **실시간 스마트폰 앱 라이브 시뮬레이터**:
  - 실제 소비자가 쿠팡/네이버 앱에서 스크롤하며 보는 화면을 실시간 시뮬레이션
