# AI 12단 상세페이지 자동화 (detail-page-12p)

쿠팡(12장+) 및 네이버 스마트스토어(9장+) 규격 자동 최적화, 1초 스펙 자동검색, 사양서 문서 파싱, Nano Banana AI 멀티모달 상세페이지 일괄 완성 스튜디오입니다.

## 주요 기능

1. **플랫폼 규격 자동 최적화**:
   - 쿠팡 로켓배송 860px 12장면 풀 시퀀스
   - 네이버 스마트스토어 감성 리뷰형 9장면 시퀀스
2. **1초 스펙 자동조사**:
   - 상품명 하나만 입력하면 핵심 스펙, 매력적인 제품 설명, 타겟 고객, 할인율, 3대 후킹 포인트를 1초 만에 자동 작성
3. **사양서 및 다각도 실물 사진 인식**:
   - PDF, TXT, MD 파일 내용 파싱
   - #FFFFFF 흰색 배경 누끼 제품 사진 다각도 분석 및 AI 렌더링 프롬프트 매칭
4. **Nano Banana 비주얼 렌더링**:
   - ⚡ Nano Banana (초고속 상업용 렌더링)
   - ✨ Nano Banana2 (초고해상도 극세사 질감)
5. **실시간 스마트폰 앱 라이브 시뮬레이터**:
   - 실제 고객이 쿠팡/네이버 앱에서 스크롤하며 보는 화면을 실시간 시뮬레이션
6. **860px 쿠팡 표준 세로 통상세페이지 자동 합성 & 원클릭 다운로드**:
   - 12개 장면을 HTML5 Canvas로 깔끔하게 하나의 긴 상세페이지 이미지로 합성하여 다운로드 지원
