# AI 12단 상세페이지 자동화 매뉴얼 (MANUAL.md)

## 1. 시작하기
1. 좌측 메뉴의 `🔑 API키등록·플랫폼연동`에서 본인의 Google Gemini API 키를 등록합니다.
2. `1. 제품 정보 입력`에서 제작하려는 상품명을 입력합니다.
3. `🔍 1초 스펙 자동검색`을 클릭하여 기본 스펙 및 카피를 자동으로 채웁니다.
4. 필요 시 제품 실물 사진이나 사양서 문서를 첨부합니다.

## 2. 12단 상세페이지 기획 및 렌더링
1. 하단의 `쿠팡 12단 상세페이지 원클릭 일괄 기획하기` 버튼을 누릅니다.
2. `2. 12단 상세 스튜디오`에서 생성된 12개 씬의 카피와 비주얼 프롬프트를 확인합니다.
3. 원하는 문구가 있으면 즉시 편집할 수 있습니다.
4. `⚡ 전체 이미지 일괄 렌더링` 또는 개별 씬 카드의 `이미지 렌더링`을 눌러 고화질 비주얼을 생성합니다.

## 3. 결과 다운로드
1. 우측의 실시간 스마트폰 뷰어로 완성된 상세페이지의 스크롤 감각을 검토합니다.
2. `📥 860px 통이미지 다운로드`를 누르면 쿠팡/스마트스토어에 바로 등록할 수 있는 긴 세로 통상세페이지 이미지가 생성됩니다.
3. `3. 보관함 & 다운로드`에서 언제든 프로젝트를 다시 열어 수정할 수 있습니다.
