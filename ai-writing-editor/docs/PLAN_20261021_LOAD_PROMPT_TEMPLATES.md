# 개발 플랜 — AI 글쓰기 에디터에서 「📁 내 템플릿」 불러오기 (2026-10-21, Claude Code 윈도우)

주인님 지시: AI Prompt 병합 C 「추가개선 제안 3」(다른 프로그램 연계). 대상: `ai-writing-editor` v1.11 → v1.12. 블로그 프로그램은 Codex 담당이라 이번 범위에서 뺌.

## 1. 문제
AI Prompt 자동화 「📁 내 템플릿 보관함」(표 `ai_prompt_templates`)에 만든 프롬프트를 글쓰기 에디터에서 쓰려면 복사·붙여넣기 후 변수를 손으로 고쳐야 한다.

## 2. 해결
| 항목 | 내용 |
|---|---|
| 위치 | 홈 「새 글 생성」의 「주제 또는 요청」 칸 위 「📁 내 템플릿 불러오기」 |
| 흐름 | 목록(검색) → 고르기 → `{{변수}}` 칸에 값 입력(AI 호출 없음, 비용 0) → 「요청 칸에 넣기」 |
| 데이터 | 새 읽기 전용 API `GET /api/prompt-templates` — 이 프로그램 권한(`checkProgramAccessApi`) + 서비스 롤 + `user_id` 필터, 본인 템플릿만. 프로그램끼리 서로 호출하지 않고 공용 DB 표를 직접 읽는다(회원 데이터 격리 유지, 쓰기 없음) |
| 빈 보관함 | 「AI Prompt 자동화에서 템플릿을 만들어 주세요」 + 링크 |
| 요청 칸 한도 | 2,000자 → 6,000자(템플릿 본문이 길기 때문, 서버 `LIMITS.prompt` 같이 변경) |

## 3. 구현 순서
1. `src/app/api/prompt-templates/route.ts`(GET, 캐시 방지 두 줄)
2. `src/components/editor/TemplatePicker.tsx`(목록·검색·변수 입력·넣기), `StartPanel`에 연결
3. `LIMITS.prompt` 6000, 버전 v1.12(코드·DB), 매뉴얼 한 줄
4. 역량 지도·AGENTS·HANDOFF

## 4. 검수
`npx tsc --noEmit`·기존 테스트·`npm run build` → 배포 → 크롬(일반 회원): AI Prompt에 저장한 템플릿이 목록에 보임 → 변수 입력 → 요청 칸에 들어감 → 초안 생성 1회 → 시험 문서·템플릿 삭제. 다른 회원 템플릿이 안 보이는지(관리자 계정 템플릿 0개 상태) 확인. 390px.

## 5. 비용
| 구분 | 내용 |
|---|---|
| 개발·시험 | 초안 생성 Gemini 1회(회원 본인 키) |
| 운영자 인프라 | 없음(배포 1회, DB 변경 없음) |
| 회원 부담 | 불러오기 자체는 AI 호출 없음 |
