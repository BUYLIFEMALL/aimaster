## 1. 프로그램 로직 및 기능 개선 (Logic & Feature Improvements)

### 1.1 문서 버전 히스토리 스냅샷 & 롤백 (Time-Machine Rollback)
- **현상 및 문제점**:
  - 현재는 1.5초 디바운스로 문서가 자동 저장되며 최신 1개 상태만 DB에 덮어써짐. 사용자가 AI 제안을 여러 번 적용하거나 대량 텍스트를 실수로 수정한 후 브라우저 세션을 새로고침하면 과거 특정 시점으로 되돌릴 수 없음 (Ctrl+Z는 세션 내에서만 유효).
- **개선 방안**:
  - `ai_writing_editor_snapshots` 테이블을 신설하거나 JSONB 배열로 저장 시점별 주요 스냅샷(최대 10개)을 자동 보관.
  - 에디터 상단에 [버전 기록] 메뉴를 추가하여 이전 스냅샷과 현재 글의 차이(Diff)를 시각적으로 확인하고 원하는 시점으로 복원(Restore)할 수 있도록 구현.
- **예상 효과**: 사용자 집필 안정성 대폭 향상 및 실수로 인한 원고 유실 방지.

### 1.2 다중 문장 일괄 AI 스타일 변환 및 맞춤형 프롬프트 프리셋
- **현상 및 문제점**:
  - 현재 버블 툴바는 드래그된 단일 범위에 대해 '다시쓰기', '줄이기', '늘리기', '전문적으로', '친근하게' 5개 버튼만 고정 제공됨.
- **개선 방안**:
  - 사용자가 자주 쓰는 커스텀 프롬프트(예: "중학생 수준으로 쉽게 풀기", "쿠팡 파트너스 어투로 변환", "경어체에서 평어체로 변경")를 직접 저장하고 원클릭으로 호출할 수 있는 [내 프롬프트 프리셋] 기능 추가.
- **예상 효과**: 개인화된 글쓰기 작업 시간 50% 이상 단축.

## 2. 사용자 인터페이스 / UI 가독성 및 사용편리성 개선 (UI/UX Improvements)

### 2.1 집중 집필 젠 모드 (Distraction-Free Zen Mode)
- **현상 및 문제점**:
  - 좌측 사이드바와 상단 네비게이션이 항상 노출되어 있어 긴 호흡의 글을 집필할 때 시각적 분산이 발생할 수 있음.
- **개선 방안**:
  - 에디터 우측 상단에 전체화면 집필 모드(Zen Mode) 버튼을 추가하여 사이드바와 상단 바를 부드럽게 숨기고 화면 중앙에 페이퍼 캔버스만 남기는 모드 구현 (ESC 키로 복귀).
- **예상 효과**: 전문 작가 및 블로거의 집필 몰입도 극대화.

### 2.2 실시간 통계 플로팅 인디케이터 (Word Count & Reading Time)
- **현상 및 문제점**:
  - 현재 본문의 글자 수나 단어 수, 예상 읽기 시간을 확인하려면 문서를 일일이 스크롤하거나 외부 도구를 사용해야 함.
- **개선 방안**:
  - 에디터 우측 하단에 미니멀한 플로팅 캡슐을 배치하여 [공백 포함/제외 글자수], [단어 수], [예상 소요 시간(분)]을 실시간으로 카운팅하여 노출.
- **예상 효과**: 네이버 블로그 포스팅 최적 분량(2,000자 이상) 맞춤 작업 편의성 증대.

### 2.3 표(Table) 스타일 프리셋 & 모바일 반응형 가로 스크롤 강화
- **현상 및 문제점**:
  - 표 삽입 시 기본 흑백 테두리로만 생성되어 디자인 완성도가 다소 밋밋함.
- **개선 방안**:
  - 파스텔 블루 헤더, 모던 스트라이프, 미니멀 보더리스 등 4종의 표 디자인 테마를 클릭 한 번으로 적용할 수 있는 표 스타일러 도입.

## 3. 현재 만들어져 있는 다른 자동화 프로그램과의 연계 가능한 기능 (Cross-Program Integration)

- **연계 시나리오**:
  - `blog-content-maker`에서 키워드 리서치 및 뼈대 아웃라인을 생성한 뒤, [AI 글쓰기 에디터로 보내기] 버튼을 클릭하면 `ai-writing-editor`의 새 문서로 즉시 전송되어 Tiptap 에디터에서 정밀 윤문 및 서식 편집을 이어갈 수 있는 파이프라인 연계.
- **구현 방식**:
  - Supabase DB 공유 테이블 또는 URL 쿼리 파라미터 / 로컬 스토리지 브릿지를 통한 데이터 인수인계.

### 3.2 76번 AI 썸네일 마스터 자동화 (`thumbnail-master`) 연계
- **연계 시나리오**:
  - 에디터 상단에 [대표 썸네일 생성] 버튼을 두고, 현재 작성 중인 글의 제목과 카테고리를 `thumbnail-master`로 전달하여 매거진 스타일 썸네일을 즉시 생성한 후 본문 최상단에 자동 삽입.
- **구현 방식**:
  - `thumbnail-master` API 호출 또는 새 창 연동 딥링크 파라미터 전달.

### 3.3 23번 이미지 스타일 분석기 (`style-dna-analyzer`) 연계
- **연계 시나리오**:
  - 글쓰기 에디터에 삽입할 이미지의 시각적 톤앤매너나 테마를 `style-dna-analyzer`의 분석 결과(프롬프트 추출물)와 결합하여 본문 맥락에 완벽히 일치하는 일러스트를 생성하는 협업 워크플로우.
