## v1.03 — 서식 에디터 (2026-10-14)
- 요청: "서식 에디터로 기능 확장". 평문 textarea를 **Tiptap(ProseMirror) 서식 에디터**로 교체. 저장은 마크다운 그대로(기존 문서 호환, DB 변경 없음).
- 추가: 서식 도구(제목1~3·굵게·기울임·취소선·코드·목록·번호·인용·링크·구분선·서식 지우기·실행 취소/다시 실행), 선택 시 버블 툴바(굵게·기울임 + AI 수정 5동작 + 직접 지시), 서식 복사(HTML+텍스트로 블로그·문서에 붙여넣기), .md/.html/.txt 내려받기, 마크다운 복사.
- 바뀐 동작: 되돌리기는 Tiptap 이력(AI 수정·제안 적용 포함), 제안 적용은 `insertText`로 그 자리 서식 유지, AI 프롬프트가 마크다운 서식을 쓰도록 허용(표·HTML 금지).
- 검수: 단위 14/14(ProseMirror 위치 찾기 3건 추가), Chrome 15/15(마크다운 렌더링·버블 툴바·서식 도구·링크 주소 검증·서식 유지 적용·서식 복사 HTML·다운로드), 빌드. 실제 호출은 `real-call.mts` 참고.

## v1.04 — 표·이미지·글자 색·정렬·여러 문단 제안 (2026-10-14)
- 요청: 마크다운 한계였던 표·이미지·글자 색·밑줄과 여러 문단 제안 적용을 확장 가능성 검토 후 구현.
- 검토 결과: 표(GFM)·이미지·밑줄(`++`)·형광펜(`==`)은 마크다운 직렬화가 있으나 **글자 색·정렬은 마크다운 표현이 없어** 저장 형식을 HTML로 확장(`content_type` 컬럼, 이전 문서는 마크다운 그대로 열리고 편집 후 HTML로 저장). 마크다운 내보내기는 손실이 있어 화면에 안내.
- 추가: 표(넣기·행/열 추가·삭제·머리글 전환·너비 조절), 이미지(파일 선택·붙여넣기·끌어놓기 업로드, 설명 alt·크기·삭제 메뉴, 모서리 크기 조절), 글자 색 9색·형광펜 6색·밑줄·좌/중/우 정렬, **문단 경계를 넘는 분석 제안의 찾기·본문에서 보기·적용(문단 병합/분할)**, 분석 프롬프트가 필요 시 문단 경계 포함 허용, 생성 프롬프트가 GFM 표 허용.
- 이미지 저장: 공개 버킷 + UUID 경로(주소를 아는 사람만 접근, 서식 복사·.html 호환). 회원당 60개, 캐시 1시간(삭제 후에도 CDN 캐시 최대 1시간 응답 — 실측), 문서 삭제 시 미사용 이미지 정리. 민감 이미지 주의 문구를 매뉴얼 FAQ에 추가.
- 검수: 단위 17/17, Chrome 20/20, 빌드, 실제 Storage·DB 검증(`image-real.mts`: 형식 거부·업로드·공개 주소·본인 폴더·HTML 문서 저장·목록 글자 수·삭제 시 정리·공유 이미지 보존).

- v1.05: 문서를 열 때 맨 앞 이미지가 자동 선택돼 이미지 메뉴가 툴바 위에 겹치던 문제 수정(`ImageMenu`는 에디터 또는 메뉴 입력칸에 포커스가 있을 때만 표시). 운영 확인: 이미지 붙여넣기(1.6MB PNG → 1600px로 축소 업로드, 공개 주소 로드)·표 삽입·자동 저장·새로고침 후 표/이미지/색/밑줄/형광펜/가운데 정렬 유지·삭제 시 Storage 이미지 0개.

## 알려진 한계 / 남은 일
1. 일반 회원(buylifemall@naver.com) 계정으로 로그인한 화면 확인(비밀번호 입력은 에이전트가 하지 않음).
2. 인터넷 검색 옵션은 모델이 실제로 검색했을 때만 출처가 붙는다(검색하지 않으면 출처 0건). 프롬프트에 "반드시 검색"을 넣었지만 보장은 아니다.
3. `.md`/마크다운 복사에는 글자 색·형광펜·정렬·이미지 크기가 담기지 않는다(서식 복사·.html은 유지). 표 셀 안의 여러 문단·병합 셀(rowspan/colspan)은 GFM 마크다운에서 단순화된다. 이미지는 공개 주소라 개인정보 이미지는 넣지 않도록 안내 중이며, 접근 제한이 필요하면 비공개 버킷 + 서명 주소(저장 시 경로 치환) 구조로 바꿔야 한다.
4. 후속 아이디어: 문서 버전 기록, 여러 제안 중 선택 적용 미리보기(diff), 말투 프리셋을 페르소나 문체 자동화와 연결.
