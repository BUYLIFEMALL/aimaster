# 🖋️ AI 글쓰기 에디터 자동화 (ai-writing-editor)

> **공식 서비스 URL**: https://ai-writing-editor.buylife.xyz  
> **현재 버전**: `v1.12` (2026-10-21 「📁 내 템플릿 불러오기」 — AI Prompt 보관함 연계, 상세는 `AGENTS.md`)  
> **디자인 템플릿**: 포커스 스튜디오 스타일 (`Focus Studio Theme`)

---

## 1. 프로그램 개요
주제와 간단한 요구사항만 입력하면 전문적인 초안을 생성하고, Tiptap 기반의 리치 서식 에디터에서 문장별 AI 다듬기(버블 툴바)와 글 전체 4대 관점 심층 분석 제안을 원스톱으로 적용하는 전문 콘텐츠 에디토리얼 자동화 웹 애플리케이션입니다.

- **포커스 스튜디오 테마 (`Focus Studio`)**: 따뜻하고 편안한 크림 페이퍼(`#fdfbf7`), 퓨어 화이트 카드, 딥 인디고(`#4f46e5`) & 로열 바이올렛(`#8b5cf6`) 포인트 컬러 적용.
- **Tiptap 리치 서식**: 표(Table), 이미지 업로드, 텍스트 색상, 형광펜, 밑줄, 텍스트 정렬, 마크다운 & HTML 듀얼 지원.
- **서식 복사 (Rich Copy)**: 네이버 블로그, 노션, 워드에 표와 스타일을 원형 그대로 붙여넣기 가능.
- **독립 비주얼 가이드북 (`/guide`)**: 4단계 파이프라인 다이어그램, 툴킷 쇼케이스, 상위 보안 원칙(BYOK) 배너, FAQ 5종 제공.

---

## 2. 주요 기능
1. **9대 전문 글쓰기 템플릿**: 블로그, 뉴스레터, 업무 보고서, 칼럼, 기획서, 상품 리뷰, 보도자료, SNS 스레드, 자유 양식.
2. **ProseMirror 완벽 보존 AI 버블 툴바**: 본문 문장 드래그 시 다시 쓰기, 짧게/길게, 전문적/친근하게, 직접 프롬프트 지시.
3. **4대 관점 AI 심층 분석 제안**: 문법/맞춤법, 표현력, 글 구조, 명확성 진단 및 본문 원클릭 치환.
4. **표 & 이미지 클라우드 에디터**: 3x3 표 삽입 및 너비 조절, 이미지 드래그/붙여넣기 시 1,600px 자동 최적화 업로드.
5. **회원 본인 키 보안 (BYOK)**: 회원 본인의 Google Gemini API 키로만 동작하며 안전하게 암호화 보관.

## 3. 기술 스택
- **프론트엔드**: Next.js 16.4.0 (Turbopack App Router), React 19.3.0, TypeScript 5.9.3, Tailwind CSS
- **에디터**: Tiptap 3.31.4, Floating UI 1.8.0, ProseMirror
- **AI 백엔드**: Google Gemini API (`gemini-2.5-flash`), 웹 그라운딩 검색
- **데이터베이스/스토리지**: Supabase PostgreSQL (RLS 완비), Supabase Storage
