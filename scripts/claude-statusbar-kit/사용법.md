# Claude Code 사용량 상태바

Claude Code 입력창 아래에 남은 사용량을 항상 보여 줍니다.

```
Opus 5.5·medium | 5h 97% (3h 40m) | weekly 99% (6d 22h 40m) | context 53%
```

| 표시 | 뜻 |
|---|---|
| `Opus 5.5·medium` | 지금 쓰는 모델과 추론 강도 |
| `5h 97% (3h 40m)` | 5시간 한도가 **97% 남음**, 3시간 40분 뒤 초기화 |
| `weekly 99% (6d 22h 40m)` | 주간 한도가 **99% 남음**, 6일 22시간 40분 뒤 초기화 |
| `context 53%` | 이 대화에서 쓸 수 있는 공간이 **53% 남음** |
| `credit $6.02/$250.00` | 구독 한도를 다 쓴 뒤 추가 크레딧으로 넘어갔을 때만 표시 |
| `session $0.12` | 구독 한도 값이 없을 때(API 키 사용 등) 이번 세션의 예상 비용 |

**모든 %는 쓴 양이 아니라 남은 양입니다.**

## 설치

준비물: Claude Code, Node.js

- **윈도우:** `상태바설치.cmd` 더블클릭
- **맥:** `상태바설치.command` 더블클릭. 막히면 터미널에 `node `를 입력하고 `install.js`를 끌어다 놓은 뒤 Enter

끝나면 Claude Code를 완전히 닫았다가 다시 시작하고, 질문을 한 번 보내 주세요.

## 제거

- **윈도우:** `상태바제거.cmd` 더블클릭
- **맥:** 터미널에서 `node install.js --uninstall`

## 안 보일 때

| 증상 | 확인 |
|---|---|
| 상태바가 전혀 안 보임 | Claude Code를 완전히 닫고 다시 시작 |
| 모델과 context만 보임 | 질문을 한 번 보낸 뒤 확인. API 키로 쓰면 5h·weekly 대신 `session`이 나옵니다 |
| 「node를 찾을 수 없습니다」 | https://nodejs.org 에서 LTS 버전 설치 |

이 도구는 내 PC에서만 동작하며 인터넷으로 아무것도 보내지 않습니다. 설치 때 바꾸는 것은 `settings.json`의 `statusLine` 항목과 상태바 파일뿐이고, 원래 설정은 `settings.json.before-statusbar`에 백업합니다.

## 스크립트 없이 만들기

`프롬프트.txt`의 내용을 Claude Code에 붙여 넣으면 Claude Code가 직접 만들어 줍니다.
