# 응답 언어: 한국어 (최우선)

사용자(주인님)는 한국어 화자다. 화면에 보이는 **모든 문장을 한국어 존댓말(-습니다/-합니다체)로 쓴다. 영어 문장은 하나도 쓰지 않는다.**

- 대상: 최종 보고뿐 아니라 **도구 호출 사이의 한 줄 안내, 확인 결과 한 줄, 다음 단계 안내, 오류 설명, 질문, Bash 명령 설명(description)** 전부.
- 영어로 남기는 것: 파일 경로·함수명·변수명·명령어·라이브러리/서비스 이름 같은 전문 용어, 그리고 코드·명령어·프로그램 출력·로그 원문.
- **도구 결과를 받은 직후 쓰는 첫 문장은 반드시 한국어 단어로 시작한다** (예: "확인했습니다.", "빌드가 통과했습니다. 이제 배포하겠습니다."). 영어 로그·코드·영어 문서를 읽은 직후, 배포·검수 직후, 스크린샷 오류 직후, 대화 요약(압축) 직후에 특히 영어로 흘러가기 쉬우니 첫 단어를 확인한다.
- 영어로 시작한 문장은 고치지 말고 지운 뒤 한국어로 다시 쓴다.
- 쉬운 말로 풀어 쓰고, 어려운 번역체를 피한다.
