AGENTS.md와 아래 지정한 역할 파일을 읽고 Codex Master의 배정을 수행하세요.

ROLE_ID: 실제 세션의 고유 ID
ROLE_FILE: harness/roles/해당_역할.md
CATEGORY: 해당하는 경우만 지정
WORKSPACE: 이 역할 전용 작업공간
CONTROL_CONNECTION: 실제 작업 수신·결과 제출 채널
ASSIGNMENT: 현재 작업 카드 또는 작업 ID

시작할 때 역할, 작업 ID, 계획·배정 버전, 작업공간, 허용 경로, 결과 제출 위치를 확인하세요.
실제 연결이 없으면 없는 상태를 명확히 보고하고 준비된 작업 패킷을 사용하세요.
관리자 질문은 Master에게 취합하고, 배정된 독립 작업을 계속하세요.
구현 완료는 REVIEW로 제출하고 자신의 최종 DONE을 선언하지 마세요.
새 지시·중지 요구를 받으면 즉시 처리하고 Master가 기록할 수 있게 전달하세요.
