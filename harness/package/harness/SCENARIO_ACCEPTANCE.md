# 실제 설치 후 반드시 확인할 운영 시나리오
이 목록은 테스트 계획입니다. 이 패키지 제작 중 사용자 PC에서 실행한 테스트가 아닙니다.

| 시나리오 | 통과 기준 |
|---|---|
| 작은 작업 하나 완료 | 결과 기록 후 다음 READY 작업이 실제 배정됨 |
| 한 작업에 로그인 필요 | 해당 작업만 BLOCKED, 다른 구현·검수 계속 |
| 관리자 요구 3개 발생 | Master가 중복 제거한 한 묶음으로 제시 |
| 관리자 중간 우선순위 변경 | CMD 이력·계획/배정 변화·작업자 수신 확인 연결 |
| 오래된 작업 결과 도착 | 현재 배정과 대조, 자동 통합 금지·유효성 판정 |
| 테스트 실패 | 재현 증거 → 수정 배정 → 독립 재검수 |
| 작업자 종료·재호출 | 기존 프로세스·파일 상태 확인 후 중복 없는 복구 |
| Master/Controller 재시작 | 체크포인트와 사건 이력에서 다음 작업 복구 |
| 동일 입력·결과 두 번 도착 | 두 번 배정·두 번 외부 실행하지 않음 |
| 사람이 로그인 완료 보고 | 인증 확인 후 관련 작업만 재개 |
| 관리자 중지 | 신규 배정 중단·기존 실행 안전 처리·실제 적용 로그 |
| 로그/보고서 | 터미널과 파일의 작업·상태·결정이 일치 |
| 민감정보 출력 | 저장·표시 전에 제거됨 |
| 한도·환경 장애 | 상태가 사실대로 표시되고 무허가 추가 과금 없음 |
| 모든 준비 작업 소진 | 서비스 종료 없이 MONITORING, 불필요한 변경·모델 호출 없음 |
| 통합 후 코드 변경 | 최종 커밋을 대상으로 필요한 검수 재실행 |

시험용 저장소와 모의 외부 시스템에서 먼저 검증하고, 실제 외부 부작용은 기존 승인 범위에서만 확인합니다.
