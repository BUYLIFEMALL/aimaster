# 관리자 중간 지시 입력
## 간단 입력
우선순위를 SNS 로그인 → 블로그 → 쇼핑몰 순서로 바꾸세요.
디자인은 주황색을 유지하고, 쇼핑몰 신규 작업은 다음 단계로 미루세요.
현재 진행 중인 변경은 보존하고, 영향과 재배정 결과를 알려주세요.

## 선택 입력
- 지시 종류: 추가 / 수정 / 우선순위 / 중지 / 재개 / 취소
- 대상 작업·카테고리:
- 요청 내용:
- 유지할 기존 조건:
- 적용 시점:
- 승인 범위 변경 여부:
