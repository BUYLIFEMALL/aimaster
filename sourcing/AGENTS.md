# 🤖 AI Agent 협업 가이드라인 — Sourcing Agent (AGENTS.md)

이 문서는 **AIMaster Sourcing Agent (제조공장 & 소싱 데이터 AI 자동 분석 모듈)** 프로젝트에서 AI Agent가 작업할 때 준수해야 할 가이드라인 및 안전 수칙입니다.

---

## 🛡️ 에이전트 안전 수칙 (Mandatory Rules)

### 1. 자율 진행 허용 작업
다음 작업은 사전 승인 없이 자율적으로 수행합니다:
- 견적서(PDF/Excel/이미지/TXT) 파서 작성, LLM 추출 구조화, 프롬프트 작성, 코드 수정
- 패키지 설치 (`npm`, `pip` 등)
- 로컬 테스트 및 빌드 실행

### 2. 사전 승인 필수 작업 (🚨 승인 없이 금지)
다음 6가지 작업은 실행하기 전 **반드시 사용자에게 명확히 확인 및 승인**을 받으세요:
1. **파일이나 폴더 삭제**
2. **Git push**
3. **실제 서비스 배포**
4. **데이터베이스 마이그레이션 또는 데이터 삭제**
5. **환경변수와 API 키 변경**
6. **유료 API 호출**

---

## 🎯 프로젝트 목적
상품별 폴더(`sourcing/data/[product_name]/`) 내에 축적되는 **제조공장 견적서(Quotation), 제품 스펙시트, 위챗(WeChat) 대화 캡처/텍스트, 이메일 스레드**를 AI(Gemini Vision / Claude 3.5 Sonnet)가 멀티모달로 종합 읽어들여 **공장별 비교표(MOQ, 단가, 샘플비, 생산기간, 결제조건)** 자동 집계, **미확인/미답변 사항 추적**, **공장 전달용 질문 리스트(중문/영문)**를 자동 작성합니다.

---

## 📂 프로젝트 작업 디렉토리
* **메인 모듈 경로**: `sourcing/`
* 모든 데이터 파서, 멀티모달 문서 추출기, 비교 매트릭스 생성기, 대화 흐름 분석기는 `sourcing/` 폴더 내에서 개발하고 관리합니다.

---

## 🏗️ 4단계 서브 프로젝트 로드맵

| 단계 | 서브 프로젝트명 | 주요 기능 |
| :--- | :--- | :--- |
| **Phase 1** | **Multi-Format Document Parser (MVP)** | 상품별 폴더 내 PDF/Excel/이미지/TXT 종합 읽기 ➔ 공장별 5대 핵심 항목 비교표 자동 추출 |
| **Phase 2** | **Unconfirmed & Pending Tracker** | 미확인 스펙/인증 항목 탐지 ➔ 이전에 요청했으나 답변받지 못한 미결 사항 자동 추출 |
| **Phase 3** | **WeChat & Email Follow-up Generator** | 다음 공장에 물어볼 질문 리스트 자동 생성 (한글 ➔ 영문 / 중문 🇨🇳 자동 번역 제공) |
| **Phase 4** | **Landed Cost & Margin Calculator** | 소싱 단가 + 관부과세 + 해상운송비 + 물류비 + 쿠팡/네이버 수수료 = **최종 착한 마진 계산기** 연동 |
