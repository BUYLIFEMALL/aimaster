## 현재 기능과 보존할 장점

네이버·구글 자동완성 롱테일 키워드, AI 연관검색어와 사람들이 묻는 질문, 콘텐츠 빈틈을 보여 주고, 네이버 상위 블로그 10개의 구조를 분석해 1위 공략법을 제안합니다. / 기회 점수·경쟁 난이도와 함께 실측 블로그 문서 수·월간 검색수·12개월 검색 추이로 키워드 경쟁력을 확인합니다. / 오늘 기준 정책·이슈 전략 키워드 10개, 4가지 관점의 글감 40개, 최신 뉴스 기반 글 기회와 뜨는 키워드를 보고, 결과마다 제목·썸네일 문구·공략 전략을 받아 기록 100건 저장·Markdown·CSV로 내보냅니다.

**보존할 장점:** 자동완성·경쟁도·이슈·글감 탐색

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
