## 2. 기능 플랜

### C-1 키워드 등급 탐색 (`feature: discover`)
1. 입력: 카테고리 최대 3 + 세부 주제 최대 5(또는 「직접 입력」 탭: 검색어 최대 20개 → AI 없이 수치·등급만).
2. AI(회원 Gemini) 후보 12개 + 검색광고 연관어.
3. **[도톨이 N9] 수치 조회 전 주제 판정**: 연관어 후보를 AI가 한 번에 「주제와 맞음/아님」으로 거른 뒤에만 수치를 조회(관계없는 연관어에 검색 API 한도를 쓰지 않음). 같은 회원·같은 주제의 판정은 **6시간 재사용**(최근 같은 주제 `discover` 기록의 판정 결과를 읽음, 새 표 없음).
4. 수치: 월 검색량(PC·모바일)·블로그 문서 수·비율·등급 5단계, 등급순 정렬. 실측 값과 「값 없음」을 구분(0과 다름).
5. 결과: 저장(30일)·즐겨찾기·CSV, 키워드마다 「경쟁력 분석」·「SEO 스튜디오로 보내기」(기존 v1.06 넘기기 재사용).

### C-2 급상승 검증 (`feature: surge`)
1. 주제 → 최신 뉴스 10 + 웹 문서 10(네이버 검색, `webkr` 추가).
2. AI 요약 + 자료 속 새 용어 최대 10(자료 글에 실제로 나온 용어만 남김 — 작업실 규칙 그대로).
3. 데이터랩 14일(집계 지연 감안 16일 요청) → 급상승 판정(작업실 `surge` 규칙 그대로) + 검색량·문서 수·등급.
4. 화면: 용어별 14일 작은 그래프·변화율·「급상승」 표시. 기존 「카테고리 트렌드」와 메뉴 이름을 구분(「분야 트렌드」/「급상승 검증」).

### C-3 블로그 벤치마킹 (`feature: benchmark`)
1. 주제(최대 3) → 블로그 검색 50건씩 → 블로그별로 묶기.
2. **[도톨이 N8] 최근 활동 우선**: 검색 결과 글 날짜로 **최근 7일 안에 관련 글을 쓴 블로그**를 앞에(없으면 전체에서), 최대 12개.
3. 블로그 하나 고르기 → RSS 최근 10개·본문 3개 → AI 패턴·강점·참고 검색어 10 → 수치·등급.
4. **[도톨이 N8] 관심 블로그·새 글만 분석**: 분석한 블로그를 「관심」으로 표시해 두면, 다음 분석 때 **지난번 이후 새 글만** 읽고 AI를 부름(새 글이 없으면 AI 호출 없이 「새 글 없음」). 지난번 분석한 글 번호는 그 블로그의 마지막 `benchmark` 기록에 남김(새 표 없음, 30일 보관 안에서).

### 하지 않는 것
- 작업실 「키워드 보관함 1,000개」: 키워드 프로그램은 생성 데이터 30일 자동 삭제가 원칙이고, 오래 보관할지는 **BC-05(키워드 30일 자동 삭제) 주인님 결정 대기**라 이번엔 즐겨찾기·CSV로 대신.
- 작업실 코드 수정·중단(BLC-15는 별도 결정), 올인원 키워드 파인더(AI 추정이라 가져오지 않음), 도톨이 「실제 검색 화면 상위 5」(확장 작업 필요 — 3차 후보).
