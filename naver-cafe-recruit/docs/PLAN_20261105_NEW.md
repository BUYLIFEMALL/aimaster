## 0. 절대 경계 (어느 방식에서도 바꾸지 않음)
0. **회원 본인 로그인 상태에서 동작**(2026-11-05 주인님 「사용자 본인 계정으로 로그인 한 상태 / 그 상태에서 초대하는거야」): 회원이 본인 네이버 계정으로 **직접 로그인한 그 브라우저 창**에서, 우리 확장이 초대·게시를 한다. 프로그램은 로그인을 대신하지 않고(비밀번호를 다루지 않음), 이미 로그인된 세션에서만 동작한다. → 원본의 새 기기 보안 알림 자동 승인·메일함 읽기가 애초에 필요 없다.
1. **보안 확인 자동 통과 금지**: 원본은 새 기기 로그인 알림을 자동 승인했으나, 이는 보안 확인 우회(최상위 동작 조건)라 **만들지 않는다.** 위 0번대로 회원이 직접 로그인한 상태를 쓰므로 해당 없음.
2. **회원 본인 계정 하나·본인 키**. 비밀번호를 프로그램이 다루지 않음(여러 계정·평문 파일 ❌).
3. **IP 바꾸기·탐지 회피 크롬 ❌**(기본 회원 자기 IP). 
4. **보낼 때 동의 없는 광고 ❌**: 초대·메시지는 그 공개·관계 목적 범위에서, 상한 안에서, 제한 안내가 뜨면 그날 중지.
5. 결과는 회원 본인 소유로 격리(owner-only RLS), 보관 기간 아래 §6.

## 1-A. 모드 A — 카페 활동 회원 모으기 상세 (관리자 지정 예외)
> 전제(§0-0): **회원이 본인 네이버 계정으로 직접 로그인한 브라우저 창**에서, **회원이 운영·가입한 카페**의 **공유 가능한 글** 범위에서만. 우리 확장이 그 로그인 세션으로 읽고, 우리 서버는 네이버에 직접 요청하지 않는다(마케팅 예외 §3-1).

### 흐름 (웹 설정 → 확장이 회원 로그인 세션에서 수집 → 검토 → 실행 → 기록)
1. **카페 고르기**: 확장이 회원의 **가입 카페 목록**을 회원 로그인 화면에서 읽어 옴 → 회원이 운영·가입한 카페만 고름(남의 카페 전수 수집 ❌). 카페 주소→번호 자동 변환.
2. **게시판·범위 고르기**: 게시판 목록 자동 불러오기 → 게시판·페이지 범위·등급 범위 선택. 기본값 미리 채움.
3. **수집**: 확장이 공유 가능한 글 범위에서 작성자 **아이디·닉네임·등급·게시판·글 제목**을 모음. 사람 같은 속도(요청 사이 무작위 간격·한 번에 조금씩·동작 시간대), 「제한」·보안문자 뜨면 **그날 중지**.
4. **거르기**: 탈퇴 회원·매니저 기본 제외, 새싹 등급 제외(선택), 등급 범위, 이미 내 카페 회원·이미 모은 사람 제외.
5. **검토**: 웹 목록에서 회원이 확인·승인(§2 공통).
6. **실행/저장**: 회원이 고른 동작 — ① 명단 저장만(내 소유로 격리), 또는 ② 모드 B와 합쳐 초대 보내기(회원 본인 카페·상한 안·실제 초대 화면).

### 수집 항목·범위
- 아이디 · 닉네임 · 등급 · 게시판 이름 · 글 제목. (이메일·전화는 모으지 않음 — 지침 §4, 무단 이메일 수집 금지.)
- **회원 본인이 운영·가입한 카페의 공유 가능한 글만.** 비공개·가입 안 한 카페·공유 불가 글 ❌.

### 안전·책임
- 모드 A는 기본 꺼짐. 켤 때 **책임 고지 동의**(약관 위반·계정 제재·법적 책임·사용 책임은 회원 본인, 마케팅 예외 §3-6).
- 하루 상한·동작 시간대·사람 같은 속도는 코드 기본값. 결과 불확실하면 다시 안 함.
- 수집 결과는 그 회원만 보는 저장소(owner-only RLS), 공유·판매 ❌, 보관 기간 §6.
- **가져오지 않는 것**: 여러 계정·비밀번호 파일·IP 바꾸기·탐지 회피 크롬·새 기기 보안 알림 자동 승인·메일함 읽기(§0, 회원 직접 로그인이라 불필요).

### 관리자 지정 기록
2026-11-05 주인님 「3가지 방식 모두 필요해 / 본인 계정 로그인 상태에서 초대」로 모드 A를 **관리자 지정 예외**로 승인 → [최상위 규칙 §8](../../docs/TOP_RULE_PERSONAL_ACCOUNT_API.md) 지정 목록에 기록(구현 착수 시).

## 2. 공통 흐름 (웹에서 설정 → 확장이 실행 → 결과 기록)
1. **대상 모으기**(B/C/A) → 웹 목록에 쌓임
2. **회원 검토**: 목록을 보고 「이 목록 승인」 한 번(빼고 싶은 것만 체크 해제)
3. **실행**: 회원 PC 확장이 동작 시간대·하루 상한 안에서 사람처럼
   - B: 초대 보내기(회원 본인 카페, 실제 초대 화면)
   - C: 카페 글 게시(`naver-cafe-poster` 재사용)
   - A: 회원이 고른 동작(초대 또는 명단 저장만)
4. **기록**: 보낸 사람·실패·제한으로 중지를 남김. 같은 사람 중복 안 함. 결과 불확실하면 다시 안 함.
5. **엑셀 내려받기**(2026-11-05 주인님 「수집된 데이터를 엑셀파일로 다운로드 받을 수 있게」): 「모은 대상」·「보낸 기록」 두 시트를 회원 본인 것만 `.xlsx`로. 보관이 30일이라 지워지기 전에 회원 PC에 보관하는 용도. 초안 `src/app/api/export/route.ts`(기준: `kakao_auto_poster`·`booking-reminder`·`stepmail`의 `xlsx` 방식).
