2. 「초대하기」가 보내는 **그 요청의 응답만** 지켜봄(최대 15초, 끝나면 원래대로 되돌림, 네이버 API 직접 호출 없음) → `judgeResponse`가 응답 값으로 판정: `success:true`=sent / `success:false`=failed(사유)·한도 문구면 limited / 오류=failed+멈춤 / 권한 없음=limited(그날 멈춤) / 응답 없음·형식 다름=불확실(재전송 없음)
3. 보안문자 창이 보이면 **누르지 않고 멈춤**, 누른 뒤 뜨면 불확실로 멈춤
4. 「초대하기」를 아이디 창 안에서만 찾음(같은 `btn_invite`가 초대링크·QR 창에도 있음)
- 시험: `npm test` 17개 통과(EX12 응답 분기 10가지, EX13 `new Event` 재발 방지·blur·보안문자 순서·관찰 해제·직접 호출 없음). 성공 화면 문구는 여전히 실물 미확인 — 응답 값으로만 판정.
