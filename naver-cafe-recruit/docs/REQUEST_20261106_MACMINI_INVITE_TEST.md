## 순서 (ego, 작업 공간 하나, 끝나면 닫기)
1. https://naver-cafe-recruit.buylife.xyz/dashboard 에서 「⬇️ 확장 내려받기」 → ZIP을 새 폴더에 풀고 `chrome://extensions` → 개발자 모드 → 「압축해제된 확장 프로그램 로드」.
2. 「⚙️ 모집 방식·설정」: 「👋 아는 사람」 켜짐, 하루 상한 1 → 저장.
3. 「👥 초대할 사람 모으기·승인」: 주인님이 알려 준 아이디 1개 넣기 → 「이 목록 승인」.
4. 네이버에 로그인된 상태로 카페 「바이라이프」(`cafe.naver.com/buylife`) 첫 화면을 열고, 확장 아이콘 → 「이 카페로 초대 시작」. **카페 탭을 앞에 둔 채 기다린다**(약 10초 뒤 초대 화면으로 이동해 입력·「초대하기」).
5. 확장 팝업의 상태 문구와 「📊 보낸 결과」 기록(결과·detail)을 캡처한다.
6. 확장이 「결과를 확인하지 못해 멈췄습니다」로 멈추면: 그 순간 초대 화면에 보이는 문구·알림창을 **그대로 옮겨 적는다**(이게 판정 규칙에 넣을 문구). 다시 보내지 않는다.
7. (관찰만) 초대 화면 「초대링크」 버튼을 누르면 화면에 링크 주소가 보이는지, 「초대링크 복사」만 있는지 기록 — 모드 A-1 초대링크 자동 읽기 판단용. 링크를 다른 곳에 붙여 넣거나 보내지 않는다.

## 추가(2026-11-06 v1.02 배포 뒤) — 모드 A-1 명단 모으기 확인
초대 시험이 끝난 뒤 같은 작업 공간에서 진행한다.
1. 대시보드 「⬇️ 확장 내려받기」로 **v1.02 ZIP**을 받아 기존 폴더에 덮어쓰고 → `chrome://extensions`에서 이 확장 「새로고침」. 팝업 제목 옆이 v1.02인지 확인.
2. 「⚙️ 모집 방식·설정」: 「🔎 A. 카페 활동 회원 명단」 켜기 → 책임 고지 동의 체크 → 저장. 같은 화면 「🔗 내 카페 초대링크」는 비워 둬도 됨(7번에서 링크 모양을 봤으면 붙여 넣고 저장).
3. 카페 「바이라이프」 → 게시판 「☕일상TALK」 **글 목록 화면**을 연다 → 확장 팝업 「이 게시판 작성자 명단 모으기」. 카페 탭을 앞에 둔 채 기다린다(페이지마다 30~45초).
4. **2~3페이지 읽으면 「멈추기」**를 눌러도 된다. 팝업 「명단:」 줄 문구를 캡처.
5. 「📊 보낸 결과·엑셀」의 「🔎 카페 활동 회원 명단」에 닉네임·등급이 나오는지, 「📥 엑셀로 내려받기」 파일에 「활동 회원 명단」 시트가 있는지 확인.
6. 기록할 것: 다음 페이지로 실제로 넘어갔는지(넘어가지 않고 「마지막 페이지까지 읽었습니다」로 끝났다면 그때 페이지 번호 버튼 모양·위치 캡처), 공지·매니저 줄이 명단에 섞였는지, 「글쓴이 칸을 찾지 못했습니다」가 떴다면 그 화면 주소와 캡처.
