# [윈도우 → 맥미니 요청] 카페 회원 모집 첫 실물 초대 1건 (2026-11-06)

작성: 윈도우 `claude-win-blog` [역할: blog] · 주인님 지시(2026-11-06 채팅): 「맥미니에 요청」
대상: 운영 v1.01 https://naver-cafe-recruit.buylife.xyz (비공개 `is_active=false`, 관리자 계정은 접근 가능)

## 목적
초대를 실제로 1번 보내, 네이버가 보여 주는 **성공·실패·제한 문구**를 기록한다. 확장의 결과 판정(`extension/invite.mjs` `classify`)은 아직 추정이라, 이 문구로 확정한다.

## 받을 사람 — 주인님이 맥미니 채팅에서 지정
- **초대할 네이버 아이디 1개는 주인님이 맥미니 세션 채팅으로 직접 알려 주신다.** 받는 사람 「내소식」에 실제 알림이 가므로, 주인님이 지정하지 않은 아이디로는 보내지 않는다.
- 이미 그 카페 회원인 아이디면 「실패」 문구를 보게 되므로, 가능하면 카페 「바이라이프」 회원이 아닌 아이디.

## 순서 (ego, 작업 공간 하나, 끝나면 닫기)
1. https://naver-cafe-recruit.buylife.xyz/dashboard 에서 「⬇️ 확장 내려받기」 → ZIP을 새 폴더에 풀고 `chrome://extensions` → 개발자 모드 → 「압축해제된 확장 프로그램 로드」.
2. 「⚙️ 모집 방식·설정」: 「👋 아는 사람」 켜짐, 하루 상한 1 → 저장.
3. 「👥 초대할 사람 모으기·승인」: 주인님이 알려 준 아이디 1개 넣기 → 「이 목록 승인」.
4. 네이버에 로그인된 상태로 카페 「바이라이프」(`cafe.naver.com/buylife`) 첫 화면을 열고, 확장 아이콘 → 「이 카페로 초대 시작」. **카페 탭을 앞에 둔 채 기다린다**(약 10초 뒤 초대 화면으로 이동해 입력·「초대하기」).
5. 확장 팝업의 상태 문구와 「📊 보낸 결과」 기록(결과·detail)을 캡처한다.
6. 확장이 「결과를 확인하지 못해 멈췄습니다」로 멈추면: 그 순간 초대 화면에 보이는 문구·알림창을 **그대로 옮겨 적는다**(이게 판정 규칙에 넣을 문구). 다시 보내지 않는다.
7. (관찰만) 초대 화면 「초대링크」 버튼을 누르면 화면에 링크 주소가 보이는지, 「초대링크 복사」만 있는지 기록 — 모드 A-1 초대링크 자동 읽기 판단용. 링크를 다른 곳에 붙여 넣거나 보내지 않는다.
