# 모드 A-1 플랜 — 카페 활동 회원 명단 + 초대링크 (2026-11-06, 윈도우 `claude-win-blog` [역할: blog])

주인님 결정(2026-11-06 채팅): **A-1** — 활동 회원의 닉네임·등급·게시판 명단만 모아 엑셀로 받고, 실제 모집은 카페 초대링크·QR을 홍보 글·블로그에 넣어서 한다. 아이디 수집 없음.
근거: [`DOM_CHECK_20261105.md`](DOM_CHECK_20261105.md) — 회원 화면에 작성자 네이버 아이디가 없음(§0-1), 초대링크·QR은 아이디 없이 가능(§0-2).

## 1. 무엇을 만드나
| # | 기능 | 어디서 | 내용 |
|---|---|---|---|
| 1 | 명단 모으기 | 확장 | 회원이 가입한 카페의 **게시판 목록 화면**(`ArticleList.nhn`·`/menus/<번호>`)을 연 채 「이 게시판 작성자 명단 모으기」를 누르면, 화면에 보이는 작성자 칸(`span.nickname` + 등급 `span.blind` 「멤버등급 : …」)만 읽어 보낸다. 다음 페이지는 30~45초 간격, 한 번에 최대 10페이지. 외부 링크 메뉴·메모형·앨범형은 건너뜀. 공지·필독 줄과 매니저(M) 표시는 빼고, 내 닉네임도 뺌 |
| 2 | 명단 저장 | 서버 | 새 표 `ncr_members`(아래 2절). 같은 카페·같은 닉네임은 한 줄(글 수·마지막 본 시각만 갱신). 30일 보관(관리자·시험 계정 열외) |
| 3 | 명단 보기·엑셀 | 웹 | 「📊 보낸 결과·엑셀」에 「🔎 카페 활동 회원 명단」 칸 + 엑셀에 시트 하나 더(카페·게시판·닉네임·등급·글 수·마지막 본 날짜) |
| 4 | 초대링크 | 웹·확장 | 설정에 「내 카페 초대링크」 칸(회원이 카페 초대 화면 「초대링크 복사」로 붙여 넣기). 확장이 그 링크를 자동으로 읽을 수 있는지는 맥미니 실물 확인 뒤 결정(지금은 붙여 넣기) |
| 5 | 홍보 글에 초대링크 | 웹 | 모드 C(카페 홍보 글, `naver-cafe-poster` 재사용) 문안에 초대링크 자리 `{초대링크}`를 넣는다 — **모드 C 연결 작업 때 함께**(이번 범위 아님) |

하지 않는 것: 아이디·회원 번호·블로그 주소 수집, 닉네임 메뉴(쪽지·채팅) 누르기, 글 본문 읽기, 내가 가입하지 않은 카페 읽기, 명단으로 자동 쪽지·채팅.

## 2. DB 변경 (추가만 — 주인님 승인 필요)
- 새 표 `public.ncr_members`: `id`, `user_id`, `cafe_id`(숫자), `cafe_name`, `board_id`, `board_name`, `nickname`(최대 40자), `member_grade`(최대 50자), `post_count`(int), `first_seen_at`, `last_seen_at`, `expires_at`(30일), `unique(user_id, cafe_id, nickname)`. RLS 켬·회원 직접 접근 없음(기존 표와 같음), 열외 트리거 재사용.
- `ncr_settings`에 `invite_link text`(카페 초대링크, `https://cafe.naver.com/` 로 시작하는 주소만) 칸 추가.
- `ncr_dispatch`에 작업 3개 추가: `members_add`(확장, 한 번 최대 50줄·하루 최대 3,000줄, 모드 A가 켜져 있고 책임 고지 동의가 있어야 함) · `members_list`(웹, 최대 2,000줄) · `settings_save`에 `invite_link` 받기. `ncr_cleanup`에 새 표 포함.
- 기존 표·함수 동작은 바꾸지 않는다(추가만).

## 3. 순서
1. 마이그레이션 작성 → 격리 DB 시험(`npm run test:database`에 새 시험 추가) → **주인님 DB 승인** → 운영 적용(ego SQL 편집기, 사전·사후 확인)
2. 서버 라우트: 확장 라우트에 `members_add`, 웹 라우트에 `members_list`·`invite_link`
3. 확장: 게시판 목록 화면 판별·작성자 칸 읽기·페이지 넘기기(사람 간격)·멈춤 조건. 판정 함수는 순수 함수로 시험
4. 웹: 설정 화면 A 설명·초대링크 칸, 결과 화면 명단 칸, 엑셀 시트
5. 시험·tsc·빌드 → 미배포 대기 수정(메뉴 이름 `e0dd9a52c`)과 함께 배포(빌드 1회, 승인) → v1.02
6. 맥미니 실물 확인: 게시판 1개 명단 모으기 → 엑셀
