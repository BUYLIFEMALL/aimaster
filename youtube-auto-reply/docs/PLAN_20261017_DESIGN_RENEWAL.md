## 2. 현재 문제 (분석)
- 밝은 회색 배경 + 파랑·보라 그라데이션 버튼 → 유튜브 느낌 없음, 로그인 화면도 밝은 파랑 격자.
- 사이드바: 휴대폰 ☰ 메뉴 없음(원칙 19 — 위아래로 쌓임), 📖 매뉴얼 메뉴·`/guide` 없음(원칙 ⑦).
- 시작 화면이 없어 `/` → `/videos`로 바로 이동, 현황(검토 대기·게시 수·모니터링 상태)을 한눈에 볼 곳이 없음.
- 댓글 검토 화면: 댓글이 흰 카드로만 나열, 작성자·영상 맥락이 약함.
