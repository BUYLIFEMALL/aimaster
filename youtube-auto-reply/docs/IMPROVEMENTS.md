## 2026-10-17 Codex(Windows) — 인수 검사 추가 발견

- **#9 빈 댓글/이력 UUID 조회 오류(수정·운영 검수 완료 v1.09)**: 두 페이지의 영상 제목 조회에서 빈 목록에 `__none__`를 UUID 필터로 전달합니다. 빈 경우 조회 생략, 채워진 경우 user_id 소유자 조건 추가. 합성 빈/채워진 페이지로 재검수합니다.
- **#10 이용 권한 조회 RLS 의존(수정·운영 검수 완료 v1.09)**: requireProgramAccess/checkProgramAccessApi의 권한 테이블을 회원 클라이언트로 조회합니다. 인증은 실제 회원 세션으로 하고 권한 조사는 관리자 클라이언트를 사용하는 공통 지침 적용. 등급/기간/FREE/핸드폰/정지 정책 자체는 유지.
- **#11 기존 Next14 보안 경고(critical 보완·잔여11건 후속)**: 초기 audit15건(critical1/high12/moderate2), Windows RCE/이미지 최적화 등 공식 Next 보안 공지 대조. 수정판15.5.27·React19 및 같은 범위 전이 의존성 보완 후 재빌드/회귀검사. 개발 도구/Next 내장 PostCSS 등 남는 경고는 최종 JSON으로 기록하며 전체 보안 완료로 확대하지 않음.
- **#12 설정 GET 토큰 갱신 주의**: getYoutubeConnectionStatus는 연결된 회원의 토큰 만료 시 Google 호출/DB 갱신을 할 수 있음. 무료 검수는 채널 미연결 시험 회원임을 확인하고 설정 방문. 운영 채널·토큰은 읽거나 변경하지 않음.
- **#13 DB 조회 오류를 빈 상태로 표시(별도 개선 제안)**: 새 대시보드 및 기존 목록의 Supabase error를 대부분 확인하지 않아 장애 시 빈 목록/0으로 보일 수 있음. 구분된 오류 안내·재시도와 장애 합성 검사를 다음 기능 작업에서 검토.

- **#14 한국 시간 표시(수정·회귀/운영 반영 완료 v1.09)**: formatDateTimeKo가 서버 기본 시간대를 사용해 운영 UTC에서 9시간 차이/날짜 역전 가능. Asia/Seoul 고정·자정/정오 회귀 검사 추가.
- **#15 모바일 긴 댓글·영상 배치(수정·검수 완료 v1.09)**: 합성 긴 URL 댓글을 넣은 실제375px에서 가로 넘침 재현. 댓글/이력/대시보드 줄바꿈, 모바일 영상 버튼 다음 줄·제목 공간, 매뉴얼 예시 버튼 줄바꿈 보완.
- **#16 생성 자료30일 자동삭제 적용 확인(후속)**: owner-only RLS는4개 ytreply 테이블 모두 확인. 전용 Cron/정리 함수에서 ytreply 대상은 확인되지 않아 30일 적용 완료를 주장하지 않음. 다음 CLI는 공통 보관 체계 포함 여부·수집 시각 기준·삭제 영향(영상 FK cascade/재수집 중복)을 설계하고 DB/삭제 승인 범위를 확인. 계정/키/환경설정은 생성 자료 자동삭제에서 구분.
