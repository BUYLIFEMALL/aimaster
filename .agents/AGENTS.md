# 🛡️ Agent Execution Guidelines & Safety Rules

## 1. Autonomous Actions (자율 진행 허용)
다음 작업은 사용자 사전 승인 없이 자율적으로 진행합니다:
- 파일 생성 및 코드 수정
- 패키지 설치 (npm/pip 등)
- 로컬 테스트 및 빌드 실행
- **단일 작업 순차 진행 원칙 (2026-10-16 주인님 지시)**: 사용자가 작업을 보이는 대로 연속해서 올리더라도, 여러 작업을 한 번에 섞어서 진행하지 않고 반드시 하나씩 순서대로 [플랜 → 구현 → 로컬 빌드 및 오류 검증 → Vercel 배포 → 브라우저 실세션 검수 → 인수인계/커밋/푸시] 완료 후 다음 작업으로 착수
- **모든 작업 완료 후 자율적으로 Git Commit, Git Push, 실제 서비스 배포(Vercel 등) 및 검수 진행 후 결과 보고**


## 2. Mandatory Approval Rules (사전 승인 필수 작업)
다음 4가지 작업은 실행하기 전에 **반드시 사용자에게 사전 확인 및 승인**을 받으셔야 합니다:
1. **파일이나 폴더 삭제**
2. **데이터베이스 마이그레이션 또는 데이터 삭제**
3. **환경변수와 API 키 변경**
4. **유료 API 호출**
