# 🛡️ Agent Execution Guidelines & Safety Rules

> **2026-11-18 협업 기준:** 루트 `AI_TEAM_RULES.md`와 `.ai/TRANSPORT.md`의 최신 주인님 지시·Master 배정·작은 수정 묶음 배포 기준을 먼저 적용한다. 이 파일의 과거 자율 진행 안내는 승인된 작업 범위와 장비별 실행 제한 안에서 적용한다.

## 1. Autonomous Actions (자율 진행 허용)
다음 작업은 사용자 사전 승인 없이 자율적으로 진행합니다:
- 파일 생성 및 코드 수정
- 패키지 설치 (npm/pip 등)
- 로컬 테스트 및 빌드 실행
- **단일 작업 순차 진행 원칙 (2026-10-16 주인님 지시)**: 사용자가 작업을 보이는 대로 연속해서 올리더라도, 여러 작업을 한 번에 섞어서 진행하지 않고 반드시 하나씩 순서대로 [플랜 → 구현 → 로컬 빌드 및 오류 검증 → Vercel 배포 → 브라우저 실세션 검수 → 인수인계/커밋/푸시] 완료 후 다음 작업으로 착수
- **작업 완료 후 담당 경로의 커밋·결과 보고를 진행한다. 원격 배포 전에는 주인님의 기존 지시와 배포 의도·승인 범위·빌드 잔여 횟수, Master 실행 순번, 명시 소스 SHA·manifest를 확인한다. 작은 수정은 모아 배포한다. 「반영 안 됨」처럼 운영 반영을 요구하는 지시는 맥락과 함께 Master에게 취합하고, 기능 요청만으로 추가 빌드 횟수나 정책 예외를 확대하지 않는다.**


## 2. Mandatory Approval Rules (사전 승인 필수 작업)
다음 4가지 작업은 실행하기 전에 **반드시 사용자에게 사전 확인 및 승인**을 받으셔야 합니다:
1. **파일이나 폴더 삭제**
2. **데이터베이스 마이그레이션 또는 데이터 삭제**
3. **환경변수와 API 키 변경**
4. **유료 API 호출**
