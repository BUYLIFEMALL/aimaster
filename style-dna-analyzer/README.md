# 이미지 스타일 분석기 (style-dna-analyzer)

> **라이브**: [https://style-dna-analyzer.buylife.xyz](https://style-dna-analyzer.buylife.xyz) (Vercel alias: `style-dna-analyzer.vercel.app`)  
> **현재 버전**: `v1.12` (2026-10-12 최신)  
> **최상위 불변 규칙**: 모든 AI 기능은 회원 본인의 API 키(Gemini / OpenAI / Claude)로만 동작하며, 운영자/타인 키 폴백은 일절 없습니다.

---

## 1. 프로그램 개요

이미지 한 장을 업로드하면 AI가 **카메라 앵글·렌즈·조명 환경·색상 팔레트·스타일 DNA**를 정밀 분석하여, 어떤 이미지 생성 AI(Midjourney, Gemini, ChatGPT/DALL-E 등)에서도 원본의 스타일과 구도를 100% 재현하거나 변형할 수 있는 **마스터 프롬프트(영어·한국어)**를 추출하는 전문 프롬프트 엔지니어링 스튜디오입니다.

---

## 2. 핵심 기능

1. **3단 스튜디오 전문 레이아웃 (클린 화이트 베이스)**
   - **좌측 컬럼**: 이미지 소스 업로드, 카메라 & 렌즈 사양, 조명 환경 분석, 시스템 가이던스(스타일 복제/변형, 변형 강도 슬라이더 0~100%, 첨부 이미지 제공 토글, 타겟 모델 선택, 추가 분석 지침).
   - **중앙 메인**: AI 스마트 스캔 이미지 뷰어(십자선 그리드 & 타겟 앵커 & 왕복 레이저 빔 스캔 애니메이션) + 심층 분석 리포트(상징적 타이틀, 구조 청사진, 스타일 분석, 프로 팁, 마스터 프롬프트 EN/KO 복사).
   - **우측 컬럼**: 미학적 팔레트(써클 도넛, 동적 분할 색상 바, 입체 원형 스와치 목록) + 스타일 핵심 요소 막대 + 스타일 일치율 + 추천 키워드 태그.
   - **하단 추론 인터페이스 바**: 실시간 미세 보정 입력창 및 3단계 결과 테스트 바로가기.

2. **미학적 팔레트 시스템 (실제 색상 100% 렌더링)**
   - **써클 도넛 차트**: 32x32 SVG 규격으로 분석된 색상 세그먼트가 트랙을 오차 없이 꽉 채워 회전/표현. 중앙 라벨 상단 `미학적` / 하단 `컬러` 고정.
   - **동적 분할 색상 바**: 점선 빈 박스 없이 분석된 색상 개수에 맞춰 100% 가득 찬 색상 바로 렌더링(흰색도 입체 음영으로 선명하게 분리).
   - **원형 컬러 스와치**: 하단 목록의 원에 이중 링 테두리와 입체 광택 그림자를 적용해 흰색(#FFFFFF)도 속이 꽉 찬 단단한 원형 알약/컬러 칩으로 시각화.
   - **즉시 색상 추출**: 브라우저 캔버스를 통해 이미지를 올리자마자 0.05초 만에 실제 색상 5개를 추출하여 대기 시간 없이 즉시 렌더링하고, 분석 완료 시 백엔드 sharp 픽셀 분석 결과와 자동 동기화.

3. **듀얼 프롬프트 & 멀티모달 참조**
   - **스타일 복제 vs 스타일 변형**: 0~100% 변형 강도에 따른 안정(0~30%)/조화(31~70%)/파격(71~100%) 단계별 지능형 변형.
   - **[첨부 이미지] 참조 모드**: 프롬프트에 `[첨부 이미지]` 태그를 삽입하여 멀티모달 AI에 원본을 파일로 동시 첨부할 때 스타일 전이(Style Transfer) 극대화.
   - **피사체 자리표시자**: `[INSERT SUBJECT HERE]` / `[주제 입력]` 태그로 피사체만 자유롭게 교체하여 동일 화풍/구도의 시리즈 이미지 무한 양산.

4. **3단계 결과 테스트 (`/test`)**
   - 피사체를 직접 입력하여 Gemini Nano Banana 엔진으로 실제 결과 이미지를 1장 생성.
   - 원본 사진과 생성 결과를 나란히 대조하고, 히스토그램 기반의 **실측 색감 일치율(%)**을 정밀 측정.

## 3. 기술 스택 & 데이터베이스

- **프레임워크**: Next.js 16 (App Router, Turbopack) + TypeScript + Tailwind CSS v4
- **이미지 엔진**: Sharp (서버 픽셀 분석 및 WebP 최적화) + HTML5 Canvas (클라이언트 실시간 색상 추출)
- **데이터베이스**: 공용 Supabase DB (`sda_analyses` 테이블, RLS owner-only 격리) + `style-dna-images` 스토리지 버킷
- **AI 연동**: Gemini REST, OpenAI REST, Anthropic Claude REST (멀티모달 이미지 입력 지원)
