# AI Prompt 자동화 (AI Prompt Automation) — 사용자 매뉴얼 (MANUAL.md)

> **버전**: v1.01  
> **공식 명칭**: AI Prompt 자동화  
> **주요 기능**: 세계 최고 수준의 메타 프롬프트(Meta-Prompt) 엔지니어링 자동화 스튜디오

---

## 1. 개요 (Overview)

**AI Prompt 자동화**는 복잡한 프롬프트 작성 지식 없이도 누구나 최상의 답변을 이끌어낼 수 있는 완성형 실행 프롬프트(Meta-Prompt)를 설계해주는 AI 도구입니다.

- **핵심 철학**: "좋은 질문이 좋은 답변을 만든다." 사용자의 거친 아이디어를 분석하여 ChatGPT, Claude, Gemini 등에 바로 붙여넣어 실행할 수 있는 고도화된 프롬프트를 자동으로 생성합니다.
- **최상위 불변 규칙**: 모든 회원은 본인의 Google Gemini API 키를 직접 등록하여 독립적으로 사용합니다. (타인/운영자 키 공유 금지)

---

## 2. 핵심 기능 안내

### ① ⚡ 빠른 프롬프트 만들기 (Quick Magic)
단 한 줄의 생각만 입력해도 검증된 3대 마법 수식을 즉시 적용하여 즉시 실행형 지시문을 완성합니다.
1. **역질문 유도 (Interview)**: AI가 먼저 질문을 던져 요구사항을 구체화하도록 유도
2. **페르소나 부여 (Auto Persona)**: 주제에 최적화된 최고 권위 전문가 페르소나 자동 매핑
3. **비판적 개선 (Critical Refine)**: 약점과 한계를 날카롭게 분석·보완하는 메타 지침 생성

### ② 5대 프로 엔지니어링 모드
1. **RTSC 마스터**: 역할(Role), 작업(Task), 구조(Structure), 제약(Chain) 4단계 설계를 통해 가장 완벽하고 신뢰도 높은 프롬프트 구축
2. **프레임워크 전문가**: CO-STAR, RTF, RICE, PREP, SWOT, PAS 등 글로벌 비즈니스 기획 프레임워크 자동 매핑
3. **프롬프트 아키텍트**: Zero-Question 원칙에 따라, 단 한 줄의 아이디어만으로 즉시 실행 가능한 고품질 한국어 실행문 완성
4. **Vertex AI XML**: Google 권장 표준 XML 태그(`<OBJECTIVE_AND_PERSONA>`, `<INSTRUCTIONS>` 등)로 모델의 지시 이행률 극대화
5. **논리적 추론 (Chain-of-Thought)**: 단계별 사고 체인과 `<thought>` 내부 독백 기법을 강제하여 수학, 코딩, 복잡한 비즈니스 의사결정에서 환각을 최소화하고 정답률 극대화

### ③ 단계별 실시간 AI 보조 제안
- **AI 구체화 (Goal)**: 거친 아이디어를 구체적인 육하원칙 문장으로 즉시 확장
- **추천 역할 5선 (Role)**: 목적에 부합하는 상위 5개 전문가 페르소나 추천 및 원클릭 주입
- **작업문 자동 작성 (Task)**: 3~4단계 세부 작업 실행 지침 자동 완성
- **출력 포맷 & 제약 조건 추천 (Structure & Chain)**: 가독성 높은 서식과 사고 체인 추천

### ④ 모델 기능 제한 (Capability Constraints)
- 웹 검색 금지 (`WEB_SEARCH`)
- 코드 실행 금지 (`CODE_INTERPRETER`)
- 이미지 생성 금지 (`IMAGE_GEN`)
- 순수 논리 추론 강제 (`NO_AI`)

### ⑤ 피드백 루프 (Iterative Refinement)
생성된 프롬프트에 대해 "어조를 부드럽게 바꿔줘", "영문 번역본을 추가해줘" 등의 피드백을 전달하면 기존 구조를 유지한 채 즉시 재작성합니다.

---

## 3. 시작하기 (Quick Start)

1. 좌측 메뉴의 **`🔑 API키등록·플랫폼연동`**을 클릭하고 본인의 Google Gemini API 키를 등록합니다.
2. **`1. 모드 선택 & 프리셋`**에서 원하는 모드를 고르거나 50종 실전 예제 중 하나를 선택합니다.
3. **`2. 정밀 엔지니어링`**에서 목적을 입력하고 필요 시 AI 보조 버튼을 활용합니다.
4. **`✨ 메타 프롬프트 생성하기`**를 클릭합니다.
5. **`3. 메타 프롬프트 완성`**에서 원클릭 복사 후 ChatGPT, Claude, Gemini 등에 붙여넣어 실행합니다!
