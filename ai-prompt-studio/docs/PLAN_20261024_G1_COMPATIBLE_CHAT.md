# G-1 템플릿 실행 공급자·회원 공용 키

2026-10-24 · Codex(윈도우) `codex-win-20261024-docbot-g1`.

[공통 구현 플랜](../../ai-doc-chatbot/docs/PLAN_20261024_G1_COMPATIBLE_CHAT.md)의 G-1을 이 프로그램에 연결합니다. 공용 기준은 문서 챗봇 폴더, 이 프로그램은 동일 사본을 사용합니다.

- 기존 Gemini 기반 프롬프트 설계·변수 제안·자동 채우기를 보존합니다. 새 공급자 선택은 템플릿 실행 경로부터 적용합니다.
- 기존 Gemini 기본 실행과 회원 소유 템플릿/이용 권한은 유지합니다.
- FREE 회원이 유료 챗봇 권한 없이 같은 공용 키 항목을 등록/조회할 수 있도록 기존 키 설정 창에 공용 등록 부품을 추가합니다. 본인 키만 서버에서 읽고 별도 저장소를 만들지 않습니다.
- 코드/로컬 검사·미배포 상태는 G-1 인수인계에 구분합니다. 버전은 실제 묶음 배포 때 올립니다.
