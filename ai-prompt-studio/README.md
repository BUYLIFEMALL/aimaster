## 1. 프로그램 개요
사용자의 아이디어를 분석하여 ChatGPT, Claude, Gemini 등에 바로 붙여넣어 실행할 수 있는 완성형 메타 프롬프트를 자동 생성하는 프롬프트 엔지니어링 스튜디오입니다.
5대 프롬프트 프레임워크(APE, CARE, TRACE 등)와 AI 3단 스마트 어시스턴트를 통해 비즈니스 및 실무에 최적화된 프롬프트를 원클릭으로 설계할 수 있습니다.
