## 1. 템플릿 선정 이유 및 핵심 가치
- 일반적인 평범한 입력창을 탈피하여, 유튜브 썸네일 제작의 핵심인 **초고대비 네온 배색과 시각적 집중도**를 극대화.
- 퓨어 딥블랙(`#070913`) 바탕에 일렉트릭 사이안(`#38BDF8`)과 바이올렛(`#A78BFA`) 포인트, 그리고 상단 4px 눌림 모션의 **3D 엠보싱 사이안 버튼 (`.btn-3d-cyan`)**을 장착하여 고성능 비주얼 NLE 워크스페이스 완성.

## 2. 디자인 토큰 및 UI 컴포넌트

### 컬러 시스템
- **메인 배경 서피스**: `var(--background)` (`#070913`)
- **카드 서피스**: `#0E162B` + `border: 1px solid rgba(56, 189, 248, 0.22)`
- **시그니처 포인트**: 사이버 일렉트릭 사이안 (`#38BDF8`), 네온 바이올렛 (`#A78BFA`)
- **텍스트 가독성**: 본문 헤드라인 `#F8FAFC`, 서브 텍스트 `#94A3B8`

### 3D 엠보싱 버튼 규격
- `button.primary`, `.btn-3d-cyan`:
  - 배경: `linear-gradient(180deg, #38BDF8 0%, #0284C7 100%)`
  - 입체 그림자: `box-shadow: 0 4px 0 #075985`
  - 인터랙션: 호버 시 `-1.5px` 부유, 활성 클릭 시 `translateY(4px)` 압축 모션.
