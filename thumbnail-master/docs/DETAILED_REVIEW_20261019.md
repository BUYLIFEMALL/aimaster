## 현재 기능과 보존할 장점

주제(또는 대본 파일), 시청 타겟(10대~시니어), 등장 피사체를 정하면 AI가 직관형 A안과 호기심형 B안의 메인·서브 문구와 이미지 구성을 제안합니다. / 확정하면 문구가 들어간 16:9 썸네일 2종을 동시에 만들고, 테두리(단색·네온·손그림)·채널명 브랜딩·글자 없는 배경·1K·2K 해상도를 고를 수 있습니다. / 지시문으로 수정을 요청하거나 이전 버전으로 되돌리고, 프로젝트를 최대 30개 저장해 JPG로 내려받습니다.

**보존할 장점:** A/B 문구·이미지 썸네일 생성

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
