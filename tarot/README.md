# AIMaster 타로점 (AI Tarot Reading) — v1.20

12종 정통 스프레드와 78장 아르카나 덱을 기반으로 AI가 실시간으로 고유 일러스트를 그리고 심층 타로 해석을 제공하는 AIMaster 서브프로젝트입니다.

- **공식 서비스 URL**: https://tarot-reading.buylife.xyz (대체: `https://tarot-reading.buylife.xyz`)
- **비주얼 가이드북 URL**: https://tarot-reading.buylife.xyz/guide
- **적용 템플릿**: **크리에이티브 아틀리에 스타일 — 신비로운 미드나잇 퍼플 랩 에디션 (Creative Atelier Style — Mystic Midnight Purple Lab Edition)**

---

## 1. 주요 특징

- **12종 정통 스프레드**: 원카드, 3카드 시간흐름, 3카드 궁합, 5카드 심층, 켈틱크로스 10카드, 커리어 6카드 등 상황별 맞춤 스프레드.
- **78장 정통 아르카나 & 12대 화풍 연성**: 메이저 22장 + 마이너 56장 덱을 바탕으로 Google Gemini가 12대 화풍(르네상스 유화, 사이버펑크, 다크 고딕 등)의 세상에 하나뿐인 일러스트 실시간 생성.
- **맞춤형 AI 종합 해석**: LLM 엔진이 질문자의 고민과 뽑힌 카드 간의 유기적 상관관계를 심층 분석하여 보관함에 영구 저장.
- **100% BYOK 보안 원칙**: 개인의 사적인 타로 리딩 내역과 API 키는 회원 본인 소유로 격리 보관.
