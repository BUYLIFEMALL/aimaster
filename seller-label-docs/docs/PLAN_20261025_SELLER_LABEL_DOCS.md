## 1. 무엇을 만드나
쇼핑몰 판매자가 출고·입점·홍보 때 반복하는 서류·라벨 작업 5가지를 **브라우저 안에서만** 처리하는 도구함입니다. 파일을 서버로 보내지 않으므로 운영자 비용이 없고(기본 프로그램, 프리미엄 아님), AI·API 키도 필요 없습니다.

| 순서 | 도구 | 하는 일 | 쓰는 라이브러리(공개 라이선스) |
|---|---|---|---|
| 1 | 🏷 라벨 인쇄 | A4 라벨지 규격 선택(자주 쓰는 규격 + 직접 입력) · 칸마다 글자·바코드·QR · **엑셀로 칸마다 다른 내용 채우기** · 시작 칸 지정(쓰다 남은 라벨지) · 인쇄 위치 보정 · 식품 한글표시사항 라벨 틀 | `bwip-js`(MIT), SheetJS(`file-merge`와 같은 배포본) |
| 2 | 🔳 QR 만들기 | 주소·글 → QR, 색·점 모양·모서리, 오류 정정 H, **배경 대비 검사**, PNG·SVG 저장 | `qr-code-styling`(MIT) |
| 3 | 🗂 파일명 일괄 변경 | 사진 여러 장 → 「공통 이름 + 순번(시작 번호·자릿수)」 미리보기·순서 바꾸기 → ZIP 저장 | `jszip`(10여 곳에서 이미 사용) |
| 4 | 📄 PDF 정리 | 사진 → PDF, PDF 합치기·나누기·페이지 추출·순서 바꾸기(페이지 미리보기) | `pdf-lib`(MIT), `pdfjs-dist`(`markdown-studio`·`document-translator`와 같은 버전) |
| 5 | ✍ 문서 서명 | 손글씨 서명판·서명 이미지·이름 글자 → 사진·PDF 원하는 위치에, 모든 페이지 같은 위치 복사, PDF·PNG 저장. **「법적 효력이 있는 전자서명이 아닙니다」 화면 고정 표시** | `pdf-lib` |

### 원본과 다르게 하는 점(D2·D4)
- 원본 코드·라벨 규격표·문구는 옮기지 않습니다. 라벨 규격은 **라벨지 제조사 공식 규격표**를 직접 확인해 새로 적고, 표에 「확인 날짜·출처」와 「실제 라벨지로 시험 인쇄 후 위치 보정하세요」 안내를 붙입니다. 규격표에 없는 라벨지는 직접 입력(가로·세로 칸 수, 칸 크기, 위·왼쪽 여백, 칸 사이 간격 mm)으로 씁니다.
- 식품 한글표시사항은 식약처 「식품등의 표시기준」 항목 이름으로 빈 틀만 제공하고, 내용의 정확성은 판매자 책임이라는 안내를 붙입니다(예시 문구를 지어내지 않음).
- 바코드 번호(EAN-13 등)는 **회원이 GS1에서 발급받은 번호**를 넣는 것이며, 검증 숫자(체크 디지트) 오류만 알려 줍니다.
- 원본의 외부 쇼핑 추천 링크는 넣지 않습니다.

### 기존 프로그램에서 가져오는 것(프로그램 비교표 기준)
| 가져올 것 | 출처 | 비고 |

| 앱 뼈대·권한 판정·로그인·좌측 메뉴·모바일 ☰ | `image-convert-studio`(Next 16, 브라우저 전용 도구) | 권한 순서 정지→관리자→핸드폰→FREE→구독→등급+기간 그대로 |
| 엑셀 읽기 방식 | `file-merge` SheetJS 배포본 | 같은 버전 |
| ZIP 저장 | `jszip` 기존 사용 방식 | |
| PDF 미리보기 | `markdown-studio`의 `pdfjs-dist` 작업자 설정 | |
| 단점 보강 | 원본은 데스크톱 크롬·엣지 전용, 도구가 흩어져 있음 → 한 도구함 + 모바일에서도 QR·파일명·PDF는 사용 가능(라벨 인쇄는 PC 권장 안내) | |

## 2. 화면 구성(좌측 메뉴)
```
🏠 도구함 홈       — 도구 5개 카드 + 「어떤 작업이세요?」 안내
🏷 라벨 인쇄
🔳 QR 만들기
🗂 파일명 일괄 변경
📄 PDF 정리
✍ 문서 서명
📖 연동 & 사용 매뉴얼 — Step 1~4 카드, 라벨 위치 보정법, FAQ
```
- AI·외부 계정이 없으므로 「API키등록·플랫폼연동」 메뉴는 두지 않습니다.
- 라벨 설정·자주 쓰는 라벨 틀은 **이 브라우저에만 저장**(localStorage). 서버 DB 표는 만들지 않습니다(필요해지면 2차로 승인 후).
- 디자인: 기존 템플릿 「포커스 스튜디오 스타일」(image-convert-studio 계열) 재사용, 흰색 바탕. 디자인 리뉴얼은 디자인 담당 몫으로 남깁니다.

## 3. 구현 순서(작업 단위마다 로컬 커밋)
1. 뼈대: 폴더·권한·로그인·메뉴·버전 `v1.01`·`/guide` 빈 틀 → `tsc`
2. 라벨: 규격표(공식 규격 확인) + 칸 배치 계산(mm → 인쇄) + 엑셀 채우기 + 바코드·QR 칸 + 시작 칸·위치 보정 + 식품 표시 틀 + 인쇄 전용 CSS
3. QR: 생성·꾸미기·대비 검사·저장
4. 파일명: 미리보기·순서·ZIP
5. PDF: 사진→PDF·합치기·나누기·추출·순서
6. 서명: 서명판·이미지 배경 투명화(흰 바탕만)·배치·전체 페이지 복사·저장
7. 매뉴얼·등록 준비: `/guide` 완성, 설명 문구(표준), 썸네일
