# 개선 제안 — seller-label-docs

## 1. 로직·기능
- (중) 라벨 규격 기본값은 가운데 정렬 추정값이다. 주인님 실물 라벨지 시험 인쇄 결과나 제조사 규격표 PDF 값으로 자주 쓰는 규격(21칸·14칸·65칸)의 여백을 보정한다.
- (중) 1차원 바코드는 칸 높이 비율로 가로가 정해져, 작은 칸(65칸)에서는 스캐너가 못 읽을 만큼 작아질 수 있다 → 칸 크기 대비 바코드 실제 가로 mm를 계산해 30mm 미만이면 경고.
- (하) HEIC 사진(아이폰) 미지원 — 브라우저 변환 라이브러리 검토.
- (하) PDF 저장 시 원본 북마크·양식 칸은 남지 않는다(pdf-lib 페이지 복사 한계) — 매뉴얼에 안내.

## 2. UI/UX
- 라벨 미리보기 확대·축소, 칸 하나 크게 보기.
- 파일명·PDF 카드 끌어서 순서 바꾸기(지금은 화살표 버튼).
- 자주 쓰는 라벨 틀 이름 붙여 여러 개 저장.

## 3. 다른 프로그램과 연계
- 상품소싱·E7 주문 리포트 표 → 라벨 표 바로 넘기기(E9 흐름 띠).
- 바나나 캔버스·상세페이지 결과 이미지 → 파일명 일괄 변경으로 넘기기.

## 타 프로그램 탐색 메모
- `image-convert-studio`의 `.env.local`에는 Vercel 토큰만 있어 복사해도 Supabase 값이 없다 — 새 프로젝트 환경변수는 루트 `.env.local` 기준 등록 스크립트로 넣는다.
