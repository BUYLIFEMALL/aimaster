# 셀러 라벨 작은 기능 3가지 — 개발 플랜 (2026-11-14)

작성: [역할: ecommerce-image] Claude Code(윈도우) `claude-win-sdp` · 주인님 지시(2026-11-14) 「순서대로 진행해」 — 보류 목록 두 번째(첫 번째 E2-1은 상품소싱기에 완료·미배포 대기).

## 1. 범위
| 기능 | 지금 | 바꾸는 것 | 파일 |
|---|---|---|---|
| 바코드 30mm 경고 | 「글자 오른쪽」일 때만 고정 문구 경고 | **실제 찍히는 가로(mm)를 계산**해 1차원 바코드(EAN-13·Code128)가 30mm보다 좁으면 「약 N mm」와 해결 방법을 보여 줌(칸이 좁은 라벨지·여백·높이 때문에 줄어드는 경우까지) | `src/lib/label/barcode.ts` `barcodeWidthMm`·`svgAspect`, `LabelTool.tsx` |
| 라벨 틀 이름 붙여 저장 | 마지막 설정 하나만 자동 저장 | 「💾 내 라벨 틀」: 이름 붙여 저장(라벨지 규격·칸 내용·위치 보정), 불러오기·삭제, 같은 이름은 덮어씀, 최대 20개, **이 PC 브라우저에만**(서버·DB 저장 없음) | `src/lib/label/savedTemplates.ts`, `LabelTool.tsx` |
| HEIC 사진 | 열리지 않으면 「JPG로 바꿔 넣어 주세요」 | 파일 고르기 창에 HEIC도 보이게, 브라우저가 스스로 열 수 있으면(사파리 등) 그대로 변환, 못 열면 아이폰 설정(카메라 → 포맷 → 「높은 호환성」) 안내 | `src/lib/browser/imageInput.ts`, `PdfTool.tsx` 안내 |

## 2. 하지 않는 것·결정 항목
- **HEIC 변환 라이브러리(`heic2any`·`heic-to`) 도입은 하지 않음** — 안에 든 libheif가 LGPL-3.0이라 웹 번들 배포가 라이선스 회색 지대, 크기도 1MB 이상. 크롬에서도 HEIC를 열어야 하면 주인님 결정 뒤(역할 파일 「주인님께 여쭐 것」).
- 틀 저장을 계정(DB)에 두는 것 — 지금 설정도 브라우저 저장이라 맞춤. 여러 PC에서 써야 하면 다음 결정.

## 3. 검수·비용·배포
- 순수 함수 시험(`tests/tools.test.mjs`에 추가) · `tsc` · 로컬 `build`. 화면은 다음 배포 뒤 ego 확인.
- 비용 없음. **미배포 대기**(작은 수정) — 기존 대기 「흐름 띠 마켓 등록」(`48b67dd5c`)과 함께 다음 라벨 배포 때(버전 +0.01).
