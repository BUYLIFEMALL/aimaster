# AI 리버스 프롬프트 자동화 (reverse-prompt) 개선 과제 및 제안서

> **작성 일자**: 2026-10-19  
> **작성자**: Antigravity CLI (agy, 윈도우)  
> **기반 버전**: `v1.10`

---

## 1. 프로그램 로직 및 기능 개선
1. **원본 미디어 vs 역분석 프롬프트 비교 뷰어 (Side-by-Side Dual View)**:
   - 현재는 결과 화면 상단에 텍스트 프롬프트 위주로 배치되어 원본 미디어와의 대조가 어려움.
   - 좌측에 원본 미디어 고정 프리뷰, 우측에 역분석 결과 및 프롬프트 편집창을 배치하는 2열 분할 레이아웃 도입 추천.
2. **단어별 가중치(Weight) 슬라이더 조절 UI**:
   - Midjourney의 `word::2` 문법이나 Stable Diffusion의 `(keyword:1.2)` 문법을 클릭 몇 번으로 쉽게 부여할 수 있는 키워드 칩 가중치 컨트롤러 지원.
3. **분석 모델 세분화 및 다중 체인 옵션**:
   - Gemini 2.5 Flash 외에 Claude 3.5 Sonnet Vision 또는 GPT-4o 멀티모달 분석을 회원 본인 키로 선택할 수 있는 멀티 LLM 엔진 옵션 확장.

---

## 2. 사용자 인터페이스(UI/UX) 편의성 개선
1. **타겟 도구 원클릭 전환 및 즉시 재변환**:
   - 이미 분석된 결과를 두고 타겟 도구(Midjourney ➔ Flux ➔ DALL-E)를 상단 탭에서 변경할 때마다 추가 API 호출 없이 로컬 정규화 규칙을 통해 프롬프트 문법을 즉시 재포맷하는 탭 UI 제공.
2. **원클릭 프롬프트 테스트 클립보드 템플릿**:
   - 디스코드(Discord) 봇에 바로 붙여넣기 위한 `/imagine prompt: ...` 복사 전용 버튼과 웹 콘솔용 순수 텍스트 복사 버튼 분리 제공.
3. **히스토리 검색 및 태그 필터**:
   - 내 분석 기록(`/history`)에서 미디어 종류(이미지/영상/음악) 및 타겟 도구별로 빠르게 필터링할 수 있는 상단 칩 필터 바 추가.

## 3. 현재 만들어져 있는 다른 자동화 프로그램과의 연계 가능한 기능
1. **`thumbnail-master` (76번 AI 썸네일 마스터) 연계**:
   - 유튜브 인기 썸네일을 캡처해 리버스 프롬프트로 업로드하면, 조명·배치·폰트 스타일 프롬프트를 추출하여 원클릭으로 썸네일 마스터로 전송, 내 영상 맞춤 썸네일로 즉시 재생성.
2. **`banana-canvas` (80번 AI 바나나 캔버스) 연계**:
   - 마음에 드는 일러스트나 캐릭터 원화의 프롬프트를 역추출한 뒤 바나나 캔버스 레이어로 자동 전송하여 브러시 편집 및 재생성 워크플로우 완성.
3. **`fashion-style` (82번 AI 패션스타일) 연계**:
   - 명품 룩북이나 런웨이 사진에서 모델 착장, 패브릭 재질, 조명 톤을 리버스 프롬프트로 분석한 후 패션 스타일 생성기의 의상 프롬프트로 직접 연동.
