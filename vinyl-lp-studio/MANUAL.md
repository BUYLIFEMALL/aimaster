## 1. 프로그램 개요

**AI 바이닐 스튜디오 (Vinyl LP/CD Studio)**는 음악 앨범, 오디오 콘텐츠, SNS 홍보, 음악 유튜브/릴스 채널에 즉시 활용할 수 있는 **LP 레코드판(Vinyl) 및 CD 컴팩트 디스크의 사실적인 회전 3D 목업 애니메이션**을 원클릭으로 제작하는 전문 크리에이티브 도구입니다.

### 핵심 특장점
1. **CD & LP 2대 미디어 포맷**: 클래식 블랙 LP 음반의 그루브 홈과 하이라이트 광택, CD의 프리즘 무지개빛 홀로그램 반사광을 정밀하게 시뮬레이션
2. **AI 스타일 자동 추천**: 앨범 제목과 아티스트 이름만 입력해도 감각적인 커버 아트 프롬프트를 자동 생성
3. **Google Gemini 고화질 아트워크**: 중앙 홀 컷아웃을 고려한 맞춤형 정방형 아트워크 생성
4. **나만의 커스텀 이미지 변환**: 본인이 소장한 이미지나 앨범 재킷을 업로드하여 LP/CD로 즉시 변환
5. **브라우저 네이티브 고화질 렌더링**: 서버 업로드 없이 사용자 PC에서 WebCodecs 기술로 부드러운 60fps MP4 비디오 또는 무한 루프 GIF를 몇 초 만에 직접 인코딩 및 다운로드

## 3. 필수 준비 사항 (Google Gemini API 키 연동)

AIMaster의 **최상위 불변 규칙(본인 계정·본인 API 키 연동 원칙)**에 따라, 회원은 본인의 Google Gemini API 키를 직접 등록하여 사용합니다.

### API 키 발급 및 등록 절차
1. [Google AI Studio (aistudio.google.com)](https://aistudio.google.com/)에 접속하여 구글 계정으로 로그인합니다.
2. **`Get API key`** 메뉴에서 `Create API key` 버튼을 클릭하여 새 키를 무료로 발급받습니다.
3. 스튜디오 좌측 사이드바의 **`🔑 API키등록·플랫폼연동`** 메뉴(또는 상단 툴바의 톱니바퀴 아이콘)를 클릭합니다.
4. 발급받은 키를 입력하고 **`API 키 저장 및 연동`**을 누르면 안전하게 등록 완료됩니다.

## 4. 단계별 사용 가이드 (Step 1 ~ 4)

### Step 1. 미디어 포맷 & 메타데이터 입력
* **포맷 선택**:
  * `바이닐 LP 레코드`: 아날로그 감성의 클래식 블랙 LP 디스크 (그루브 홈 + 센터 라벨)
  * `CD (컴팩트 디스크)`: 모던 감성의 광택 디스크 (홀로그램 반사광 + 투명 중앙 허브링)
* **앨범 제목 (Album Title)**: 곡명 또는 앨범 명칭 입력 (예: `Midnight Highway`)
* **아티스트 이름 (Artist)**: 가수, 프로듀서 또는 밴드명 입력 (예: `Yuki & The Breeze`)
* **세부 정보 (연도 / 장르)**: 발매 연도 또는 장르 입력 (예: `1982 - Tokyo City Pop`)

### Step 2. 비주얼 아트워크 기획
* **스타일 프롬프트**: 원하는 앨범 커버의 화풍, 색감, 조명을 입력합니다.
* **`✨ AI 스타일 추천` 버튼**: 입력된 제목과 아티스트, 장르를 AI가 분석하여 가장 어울리는 비주얼 프롬프트를 1~2문장으로 자동 완성해 줍니다.
* **인기 장르 프리셋 칩**: 시티팝, 로파이, 사이버펑크, 미드나잇 재즈, 사이키델릭 락, K-POP 퓨처 베이스 중 원하는 칩을 누르면 제목, 아티스트, 프롬프트가 한 번에 자동 세팅됩니다.
* **나만의 이미지 파일 업로드**: 이미 가지고 있는 앨범 커버 이미지(PNG/JPG)를 직접 업로드할 수 있습니다.

### Step 3. 턴테이블 & 재생 속도 (RPM) 설정
* **슬라이더 조절**: 10 RPM부터 100 RPM까지 회전 속도를 부드럽게 조절할 수 있습니다.
* **퀵 프리셋**:
  * `33 RPM`: 정규 LP 앨범의 표준 감성 회전 속도
  * `45 RPM`: 싱글 바이닐 음반의 경쾌한 회전 속도 (기본 권장)
  * `78 RPM`: 다이나믹하고 빠른 고속 회전 속도

### Step 4. 디자인 생성 & 영상 내보내기
* **`디자인 생성하기` 버튼 클릭**: Gemini AI가 중앙 홀을 고려한 정방형 앨범 아트를 생성하고, 캔버스 엔진이 LP 그루브/CD 홀로그램으로 즉시 합성합니다.
* **영상 내보내기**:
  * **`🎬 60fps MP4 내보내기`**: 720p 60fps의 부드러운 고화질 영상으로 인코딩 (유튜브 쇼츠, 릴스 배경에 최적)
  * **`🖼️ 루프 GIF 내보내기`**: 끊김 없이 무한 루프로 회전하는 투명 GIF 생성 (웹페이지, 커뮤니티, 블로그용)
* 렌더링이 완료되면 우측 화면에 다운로드 버튼이 활성화되어 원클릭으로 저장할 수 있습니다.
