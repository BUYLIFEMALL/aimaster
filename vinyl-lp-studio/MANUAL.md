## 1. 프로그램 개요

**LP 턴테이블 자동화 (LP Turntable Automation)**는 음악 앨범, 오디오 콘텐츠, 유튜브 음악 플레이리스트, 인스타그램 릴스/쇼츠, 틱톡 등에 즉시 활용할 수 있는 **LP 레코드판 및 CD 디스크의 사실적인 회전 3D 목업 애니메이션**을 원클릭으로 제작해 주는 전문 비주얼 스튜디오 솔루션입니다.

### 🌟 핵심 특장점 5가지
1. **LP 레코드 & CD 2대 미디어 포맷 정밀 재현**:
   - 아날로그 LP 음반 특유의 딥 블랙 바디, 미세 동심원 음각 소리골(Groove), 대각선 코닉 반사광
   - 모던 광학 디스크 CD의 풀페이지 인쇄, 투명 플라스틱 허브링, 각도에 따라 변하는 무지개빛 홀로그램 반사광
2. **Google Gemini AI 맞춤형 앨범 아트워크 생성**:
   - 앨범 제목과 아티스트 이름만 입력해도 중앙 스핀들 홀 구멍을 회피하는 정방형(1:1) 맞춤형 아트워크를 AI가 자동 디자인
3. **AI 스타일 자동 추천 & 6대 인기 장르 프리셋**:
   - 곡명과 가수에 어울리는 비주얼 프롬프트 1~2문장 자동 제안 (시티팝, 로파이, 사이버펑크, 재즈 등)
4. **소장 이미지 원클릭 변환**:
   - 사용자가 소장한 앨범 커버, 캐릭터 일러스트, 프로필 사진(PNG/JPG)을 업로드하면 즉시 회전 디스크로 변환
5. **브라우저 100% 네이티브 초고속 인코딩 (서버 비용 0원, 무제한 다운로드)**:
   - 서버 대기 시간 없이 WebCodecs 기술로 **720p 60fps 고화질 MP4 비디오** 및 **무한 루프 GIF**를 사용자 브라우저에서 몇 초 만에 무료 인코딩

## 2. LP 레코드 vs CD 포맷 기능 비교

사용자는 작업 1단계에서 음반 형태를 자유롭게 선택할 수 있으며, 두 포맷은 아래와 같은 시각적·기능적 차이가 있습니다:

| 비교 항목 | 💽 LP 레코드 | 💿 CD (컴팩트 디스크) |
| :--- | :--- | :--- |
| **디자인 인쇄 영역** | **중앙 원형 라벨 영역만 (전체의 약 38%)**<br>바깥쪽은 블랙 레코드판으로 감싸짐 | **디스크 전체 면적 (전체의 98% 풀 블리드)**<br>표면 전체에 앨범 이미지가 인쇄됨 |
| **특수 질감 셰이더** | **미세 동심원 음각 소리골 (Groove)**<br>수십 줄의 아날로그 레코드 홈 정밀 렌더링 | **점선 레이저 서클 & 플라스틱 베젤**<br>디지털 광학 디스크의 정밀 가이드 라인 |
| **빛 반사 효과** | **45° / 225° 대각선 코닉 광택 (`screen`)**<br>LP 레코드 특유의 묵직한 하이라이트 광택 | **무지개빛 프리즘 홀로그램 (`color-dodge`)**<br>각도에 따라 색이 변하는 화려한 무지개 반사광 |
| **중앙 구멍 (홀 규격)** | **초미세 스핀들 핀 홀 (반경 약 1.4%)**<br>턴테이블 바늘 핀이 꽂히는 작은 구멍 | **표준 CD 허브 링 홀 (반경 약 13%)**<br>투명 플라스틱 허브와 메탈 클램프 링 |
| **AI 생성 구도 (`Gemini`)** | **원형 센터 스티커에 어울리는 고대비 구도** | **원반 전면을 채우는 평면 풀페이지 앨범 아트** |
| **추천 활용 장르** | ☕ 로파이, 재즈, 시티팝, 인디음악, 레트로 턴테이블 | ⚡ K-POP, 일렉트로닉, 힙합, 2000년대 Y2K 감성 |

## 4. 필수 준비 사항 (Google Gemini API 키 연동)

AIMaster 최상위 불변 규칙에 따라, 회원은 본인의 구글 API 키를 연동하여 AI 기능을 사용합니다.

1. **[Google AI Studio (aistudio.google.com)](https://aistudio.google.com/)**에 접속하여 구글 계정으로 로그인합니다.
2. 좌측 메뉴 **`Get API key`**에서 `Create API key` 버튼을 클릭하여 새 키를 무료로 발급받습니다.
3. 스튜디오 좌측 사이드바의 **`🔑 API키등록·플랫폼연동`** 메뉴(또는 상단 툴바의 톱니바퀴 아이콘)를 클릭합니다.
4. 발급받은 키를 붙여넣고 **`API 키 저장 및 연동`**을 누르면 안전하게 등록 완료됩니다.

## 5. 단계별 상세 사용 가이드 (Step 1 ~ 4)

### Step 1. 미디어 포맷 & 메타데이터 입력
* **포맷 선택**:
  * `LP 레코드`: 아날로그 감성의 클래식 블랙 음반 (중앙 라벨 + 외곽 소리골)
  * `CD (컴팩트 디스크)`: 모던 감성의 광택 디스크 (전면 인쇄 + 무지개 홀로그램 광택)
* **앨범 제목 (ALBUM TITLE)**: 곡명 또는 앨범 명칭 입력 (예: `Midnight Highway`)
* **아티스트 이름 (ARTIST)**: 가수, 프로듀서, 밴드명 입력 (예: `The Smooth Trio`)
* **세부 정보 (연도 / 장르)**: 발매 연도 또는 장르 입력 (예: `1984 - Tokyo City Pop`)

### Step 2. 비주얼 아트워크 기획
* **스타일 프롬프트 직접 입력**: 원하는 앨범 커버의 화풍, 색감, 조명을 자유롭게 서술합니다.
* **`✨ AI 스타일 추천` 버튼**: 제목과 아티스트 정보를 바탕으로 Gemini AI가 최적의 아트 스타일 프롬프트를 1~2문장으로 자동 완성합니다.
* **인기 장르 프리셋 칩**:
  * 🌃 `시티팝 (City Pop)`: 네온 빛 도시와 레트로 드라이브 감성
  * ☕ `로파이 힙합 (Lo-Fi Chill)`: 비 오는 창가, 따뜻한 커피와 감성 스튜디오
  * 🤖 `신스웨이브 / 사이버펑크`: 네온 퍼플/시안 그리드와 미래지향적 레트로
  * 🎷 `미드나잇 재즈 (Midnight Jazz)`: 빈티지 블루스 클럽과 감미로운 금관 악기
  * 🌈 `사이키델릭 락 (Classic Rock)`: 왜곡된 소용돌이 패턴과 강렬한 빈티지 락
  * ⚡ `K-POP 퓨처 베이스`: 홀로그래픽 파스텔 컬러와 감각적인 그래픽
* **나만의 이미지 파일 업로드**: 이미 가지고 있는 앨범 재킷, 사진(PNG/JPG)을 업로드하면 AI 생성 없이 내 사진으로 즉시 턴테이블 디스크를 제작합니다.

### Step 3. 턴테이블 & 재생 속도 (RPM) 설정
* **슬라이더 조절**: 10 RPM부터 100 RPM까지 회전 속도를 1 RPM 단위로 정밀 조절합니다.
* **원클릭 프리셋 버튼**:
  * `33 RPM`: 정규 LP 앨범의 표준 감성 회전 속도 (차분한 로파이/재즈 감성)
  * `45 RPM`: 싱글 음반의 경쾌한 회전 속도 (기본 권장값)
  * `78 RPM`: 다이나믹하고 스피디한 고속 회전 속도

### Step 4. 디자인 생성 & 영상 내보내기
* **`디자인 생성하기` 버튼 클릭**: Gemini AI가 중앙 홀을 고려한 정방형 앨범 아트를 생성하고, 캔버스 엔진이 LP 소리골/CD 홀로그램으로 즉시 합성합니다.
* **영상 내보내기**:
  * **`🎬 60fps MP4 내보내기`**: 720p 60fps의 부드러운 고화질 영상으로 인코딩 (유튜브 쇼츠, 릴스 배경에 최적)
  * **`🖼️ 루프 GIF 내보내기`**: 끊김 없이 무한 루프로 회전하는 투명 배경 GIF 생성 (웹페이지, 커뮤니티, 블로그용)
* 렌더링이 완료되면 우측 화면에 다운로드 카드가 활성화되어 원클릭으로 저장할 수 있습니다.

## 6. 대표 활용 사례 (크리에이터 실전 가이드)

1. **Suno / Udio AI 음원 크리에이터**:
   - AI로 생성한 노래에 감성적인 턴테이블 회전 영상을 입혀 유튜브나 인스타그램에 정식 음반 발매 느낌으로 업로드
2. **유튜브 Lo-Fi / 감성 플레이리스트 채널**:
   - 1시간~3시간 플레이리스트 영상 제작 시, 화면 중앙에 계속해서 돌아가는 고화질 턴테이블 배경 비디오 소스로 활용
3. **인스타그램 릴스 & 틱톡 숏폼**:
   - 9:16 세로 릴스 템플릿 중앙에 45 RPM으로 회전하는 감성 LP 목업을 배치하여 시선 집중 유도
4. **블로그 / 노션 / 쇼핑몰 상세페이지**:
   - 제품 소개나 아티스트 포트폴리오에 무한 루프 GIF를 삽입하여 생동감 넘치는 시각 효과 제공

## 7. 자주 묻는 질문 (FAQ)

**Q1. 영상 렌더링 시 서버 트래픽이나 과금이 발생하나요?**  
A. 아닙니다! 본 프로그램은 브라우저의 WebCodecs 및 메모리 캔버스 기술을 사용하여 사용자 PC에서 100% 로컬로 인코딩되므로 서버 비용이 들지 않고 완전 무료입니다.

**Q2. 한글 제목도 앨범에 잘 디자인되나요?**  
A. 네, Gemini AI 엔진에 한국어 타이포그래피 안내가 내장되어 있어 국문 앨범 타이틀도 감각적으로 반영됩니다.

**Q3. 내가 가진 사진을 쓰면 AI 호출을 안 하나요?**  
A. 네! '나만의 이미지 파일 업로드' 버튼으로 사진을 등록하면 Gemini API를 호출하지 않고 브라우저에서 즉시 LP/CD 텍스처로 변환되어 API 할당량을 아낄 수 있습니다.
