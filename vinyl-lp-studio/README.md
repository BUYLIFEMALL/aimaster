## 0. 절대 불변 최상위 규칙 (모든 에이전트 필독)

1. **★ 회원 본인 Gemini API 키 연동 원칙**:
   - 운영자(`buylifemall`) 또는 타인의 공용 키로 폴백하지 않습니다.
   - 키가 없으면 기능을 임의 우회하지 않고 `ApiKeyModal`을 열어 등록을 안내합니다. (`user_api_keys.provider = 'gemini'`)
2. **FREE 배지 가입자 전체 무료 이용 원칙**:
   - `programs.badges`에 `'free'`가 등록되어 있으므로 가입 회원은 누구나 무료 이용 가능합니다. (비로그인은 자체 `/login` 리다이렉트)
3. **프로그램 내 전체 페이지 단일 배경색 및 일관된 테마 준수 원칙 (`#0c0d12`)**:
   - 본문, 컨트롤 패널, 사이드바, 가이드, 로그인 화면 등 모든 페이지는 딥 옵시디언 나이트 `#0c0d12` 배경을 유지합니다.
4. **단일 작업 순차 진행 및 완결 원칙**:
   - 플랜 제시 → 구현 → 빌드 검증(`npm run build`) → Vercel 배포(`vercel --prod --yes`) → Edge 브라우저 실세션 검수 → 버전 동기화(`lib/version.ts` + `package.json` + DB) → 인수인계 문서 갱신 및 Git 푸시.

## 1. 프로그램 사용목적 및 대상 (Target & Purpose)

- **타깃 사용자 페르소나**:
  1. **음악 및 사운드 크리에이터 / 인디 뮤지션**: 자신의 자작곡, Lo-Fi 비트, BGM 음원을 유튜브, 인스타그램 릴스, 틱톡 등에 감성적인 영상으로 배포하고자 하는 창작자.
  2. **숏폼 / 릴스 / 유튜브 채널 운영자**: 음악 플레이리스트, 공부할 때 듣는 음악, 카페 감성 BGM 영상의 시각적 몰입감을 높여 조회수와 체류 시간을 극대화하려는 유튜버.
  3. **바이닐 / 레트로 애호가 및 일반 회원**: 자신이 좋아하는 앨범 커버를 턴테이블 위에서 회전하는 실제 아날로그 바이닐 LP 및 CD 형태로 시뮬레이션하고 간직하고 싶은 사용자.
- **해결하는 핵심 문제 및 가치 제안 (Value Proposition)**:
  - **3D 렌더링 툴(Blender, Cinema 4D) 없이 1초 만에 영상화**: 복잡한 3D 그래픽 기술이나 고가의 GPU 소프트웨어 없이, 브라우저에서 이미지 한 장으로 고화질 회전 비디오를 즉시 완성합니다.
  - **서버 비용 0원의 경제성**: WebCodecs 기술을 활용해 사용자의 브라우저에서 100% 비디오를 렌더링하므로 서버 인프라 유지 비용이 들지 않습니다.
  - **음악과 영상의 즉시 결합**: 음원 파일을 업로드하는 즉시 회전 영상과 오디오가 완벽 동기화된 완성형 MP4를 출력합니다.

## 2. 개발 구현에 사용된 도구 / 개발기법 / 플러그인 / 스킬 (Tech Stack & Skills)

- **핵심 프레임워크 및 언어**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4.
- **그래픽 텍스처 엔진**:
  - HTML5 2D Canvas API 기반 맞춤형 마스킹 및 디스크 텍스처 엔진 (`canvas-texture.ts`).
  - LP 원형 홈(Grooves) 수학적 음각 렌더링 및 45°/225° 코닉 그라디언트 하이라이트 (`screen` 블렌딩).
  - CD 표면 무지개빛 코닉 홀로그램 광택 반사 알고리즘 (`color-dodge` 블렌딩).
- **클라이언트 비디오 / 애니메이션 인코딩 엔진**:
  - **WebCodecs API (`VideoEncoder`)**: 브라우저 하드웨어 가속을 활용한 60fps 초고속 무음/유음 MP4 비디오 인코딩.
  - **`mp4-muxer`**: 브라우저 내부에서 H.264 비디오 트랙과 AAC 48kHz 스테레오 오디오 트랙을 단일 MP4 컨테이너로 Muxing.
  - **Web Audio API (`AudioContext`)**: 업로드된 오디오 파일을 브라우저에서 실시간 디코딩 및 샘플레이트 리샘플링.
  - **`gifenc`**: 360×360 30fps 무한 루프 최적화 팔레트 GIF 렌더링.
- **AI 모델 연동 및 프롬프트 엔지니어링**:
  - **Google Gemini 2.5 / Flash API**: 아티스트/곡명 기반 바이닐 아트워크 프롬프트 자동 추천 (`suggest-style`) 및 1:1 정방형 앨범 커버 생성 (`generate-artwork`).
  - 회원 개인 Gemini API 키 연동 암호화 세션 관리 (`user-key/route.ts`).
- **에이전트 스킬 및 도구**:
  - Microsoft Edge 브라우저 전용 실세션 자동 검수 (데스크톱 및 375px 모바일 반응형 캡처 보존).
  - Vercel CLI 프로덕션 배포 파이프라인.

## 4. 프로그램 장점 및 단점 (Pros & Cons)

### 장점 (Strengths & Pros)
1. **서버 인프라 렌더링 비용 제로 (0원 운영)**: 모든 연산과 비디오 인코딩이 클라이언트 브라우저에서 수행되어 GPU 서버 비용이 발생하지 않습니다.
2. **압도적인 레트로 감성 비주얼**: 다크 옵시디언 나이트(`#0c0d12`)와 바이닐 앰버/골드 조화의 크리에이티브 아틀리에 템플릿 적용.
3. **회원 본인 API 키 기반의 완벽한 보안/비용 격리**: 개인 키로 직접 생성하여 운영자 및 타 회원 키로의 비용 누출 차단.
4. **오디오 결합 지원**: 사용자의 음원 파일을 즉시 동기화 결합하여 숏폼/쇼츠용 완제품 비디오 즉시 출력.
5. **친절한 비주얼 가이드북 제공**: 5단계 파이프라인과 4대 팁을 비로그인 상태에서도 쉽게 열람 가능.

### 단점 및 한계 (Weaknesses & Cons)
1. **오디오 주파수 파형(Waveform) 시각 효과 미탑재**: 음악에 맞춰 튀는 실시간 이퀄라이저 파형 애니메이션이 아직 미구현됨 (`LOGIC-01`).
2. **3D 앨범 자켓(슬리브) 거치 뷰 미지원**: 디스크 단독 회전 뷰 중심이며 앨범 자켓과의 듀얼 3D 거치 뷰가 없음 (`LOGIC-02`).
3. **로열티 프리 샘플 음원 기본 내장 부재**: 사용자가 테스트할 수 있는 무료 BGM 음원 샘플 미제공 (`UI-02`).
4. **구형 브라우저 가속 편차**: 최신 크로미움 브라우저 외 구형 브라우저에서는 WebCodecs 지원이 제한적일 수 있음.

   - 회전하는 디스크 옆에 비스듬히 거치된 종이 질감의 정방형 앨범 자켓을 함께 렌더링하여 LP 앨범의 실물 느낌을 극대화.
3. **[보통] `UI-01`: 턴테이블 톤암(Tone-arm) 재생/일시정지 클릭 인터랙티브 애니메이션**
   - 재생 시 톤암이 부드럽게 디스크 위로 올라가고, 일시정지 시 바깥 거치대로 복귀하는 아날로그 감성 인터랙션.
4. **[보통] `UI-02`: 로열티 프리 감성 Lo-Fi / Jazz 샘플 BGM 3종 프리셋 탑재**
   - 음원 파일이 없는 사용자도 즉시 음악 결합 비디오를 시연해 볼 수 있도록 샘플 음원 제공.

## 7. 기존 타 프로그램과의 연계 / 기능 병합 제안 및 다양한 혁신 아이디어 (Integration & Innovative Ideas)

1. **AI 숏폼 / 릴스 제작기(`youtube-shorts-generator`)와의 원스톱 에셋 연동 (`COLLAB-01`)**:
   - `vinyl-lp-studio`에서 생성한 회전 LP 비디오를 다운로드하지 않고도, 상단 `[AI 숏폼 제작기로 보내기]` 버튼 하나로 쇼츠 제작 프로그램의 배경 비디오 에셋으로 즉시 전송.
2. **AI 프롬프트 스튜디오(`ai-prompt-studio`) 연계 (`COLLAB-02`)**:
   - 프롬프트 스튜디오의 아트워크/커버 디자인 프리셋을 원클릭으로 불러와 레트로 바이닐 자켓에 즉시 적용하는 파이프라인.
3. **AI 작곡 프로그램(Suno/Udio 연동 프로그램)과의 완벽한 워크플로 통합**:
   - AI 음악 생성 프로그램에서 작곡된 음원이 완성되는 즉시 `vinyl-lp-studio`로 자동 전달되어 "음악 작곡 → 바이닐 아트워크 생성 → 턴테이블 비디오 렌더링 → 유튜브 쇼츠 발행"으로 이어지는 완전 자동화 파이프라인 구축.
4. **혁신 아이디어 — 투명 아크릴 턴테이블 & 네온 바이닐 테마 추가**:
   - 전통적인 블랙 바이닐 외에, 최신 트렌드인 **반투명 컬러 바이닐(컬러 LP)** 및 투명 아크릴 플래터(Platter) 텍스처 모드를 도입하여 Z세대 감성의 바이닐 영상 제작 지원.

## 8. 사용자 편의성 증대를 위한 UI/UX 개선안 및 레이아웃/스타일 변경 제안 (UI/UX Proposals)

1. **상단 실시간 볼륨 VU 레벨 메터 (Analog Needle Meter)**:
   - 음악 재생 시 레트로 아날로그 바늘이 좌우로 흔들리는 앰버/그린 듀얼 VU 미터를 컨트롤 패널 상단에 배치하여 아날로그 오디오 기기 조작감 극대화.
2. **모바일 한 손 조작 바텀시트(Bottom Sheet) 컨트롤러**:

   - 1:1 정방형(인스타그램 피드), 9:16 세로형(쇼츠/릴스/틱톡), 16:9 가로형(유튜브 롱폼) 3대 화면비를 원클릭으로 선택할 수 있는 캔버스 프레임 레이아웃 추가.
