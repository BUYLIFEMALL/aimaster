## 2. 상세 개선 대기 목록 (3대 필수 제안 항목별)

### 2.1 [항목 1] 프로그램 로직 및 기능 개선

#### 1) `LOGIC-01`: 실시간 오디오 주파수 스펙트럼(Waveform) 비주얼라이저 오버레이
- **현황 및 문제의식**:
  - 현재 배경 음악을 넣으면 LP 회전 영상에 사운드가 결합되지만, 영상 자체는 디스크만 회전하므로 오디오 반응형 시각 효과가 부족함.
- **개선 방안**:
  - `Web Audio API` (`AudioContext` + `AnalyserNode`)를 활용하여 음원의 주파수 바(Frequency Bar) 또는 부드러운 사인 곡선 파형을 턴테이블 하단에 렌더링.
  - `media-exporter.ts`의 Canvas 드로잉 루프에 오디오 프레임별 버퍼를 연동하여 영상 렌더링 시 파형이 음악 박자에 맞춰 춤추도록 구현.
- **기대 효과**:
  - 릴스, 틱톡, 유튜브 쇼츠에 최적화된 오디오 반응형 비주얼 콘텐츠 완성, 조회수 및 시청 지속 시간 대폭 증가.
- **관련 파일**: `src/lib/render/media-exporter.ts`, `src/components/TurntableDisplay.tsx`, `src/components/ControlPanel.tsx`.

#### 2) `LOGIC-02`: 3D 앨범 자켓(슬리브) 비스듬히 거치 듀얼 렌더 모드
- **현황 및 문제의식**:
  - 턴테이블 위의 원형 디스크만 렌더링되어 실제 앨범 발매 목업으로서의 현장감이 다소 아쉬움.
- **개선 방안**:
  - 턴테이블 좌측이나 뒷편에 사각 앨범 자켓 커버를 3D 원근 투시(`perspective`, `rotateY`)로 비스듬히 세워두는 레이아웃 뷰 모드 추가.
  - 디스크가 자켓 속에서 빠져나와 턴테이블로 올라가는 인터랙션 애니메이션 지원.
- **관련 파일**: `src/lib/render/canvas-texture.ts`, `src/components/TurntableDisplay.tsx`.

#### 3) `LOGIC-03`: 아날로그 바이닐 스크래치 & 레트로 크랙클 오디오 필터 합성
- **현황 및 문제의식**:
  - 일반 디지털 음원(MP3)을 넣었을 때 LP 특유의 따뜻하고 지지직거리는 아날로그 질감이 없음.
- **개선 방안**:
  - Web Audio API 버퍼 믹싱을 통해 레트로 바이닐 크랙클(Crackle & Pop) 노이즈를 3~5% 은은하게 블렌딩하는 토글 옵션 탑재.
- **관련 파일**: `src/lib/render/media-exporter.ts`.

### 2.2 [항목 2] 사용자 인터페이스/UI 가독성, 사용편리성 개선

#### 1) `UI-01`: 턴테이블 조명 & 네온 앰비언트 글로우 토글 스위치
- **현황 및 문제의식**:
  - 턴테이블 카드가 다크 톤으로 안정적이나, 영상 제작 시 감성적인 무드 조명 연출 요구가 높음.
- **개선 방안**:
  - 턴테이블 림 주변에 원형 앰비언트 라이트(빈티지 웜 화이트 / 사이버 네온 블루 / 레트로 앰버)를 켤 수 있는 조명 토글 버튼을 컨트롤 패널에 추가.
- **관련 파일**: `src/components/ControlPanel.tsx`, `src/components/TurntableDisplay.tsx`.

#### 2) `UI-02`: 원클릭 로열티 프리 Lo-Fi BGM 샘플 프리셋 기본 제공
- **현황 및 문제의식**:
  - 사용자가 개인 PC나 스마트폰에 음원 파일이 없으면 음악 포함 MP4를 테스트해보기 번거로움.
- **개선 방안**:
  - 30초 분량의 무료 상업용 Lo-Fi 재즈/시티팝/어쿠스틱 샘플 음원 3종을 기본 내장하여 버튼 클릭 한 번으로 배경 음악 적용 가능하도록 개선.
- **관련 파일**: `src/data/sampleAudios.ts`, `src/components/ControlPanel.tsx`.

### 2.3 [항목 3] 현재 만들어져 있는 다른 자동화 프로그램과의 연계가능한 기능

#### 1) `INTEG-01`: `yt-playlist-studio` (유튜브 플레이리스트 스튜디오)와의 파이프라인 연계
- **연계 시나리오**:
  - `yt-playlist-studio`에서 선정한 플레이리스트 곡 목록과 앨범 커버를 턴테이블 스튜디오로 URL 파라미터 또는 세션 공유로 전달.
  - "이 플레이리스트 LP 회전 숏폼 만들기" 버튼 클릭 시, 턴테이블 스튜디오가 자동으로 해당 곡 정보와 커버를 불러와 10초 쇼츠 홍보 비디오 생성.
- **기대 효과**: 유튜브 채널 운영자가 플레이리스트 홍보용 쇼츠/릴스 콘텐츠를 10초 만에 제작.

#### 2) `INTEG-02`: `youtube-viral-studio` (유튜브 바이럴 스튜디오)와의 연계
- **연계 시나리오**:
  - 바이럴 스튜디오에서 숏폼 대본/음악 큐레이션 기획 시, 인트로/아웃트로용 턴테이블 회전 비디오(MP4)를 리소스로 연동.
