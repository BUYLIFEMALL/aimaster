## 2. 주요 리뉴얼 및 구현 내역

### 1) 좌측 사이드바 (`Sidebar.tsx`)
- 딥 옵시디언 다크 테마 적용
- 최상단 공통 지침 필수 메뉴: `📖 연동 & 사용 매뉴얼` 메뉴 공식 추가
- 대시보드 및 4단계 작업 흐름 번호 배지와 세로 연결선 탑재
- `activeView` ("studio" | "guide") 상태를 연동하여 가이드 뷰 전환 지원

### 2) 비주얼 사용 매뉴얼 신설 (`VinylGuideView.tsx` & `/guide`)
- **비주얼 5단계 표준 파이프라인**:
  1. 미디어 타입 & 메타데이터 설정 (12인치 LP vs 4.7인치 CD)
  2. AI 앨범 아트워크 생성 & 업로드 (Gemini AI 프롬프트 추천 연동)
  3. 턴테이블 속도 & 회전 셋업 (10~100 RPM 슬라이더 & 프리셋)
  4. 배경 음악 오디오 결합 (선택 사항, 클라이언트 로컬 병합)
  5. 고화질 회전 비디오/GIF 내보내기 (WebCodecs 60fps MP4 & 무한 루프 GIF)
- **바이닐 턴테이블 영상 떡상 4대 골든 팁** 수록
- **자주 묻는 질문(FAQ) 4종 아코디언** 탑재
- **개인 API 키 직접 연동 보안 원칙 배너** 에메랄드 테두리로 강조 배치
- **비로그인 방문자 열람 허용**: 누구나 사전 열람 가능하도록 공개 라우트 구성

### 3) 로그인 / 회원가입 페이지 표준화 (`(auth)/layout.tsx`, `(auth)/login/page.tsx`)
- 다크 옵시디언 `#0c0d12` 배경 + 골드/앰버 모눈 격자 패턴
- 바이닐 턴테이블 심볼 로고 및 `v1.08` 버전 뱃지
- `[로그인] / [회원가입]` 표준 탭 토글 레이아웃 적용
- 회원가입 선택 시 AIMaster 통합 회원가입 페이지로 안전하게 안내

### 4) 컨트롤 패널 & 턴테이블 모니터 (`ControlPanel.tsx`, `TurntableDisplay.tsx`)
- 기존 화이트/슬레이트 테마를 딥 옵시디언 다크 레트로 콘솔 스타일로 전면 교체
- 상단 툴바, 인풋 필드, 장르 프리셋 칩, RPM 슬라이더, CTA 버튼 디자인 통일
- 실시간 회전 턴테이블 플레이터와 알루미늄 에지 림, 센터 스핀들 핀 디테일 보강
- 렌더링 진행률 오버레이 및 다운로드 카드 다크 룩 전환

### 5) 모달 및 드로어 (`ApiKeyModal.tsx`, `HelpModal.tsx`, `HistoryDrawer.tsx`)
- 백드롭 `bg-black/75 backdrop-blur-xs` 및 다크 카드 서피스 일체화

## 4. 다음 CLI를 위한 주의사항

1. **단일 배경색 유지**: 신규 컴포넌트 추가 시 반드시 `bg-[#0c0d12]`, 카드 서피스는 `bg-[#141620]`, 보더는 `border-[#272b3f]`를 유지할 것.
2. **클라이언트 사이드 렌더링**: 비디오 렌더링은 `media-exporter.ts`에서 WebCodecs / Canvas API를 통해 브라우저에서 수행되므로 서버 부하가 없음.
3. **개인 API 키 원칙**: Gemini API 키는 로컬 스토리지 및 세션 기반으로만 동작하며 타인/운영자 키 폴백을 절대 추가하지 말 것.
