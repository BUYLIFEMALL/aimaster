## 1. 시험 순서 (맥미니 크롬, 시험 계정 `buylifemall@naver.com`, 비밀번호는 주인님이 직접)

2. https://free-music-studio.buylife.xyz/library 「모든 음악」에서 곡 하나(가능하면 3분 넘는 곡) → 곡 메뉴 「쇼츠 배경음악으로」.
3. 새 창 `https://shorts-onestop-studio.buylife.xyz/render#fms=<곡 번호>`가 열리고 「🎵 AI 무료음악 자동화에서 음악 파일을 받는 중…」이 잠깐 보인다.
4. 대본이 하나면 바로, 여러 개면 「작업할 대본」 아래 「이 대본에 넣기」를 눌러 넣는다 → ③ 배경음악 칸에 `🎵 <곡 제목>.mp3`가 보인다 → [저장].
5. 「MP4 만들기」로 짧게 렌더 → 내려받은 MP4에 배경음악 소리가 들어갔는지 듣는다.
6. 엔진을 끄고 2번을 다시 → 3분 뒤 「음악 파일이 오지 않았습니다… 직접 넣어 주세요」 안내가 나오는지(3분 기다리기 어려우면 생략하고 「생략」으로 적기).
