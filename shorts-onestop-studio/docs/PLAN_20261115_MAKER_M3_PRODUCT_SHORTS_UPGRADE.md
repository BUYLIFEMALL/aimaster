## 2. 할 일 (순서)
1. **장면 기획 JSON**: AI는 JSON만 낸다 — 훅·고민·장점·근거·혜택 + 장면별 문구·사진 id·길이·효과음 이름. **AI가 쓴 HTML/JS는 만들지도 실행하지도 않는다.** 그림은 우리 캔버스 템플릿이 그린다.
2. **모션 템플릿 4종 신규**(우리 디자인): 예) 문제→해결, 장점 3가지, 비교·근거, 혜택 강조. 템플릿마다 장면 길이·효과음·배경음악 짝 기본값.
3. **검증 + 다시 쓰기 1회**: 글자 수·장면 수·사진 id 존재·가격/평점/리뷰 수가 입력에 있는지 검사 → 어기면 같은 요청으로 **1회만** 다시 받음(회원 키 이중 과금 방지), 그래도 어기면 문제 칸을 빨갛게 표시해 회원이 고침. 시스템 지시에 「입력에 없는 가격·평점·리뷰 수는 쓰지 않는다」.
4. **단어 강조 자막 3~5종**: 지금 문장 길이 기반 시각 → 낱말 단위 추정으로 확장(`docs/PLAN_20261111_WORD_TIMING_AFTER_WHISPER.md`와 맞춤).
5. **효과음 라이브러리(CC0만)**: 출처·라이선스 표를 `NOTICE`에, 장면 전환 시각을 배경음악 박자에 맞춰 자동 배치(박자 추정은 브라우저 소리 분석, 실패하면 장면 경계 그대로).
6. **다시 설계 없이 고치기**: 문구·자막·사진·음악·목소리·효과음 바꾸면 AI 재호출 없이 즉시 반영.
7. **버전 기록·되돌리기**: 저장 때마다 장면 JSON 버전을 남기고(최근 10개) 되돌리기. 30일 보관 규칙 그대로(`retentionRows.ts`).

## 3. AI 엔진
- 회원 본인 `user_api_keys`(기본 Claude, 없으면 회원이 등록한 다른 제공자). 운영자 키 폴백 없음.
- 모델: 장면 기획은 `json_schema` 구조화 응답, 재시도 0(검증 뒤 다시 쓰기 1회는 화면에 알림).
- **M4(내 PC Claude Code·Codex 구독 사용)는 이 플랜에 넣지 않는다** — 주인님 결정 + Anthropic·OpenAI 약관 확인 뒤 별도 플랜.

## 4. 조작 숫자
- 처음 설정 **0단계**(이미 등록한 회원 키 재사용, 없으면 등록 안내 1번)
- 매일 조작 **2~3번**(상품 받기 → 템플릿 고르기 → 만들기, 고치기는 선택)
- 동의 **0번**(게시 전 확인은 M3-①에서 업로드마다 1번)

## 5. 검수
- 단위 시험: JSON 검증(장면 수·글자 수·없는 사진 id·입력에 없는 숫자), 다시 쓰기 최대 1회, 효과음 박자 맞춤 시각, 버전 되돌리기.
- 시험 호출: 시험 계정 본인 키 + **Haiku 5.5**, 템플릿 4종 × 1~2회(약 $0.1~0.5, 실행 직전 승인).
- ego lite 시험 계정: 템플릿별 MP4 저장 → **실제 파일을 열어** 장면·자막 강조·효과음 위치·광고 고지 확인, 375px.

## 6. 비용·버전
