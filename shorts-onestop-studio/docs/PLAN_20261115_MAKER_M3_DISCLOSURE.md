## 1. 문제
상품 숏폼(쿠팡파트너스 등 제휴 링크)을 올리면서 광고 고지가 없으면 공정위 「추천·보증 등에 관한 표시·광고 심사지침」 위반이 될 수 있다. 지금 원스톱에는 고지 기능이 없고, AI 제작 표기는 무료 음성일 때 설명란 한 줄뿐이다.

## 2. 지금 있는 것 (코드 확인)

|---|---|---|
| 안전 영역 점선 | `src/lib/render/scene.ts` `drawSafeArea` (`opts.safe`) | 있음 — 플랫폼 버튼 위치 표시로 확장 |
| 합성음 설명란 한 줄 | `src/lib/script.ts` `FREE_VOICE_NOTE`, `src/lib/youtube/browserUpload.ts` | 있음(무료 음성일 때만) |

| 게시 전 확인 | — | 없음 |

## 3. 할 일
1. **광고 고지 설정**(작업마다 저장, 마지막 선택 기억): 끄기 / 쿠팡파트너스 / 제휴 링크 수수료 / 협찬·제품 제공 / 직접 입력. 상품 숏폼(상품 넘겨받기·상품 사진 쇼츠)에 제휴 주소가 있으면 **기본 켬**(쿠팡 주소면 쿠팡파트너스 자동 선택).
2. **영상 안 표시**: 켜면 영상 처음부터 끝까지 위쪽 띠에 고지 문구(우리 문구, 글자 가림 없게 안전 영역 안). MP4 렌더(`scene.ts`)에 그린다.
3. **AI 제작 표기**: 「AI로 만든 영상입니다」 작은 표기(기본 켬), AI 음성·무료 음성을 쓰면 「AI 음성」 표기는 끄지 못함(OpenRAIL-M 조건).
4. **업로드 설명란 첫 줄**: 광고 고지 문구를 설명란 **맨 첫 줄**에, AI 표기를 아래에 자동 삽입. 유튜브 API의 합성 콘텐츠·유료 프로모션 표시 칸은 **공식 문서로 확인한 뒤** 지원되면 같이 켠다(확인 안 되면 설명란만).
5. **안전 영역 확장**: 미리보기에서 쇼츠·릴스·틱톡 버튼 자리를 반투명으로 겹쳐 보기(최종 MP4에는 안 그림).
6. **게시 전 확인**: 업로드 버튼 앞에 체크 4개(사실 확인·사진 권리·AI 표기·광고 고지). 4개 모두 체크해야 업로드 버튼이 켜짐. 한 작업에서 한 번 체크하면 다시 묻지 않음.
7. MP4 메타데이터 메모(AI 제작)는 공용 `browser-mp4-encoder`(기준 = 원스톱)에 선택값으로 넣을 수 있는지 검토 — 넣으면 기준만 고치고 `--sync`, 사본(shots·lyric)은 다음 배포 때 함께.

## 4. 조작 숫자
- 처음 설정 **0단계**(기본값으로 바로 동작)
- 매일 조작 **0~1번**(제휴가 아닌 협찬 영상일 때만 종류 바꾸기)
- 동의 **업로드마다 1번**(게시 전 확인 체크 — 법적 위험이라 의도적으로 남김)

## 5. 검수
- 단위 시험: 고지 문구 고르기(쿠팡 주소 → 쿠팡파트너스), 설명란 첫 줄 순서, 체크 4개 전부여야 업로드 가능.
- ego lite 시험 계정: 상품 숏폼 1개를 MP4로 저장 → **실제 파일을 열어** 처음·중간·끝 장면에 고지 띠가 보이고 자막·상품과 겹치지 않는지, 375px 화면 확인. 유튜브 업로드는 비공개로 1회(설명란 첫 줄 확인).
