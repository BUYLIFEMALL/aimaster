## 1. 리뉴얼 목표 및 배경

1. **지나치게 어둡고 무거운 차콜 톤 탈피**:
   - 기존의 침침한 인더스트리얼 차콜(#07090e)에서 벗어나, 상용 유튜브 크리에이터 스튜디오 수준의 깨끗하고 산뜻한 **소프트 화이트(#ffffff) & 클린 슬레이트(#f8fafc)** 베이스 구축.
2. **유튜브 쇼츠 아이코닉 브랜드 감성 일체화**:
   - 글로벌 숏폼 시그니처인 **유튜브 레드(#FF0000 / #EA3323)**를 메인 액센트로 적용.
   - 핵심 CTA 및 렌더링 버튼에 **유튜브 레드 3D 엠보싱 버튼** 탑재 (`box-shadow: 0 4px 0 #9b0018`).
3. **실시간 9:16 유튜브 쇼츠 모바일 뷰파인더 통합**:
   - 우측에 스마트폰 프레임을 배치하여 실제 유튜브 쇼츠 UI(조회수, 좋아요 4.8만, 댓글 1,230개, 구독 버튼, 하이라이트 자막)를 실시간으로 확인하며 대본과 씬을 편집.
