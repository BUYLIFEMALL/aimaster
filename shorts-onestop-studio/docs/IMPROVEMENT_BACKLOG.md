## 1. 프로그램 로직·기능

- [x] (v1.55 배포 2026-11-14 — 계약 없이 「내 자료함에서 고르기」로) **메이커 2단계 — 자료함 `sourceRef` 원본 참조로 상품 사진 받기**: 복사하지 않고 참조(주인님 2026-11-13 결정). 렌더 직전에 다시 서명, 원본이 지워졌으면 「원본 사진이 지워졌습니다」 안내. 기다리는 것: 기능 담당(sdp)의 내부상품ID·사진 역할·권리 값 계약.
- [x] (v1.54에서 확인, 색 차이 1 이하) **실제 MP4 파일로 상품 외형 대조**: v1.52·v1.53은 미리보기(같은 그리기 함수)로만 확인했다. MP4를 한 번 만들어 첫·가운데·끝 프레임을 원본과 비교(무료, 브라우저 렌더).
- [ ] (바로) **긴 넘겨받기 주소 시험**: 확정 설명 300자(주소 약 2,700자)가 로그인 화면을 거쳐도(`sessionStorage`) 그대로 오는지 실제 화면 시험. 지금은 순수 함수 시험만 있음.
- [x] (v1.55 배포 2026-11-14) **용량 사전 검사**: 상품 사진 올리기 전에 `member_storage_policy` 남은 용량 확인. 지금은 회원당 120장 한도만. 기다리는 것: 정책 담당(policy) 판정.
- [x] (v1.54 배포 2026-11-14) **지운 상품 사진 파일 정리**: 주제 화면에서 「빼기」를 눌러도 버킷 파일은 남는다(30일 정리 때 지워짐). 빼는 즉시 지우는 API 추가 검토.
- [ ] (보류 — 주인님 2026-11-14 「나중에 필요할때」) **상품 장면 AI 영상 형태 변형 시험**: 「상품 장면도 AI 영상 허용」을 켰을 때 실제로 모양·글자가 얼마나 바뀌는지 1회 확인(Wan 3.0 480p 5초 약 $0.25 — 유료, 실행 직전 승인).
- [x] (v1.54 배포 2026-11-14) **같은 상품 다시 만들기**: 대본에 저장된 상품 기록(`ShortsScript.product`)을 불러와 주제 화면 칸을 다시 채우는 「이 상품으로 다시 만들기」.
- [x] (v1.55 배포 2026-11-14) **공용 인코더 `browser-mp4-encoder` 안정화 3가지**(음악 담당 11-13 제안): 하드웨어 가속 먼저 시도 후 자동 대체 · 저장 중 화면 꺼짐 방지(`navigator.wakeLock`) · 남은 시간 어림. 참고 `playlist-channel-studio/src/lib/render/video-exporter.ts`. 기준 `src/lib/render/mp4Encoder.ts` 고친 뒤 `--sync` → 원스톱·`shots`·`lyric-video-studio` 세 프로그램 MP4 시험(무료), 배포는 각 프로그램 다음 배포 때.
