# 개발 플랜 — AI 동영상 장면·본인 목소리·단어 단위 자막 (2026-10-22, 승인 대기)

> 출처: [외부 `shorts-auto` 비교 분석](../../docs/analysis-shorts-auto-20261022/REPORT.md) 묶음 ①. 2026-10-22 주인님 확정 「독립 프로그램 없이 기능만 흡수」.
> 외부 저장소는 라이선스가 없어 **코드·프롬프트를 옮기지 않고**, 우리 구조(`src/lib/script.ts`의 `Bg`·`Voice`, 브라우저 MP4)에 맞춰 새로 만든다(핵심 원칙 21).
> 작성: Claude Code(윈도우). 현재 버전 v1.22.

## 1. 문제

- 지금 장면 배경은 스톡 사진·영상이나 AI 정지 이미지(느린 확대)뿐이다. 「AI가 만든 움직이는 장면」이 없다.
- 목소리는 OpenAI·Gemini 기본 음성뿐이라 채널 고유의 목소리를 쓸 수 없다.
- 자막은 문장을 16자씩 잘라 균등 분배(`captionChunks`)해서, 말하는 순간과 글자가 어긋난다.

## 2. 범위 — 3단계, 단계마다 배포 1회

| 단계 | 버전 | 내용 | 회원 키 |
|---|---|---|---|
| A | v1.23 | **AI 동영상 장면**: 장면 이미지(AI·스톡 사진)를 시작 화면으로 5초 영상 생성. 「다음 장면과 이어지게」를 켜면 다음 장면 이미지를 끝 화면으로 넣어 장면 사이가 끊기지 않게 함. 장면별 또는 전체 일괄, 장면마다 다시 만들기 | 본인 fal 키(공용 연동 항목 재사용, 없으면 공용 목록에 추가) |
| B | v1.24 | **본인 목소리 복제**: 10~60초 내 목소리 샘플 업로드 → ElevenLabs 즉시 복제 → 음성 제공자에 「내 목소리(ElevenLabs)」 추가. 「본인 목소리이거나 사용 동의를 받았습니다」 확인 칸 필수 | 본인 ElevenLabs 키(Shots에서 쓰는 공용 항목 재사용) |
| C | v1.25 | **단어 단위 자막**: ElevenLabs는 글자 시간 응답(`with-timestamps`), OpenAI·Gemini 음성은 Whisper 단어 시간으로 자막 위치를 맞춤. 숫자·영문 표기는 원래 대본 글자를 그대로 사용 | 본인 OpenAI 키(Whisper) |

범위 밖: `yt-dlp` 원본 다운로드(약관 위험), Remotion·ffmpeg 서버 합성(브라우저 합성 유지), `shorts-viral-studio` 대본 넘기기(별도 작업).

## 3. 구현 순서 (A단계 기준, B·C는 같은 틀)

1. `src/lib/script.ts` `Bg`에 `source: "ai-video"`와 생성 정보(`model`, `endFrom`) 추가 — 기존 값은 그대로 읽힘(하위 호환).
2. 서버 `src/lib/videoGen.ts`: fal **대기열 방식**(제출 → 상태 조회 → 결과 받기)으로 호출. 영상 생성은 1~5분이라 한 번의 요청으로 기다리지 않는다(Vercel 300초 제한). 모델·주소·호출 방식은 `ai-image-studio/lib/providers/adapters/fal.ts` 기준을 따름.
3. API 3개(`/api/ai/video/submit`·`status`·`save`) — 모두 `checkProgramAccessApi` + `force-dynamic`/`force-no-store`, 회원 본인 키만, 결과 영상은 회원 경로에 저장(기존 30일 자동 삭제 적용).
4. 화면: 배경 단계의 장면 카드에 「🎬 AI 영상으로」 버튼, 모델 선택(가성비 Seedance 1.5 Pro / 고품질 Kling O1), 예상 비용 표시, 진행 상태, 실패 시 원래 사진 유지.
5. **이중 과금 방지**: 자동 재시도 없음, 같은 장면 진행 중이면 버튼 잠금, 제출 번호를 대본에 저장해 새로고침 뒤에도 이어서 조회.
6. 브라우저 MP4: 이미 영상 배경을 처리하므로 그대로 사용(5초보다 장면이 길면 마지막 화면 정지 또는 반복 — 시험 후 결정).
7. 매뉴얼(`/guide`)에 fal 키 발급·비용 안내 추가, 사용 기록 `usage_logs`에 생성 횟수 기록.

## 4. 검수 방법

- 무료: `npx tsc --noEmit`, 기존 시험 + 새 순수 함수 시험(제출 응답 해석, 장면 연결 순서, 비용 계산), `npm run build`.
- 유료(승인 후): 시험 회원 `buylifemall@naver.com` 본인 fal 키로 **가장 저렴한 모델 5초 장면 2개**(이어 붙이기 확인) → 메인 크롬에서 MP4까지 확인.
- B단계: ElevenLabs 즉시 복제는 유료 요금제(Starter)가 필요 — 시험 회원 키 상태 확인 후 진행.
