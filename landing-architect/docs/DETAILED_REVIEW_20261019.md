## 현재 기능과 보존할 장점

AI가 페이지 구조(6개 섹션)·콘텐츠 전략·디자인 시스템·이미지 구성을 담은 기획안을 만들고, 20가지 주제 프리셋과 5가지 레이아웃 중에서 고르며 섹션별로 고치거나 다시 만듭니다. / 기획안으로 단일 HTML 프로토타입을 만들어 바로 미리 보고, 이미지는 LoremFlickr·Unsplash·Pexels·Pixabay 중에서 골라 채웁니다. / 프로젝트를 저장해 다시 열어 고칠 수 있고, 완성본은 HTML로 내보냅니다.

**보존할 장점:** 기획안과 격리된 HTML 미리보기

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
