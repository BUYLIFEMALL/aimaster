## 완료한 일

- 실제 Chrome 초기 화면과 앱 URL·제목·입력·버튼 확인.
- 확보된 원본 실행 코드·서비스·컴포넌트·설정·타입·문서 18개 정독. 환경 키 값은 제외.
- 모델 호출, 템플릿 문자열 매핑, JSON·HTML 반환 처리, 이미지 API 요청과 응답 필드, 저장·출력·미연결 컴포넌트를 대조.
- 기존 개발 계획을 보완하는 별도 문서와 검수 기준 작성.

## 기존 계획을 읽을 때 정정할 부분

- 주제 템플릿은 의미 분석이 아닌 문자열 정확 일치다. 프리셋과 설명을 별도 저장해야 한다.
- `ConversionFooter`와 배포 문제 해결 가이드는 정의만 있고 앱에 연결되지 않는다. 원본의 실제 하단 기능으로 보장하지 않는다.
- 키 기반 이미지 소스의 키 미등록은 생성 전에 차단해야 한다. LoremFlickr로 조용히 전환하지 않는다.
- 원본의 기획 JSON은 프롬프트 예시일 뿐 API 스키마 검증이 아니다. HTML 오류 화면 문자열도 정상 완료로 처리될 수 있다.
- 원본 모델명은 소스 확인값이다. 운영 적용 전에 본인 키로 현재 사용 가능한 모델과 지원 기능을 확인한다.

## 남은 확인

- 운영 번들과 ZIP 소스의 동일성 및 실제 네트워크 응답 대조.
- 본인 키로 실제 생성한 기획·HTML 결과와 모든 서브 화면, 이미지, 다운로드 확인.
- 구현 이후 자동 검사·실제 회원 Chrome 검수·커밋·푸시·프로덕션 배포·운영 검수.

분석 단계에서 위 실호출·배포가 완료되었다고 보고하지 않는다. DB 스키마·환경변수·키 변경 등 특별 승인 대상은 이미 승인된 범위를 확인하고 실행한다. 이 문서 자체는 승인 기록이 아니다.

## 공유 작업 주의

작성 중 저장소에 다른 CLI가 만든 `landing-architect/src/`, `tests/`, `supabase/`, 설정 파일이 미추적 상태로 존재했다. 이번 문서 작업은 해당 파일을 수정·스테이징·빌드·배포하지 않았다. 기존 개발 계획 커밋은 `9b88bfba`다. 재개 시 `git status`와 최신 로그를 다시 확인하고 다른 CLI의 작업을 보존한다.

이 작업은 문서 변경이므로 프로그램 버전·DB·라이브 사이트를 바꾸지 않는다. 완료 증거는 소스 대조·문서 링크/해시 검증·이 문서만 포함한 커밋과 원격 푸시다.
