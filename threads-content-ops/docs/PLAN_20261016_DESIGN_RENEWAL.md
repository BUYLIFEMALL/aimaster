## 1. 개요 및 분석 배경

### 1.1 프로그램 목적 및 정체성
`threads-content-ops`는 **Meta Threads 플랫폼의 콘텐츠 기획 ➔ 수집 ➔ AI 생성 ➔ 검토/수정 ➔ 자동/예약 발행 ➔ 쇼핑제휴 머니타이징**까지 전 과정을 단일 콘솔에서 통제하는 **올인원 SNS 운영 자동화 SaaS 엔진**입니다.

### 1.2 기존 화면 및 아키텍처 분석
- **현행 버전**: `v1.95` (독립 Next.js 14 앱으로 분리 완료, Vercel `threads-content-ops` 배포).
- **레이아웃 구조**:
  - `app/threads-content-ops/page.tsx` 중심의 단일 페이지 URL 쿼리 파라미터(`?tab=dashboard|viral|create|manage|accounts|sources|settings`) 전환 방식.
  - 좌측 `ContentOpsSidebar.tsx` (너비 `w-60`), 우측 메인 워크스페이스 컨테이너 (`max-w-6xl mx-auto`).
- **발견된 구조적 결함 및 문제점**:
  1. **사용 매뉴얼(`/guide` 또는 `?tab=guide`) 전면 누락**:
     - 사이드바 및 본문 라우트에 가이드북 메뉴가 완전히 부재함. 신규 회원이 Meta 앱 설정, OAuth 콜백, Fixie 프록시, 6종 페르소나 활용법을 학습할 수 없음.
  2. **모바일 반응형 뷰포트 결함 (모바일 햄버거 메뉴 ☰ 부재)**:
     - 사이드바가 `hidden md:flex`로만 선언되어 있어 768px 미만(스마트폰 375~390px) 화면 접속 시 좌측 메뉴가 아예 사라지고 상단 햄버거 토글이 없어 다른 탭으로 이동할 수 없음.
  3. **스타일 충돌 및 텍스트 가시성 문제 (`.threads-content-ops-light` vs `text-white`)**:
     - 기존에 다크 테마용 클래스(`text-white`, `text-subtext`, `text-gold`)와 라이트 배경(`bg-white`)이 혼재되어, 버튼 글자가 안 보이거나 흰색 텍스트가 사라지는 문제가 반복되어 땜질식 CSS 덮어쓰기가 발생함.
  4. **사이드바 표준 미준수**:
     - 계정 이메일과 로그아웃 버튼이 유틸리티 영역 아래에 어정쩡하게 섞여 있으며, 카드 형태의 정돈된 사용자 프로필 UI가 아님.
  5. **5단계 파이프라인 흐름의 시각적 연결성 부족**:
     - 떡상수집(1) ➔ 글생성(2) ➔ 보관함(3) ➔ 계정설정(4) ➔ 제휴상품(5)의 연속적 업무 흐름이 대시보드와 각 화면에서 한눈에 보이는 프로세스 맵으로 표현되지 못함.

## 2. 디자인 리뉴얼 컨셉 및 스타일 템플릿

### 2.1 공식 템플릿 명칭
- **템플릿 고유 명칭**: **`스레드 바이럴 스튜디오 스타일 (Threads Viral Studio Style)`**
- **디자인 철학**: Meta Threads의 세련되고 미니멀한 흑백 모노크롬 감성을 베이스로 하되, 바이럴 콘텐츠의 폭발력을 상징하는 **파이어 앰버(Fire Amber, `#f59e0b`)**와 미래지향적 AI를 상징하는 **일렉트릭 바이올렛(Electric Violet, `#8b5cf6`)**을 액센트로 결합한 **하이엔드 SNS 오퍼레이션 콘솔**.

### 2.2 메인 컬러 시스템 (Color Palette)
- **베이스 배경 (Surface)**:
  - 데스크/콘솔 기본: **퓨어 화이트 (`#ffffff`)** 및 서브 슬레이트 (`#f8fafc` / `#f1f5f9`)의 극도로 정갈한 라이트 테마.
  - (다크 옵션 대비 토큰): 딥 옵시디언 블랙 (`#090d16` / `#0f172a`), 카드 서피스 (`#1e293b`).
- **타이포그래피 및 텍스트**:
  - 메인 헤드라인: 딥 잉크 블랙 (`#0f172a`, `text-neutral-900`) — 명확한 대비 보장.
  - 서브 텍스트: 슬레이트 그레이 (`#64748b`, `text-neutral-600`).
  - 안내/힌트: 뮤티드 그레이 (`#94a3b8`, `text-neutral-400`).
- **브랜드 액센트**:
  - **Threads Black**: `#000000` (Threads 공식 심볼 및 주요 액션 버튼).
  - **Viral Fire Amber**: `#f59e0b` / `#d97706` (떡상 지표, 1~5 파이프라인 단계 뱃지, 불꽃 아이콘).
  - **AI Magic Violet**: `#8b5cf6` / `#7c3aed` (페르소나 선택, AI 글생성 액션).
  - **Success Green**: `#10b981` (발행 완료, 정상 연동 칩).
  - **Warning / Error**: `#ef4444` (토큰 만료, 500자 초과 경고).

## 3. 화면별 리뉴얼 상세 설계

### 3.1 좌측 메뉴바 표준화 (`ContentOpsSidebar.tsx`)
- **규격**: 데스크톱 `md:w-60` ~ `md:w-64`, 좌측 상시 고정 (`sticky top-0 h-dvh`).
- **헤더부**:
  - 앱 타이틀: **Threads 운영 자동화**
  - 버전 뱃지: `v1.96` (알약형 바이올렛/앰버 배지)
  - 상단 링크: `← 다른 프로그램 보기` (`https://www.buylife.xyz/programs`)
- **네비게이션 본문**:
  1. `🏠 오퍼레이션 대시보드` (`?tab=dashboard`)
  2. **5단계 파이프라인 (세로 타임라인 연결선 + 번호 뱃지)**:
     - `1️⃣ 떡상 콘텐츠 수집` (Flame 아이콘, 앰버 액센트)
     - `2️⃣ AI 콘텐츠 생성` (Sparkles/PenLine 아이콘, 퍼플 액센트)
     - `3️⃣ 콘텐츠 보관함 & 발행` (Send/Layers 아이콘, 블루 액센트)
     - `4️⃣ 계정 콘셉트 설정` (Users/Bot 아이콘, 인디고 액센트)
     - `5️⃣ 쇼핑제휴 상품 등록` (ShoppingBag/Library 아이콘, 에메랄드 액센트)
  3. **구분선 및 유틸리티 영역**:
     - `🔑 API키등록·플랫폼연동` (`?tab=settings`, KeyRound 아이콘)
     - `📖 연동 & 사용 매뉴얼` (`?tab=guide` 또는 `/guide`, BookOpen/HelpCircle 아이콘 — **신설**)
  4. **접속 계정 및 로그아웃 (하단 밀착 카드)**:
     - 유틸리티 메뉴 바로 아래(8~16px 간격) 배치.
     - 사용자 이메일 뱃지 (`buylifemall@naver.com`) + 간결한 로그아웃 버튼.

### 3.2 모바일 반응형 헤더 (신설)
- 768px 미만 화면 최상단에 `sticky top-0 z-50` 모바일 헤더 배치.
- 좌측: Threads 브랜드 로고 및 타이틀 (`Threads 운영 v1.96`).
- 우측: 햄버거 토글 버튼 (`☰` / `✕`).
- 터치 시 좌측에서 부드럽게 슬라이드되는 오버레이 드로어(Drawer) 네비게이션 제공.

### 3.3 대시보드 (`OperationsDashboard.tsx`) — 오퍼레이션 컨트롤 타워
1. **상단 KPI 지표 요약 카드 (4종)**:
   - 🔗 **연결된 Threads 계정** (토큰 상태 정상/만료 알약 칩)
   - 🔥 **수집된 떡상 글감** (대기 중 / 총 수집 건수)
   - 📝 **보관함 초안 & 예약** (발행 대기 / 예약 중 건수)
   - 🚀 **누적 포스팅 완료** (성공 건수 및 성공률)
2. **5단계 운영 파이프라인 상태 다이어그램 (신규 위젯)**:
   - 1 수집 ➔ 2 생성 ➔ 3 보관/발행 ➔ 4 계정 ➔ 5 제휴상품 간의 데이터 흐름을 시각적인 가로 단계 카드로 표현하여 원클릭 이동 지원.
3. **시스템 헬스체크 배너**:
   - Meta Threads API 토큰 만료 여부 경고
   - AI API 키(OpenAI, Gemini) 등록 상태
   - 토스/쿠팡 쇼핑제휴 프록시(Fixie) 연결 상태
4. **최근 포스팅 피드 타임라인**:
   - 최근 30건의 발행/예약 이력을 타임라인 카드 형태로 미리보기(본문, 미디어 썸네일, 링크, 상태 칩).

### 3.4 1단계: 떡상 콘텐츠 수집 (`ViralCollector.tsx`)
- **3대 수집원 직관적 탭 인터페이스**:
  - 🌐 **URL/아티클 수집**: 웹 링크 입력 ➔ 핵심 문장 자동 추출
  - 🔍 **Perplexity 트렌드 리서치**: 키워드 입력 ➔ 실시간 핫이슈 자동 요약
  - 🎬 **유튜브 쇼츠 분석**: 쇼츠 URL/키워드 ➔ 바이럴 스크립트 구조 역분석
- **카테고리 칩 필터 & 글감 카드 갤러리**:
  - 미분류 카테고리를 포함한 태그형 필터.
  - 글감 카드에 [즉시 AI 글 생성으로 보내기 ➔] 퀵 액션 버튼 배치.

### 3.5 2단계: AI 콘텐츠 생성 (`AttentionComposer.tsx`)
- **6종 페르소나 카드 갤러리 시각화**:
  - 공감형 에세이, 직설형 인사이트, 데이터 분석가, 위트 일상러, 트렌드 큐레이터, 1인 창업가.
  - 선택 시 초록/퍼플 보더 + 발광 효과 + [페르소나 적용하기] / [원클릭 즉시 생성].
- **실시간 스마트 에디터 & 500자 게이지 바**:
  - 글자 수 500자 제한을 실시간 프로그레스 바로 시각화 (450자 이상 주의 노랑, 500자 초과 빨강 경고).
  - 훅(Hook) / 본문(Body) / CTA(행동유도) 구조화 안내 팁.
  - 쇼핑제휴 상품 선택 시 단축 URL 및 공정위 문구 자동 삽입 미리보기.

### 3.6 3단계: 콘텐츠 보관함 & 발행 (`DraftComposer.tsx`)
- **상태별 탭 바**: 전체, 검토 대기(`draft`), 예약됨(`scheduled`), 포스팅 완료(`published`), 실패(`failed`).
- **카드형 인라인 편집기**:
  - 모달 팝업 대신 리스트 내에서 직접 [수정] ➔ [저장], [지금 발행], [예약 변경] 수행.
  - 이미지 드래그앤드롭 및 캐러셀 미리보기.

### 3.7 4단계: 계정 콘셉트 설정 (`AccountOperations.tsx`)
- 계정별 말투/톤앤매너, 일일 발행 목표(슬라이더), 포스팅 시간대 타임블록 시각화.
- 금지 키워드 태그 입력 UI.

### 3.8 5단계: 쇼핑제휴 상품 등록 (`SourceQueue.tsx`, `CoupangManualRegistration.tsx`)
- 쿠팡 파트너스 5단계 수동 등록 가이드 (HTML 복사 ➔ 상품명/사진 자동 파싱 ➔ 미리보기).
- 토스 쇼핑 실시간 베스트 상품 30선 그리드.

### 3.9 신설: 연동 & 사용 매뉴얼 (`UsageGuide.tsx` / `?tab=guide`)
- **구조**:
  - **탭 1: 5단계 운영 파이프라인 (Visual Workflow)**
    - 계정 연동부터 바이럴 수집, 생성, 발행까지 인포그래픽 다이어그램.
  - **탭 2: Meta Threads 앱 및 API 연동 가이드**
    - Meta for Developers 앱 생성, Threads API 권한 추가, 콜백 URL 설정 가이드.
  - **탭 3: 바이럴 알고리즘 & 6대 페르소나 공략법**
    - 스레드 알고리즘이 선호하는 훅(Hook) 작성법, 체류 시간 늘리는 줄바꿈 팁.
  - **탭 4: 쇼핑제휴(쿠팡/토스) 수익화 매뉴얼**
    - 제휴 링크 규정, 공정위 문구 자동화, 수익 배너 제작 노하우.
  - **탭 5: 자주 묻는 질문(FAQ) 및 오류 해결**
    - 토큰 만료 시 재인증 방법, 500자 초과 대처법, 이미지 업로드 규격.

   - `ContentOpsSidebar.tsx`에 `📖 연동 & 사용 매뉴얼` 메뉴 추가.
