## 3. 아키텍처 및 핵심 기술 스택

1. **클라이언트 사이드 WASM 변환 엔진**:
   - 서버(Render 워커)가 아닌 사용자 브라우저 내에서 `@ffmpeg/ffmpeg` (v0.12.15) WebAssembly 바이너리로 직접 구동.
   - Vercel 100MB 요청 제한 및 서버 유지비용을 원천 차단.
2. **지능형 8단계 화질 사다리 (Candidates Ladder)**:
   - 결과 GIF가 **8MiB(약 8.3MB)** 이하가 될 때까지 1단계(100% 해상도/256색)부터 8단계(45% 해상도/128색)까지 자동 최적화 탐색.
   - 영상의 전체 재생 시간을 임의로 자르지 않고 100% 보존.
3. **색상표(팔레트) 최적화 고화질 변환** (2026-10-23 문서 정정 — v1.15부터 방식 변경):
   - 기본은 **한 번에 만들기**: `split → palettegen(max_colors, stats_mode=diff) → paletteuse(sierra2_4a 디더링, diff_mode=rectangle)`를 한 번의 실행으로(`components/ConverterWorkspace.tsx` `convertOne`).
   - 메모리가 모자라거나(`lib/gifLadder.ts` 판단) 한 번에 만들기가 실패하면 예전 **두 번 방식**(1차 `palettegen`으로 색상표 파일 → 2차 `paletteuse`)으로 자동 전환. 화질·필터는 같다.
4. **다중 큐 및 일괄 처리**:
   - 최대 20개 동시 등록, 파일당 최대 200MB 지원. 브라우저 CPU 안전을 위해 순차(1개씩) 인코딩 처리.
