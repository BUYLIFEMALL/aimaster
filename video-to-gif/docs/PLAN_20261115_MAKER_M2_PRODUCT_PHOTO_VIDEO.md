# 개발 플랜 — M2 「🛍 상품 사진 영상」 (사진 → MP4·상세페이지 움짤 WebP, 키·AI 없음)

> 2026-11-15 · [역할: video] `claude-win-video` · 상태: **플랜 — 주인님 결정 대기(구현 0)**
> 근거: [`docs/analysis-ecommerce-bundle-20261024/HANDOFF_20261115_MAKER_V033_VIDEO.md`](../../docs/analysis-ecommerce-bundle-20261024/HANDOFF_20261115_MAKER_V033_VIDEO.md) §3 M2
> 위치 추천: `video-to-gif`(이 문서). 결정이 `shorts-onestop-studio`이면 이 문서를 그쪽으로 옮긴다.
> 원본(메이커, 상용)은 동작만 참고 — 무빙·전환 이름과 종류, 문구, 화면은 우리 디자인으로 새로 정한다.

## 1. 왜 GIF 변환에 두는가
- 이미 「🛍 상세페이지로」 보내기(`lib/gifHandoff.ts`), 20개 일괄·ZIP(`lib/zip.ts`), 8MiB 사다리(`lib/gifLadder.ts`), `ffmpeg.wasm`, 내 PC 고속 변환(로컬 렌더러)이 있다 → 「상세페이지용 움짤」 결과물과 흐름이 같다.
- 키·AI가 없어 원스톱(AI·음성 중심)보다 가볍고, 회원이 바로 쓸 수 있다.

## 2. 할 일
1. 새 화면 `/product-video`(좌측 메뉴 「🛍 상품 사진 영상」).
2. **사진 1~6장**(끌어 놓기·순서 ◀▶), 템포 3종(짧게·보통·여유), 사진마다 카메라 무빙(우리 종류 6~8개)·전환(5~7개, 기본 자동 섞기), 문구 3층(제목·설명·브랜드) 글꼴·테두리·그림자.
3. 비율 9:16 / 1:1 / 상세페이지 가로폭(860px), 30fps 기본(15/60 선택).
4. **결과 두 가지**
   - MP4: 공용 `browser-mp4-encoder` **사본 추가**(기준 원스톱, `check-shared-modules.mjs` copies에 등록 → `--sync`). 그리기(`drawFrame`)는 이 프로그램 것.
   - 애니메이션 WebP(**10MB 이하 자동**): `ffmpeg.wasm`의 `libwebp_anim`로 만들고, 넘으면 기존 사다리 방식(크기·품질·fps 단계)을 WebP용 표로 확장해 다시 시도. 내 PC 고속 변환이 켜져 있으면 PC ffmpeg로.
5. **음악**: `/fms-bgm` 무료 곡 + 회원 음악(「상업 이용 조건 확인」 안내 한 줄). WebP는 소리 없음.
6. **여러 상품 일괄**: 파일 이름 `상품코드_1~6.jpg`를 묶어 상품별로 **하나씩 순서대로** 생성(동시 처리 없음)·중단 버튼·실패만 다시. 결과는 `상품코드.mp4/.webp` ZIP.
7. 결과마다 「🛍 상세페이지로」 기존 연결 재사용.
8. **사전 검증 먼저**: `ffmpeg.wasm` 코어에 `libwebp_anim`이 들어 있는지, 6장 15초 WebP가 10MB 안에 드는지 저장소 밖 사전 검증 페이지로 확인 → 안 되면 로컬 렌더러 명령(호스트 1.31)으로 돌리고 화면에 「내 PC 고속 변환 필요」 안내.

## 3. 조작 숫자
- 처음 설정 **0단계**(키·로그인 연동 없음)
- 매일 조작 **2번**(사진 넣기 → 만들기), 일괄은 폴더 한 번 넣기 + 시작
- 동의 **0번**(내 음악을 넣을 때만 안내 1줄, 체크는 없음)

## 4. 검수
- 단위 시험: 파일 이름 묶기(`ABC_1.jpg`~`ABC_6.jpg`, 빠진 번호·확장자 섞임), WebP 사다리 다음 단계 계산, 템포별 장면 길이 합.
- ego lite 시험 계정: 사진 6장 → MP4·WebP 만들기 → **실제 파일을 열어** 상품 외형 왜곡·문구 가림·움직임 확인, WebP 용량 10MB 이하, 상품 2개 일괄 ZIP, 「상세페이지로」 넘김, 375px.

## 5. 비용·버전
- AI·유료 호출 없음. 빌드 1회(GIF 변환 미배포분 — 배지 Aside·왼쪽 메뉴 버전 글자와 묶음, 실행 전 승인). 버전 v1.30.
- 로컬 렌더러 명령을 바꾸면 확장·호스트 ZIP·DB 버전을 함께 맞춘다(핵심 원칙 10).
