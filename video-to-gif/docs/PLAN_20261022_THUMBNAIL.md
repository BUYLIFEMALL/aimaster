# 플랜 — 대기 목록 영상 첫 장면 썸네일 (v1.12, 2026-10-22 주인님 승인: 「진행해」)

## 문제
영상을 여러 개 넣으면 목록에 파일 이름만 보여 `IMG_1234.mp4`처럼 비슷한 이름은 구분하기 어렵다.

## 범위 (`components/ConverterWorkspace.tsx`)
1. `readDuration` → `readVideoInfo`: 길이와 함께 0.1초(짧은 영상은 길이의 절반) 지점 장면을 가로 160px JPEG(`data:` 주소)로 만든다. 8초 안에 못 그리면 길이만.
2. 목록 왼쪽 번호 칸 → 썸네일(가로 64px, 세로 최대 64px), 번호는 왼쪽 위에 겹침.
3. 브라우저가 못 읽는 영상(예: 아이폰 HEVC)은 지금처럼 번호 칸, 변환은 그대로.
- 서버·DB·AI·ffmpeg 변경 없음. 구간 시작 장면으로 썸네일 바꾸기는 2-5(끌어서 고르는 막대)와 함께.
