## 현재 기능과 보존할 장점

MP4·MOV·MKV·AVI·WebM 영상을 한 번에 최대 20개(파일당 200MB)까지 올리고, 프레임 수(40·50fps)와 가로 크기(160~800px)를 고릅니다. / 용량 제한(8MiB)을 넘으면 크기를 단계적으로 낮춰 가며 제한 안에 들어올 때까지 자동으로 다시 만들어, 화질을 최대한 지킵니다. / 완성된 GIF는 서버에 저장되지 않으니 화면을 벗어나기 전에 바로 내려받으세요.

**보존할 장점:** 브라우저 변환과 결과 용량 제한

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
