## 1. 문제
상세페이지 사용법·프로그램 조작법 GIF를 만들려면 지금은 다른 녹화 프로그램으로 영상을 만든 뒤 다시 올려야 한다(파일 왕복).

## 2. 범위
| 넣는 것 | 안 넣는 것 |
|---|---|
| 작업 화면 드롭존 아래 「🖥 화면에서 바로 녹화」 버튼 | 소리 녹음(GIF에는 소리가 없음) |
| 브라우저 화면 공유 창(`getDisplayMedia`)으로 화면 전체·창·탭 중 하나 고르기 = 영역 지정 | 사각형 직접 그려 자르기(다음 단계 후보 — 구간 막대처럼 따로) |
| 최대 15초, 남은 초 표시, 「녹화 멈추기」, 공유 중지(브라우저 막대)로도 멈춤 | 서버 업로드(지금처럼 브라우저 메모리만) |
| 녹화본(WEBM)을 대기열에 그대로 넣음 → 기존 구간 자르기·8MiB 사다리·내 PC 변환 그대로 | 휴대폰 녹화(지원 안 하는 브라우저는 버튼 대신 「PC 크롬·엣지에서 쓸 수 있습니다」 안내) |
| 녹화본은 길이 정보가 비어 있는 경우가 많아 녹화한 시간을 길이로 넣음(구간 막대가 동작하게) | |
| 사용 매뉴얼 FAQ 1개 추가 | |

## 3. 구현 순서
1. `lib/screenRecord.ts`(순수 함수): 녹화 형식 고르기(vp9 → vp8 → webm), 파일 이름(`화면녹화-YYYYMMDD-HHMMSS.webm`), 지원 여부, 남은 초 계산 + `node --test` 시험
2. `components/ScreenRecorder.tsx`: 버튼·카운트다운·멈추기·오류 안내(공유 취소는 조용히)
3. `ConverterWorkspace.tsx` `addFiles`가 `File[]`와 미리 아는 길이를 받게 조금 고침 → 녹화본 연결
4. `app/guide/page.tsx` FAQ 한 개
5. `tsc`·시험·`npm run build`(로컬, 무료)

## 4. 검수
- 자동: 순수 함수 시험, `tsc`, 로컬 빌드
- 실제 화면: 화면 공유 창은 브라우저 바깥 창이라 에이전트가 고를 수 없음 → 배포 뒤 주인님이 한 번 「탭」을 골라 주시면 녹화 → 대기열 → GIF까지 확인(배포 전에는 「미확인」으로 표기)
