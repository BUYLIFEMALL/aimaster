# 개발 플랜 — 쿠팡 상품 자동등록기 (2026-10-28, Claude Code 윈도우 `claude-win-sdp` · 역할 ecommerce-image)

> 상태: **플랜 보고 단계(주인님 승인 전, 코드·DB 변경 없음)**.
> 기준 문서: [마켓 등록기 공통 레퍼런스](../../docs/MARKETPLACE_REGISTER_ANALYSIS_GUIDE.md) · 기준 프로그램 [`smartstore-register`](../../smartstore-register/AGENTS.md)(v1.24, 실물 시험 전 항목 통과) · [프로그램 비교표](../../docs/PROGRAM_CAPABILITY_MAP.md)

## 1. 목표
AI 상세페이지 자동화(`shop-detail-page`)로 만든 상품을 **쿠팡 WING에 다시 입력하지 않고 등록**한다. 스마트스토어 등록기와 같은 사용 흐름(상품 고르기 → 보내기 → 결과 기록)을 쓰되, 쿠팡은 **판매자 본인 키로 쓰는 공식 API**가 있으므로 화면 조작 대신 API를 쓴다(레퍼런스 §0-1 「마켓이 회원 본인 키를 허용하면 API 방식을 먼저 검토」).

## 2. 확인한 사실(2026-10-28 공개 자료)
| 항목 | 내용 | 근거 |
|---|---|---|
| 키 | WING 「판매자정보 → 추가판매정보 → OPEN API 키 발급」 — **업체코드(vendorId)·Access Key·Secret Key**. Open API 이용 신청 먼저 | 연동 업체 안내(채널톡·CJ대한통운 등) |
| **IP 등록** | 키 발급·수정 때 **호출할 IP 주소를 등록**해야 하고 등록된 IP에서만 호출됨(여러 개는 쉼표, 「자체개발」로 추가) | 같은 자료·셀러 커뮤니티 |
| 키 수명 | **180일(6개월)마다 재발급** | 같은 자료 |
| 서명 | `Authorization: CEA algorithm=HmacSHA256, access-key=…, signed-date=…, signature=…` | 연동 업체 문서 |
| 상품 생성 | `POST /v2/providers/seller_api/apis/api/v1/marketplace/seller-products` (`api-gateway.coupang.com`) | 쿠팡 개발자 문서 360033877853 |
| 이미지 | **URL을 `vendorPath`로 넘기면 쿠팡이 내려받아 CDN에 등록**(80·443 포트). 대표 이미지 필수·정사각형·500~5000px·3MB 이하 | 같은 문서 |
| 저장/승인 | `requested: false` = 저장만(판매 요청 전), `true` = 저장 + 판매 승인 요청 | 같은 문서 |
| 필수 칸 | 상품명·브랜드·판매 기간·배송(택배사·배송비·출고지 코드)·반품(반품센터 코드·주소·반품비)·옵션 항목(최대 200, 가격·재고·이미지·상세)·**카테고리별 구매옵션·고시정보(카테고리 메타 조회 API로 확인)** | 같은 문서 |

## 3. 방식 결정 — 어디서 API를 부를까(IP 등록 때문에 가장 중요)
| 후보 | 하는 법 | 장점 | 단점 |
|---|---|---|---|
| **A. 회원 PC의 확장이 직접 호출(추천)** | 회원이 키를 **확장에만** 저장(우리 서버에 Secret Key를 두지 않음), 확장 배경이 서명해 쿠팡 API를 부름. 회원은 **자기 PC의 공인 IP**를 WING에 등록 | 운영자 비용 0, 「트래픽은 회원 PC에서」 원칙과 맞음, 키 유출 위험이 가장 작음, 스마트스토어 확장 구조 그대로 | 집·사무실 IP가 바뀌면 다시 등록해야 함 → 확장이 「내 IP」를 보여 주고 「IP 미허용」 오류를 알아서 안내 |
| B. 우리 서버가 호출(고정 IP 필요) | 회원 키를 공용 키 표에 저장, Vercel 고정 IP(유료) 또는 고정 IP 중계 서버로 호출 | 회원 IP가 바뀌어도 됨, 회원은 우리 IP 하나만 등록 | **운영자 비용(고정 IP)**, 회원 Secret Key를 서버가 보관, 여러 회원 호출이 한 IP로 몰림 |
| C. WING 화면 조작(스마트스토어와 같은 방식) | 확장이 WING 상품 등록 화면 칸을 채움 | 키·IP 필요 없음 | WING 화면 분석·보정이 큼(스마트스토어에서 수십 번 보정), 화면이 바뀌면 깨짐 |

**추천: A.** 1차는 A로 만들고, IP 변경이 실제로 불편하다는 회원 의견이 쌓이면 B를 프리미엄 선택지로 검토한다.

| 가져옴(같은 구조·컴포넌트 복사) | 새로 만듦 |
|---|---|
| 뼈대(권한·로그인·사이드바·`slw-*` 스타일·버전·30일 정리), 상세페이지 상품 불러오기(`data.ts`), 확장 연결(토큰·연결 계정 표시), 작업 표·등록 기록, 연속 보내기, 중복 등록 막기, 오래된 화면 막기, 결과 기록, 매뉴얼 틀(v1.24), 상품속성 AI 추천(회원 본인 Claude 키) | 쿠팡 API 서명(HMAC)·호출(확장), 키 저장(확장 안, 「내 IP」 표시), 카테고리 추천/검색·**카테고리 메타(구매옵션·고시 필수 항목)** 조회, 출고지·반품센터 코드 불러오기, 쿠팡 요청 본문 만들기(`buildCoupangProduct`), 이미지 공개 주소(쿠팡이 내려받을 수 있는 시간 동안 유효한 서명 주소), 등록 뒤 승인 상태 조회 |

## 5. 등록 방식(회원이 고름)
| 방식 | 쿠팡 동작 | 스마트스토어 대응 |
|---|---|---|
| 저장만 | `requested: false` — WING에 「판매 요청 전」으로 저장 | 임시저장까지 |
| 저장 + 승인 요청 | `requested: true` — 쿠팡 검수 뒤 판매 | 바로 등록 |
| 미리보기 | API를 부르지 않고 보낼 내용·빠진 필수값만 확인 | 입력만에 가까움 |
