## 현재 기능과 보존할 장점

채널 이름·@핸들·주소를 넣으면 구독자·총 조회수·업로드 주기를 보여 주고, 최근 영상 50·100·200개의 인기 점수와 쇼츠·일반 영상 비율을 차트와 목록으로 진단합니다. / 키워드를 넣으면 검색된 영상의 조회수·좋아요·댓글, 채널 점유율, 게시 시기를 분석하고, 구독자는 적은데 평균 조회수가 높은 소형 고효율 채널을 찾아 줍니다. / AI가 경쟁 전략·채널 성장 과정·채널 진단과 영상 요약을 정리하고, 결과는 JSON·CSV로 내보낼 수 있습니다.

**보존할 장점:** 채널 진단·키워드·황금 채널 엔진

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
