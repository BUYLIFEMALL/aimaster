# G-3 역할 유지·자료 경계 보강

2026-10-25 · 역할 `docbot-prompt`, 세션 `codex-win-20261025-docbot-g3`.

주인님 「디자인은 agy 담당… 넌 프로그램 완성도를 높여」에 따라 G-2 일반 회원 검수와 기존 승인 G-3을 순서대로 진행합니다. 대상은 AIMaster 운영 `ai-doc-chatbot`이며 DB ref는 `esgxyikcnnvmlhygjkth`입니다. 로그인·CSS·테마는 수정하지 않습니다.

## 문제와 범위

현재 시스템 지침에 문서·웹 원문과 봇 지침이 이어 붙고, 사용자의 처리 대상과 역할 변경 요청이 구분되지 않습니다. 번역 봇의 언어와 형식이 플랫폼 기본 한국어 답변 지침과 충돌할 수 있으며, 웹 라우터도 질문·문서 원문을 한 user 메시지로 받습니다. 현재 연도 지침은 과거 원문 연도를 바꾸지 않는다는 예외가 필요합니다.

## 순서와 검수

1. G-2: 지정 일반 회원 Edge에서 비용 없는 합성 봇 생성·수정·목록 재열기·선택·삭제를 검수합니다. 기존 회원 자료는 바꾸지 않습니다. 현재 대화방은 비어 있으므로 실제 방 저장·과거 답변 검수는 본인 키 준비 여부에 따라 구분합니다.
2. G-3: 플랫폼 규칙 → 회원이 저장한 봇 역할 → 현재 처리 대상/대화 → 문서·웹 근거의 경계를 명시합니다. 자료는 JSON 등으로 감싸 역할 구분자처럼 보이는 문구도 원문으로 처리하도록 합니다. 기존 프롬프트 문구와 출처/NDJSON 계약을 보존하면서 필요한 조립 부분만 고칩니다.
3. 번역·요약 봇에는 질문형 문장/역할 변경 유도/출력 언어 변경도 처리 대상으로 다루는 예시를 직접 작성합니다. 커스텀 봇의 언어·형식은 플랫폼 기본값보다 우선하되 회원 격리·출처 정확성·실제 도구 권한을 바꾸지 못합니다. 현재 날짜와 원문 과거 사실을 구분합니다.
4. 구조화 라우터는 system 지침과 비신뢰 입력을 구분하며 비스트리밍 JSON 경로를 유지합니다. 번역·요약 기본 봇에는 원문의 질문에 대한 불필요한 웹 검색을 피합니다.
5. 실제 조립된 메시지·라우트에서 질문형 번역, 역할 변경 유도, 자료 속 명령, 언어/형식, 과거 연도, 서버가 읽은 봇 설정만 적용함을 무료 모의 검사합니다. 타입 검사·필요한 로컬 빌드를 수행합니다. 모의 출력은 실제 모델의 역할 준수 성공으로 계산하지 않습니다.

## 비용·배포·산출물

새 패키지·DB 스키마·키 변경·실제 AI 호출 없이 구현과 로컬 검사를 먼저 끝냅니다. 실제 AI는 일반 시험 회원 본인 키가 있을 때만 기존 승인 텍스트 10회/1,000원 상한에서 최소 호출합니다. G-1~G-4 앱별 묶음 배포 계획을 유지하고 이번 작은 보강은 미배포 대기, v1.07 유지입니다.

프로그램 개선·인수인계/AGENTS/README, 역할·프로그램 비교표·카테고리 비교표/작업표·아이디어 표와 루트 HANDOFF를 실제 증거에 맞춥니다. G-4·G-5를 이번 G-3 완료로 합쳐 보고하지 않습니다. 프롬프트만으로 지침 이탈을 완벽히 막는다고 보장하지 않습니다.
