**포커스 스튜디오 스타일 — 미드나잇 챗 콘솔 변형** (Focus Studio Style · Midnight Chat Console Variant)
- 기존 「포커스 스튜디오 스타일」(한 가지 작업에 집중하는 단일 작업 화면)의 골격을 유지하고, 오래 읽는 채팅 화면에 맞춰 어두운 미드나잇 배경으로 바꾼 변형입니다. 새 대분류를 만들지 않았습니다.

## 구성
- 좌측 사이드바: 「← 다른 프로그램 보기」(https://www.buylife.xyz/programs) → AI 채팅 · 내 문서 · 📖 연동 & 사용 매뉴얼 · API키등록·플랫폼연동 → 계정 이메일·로그아웃(마지막 메뉴 바로 아래).
- 채팅: 상단 「새 대화」 + 채팅방 목록 토글, 빈 화면에 추천 질문 3개, 하단 입력창(Enter 보내기·Shift+Enter 줄바꿈) + 「📄 내 문서 참고」「🌐 웹 검색(필요할 때 자동)」 체크, 답변 아래 📄/🌐 출처 칩.
- 매뉴얼(`/guide`): 4단계 카드(키 등록 → 문서 올리기 → 질문 → 출처 확인) + 「답변이 만들어지는 과정」 + FAQ.
- 키 등록: Upstage(필수)·Tavily(선택) 카드 + 하단 「📖 연동 매뉴얼」 팝업 버튼 2개(`platform_guides`).
