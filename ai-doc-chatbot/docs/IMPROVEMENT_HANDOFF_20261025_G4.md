## 실제 Edge 검수와 정리

지정 일반 회원 `buylifemall@naver.com`, localhost:4311 실제 보이는 Edge 창입니다. 처음 로그인 화면으로 이동해 주인님께 직접 로그인을 요청했고, 일반 회원 로그인 뒤 재개했습니다.

업로드 API·AI를 호출하지 않고 화면 검수용 합성 문서2개/조각2개를 SQL로 넣었습니다(가짜 임베딩, 실제 업로드·파싱 성공으로 계산하지 않음). `G4-screen-probe-1.txt`는 본문에 `<b>` 글자 표시, `G4-screen-probe-2.pdf`는 추출 의심 경고 표시 확인용입니다.

확인: 분류 저장 → 완료 알림 → 분류 필터1건 → 새로고침 후 분류 유지 → 본문 미리보기·HTML 글자 그대로 표시 → 두 문서 체크/채팅 전달·2개 선택 유지 → 채팅에서 PDF 경고 미리보기 → 선택0개 경고 → 내 문서에서 시험 문서2개만 확인 후 삭제.

마지막 SQL에서 두 시험 문서ID와 조각 모두0건·시험 회원 전체 문서0건·Upstage 키 미등록을 확인했습니다. 기존 회원 자료는 수정하지 않았습니다. 캡처는 Orca 임시 경로이며 장기 보관 증거는 아닙니다. 실제 답변/업로드/원본 PDF 파싱·좁은 화면·예전 답변에서 미리보기 열기는 미검수입니다.
