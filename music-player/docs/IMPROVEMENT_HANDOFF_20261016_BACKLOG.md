## 다음 CLI의 재개 순서

1. 루트 지침·ACTIVE_WORK·최신 HANDOFF → 프로그램 AGENTS/README → 이 문서 → 개선 원장을 읽고 다른 CLI의 작업·미커밋 파일을 확인합니다. 현재 상태가 달라졌으면 최신 결과부터 반영합니다.
2. 주인님 요청 범위의 개발 플랜을 **코드 변경 전에 제시**합니다. 원장 권장 우선순위는 MP-01~03. 독립적으로 진행 가능한 MP-02와 저장 모델이 연결된 MP-01/03/08 순서를 검토합니다.
3. 회원별 로컬 저장과 음원·커버·ID·재생 설정을 보존합니다. 클라우드 DB 스키마·키·환경변수는 임의 변경하지 않습니다. 로컬 IndexedDB 변경도 마이그레이션·실패 복구를 플랜에 명시합니다.
4. 승인된 기능별로 구현→자동/타입/빌드→보이는 Edge 실제 회원 화면→원본 보존·모바일 검수→문서→커밋/푸시→프로그램 운영 배포→운영 검수→보고까지 마칩니다. 수정 릴리스의 코드/DB 버전을 함께 +0.01 하고 기존 다크 디자인을 유지합니다.
5. 원장과 날짜별 인수인계에 상태·증거·커밋·배포·남은 한계를 추가합니다. 실제 운영 검증 전 완료로 표시하지 않습니다.

## 이번 문서 작업의 검수·한계

최상단 규칙 일치·문서 링크·8건 상태와 기존 완료 범위 구분을 검토합니다. 기능 코드·버전·키·환경변수·DB 변경 및 유료 API 호출은 없습니다. 빌드·브라우저·8개 기능 검수를 이번에 실행한 것으로 기록하지 않습니다. 문서 커밋·푸시 결과는 이 파일의 최신 Git 이력과 루트 현황판에서 확인합니다.
