## 썸네일

- [전용 실사 이미지](assets/blog-content-maker-thumbnail.jpg): **1600×900, 16:9, JPEG**. 한국인 콘텐츠 제작자가 노트북에서 원고·이미지·점검 화면을 확인하는 장면입니다. 이미지 안에 문구·로고·워터마크가 없습니다.
- 기본 제공 `imagegen` 도구로 한 장 생성했습니다. 회원 DB의 AI 키를 조회하거나 별도 AI API 키를 입력하지 않았습니다. [최종 프롬프트](thumbnail-prompt-20261016.txt)를 보존했습니다. 생성 결과는 JPEG 출력 크기·압축만 조정했습니다.
- 기존 공개 버킷 `program-images`의 `catalog/blog-content-maker-thumbnail.jpg`에 업로드하고 캐시 갱신용 `?v=`를 붙였습니다. 공개 이미지 HTTP 200과 다운로드 바이트 일치를 확인했습니다. 파일 크기·해시·주소는 [이미지 반영 기록](catalog-thumbnail-release-20261016.json)에 있습니다. 회원 콘텐츠용 비공개 버킷과 구분됩니다.
- `scripts/publish-catalog-thumbnail.mjs`는 프로젝트와 기존 프로그램 ID를 확인하고 이미지 업로드·바이트 검증만 수행합니다. DB 메타데이터는 기록된 SQL로 한 번에 반영했습니다.
