## v1.02 검색 보완

초기 운영 검색 검사에서 Gemini의 JSON·검색 동시 요청이 실제 출처 메타데이터를 반환하지 않아 422로 차단됐습니다. 출처를 추측해 채우거나 다른 회원 키로 대체하지 않았습니다.

공식 [Google Search grounding](https://ai.google.dev/gemini-api/docs/generate-content/google-search)과 [구조화 출력](https://ai.google.dev/gemini-api/docs/structured-output)을 확인하고, 같은 회원·모델·키로 자연어 근거 조사 후 JSON 원고 구성 두 단계로 보완했습니다. 검색 출처·추천 검색어는 실제 첫 응답의 메타데이터만 보존합니다. 화면에 두 번 호출과 비용을 안내하며 검색 실패 시 중단합니다. 전체 요청은 검색 90초·구성 170초로 제한하고 개별 재시도도 원래 시간 예산을 공유합니다.

수정 후 실제 회원 Chrome에서 공식 문서 관련 제목 검색과 HTTPS 검색 출처 반환, 설정 복원·9개 모바일 화면·비로그인 차단을 포함한 14개 검사 통과. 코드·DB·확장은 v1.02로 함께 갱신합니다. 단위 10/10·린트·빌드 재통과.
