## 실제 Chrome — 일반 시험 회원

- 최초 전체 흐름 25개 검사 통과: 원고·이미지 실제 생성, 입력 원문 보존, 마지막 문장까지 저장·새로고침 복원, 과거 수정본 보존, 생성 전 이미지 점검 경고, 비공개 실제 이미지 URL, 변경 후 재점검, 없는/다른 프로젝트 404, 이전 수정본 저장 409, MD·이미지 ZIP 다운로드, 9개 화면 400px·메뉴 펼침·가로 넘침 없음, 비로그인 API 401.
- 원고 1회·이미지 1회는 **시험 회원 본인 Gemini 키**로 처리했습니다. 새 이미지가 실제 비공개 Storage 파일로 저장됐고 이전 점검이 오래된 상태로 바뀌는 것을 대조했습니다.

## 네이버 확장 실제 입력

연결 서버·발행 금지·기존 글 보호·부분 업로드 보호는 검사했습니다. 기본 Chrome에서 본인 네이버 로그인과 빈 글쓰기 화면까지 확인했습니다. 현재 자동화 환경에서 기본 Chrome 키보드 초점·화면 캡처를 얻지 못하며, 확장 설치의 Windows 폴더 선택 창도 입력 가능한 요소를 제공하지 않습니다. 실제 확장 로드·네이버 원고 입력 대조는 **검수 미완료**입니다. Chrome의 자동 실행 플래그로 확장이 로드됐다고 가정하지 않습니다.

추가 미디어 검사 21개 통과: 직접 그린 머그잔 참고 JPEG 업로드, 참고 이미지 합성 호출, 첫/끝 장면 계획 두 개·서로 다른 이미지 파일 생성, 참고 파일 보존, ZIP에 현재 장면 이미지 두 개만 포함 확인. 실제 판매 제품의 정밀한 형태 보존 품질은 별도 사람 검수가 필요합니다. 표는 확장에서 행별 텍스트로 입력하며 최종 발행은 회원이 직접 합니다.

## v1.02 검색 보완

초기 운영 검색 검사에서 Gemini의 JSON·검색 동시 요청이 실제 출처 메타데이터를 반환하지 않아 422로 차단됐습니다. 출처를 추측해 채우거나 다른 회원 키로 대체하지 않았습니다.

공식 [Google Search grounding](https://ai.google.dev/gemini-api/docs/generate-content/google-search)과 [구조화 출력](https://ai.google.dev/gemini-api/docs/structured-output)을 확인하고, 같은 회원·모델·키로 자연어 근거 조사 후 JSON 원고 구성 두 단계로 보완했습니다. 검색 출처·추천 검색어는 실제 첫 응답의 메타데이터만 보존합니다. 화면에 두 번 호출과 비용을 안내하며 검색 실패 시 중단합니다. 전체 요청은 검색 90초·구성 170초로 제한하고 개별 재시도도 원래 시간 예산을 공유합니다.

수정 후 실제 회원 Chrome에서 공식 문서 관련 제목 검색과 HTTPS 검색 출처 반환, 설정 복원·9개 모바일 화면·비로그인 차단을 포함한 14개 검사 통과. 코드·DB·확장은 v1.02로 함께 갱신합니다. 단위 10/10·린트·빌드 재통과.
