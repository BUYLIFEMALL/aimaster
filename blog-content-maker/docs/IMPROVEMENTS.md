# 💡 AI 블로그 콘텐츠 제작 자동화 (`blog-content-maker`) 개선사항 및 고도화 제안 (IMPROVEMENTS.md)

> **프로그램 공식 URL**: https://blog-content-maker.buylife.xyz  
> **현재 버전**: `v1.10`  
> **작성 일시**: 2026-10-18  
> **작성자**: Antigravity CLI (agy)

---

## 1. 프로그램 로직 및 기능 개선

1. **실시간 검색 트렌드 키워드 자동 주입 엔진**:
   - 현재 사용자가 직접 키워드를 입력하는 방식에 더하여, 네이버 데이터랩 및 구글 트렌드 급상승 검색어를 실시간으로 수집하여 관련 유망 롱테일 키워드를 1클릭으로 추천하는 추천 패널 도입.
2. **다양한 블로그 플랫폼 맞춤형 HTML/Markdown 렌더러**:
   - 현재 네이버 스마트에디터 최적화 중심에서 티스토리(Tistory), 워드프레스(WordPress), 벨로그(Velog) 맞춤형 서식 변환기(CSS 인라인 태그 자동 치환기)를 추가 제공하여 블로그 확장성 강화.
3. **글 분량 및 읽기 시간 동적 조절 옵션**:
   - AI 프롬프트 생성 파이프라인에서 기본 2,000자 외에 `숏폼 블로그(800자)`, `표준 리뷰형(1,500자)`, `심층 전문 분석형(3,500자 이상)`의 3단계 길이 선택 옵션을 제공하여 콘텐츠 목적별 최적화.

---

## 2. 사용자 인터페이스/UI 가독성 및 사용편리성 개선

1. **에디터 분할 뷰(Split View) 실시간 미리보기**:
   - 좌측에 프롬프트 및 설정 패널, 우측에 생성된 블로그 초안을 실시간 마크다운 렌더링으로 확인하고 즉시 수정할 수 있는 분할 뷰 레이아웃 도입.
2. **AI 본문 문단별 재작성(Regenerate) 퀵 버튼**:
   - 전체 글을 다시 생성하지 않고, 마음에 들지 않는 특정 소제목 문단만 마우스 호버 시 `🔄 이 문단 다시 쓰기` 버튼을 통해 부분 재생성할 수 있는 기능 추가.
3. **블로그 가독성 지수 점수화 대시보드 위젯**:
   - 글자 수, 문장 평균 길이, 키워드 반복 빈도, 소제목 개수를 분석하여 '검색 최적화 점수 (예: 92점)'를 실시간 원형 차트로 시각화.

## 3. 현재 구축된 타 자동화 프로그램과의 연계 제안

1. **76번 AI 썸네일 마스터 (`thumbnail-master`) 연계**:
   - 블로그 글 생성 완료 시 추출된 메인 제목과 핵심 키워드를 기반으로 76번 썸네일 마스터 API를 호출하여, 블로그 대표 썸네일(1:1 또는 16:9 비율)을 즉시 자동 생성하고 다운로드받을 수 있는 원클릭 연동 버튼 추가.
2. **80번 AI 블로그 4컷 만화 생성기 (`blog-4cut-toon`) 연계**:
   - 작성된 블로그 본문의 도입부 에피소드를 요약하여 80번 4컷 만화 생성기로 전송, 블로그 본문 중간에 삽입할 4컷 인스타툰/웹툰 컷을 생성하여 본문 체류 시간을 극대화.
3. **82번 AI 제품 리뷰 포토 에디터 (`product-review-photo-editor`) 연계**:
   - 제품 협찬/내돈내산 리뷰 블로그 작성 시 제품 사진을 보정하고 장단점 인포그래픽 텍스트를 오버레이한 이미지를 블로그 본문 각 소제목에 자동 매칭.
