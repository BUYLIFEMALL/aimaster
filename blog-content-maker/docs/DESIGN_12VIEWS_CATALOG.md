## 1. 개요 및 스타일 선정 이유
- **프로그램 성격:** 키워드 발굴부터 개요, 본문 집필, 팩트/후기 검증, 네이버 스마트에디터 ONE 자동 연동까지 5단계 파이프라인으로 네이버 블로그 콘텐츠를 완성하는 전문 제작 도구.
- **선정 템플릿:** **18. 네이버 스마트 그린 저널 스타일**
- **선정 이유:** 네이버 공식 시그니처 그린(`#03c75a`)과 깨끗한 화이트/슬레이트 카드 구조를 결합하여 네이버 블로그 생태계와의 일체감과 가독성을 극대화함. 기존의 칙칙하고 어두운 암녹색을 완전히 걷어내고 밝고 신뢰감 높은 네이버 고유의 그린 톤을 정확히 구현함.

## 2. 4대 화면 3시안 매트릭스 (총 12뷰)

| 화면 구분 | 시안 1: 네이버 스마트 그린 (확정 채택) | 시안 2: 다크 레이더 프로 | 시안 3: 파이프라인 위저드 |
| :--- | :--- | :--- | :--- |
| **1. 메인 (Home/글감)** | 산뜻한 네이버 그린(`#03c75a`) 헤더, 5단계 프로그레스 바, 실시간 트렌드 키워드 레이더 | 딥 블랙 다크모드(`#0f172a`), 네온 그린 포인트, 분석 레이더 차트 | 모던 스텝 인디케이터, 카드형 대형 위저드 레이아웃 |
| **2. 상세 (Editor/원고)** | 마크다운/스마트에디터 ONE 듀얼 프리뷰, 팩트체크 충족률 게이지, 네이버 맞춤 태그 클라우드 | 코드형 분할 에디터, 실시간 키워드 밀도 분석 터미널 | 타임라인 기반 버전 히스토리, 섹션 블록 편집기 |
| **3. 매뉴얼 (Guide)** | 5단계 파이프라인 인터랙티브 인포그래픽, 확장 연동 튜토리얼 탭 | 다크 인터랙티브 아키텍처 다이어그램, 단축키 치트시트 | 카드 슬라이드형 퀵스타트 가이드 |
| **4. 설정 (Settings)** | 원클릭 API 키 관리, 네이버 블로그 스마트 연동 토큰 발급, 자동 백업 설정 | 보안 볼트형 마스터 키 관리, 실시간 웹훅 모니터링 | 단계별 계정 연동 마법사, 플랫폼 권한 설정 폼 |

## 3. 핵심 기능 및 UI 업그레이드 내역 (v1.13)
1. **네이버 시그니처 그린(`#03c75a`) 전면 보정**:
   - 기존의 짙은 암녹색(`#059669`)을 네이버 공식 시그니처 비비드 그린(`#03c75a`) 및 소프트 틴트(`#edfbf3`)로 브랜드 토큰 전면 교체.
2. **사이드바 및 핵심 액션 3D 엠보싱 버튼 탑재**:
   - 사이드바 `.nav-download` (확장 프로그램 받기): 2단 수직 그라데이션(`linear-gradient(180deg, #04e065 0%, #03c75a 100%)`)과 하단 입체 그림자(`0 4px 0 #029f45`) 장착.
   - 5단계 전송 `.btn-3d-naver`: 스마트에디터 ONE 자동 전송 3D 엠보싱 버튼 장착.
3. **블로그 핵심 지침: 3종 포스팅 모드 선택 칩셋 탑재**:
   - 5단계(완성 원고 가져가기) 화면에 회원이 직접 포스팅 방식을 선택할 수 있는 3종 라디오 칩셋 탑재:
     - 📝 **발행 전까지**: 스마트에디터에 자동 입력만 완료하고 회원이 최종 검토 후 수동 발행
     - ⚡ **즉시 포스팅**: 자동 입력 후 즉시 발행 버튼 클릭 및 등록 URL 자동 수집
     - ⏰ **예약 포스팅**: 지정한 날짜 및 시간에 맞춰 네이버 블로그에 자동 예약 등록
4. **확장 프로그램 v1.13 동기화**:
   - `manifest.json` 버전 1.13.0 동기화 및 최신 ZIP 아카이브 자동 빌드 완료.
