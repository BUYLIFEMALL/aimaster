## 4. 그대로 가져오면 안 되는 동작·설명

1. **점검 충족률을 네이버 점수처럼 표시**: 원본 점수는 `통과 항목 수 / 전체 항목 수 × 100`이며 실제 검색 평가 API의 결과가 아닙니다. 일부 항목만 코드로 다시 계산하고 나머지는 AI 응답을 사용합니다.
2. **이미지 개수를 실제 생성 성공으로 오인**: 일부 검사는 본문의 이미지 자리표시자 수를 셉니다. 새 앱은 실제 저장 자산·삽입 위치·필요 개수를 대조합니다.
3. **수치가 있으면 근거가 있다고 판정**: 숫자 등장 횟수나 ‘최신’ 문구 포함은 사실성·최신성 증명이 아닙니다. 출처 확인과 분리합니다.
4. **영상 생성이라고 소개**: 확인한 앱 기능 호출 범위에서 동영상 생성 API 호출을 찾지 못했고, 장면 이미지 준비 흐름을 확인했습니다. 미확인된 기능까지 없다고 단정하지 않습니다.
5. **가상 경험을 실제 후기처럼 사용**: 원본에는 그럴듯한 1인칭 경험 제안 요청이 있습니다. 새 앱은 회원 경험을 묻는 질문·입력 예시만 제안하고 확인 전에는 본문 사실로 넣지 않습니다.
6. **고정 연도·제품명·모델 가격 재사용**: 원본에는 2025/2026, 과거 제품 예시, 모델·가격 상수가 있습니다. 새 앱은 동적 현재 날짜와 검증된 자료를 쓰고, 가격·모델은 구현 시 공식 문서로 다시 확인합니다.
7. **키 저장 시 숨은 유료 진단**: 원본의 티어 판별은 검색 도구를 넣은 실제 호출을 사용합니다. 새 앱은 회원이 요청한 연결 확인과 실제 생성 작업을 구분합니다.
8. **원본 로컬 인증·업데이트·설정 복사**: 원본에는 별도 인증 화면과 로컬 설정 처리가 있습니다. 이를 해제하거나 옮기지 않고 AIMaster의 회원·프로그램 권한으로 새로 구성합니다.
9. **브랜드만 치환한 코드 이식**: 원본 코드·가이드 전문·프롬프트·아이콘을 그대로 가져오지 않습니다. 기능 계약을 바탕으로 우리 코드·문구·디자인으로 작성합니다.
