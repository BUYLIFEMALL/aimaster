# AI 블로그 콘텐츠 제작 자동화 — 개발 전 계획

현재 상태: **프로그램명 확정, 정적 분석·개발 계획 작성 완료, 개발안 검토 대기**. 주인님이 2026-10-15 프로그램명을 「AI 블로그 콘텐츠 제작 자동화」로 확정했습니다. 폴더·slug는 `blog-content-maker`입니다. 실행 가능한 앱·확장·운영 배포는 아직 없습니다.

주제 또는 기존 원고를 받아 제목·본문·이미지를 만들고, 근거와 표현을 점검한 뒤 회원이 네이버 편집기로 옮겨 완성하는 AIMaster 서브프로그램을 제안합니다. 처음 공개하는 버전은 `v1.01`입니다.

- [개발 계획·확정 프로그램 정보](docs/DEVELOPMENT_PLAN.md)
- [배포 파일 정적 분석 결과와 근거](docs/REFERENCE_ANALYSIS.md)
- [에이전트 인수인계](AGENTS.md)

분석 대상의 실행 파일·번들·아이콘·원문 프롬프트는 이 폴더에 넣지 않았습니다. 분석은 파일 읽기·압축 해제·문법 분석으로 진행했으며 설치 파일이나 앱을 실행하지 않았습니다. 원본의 이름·제작자 표시·홍보 링크·인증 체계는 새 앱에 가져오지 않습니다.

예정 흐름은 **글감·제목 → 원고 만들기 → 글 점검 → 이미지·장면 준비 → 네이버로 옮기기**입니다. 작업 보관함과 API키등록·플랫폼연동을 함께 제공합니다. 모든 외부 AI 호출은 회원 본인 키로만 처리합니다.

현재는 문서만 있는 폴더입니다. 여기에서 `npm run build`를 실행하면 상위 AIMaster의 명령이 실행될 수 있으므로 앱 검수로 사용하면 안 됩니다. 앱 코드 작성·DB 구조 변경·환경변수 등록·프로그램 등록·배포는 아직 진행하지 않았습니다.
