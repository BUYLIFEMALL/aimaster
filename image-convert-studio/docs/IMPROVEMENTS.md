## 1. 필수 3대 개선 과제 리포팅

### 1) 프로그램 로직 및 기능 개선
- **Web Worker 기반 병렬 변환 파이프라인 도입**:
  - 현재 pica 리사이저는 번들러 환경 호환성 문제로 워커 대신 메인 스레드(JS/WASM)로 처리되고 있음. 대용량 300장 일괄 변환 시 브라우저 메인 스레드의 UI 프레임 드랍을 원천 방지하기 위해, 순수 Web Worker(또는 Comlink 기반 격리 워커 스레드)로 백그라운드 병렬 렌더링을 처리하는 하이브리드 엔진 도입 제안.
- **EXIF 메타데이터 보존/삭제 선택 토글 기능**:
  - 현재 캔버스 기반 변환 특성상 사진의 EXIF(촬영 날짜, 위치, 카메라 설정)가 제거됨. 개인정보 보호 차원에서는 이점이 있으나, 사진 작가나 블로거 중 촬영 정보 보존을 원하는 사용자를 위해 piexifjs 등을 활용한 "EXIF 메타데이터 보존" 옵션 토글 추가 권장.
- **SVG / ICO 포맷 확장**:
  - 웹 개발자 및 파비콘 제작자를 위해 `.ico` 멀티 사이즈 변환 및 SVG ➔ 래스터(PNG/WebP) 고화질 래스터라이징 도구 추가.

### 2) 사용자 인터페이스/UI 가독성 및 사용편리성 개선
- **변환 전/후 실시간 스플릿 슬라이더(Split Compare Slider) 뷰어**:
  - 이미지를 변환한 후 원본과 변환본의 화질 및 디테일을 반반 나누어 비교해 볼 수 있는 인터랙티브 비포/애프터 비교 뷰어 컴포넌트 추가 제안.
- **이미지 간단 회전 / 자르기(Crop) 모달**:
  - 변환 전 각 이미지 카드의 썸네일에서 90도 회전, 좌우 반전, 1:1 / 16:9 규격 프리셋 자르기를 빠르게 적용할 수 있는 퀵 편집 모달 지원.
- **드롭존 드래그 순서 재배치(DnD) 지원**:
  - 콜라주 툴에서 화살표 버튼 외에도 HTML5 Drag & Drop으로 카드를 직접 끌어다 원하는 위치로 바꿀 수 있는 직관적인 드래그 순서 재배치 기능 구현.

### 3) 현재 만들어져 있는 다른 자동화 프로그램과의 연계가능한 기능
- **AI 이미지 스튜디오 (`ai-image-studio`, 34번) 연계**:
  - `ai-image-studio`에서 생성된 고해상도 생성 이미지를 다운로드하지 않고 [이미지 변환 스튜디오로 보내기] 버튼 한 번으로 원클릭 전송하여 WebP 고효율 압축 및 콜라주 제작 파이프라인 완성.
- **AI 4컷 만화 자동화 (`four-cut-comics`, 81번) 연계**:
  - 4컷 만화에서 생성된 4개의 패널 이미지를 이미지 변환 스튜디오의 콜라주 툴로 불러와 2×2, 4단 세로 스크롤 웹툰 등 다양한 레이아웃의 고해상도 한 장 이미지로 병합 출력.
- **네이버 블로그 올인원 / 티스토리 생성 자동화 (`naver-blog-allinone`, `tistory-auto-blog`) 연계**:
  - 블로그 본문에 삽입될 수십 장의 무거운 카메라 사진들을 블로그 업로드 전 본 스튜디오에서 일괄 85% WebP 압축하여 블로그 검색엔진 LCP 로딩 속도를 극대화할 수 있도록 연계 안내 배너 제공.

## 2. 타 프로그램 탐색 기반 추가개선 제안

### 1) AI 상세페이지 자동화 (`shop-detail-page`, 7번)
- **개선점**: 15단 상세페이지 섹션을 개별 이미지로 내보낸 후 한 장의 롱 이미지(Long Image)로 합치는 기능이 있으나, 본 `image-convert-studio`의 세로(Vertical) 콜라주 엔진과 코드 공유(`docs/SHARED_MODULES.md`)를 통해 캔버스 렌더링 안정성을 공용화할 수 있음.

### 2) 썸네일 마스터 / AI 유튜브 썸네일 프로 (`seo-thumbnail-pro`, 22번)
- **개선점**: 유튜브 권장 규격인 1280×720(16:9, 2MB 이하)을 본 변환 스튜디오의 '유튜브 썸네일 맞춤 1-Click 프리셋'으로 등록하여, 크기 제한(1280×720)과 용량 자동 제한(2MB 미만 자동 압축)을 원클릭으로 제공하는 프리셋 버튼 탑재 제안.
