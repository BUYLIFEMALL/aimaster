## 4. 결정 항목(주인님/Master)

1. **법적 경계(가장 중요)**: 매물 알림 행은 **다른 중개사가 올린 매물**이다. 내 사무소가 의뢰받지 않은 매물을 「광고 중」 내 매물로 등록해 고객에게 광고 문자를 보내면 공인중개사법상 표시·광고 규정(의뢰받은 중개대상물만 광고) 위반 소지. 추천: 후보로 들어온 매물은 저장 시 **「의뢰를 직접 받은 매물입니다」 확인란을 체크해야 등록**되게 하거나, 새 상태 「후보(광고 불가)」를 둠(→ DB 상태 값 추가 = DB 변경 승인). 추천은 확인란(DB 변경 없음).
2. 주소 수준: 결과에 지번 주소가 없어 「시군구 동 단지명」만 채움 — 회원 보완으로 충분한지.
3. 중복 기준: 위 휴리스틱(경고만)으로 충분한지, 아니면 출처 칸(`source_ref`, 네이버 매물 번호) 추가(DB 변경)로 정확히 막을지. 추천: 경고만(매물 번호는 넘기지 않는 원칙 유지).
4. 버튼 위치: `/results` 새 매물 행만 vs 변동 기록 탭까지.
