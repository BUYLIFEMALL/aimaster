## 1. 이미지 보관 — 「실제 발행된 구글 블로그 이미지만 발행일부터 1년」
지금: 구글 블로그 발행·**예약** 글이면 `keep_images=true` → 30일 뒤 본문만 비우고 이미지는 **무기한** 보관. → 바꿔야 함.

| 대상 | 바꾼 뒤 |
|---|---|
| 구글 블로그 **실제 발행** 글 | 이미지 만료 = 실제 발행일 + 1년. 본문은 지금처럼 30일 뒤 비움. 1년 뒤 이미지·기록 삭제 |
| 구글 블로그 **예약** 글 | 예약만으로는 1년을 주지 않음. 예약 시각이 지나면 블로그 API로 **실제 발행 여부를 읽어 확인**한 뒤에만 「발행됨」+1년 |
| 초안·미발행·워드프레스·실패·확인 필요 | 기본 30일 그대로 (워드프레스는 이미지를 워드프레스 미디어로 올리므로 보관 불필요) |
| 관리자·시험 계정(`retention_exempt`) | 지금처럼 삭제 제외 |

구현:
- DB 마이그레이션 `20261111120000_wba_image_retention.sql`: 칸 `image_expires_at timestamptz` 추가, `wba_cleanup()` 고침 — (가) `keep_images` 행의 본문 30일 비우기는 유지 (나) `image_expires_at < now()`인 행은 이미지 경로를 돌려주고 삭제 (다) 나머지 만료 행 삭제는 그대로. 기존 행 보정: 구글 블로그 `published` + `keep_images` → `image_expires_at = published_at + 1년`, `scheduled` + `keep_images` → `keep_images=false`(확인 뒤 다시 켬).
- 코드: `keepPublishedImages`에서 `scheduled` 제외, 발행 성공·「올라갔어요」 정리 때 `image_expires_at` 기록.
- **예약 확인(새 기능)**: 매일 정리 호출(03:50 KST) 때 예약 시각이 지난 구글 블로그 예약 글을 회원 본인 연결로 **읽기만**(`posts.get`, 상태 LIVE인지) → LIVE면 `published`·`published_at=실제 시각`·`keep_images=true`·+1년. 확인 실패면 그대로 두고 다음 날 다시(자동 재발행 없음). 워드프레스 예약 글도 같은 방식으로 상태만 「발행됨」으로 맞춤(대시보드 숫자 정확).
- **장기 예약 대책**: 원고 만료(만든 날+30일)보다 늦은 예약은 이미지가 먼저 지워져 깨질 수 있음 → 예약 시각을 「원고 만료 1일 전」까지로 제한하고 화면에 안내(결정 항목 1).
- 문서: `docs/TOP_RULE_PERSONAL_ACCOUNT_API.md` §8 지정 줄을 「발행 이미지 1년」으로 고침.
- 경계 시험(DB 쓰지 않는 단위 시험): 발행 364일·366일, 예약 미확인, 예약 확인 뒤 1년, 시험 계정 제외, 워드프레스 30일.

## 2. 발행 화면 — 카테고리·선택값 유지
- 카테고리 불러오기 실패 시 「불러오지 못했습니다 — 다시 불러오기」 버튼, 불러오는 중 표시가 끝나지 않는 문제 수정.
- 원고 저장 뒤 화면이 다시 그려져도 카테고리·발행 방식·예약 시각·이미지 수 선택이 남도록(편집 화면 상태를 원고별로 유지).

## 3. 이미 보낸 초안을 그대로 발행·예약으로 바꾸기 (권장: 복제보다 전환)
지금: 초안으로 한 번 보내면 같은 원고로 예약·발행이 막힘(409), 예약 취소 뒤 재예약도 막힘.
- 「블로그에 초안으로 있음」 상태에서 **바로 발행 / 예약** 버튼을 보여 주고, 새 글을 만들지 않고 **같은 글(remote_id)의 상태만 바꿈** — 워드프레스: `POST /posts/{id}` status `publish`/`future`+날짜, 구글 블로그: `posts/{id}/publish`(`publishDate`로 예약).
- 중복 방지 유지: 같은 행 조건부 잠금(publishing) 그대로, 상태가 `draft`이고 remote_id가 있을 때만 전환 허용, 결과 불확실이면 「확인 필요」, 자동 재시도 없음.
- 원고 복제는 하지 않음(블로그에 같은 글이 두 개 생길 수 있어 회원 혼란).
