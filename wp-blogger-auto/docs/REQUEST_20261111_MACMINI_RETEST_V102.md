## 1. v1.02에서 바뀐 것(검수 대상)
1. 블로그에 초안으로 올라간 원고 → 편집 화면 「발행 결과」에서 **⚡ 바로 발행 / ⏰ 예약 발행**으로 전환(새 글을 만들지 않고 같은 글 상태만 바꿈).
2. 예약 날짜 상한 = **원고 보관 만료(만든 날+30일) 하루 전** — 입력 칸 max와 서버 양쪽에서 막음(서버 오류 코드 `schedule_too_late`).
3. 이미지 보관: 구글 블로그 **실제 발행** 글 이미지만 발행일+1년, 예약 대기·초안·실패·확인 필요·워드프레스 사본은 30일. 예약 글은 매일 03:50(한국 시간) 「예약 확인」이 실제 공개를 읽어 확인한 뒤에만 「발행됨」+1년.
4. 카테고리(워드프레스): 불러오는 중 표시, 실패 시 「다시 불러오기」 버튼.
5. 발행 방식·예약 시각·카테고리·이미지 수 선택이 저장·새로고침 뒤에도 원고별로 남음(같은 브라우저 탭).
6. 보관함: 조회 오류 시 빈 목록 대신 「불러오지 못했습니다 — 새로고침」.
7. 좌측 메뉴(휴대폰 767px 이하는 ☰).
