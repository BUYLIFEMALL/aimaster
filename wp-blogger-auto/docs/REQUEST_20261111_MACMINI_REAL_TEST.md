## 0. 먼저 알아 둘 것
- **비공개 프로그램이라 시험 계정(`buylifemall@naver.com`)은 들어갈 수 없다**(권한 판정이 `programs.is_active=true`만 찾음 → 메인 사이트 프로그램 주소로 이동하고 「찾을 수 없음」). 공개 전 시험은 **관리자 계정 `buylifemall@gmail.com`**으로 한다. 공개 뒤 시험 계정으로 한 번 더 본다.
- 이 프로그램은 확장 없이 **공식 API로 서버가 직접 발행**한다(워드프레스 REST API + 응용 비밀번호, 구글 블로그 Blogger API v3 + 회원 본인 구글 OAuth 앱). 블로그 핵심 지침의 「공식 API 예외」(2026-11-10 주인님 결정).
- 포스팅 방식 세 가지: **초안(발행 전까지)** · **바로 발행** · **예약 발행**. 결과가 불확실하면 「확인 필요」로 남고 자동으로 다시 보내지 않는다.
- 원고 기본 AI는 Claude Sonnet 5.5, 이미지는 Gemini(나노바나나). 모두 로그인한 회원 본인 키(`user_api_keys`)로 호출된다.

## 역할 나눔
- **맥미니**: 실물 시험·재현·디버깅(코드 수정 가능)·결과 기록.
- **윈도우 블로그 세션**: 빌드·배포·운영 DB·환경변수. 맥미니가 코드를 고치면 커밋 해시를 알려 주면 다음 배포에 싣는다(작은 수정은 모아서 배포).
- 맥미니가 `wp-blogger-auto/`를 고치는 동안 윈도우는 이 폴더를 수정하지 않는다. 시작할 때 `docs/ACTIVE_WORK.md`에 맥미니 줄을 넣는다.

## 1. 준비 (주인님과 함께)
1. **구글 시험 블로그 새로 만들기**(2026-11-10 주인님 결정): 관리자 구글 계정으로 https://www.blogger.com 에서 시험용 블로그 1개 생성(이름 예: 「AIMaster 시험 블로그」).
2. **구글 OAuth 앱 키**: 관리자 계정에 `google_client_id`·`google_client_secret`가 메인 사이트 https://www.buylife.xyz/api-settings 에 있는지 프로그램 「AI 키·모델」(`/settings`)에서 「등록됨」으로 확인. 없으면 주인님이 등록(유튜브 자동화와 같은 키). 구글 콘솔의 그 OAuth 클라이언트 「승인된 리디렉션 URI」에 **`https://wp-blogger-auto.buylife.xyz/api/oauth/google/callback`** 이 있어야 한다(없으면 주인님이 추가). Blogger API가 사용 설정돼 있어야 한다.
3. **워드프레스 시험 사이트**: https 로 열리는 워드프레스 사이트 1개(카페24 등). 관리자 화면 → 사용자 → 프로필 → 「응용 프로그램 비밀번호」 발급(주인님이 직접 입력).
4. `anthropic`·`gemini` 키 등록 여부를 `/settings`에서 확인.

## 2. 연결 시험 (`/connect`)
1. 워드프레스 카드: 사이트 주소·아이디·응용 비밀번호 입력 → 「연결」 → 사이트 이름이 보이고 「연결됨」인지. 틀린 비밀번호·http 주소·없는 주소일 때 쉬운 한국어 오류가 나오는지.
2. 구글 블로그 카드: 「구글로 연결」 → 동의 화면 → 돌아오면 내 블로그 목록에서 1번에서 만든 시험 블로그 선택 → 「연결됨」인지.
3. 두 카드 모두 「연결 해제」 → 다시 연결이 되는지(해제는 시험 마지막에 한 번만).

## 3. 원고·이미지 (비용 — 주인님 승인 뒤)
- 원고 1건 생성(`/write`, 기본 모델 Sonnet 5.5, 회원 키 약 0.05달러 안팎) + 대표 이미지 1장(약 0.04달러). **승인 전에는 기존 원고만 쓴다**(관리자 계정에 2026-11-10 시험 원고 있음 — `/posts`).
- 편집 화면에서 제목·본문 수정 저장, 이미지가 본문에 들어갔는지 확인.

## 4. 발행 시험 — 블로그마다 같은 순서
| 순서 | 방식 | 확인할 것 |
|---|---|---|
| 1 | **초안** | 보관함 상태 「초안」, 블로그 관리 화면 임시글에 같은 제목·본문·이미지. 공개 화면에는 안 보임 |
| 2 | **예약 → 취소** | 30분 뒤 예약 → 상태 「예약」·시각 표시, 블로그에 예약글 존재 → 프로그램에서 「예약 취소」 → 블로그 예약글이 사라지거나 임시글로 돌아가는지, 상태가 되돌아오는지 |
| 3 | **바로 발행** | 상태 「발행됨」, 「열기 ↗」 주소가 실제 공개 글로 열림, 이미지 깨짐 없음(구글 블로그는 이미지가 우리 저장소 주소이므로 30일 정리 뒤에도 보관되는지 — `keep_images`) |
| 4 | **불확실 처리** | 발행 중 네트워크를 끊거나 창을 닫아 「확인 필요」가 생기면: 자동 재발행이 없는지, 「올라갔음/안 올라갔음」 정리 버튼이 동작하는지 |

- 대시보드(`/dashboard`) 숫자·다음 예약 시각이 보관함과 맞는지.
- 휴대폰 폭(390px)에서 상단 메뉴 ☰가 열리고 연결·발행 화면을 쓸 수 있는지.

## 5. 하지 않는 것

- 비밀번호·키·응용 비밀번호를 입력하거나 기록하지 않는다(주인님이 직접).
- 「확인 필요」 원고를 자동으로 다시 보내지 않는다.
- 빌드·배포·운영 DB 쓰기는 하지 않는다(윈도우 몫).
