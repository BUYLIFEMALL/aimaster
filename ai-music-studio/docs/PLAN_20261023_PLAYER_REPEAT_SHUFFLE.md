# 플랜 — 미니 플레이어 반복·무작위 재생 (2026-10-23, Claude Code 윈도우 · 세션 claude-win-20261023-bgm)

주인님 지시: 「이것부터 해보자」 → 「제안한건 작업 대기 리스트에 올려 순차적으로 진행하자」(제안 가~라를 하나씩, 배포는 미배포 대기로 모아 함께).

## 문제
v1.11 미니 플레이어는 곡이 끝나면 화면에 보이는 다음 곡으로만 넘어가고 마지막 곡에서 멈춘다. 한 곡을 계속 듣거나 섞어 듣는 방법이 없다.

## 만들 것
| 버튼 | 누를 때마다 | 동작 |
|---|---|---|
| 반복 | 끔 → 목록 반복 → 한 곡 반복 → 끔 | 끔: 마지막 곡에서 멈춤 / 목록 반복: 마지막 다음 첫 곡 / 한 곡 반복: 같은 곡 다시 |
| 무작위 | 켜기 ↔ 끄기 | 다음 곡을 지금 곡을 뺀 나머지에서 무작위로. 「이전 곡」은 실제로 들었던 곡으로 |

- 「다음 곡」 버튼을 직접 누르면 한 곡 반복이어도 다음 곡으로 넘어간다(한 곡 반복은 곡이 끝났을 때만).
- 설정은 이 브라우저 `localStorage`(`ams-player-mode`, try/catch)에만 기억. 서버 저장 없음.

## 구현 순서
1. `lib/playerOrder.ts` 순수 함수(`pickNext`·`pickPrev`·`nextRepeat`) → `tests/playerOrder.test.mjs`
2. `components/player/PlayerProvider.tsx` 상태·들은 곡 기록
3. `components/player/MiniPlayer.tsx` 버튼 2개(휴대폰 폭 한 줄)
4. 문서·커밋, 미배포 대기 등록

## 검수·비용
- 시험·tsc·build(무료). 화면 확인은 다음 배포 뒤 크롬 + 주인님 소리 확인.
- 비용: 개발 없음. 배포는 제안 가~라를 모은 뒤 빌드 1회(그때 사전 승인).
