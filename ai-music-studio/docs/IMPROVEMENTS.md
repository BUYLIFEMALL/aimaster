## 2. UI/UX·가독성·편의성
- 모델 카드 11개가 길다 → 「추천 3개」 묶음 + 「모두 보기」 접기, 보유 키 있는 모델 먼저.
- 비교 결과에 「이 곡 고르기(별 표시)」와 메모, 보관함 정렬(모델별·별 표시).
- 진행 중 카드에 공급자별 평균 소요 시간 표시.
- 설정 화면: 키 「연결 확인」 버튼(무료 조회 API — Suno 크레딧, Replicate 계정 등).

## 3. 다른 자동화 프로그램과 연계
- **가사 영상 자동화**(`lyric-video-studio`): 지금은 음악(SUNO)자동화 변주 번호(`?suno=`)만 받는다 → `?ams=<생성 id>` 받기를 추가하면 Lyria 시간 가사까지 넘길 수 있음(양쪽 수정·배포 필요).
- **YOUTUBE 플레이리스트 자동화**(`playlist-channel-studio`): 같은 방식으로 여러 곡 넘기기.
- **AI 마스터링 스튜디오**: 내려받은 WAV를 바로 마스터링(링크만으로 가능).
- **쇼츠·뮤직비디오 프로그램**: 배경음악 모델 선택을 이 프로그램의 어댑터(공용 기준 코드화)로 통일 — Suno 하나에 묶인 곳(쇼츠 이미지 스토리 등)의 대체 수단.
