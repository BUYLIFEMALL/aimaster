# AI 음악 스튜디오 — 디자인 리뉴얼 플랜 (2026-10-23, Claude Code 윈도우 · 세션 claude-win-20261023-bgm)

주인님 지시: 「디자인 리뉴얼 너가 맡아서 진행해」(음악 작업 담당). 이 문서는 **승인 전 플랜**이다 — 구현은 주인님 승인 뒤.

## 1. 현재 상태 분석 (v1.10)

## 2. 적용 템플릿 (제안)
- **그룹 B 「미디어 사운드 & 하이테크 오디오 콘솔」** 안에서 새 변형 **「사운드 랩 바이올렛 스타일」**(Sound Lab Violet).
- 바탕은 지금 그대로 다크 `#09090b`·바이올렛 `#8b5cf6`(가사영상 자동화와 같은 계열 — 음악 → 가사영상 연결 시 이질감 없음), 보조 강조 시안 `#22d3ee`(재생·진행 표시).
- 시그니처: 곡 카드의 **파형 막대(모델 색)**, 화면 아래 **고정 미니 플레이어**, 모델(공급자)별 색 배지.
- 모든 화면(만들기·비교·보관함·안내·설정·로그인) 같은 배경·카드·테두리·글자 대비(지침 ⑪).

## 3. 구현 범위 (승인 뒤 순서대로)
1. **공통 토큰·레이아웃** — `globals.css` 색 토큰 정리, 카드·버튼·칩 공통 클래스, 사이드바(아이콘·현재 메뉴 표시, 계정 위치 표준 유지).
2. **곡 만들기** — 데스크톱 2열: 왼쪽 입력 단계(①모델 ②설명 ③가사·옵션), 오른쪽 **고정 요약 패널**(고른 모델·길이·형식·예상 비용·「음악 만들기」 버튼·최근 진행 중 곡). 휴대폰은 아래 고정 버튼 막대. 모델 카드에 공급자 색·아이콘·「보컬/연주」「최대 길이」 칩.
3. **보관함** — 곡 카드에 파형 막대·모델 색, 필터 칩 정리, **아래 고정 미니 플레이어**(카드의 재생 버튼 → 한 플레이어로 이어 듣기, 다음 곡).
4. **비교** — 모델별 나란히 열(휴대폰은 탭), 같은 위치에서 번갈아 듣기 버튼.
5. **안내(매뉴얼)** — 매뉴얼 지침 규격으로 다시 만들기: 헤더 메타바(소요 시간·콘솔 링크), 개요 히어로, **Step 1~4 시각 카드**, 공급자별 키 발급 상세(콘솔 직링크·1초 복사), 💡팁·⚠️주의 배너, FAQ.
6. **로그인** — 디자인 메인 원문의 표준 2탭 레이아웃 확인·맞춤.
7. **모바일(767px 이하)** — ☰ 메뉴·계정 접근, 가로 넘침 0, 고정 버튼이 본문을 가리지 않는지.

동작(생성·저장·링크·키)은 바꾸지 않는다 — 화면만. 기존 시험 33개 유지.

## 4. 검수
- 로컬: tsc·시험·build, `node scripts/check-mobile-account.mjs`.
- 크롬(주인님 메인 크롬, 시험 계정): 데스크톱·390px 폭에서 6개 화면, 메뉴 펼침·계정, 곡 만들기 1회 흐름(생성은 하지 않고 버튼·요약까지), 미니 플레이어로 기존 곡 재생.
- ⚠️ 크롬 창이 숨김이면 화면 캡처가 안 됨(2026-10-23 실측) — 검수 때 크롬 창을 앞에 띄워 주셔야 함.
