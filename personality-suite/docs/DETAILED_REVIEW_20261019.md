## 현재 기능과 보존할 장점

일·연애·갈등·학습·여행 같은 상황별 16유형 검사 10종과 성격 5요인·행동 스타일·애착·에니어그램·기질 검사, 스트레스·마음 상태 자기점검을 한 문항씩 풀면 점수·강점·주의할 점·활용 팁이 바로 나옵니다. / 같은 검사를 다시 하면 지난 결과와 비교해 주고, 종합 프로필에서는 검사별 반영 비중을 골라 시기별 변화 그래프와 2주 실천 계획을 받습니다. / 결과마다 AI 심층 분석(강점·성장 조언·잘 맞는 환경·관계 팁)을 받고, PNG 이미지나 PDF로 저장합니다.

**보존할 장점:** 다양한 자기점검·종합 결과

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
