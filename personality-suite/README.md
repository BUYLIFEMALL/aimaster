# AI 종합 성격 진단 자동화 (personality-suite)

AIMaster의 다기능 종합 성격 및 심리 진단 자동화 프로그램입니다.

- **서비스 URL**: `https://personality-suite.buylife.xyz`
- **현재 버전**: `v1.20`
- **적용 테마**: **크리에이티브 아틀리에 스타일 — 파스텔 퍼스널리티 종합 진단 에디션**

## 주요 기능
1. **상황별 16유형 및 심리 검사 스위트 (16종)**:
   - 일상·직무·연애 등 다양한 상황별 16유형 검사.
   - 성격 5요인(Big 5), 행동 스타일, 애착 유형, 에니어그램, 기질 및 성향 검사.
   - 마음 상태(스트레스·번아웃) 민감 정보 분리 자기점검.
2. **AI 심층 분석 & 융합 종합 프로필**:
   - 2종 이상의 검사 결과를 교차 분석하여 단일 입체 리포트를 생성하는 종합 프로필.
   - 회원 본인의 Google Gemini API 키 연동 기반 AI 심층 맞춤 피드백.
3. **시계열 비교 & 통계**:
   - 이전 검사 결과와의 변화 추이 비교 및 누적 이력 보관.
