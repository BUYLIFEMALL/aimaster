# AI 쿠팡 운영 자동화 (`coupang-ops`)

쿠팡 공식 WING Open API(판매자 본인 키, 「자체개발」)로 상품 등록부터 주문·송장·문의까지 처리하는 AIMaster 서브 프로그램입니다.

- 주소(예정): https://coupang-ops.buylife.xyz
- 개발 실행: `npm install` → `npm run dev`(포트 3078)
