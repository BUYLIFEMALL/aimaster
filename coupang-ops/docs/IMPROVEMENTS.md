# coupang-ops 개선 제안

작업 대기 체크리스트는 [`IMPROVEMENT_BACKLOG.md`](IMPROVEMENT_BACKLOG.md)입니다. 여기 있는 제안은 구현 승인이 아닙니다.

## 1. 프로그램 로직·기능
- 쓰기 기능 실제 시험(S7): 실제 건이 생긴 뒤 건별 승인.
- 품절 임박 자동 알림, 예약 가격·판매 중지, 출고중지·미답변 수시 알림(R9·R10): 회원 본인 Fixie 호출을 쓰므로 회원이 켠 경우만.
- 이미지·옵션 구성 수정: 상품 수정 본문을 쿠팡이 받는지 확인한 뒤.
- 쿠팡 응답의 키 만료일 조회 가능 여부 확인(가능하면 수동 입력을 줄임).

## 2. UI·사용 편의
- Fixie 대시보드 실제 화면을 보고 매뉴얼에 캡처와 정확한 메뉴를 추가.
- 첫 화면 호출 수가 무료 한도에 가까우면 색으로 표시.

## 3. 다른 프로그램과 연계
- 고정 IP 프록시 공용 키를 토스 등 허용 IP가 필요한 다른 프로그램으로 확대.
- 상세페이지 자동화에서 쿠팡 등록 화면으로 바로 넘기기 흐름 점검.
- 아침 요약 전송 코드를 다른 판매 채널 프로그램의 기준 코드 후보로 검토.
