# B3 반려 상품 알림 플랜 (2026-10-31, 승인 대기)

## 문제
승인반려는 상품을 하나씩 열어 「쿠팡 상태 확인」을 눌러야 보인다. 첫 저장 시험처럼 저장 직후 반려돼도 놓칠 수 있다.

## 범위
1. 첫 화면 「오늘 할 일」 아래에 「반려된 상품」 칸: 등록 기록(`coupang_ops_jobs`) 중 `rejected`를 최근 순 10건, 사유(`message`)와 상품 링크 표시. DB만 읽어 쿠팡 호출 없음. 다른 상품으로 다시 보낸 뒤 남은 옛 기록은 `deleteJobProductAction`이 `failed`로 바꾸므로 자동으로 빠진다.
2. 같은 칸에 「등록 상태 다시 확인」 버튼: 아직 결과를 모르는 기록(`saved`·`requested`) 최근 5건만 기존 상태 확인 로직으로 갱신. 버튼을 눌렀을 때만, 회원별 30초 간격, 1회 최대 10회 호출.

## 하지 않는 것
자동·예약 확인, 메일·문자 알림, 자동 삭제·재전송, 이 프로그램 밖에서 등록한 상품의 반려(「내 쿠팡 상품」의 「승인반려」 필터로 확인).

## 검수
시험·`tsc`·로컬 빌드 → 배포 → 크롬에서 칸 표시 확인. 시험 계정에는 지금 반려 기록이 없을 수 있으며, 그 경우 빈 상태와 임시저장 건 상태 확인만 실제로 확인되고 반려 표시는 자동 시험으로만 검증된다. 상태 확인은 읽기만이라 중지 중인 `16433545652`를 바꾸지 않는다.
