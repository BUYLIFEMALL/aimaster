### 1-3. 주인님이 정한 규칙(반품비·배송)
- 반품비는 회원이 직접 정할 수 있고, 비우면 **편도 = 발송비 + 1,000원**(1,000원 = 반품 회수 때 새 박스·포장 비용 — 돌아온 박스는 더러워 재사용 불가).
- 무료배송 상품을 **고객 사유(단순변심 등)**로 반품하면 처음 무료로 보낸 택배비까지 받아 **왕복 = (발송비 + 1,000원) × 2**(쿠팡 초도 반품배송비 + 반품배송비). 판매자 사유(불량·오배송)는 쿠팡이 고객에게 청구 안 함. 교환비 계산 방식은 공식 문서로 아직 확인 안 함.
- 반품비 두 칸이 0이면 저장 막음(무료배송이어도 반품비는 받음).
- 쿠팡 배송비 방식은 **무료·유료·착불·조건부 무료 4가지뿐** — 수량별·구간별은 스마트스토어 전용(주인님 확인).
- 제주·도서산간 추가배송비는 **WING 출고지 설정**의 택배사별 값. 지금 출고지 「바이라이프」는 **제주 0원·도서산간 0원**(주인님께 WING에서 넣으시라고 안내함).
