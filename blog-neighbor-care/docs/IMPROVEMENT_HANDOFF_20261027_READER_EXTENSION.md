## 구현한 흐름

1. 기존 공용 로그인·프로그램 이용 권한·전화/정지 판정을 그대로 통과한 회원만 `/reader`에서 본인 블로그 아이디를 지정합니다. 연결 번호는128비트·10분·1회용, DB에는해시만 저장합니다.
2. 확장은 번호를 서비스전용RPC로 원자적으로 교환합니다. 256비트 토큰 원문은 확장의 trusted local storage에만 보관하며 웹페이지/DB/로그에 반환하지 않습니다. 서버는 매 요청마다 회원권한·기기만료/해제·공용계정 연결을 다시 확인합니다.
3. 공용 `member_platform_accounts(platform=naver_blog,auth_method=browser_read)`를 재사용합니다. 별도 블로그계정 저장소를 만들지 않습니다. 새 카탈로그는 `account_set`이며 OAuth토큰은빈문자열입니다. 회원이 지정한블로그이지 네이버가 소유권/세션/게시권한을 인증한 연결이 아닙니다. 메타의 `ownership=member_declared,naver_session_verified=false`를 유지합니다.
4. 회원이 네이버에서 본인 글 **1개의주소**를 열고 확장을 눌러 동의→읽기를 선택합니다. `activeTab`으로 현재 글의 제목/본문텍스트만 읽습니다. 본문 확인 후 별도 ‘보내기’ 클릭 전에는 서버에 본문을 저장하지 않습니다. 목록/편집기/다른블로그/모호한 여러본문/2만자 초과는 거절합니다. 이미지·댓글·알림·쿠키·비밀번호는 추출하지 않습니다.
5. 서버가 회원/기기에 묶은5분 요청으로만 받습니다. 전송응답 유실 시 자동재시도 없이 ‘결과 확인’으로 조회합니다. 같은 요청은멱등이며 다른 기기·다른 요청번호라도 같은회원/글/내용은한건입니다. 수정본도 기존원본의 보관기한을 따릅니다.
6. 받은자료는 회원별격리, 최초요청/원본생성부터30일. 만료즉시 조회를막고 정리RPC/일일Cron설정으로 물리삭제를준비했습니다. **Cron은미배포·미활성**이며 실제일일실행검수는남습니다. 기기해제/공용계정삭제는추가읽기를막되 이미받은본문의원래수명을지킵니다.

정기수집·이웃신청·공감·댓글·AI분석·발행기능을 추가하거나 `bnc_runtime.live_allowed`를 켜지 않았습니다. 이 읽기토큰으로 기존worker의observe/claim/arm/result를호출할수없습니다. 네이버반복수집/자동소통 허용근거가확보됐다고표시하지않습니다.

2. [기본3단계·coming표시등록 검토SQL](../supabase/register_reader_pilot.sql)을검토/승인후적용합니다. 기존회원권한을수동재작성하지않으며VIP/등급자동부여트리거의실제결과를확인합니다. 전체소통프로그램이완성됐다고공개하지않습니다. 현재운영 `bnc_reader_*`0표·program등록0행입니다.
3. Vercel팀`buylife`의새프로젝트`blog-neighbor-care`, 운영도메인/보조도메인, 필요한기존운영Supabase URL/공개키/서버키 및 `CRON_SECRET`을서버환경에만설정합니다. 키원문출력/문서기록0, 동시빌드추가구매OFF유지. CRON_SECRET은기존공용값이있는지확인해승인범위내서버에서취급합니다.
4. 팀빌드대기0확인후 **Vercel배포1회**. 소스신규분량이커서즉시배포예외①이며실제설치시험의전제라예외②에도해당하지만, 비용사전승인은별도필요합니다. 미승인상태로배포/푸시하지않습니다. 현재 [공식요금표](https://vercel.com/pricing)의Standard $0.014/분을가정하면1~3분빌드약$0.014~$0.042(약$0.01~$0.05)예상이며실제머신/시간/포함크레딧/세금에따라달라집니다. 과거동시빌드OFF무료설명을현재계정요금확인없이보장하지않습니다. 금액상한보장이아닌예상이며빌드1회수량으로승인받습니다.
