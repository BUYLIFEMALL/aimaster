## 2. 설계
### C-1. 걸림돌 정리 (자동 모드 전에 꼭 필요한 것)
**(1) 정독 대기 중 창 선택이 15초 넘게 풀리면 멈춤** (`extension/work-bridge.mjs` 73줄)
- 지금: 대기 중 창 선택이 풀리면 15초 뒤 실행 중단 → 회원이 다른 프로그램을 쓰면 자동 운영이 매번 멈춤.
- 제안(추천 **가안**): 「창 선택(focus)」 대신 **「대상 탭이 화면에 보이는가(visibility)」**로 판단.
  - 정독 시간은 탭이 보이는 동안만 셈 → 가려지면 **시계를 멈추고 기다림**(실패 아님), 다시 보이면 이어서.
  - 누르는 순간에는 지금처럼 엄격히 확인(대상 탭이 보이는 상태·같은 계정·같은 본문). 창이 최소화됐거나 탭이 바뀌면 누르지 않음.
  - 10분 넘게 안 보이면 이 작업을 **다음 주기로 미룸**(상태는 「검토 완료」 유지, 재시도 횟수에 넣지 않음, 자동으로 다시 누르지 않음).
  - 효과: 브라우저 창을 다른 창 뒤에 두거나 다른 모니터에 띄워 두고 다른 일을 해도 이어감(최소화만 안 하면 됨).
- 봇 탐지 원칙(§20)과의 관계: 사람처럼 「보이는 글을 시간을 두고 읽은 뒤 누름」은 그대로이고, 숨은 탭에서 누르지 않으므로 원칙 안. **확인할 것**: 가려진 창에서 네이버 화면이 정상으로 그려지는지(브라우저가 가려진 창을 「숨김」으로 처리하면 시계가 멈춤 — 맥미니 실물 시험으로 확인).
- 나안(대안): 지금처럼 창 선택 기준 유지 + 「일시 정지 → 돌아오면 이어서」만 추가. 더 보수적이지만 다른 일을 하는 동안 자동 운영이 서 있음.

**(2) 같은 글·같은 동작 중복 작업 차단**
- 작업을 **만드는 단계**(초안 저장·새 글 자료에서 공감 준비·자동 생성)에서 같은 회원·계정·이웃·글·동작에 「초안·검토 완료·실행 중·불확실·성공」 작업이 있으면 새로 만들지 않고 기존 작업을 알려 줌.
- DB: 작업 생성 함수들이 쓰는 공통 확인 함수 1개 추가(기존 고유 장치는 그대로). 기존 자료는 바꾸지 않음.
- 화면: 작업 기록에 **글 번호(또는 글 제목 앞부분)** 함께 표시 → 이번처럼 다른 글 기록이 섞여 보이지 않게.

**(3) 대상 글을 프로그램이 열기**
- 「오늘의 소통」에 **「승인한 작업 실행」 버튼 1개** → 확장의 기존 「승인한 글 순회」를 시작(같은 창 새 탭, 서버가 고른 검토 완료 작업만).
- 웹 → 확장 신호는 기존 연결 방식(`web-bridge.js` 메시지)을 재사용. 확장이 없거나 꺼져 있으면 「확장을 켜 주세요」 한 줄.

**(4) 확장 실행 동의를 처음 한 번만**
- 동의 내용(기기·동작 종류·순회/반복 허용)을 확장 저장소(`storage.local`, 브라우저를 껐다 켜도 유지)와 서버 기록에 남김.
- 같은 범위면 다시 묻지 않음. 새 동작 추가·새 기기·버전이 바뀌어 권한이 넓어질 때만 다시 물음. 회원이 「동의 철회」를 누르면 즉시 꺼짐.

### C-2. 완전 자동 운영 (단순화 플랜 §3-3 그대로)
1. **시작하기 화면**(오늘의 소통 맨 위, 처음 한 번): 할 일 체크 4개(공감·댓글·답방·받은 신청 수락) + 모드(자동 / 검토 후 실행) + **통합 동의 1번**(AI 문장 초안을 내 키로 만들기 · 승인된 작업만 이 기기 확장이 등록 · 상한·시간대 안에서만 · 결과 불확실 시 재실행 안 함 · 하루 최대 AI 비용 안내). 저장하면 실행 허용·기기 허용·상한·시간대 기본값이 한 번에 저장.
2. **자동 흐름**(브라우저가 켜져 있는 동안, 회원 PC에서):
   - 새 글 확인(기존 `feed-watch`) → 새 글이면 **공감은 AI 없이 바로 작업 생성·자동 승인**, 댓글은 회원 키로 AI 초안 → 기존 품질 검사 통과분만 자동 승인(통과 못 하면 「확인 필요」 카드).
   - 시간대 안에서 주기마다 「승인한 글 순회」 자동 시작 → 글 열기 → 정독 대기 → 실행 → 결과 기록.
   - 받은 신청 수락·답방도 같은 방식(회원이 고른 조건).
3. **안전 조건**: 하루·회당 상한(기본 공감 30·댓글 10·신청 수락 10 — 단순화 플랜 확정값), 동작 시간대, 사람 같은 간격, **결과 불확실 시 재실행 금지**(지금 그대로), 로그인 풀림·보안문자·계정 불일치·화면 구조 변경이면 **멈추고 알림**(확장 배지 + 오늘의 소통 맨 위 「확인 필요」), 같은 글 중복 금지(C-1 (2)).
4. **전체 일시정지 버튼 1개**: 오늘의 소통 맨 위 + 확장 팝업. 누르면 새 글 확인·순회·반복 모두 멈춤.
5. **오늘의 소통 첫 화면**: 「오늘 한 일 · 결과 · 확인이 필요한 것」 요약 카드가 맨 위, 기존 칸들은 그 아래(검토 후 실행 모드면 초안 카드 [승인]/[고치기]/[건너뛰기], 여러 장 한 번에).
6. **첫 자동 시험은 상한 1건**(맥미니, 공감 1건 → 다음에 댓글 1건).
