- **중복**: 「회원 실행 허용·일일 상한」과 「작업 기록」이 4번 화면과 설정 화면에 **똑같이 두 번**. 모델 고르기가 **네 곳**(설정·분석·새 글 확인·문장 만들기).
- 메뉴 이름과 실제 일이 다름: 매일 쓰는 「문장 만들기·검토·실행」이 4번 「이웃 관계 기록」 안 9개 칸 사이에 묻혀 있음. 「대시보드」는 분석 화면.

### 확장 팝업
- 칸 **11개**, 버튼 **약 40개**: 연결 · 새 글 자동 확인 · 내 글 읽기 · 기존 이웃 가져오기 · 현재 탭 실행 연결 · 수락·원댓글·답방 글 확인 · 현재 탭 반복 실행 · 받은 서로이웃 신청 · 검토한 신청 반복 수락 · 승인한 글 순회 · 연결 해제.
- 칸마다 시작·상태 확인·중단·이전 결과 버튼이 따로 있고, 실행마다 동의 체크를 새로 함.

### 오늘 실제 시험에서 댓글 1건에 거친 단계 (공감도 비슷)
1. 4번 화면 문장 만들기: 모델 고르기 + AI 전송 동의 → 생성 → 초안 저장
2. 같은 화면 작업 기록: 조회 → 계정·글·문장 확인 → 검토 완료 저장
3. 회원 실행 허용 켜기·일일 상한 저장(설정 화면 또는 4번 화면)
4. 설정 화면 「웹·확장 실행 연결」: 기기 고르기 → 동작(공감·댓글) 체크 → 동의 → 저장. **체크가 매번 비어서 나오고 저장하면 목록이 통째로 바뀌어**, 댓글을 더하려다 공감 허용이 빠질 뻔함
5. 네이버 대상 글 탭을 직접 열기
6. 팝업 「현재 탭 실행 연결」 펼치기 → 동의 체크 → 실행
7. 결과는 설정 화면 「작업 기록」에서 조회
→ **화면 3곳 + 팝업, 동의 4번, 클릭 약 20번**으로 댓글 1개.

## 2. 문제를 한 줄씩
1. 처음 쓰는 사람이 무엇을 어떤 순서로 해야 하는지 알 수 없다(메뉴 7개, 4번 안에 칸 9개).
2. 같은 설정이 두 곳에 있고, 모델을 네 번 고른다.
3. 동의 체크가 너무 많다 — 대부분 「한 번 동의하면 되는 같은 내용」을 기능마다 다시 묻는다.
4. 기기 허용 칸이 저장값을 보여 주지 않는다(실제 버그성 불편).
5. 매일 하는 일(새 글 확인 → 문장 → 승인 → 실행 → 결과)이 한 화면에 모여 있지 않다.
6. 팝업이 「기능 목록」이라, 지금 탭에서 무엇을 누르면 되는지 회원이 판단해야 한다.

## 3. 바꾼 뒤의 모습
### 3-1. 원칙 (안전장치는 그대로, 묻는 횟수만 줄임)
- **그대로 지킴**: 회원 본인 계정·본인 키 / 자동 모드는 회원이 시작하기에서 직접 켠 경우만(끄면 검토 후 실행) / 일일 상한 / 본인 계정·대상 글 확인 / 결과 불확실하면 자동 재실행 금지 / 30일 보관(열외·1년 통계 기준은 `AGENTS.md` 맨 위).
- **줄임**: 같은 내용 동의는 **처음 한 번**(범위가 넓어질 때만 다시), 설정은 **기본값이 정해진 상태로 시작**, 모델은 **한 곳**.

### 3-2. 처음 한 번 — 「시작하기」 3단계 (5분 목표)
| 단계 | 회원이 하는 일 | 프로그램이 대신 하는 일 |
|---|---|---|
| 1. 확장 연결 | 확장 받기 → 설치 → 팝업 「이 회원 계정과 연결」 1번 | 로그인한 네이버 블로그 계정 자동 인식, 기기 등록 |
| 2. 내 블로그 맞추기 | 「내 글 읽기」 1번(현재 글 또는 최근 글 자동) | AI 키는 메인 사이트 `/api-settings` 등록값을 그대로 사용(없으면 등록 안내), 기본 모델 자동(균형형), 내 블로그 문체 분석 자동 실행 |
| 3. 무엇을 할지 고르기 | 체크 4개(공감 · 댓글 · 답방 · 받은 신청 수락) + **통합 동의 1번** | 회원 실행 허용 켜기, 이 기기 허용(고른 동작 그대로), 일일 상한·동작 시간대 기본값, 기존 이웃 가져오기 1회 |
- 통합 동의 한 문단: 「AI로 문장 초안 만들기(내 키) · 승인한 작업만 이 기기 확장이 등록 · 상한·시간대 안에서만 · 결과 불확실 시 재실행 안 함」. 이후 같은 범위는 다시 묻지 않음.

### 3-3. 매일 — 기본은 **완전 자동 운영** (사용자 조작 0번, 결과만 확인)
> 2026-11-04 주인님 추가 지시: 「최대한 자동화되는 처리 흐름으로 사용자는 최소한의 설정만으로 자동화운영이 가능하도록」「자동화를 구현한다는건 최소한의 설정,동작으로 사용자 대신 자동으로 동작하는 프로그램이어야해」 → 메인 지침 [`docs/AUTOMATION_MINIMAL_SETUP_POLICY.md`](../../docs/AUTOMATION_MINIMAL_SETUP_POLICY.md). 아래는 이 지시에 맞춰 고친 흐름이다.

**자동 모드(기본)** — 시작하기에서 켜면 그 뒤로 사람 클릭 없이 돈다.
1. 동작 시간대 안에서 정해진 주기마다 확장이 소통 대상 이웃의 새 글을 확인(기존 `feed-watch`)
2. 새 글이면 회원 키로 AI 문장 생성 → 기존 품질 검사 통과분만 자동 승인(검토 완료 상태로)
3. 확장이 기존 「승인한 글 순회」로 글을 하나씩 열어 공감·댓글 등록 → 결과 기록
4. 받은 서로이웃 신청은 회원이 고른 조건(예: 전부 수락 / 내 이웃 기준에 맞을 때만)으로 자동 수락, 답방도 같은 방식
5. 회원은 첫 화면 「오늘의 소통」에서 **결과만 확인**(성공·불확실·실패·멈춤 이유), 필요하면 전체 일시정지 1번
- 안전 조건(메인 지침 3절): 하루·회당 상한, 동작 시간대, 사람 같은 간격, 결과 불확실 시 재실행 금지, 로그인 풀림·보안문자·계정 불일치면 멈추고 알림, 같은 글 중복 금지(기존 중복 방지 기록).
- 조건: 확장이 켜진 브라우저가 열려 있어야 동작(회원 PC에서 실행 — 서버 고정 IP로 하지 않음). 브라우저가 닫혀 있던 동안의 밀린 작업은 몰아서 하지 않음(기존 반복 규칙).

**검토 후 실행 모드(선택)** — 원하는 회원만. 「오늘의 소통」에 초안 카드 → [승인]/[고치기]/[건너뛰기](여러 장 한 번에) → 승인분만 같은 자동 순회로 실행.
