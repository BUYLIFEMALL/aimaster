## 흐름과 데이터

1. 연결된 확장 팝업에서 본인 목록 읽기·임시 전송에 동의합니다. 기존 activeTab/scripting/storage 권한만 사용하며 네이버 상시 호스트 권한·알람·백그라운드 수집을 추가하지 않습니다.
2. 서버는 읽기 허용 정책과 회원/기기/계정을 확인하고 가져오기 ID를 발급합니다. 페이지마다 60초 nonce를 발급하고 DB에는 해시만 보관합니다. 허용 근거 미확인 시 DOM 읽기 전에 차단합니다.
3. 보이는 관리 표에서 블로그 ID·관계 표시만 읽어 임시 전송합니다. 별명·방문자 수·글·댓글·쿠키·로그인 비밀번호를 수집하지 않습니다. 중복 ID·범위/총인원 변경·누락·계정/활성 탭 변경·허가 만료는 중단합니다. 전송 결과 불명 시 자동 재시도하지 않습니다.
4. 웹 `/neighbors`에서 받은 페이지·인원을 확인하고 명시 체크한 뒤 반영합니다. `ready` 전에 반영할 수 없습니다. 전체 표시 범위는 읽는 동안의 여러 시점 자료이며 원자적 네이버 스냅샷을 보장하지 않습니다.
5. 새 서로이웃은 새 글·답방 대상 ON, 새 일반 이웃은 OFF입니다. 다시 읽어도 기존 회원 설정·최초 생성일을 유지하고, 이번 목록에 없는 행을 자동 삭제하지 않습니다. 개별/전체 대상 변경은 외부 소통 실행과 별개입니다.

## 상한·수명·복구

- 앱 읽기 상한: 회원당 KST 하루 100페이지, 요청당 최대100페이지/5,000명, 페이지당 최대100명. 네이버가 허용한 횟수로 표현하지 않습니다.
- 가져오기 확인 기한15분, 페이지 허가60초, 원시 임시 목록24시간, 요청 결과 최초 생성부터720시간. 재조회/확인/수정으로 원래 만료를 연장하지 않습니다.
- 최소 이웃 관계/대상 설정은 생성 자료와 구분해 유지합니다. 계정 삭제 시 연결 데이터가 삭제되고, 만료된 원시 목록/요청은 정리해도 최소 설정은 유지합니다.
- 중단은 진행 중인 한 페이지를 되돌리지 않습니다. 회원 취소는 임시 목록을 삭제하고 읽기 예약량을 환불하지 않습니다. 계정 재연결이 필요한 상태에서도 본인 요청 취소는 허용합니다.
- nonce 응답 유실/워커 종료로 페이지를 다시 허가할 수 없으면 상태 조회→회원 취소→명시 새 시작 순서입니다. 자동 재읽기·자정 재개·원고 발행/소통은 없습니다.
