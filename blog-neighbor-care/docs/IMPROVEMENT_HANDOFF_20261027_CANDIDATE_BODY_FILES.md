## 범위 결정과 근거

기존 읽기 확장은 연결한 **본인 블로그만** 읽습니다. 이 조건을 제거하거나 네이버 전체 host 권한/백그라운드 수집을 추가하지 않았습니다. 기존 [0-A 명세 §2](../../docs/analysis-naver-blog-neighbor-20261024/SPEC_20261026_BLOG_NEIGHBOR_CARE_0A.md)는 「미확인은 기능 구현 여부와 별개로 운영 실행 차단 상태」, 본문 분석은 「회원 제공·사용 권한이 확인된 자료 또는 가상 자료로 검증」으로 정하고 있습니다. 개발 진행 지시나 회원 체크박스를 플랫폼의 허락으로 간주하지 않습니다.

2026-10-27 [네이버 서비스 접근 안내](https://policy.naver.com/policy/disclaimer.html)·[이용약관](https://policy.naver.com/rules/service.html)을 다시 읽었습니다. 자동화 접근의 예외 범위는 명시 허용·제공 API·허용된 탐색 범위 등으로 구분돼 있으며, 후보 전문 읽기용 개별 허용은 이번에 확인하지 못했습니다. 이는 법률 판단이나 모든 수단의 불가능 판정이 아닙니다. **타인 전문 자동 열람/수집 운영 경로는 여전히 미구현·차단**입니다.

## 이번 구현과 사용자 흐름

1. `/candidates`에서 글별 UTF-8 **TXT/MD** 파일을 선택해 본문을 먼저 보고, 「확인한 본문 사용」을 눌러 입력합니다. 주소·제목은 기존 검색 결과/직접 입력과 연결합니다. 파일을 읽는 동안 대상 글이 바뀌면 적용하지 않거나 미리보기를 이전 입력으로 표시하고 적용을 막습니다.
2. 여러 글은 UTF-8 **JSON** 양식의 `posts:[{url,title,body}]`를 사용합니다. 최대192KiB, 한 번에1~20개·글당6,000자·전체60,000자·같은 블로그 최대5개. 가져올 때1~2개도 가능하지만 **평가할 때는 블로그당3~5개** 조건을 기존 서버가 다시 검사합니다.
3. 파일 내용을 확인한 뒤 **기존 입력에 추가 / 현재 입력을 교체**합니다. 기본은 추가. 교체는 별도 확인이 필요하고 현재 입력이 바뀌면 교체 확인을 다시 받습니다. 동일 주소·동일 내용은 중복 추가하지 않으며, 이미 작성한 본문과 충돌하면 전체 적용을 중단합니다. 검색으로 준비한 주소/제목에 본문이 비어 있고 제목이 같으면 해당 행을 채울 수 있습니다.
4. 파일의 `rightsConfirmed:true`는 신뢰하지 않습니다. **새로 들어오거나 채운 글은 사용 권한 미확인**, 전체 권한/외부 AI 전송 동의도 해제합니다. 기존 입력과 내용이 정확히 같은 행의 회원 확인만 보존합니다. 현재 화면의 이전 평가 결과는 닫지만 서버의 이전 분석 기록은 지우지 않습니다.
5. JSON/TXT는 브라우저에서 읽기만 하며 URL 방문·API·AI·키 조회·서버 업로드·브라우저 저장소 기록을 하지 않습니다. HTML/마크다운도 텍스트로 보여주고 실행/렌더링하지 않습니다. **파일을 읽었다는 사실은 그 자료의 진위·완전한 전문·사용권을 독립 검증했다는 뜻이 아닙니다.**
6. 회원이 권한·모델·비용·외부 전송에 별도 동의하고 후보 평가 버튼을 눌러야 기존 서버로 전달합니다. 원본 수명·소유자·출처·수정본/중복 과금 경계는 기존 분석 계약 그대로입니다. 개인 PC의 원본 파일은 프로그램이 원격 삭제한다고 약속하지 않습니다.

공개 다운로드 `candidate-posts-template.json`에는 실제 글로 제출할 수 없는 `POST_ID_1` 자리표시자가 있습니다. 양식을 그대로 분석하지 못하게 검수했습니다. 예제 합성 글3건은 로컬 기능 확인 폴더에만 있고 실제 네이버에서 방문하지 않았습니다.

## 재사용·코드

- 콘텐츠 메이커 `WriteViews.tsx`의 회원 원문 파일→입력 패턴을 참고하고, 이 프로그램의 후보 수/본문 크기/동의 경계에 맞게 구현했습니다. 기존 앱 소스는 바꾸지 않았습니다.
- 네이버 단일 글 주소 판정은 기존 확장 `extension/extractor.mjs`의 `parsePost`를 **직접 import**합니다. 새 URL 판정 사본을 만들거나 기존 본인 글 읽기 조건을 수정하지 않았습니다.
- `candidateFiles.ts`는 파일 읽기/스키마/원자적 합치기 순수 계약. `CandidateFileImport.tsx`는 미리보기·명시 적용·읽기 경합 방지. 기존 `AnalysisStudio`의 후보 입력과 연결했습니다. 새 SQL·서비스·Cron·네이버 권한·버전 상승 없음.
