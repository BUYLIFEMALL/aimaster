2026-10-27 · Codex `codex-win-20261026-blog-check` [역할: blog]. [관리자 결과함](https://www.buylife.xyz/admin/dev-docs/requests). **로컬 구현·검수 완료, 미배포**입니다. 운영 프로그램/도메인/공개화면은 아직 없으며 실제 읽기 검수와 AI 분석은 미완료입니다.

## 결과

- `POST /api/material/preview`: 공용 `authorizeMember`로 로그인·활성프로그램·회원권한을 확인한 뒤, 세션에서 소유자를 결합합니다. 회원이 요청에 보낸 소유자·관계·실행상태·AI점수는 받지 않습니다. 기존 `POST /api/work`의 기능/권한은 유지합니다.
- `summary_preview`: 회원이 제공한 검색 응답의 제목/요약/글URL/작성일과 본인 블로그/키워드/제외목록으로 사전 선별합니다. 본인·제외·무관·잘못된 날짜/주소를 빼고 블로그당 최신 글 한 개, 키워드 일치 수/날짜 순 최대20개를 반환합니다. 입력은 최대50개입니다. 이는 전체 적합도 점수나 진정성/활동성 분석이 아닙니다.
- `text_preview`: 사용 범위 확인을 표시한 회원 제공 본문을 텍스트로 정리하고 글주소·본문·내용해시를 반환합니다. 동의 표시는 회원의 진술이며 출처·권리·자료 진위·계정의 독립 검증이 아닙니다. 본문 최대20,000자입니다.
- 두 작업 모두 관계 `unknown`, 계정미검증, 자동소통불가, 본문AI분석/점수화 미수행을 명시합니다. 서버의 네이버URL 수집·AI/외부호출·DB저장·실행큐 등록은 하지 않습니다. `Cache-Control: private, no-store`이며 요청 실제 UTF8 스트림을128KiB로 제한합니다.
- 본인키 연결·자료저장·30일삭제·프로필AI·모델/예산선택·사용자UI는 후속입니다. 현재 미리보기는 저장이 없으므로 30일삭제 구현 완료로 취급하지 않습니다. 입력의 과거생성일을 새로 저장해 수명을 연장하는 경로도 이번에는 없습니다.

## Edge 실제 확인

- 네이티브 전경 HWND1838288 일치 후 Edge 접근성으로 확인했습니다. 합성 Ctrl+T는 새 탭이 만들어진 증거가 없어 완료로 보지 않았고, 최신 트리의 ‘새 탭’ 버튼을 클릭해 별도탭 생성과 주소값을 확인했습니다.
- 기존 SQL/스마트스토어 탭 내용은 수정하지 않았습니다. 자기 신규탭에서 네이버홈을 열어 로그인 영역만 읽었습니다. **네이버 로그인은 기존 시험회원과 다른 계정**이었습니다. 아이디·알림 내용은 결과JSON에 저장하지 않았습니다.
- 시험회원 `buylifemall@naver.com`으로 직접 전환하도록 채팅 질문을 남겼습니다. 다른계정으로 본문/이웃피드/관계 조회·설정변경·신청·공감·댓글은 하지 않았습니다. 계정전환/로그아웃도 하지 않았습니다.
- 이전 전경HWND0과 달리 이번에는 전경확인이 성공했지만, 이것을 계정 일치·실제본문 검수 성공으로 취급하지 않습니다.
