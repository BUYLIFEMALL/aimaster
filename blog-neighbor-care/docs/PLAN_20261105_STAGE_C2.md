## 2. 만들 것
### 2-1. 시작하기 화면 (🏠 오늘의 소통 맨 위, 처음 한 번)
- 3단계 카드: **(1) 확장 연결**(이미 연결됐으면 ✅ 자동 표시) → **(2) 내 블로그 글 1개**(기존 내 블로그 분석 재사용, 있으면 ✅) → **(3) 할 일·모드·통합 동의**.
- (3)의 기본값을 미리 채움: 할 일 4개(공감 ✅·댓글 ✅·답방 ✅·받은 신청 수락 ✅) · 모드 **자동**(검토 후 실행 선택 가능) · 시간대 09:00~22:00 · 상한 공감 30 · **댓글 3**(주인님 결정, 회원이 바꿀 수 있음, 최대 10) · 신청 수락 10.
- **통합 동의 1번**: AI 문장 초안을 회원 본인 키로 만들기 · 승인된 작업만 이 기기 확장이 실행 · 상한·시간대 안에서만 · 결과 불확실 시 다시 하지 않음 · 하루 최대 AI 비용 안내(댓글 상한 × 선택 모델 1회 단가, 모델 선택표 기준 숫자로).
- 저장하면 실행 허용·기기 허용·상한·시간대·자동 모드·동의 기록이 **한 번에** 저장되고, 확장에도 같은 동의가 전달됨(확장 팝업에서 다시 묻지 않음).
- 시작하기를 마친 회원에게는 카드 대신 「⚙️ 자동 운영 설정 바꾸기」 한 줄만 보임. 같은 설정은 이 한 곳에서만(설정 화면의 같은 칸은 이 카드로 연결, 중복 칸 없음).

### 2-2. 자동 흐름 (회원 PC 브라우저가 켜져 있는 동안)
- **새 글 확인**(기존 `extension/feed-watch.mjs`, 15분) → 새 글이면
  - 공감: AI 없이 작업 생성 + **자동 승인**(검토 완료).
  - 댓글: 회원 키로 AI 초안 → 기존 품질 검사 통과분만 자동 승인, 실패·미통과는 「확인 필요」 카드. 하루 댓글 상한 도달 시 초안도 만들지 않음(비용 0).
- **순회 자동 시작**: 자동 모드 + 통합 동의가 있으면, 확장이 시간대 시작 시각에 「승인한 글 순회」를 스스로 켬(지금은 웹 버튼·팝업으로만 켬). 시간대가 끝나면 끄고 다음 날 다시 켬.
- 받은 신청 수락·답방도 같은 방식(기존 `accept-schedule.mjs`·답방 흐름 재사용, 회원이 고른 할 일만).
- 검토 후 실행 모드: 자동 승인만 빠지고 초안 카드 [승인]/[고치기]/[건너뛰기](여러 장 한 번에 승인 가능). 승인 뒤 실행은 자동.

### 2-3. 안전 장치 (자동의 전제)
- 상한·시간대·사람 같은 간격 그대로, **결과 불확실 시 재실행 금지** 그대로, 같은 글 중복 차단(C-1 DB 장치) 그대로.
- 로그인 풀림·보안문자·계정 불일치·화면 구조 변경 → **멈추고 알림**: 확장 배지 「!」 + 오늘의 소통 맨 위 「확인 필요」 카드(무엇이 왜 멈췄는지 한 줄 + 해야 할 일). 우회하지 않음.
- **전체 일시정지 버튼 1개**: 오늘의 소통 맨 위 + 확장 팝업. 누르면 새 글 확인·순회·반복 실행 모두 멈춤(서버 기록 + 확장 저장소, 둘 중 하나라도 멈춤이면 멈춤). 「다시 시작」도 같은 자리.
- 모든 자동 동작은 기존 작업 기록에 남음(누가·언제·무엇을·결과).

### 2-4. 오늘의 소통 첫 화면
- 맨 위 요약 카드: **「오늘 한 일(공감 n · 댓글 n · 수락 n) · 다음 실행 시각 · 확인이 필요한 것 n」** + 일시정지 버튼.
- 기존 칸(새 글 자료·문장 만들기·작업 기록·답방·대댓글·받은 신청)은 그 아래 접기 안으로.

### 2-5. 맥미니 발견 반영 (v1.17 실물 확인)
| 번호 | 발견 | 처리 |
|---|---|---|
| (1) | 같은 창 다른 탭을 누르면 순회가 바로 꺼짐(`target-traversal.mjs` 59줄 `onActivated` → `stop`) | **끄지 않고 「잠시 멈춤」**: 정독 대기 중이면 C-1의 가림 규칙과 같이 시계만 멈춤(10분 넘으면 다음 주기로 미룸), 대기 중이면 그대로 대기. 누르는 순간에는 대상 탭이 앞에 보여야 함(숨은 탭에서 누르지 않음, §20 그대로). 진행 상태는 팝업 대신 실행 탭·오늘의 소통에서 보이게 |
| (2) | 중복 안내 끝 문장이 앞 문장과 겹침 | 409 중복 안내는 「이 글에 같은 작업이 이미 있습니다(상태: …). 작업 기록에서 확인하세요.」 한 문장으로 |
| (4) | 시간대 밖이면 안내 없이 대기 | 「승인한 작업 실행」·실행 탭·확장 팝업에 **「지금은 동작 시간대 밖 · 오전 9시에 시작합니다」**(서버가 주는 `nextDueAt`·`outside_window` 그대로 표시) |
| (5) | 순회 8시간 기한이 시간대와 어긋남 | 고정 8시간 대신 **「오늘 시간대 끝」**까지, 자동 모드면 다음 날 시작 시각에 다시 켬. 시간대 밖에 시작하면 기한은 다음 시간대 끝으로 |
| (6) | 실행 탭이 설명 없는 `/neighbors`로 열리고 탭 이름이 같음 | 순회 시작 탭을 새 화면 **`/run`**(「🤖 자동 실행 중 · 이 탭을 그대로 두세요」, 지금 하는 일·다음 실행 시각·일시정지)으로, 탭 제목도 「🤖 자동 실행 중」 |
| (7) | 작업 기록에 글 제목 없음 | 맥미니 수정(`3256ee05b`) 그대로 함께 배포 |
| (3) | 결과 문구 위치 | 이미 정상(변경 없음) |

### 2-6. 주인님 결정이 필요한 2건 (맥미니가 남긴 것)
1. **「문장 만들기 실패 원인 구분」을 C-2에 넣을지** — 추천: **넣음**. 자동 댓글은 실패하면 「확인 필요」 카드로 가므로, 원인(키 없음·한도·모델 오류·품질 미통과)을 구분해 보여 줘야 회원이 무엇을 할지 앎. 화면 문구·분류만(새 AI 호출 없음).
2. **감시 AI 단가표 환경변수 `BNC_AUTO_MESSAGE_PRICES`의 옛 모델 이름 교체** — 추천: **교체**(새 이름 `claude-sonnet-5-5` 등 모델 선택표 기준). 지금은 옛 이름 단가가 선택지에서 빠져 멈추는 쪽(위험 없음)이지만, 자동 댓글의 「하루 최대 AI 비용 안내」가 이 단가표를 쓰므로 C-2 전에 맞춰야 숫자가 나옴. 환경변수 변경이라 승인 필요(값은 공식 가격표 확인 후 넣음).

## 3. 구현 순서
1. DB(추가만, 운영 SQL 1건): `bnc_autopilot`(회원별 1줄 — 모드·할 일·통합 동의 시각·동의 범위 버전·일시정지·시간대 기준 기한) + 디스패치 함수(`get`·`save`·`pause`·`resume`), owner-only RLS, 열외 계정 규칙(30일 정리 대상 아님 — 설정이라 생성 데이터 아님).
2. 서버: 자동 승인(공감 즉시·댓글 품질 통과), 시작하기 저장 한 번에, 일시정지 확인을 새 글 확인·작업 생성·순회 응답에 모두 연결.
3. 확장: 통합 동의 받아 저장, 시간대 자동 시작·종료(`alarms`), `onActivated` 잠시 멈춤, 기한을 시간대 끝으로, 일시정지 상태 확인, 배지 알림.
4. 화면: 시작하기 카드 · 요약 카드 · 일시정지 · 「확인 필요」 카드 · `/run` 화면 · 시간대 밖 안내 · 중복 안내 문구.
5. 시험: 지금 362개 + 새 시험(자동 승인 범위, 댓글 상한 3에서 초안 생성 멈춤, 일시정지 시 순회·새 글 확인 정지, 탭 전환 잠시 멈춤·숨은 탭 누름 금지 유지, 시간대 기한, 시작하기 저장 한 번에, `/run` 안내) + DB 시험(추가 표 owner-only·열외).
6. 운영 SQL 대조 후 적용 → **빌드 1회(주인님 승인)** → 화면·확장·ZIP·DB 버전 **v1.18** 함께 → `check-extension-release` OK → 요청함·채팅 보고.
7. 맥미니 실물 시험: **상한 1건** — 자동 모드로 공감 1건 → 다음에 댓글 1건(시험 계정 본인 키 1회). 실행 중 다른 탭 누르기·다른 앱 쓰기·일시정지 확인.
