# 이웃 소통 화면·템플릿 규격

2026-10-27 · 역할 blog · Codex `codex-win-20261026-blog-check`.

사용자 선택: **3번 릴레이 데스크**. 후속 지시: 네이버 블로그 톤으로 색상 조정, 기존 자동화처럼 플랫폼 선택 후 해당 모델을 별도로 선택. 이 결정으로 해당 UI 구현을 진행하며 다시 시안 선택을 요청하지 않습니다.

| 템플릿 | 구조·스타일 | 용도·선정 이유 | 상태 |
|---|---|---|---|
| 이웃 편집실 | 넓은 좌측 메뉴, 세리프 제목, 크림 종이·벽돌색, 근거 중심 카드 | 글을 천천히 읽고 확인하는 편집 작업 | 비선택·영구 보존 |
| 커넥트 아틀리에 | 얇은 아이콘 메뉴, 큰 단계 바, 둥근 카드, 라벤더·살구 | 처음 사용하는 회원의 단계별 안내 | 비선택·영구 보존 |
| 릴레이 데스크 — 네이버 그린 변형 | 좌측 메뉴, 두 열 작업/결과, 표·근거 접기, 그린·화이트·민트 | 내 글·프로필·후보를 비교하고 선택하는 반복 작업. 사용자 선택 | 채택·로컬 UI 구현·운영 미반영 |

색상은 `naver-blog-allinone/src/app/globals.css`의 브랜드 그린 `#03c75a`, 하단 그림자 `#027a37` 계열을 참고했습니다. 실제 흰 글씨 실행 버튼은 대비를 위해 `#03a94c → #027b38`, 하단 `#025d2c`를 씁니다. 표/텍스트는 `#203b31`, 보조 `#64786d`, 배경 `#f5f8f6`, 강조 배경 `#edf8f0`, 경계 `#dce7df`. 주요 버튼 3D 그림자5px·hover−1.5px·active4px, reduced-motion 대응.

메인 `/studio`: 본인 전달 글 선택(1~20개) → 플랫폼/모델·원하는 이웃 조건 → 외부 전송/비용 동의 → 프로필 → 원래 AI 초안과 회원 확인본을 구분해 수정/확인. 10개 미만 잠정. 상세 `/candidates`: 확인한 프로필 → 사용 권한이 있는 후보 본문(블로그당3~5개, 합계3~20개·60,000자, 글당6,000자) → 잠정 주제점수/실제 인용 → 선택 저장. 활동/이웃 관계는 미확인. 프로필 revision 변경 시 기존 평가 선택 차단.

매뉴얼 `/guide`: 연결·자료 전달·모델/비용 동의·프로필 확인·후보 선택·불확정 복구·수명. 설정 `/settings`: 실제 기기 연결 수동 조회, 플랫폼별 모델 목록 확인, 회원 API 연동 링크. 설정의 모델 탐색은 저장된 계정 기본값이 아닙니다. 분석 모델은 메인/후보에서 각각 선택하며 실제 요청에 그대로 전달합니다. `/reader`는 기존 연결 기능을 유지하고 같은 메뉴/색상에 연결했습니다. 루트의 `/reader` 이동은 보존했습니다.

모델 UI는 SEO `components/studio/TitleView.tsx`의 플랫폼→모델·플랫폼 변경 시 기본 모델 재선택 패턴을 재사용합니다. UI 옵션은 이 프로그램 서버의 `analysis/models.ts`에서 가져와 서버 허용 목록과 일치합니다. 기준 목록 자체는 이번 새 공급자 실호출로 검증한 것이 아닙니다. 공급자 변경 시 외부 전송 동의를 해제하고 분석 중 선택을 잠급니다. 지원하지 않는 공급자/모델을 숨은 폴백으로 실행하지 않습니다. 공용 회원 키 저장소만 사용합니다.

API 결과 본문을 HTML로 삽입하지 않습니다. 요청 번호만 회원별 sessionStorage에 보관하고 본문/키/결과는 저장하지 않습니다. 같은 브라우저 탭에서 불확정 요청을 확인할 수 있고 자동 재실행하지 않습니다. 작업 번호/이전 기록에서 결과를 다시 엽니다. 대기 취소는 queued만 허용, 결과 불명은 과금 취소를 뜻하지 않습니다.

비교 HTML은 합성 예시이며 connect-src none, 외부 AI/저장/다운로드/신청 없음. 정식 React UI의 실제 호출과 구분합니다. `node --import tsx design/build-showcase.mjs`로12뷰/쇼케이스를 재생성합니다. `design/capture-views.ps1`은 실제 Edge UIA를 통해 링크를 열고 캡처하며 브라우저 디버거/헤드리스 사용 없음. Codex 브라우저 규칙에 따라 Whale 대신 Edge를 썼습니다.

후속 개발: 후보 검색·실제 본문 확보·활동/관계 근거·기존 이웃 가져오기·신청/수락·공감/댓글·답방/대댓글·반복 실행. 이 프로그램의 이번 UI는 블로그 글 발행기를 대체하지 않습니다. 글 포스팅 3방식(발행 전까지/즉시/예약)은 이번 기능으로 구현된 것으로 표시하지 않습니다.
