## 범위
- 등록기 상품 화면 「보내기」 칸 위에 **옵션 입력**: 쓰지 않음 / 단독형 / 조합형, 옵션명 1~3개 + 옵션값(쉼표 구분), 조합형은 조합마다 옵션가·재고 표.
- 저장: 새 DB 칸 없이 작업 칸 목록의 `options` 단계 값(JSON)에 담고, 다음에 화면을 열면 **마지막으로 보낸 작업의 옵션을 다시 채움**.
- 서버(`/api/extension/task`)가 양식 모양 엑셀(.xls, 1행 머리글 + 데이터, 안내 줄 없음)을 만들어 작업에 함께 보냄.
- 확장: 옵션 칸 펼치기 → 선택형 「설정함」 → 「엑셀 일괄등록」 → 단독/조합 → 「엑셀 일괄등록하기」 파일 칸에 넣기 → 옵션목록 「총 N개」 확인.

## 규칙(양식 안내 그대로)
- 옵션명·옵션값 25자 이내, 조합형 옵션가 10원 단위·**0원 조합 하나 이상**, 재고 0 이상 정수, 사용여부 Y.
- 조합 수 상한 500(넘으면 보내기 전에 안내).

## 모르는 것 → 첫 시험에서 확인
- 옵션 칸 화면 템플릿이 저장본에 없음(판매자센터가 따로 불러옴) → 버튼을 화면 글자와 옵션 칸 범위로 찾음. 「엑셀 일괄등록하기」를 누른 뒤 파일 칸·확인 창 모양, .xls 허용 여부.
