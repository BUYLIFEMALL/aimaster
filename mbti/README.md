# 🔑 성격코드 LAB - 성격코드(MBTI) 측정기 (mbti)

> **AIMaster 39번 프로그램** | **공식 도메인**: [https://personality-code.buylife.xyz](https://personality-code.buylife.xyz)  
> **현재 버전**: `v1.20` | **디자인 템플릿**: 크리에이티브 아틀리에 스타일 — 파스텔 퍼스널리티 랩 에디션

---

## 📌 주요 기능
1. **2분 빠른 검사 (`/test`)**: 20개 핵심 문항으로 신속하게 나의 성격코드 도출
2. **10분 정밀 검사 (`/test/full`)**: 60개 심층 문항으로 4대 이분지표 다각도 정밀 채점
3. **16유형 결과 리포트 (`/result/[type]`)**: 유형별 성향 분석, 숨은 강점, 주의점 및 카카오톡/인스타 공유
4. **16성격 비주얼 가이드북 (`/guide`)**: 4단계 파이프라인, 4대 지표 매트릭스 표, 16유형 기질 맵, FAQ 탑재
5. **100% 프라이버시 안심 로컬 연산**: 응답 데이터 서버 무저장, 브라우저 로컬 안전 채점

---

- **Framework**: Next.js 14.2.35 (App Router)

- **Backend**: Supabase SSR
