## 현재 기능과 보존할 장점

URL·RSS·Perplexity 검색으로 게시글 주제를 모으고, 주제를 고르면 AI가 카페 글 초안을 써서 게시글 후보로 쌓아 둡니다. / 새로 수집해 바로 올리거나 게시글 후보에서 골라 예약 발행을 등록하고, 초안은 검수한 뒤 직접 올릴 수도 있습니다. 연결이 만료되면 게시가 멈추고 이유를 알려 줍니다. / 네이버가 카페·게시판 목록을 주지 않아, 글을 올릴 카페 club_id와 게시판 menu_id를 설정 화면에서 직접 등록합니다. 찾는 방법은 연동 매뉴얼에서 단계별로 안내합니다.

**보존할 장점:** 개인 카페 계정의 글감·예약 발행

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
