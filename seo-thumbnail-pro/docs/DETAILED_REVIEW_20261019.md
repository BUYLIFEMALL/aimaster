## 현재 기능과 보존할 장점

대본·아이디어를 넣거나 txt·md 파일을 올리면 호기심 유발형·가치/혜택형·스토리/감성형 3가지 전략이 나오고, 전략마다 영상 제목·SEO 설명·해시태그·스튜디오 태그(500자)·고정 댓글 질문을 정리합니다. / 이미 올린 영상의 메타데이터를 넣어 역분석하고 개선안을 받을 수도 있습니다. / 썸네일 문구·비주얼 키워드·장르·분위기 10종·피사체 정보(참고 이미지 포함)를 정하면 16:9 고화질 썸네일을 만들고, 대화하듯 수정 요청을 보내 다듬습니다.

**보존할 장점:** 주제/문구/시각 설계·캔버스

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
