# 🎬 AI 유튜브 썸네일 프로 (`seo-thumbnail-pro`)

> **공식 서비스 URL**: https://seo-thumbnail-pro.buylife.xyz  
> **현재 버전**: `v1.10`  
> **디자인 템플릿**: **크리에이티브 아틀리에 스타일 — 프로 썸네일 캔버스 변형 (Creative Atelier Style — Pro Thumbnail Canvas Edition)**

---

## 📌 프로그램 소개
유튜브 대본과 아이디어만으로 성공 공식을 반영한 **3대 A/B SEO 전략(호기심 유발형, 가치/혜택형, 감성 후킹형)**을 세우고,
유튜브 스튜디오 500자 태그와 고정 댓글 전략, 16:9 시네마틱 고화질 썸네일까지 한 번에 제작하는 크리에이터 올인원 솔루션입니다.

---

## 🌟 주요 기능 (Features)
- **STEP 1. 기획 & 전략**:
  - 대본/아이디어 텍스트 입력 및 파일(.txt, .md) 업로드.
  - 3대 A/B 전략 자동 수립 & 스튜디오 500자 태그 1클릭 복사.
  - 기존 영상 메타데이터 역분석기 탑재.
- **STEP 2. 썸네일 상세 설정**:
  - 헤드카피 문구 및 핵심 비주얼 키워드 설정.
  - 10대 장르 & 10대 조명/분위기 프리셋.
  - 피사체 인물(성별/연령대/표정/본인 얼굴 사진 레퍼런스) 커스텀.
- **STEP 3. 결과물 & 피드백**:
  - 16:9 시네마틱 초고화질 렌더링.
  - 대화형 피드백 수정 루프를 통한 자연스러운 부분 재합성.
  - 고화질 1080p 다운로드 및 프로젝트 JSON 백업/복원.
- **📖 연동 & 사용 매뉴얼 (가이드북)**:
  - 4단계 핵심 파이프라인, CTR 300% 극대화 팁 3선, API 키 발급 가이드, FAQ 4종 완비.

## 🛠️ 기술 스택
- **Framework**: Next.js 16.2.11 (Turbopack), React 19.2.4, TypeScript
- **Styling**: Tailwind CSS v4, Lucide Icons, Creative Atelier Dark Theme
- **Backend & Auth**: Supabase Auth (SSO / Magiclink), PostgreSQL
- **AI Engine**: Google Gemini 2.5/3 Flash (전략 분석) & Nano Banana 2.1 (16:9 고화질 렌더링)
