# AI 유튜브 썸네일 프로 (SEO Thumbnail Pro)

유튜브 대본 및 기획안을 분석하여 성공 공식을 반영한 **3가지 A/B 테스트 SEO 전략**을 수립하고, **유튜브 스튜디오 전용 태그(500자)**와 **고정 댓글 전략**을 생성하며, **16:9 고화질 썸네일** 제작 및 대화형 피드백 수정까지 완성하는 올인원 크리에이터 자동화 솔루션입니다.

## 주요 기능
- **1. 기획 및 전략 (Step 1)**:
  - 대본/아이디어 직접 입력 및 텍스트 파일(.txt, .md) 업로드
  - A/B/C 3대 전략 생성: 호기심 유발형, 가치/혜택형, 스토리/감성형
  - 유튜브 스튜디오 태그(500자), 고정 댓글 질문 전략, 시각 연출 가이드
  - 기존 유튜브 메타데이터 직접 SEO 역분석 기능
- **2. 썸네일 상세 설정 (Step 2)**:
  - 썸네일 문구, 비주얼 키워드, 10대 장르, 10대 분위기
  - 피사체(인물) 정밀 설정 (국적/연령대/성별/외형 특징/레퍼런스 이미지 업로드)
  - 실시간 영문 프롬프트 조합 모니터링
- **3. 결과물 & 피드백 수정 루프 (Step 3)**:
  - 16:9 와이드 고화질 썸네일 렌더링
  - 전체화면 확대 뷰어 & PNG 다운로드
  - 결과물 대화형 피드백 수정 요청 (이전 이미지 기반 연속 수정)
- **보안 및 프로젝트 관리**:
  - Google Gemini API 키 브라우저 로컬 격리 보관
  - 전체 프로젝트 JSON 내보내기/불러오기 지원
