# seo-thumbnail-pro — AI 에이전트 작업 지침

## 프로그램 개요
- **프로그램명**: AI 유튜브 썸네일 프로 (SEO Thumbnail Pro)
- **Slug**: `seo-thumbnail-pro`
- **버전**: `v1.01`
- **목적**: 유튜브 대본/아이디어를 입력받아 성공 공식을 반영한 A/B/C 3대 SEO 전략(호기심 유발형, 가치/혜택형, 스토리/감성형)을 수립하고, 유튜브 스튜디오 500자 태그와 고정 댓글 전략을 생성하며, 이를 바탕으로 16:9 고화질 썸네일 렌더링 및 대화형 피드백 수정 루프까지 완결하는 전문가용 올인원 솔루션

## 핵심 불변 원칙 준수
1. **사용자 본인 API 키 원칙**: Google Gemini API 키는 사용자 본인의 브라우저 `localStorage`에만 보관하며 서버로 전송하지 않는다.
2. **연도 불변 원칙**: 모든 AI 프롬프트와 메타데이터 생성은 항상 당해 연도(현재 2026년)를 기준으로 작성한다 (`new Date().getFullYear()`).
3. **UI 표준**: 흰색 베이스(Clean White & Slate), 중성 회색 테두리, 카드형 3열 모듈러 레이아웃 준수.
