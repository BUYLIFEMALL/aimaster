# 주문 리포트 작은 기능 — 상품 묶기 · 정산 파일 (2026-11-14)

작성: [역할: ecommerce-image] Claude Code(윈도우) `claude-win-sdp` · 주인님 지시(2026-11-14) 「순서대로 진행해」 — 보류 목록 세 번째.

## 1. 문제
- **상품 묶기**: 같은 물건이 마켓마다 상품명·옵션 글자가 달라 리포트·원가·재고가 여러 줄로 쪼개진다.
- **정산 파일**: 주문 파일에 정산액이 없으면(쿠팡 등) 수수료 추정값으로 계산된다. 마켓이 주는 정산 내역 파일로 실제 정산액을 채울 방법이 없다.

## 2. 구현
| 기능 | 내용 | 파일 |
|---|---|---|
| 상품 묶기 | 설정 화면 「🔗 상품 묶기」: 상품·옵션마다 「묶음 이름」을 적으면 리포트·원가 표·재고 예측이 그 이름으로 합쳐 셈. 원가는 묶음 이름 값 → 없으면 예전 상품별 값(기존 설정 그대로 유지). 이름을 지우면 풀림 | `src/lib/report/aggregate.ts` `reportKey`·`costOf`, `inventory.ts` `keyOf`, 설정·재고 화면 |
| 정산 파일 | 올리기 화면 「💰 정산 파일로 실제 정산액 채우기」: 마켓 고르기 → 파일 → 주문번호·(상품주문번호)·정산금액 열 맞추기(별칭 자동) → 채우기. 상품주문번호가 맞으면 그 줄, 아니면 같은 주문번호 줄들에 판매금액 비율로 나눔(끝자리는 마지막 줄). 같은 번호 여러 줄은 더함(차감 줄 포함). 결과: 채운 줄·못 맞춘 정산 줄 수 | `src/lib/orders/settlement.ts`, `upload/page.tsx` |
| 덮어쓰기 방지 | 정산 파일로 채운 값은 나중에 같은 주문 파일을 다시 올려도(정산 칸 없음) 지우지 않음 | `parse.ts` `mergeLines`, `OrderLine.settlementFromFile` |

## 3. 지킬 것
- 개인정보 열은 지금처럼 읽지 않음(정산 파일도 `isPersonalColumn` 거름). 모든 값은 이 PC 브라우저(IndexedDB)에만 — 서버·DB 없음.
- 실제 마켓 정산 파일 열 이름은 아직 못 봄(주인님 실제 파일 대기) → 별칭은 흔한 이름만, 못 찾으면 회원이 고름.
