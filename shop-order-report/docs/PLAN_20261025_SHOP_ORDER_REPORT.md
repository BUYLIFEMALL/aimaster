## 1. 무엇을 만드나
마켓 판매자센터에서 받은 **주문·정산 엑셀을 올리면** 주문·배송·취소·반품 현황, 마켓별·기간별 매출과 **순이익**, 재고 소진 예측, 내 상품 리뷰 분석을 한 화면에 보여 주는 판매 후 리포트 도구입니다. 화면의 숫자는 모두 회원이 올린 실제 파일에서 계산하므로 그대로 「내 스토어 진짜 지표」(E8)가 됩니다. 시연·가짜 숫자는 넣지 않습니다(D3·D4).

| 순서 | 화면 | 하는 일 |
|---|---|---|
| 1 | 📥 주문 파일 올리기 | 스마트스토어·쿠팡·11번가·G마켓·옥션 엑셀/CSV 여러 개 → 마켓 자동 인식(열 이름) → 못 알아본 열은 「열 맞추기」로 지정(마켓별로 기억) → 같은 주문 중복 제거 |
| 2 | 📦 주문 현황 | 신규·배송 중·배송 완료·취소·반품·교환 카드, 상태별 목록·검색 |
| 3 | 💰 매출·순이익 리포트 | 일·주·월·상품·마켓별 매출·주문 수·객단가·반품률, **순이익 = 정산액(파일에 있으면 그대로) 또는 판매가 × (1 − 수수료율) − 원가 − 배송·포장비 − 광고비**, 막대·선 그래프, 엑셀 내보내기·인쇄(PDF) |
| 4 | 📉 재고 소진 예측 | 상품별 현재 재고를 넣으면 최근 14일 판매 속도로 「약 N일 뒤 품절」 |
| 5 | ⭐ 리뷰 분석 | **내 상품** 리뷰 파일 → 별점 분포·자주 나온 말·불만 문장 모음(무료, 브라우저). 선택: 회원 본인 Gemini 키로 개선점 요약(가장 싼 모델) |
| 6 | ⚙ 내 설정 | 상품별 원가·수수료율·포장비, 기간 광고비, 열 맞춤 기억, 설정 파일 내보내기·가져오기 |
| 7 | 📖 매뉴얼 | 마켓별 주문 파일 받는 법(그림 카드), FAQ |

### 원본과 다르게 하는 점
- 원본은 업로드·마켓 연동이 전혀 없는 무작위 숫자 화면이었다 → 우리는 실제 파일 입력부터 만든다.
- 순이익·수수료·원가·광고비는 원본에 없다 → 우리 상품소싱 `calcMargin` 계산 방식과 E0에서 확인한 수수료표를 쓴다.
- 마켓 API 자동 수집(스마트스토어 커머스 API·쿠팡 WING API)은 **회원 본인 판매자 키**가 있어야 해서 이번 범위에서 빼고 3차 후보로 둔다.

## 2. ★ 주인님 결정이 필요한 것 — 주문 데이터 저장 방식
주문 엑셀에는 **구매자 이름·주소·전화번호**가 들어 있습니다.

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A (추천) 내 PC에만 보관** | 파일은 브라우저에서 읽고 개인정보 열은 읽자마자 버림. 주문 줄(마켓·주문 키·날짜·상품·수량·금액·상태·정산액)은 이 PC 브라우저 저장소(IndexedDB)에만 보관, 서버 DB 표 없음 | 개인정보가 서버에 절대 안 감, 30일 정리 규칙과 충돌 없음(서버 보관 0), 운영 비용 0, 몇 달 치 추이도 PC에 남음 | 다른 PC·휴대폰에서 같은 리포트를 못 봄(설정 파일 내보내기로 옮김), 브라우저 데이터를 지우면 다시 올려야 함 |
| B 서버 저장(개인정보 제거) | 개인정보 열을 지운 주문 줄만 공용 DB에 회원별(RLS) 저장, 30일 자동 정리 | 여러 기기에서 같은 화면 | **30일 정리 때문에 월별·3개월 추이를 못 봄**, DB 표 3개 추가(승인 필요), 정리 작업·용량 관리 |

→ **A로 진행하고, 원가·수수료율 같은 「설정」도 우선 PC 저장 + 설정 파일 내보내기**를 추천합니다. 여러 기기 동기화가 꼭 필요하면 설정만 B 방식 작은 표 1개를 다음 단계에 추가합니다.

## 3. 확인이 필요한 위험
- **마켓 주문 파일 양식**: 열 이름은 마켓·시기마다 바뀌고, 일부 마켓은 엑셀을 **암호를 걸어** 내려받게 한다(SheetJS 공개판은 암호 파일을 못 엶 → 「암호 없이 저장」 또는 CSV로 받는 법 안내). 그래서 **자동 인식 + 열 맞추기 화면**을 기본으로 만들고, 프리셋은 주인님이 주실 수 있는 **실제 내려받은 파일(개인정보 지운 사본)**로 맞춥니다. 파일이 없으면 열 이름 추측 + 열 맞추기만으로 첫 공개합니다.
- 상태 값(「배송완료」「구매확정」「취소요청」 등)도 마켓마다 달라 상태 사전을 둔다.
