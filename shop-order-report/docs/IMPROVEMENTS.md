# 개선 제안 — shop-order-report

## 1. 로직·기능
- (상) 실제 마켓 파일로 별칭·상태 사전 검증 — 지금은 예시 파일과 일반적인 열 이름 추측. 주인님께 개인정보 지운 사본 요청(요청함 d3078433).
- (중) 같은 상품이 마켓마다 이름이 달라 따로 집계됨 → 「상품 묶기」 설정.
- (중) 쿠팡 정산 파일(정산 메뉴)도 올려 주문과 맞춰 실제 정산액 채우기.
- (하) 암호 걸린 엑셀 직접 열기(SheetJS 공개판 불가 — 안내로 대응 중).

## 2. UI/UX
- 리포트 기간 빠른 선택(이번 달·지난달·최근 3개월).
- 인쇄(PDF)에 그래프 크기 맞춤.

## 3. 다른 프로그램과 연계
- 상품소싱(E1)이 `marketFees.ts` 사본 사용, 소싱 후보 ↔ 판매 결과 비교.
- 셀러 라벨로 발송 전 주문 라벨 넘기기(E9).

## 타 프로그램 탐색 메모
- 편집 가능한 표를 「입력값으로 계산한 값」 기준으로 정렬하면 입력 중 줄이 움직인다(v1.01 재고 표) — 다른 프로그램의 편집 표도 정렬 기준 확인 필요.
