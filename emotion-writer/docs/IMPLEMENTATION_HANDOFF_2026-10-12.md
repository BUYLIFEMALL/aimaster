작성: 2026-10-12 / Codex. **구현·로컬 검수 완료, 운영 연결 승인 대기.** 운영 배포 및 실제 회원 API 실행 완료로 해석하지 않습니다.

후속: 주인님이 “프로그램 등록하고 썸네일 등록해줘”를 별도로 요청하여 등록 DML과 썸네일 업로드를 실행했습니다. 아래의 등록 DML 미적용 항목만 과거 기록입니다. [등록/요금제/HTTP 검수 결과](catalog/REGISTRATION.md)를 먼저 읽습니다. DB 스키마·환경변수 승인 상태는 바뀌지 않았습니다.

## 조사와 구현

첨부 화면과 `https://emotion-writer.vercel.app/`의 HTML·공개 전체 JavaScript 번들을 확보해 기능 핸들러까지 조사했습니다. [분석 문서](REFERENCE_ANALYSIS.md)에 근거를 기록했습니다. 원본 번들은 `docs/reference/`에 로컬 보관하며 Git에서 제외합니다. 원본 소스/프로젝트를 저장소와 buylife 팀에서 찾지 못해 새 서브폴더에 구현했습니다. 참고 사이트를 소유하거나 수정한 것이 아닙니다.

1. 흰색 카드·분홍 포인트·왼쪽 설정/오른쪽 결과, 주제 3개 및 직접 입력, 조건에 맞춰 단계 3~5 표시. 모바일은 세로 카드 배치입니다.
2. 본인 Gemini로 후보 5개 생성, 후보 선택·직접 수정/입력, 5~8줄·시/에세이/짧은 문장, 비율 9:16·1:1·3:4.
3. 나노바나나 배경 또는 본인 Pixabay/Pexels 검색·사진 선택. 작가·사진 원본 링크 보존. 직접 문구+무료 사진은 Gemini 호출 없이 사용할 수 있습니다.
4. 한글 폰트 3개를 앱에 포함하고 Canvas 공통 렌더러로 크롭·줄바꿈·글자 크기/색/위치·배경 음영·서명을 반영합니다. PNG/JPEG 파일 저장 경로를 구현했습니다.
5. 설정 변경은 AI를 호출하지 않습니다. 생성 버튼에서만 호출하며 중복 실행을 막습니다. 취소 후 오래된 응답이 결과를 덮어쓰지 않습니다. 이미 공급사에 접수된 호출의 비용까지 취소된다고 보장하지 않습니다.
6. 회원별 초안은 문구·후보·기본 선택값만 저장합니다. 사진·디자인은 새로고침/설정 페이지 이동 후 다시 설정합니다. 본인 키 등록 표시와 실제 테스트 결과를 구분합니다.

## 권한과 요청 보호

공용 Supabase 로그인과 기존 회원 권한 판정을 재사용합니다. 페이지·작업 API 모두 사용 권한을 확인하고 동적/캐시 금지 선언을 사용합니다. 로그아웃은 POST 후 303으로 로그인 화면을 엽니다. 키 조회/저장은 인증된 `user_id` 필터를 사용하며 화면에는 등록 여부만 전달합니다. 운영자/타인/환경변수 AI 키로 대체하지 않습니다.

모델·길이·후보 개수 검증, 호출 시간 제한, 오류 정리, 동일 출처 POST 검증을 적용했습니다. 사진 다운로드는 허용한 Pixabay/Pexels HTTPS CDN·경로·파일 형식만 허용합니다. 내부 주소·위장 호스트·포트·인증정보·리다이렉트·HTML·크기 초과를 거부합니다. 이미지 상한은 약 3MB이며 큰 이미지는 안내 후 중단합니다.

글귀 모델 `gemini-2.5-flash`, 이미지 선택 모델 `gemini-3.1-flash-lite-image` / `gemini-3.1-flash-image`는 공식 문서 기준으로 구현했습니다. 실제 회원 키의 모델 사용 권한과 응답은 미검수입니다. 다른 모델로 몰래 대체하지 않습니다. 프롬프트 연도는 동적으로 주입하고 인물 기본은 한국인입니다.

## 도구와 파일

Next.js 16.4.0 / React 19 / TypeScript / Tailwind 4. `src/components/Workspace.tsx`는 작업 상태, `QuoteCanvas.tsx`와 `src/lib/studio/render.ts`는 미리보기/내보내기, `services.ts`는 공급사 어댑터입니다. `/api/copy`, `/api/image`, `/api/photos`, `/api/keys`는 공용 API 가드를 사용합니다. 계정·API키등록·플랫폼연동·다른 프로그램 보기는 공통 UI를 따릅니다.

조사: 파일/번들 검색, HTTP 읽기, Supabase 스키마/메타데이터 읽기, Vercel CLI 프로젝트 조회. 검수: Next 빌드·Node 테스트·ESLint, `orca computer` Chrome 화면 확인. Aside는 실행 중이지 않아 사용하지 않았습니다. 회원 비밀 키를 추출하지 않았고 유료 생성 호출도 실행하지 않았습니다.

- 배포 후 등록 DML `supabase/migrations/20261012040558_emotion_writer_catalog.sql`: **미적용**. v1.01·멀티미디어 분류·표준 1/2/3개월 요금제, 기존 카드뉴스 실사 썸네일 재사용을 준비했습니다. 새 전용 썸네일을 만들었다고 보고하지 않습니다.

## 재개 순서

1. 두 변경에 대한 **명시적 사용자 승인** 확인. 구체 변경안 전에 온 일반 “진행해줘”를 승인으로 소급하지 않습니다.
2. 최신 DB CHECK/카탈로그 필드 재확인 후 승인 SQL 적용·기존 제공처 유지 검증. 비밀 값 출력 없이 새 프로젝트 DB 환경변수 3개 설정.
3. 인수인계 반영·검수·커밋·푸시 후 이 폴더에서 `vercel deploy --prod --yes --scope buylife`. 대상 프로젝트 ID 재확인. 새 도메인 추가·등록 DML 적용·버전/주소 확인.
4. 정상 회원으로 로그인/권한/키 미등록 안내 확인. 본인 키로 소량 글귀·배경 생성, Pixabay/Pexels 검색·선택, 세 비율 PNG/JPEG의 한글 폰트/치수/크롭 검사. 권한/키가 없으면 대체 계정·키를 사용하지 않습니다.
5. 취소/실패 후 문구 유지·계정별 초안·모바일 작업/저장까지 확인하고 증거·커밋·푸시·배포 주소·버전·남은 작업 보고.

확장 프로그램은 없으며 ZIP 릴리스 대상이 아닙니다. 회원 대신 외부 게시/카톡 공유를 실행하지 않습니다.
