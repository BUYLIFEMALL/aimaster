# 🛒 Coupang Seller Copilot — 쿠팡 셀러 운영 AI & Product Intelligence

쿠팡 셀러의 실제 **판매, 광고, 원가, 재고, 리뷰/반품, 경쟁사 데이터**를 기반으로 사업 손익을 자동 집계하고 **이상 징후 탐지**, **상세페이지 개선안**, **신제품 기획서**까지 자동 생성하는 AI 코파일럿 시스템입니다.

---

## 🎯 4단계 핵심 기능 및 서브 프로젝트

### 1️⃣ Phase 1: CSV Data Copilot (MVP)
- **CSV/Excel 통합 파싱**: 판매 실적, 매출 정산 데이터, 광고 보고서, 상품별 원가표, 현재 재고 수량
- **10대 핵심 손익/운영 지표 자동 수식 집계**:
  - 매출, 광고비, ROAS, 판매량, CPA, 원가, 공헌이익, 추정 손익, 현재 재고, 재고 소진 예상일
- **Claude AI 이상 징후(Anomaly Detection) 리포팅**:
  - 🚨 *광고 효율 악화*: "A상품 광고 효율이 최근 7일 평균 대비 20% 악화됨"
  - ⚠️ *품절 임박 경고*: "B상품은 현재 판매속도 기준 18일 후 품절 예상 (재고 보충 필요)"
  - 📉 *비효율 광고 집행*: "C상품은 광고비 35% 증가했으나 매출 증가폭은 3%에 불과함"
  - 💸 *마진 경고*: "D상품은 목표 공헌이익률(15%) 미달 (현재 8.2%)"

### 2️⃣ Phase 2: VOC & Review Intelligence
- **리뷰 및 반품 CSV 데이터 분석**:
  - 고객 불만 키워드 (사이즈 오류, 냄새, 배송 파손, 사용법 미숙 등) 자동 클러스터링
- **개선 액션 자동 제안**:
  - VOC 변화 ➔ 제품 품질 문제 탐지 ➔ **상세페이지 핏/사용법 가이드 보완 수정안** ➔ 제품 제조 개선 요청서 작성

### 3️⃣ Phase 3: Coupang WING Open API 자동화
- **WING Open API 실시간 동기화**:
  - 주문/배송, 상품별 광고 성과, 재고 수량 실시간 자동 연동
- **실시간 경고 알림**:
  - 이상 징후 발생 시 카카오톡 / 이메일 / 슬랙 즉시 알림 리포트 발송

### 4️⃣ Phase 4: Market & Product Intelligence (신제품 기획)
- **경쟁사 데이터 파이프라인**:
  - 카테고리 내 경쟁상품 수집 ➔ 가격/스펙 비교 ➔ 리뷰 부정 반응 추출
- **시장 빈틈(Unmet Needs) 탐지 & 신제품 기획서**:
  - 소비자들의 미해결 불만사항 분석 ➔ **시장 빈틈 발견 ➔ 신제품 기획서 ➔ 차별화 USP ➔ 상세페이지 카피라이팅** 자동 생성
