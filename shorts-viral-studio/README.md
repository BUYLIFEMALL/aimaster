# 쇼츠 떡상 분석·대본 자동화 (`shorts-viral-studio`)

> **공식 서비스 URL**: https://shorts-viral-studio.buylife.xyz  
> **현재 버전**: `v1.11` (2026-10-18 디자인 리뉴얼 & 비주얼 가이드북 구축)  
> **공식 템플릿**: **플로우 위저드 스타일 (다크 차콜 변형)**

---

## 1. 프로그램 사용목적 및 대상
- **사용목적**: 유튜브 쇼츠 알고리즘을 뚫은 떡상 영상(조회수÷구독자 3배~10배 이상)을 검색·분석하여, 검증된 성공 공식을 바탕으로 6가지 새로운 소재 발굴, 씬별 1문장 대본 자동화, 미드저니/DALL-E 이미지 및 비디오/Suno BGM 프롬프트까지 10분 만에 완성하는 올인원 제작 파이프라인.
- **주요 대상**: 유튜브 쇼츠 크리에이터, 숏폼 마케터, 채널 운영 대행사, 1인 사업가.

---

## 2. 개발 도구 및 기술 스택
- **Framework**: Next.js 16.2.11 (App Router, Turbopack)
- **UI & Styling**: React 19, Tailwind CSS v4, Lucide React
- **Database & Auth**: Supabase (공용 DB `svs_projects`, `svs_saved_prompts`, `user_api_keys`)
- **AI 멀티엔진**: Google Gemini (비디오 직접 시청 분석 지원), OpenAI GPT, Anthropic Claude
- **Testing**: Node.js 내장 test runner, Playwright (Microsoft Edge 포그라운드 실세션 검수)

---

## 3. 핵심 기능 및 6단계 워크플로우
1. **01 쇼츠 떡상 검색 (`/search`)**: 키워드 또는 타겟 채널 기반 떡상 영상 탐색 (초대박 10배↑ / 대박 5배↑ / 떡상 3배↑ 등급 자동 분류).
2. **02 바이럴 메커니즘 분석 (`/analyze`)**: Gemini 비디오 직접 시청 분석을 통해 3초 훅, 컷 전환, 카메라 무빙, 조명 무드, 댓글 반응 등 11대 핵심 공식 해체.
3. **03 소재 6종 AI 발굴 (`/ideate`)**: 분석된 Content DNA를 바탕으로 시청 지속 시간을 극대화할 6가지 새로운 후킹 소재 제안.
4. **04 전략 확인 & 주제 확정 (`/select`)**: 선택한 소재의 전략 로드맵 확인 및 사용자 추가 요청사항 결합.
5. **05 씬별 대본 생성 (`/script`)**: 쇼츠 이탈률을 방지하는 '씬당 1문장 원칙' 자동 보정 대본 및 연출/자막/효과음 조립.
6. **06 멀티모달 프롬프트 조립 (`/prompts`)**: 미드저니 9:16 이미지 프롬프트 + Runway 비디오 무빙 프롬프트 + Suno Master BGM 프롬프트 자동 완성 및 보관함 저장.
