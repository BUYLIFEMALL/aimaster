## 2. 향후 추가 개선 제안 (3대 핵심 분야)

### 1) 프로그램 로직 및 엔진 기능 개선
- **오래된 프로젝트 정기 삭제 Vercel Cron 연결**:
  - 현재는 사용자가 프로젝트 목록을 조회할 때(`listProjectsAction`) 30일 경과 데이터를 삭제하고 있습니다.
  - 사용자가 장기간 접속하지 않을 때도 유튜브 API 정책을 준수할 수 있도록 `/api/cron/cleanup-projects` 엔드포인트를 신설하고 `vercel.json`에 주간 크론을 등록하는 방안을 제안합니다.
- **영상 다중 분석 시 병렬 처리 최적화**:
  - 3개 영상을 동시에 분석할 때 Gemini 영상 분석 API의 응답 속도를 개선하기 위해 `Promise.all` 기반 병렬 호출 및 진행 상태 퍼센트 프로그레스바 지원.

### 2) 사용자 인터페이스(UI) 가독성 및 사용 편의성 개선
- **대본 에디터 실시간 글자수 & 예상 발화 시간 인디케이터**:
  - 각 씬의 나레이션 텍스트 박스 하단에 한국어 음절 수(글자 수)와 평균 발화 속도(초당 4~5음절) 기준의 실시간 예상 재생 시간(예: `18자 · 약 3.8초`)을 뱃지로 표기하면 사용자가 목표 시간에 맞추어 대본을 수정하기 훨씬 용이해집니다.
- **프롬프트 원클릭 일괄 복사 툴바**:
  - 6단계 프롬프트 화면에서 씬별로 일일이 복사할 필요 없이 '모든 이미지 프롬프트 복사', '모든 영상 프롬프트 복사' 원클릭 액션 버튼 추가.

### 3) 다른 자동화 프로그램과의 연계 기능 제안
- **`ai-image-studio` (34번 AI 이미지 스튜디오)와의 즉시 생성 연계**:
  - 6단계에서 생성된 미드저니/DALL-E 이미지 프롬프트를 복사하여 붙여넣지 않고도, "AI 이미지 스튜디오에서 바로 생성하기" 버튼을 통해 해당 프롬프트를 쿼리 파라미터나 상태로 전달하여 즉시 9:16 이미지를 생성할 수 있도록 브릿지 연동 구축.
- **`music-automation` / `suno-music-studio` (54번·18번 Suno 음악 자동화) 연계**:
  - 추출된 Suno BGM 프롬프트(`sunoPrompt`, `genreAndMood`, `bpm`)를 곧바로 수노 음악 생성 스튜디오로 넘겨 배경음악 음원을 즉시 추출할 수 있는 파이프라인 연계.
- **`auto-shorts-posting` (58번 YOUTUBE Shorts 자동화) 연계**:
  - 완성된 대본과 썸네일/비디오 프롬프트를 바탕으로 유튜브 쇼츠 예약 업로드 자동화로 직결되는 풀오토 퍼블리싱 체계 구축.
