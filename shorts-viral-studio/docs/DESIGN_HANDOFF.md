## 2. 모바일 반응형 내비게이션 (375px 최적화)

1. **상단 56px 고정 헤더 (`md:hidden`)**:
   - `sticky top-0 z-40 flex h-14 w-full items-center justify-between border-b border-[#30363d] bg-[#161b22]/95 px-4 backdrop-blur`
   - 좌측: 빨간 재생 버튼 아이콘 + 프로그램 타이틀 (`쇼츠 떡상 분석·대본`) + `v1.11` 배지
   - 우측: 햄버거 토글 버튼 (`☰` / `✕`, `aria-label="메뉴 열기/닫기"`)
2. **슬라이드 오버레이 드로어 메뉴**:
   - 모바일 환경에서 햄버거 버튼 클릭 시 `fixed inset-0 z-50` 딤 배경과 함께 좌측에서 290px 너비의 차콜 드로어가 부드럽게 슬라이드 오픈.
   - 링크 클릭 시 자동 닫힘 처리 및 우측 상단 명시적 닫기(✕) 버튼 탑재.
