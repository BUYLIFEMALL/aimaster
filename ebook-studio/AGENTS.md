## 2. 완성된 핵심 기능 및 아키텍처
1. **01 원본 문서 (스마트 자료 입력 & 목차 엔진)**:
   - **3가지 입력 방식**:
     - 파일 업로드: 브라우저 내부 파서로 TXT, Markdown, DOCX(JSZip 기반 `word/document.xml` 텍스트 추출) 처리 (서버로 원본 파일 미전송).
     - 웹 주소 일괄 스크래퍼: 한 번에 최대 12개 URL 입력 시 `/api/scrape` 백엔드를 통해 본문 텍스트 자동 추출 (실패 URL은 입력창에 보존).
     - 직접 붙여넣기: 이름 및 본문 50자 이상 입력 지원, "유튜브 자막 추출 스크립트" 원클릭 복사 단추 탑재 (유튜브 F12 콘솔에서 즉시 자막 추출 클립보드 복사).
   - **스마트 목차 분할 알고리즘**:
     - 파일명 넘버링(01_, 02_) 우선 정렬.
     - 본문 내 소제목(#, ##) 단위 챕터 자동 분할.
     - 긴 문단(3,500자 초과) 자동 분할 `(2)` 표기.
     - 장 제목 인라인 수정 및 "제목 되돌리기" 지원.
     - Gemini AI 기반 "AI 목차 제안" 기능 지원.
2. **02 전자책 구성 (디자인 & 집필 제어)**:
   - 도서 기본 메타데이터: 책 제목, 부제, 저자명.
   - 3대 정리 수준: `상세 정리` (강의안·가이드북용), `핵심 요약` (브리핑·요약노트용), `원문 그대로` (원문 보존 및 서식 정돈).
   - 표지 만들기 프롬프트 4대 템플릿: `체크리스트형`, `대비형`, `요점 나열형`, `인물 대비형` (클릭 시 3:4 규격 프롬프트 자동 복사).
   - 디자인 조합 10대 프리셋: 문학 에세이, 고전 문고, 출판 원고, 실용 안내서, 기술 문서, 야간 독서, 연구 노트, 접근성 우선, 검증 워크북, 다크 스튜디오 원클릭 적용.
   - 스타일 세부 조정: 21종 테마(밝은 12, 어두운 8, 고대비 1), 5종 한글 서체(본고딕, 본명조, 리디바탕, 마루부리, 페이퍼로지), 지면 꾸밈(클래식, 스튜디오), 줄간격(1.15~2.10) 및 글자크기(14~22px) 슬라이더.
   - AI 모델 드롭다운: `gemini-2.5-flash`, `gemini-2.5-flash-lite`, `gemini-2.5-pro` 선택.
   - 전자책 생성 제어: 순차 집필 진행 막대, 중단 및 이어서 생성 지원.
3. **03 실시간 뷰어 & 인라인 챕터 에디터**:
   - 반응형 e-Book 리더기: 모바일(375px), 태블릿(768px), 데스크톱 반응형 지원.
   - 전체화면 읽기 모드 지원.
   - 책 고치기 단계: 챕터별 제목, 요약, 본문 마크다운 직접 수정, 순서 변경, 장 삭제, "이 장만 다시 생성" 지원.
4. **04 내보내기 & 공유**:
   - **HTML**: 외부 서버나 인터넷 없이 단 1개의 파일로 실행되는 독립형 HTML (테마/서체/검색/목차 내장, 회원 API키 미포함).
   - **EPUB**: 리더기 표준 규격 전자책 파일 생성.
   - **웹 배포용 ZIP**: Vercel Drop(vercel.com/new/drop) 업로드용 `index.html` 기반 ZIP 번들 자동 패키징.
   - **인쇄 / PDF**: `@media print` 인쇄 최적화 규격 책 출력.
5. **이용 가이드 10개 섹션 풀 모달**:
   - 시작하기, 자료 넣기, 목차, 정리 수준, 디자인, 만들고 검토하기, 내려받기·인쇄·공유, AI 연결과 키, 화면 다루기, 안 되는 것들 전문 탑재.
