# eBook Studio (v1.01)

문서 한 뭉치를 정리하여 나만의 고품질 웹/HTML 전자책으로 발행하는 올인원 스튜디오 솔루션.

## 주요 기능
- **STEP 1: 자료 수집 & 목차 기획**: 흩어진 메모, 강의록, 기획서를 AI로 분석하여 10~15개 장 목차 자동 설계.
- **STEP 2: 목차 & 챕터 집필**: 챕터별 원고 작성, 마크다운 에디터, 핵심 인사이트 및 생각하고 실천하기 질문.
- **STEP 3: 디자인 & 표지**: 21종 독서 테마, 5종 명품 한글 서체, 지면 꾸밈, 줄간격/글자크기 조절, AI 3:4 규격 표지 생성.
- **STEP 4: 배포 & 내보내기**:
  - 독립형 단일 HTML 다운로드 (오프라인 브라우저 열람 지원)
  - 웹 배포용 ZIP 다운로드 (Vercel Drop 연동)
  - 표준 EPUB 전자책 다운로드
  - 책 규격 인쇄 / PDF 저장
  - 프로젝트 원본 JSON 백업 및 복원
- **실시간 반응형 뷰어**: 우측에 다운로드될 결과물과 100% 동일한 뷰어를 모바일/태블릿/데스크톱 규격으로 실시간 프리뷰.
