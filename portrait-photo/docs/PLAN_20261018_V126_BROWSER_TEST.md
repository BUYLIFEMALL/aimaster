## 1. 핵심 버튼 흐름 브라우저 자동 테스트 (추천 — 바로 진행)
- **발견**: `package.json`에 `test:browser`(= `node tests/browser.mjs`) 명령과 `playwright`가 있지만 **테스트 파일이 없다**(뼈대 복사 흔적). 지금 실행하면 실패한다.
- **만들 것**: 바나나 캔버스(`banana-canvas/tests/browser.mjs`)와 같은 방식 — esbuild로 `Studio`를 묶어 로컬 시험 서버에 띄우고, **서버 API는 모의 응답**(`/api/generate`는 시험 사진을 돌려줌, `/api/headcheck`는 고정 머리 위치)으로 바꿔 보이는 Chrome에서 실제로 누른다. 실제 AI 호출·비용 없음.
- **검사 흐름**(증명사진 목적 — 순백 정리가 켜진 상태라 v1.25 버그 재발을 잡는다):
  1. 사진 올리기 → 동의 체크 → [인물 사진 만들기] → 결과 표시
  2. 머리 위치 모를 때 안내·강조 버튼 2개, [규격 저장]에 「추천 영역」 없음
  3. [얼굴 위치 직접 지정 (무료)] → **패널이 열림**(v1.25 회귀 검사) → 사진에 정수리·턱 두 번 클릭 → "머리 약 X% → Y%" 안내
  4. [규격 저장 · 추천 영역] → 내려받은 파일 이름에 `-추천-`·JPEG 크기 확인
  5. [머리 비율 검사] → 모의 응답으로 측정 → 안내 갱신
  6. [프로필 세트 미리보기·저장] → 3장 → 원형 바깥 흰색 전환 → [ZIP으로 저장] → ZIP 안 파일 3개 이름 확인
  7. 휴대폰 폭(390px)에서 같은 화면 가로 넘침 없음
- **파일**: `tests/browser.mjs`, `tests/browser-entry.tsx`, 시험 입력은 기존 `test-artifacts/out-business-pro.png`(AI 가상 인물). 앱 코드는 바꾸지 않는다(버전·배포 없음 — 테스트만 추가).

## 2. 측정 전 「현재 머리 비율 약 ○%」 표시 — 제안 정정
- **정정**: 결과 화면의 가이드선은 **고정된 위치의 안내선**이라 실제 머리 위치를 알지 못한다. 측정 없이 %를 보여 주면 틀린 숫자가 된다 — 이 형태로는 만들지 않는 것을 권한다.
- **대안(별도 작업)**: 브라우저 안에서 도는 무료 얼굴 인식(예: MediaPipe Face Detector, 회원 PC에서 실행, AI 호출·서버 비용 없음)으로 **결과가 나오자마자 머리 위치를 자동 추정** → 측정 전 표시뿐 아니라 [머리 비율 검사(AI 1회)]·직접 지정 없이도 추천 영역이 바로 적용될 수 있다. 다만 얼굴 상자로 정수리를 추정하는 오차·모델 파일(수 MB) 내려받기·정확도 시험이 필요해 별도 플랜으로 제안.
