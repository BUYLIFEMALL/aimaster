## 1. 생성 전 원본 사진 품질 점검 (브라우저 안, AI 비용 없음)
- **언제**: 사진을 올리는 즉시(일괄은 사진마다) v1.26 얼굴 인식 부품으로 점검.
- **점검 항목**(순수 함수 `assessFaces` — 단위 테스트):
  | 항목 | 기준(안) | 안내 |
  |---|---|---|
  | 얼굴 없음 | 얼굴 0개 | "얼굴을 찾지 못했어요 — 얼굴이 잘 보이는 사진을 권장" |
  | 여러 사람 | 얼굴 2개 이상 | "여러 사람이 보여요 — 한 사람만 나온 사진을 권장(AI가 다른 얼굴을 섞을 수 있음)" |
  | 얼굴이 너무 작음 | 이마~턱이 사진 높이의 15% 미만 | "얼굴이 작아요 — 가까이 찍은 사진을 권장" |
  | 옆모습 | 코끝이 양 볼 가운데에서 얼굴 너비의 25% 이상 치우침 | "옆을 보고 있어요 — 정면 사진이 더 닮게 나와요" |
  | 기울어짐 | 두 눈을 이은 선이 15° 이상 기움 | "얼굴이 기울었어요" |
- **막지 않는다**: 안내(경고)만 하고 [인물 사진 만들기]는 그대로 누를 수 있다(회원 판단). 문제없으면 "정면 얼굴 1명 확인" 짧은 표시.
- 얼굴 인식을 여러 얼굴(최대 3)까지 찾도록 설정 변경(머리 위치 자동 추정은 그중 가장 큰 얼굴 사용).

## 2. 결과 사진 위에 정수리·턱 위치 선
- 머리 위치(자동 추정·AI 검사·직접 지정)가 있으면 결과 사진 위에 **정수리(파란 점선)·턱(주황 점선)** 옅은 선과 작은 이름표(「정수리(추정)」·「턱」, 출처 표시).
- 결과 사진은 무대 안에서 `contain`으로 그려지므로, 사진·무대 비율로 실제 그림 영역을 계산하는 순수 함수(`overlayY`)로 선 위치를 맞춘다 — 단위 테스트.
- 「머리 위치 선 보기」 체크(기본 켬). 원본 비교·증명사진 가이드선과 겹치면 가이드선을 우선해 숨김.
