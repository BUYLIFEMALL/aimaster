## ① 인물사진 — 브라우저 안 얼굴 인식으로 머리 위치 자동 측정 (v1.26)
**목표**: 결과 사진이 나오면 회원 PC 브라우저 안에서 얼굴을 찾아 머리 위치(정수리·턱·가로 중심)를 자동 추정 → 회원이 아무것도 누르지 않아도 [규격 저장]·[규격으로 일괄 저장]·[프로필 세트]가 머리 기준 추천 영역으로 동작. AI 검사 호출·비용 없음, 사진은 서버로 보내지 않음.

**방식**
- 라이브러리: Google `@mediapipe/tasks-vision`의 **FaceLandmarker**(얼굴 점 478개, Apache-2.0). 이 저장소에 아직 쓰는 프로그램이 없어 새로 추가.
- 계산: 턱 끝 = 점 152, 이마 위 = 점 10. 머리카락까지의 정수리는 얼굴 점으로 직접 안 나오므로 `정수리 = 이마 위 − α × (턱 − 이마 위)`로 추정(α는 시험 사진으로 보정, 0.3~0.45 예상). 가로 중심 = 얼굴 점 평균.
- 모델·실행 파일(약 수 MB)은 **우리 사이트 `public/`에 함께 올려** 외부 CDN에 의존하지 않고, 결과가 처음 나올 때만 불러온다(첫 화면 속도 영향 없음).
- 우선순위: 직접 지정(가장 정확) > AI 머리 비율 검사 > 브라우저 자동 추정. 화면에 출처를 표시(「자동 추정(브라우저)」), 마음에 안 들면 지금처럼 직접 지정·검사로 덮어쓴다.
- 실패(얼굴 없음·옆모습·브라우저 미지원)면 지금 동작 그대로(측정 전 안내·강조 버튼).

**검수**
- 순수 함수(얼굴 점 → 정수리·턱·중심) 단위 테스트, α 보정: 저장소의 시험 사진 3장(`test-artifacts/out-*.png`)을 눈으로 정수리·턱을 표시한 값과 비교해 오차 목표 ±5%p. 필요하면 AI 머리 비율 검사 결과와도 비교(본인 키 최대 3회 — 그때 확인 받음).
- 브라우저 자동 테스트에 「생성 직후 자동 추정 → [규격 저장]에 추천 영역 표시」 단계 추가(실제 모델로 동작, AI 비용 없음).
- 배포 후 크롬 실검수(기존 결과 사진 재사용 — 생성 필요 시 Flash 1회, 확인 받음).

**비용**: 회원·운영자 AI 비용 없음. 정적 파일 몇 MB가 Vercel 전송량에 추가(결과가 나올 때 1회, 브라우저 캐시). 빌드 1회.
