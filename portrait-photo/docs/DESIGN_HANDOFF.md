# AI 인물사진 자동화 (`portrait-photo`) — 디자인 개발완료 보고서 (v1.22, 2026-10-18, Claude Code 윈도우)

## 1. 템플릿
**「크리에이티브 아틀리에 스타일 — 포토 스튜디오 그래파이트 변형」** (새 변형, 루트 `DESIGN.md` 카탈로그 등록)
- 인물사진은 피부 톤·흰 배경을 눈으로 판단하는 작업이라 색이 치우치지 않은 **중립 회색** 작업 화면을 쓴다(사진 보정 프로그램과 같은 이유). 흰 배경 증명사진 가장자리도 어두운 배경에서 또렷하다.
- 4컷 만화(코믹 파스텔, 라이트)·AI 이미지 스튜디오(럭셔리 다크 골드)와 겹치지 않는 "사진관 촬영 스튜디오" 분위기.

## 3. 구조 (클래스 이름은 그대로 — 기능 코드 무변경)
- `globals.css`: 맨 위 토큰 교체 + 맨 끝 「v1.22 … 덮어쓰기」 묶음이 앞의 밝은 고정값을 덮어씀. 새 클래스는 `.st-steps`(단계 칩), `.gd-hero`·`.gd-mascot`·`.gd-bubble`·`.gd-flow`·`.gd-purposes`·`.gd-dodont`·`.gd-sizes`·`.gd-size`·`.gd-headratio`(매뉴얼).
- 결과 무대 `.st-stage::after`: 네 귀퉁이 카메라 초점 표시(배경 그라데이션 8겹, `pointer-events:none`, z-index 6 — 비교·로딩 위에도 보임).
- `Studio.tsx`: 목적 카드 위에 ① 사진 → ② 목적·옵션 → ③ 만들기 → ④ 저장·규격 칩(`previewUrl`·`busy`·`shown` 상태로 표시만).
- `Sidebar.tsx`: 메뉴 항목·순서·계정 위치 유지, 매뉴얼 메뉴 `📖 연동 & 사용 매뉴얼`, 만들기 메뉴 설명을 단계 순서로.
- `/guide`: 안내 캐릭터 「찰칵이」 말풍선, 4단계 흐름 그림, 목적 5종 카드(`PURPOSES`에서 직접 읽음 — 프리셋을 바꾸면 매뉴얼도 자동 반영), 좋은/피할 사진 이모티콘 카드, 규격 크기 비교 그림(CSS 도형), 머리 비율 그림(정수리 파란 선·턱 주황 선)과 3단계 순서. 기존 6절 문장·FAQ 전부 유지.
- 결과 사진 보기용 확대 창(`.rep-zoom img`)은 사진 판단을 위해 흰 바탕 유지.
