## 1. 증명사진 생성 구도 보강 (프롬프트)
**분석 결과 — 제안 내용 정정**
- 지금 프롬프트(`prompt.ts` `SYMMETRY`)는 "정수리~턱이 이미지 높이의 **약 80%**, 머리가 화면을 거의 채우게"라고 지시한다. 모델은 이를 잘 못 따라 실제로는 43~56%(작음)가 대부분이고, 가끔 너무 잘 따르면 「큼」·머리 잘림이 생긴다.
- v1.23부터 **작게 나온 사진은 저장 때 자동 확대로 기준에 맞출 수 있지만, 크게 나온 사진은 고칠 수 없다**(자르기는 확대만 가능).
- 그래서 단순히 "상체를 더 보이게"만 덧붙이면 80% 지시와 서로 부딪힌다. **추천: 80% 지시를 "안전 여유 구도"로 바꾼다** — 머리(정수리~턱)가 이미지 높이의 **약 55~65%**, 정수리 위에 분명한 여백, 양어깨까지 보이는 정면 상반신. 이렇게 만들면 「큼」·머리 잘림이 거의 사라지고, 저장 때 추천 영역이 기준(예: 한국 여권 71~80%)으로 확대해 맞춘다.
- 해상도: Flash 결과(약 864×1184)에서 머리 60% → 76%로 확대해도 잘린 영역 높이 약 930px로 규격(531px)보다 커서 화질 손실 없음.

**구현**: `SYMMETRY` 블록의 TIGHT ID FRAMING 한 줄만 교체(나머지 정면·대칭·조명 문장 유지). 영어 고정 문장, 모델·호출 무변경. 테스트에 "80%가 없고 새 구도 문장이 들어감" 확인 추가.

**함께 발견(이번에 고치지 않고 기록)**: 이 블록은 「정면·좌우 대칭 구도」 설정을 켜면 들어가는데, **비즈니스 프로필 목적도 이 설정이 켜져 있어** 증명사진식 구도·"입을 다문 무표정" 지시가 같이 들어간다(비즈니스의 「은은한 미소」 포즈와 충돌). 고치려면 요청 형식에 "증명사진 구도" 플래그를 따로 두는 변경이 필요 — 별도 플랜으로 제안(`IMPROVEMENTS.md`).

## 2. 프로필 세트 저장 전 미리보기
- [프로필 세트 저장]을 누르면 바로 내려받지 않고 **3장 미리보기 패널**(정사각·세로 4:5·원형 — 실제 저장될 모양 그대로 작은 그림)을 연다. 패널에서 [ZIP으로 저장]·[닫기]. 머리 위치를 모르면 패널 안에 [얼굴 위치 직접 지정 (무료)] 안내.
- 같은 `renderProfile` 결과를 미리보기와 저장에 그대로 써서 보이는 모양 = 저장 모양. AI 호출 없음.
