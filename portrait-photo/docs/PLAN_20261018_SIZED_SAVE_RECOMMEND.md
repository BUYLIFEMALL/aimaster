# AI 인물사진 자동화 (`portrait-photo`) — 규격 저장 기본값을 「추천 영역」으로 (개발 플랜, 2026-10-18, Claude Code 윈도우)

> 상태: **주인님 승인 대기**. 승인 전 코드 변경 없음.
> **진행(2026-10-18)**: 주인님 승인 + "오늘 배포해"(같은 날 두 번째 빌드 — 주인님 지시로 추가) → 구현 시작.

## 1. 문제
- 생성 모델이 증명사진 머리 높이 기준(한국 여권 71~80% 등)을 잘 따르지 못한다. 실측(v1.07 운영 확인)에서 결과는 머리 약 43~56%에 머물렀다.
- 그런데 [규격 저장] 버튼은 **항상 사진 가운데를 기계적으로 자른다**(`saveSized` → `renderSized`, 영역 지정 없음 = `coverCrop`). 그래서 머리가 작게 나온 사진이 그대로 저장된다.
- 머리 위치를 이미 알고 있을 때(① [머리 비율 검사] AI 결과 `headMeasure`, ② 일괄 검사·직접 지정 결과 `measures`)도 기본 버튼은 그 값을 쓰지 않는다. 회원이 따로 나타나는 [얼굴 확대 자르기로 규격 저장] 버튼을 찾아 눌러야 하고, 이 버튼은 「작게 나옴」일 때만 보인다(「크게 나옴」은 대응 없음).

## 2. 해결 방향
**머리 위치를 알고 있으면 [규격 저장]이 자동으로 추천 영역으로 저장한다.** 모르면 지금처럼 가운데 자르기 + "머리 비율 검사를 하면 기준에 맞춘 영역으로 저장된다"는 안내를 보여 준다.
- AI 호출을 몰래 추가하지 않는다(비용). 머리 위치는 회원이 누른 [머리 비율 검사(AI 1회)]·일괄 검사·[얼굴 위치 직접 지정](무료)에서 얻은 값만 쓴다.

| 머리 비율 판정 | 지금 | 바꾼 뒤 [규격 저장] |
|---|---|---|
| 기준보다 작음 | 가운데 자르기(별도 버튼을 눌러야 확대) | 얼굴 쪽으로 확대해 기준 중앙값에 맞춤(`tightCrop`) |
| 기준보다 큼 | 가운데 자르기(대응 없음) | ~~가능한 만큼 넓게 잘라 머리 비율을 낮춤~~ → **구현 중 정정**: 기본 가운데 자르기가 이미 원본에서 자를 수 있는 최대 크기라 비율은 낮출 수 없음. 크기는 그대로 두고 머리가 잘리지 않게 위·가로 위치만 머리 기준으로 맞춤(`tightCrop` clamped) + "상체가 더 보이게 다시 만들기" 안내 |
| 범위 안 | 가운데 자르기 | 크기는 그대로, 얼굴을 가로 가운데로(`centerFaceCrop`) |
| 측정값 없음·기준 없는 규격 | 가운데 자르기 | 그대로 + 안내 |

## 3. 구현 순서
1. `src/lib/portrait/post.ts`에 순수 함수 `recommendSizedCrop(measure, preset, srcW, srcH)` 추가 → `{ mode: "tight"|"center"|"none", crop?, ratio?, achieved?, clamped? }`. 기존 `tightCrop`·`centerFaceCrop`·`headInCrop`·`evaluateHead` 재사용.
2. `Studio.tsx`
   - `saveSized`: 현재 사진의 측정값(`headMeasure`가 같은 사진이면 그것, 아니면 `measures[sourceIdx]`)으로 `recommendSizedCrop` → 영역이 있으면 그 영역으로 저장(측정 때와 이미지 크기가 다르면 `scaleCrop`). 파일 이름 `-추천`, 안내 문구에 "머리 약 X% → Y%(기준 A~B%)".
   - [규격 저장] 버튼 이름에 추천 적용 여부 표시(예: `규격 저장 · 추천 영역`).
   - 「작게 나옴」일 때만 보이던 [얼굴 확대 자르기로 규격 저장] 버튼과 `saveTight`는 기본 버튼이 같은 일을 하게 되므로 정리하고, 그 자리에 "규격 저장 시 추천 영역이 적용됩니다(머리 약 X% → Y%)" 안내 한 줄.
   - [자르기 영역 조정] 패널의 추천 영역 계산도 같은 함수로 맞춤(지금은 작음/큼 구분 없이 `tightCrop` — 결과는 같은 값이 되도록).
3. 일괄 모드 ZIP 저장(`saveSizedBatch`)은 이번에 바꾸지 않는다(이미 사진별 자동 지정 흐름이 있음). 「크게 나옴」 사진도 추천 영역을 쓰게 하는 건 백로그에 기록.
4. 매뉴얼 `/guide` ④ 절과 FAQ 「얼굴 확대 자르기」 문구를 새 동작에 맞게 수정.
