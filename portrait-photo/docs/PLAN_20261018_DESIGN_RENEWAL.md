## 2. 적용할 디자인 템플릿 — 「크리에이티브 아틀리에 스타일 — 포토 스튜디오 그래파이트 변형」 (새 이름, `DESIGN.md` 카탈로그 등록)
**이렇게 하려는 이유**
- 현황판 권장은 다크(미드나잇)입니다. 인물사진은 **결과 사진의 색(피부 톤·흰 배경)을 눈으로 판단하는 작업**이라, 색이 들어간 배경(푸른 미드나잇·크림)보다 **색이 치우치지 않은 중립 회색(그래파이트)** 이 맞습니다. 사진 보정 프로그램들이 회색 작업 화면을 쓰는 이유와 같습니다.
- 증명사진은 흰 배경이 많아 지금처럼 흰 화면에서는 사진 가장자리가 묻힙니다. 어두운 중립 배경이면 순백 정리 결과와 자르기 영역이 또렷하게 보입니다.
- 4컷 만화(코믹 파스텔, 라이트)·AI 이미지 스튜디오(럭셔리 다크, 골드)와 겹치지 않는 고유 분위기 — "사진관 촬영 스튜디오".

**사진관 느낌 요소**: 결과 무대 네 귀퉁이에 카메라 초점 표시(⌜⌝⌞⌟), 목적 프리셋 카드에 큰 이모티콘(🪪 증명 · 💼 비즈니스 · 📱 SNS · 🎬 시네마틱 · ✨ 자유), 단계 칩 ① 사진 → ② 목적·옵션 → ③ 만들기 → ④ 저장·규격.
모든 화면(만들기·내 기록·설정·매뉴얼·로그인·설치) 같은 배경·카드·테두리(지침 ⑪).

## 3. 구현 범위 (화면·문구만, 기능 로직은 그대로)
1. `globals.css` 토큰·공통 컴포넌트(카드·버튼·칩·입력·슬라이더·드롭존·후보 격자·비교 슬라이더·자르기 패널) 값 교체 — **클래스 이름은 그대로** 두어 `Studio.tsx`·`CropAdjuster.tsx`·`ZoomCompare.tsx` 로직을 건드리지 않음.
2. `Sidebar.tsx`: 브랜드 아이콘·단계 표시를 스튜디오 스타일로, 메뉴 항목·순서·계정 위치(메뉴 바로 아래)는 그대로. 메뉴 이름 `📖 연동 & 사용 매뉴얼`로 표준화.
3. `/studio`: 상단 단계 칩 띠 추가(표시만), 목적 카드 이모티콘·설명 정리, 결과 무대 초점 표시. 3열 배치·버튼 위치·동작은 유지.
4. `/guide` 비주얼 매뉴얼로 재구성(지침 ④·⑦): 안내 캐릭터 말풍선 소개, 4단계 흐름 그림(이모티콘+화살표), 목적 5종 비교 카드, **잘 나오는 사진 / 피할 사진 예시**(이모티콘 그림 카드 — 실제 사진 생성 비용 없음), 규격 저장·머리 비율 검사 순서 그림, 개인정보·공식 서류 주의, FAQ. 기존 6절 내용은 빠짐없이 옮김.
5. `/history`·`/settings`·`/login`·`/setup`: 같은 토큰 적용.
6. 모바일 375~390px: 위쪽 접는 메뉴 유지, 스튜디오 1열(결과 무대 먼저), 후보 격자 2열, 자르기 조절 손잡이 24px 이상.
