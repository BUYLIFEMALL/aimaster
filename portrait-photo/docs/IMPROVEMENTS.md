## 3. 다른 프로그램과 연계
- 결과 사진을 **AI 이미지 자동화**(ai-image-studio) 배경 교체·화질 개선으로 넘기기.
- 비즈니스 프로필 결과를 **AI 슬라이드·명함/이력서** 계열 프로그램의 프로필 이미지로 넘기기.
- SNS 목적 결과를 **INSTA/쓰레드 자동포스팅**의 프로필·게시 이미지 후보로.
- 같은 뼈대 프로그램(4컷 만화·banana-canvas·fashion-style·photo-remake-studio)은 각자 다른 변형으로 리뉴얼 중 — 공통 토큰 구조(맨 위 `:root` + 맨 끝 덮어쓰기)를 같이 쓰면 유지보수가 쉽다.

## 4. 타 프로그램 탐색 제안 (2026-10-18)
- banana-canvas·fashion-style·photo-remake-studio(80·82·83번)도 아직 흰 기본 뼈대 + 안 쓰는 성격 검사 CSS가 남아 있을 가능성이 높다(같은 뼈대) — 리뉴얼 때 함께 확인.
