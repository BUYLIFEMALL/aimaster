# 개발 플랜 — 비회원 주문 (D15, 2026-11-06)

주인님 결정(2026-11-06): 2차 후보 4번. 범위 질문에 「전체 비회원 주문」 선택.

## 문제
- 지금은 몰 손님이 로그인 + 몰 가입을 해야 장바구니·주문이 된다. 소비자 몰(V-A)이나 처음 오는 손님은 가입 없이 주문하고 싶어 한다.

## 범위
| 구분 | 내용 |
|---|---|
| 켜기 | 운영자 설정 「비회원 주문 허용」(기본 끔). 끄면 지금과 같다 |
| 장바구니 | 로그인 없이 담기 — 쿠키(`mb_cart_<몰>`)에 상품·옵션·수량(최대 20줄). 금액은 같은 가격 엔진(보는 사람 = 비회원) |
| 주문서 | 주문하는 분 이름·휴대폰·이메일(선택), 받는 분·주소(주소 찾기 재사용), 입금자명·메모. **무통장 입금만**(카드·외상·등급가·견적·세금계산서는 가입 손님만 — 2차) |
| 주문 | DB 함수 `mall_builder_place_guest_order`가 재고·가격·배송비를 다시 계산(가입 주문 함수와 같은 규칙, 등급가 없음). 사업자 전용·승인 후 가격 공개 상품은 비회원 주문 불가 |
| 조회 | 주문 직후 비밀 토큰(쿠키 `mb_guest_<몰>`, DB엔 해시)으로 주문 상세. 「주문 조회」 화면에서 주문번호+휴대폰으로 다시 찾으면 토큰이 새로 발급된다(옛 쿠키 무효) |
| 손님 동작 | 입금 전 주문 취소, 결제 후 취소 요청, 배송 완료 뒤 구매 확정·반품 요청(가입 손님과 같은 이동표). 재고 되돌림 동일 |
| 알림 | 문자는 받는 분 휴대폰(지금과 같음), 메일은 비회원 이메일 |
| 자동 | 입금 기한 자동 취소(D8)·자동 배송 완료·구매 확정(D12)·통계(D14, 구매 손님 수에 비회원 포함) 그대로 |
| 운영자 | 주문 목록·상세에 「비회원」 표시와 연락처 |

- 하지 않는 것: 비회원 카드 결제, 비회원 후기·문의(가입 손님만), 주문 조회에 비밀번호 추가(휴대폰 번호로 충분, 토큰은 매번 새로 발급)

## 구현
1. DB `0035_guest_order.sql`(추가만): 주문 표 `user_id` 필수 해제 + `is_guest`·`guest_name`·`guest_phone`·`guest_email`·`guest_token_hash` 칸, 검사 제약(비회원이면 이름·휴대폰 필수, 아니면 `user_id` 필수). 함수: `mall_builder_place_guest_order`, `mall_builder_guest_lookup`(토큰 재발급), `mall_builder_guest_order`(토큰으로 주문·품목·기록), `mall_builder_guest_change_status`. 알림 트리거(메일 주소 비회원 포함)·통계 함수(구매 손님 수) 다시 정의. 지우기 문장 없음
2. 공용 코드 `src/lib/guest.ts`(쿠키 장바구니 읽기·쓰기·합치기, 비회원 입력 검사, 토큰 쿠키) + 자동 시험
3. 화면: 상품 담기(비로그인 + 허용 몰이면 쿠키 장바구니), 장바구니·주문서 비회원 분기, `/guest`(주문 조회)·`/guest/orders/[id]`(비회원 주문 상세), 머리글(비회원 장바구니 수·주문 조회), 운영자 설정 「비회원 주문」·주문 상세 「비회원」 표시
4. 시험: DB 시험(되돌림 — 꺼진 몰 차단, 사업자 전용 차단, 가격 불일치 차단, 토큰 조회·재발급·취소·재고 되돌림), 자동 시험, 빌드, Lab 배포 뒤 ego(비로그인 탭 — 로그아웃 상태가 필요하므로 **DB·서버 동작 시험으로 대체하고 화면은 주인님 확인 순서에 넣음**)
