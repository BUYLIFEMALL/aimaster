## 1. 지금 구조
- 상품·옵션 읽기 규칙은 `mall_builder_product_visible()` 한 함수를 거침(사업자 전용 판단은 `mall_builder_shop_viewer()`). → 여기에 「폐쇄몰이면 승인 회원만」을 더하면 **DB 단계에서** 상품이 숨겨짐(화면만 가리는 것이 아님).
- 주문은 여러 DB 함수(회원 v2·비회원·견적)가 만듦 → 주문 표 **넣기 전 검사 트리거 하나**로 「폐쇄몰 미승인 손님 주문」을 모든 경로에서 막음(함수 수정 없음).
- 몰 설정은 `mall_builder_stores.settings`(jsonb, 운영자만 수정 — 비회원 주문 켬/끔도 여기). 손님 표에는 사업자 승인 칸만 있고 「몰 입장 승인」 칸은 없음 → 새 칸 `member_status` 추가.

## 2. 기능(제안)
| 기능 | 내용 |
|---|---|
| 폐쇄몰 켜기 | 설정에서 켬/끔. 켜면 비회원 주문은 자동으로 꺼짐 |
| 입장 방식 | 운영자 승인 / 초대 코드(코드를 넣고 가입하면 바로 승인) — 둘 다 또는 하나 |
| 승인 전 화면 | 「회원 전용 몰입니다」 안내 + 로그인·가입(코드 입력) — 상품·가격·카테고리·검색은 DB에서 숨김 |
| 운영자 | 손님 목록에 「입장 대기」 거르기·승인·반려(사유), 초대 코드 만들기·바꾸기·사용 수 |
| 알림 | 승인되면 손님에게 문자(주문 알림 문자를 켠 몰, 기존 발송 대기 줄) |

## 3. 결정 항목 (주인님께 여쭐 것)
1. **입장 방식**: (추천) 승인제와 초대 코드를 각각 켜고 끌 수 있게 / 승인제만 / 코드만
2. **초대 코드 형태**: (추천) 몰 공용 코드 1개(운영자가 언제든 바꿈, 사용 수 기록) / 사람마다 1회용 코드
3. **승인 전 보이는 것**: (추천) 몰 이름·안내 문구·로그인/가입만(첫 화면 블록·상품·공지 모두 숨김) / 첫 화면 블록·공지는 보이고 상품·가격만 숨김
4. **이미 가입한 손님**: (추천) 폐쇄몰을 켜도 기존 가입자는 그대로 입장 허용(승인 상태) / 모두 다시 승인 받기

## 4. 구현 순서(결정 뒤)
1. DB 0040: 손님 `member_status`(approved/pending/rejected, 기본 approved) · 초대 코드 표(운영자만, 코드는 해시 저장) · 가입 때 상태 정하는 트리거(기존 보호 트리거와 같은 방식) · `mall_builder_product_visible()`에 폐쇄몰 조건 · 주문 넣기 전 검사 트리거 · 승인/반려·코드 함수
2. 화면: 설정 「폐쇄몰」, 손님 목록 「입장 대기」·승인/반려, 가입 화면 초대 코드 칸, 손님 화면 입장 안내(가림)
