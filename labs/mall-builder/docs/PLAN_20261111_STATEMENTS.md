## 1. 문제
도매 거래는 물건과 함께 **거래명세서**를 넣고, 외상 거래처에는 매달 **외상 원장(거래 내역·잔액)**을 보낸다. 지금은 주문 상세 화면과 장부 표만 있어서 서류로 뽑을 수 없다.

## 2. 범위(안)
**거래명세서(주문 1건 = 1장)**
1. 양식: 제목 「거래명세서」, 공급자(몰 쇼핑몰 정보 — 상호·대표자·사업자번호·주소·전화), 공급받는자(손님 — 사업자면 상호·대표자·사업자번호, 아니면 이름), 거래일·주문번호, 품목표(품목·옵션·수량·단가·공급가액·세액, 과세/면세 표시), 배송비 줄, 할인(쿠폰·포인트) 줄, 합계(공급가액·세액·합계 금액), 부분 취소분은 뺀 수량
2. 세액 계산: 세금계산서(D19)와 같은 규칙 — 과세 줄은 `세액 = 금액 ÷ 11 반올림`, `공급가액 = 금액 − 세액`, 면세 줄은 세액 0
3. 운영자: 주문 상세 「거래명세서」 / 손님: 내 주문 상세 「거래명세서」
**외상 원장(손님 1명 × 기간)**
4. 기간(월 단위 기본, 직접 지정 가능) → 이월 잔액 · 기간 안 사용·입금·조정 내역(일자·구분·주문번호·금액·잔액) · 기말 잔액 · 외상 한도
5. 운영자: 손님 상세 「외상 원장」 / 손님: 마이페이지 외상 칸 「외상 원장」
**공통**
6. 서류 화면은 인쇄에 맞춘 A4 화면(메뉴·버튼은 인쇄 때 숨김), 「인쇄 / PDF로 저장」 버튼(브라우저 인쇄 → PDF 저장)
- DB 변경 없음(있는 주문·장부·사업자 정보만 읽음)
- 1차에서 하지 않음: 직인(도장) 그림, 여러 주문을 한 장에 묶은 월 거래명세서, 이메일로 바로 보내기
