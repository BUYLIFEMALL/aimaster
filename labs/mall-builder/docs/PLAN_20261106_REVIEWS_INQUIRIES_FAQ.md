# 개발 플랜 — 상품 후기·상품 문의·1:1 문의·FAQ (D13, 2026-11-06)

주인님 지시(2026-11-06): 「순서대로 진행해」 — 2차 후보 목록 순서대로. 1번 재고 선차감은 이미 구현돼 있음을 확인(주문 때 차감 0008, 카드 미결제 30분 자동 취소·재고 되돌림 0028) → 로드맵만 완료로 고치고 2번인 이 기능부터.

## 문제
- 손님이 상품에 대해 묻거나 구매 후기를 남길 곳이 없고, 운영자에게 따로 연락할 창구(1:1 문의)도 없다. 자주 묻는 질문(FAQ)도 공지에 섞어 써야 한다.

## 범위
| 기능 | 손님 | 운영자 |
|---|---|---|
| 상품 후기 | 배송 완료·구매 확정 주문의 품목마다 1개(별점 1~5 + 글). 주문 상세에서 쓰고 고치기·지우기. 상품 상세에 평균 별점·후기 목록(이름 가림 「김**」) | 후기 목록, 답글, 숨기기 |
| 상품 문의 | 상품 상세에서 질문(비밀글 선택). 비밀글은 본인·운영자만 내용이 보임 | 답변, 숨기기 |
| 1:1 문의 | 마이페이지 「1:1 문의」에서 질문(주문 선택 가능), 늘 비밀 | 답변 |
| FAQ | 「자주 묻는 질문」 화면(분류별 접기) | 질문·답변 쓰기·순서·공개 여부·삭제 |

- 쓰기는 이 몰에 가입한 손님만(비로그인·미가입은 안내).
- 답변이 달린 문의는 손님이 고칠 수 없다(지우기만).
- 하지 않는 것: 후기 사진 첨부, 답변 알림 문자·메일(다음 묶음 후보로 백로그), 적립금 지급(쿠폰·포인트 기능 때).

## 구현
1. DB `0033_reviews_inquiries_faq.sql`(추가만)
   - 0033a: 후기·문의 표(읽기는 운영자·본인만, 쓰기 규칙 없음 → 함수로만), FAQ 표(공지와 같은 규칙)
   - 0033b: FAQ 운영자 삭제 규칙
   - 0033c 함수: 후기 쓰기/지우기/운영자 처리, 상품 후기 목록(이름 가림·숨김 제외), 문의 쓰기/고치기/지우기/운영자 답변, 상품 문의 목록(비밀글 가림). 함수 안에 지우기 문장 없음(지우기 = 표시 칸).
   - 스팸 막기: 한 손님이 한 몰에 하루 문의 20개까지.
2. 공용 코드 `src/lib/reviews.ts`(입력 검사·이름 가림·별점 표시)와 자동 시험.
3. 화면: 상품 상세(후기·문의 칸), 주문 상세(품목별 후기 쓰기), 손님 `/inquiries`(1:1 문의)·`/faq`, 머리글 「FAQ」 링크, 마이페이지 「1:1 문의」 링크. 운영자 메뉴 「후기」「문의」「FAQ」.
4. 시험: DB 시험(되돌림 방식, 지우기 문장 없이) — 남의 주문 품목 후기 막힘, 배송 전 막힘, 비밀글 가림, 이름 가림, 미가입 막힘, 운영자 답변 뒤 손님 고치기 막힘. 자동 시험, 빌드, Lab 배포 뒤 화면 확인.
