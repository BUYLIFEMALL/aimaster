# 플랜 — D21 공동구매(목표 수량·마감, 못 채우면 일괄 취소·환불) (2026-11-09)

- 상태: **결정 대기**

## 1. 지금 구조에서 확인한 것
- 주문·결제: 무통장(입금 대기→결제 완료), 카드(토스, 30분 안 결제), 외상(사업자). 카드 취소·환불은 `mall_builder_card_cancel_order`(운영자 로그인 필요, 같은 환불은 중복 방지 키로 한 번만).
- 예약 실행: 몰 운영자 cron-job.org가 1분·10분마다 `/api/cron/deposit-expire`를 부르고, 그 안에서 자동 취소·자동 배송 완료·쿠폰/포인트 매일 작업이 돈다(로그인 없음, 몰 토큰).
- 부분 취소·쿠폰·포인트 되돌림·재고 되돌림은 이미 있음(D5·D17·D18) → 공동구매 실패 취소도 같은 길로.

## 2. 기능(제안)
| 기능 | 내용 |
|---|---|
| 공동구매 만들기 | 상품 하나에 목표 수량·시작/마감 시각·공동구매 가격(정해진 할인가)·1인 최대 수량 |
| 손님 화면 | 상품 상세에 진행 막대(현재 N개/목표 M개·남은 시간), 공동구매 가격으로 주문 |
| 주문 | 공동구매 상품은 **그 상품만 따로 주문**(다른 상품과 한 주문에 섞지 않음 — 실패 때 주문째 취소하려고) |
| 마감 판정 | 마감 시각이 지나면 예약 실행이 자동 판정: 목표 달성 → 「성공」(주문은 평소대로 배송 준비), 미달 → 「실패」 |
| 실패 처리 | 그 공동구매 주문을 모두 취소(재고·쿠폰·포인트 되돌림은 기존대로), 카드는 환불, 무통장 입금분은 환불 목록 |
| 알림 | 성공·실패를 참여 손님에게 문자(문자 알림을 켠 몰) |
| 운영자 화면 | 「공동구매」 메뉴: 목록·진행률·참여 주문·조기 마감·실패 처리 결과 |

## 3. 결정 항목 (주인님께 여쭐 것)
1. **결제 시점**: (추천) 참여할 때 바로 결제(카드·무통장·외상), 미달이면 취소·환불 / 참여는 신청만 받고 성공하면 그때 결제 안내
2. **실패 때 환불**: (추천) 마감 판정은 자동, 취소·환불은 운영자가 「미달 주문 일괄 취소·환불」 버튼 한 번(카드는 자동 환불, 무통장 입금분은 환불할 목록) / 판정과 환불 모두 자동(카드 환불을 예약 실행이 직접 — 운영자 확인 없이 돈이 나감)
3. **달성 수량 기준**: (추천) 결제 완료(카드·무통장 입금 확인·외상)된 수량만 / 입금 대기 주문도 포함
4. **가격 방식**: (추천) 정해진 공동구매 가격 하나 / 참여가 늘수록 가격이 내려가는 구간 가격(마감 뒤 차액 환불)
5. **쿠폰·포인트**: (추천) 공동구매 주문에도 쓸 수 있음(실패 취소 때 기존처럼 되돌림) / 공동구매에는 못 씀
