## 1. 지금 상태
로드맵 §2의 AI 기능 6개 중 「AI 견적 회신 보조」는 D27로 끝났다(실제 호출 시험은 키 등록 대기). 남은 5개를 정리한다.

| 기능 | 로드맵 우선 | 판단 |
|---|---|---|
| AI 상품 등록 도우미 | 높음 | 이번에 — 상품 화면에서 메모(+대표 사진) → 이름·한 줄 소개·설명·옵션 후보 → 운영자가 「칸에 채우기」 후 직접 저장 |
| AI 문의 답변 초안 | 중 | 이번에 — 문의 화면 「AI 초안」 → 상품 정보·FAQ·배송 정책으로 답변 초안을 답변 칸에 채움(보내기는 운영자) |
| AI 첫 화면 자동 구성 | 높음 | 이번에 — 업종 한 줄 + 카테고리·상품 목록 → D28 블록으로 초안을 만들어 **초안에만** 저장(게시는 운영자) |
| AI 가격 점검 | 낮음 | 이번에 — 원가·판매가·등급가·구간 할인·거래처 특가에서 마진이 기준(D27 최소 마진) 아래인 곳 경고 목록. **규칙 계산이라 AI 호출 없음** |
| AI 상세페이지 | 중 | 이번엔 뺌 — `shop-detail-page`는 `ecommerce-image` 역할 프로그램이라 연동 방식부터 협의(그 담당께 요청 남김). 짧은 상세 설명은 상품 도우미가 채움 |

## 2. 공통 구조
- 키·모델: D27에서 만든 몰 대표 본인 Anthropic 키(서버 암호화)·모델 선택을 그대로 쓴다 — 새로 묻지 않음(자동화 최소 설정 지침). 설정 칸 이름을 「🤖 AI 견적 보조」 → 「🤖 AI 도우미」로 바꾸고 설명에 쓰는 곳을 적는다
- 호출부: `ai-quote-server.ts`의 키 풀기·호출·오류 안내를 `ai-client.ts` 하나로 뽑아 4곳이 함께 씀(재시도 0, effort low, zod 구조화 응답)
- 권한: 상품 도우미·첫 화면·가격 점검은 「상품」 권한, 문의 초안은 「게시판」 권한(D22 묶음 이름 그대로). 키 암호문을 읽는 DB 함수의 권한 검사를 「주문·상품·게시판·첫 화면」으로 넓힘(DB 함수 1개 고침 `0049`)
- 기록: 결과는 화면에만 보여 주고 운영자가 저장할 때만 반영(자동 저장 없음). 호출마다 모델·토큰·대략 비용을 화면에 표시
- 연도: 프롬프트에 올해 연도 주입(핵심 원칙 8), 사람 묘사 없음
