## 2. 첫 작업 D30 정기 주문 (범위 안)

- **결제**: 외상(승인 거래처, 한도 안) 또는 무통장(입금 대기 주문을 만들고 입금 안내 문자·메일). **카드 자동결제(빌링키)는 다음 후보**
- **자동 실행**: 몰 운영자 본인 cron-job.org(D12와 같은 방식, 자동화 최소 설정 지침 — 처음 한 번 켜면 이후 자동). 하루 한 번 「오늘 주문일인 정기 주문」을 주문 DB 함수로 만듦(가격·재고·외상 한도는 주문 때와 똑같은 규칙)
- **안전**: 같은 회차 이중 주문 금지(회차 고유 키), 품절·외상 한도 초과·판매 중지면 만들지 않고 손님·운영자에게 알림 + 기록, 결과가 불확실하면 자동 재실행 안 함, 운영자 화면에 전체 일시정지 단추 1개
- **운영자**: 「정기 주문」 메뉴(목록·다음 주문일·최근 결과·실패 사유), 손님 상세에 그 거래처 정기 주문
- **DB**: 정기 주문 표·회차 기록 표·만들기 함수(Lab), 알림은 기존 문자·메일(D9·D10)

## 6. D30 결과 (2026-11-11)
- **DB `0050`**(Lab 적용): 정기 주문·회차·설정 표(RLS: 손님 본인 + 「주문」 권한 직원 읽기, 쓰기는 함수로만), 날짜 함수 2개, 만들기·바꾸기·전체 일시정지·예약 실행 함수. 주문 함수 `place_order_v2`는 한 곳만 바꿈 — 정기 실행 중에만 「화면에서 본 금액」 확인을 건너뜀(금액은 서버 계산)
- **실행 방식**: 예약 실행 함수가 요청 범위 안에서만 그 거래처로(auth.uid) 장바구니에 정기 품목을 담아 같은 주문 함수를 부르고 원래 장바구니를 되돌림. 실패하면 저장점까지 되돌아감. 회차 (정기 주문, 주문일) 고유라 같은 날 두 번 주문 없음, 실패해도 그날 다시 시도하지 않고 다음 주문일로. 한국 8시 이후, 한 번에 30개
- **화면**: 손님 주문 상세 「🔁 이 주문을 정기 주문으로 만들기」(주기·요일/날짜·시작일·결제·배송지·입금자, 다음 주문일 3개 미리보기), 마이페이지 「🔁 정기 주문」(일시정지·다시 시작·건너뛰기·해지·수량), 운영자 「정기 주문」 메뉴(「주문」 권한, 전체 일시정지 단추, 자동 실행 꺼짐 경고, 최근 회차·실패 사유). 예약 실행 주소에 한 단계 추가
- **시험**: 날짜 계산 5개(말일·해 넘김), 전체 228개·tsc·빌드. DB 되돌림 시험 — 외상 한도 초과·재고 부족·최소 수량 미달은 실패 기록 + 장바구니 그대로 + 다음 주문일로, 같은 날 다시 실행해도 회차 1개, 무통장 성공 시 주문 생성(84,600원)·재고 차감·기존 새 주문 알림 4건 대기·장바구니 복원, 다른 손님은 보지도 바꾸지도 못함. ego(손님 만들기→건너뛰기→수량→일시정지→다시 시작, 운영자 목록·전체 멈춤/켬, 390px) — 시험 정기 주문은 해지해 둠
- 한계: 화면 앞에 다른 작업 공간이 있어 버튼은 화면 안 제출로 눌렀음. 실제 예약 실행(8시 이후 cron)으로 만든 주문은 배포 뒤 확인

## 8. D32 앱(PWA) (플랜, 2026-11-11)
- **지금**: 앱 설명 파일(manifest)·아이콘·서비스 워커·몰 로고 칸이 모두 없음. 손님 화면 제목도 몰마다 따로 정하지 않음
- **목표**: 거래처 담당자가 휴대폰 홈 화면에 **그 몰 이름·아이콘으로** 설치해 바로 재주문(빠른 주문·정기 주문으로 이어짐)
- **할 일(안)**
  1. 몰마다 앱 설명 파일 `/s/<몰>/manifest.webmanifest` — 이름·짧은 이름·시작 주소(그 몰 첫 화면)·색·아이콘. 하위 도메인 주소에서도 같은 파일
  2. 아이콘: 「쇼핑몰 정보」에 **몰 로고(정사각 그림) 칸** 추가 → 있으면 로고, 없으면 **몰 이름 첫 글자 자동 아이콘**(서버에서 그림 생성, 192·512)
  3. 서비스 워커(가벼운 것): 화면 껍데기만 저장, 네트워크가 끊기면 「연결이 끊겼습니다」 안내 화면. **가격·장바구니·주문은 저장하지 않음**(항상 최신 가격)
  4. 손님 화면 「📲 홈 화면에 추가」 안내: 안드로이드·PC 크롬은 설치 단추, 아이폰은 「공유 → 홈 화면에 추가」 그림 안내. 닫으면 30일 안 보임(이 기기 저장)
  5. 손님 화면 제목·설명을 몰 이름으로(검색·공유 미리보기에도 몰 이름)
- **결정 항목**
  | 번호 | 결정할 것 | 추천안 | 다른 안 |
  |---|---|---|---|
  | 1 | 범위 | **설치 + 끊김 안내까지**(푸시 알림은 다음 — 몰마다 알림 키·구독 저장·발송 서버가 필요해 큰 공사) | 푸시 알림까지 이번에 |
  | 2 | 아이콘 | **몰 로고 칸 추가 + 없으면 첫 글자 자동 아이콘** | 첫 글자 자동 아이콘만 |
  | 3 | 설치 안내 | **손님 화면 아래쪽 작은 안내 띠, 닫으면 30일 숨김, 로그인한 사업자 손님에게만** | 모든 손님에게 / 안내 없이 설치 메뉴만 |
- **비용**: 없음(저장 용량은 로고 그림 1장, 기존 그림 저장소)
