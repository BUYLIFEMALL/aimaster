# 통계·추이 대시보드 개발 플랜 (2026-10-31)

주인님 지시: 매물 알림처럼 상가 쪽도 대시보드와 분석 표를 같은 스타일·기능으로 확장.
기준 코드: `realty-listing-alert`의 `app/results/StatsDashboard.tsx`, `extension/lib/stats.js`, `extension/lib/aiSummary.js`, `extension/lib/weekly.js`. 프로그램끼리 호출하지 않고 복사해 상가 항목에 맞게 고친다.

## 범위
1. 확장: 수집마다 요약 기록과 변동 기록을 회원 PC에 저장(최근 1년, 제3자 개인정보 없음).
2. 결과 화면 위쪽: 카드 4개(지금 매물, 새 매물, 가격 내림·오름, 사라진 매물), 카드 누르면 아래 표 거르기.
3. 추이 그래프: 감시 화면·유형·거래 종류·기간(1·3·6개월, 1년) 선택, 매물 수와 평균 가격.
4. 비교 표: 감시 화면×유형별 매물 수, 매매 평균, 평당가, 실거래 대비, 월세 평균, 평균 추정 수익률, 실거래 목록 바로가기.
5. AI 한 줄 요약: 기존 AI 요약 버튼에 통계 추이를 더함(회원 본인 키, 누를 때만).
6. 주간 리포트: 지난주 요약을 화면에 접어 표시하고 켠 채널로 발송.

## 하지 않는 것
- 전세 평균·전세가율: 상가·건물·토지에 맞지 않아 월세·수익률로 대체.
- 블로그 글쓰기 연결: 2차로 분리.
