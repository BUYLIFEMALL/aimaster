이 안내는 Google Cloud를 처음 써 보는 분도 그림 없이 글만 보고 따라 할 수 있게 한 단계씩 풀어 쓴 것입니다. 전체 소요 시간은 약 10~15분이고, 한 번만 하면 됩니다. 비용은 무료입니다.

먼저 알아두세요

  • 왜 해야 하나요? 이 프로그램은 운영자의 구글 앱을 빌려 쓰지 않고, 내가 직접 만든 구글 앱으로 내 구글 드라이브에 연결합니다. 그래서 내 문서는 내 드라이브에만 저장되고 운영자도 볼 수 없습니다. 이 앱의 "신분증" 역할을 하는 것이 클라이언트 ID입니다.
  • 무엇을 만드나요? ① 구글 클라우드 프로젝트(앱을 담는 상자) ② 드라이브 사용 설정 ③ 동의 화면(앱 소개) ④ 클라이언트 ID(웹 앱 신분증). 이 4가지입니다.
  • 안전한가요? 프로그램은 drive.file이라는 가장 좁은 권한만 요청합니다. 이 프로그램이 만든 파일만 볼 수 있고, 내 드라이브의 다른 파일은 볼 수 없습니다. 파일은 지우지도 않습니다.
  • 준비물: 구글 계정(Gmail), 크롬 같은 최신 브라우저, 그리고 프로그램 설정 화면에 표시된 내 사이트 주소(예: https://markdown-studio.buylife.xyz). 주소는 설정 화면의 "주소 복사" 버튼으로 복사해 두세요.
  • 화면이 조금 다를 수 있어요. 구글이 화면을 자주 바꿉니다. 메뉴 이름이 약간 달라도 같은 이름의 항목을 찾아 누르면 됩니다. 영어로 보이면 오른쪽 위 설정에서 언어를 한국어로 바꾸거나, 괄호 안의 영어 이름을 찾으세요.

1단계. 구글 클라우드에 로그인하기

  1. 새 탭에서 console.cloud.google.com을 엽니다.
  2. 드라이브를 연결할 구글 계정으로 로그인합니다. 계정이 여러 개라면 오른쪽 위 동그란 프로필 사진을 눌러 올바른 계정인지 확인하세요.
  3. 처음이라면 "이용약관 동의" 창이 나올 수 있습니다. 국가를 대한민국으로 두고 약관에 체크한 뒤 동의 및 계속을 누르세요. (결제 정보 입력은 요구하지 않습니다. 결제 정보를 넣으라는 화면이 나오면 건너뛰어도 됩니다.)

✅ 이렇게 보이면 성공: 파란색 Google Cloud 로고가 있는 화면이 열립니다.

2단계. 프로젝트 만들기

  1. 화면 맨 위 왼쪽, Google Cloud 로고 옆의 프로젝트 선택 상자(프로젝트 이름이나 "프로젝트 선택"이라고 적힌 곳)를 누릅니다.
  2. 작은 창 오른쪽 위의 새 프로젝트(New project)를 누릅니다.
  3. 프로젝트 이름에 알아보기 쉬운 이름을 적습니다. 예: my-markdown-drive (영어·숫자·하이픈 권장)
  4. "위치"(조직)는 그대로 둡니다. 만들기를 누르세요.
  5. 몇 초 뒤 오른쪽 위 알림(종 모양)에 "프로젝트가 생성되었습니다"가 뜨면 프로젝트 선택을 눌러 방금 만든 프로젝트로 들어갑니다.

✅ 이렇게 보이면 성공: 맨 위 왼쪽 프로젝트 이름이 내가 만든 이름으로 바뀌어 있습니다. 이후 모든 단계는 반드시 이 프로젝트 안에서 진행하세요. (이미 쓰는 프로젝트가 있으면 새로 만들지 않고 그 프로젝트를 골라도 됩니다.)

3단계. 구글 드라이브 사용 설정하기

  1. 왼쪽 위 ☰ 메뉴(줄 3개)를 누릅니다.
  2. API 및 서비스 → 라이브러리를 누릅니다.
  3. 가운데 검색창에 Google Drive API를 입력하고 검색 결과에서 Google Drive API를 누릅니다. (비슷한 이름이 여러 개면 "Google Enterprise API"가 붙은 곳의 Google Drive API를 고르세요.)
  4. 파란색 사용(Enable) 버튼을 누릅니다. 이미 사용 중이면 "API 관리"라고 표시되며, 그대로 두면 됩니다.

✅ 이렇게 보이면 성공: 화면에 "API가 사용 설정됨" 또는 "API 관리" 버튼이 보입니다.

4단계. 동의 화면 만들기 (앱 소개 입력)

구글이 "이 앱이 내 드라이브에 접근해도 되나요?"라고 물을 때 보여주는 화면을 준비하는 단계입니다.

  1. 왼쪽 ☰ 메뉴 → API 및 서비스 → OAuth 동의 화면을 누릅니다. 최신 화면에서는 Google 인증 플랫폼(Google Auth Platform)이 열리고 "시작하기" 버튼이 보입니다. 누르세요.
  2. 앱 정보: 앱 이름에 내 마크다운 문서처럼 아무 이름이나 적고, 사용자 지원 이메일은 목록에서 내 이메일을 고릅니다. 다음을 누릅니다.
  3. 대상(Audience): 외부(External)를 선택하고 다음을 누릅니다. (개인 Gmail은 "외부"만 선택할 수 있습니다.)
  4. 연락처 정보: 내 이메일을 입력하고 다음을 누릅니다.
  5. 완료: "Google API 서비스 사용자 데이터 정책에 동의합니다"에 체크하고 계속 → 만들기를 누릅니다.

✅ 이렇게 보이면 성공: 왼쪽에 개요 · 브랜딩 · 대상 · 클라이언트 · 데이터 액세스 같은 메뉴가 나타납니다. (옛 화면이면 "게시 상태: 테스트"가 보입니다.)

5단계. 내 계정을 테스트 사용자로 추가하기 (가장 많이 빠뜨리는 단계!)

앱이 "테스트" 상태일 때는 미리 등록한 사람만 로그인할 수 있습니다. 이 단계를 빠뜨리면 내 계정으로도 "액세스 차단됨" 오류가 나옵니다.

  1. 왼쪽 메뉴에서 대상(Audience)을 누릅니다. (옛 화면은 OAuth 동의 화면 안의 "테스트 사용자" 영역)
  2. 화면을 아래로 내려 테스트 사용자(Test users) 항목을 찾아 + Add users(사용자 추가)를 누릅니다.
  3. 드라이브를 연결할 내 구글 이메일을 입력하고 저장을 누릅니다. (여러 명이 같은 프로젝트를 쓰면 줄마다 한 명씩 추가)

✅ 이렇게 보이면 성공: 테스트 사용자 목록에 내 이메일이 나타납니다. 상단의 게시 상태는 테스트(Testing) 그대로 두면 됩니다.

6단계. 클라이언트 ID 만들기 (핵심 단계)

  1. 왼쪽 메뉴에서 클라이언트(Clients)를 누릅니다. (옛 화면: ☰ → API 및 서비스 → 사용자 인증 정보 → 위쪽 + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID)
  2. + 클라이언트 만들기(Create client)를 누릅니다.
  3. 애플리케이션 유형에서 반드시 웹 애플리케이션(Web application)을 고르세요. (데스크톱, Android, iOS 등을 고르면 동작하지 않습니다.)
  4. 이름은 아무거나 적습니다. 예: markdown-drive
  5. 아래로 내려 승인된 JavaScript 원본(Authorized JavaScript origins) 영역을 찾아 + URI 추가를 누릅니다.
  6. 나타난 입력칸에 프로그램 설정 화면에 표시된 주소를 그대로 붙여 넣습니다. 예:
    https://markdown-studio.buylife.xyz
    ※ 맨 끝에 /를 붙이지 마세요. 앞의 https://는 꼭 있어야 하고, 주소 뒤에 다른 글자(/settings 등)를 붙이면 안 됩니다.
  7. "승인된 리디렉션 URI" 영역은 비워 둡니다. 이름이 비슷해 헷갈리기 쉬운데, 이 프로그램은 리디렉션 방식을 쓰지 않습니다.
  8. 맨 아래 만들기(Create)를 누릅니다.

✅ 이렇게 보이면 성공: "OAuth 클라이언트가 생성되었습니다" 창이 나타나고 클라이언트 ID(숫자-문자.apps.googleusercontent.com 모양)가 보입니다.

⚠️ 같은 창에 클라이언트 보안 비밀번호(Client secret)도 보일 수 있습니다. 이 프로그램은 사용하지 않으니 복사하거나 어디에도 입력하지 마세요.

7단계. 클라이언트 ID 복사하기

  1. 생성 완료 창의 클라이언트 ID 오른쪽 복사 아이콘(📋)을 누릅니다.
  2. 창을 닫았다면 왼쪽 클라이언트 메뉴에서 방금 만든 클라이언트를 눌러 열면 오른쪽에 클라이언트 ID가 다시 보입니다.
  3. .apps.googleusercontent.com까지 한 줄 전체가 복사되어야 합니다.

💡 클라이언트 ID는 비밀번호가 아니라 앱의 이름표 같은 공개 정보입니다. 다만 클라이언트 보안 비밀번호(Secret)는 절대 남에게 보여주지 마세요.

8단계. 프로그램에 입력하고 연결하기

  1. 프로그램의 API키등록·플랫폼연동 화면으로 돌아옵니다.
  2. Google Client ID 입력칸에 복사한 값을 붙여 넣고 Client ID 저장을 누릅니다. ("Client ID를 이 브라우저에 저장했습니다"가 뜹니다.)
  3. Google에 연결 버튼을 누릅니다. 작은 구글 창이 열립니다. (팝업이 차단되면 주소창 오른쪽의 차단 표시를 눌러 허용하세요.)
  4. 드라이브를 연결할 내 계정을 고릅니다.
  5. "Google에서 확인하지 않은 앱" 안내가 나오면 고급 → (앱 이름)(안전하지 않음)으로 이동을 누릅니다. (내가 만든 앱이라서 나오는 정상적인 안내입니다.)
  6. Google 드라이브에서 이 앱이 만든 파일 보기 및 관리 같은 항목에 체크한 뒤 계속을 누릅니다. 체크를 해제하면 연결이 되지 않습니다.

✅ 이렇게 보이면 성공: 설정 화면에 "연결됨: 내 이메일"이 표시됩니다.

9단계. 잘 되는지 시험해 보기

  1. 프로그램 왼쪽 메뉴에서 4. 문서 보관함을 누릅니다. (주소창에 직접 입력하지 말고 메뉴를 눌러 이동하세요. 새로고침하면 연결이 풀려 다시 연결해야 합니다.)
  2. 맨 아래 Google Drive 카드에서 현재 문서 올리기를 누릅니다.
  3. 구글 드라이브(drive.google.com)를 열면 "마크다운 문서 자동화" 폴더가 생기고 그 안에 문서가 올라와 있습니다.

막혔을 때 (오류별 해결 방법)

구글 창에 "오류 400: origin_mismatch"가 나와요

  • 6단계의 승인된 JavaScript 원본에 주소가 없거나 틀린 것입니다. 클라이언트를 열어 주소를 확인하세요. 끝의 /, 공백, 오타가 없어야 합니다.
  • 리디렉션 URI 칸이 아니라 JavaScript 원본 칸인지 확인하세요.
  • 저장 직후에는 반영까지 5분(길면 몇 시간) 걸릴 수 있습니다. 잠시 기다린 뒤 다시 시도하세요.

"액세스 차단됨" 또는 "access_denied"가 나와요

  • 5단계의 테스트 사용자에 내 이메일이 없는 것입니다. 추가하세요. 구글 창에서 고른 계정이 등록한 계정과 같은지도 확인하세요.

구글 창이 열리자마자 닫혀요 / "연결 창이 닫혔습니다"

  • 브라우저가 팝업을 막은 것일 수 있습니다. 주소창 오른쪽의 팝업 차단 표시를 눌러 항상 허용하고 다시 시도하세요.
  • 위의 origin_mismatch 때문에 구글이 창을 바로 닫는 경우도 있으니 6단계 주소를 다시 확인하세요.

연결은 됐는데 "Drive API가 사용 설정되어 있지 않습니다"라고 나와요

  • 3단계를 클라이언트를 만든 같은 프로젝트에서 했는지 확인하세요. 프로젝트가 다르면 소용이 없습니다. 맨 위 프로젝트 이름을 확인하고 3단계를 다시 하세요.

"Drive 파일 접근" 권한이 없다고 나와요

  • 8단계 마지막의 체크 항목을 해제한 경우입니다. 설정 화면에서 Google에 연결을 다시 누르고 해당 항목에 체크하세요.

잘못된 클라이언트 ID라고 나와요

  • 숫자-문자.apps.googleusercontent.com 형태 한 줄 전체인지 확인하세요. 앞뒤 공백이나 줄바꿈이 섞이지 않았는지, 보안 비밀번호(Secret)를 넣지 않았는지도 확인하세요.

새로고침했더니 연결이 풀렸어요

  • 정상입니다. 보안을 위해 접근 허가 정보는 이 브라우저 화면 메모리에만 두고 저장하지 않습니다. Google에 연결을 다시 누르면 되고, 클라이언트 ID는 그대로 기억됩니다.

자주 묻는 질문

  • 비용이 드나요? 아니요. 구글 클라우드 프로젝트와 OAuth 클라이언트 만들기, 드라이브 API 사용은 무료입니다. 결제 수단을 등록할 필요가 없습니다.
  • 내 드라이브의 다른 파일도 보이나요? 아니요. 이 프로그램이 만든 파일(그리고 "마크다운 문서 자동화" 폴더 안의 항목)만 접근합니다.
  • 이미 구글 클라우드를 쓰고 있어요. 새 프로젝트를 만들지 않아도 됩니다. 기존 프로젝트에서 3~7단계를 하면 되고, 이미 만든 웹 애플리케이션 클라이언트가 있으면 승인된 JavaScript 원본에 주소만 추가해도 됩니다(기존 항목은 지우지 마세요).
  • "테스트" 상태로 계속 써도 되나요? 네, 본인과 등록한 테스트 사용자만 쓰는 개인용이면 충분합니다.
  • 연결을 끊고 싶어요. 프로그램의 연결 해제 버튼을 누르세요. 구글 쪽에서도 끊으려면 myaccount.google.com/permissions에서 이 앱을 찾아 "액세스 권한 삭제"를 누르면 됩니다. 드라이브의 파일은 지워지지 않습니다.
  • 다른 사람이 내 앱을 쓸 수 있나요? 클라이언트 ID가 알려져도 내가 등록한 테스트 사용자만 로그인할 수 있고, 연결된 정보는 각자의 브라우저에만 저장됩니다.

설정 완료 체크리스트

  • ☐ 내 프로젝트가 만들어졌고 맨 위에 그 이름이 보인다
  • ☐ Google Drive API가 "사용"으로 되어 있다
