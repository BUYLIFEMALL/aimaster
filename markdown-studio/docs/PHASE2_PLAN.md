## 2. 설계 원칙

1. **명령은 순수 함수**로 만든다: `(text, selection, option) → { text, selection }`. `src/lib/editor/commands.ts`에 두고 Node 단위 시험을 붙인다. CodeMirror는 이를 트랜잭션으로 적용하는 얇은 어댑터.
2. 미리보기와 3단계 변환이 같은 Marked 설정(알파벳 목록 확장 포함)을 쓰도록 `sanitizedMarkdown`을 공용 모듈로 분리한다.
3. 기존 저장 계층(`WorkspaceProvider`/`repository`)은 변경하지 않는다. 편집기는 `draft.markdown`을 받고 `store.edit`로 내보내는 입출력만 교체한다.
4. 원본 결함은 복제하지 않는다 (검색 정규식 오류, 작동 없는 단축키, 체크박스 이어쓰기 없음).

## 3. 구현 범위

### 3-1. 서식 명령 20개 (원본 동일) + 보완

| 그룹 | 명령 | 동작 정의 (원본 대비 보완) |
|---|---|---|
| 제목 | H1·H2·H3 | 선택한 **모든 줄**의 기존 `#` 접두를 교체, 같은 단계를 다시 누르면 해제(토글) |
| 글자 | 굵게·기울임·취소선 | 선택을 `**`/`*`/`~~`로 감쌈, 이미 감싸져 있으면 해제, 선택 없으면 기호 쌍 삽입 후 커서를 가운데로 |
| 목록 | 글머리(`- `)·숫자(`1. `)·알파벳(`a. `) | 선택 줄 전체에 적용, 같은 종류면 해제, 다른 종류면 교체. Enter: 번호/알파벳 증가, 빈 항목에서 종료 |
| 체크 | 체크리스트 | `- [ ] ` 적용·해제, Enter 시 새 `- [ ] ` 자동 이어쓰기 (원본 결함 보완) |
| 들여쓰기 | 들여쓰기·내어쓰기 | 선택 줄에 공백 2칸 가감, Tab/Shift+Tab 연결 |
| 블록 | 인용·코드 블록·구분선 | 인용 줄 단위 토글, 코드는 **언어 선택** 목록(없음/js/ts/py/json/bash 등), 구분선은 앞뒤 빈 줄 보장 |
| 삽입 | 링크·이미지 | URL 입력창, `http(s)`/`mailto`/상대경로만 허용, 선택을 표시 문구로 사용. 로컬 이미지 등록은 3단계(자산 저장) |
| 표 | 표 삽입·행 추가·열 추가 | 삽입 시 행·열 수 지정(기본 3×2). **행/열 삭제, 열 정렬(왼/가운데/오른) 추가**. 셀의 `\|`·코드 블록 안의 `\|` 처리 |
| 기타 | 특수기호 32개·원문 복사 | 32개 기호 팝업(원본 목록과 동일), 복사 실패 안내 |
| 추가 | 실행 취소·다시 실행·찾기/바꾸기 | 한글 패널, 대소문자·정규식 옵션은 **끄는 것이 기본**이며 잘못된 정규식도 오류 없이 안내 |

### 3-2. 단축키
`Mod-B` 굵게, `Mod-I` 기울임, `Mod-K` 링크, `Mod-S` 저장(기존 유지), `Mod-Z`/`Mod-Shift-Z` 실행 취소·다시 실행, `Mod-F`/`Mod-H` 찾기·바꾸기, `Tab`/`Shift-Tab` 들여쓰기. 도움말 표와 실제 동작을 일치시키고 시험으로 증명한다 (원본은 안내와 불일치).

### 3-3. 미리보기·편의
HTML 소스 보기(밝은 배경)와 복사, Markdown/HTML 복사, 목차(제목 목록 클릭 이동), 글자 수·단어 수, 표 열 정렬 유지(기존 CSS 점검), 링크 `rel` 처리, 알파벳 목록 렌더링, 편집↔미리보기 스크롤 동기화(선택, 성능 문제 시 제외).

### 3-4. 탐색기·화면
분할 비율·탐색기 접힘 복원(1단계에 구현됨, 유지). 모바일 도구 모음 가로 스크롤, 탐색기 서랍 방식 개선 여부는 390px 측정 후 결정. **이번 2단계에서는 새 저장 구조·DB 변경 없음.**

## 4. 결정 사항 (제 판단으로 확정, 이의 시 변경)

1. 편집기: CodeMirror 6 (`@codemirror/state`, `view`, `commands`, `language`, `lang-markdown`, `search`) — 정확한 버전으로 고정, `npm audit`·라이선스(MIT) 확인.
2. 기본 목록 3종 외 순서 있는 목록의 시작 번호는 보존.
3. **알파벳 목록**: 공용 Marked 확장으로 `a.` 연속 줄을 `<ol type="a">` 렌더. 중첩·혼합 시 규칙은 단위 시험으로 고정. 다른 마크다운 앱에서는 일반 문단으로 보일 수 있음을 사용 안내에 한 줄 표기.
4. 편집기 테마는 흰색 기반(웹 공통 규칙), 줄 번호는 선택 사항 끔.
5. 줄바꿈 처리: 기본 줄 감싸기 켬 (모바일 가독).

## 6. 위험과 대응

- CodeMirror 도입으로 기존 UI 시험 재작성 필요 (일정 위험) → G 단계에 포함.
- IME 조합 중 자동 저장/상태 갱신이 입력을 끊을 수 있음 → 조합 중에는 상태 갱신 호출만 하고 편집기 문서는 편집기가 소유, 시험으로 증명.
- 큰 문서(예: 1MB) 성능 → 미리보기는 지연 값 사용 중. 측정 후 필요하면 디바운스 상향.
- 알파벳 목록 확장이 GFM 표준과 달라 변환 단계(3단계)에서 불일치 → 공용 모듈 사용을 3단계 완료 기준에 추가.
