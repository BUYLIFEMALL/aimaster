## 1. 디자인 업그레이드 개요

기존의 밋밋하고 딱딱했던 기능 중심 인터페이스에서 탈피하여, 사용자가 첫 화면에서부터 몰입감을 느끼고 직관적으로 문서를 작성·관리·변환할 수 있도록 **포커스 스튜디오(Focus Studio) 템플릿**을 적용하고, **연동 & 사용 매뉴얼(/guide)**을 비주얼 가이드북으로 전면 개편하였습니다.

---

## 2. 주요 디자인 구현 내역

### 2.1 대시보드 (`/dashboard`)
1. **히어로 웰컴 배너 (`.studio-hero`)**:
   - 딥 인디고 그라데이션(`linear-gradient(135deg, #4f46e5 0%, #3730a3 50%, #1e1b4b 100%)`)으로 전문가용 작업공간의 신뢰감과 깊이감 부여.
   - 반투명 블러 뱃지: `✨ Focus Studio 템플릿`
   - 직관적인 3대 빠른 시작 퀵 버튼: `새 문서 시작하기`, `에디터 열기`, `보관함 둘러보기`
2. **현대적 3대 지표 통계 그리드 (`.studio-stat-grid`)**:
   - 보관된 마크다운 문서(인디고 아이콘), 생성된 카테고리 폴더(에메랄드 아이콘), 실시간 버전 복원(앰버 아이콘).
   - 카드 호버 시 부드러운 엘리베이션 입체 효과 (`transform: translateY(-2px)`).
3. **최근 작업 문서 그리드 뷰 (`.recent-docs-grid`)**:
   - 기존의 단순 줄글 목록을 대체하여, 마크다운 본문 발췌 미리보기(2줄)와 수정 횟수 뱃지, 최종 수정 일시가 포함된 카드 뷰로 제공.
4. **부드러운 일러스트형 빈 상태 (`.empty-state-card`)**:
   - 보관된 문서가 없을 때 라운드 점선 보더와 보라색 스파클 아이콘, 친절한 작성 유도 버튼 제공.

### 2.2 연동 & 사용 매뉴얼 (`/guide`)
1. **시각적 프로세스 다이어그램 (`.guide-flow-diagram`)**:
   - 최상단에 4단계 스텝 박스(`1. 문서 준비 📄` ➔ `2. 편집 & 미리보기 ✍️` ➔ `3. 변환 & 내보내기 📦` ➔ `4. 보관 & 드라이브 🗄️`)를 시각적으로 연결.
2. **단계별 비주얼 라운드 카드**:
   - 각 단계마다 대표 아이콘 아바타와 `Step 01 ~ Step 04` 뱃지 배치.
   - 단축키 치트시트 칩 6종(`Ctrl+B`, `Ctrl+S`, `Ctrl+K` 등) 시각화.
3. **4대 포맷 쇼케이스 카드 (`.format-showcase-grid`)**:
   - PDF(레드), Word(블루), HTML(오렌지), ZIP(그린)의 4대 포맷 미니어처 쇼케이스 카드 배치.
4. **인포박스 시스템**:
   - 💡 팁 박스(초록 파스텔): 이름 중복 시 `(2)` 자동 보호 원리 및 모바일 탭 최적화 안내.
   - 🔒 보안 주의 박스(앰버 파스텔): 회원 본인 1:1 OAuth 토큰의 브라우저 메모리 안전 보관 원칙.
   - 🛡️ 데이터 보관 안내 박스(블루 파스텔): IndexedDB 보관 원리 및 주기적 백업 권장.

## 3. 디자인 유지보수 시 유의사항 (Design Caveats & Constraints)

다음 작업자 및 유지보수 시 반드시 아래 규칙을 준수해야 합니다:

1. **사이드바 레이아웃 표준 준수**:
   - 좌측 사이드바는 폭 244px 고정이며, 하단 계정 블록(`buylifemall@naver.com`)은 메뉴 바로 아래에 밀착되어야 함 (`margin-top: auto` 등으로 맨 아래로 강제 밀지 말 것).
   - 모바일(폭 767px 이하)에서는 좌측 사이드바가 자동으로 숨겨지고 상단 햄버거 메뉴(`☰`)로 전환되어야 함.
2. **색상 및 대비율 (Color Tokens)**:
   - 주요 텍스트는 `#1e293b`(Slate 800) 이상을 유지하여 WCAG 2.1 명도 대비(4.5:1 이상)를 충족해야 함.
   - 배경은 깨끗하고 편안한 `#fafbfc`, 카드 표면은 순백색 `#ffffff` 사용.
3. **단축키 및 인터랙션 요소**:
   - 에디터 내 단축키(`Ctrl+S` 등)는 브라우저 기본 동작을 가로채고 자동 저장 함수를 호출하므로, 서식 변경 시 이벤트 버블링에 주의.
4. **회원 본인 키/계정 절대 불변 원칙**:
   - Google Drive 연동 안내 및 UI 컴포넌트에서 운영자 공용 앱을 사용하도록 유도하는 UI를 절대 만들지 말 것 (회원 각자 본인의 Google Cloud Client ID 등록 필수).
