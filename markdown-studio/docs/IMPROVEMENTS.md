## 2. 프로그램 검토 중 발견된 개선 과제 및 상세 제안

### [영역 1] 프로그램 로직 및 데이터 무결성 (Logic & Integrity)

| 과제명 | 현황 및 분석 | 구체적 개선 방안 | 기대 효과 및 난이도 |
| :--- | :--- | :--- | :--- |
| **타이핑 지연 저장 (Debounce & Flush)** | 현재 에디터에서 글자 입력 시마다 즉각적인 로컬 I/O나 상태 갱신이 빈번하게 일어날 수 있음 | 300ms 디바운스(Debounce)를 적용하여 연속 타이핑 중 불필요한 IndexedDB 트랜잭션을 억제하고, 창 닫기/새로고침/페이지 이동 시 `window.addEventListener('beforeunload')`를 통해 버퍼 내용을 즉시 강제 플러시(Flush)함 | 브라우저 성능 최적화 및 비정상 종료 시에도 단 1글자의 유실도 방지 (난이도: 보통) |
| **대용량 마크다운 렌더링 가상화** | 수만 자 이상의 초대형 문서나 수백 개의 이미지/테이블이 포함될 때 미리보기 렌더링 딜레이 발생 가능 | 긴 본문에 대해 뷰포트 기반 가상화(Virtualization) 또는 청크 단위 파싱 렌더링 고려 | 렉 없는 부드러운 스크롤링 및 에디터 타이핑 반응 속도 60fps 유지 (난이도: 높음) |
| **클라우드 동기화 오프라인 큐** | Google Drive 연동 시 네트워크 연결이 끊기면 저장이 실패로 끝날 수 있음 | 오프라인 작업 시 로컬 변경사항을 '동기화 대기 큐'에 적재하고, 네트워크 재연결 시 백그라운드 자동 순차 업로드 | 완전한 오프라인 작업 보장 (난이도: 보통) |

### [영역 2] 사용자 편의성 및 인터랙션 (UX & Ergonomics)

| 과제명 | 현황 및 분석 | 구체적 개선 방안 | 기대 효과 및 난이도 |
| :--- | :--- | :--- | :--- |
| **단축키 치트시트 모달 (Hotkeys Modal)** | 현재 에디터 하단에 작은 글씨로만 단축키가 안내되어 있어 사용자가 인지하기 어려움 | 에디터 우측 상단 툴바에 `⌨️ 단축키 안내 (? 키)` 버튼을 배치하고, 누르면 깔끔한 단축키 팝업 모달 노출. 모달 내에서 클릭 시 해당 서식(표, 코드블록 등) 즉시 삽입 기능 연계 | 초보자도 파워 유저처럼 즉각 서식을 활용할 수 있음 (난이도: 낮음) |
| **원클릭 복사 성공 토스트 피드백** | 마크다운 원문 복사나 HTML 소스 복사 버튼 클릭 시 복사가 되었는지 피드백이 약함 | 복사 완료 시 우측 하단에 부드럽게 떠오르는 `✅ 클립보드에 복사되었습니다!` 플로팅 토스트 컴포넌트 추가 | 작업 성공에 대한 명확한 인지 및 신뢰감 부여 (난이도: 매우 낮음) |
| **최근 문서 핀 고정 (Pin) & 검색 필터** | 대시보드에서 최근 문서가 수정일시 순으로만 나열되어 자주 보는 중요 문서가 뒤로 밀림 | 문서 카드 우측 상단에 핀(📌 Pin) 아이콘을 제공하여 자주 쓰는 문서를 상단 고정하고, 문서 이름 즉시 필터링 검색창 제공 | 실무 문서 관리 생산성 대폭 향상 (난이도: 보통) |
| **템플릿 비주얼 프리뷰 미니어처** | 1단계(문서 준비)에서 템플릿 선택 시 라디오 버튼과 텍스트 설명만 제공됨 | 각 템플릿 카드 안에 표 서식, 코드블록, 체크리스트 등의 미니어처 레이아웃 그래픽을 함께 표시 | 시각적으로 어떤 구조인지 한눈에 파악하고 선택 가능 (난이도: 낮음) |

### [영역 3] 생산성 확장 기능 (Productivity Features)

| 과제명 | 현황 및 분석 | 구체적 개선 방안 | 기대 효과 및 난이도 |
| :--- | :--- | :--- | :--- |
| **실시간 예상 읽기 시간 (Reading Time)** | 글자 수(문자 수)만 표시되어 블로그 원고나 발표 대본 작성 시 분량 가늠이 어려움 | 한국어 분당 평균 읽기 속도(약 500자/분)를 기준으로 `약 3분 소요 · 1,420자` 위젯을 에디터 헤더에 실시간 계산 표시 | 마케터, 블로거, 발표자의 시간 분량 조절 편의성 극대화 (난이도: 매우 낮음) |
| **실시간 목차(TOC) 미니맵 내비게이터** | 본문이 길어지면 특정 제목 위치를 찾기 위해 마우스 휠을 계속 굴려야 함 | 본문의 `# H1`, `## H2`, `### H3`를 실시간 파싱하여 미리보기 패널 우측(또는 좌측)에 얇은 플로팅 목차 바를 띄우고, 클릭 시 해당 위치로 부드러운 스크롤 이동 | 장문 리포트나 기술 문서 작성 시 압도적인 탐색 편의성 제공 (난이도: 보통) |
| **원클릭 다크 모드 (Dark Theme) 스위치** | 현재는 화이트 메인 테마만 적용되어 있어 야간이나 어두운 환경에서 눈 피로 발생 | 사이드바 하단이나 헤더에 '라이트 ↔ 다크' 원클릭 토글 스위치를 배치하고, `globals.css`의 다크 토큰(`--background: #0f172a` 등)과 연동 | 야간 장시간 작업 몰입감 극대화 (난이도: 보통) |
