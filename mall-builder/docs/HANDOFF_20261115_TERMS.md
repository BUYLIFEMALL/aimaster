## 1. 네 가지 호칭 (화면 문구·알림·메일·문서·보고·채팅 모두)
| 호칭 | 뜻 | 예전에 쓰던 말(쓰지 않음) |
|---|---|---|
| **운영사** | 쇼핑몰을 운영하는 본사(몰 대표·직원 포함) | 운영자, 본사, 몰 주인 |
| **공급사** | 상품을 공급하는 회사 | 공급업체, 입점사 |
| **리셀러** | 홍보 링크로 상품을 파는 판매자 | 제휴 판매자, 파트너 |
| **유저** | 상품을 사는 사람 | 손님, 고객, 구매자, 사용자 |

- 화면 이름도 같이: 「손님 화면」 → **「유저 화면」**, 「손님에게 보임」 → **「유저에게 보임」**, 「운영자만」 → **「운영사만」**.
- **조사**: 손님(받침 있음) → 유저(받침 없음)라 「손님이·은·을·과·으로」는 「유저가·는·를·와·로」로 바꾼다. 운영자 → 운영사는 둘 다 받침이 없어 조사 그대로.
- **예외(바꾸지 않음)**: 코드 식별자·DB 표/칸 이름(`customers`·`staff`·`is_admin` 등), AIMaster 메인 사이트의 회원 등급 이름(「일반 사용자 등급」 등 — 메인 사이트 용어), 법정 문구에 정해진 말(「구매자」가 법에서 쓰인 경우 그대로).
- 「분양몰 운영자(분양자)」처럼 몰 종류가 다른 주체는 「분양몰 운영사」로 쓴다(필요하면 「분양사」 — 정해지면 이 표에 추가).
