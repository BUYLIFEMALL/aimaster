## 1. 지금 있는 것
- F17(0015): 승인 사업자 손님이 주문에 「세금계산서 발행 요청」(받을 메일) → 운영자가 홈택스에서 직접 발행 → 「발행 완료」로 표시. 기록만 있고 실제 발행 연동은 없음.
- 공급자 정보: 몰 「쇼핑몰 정보」의 상호·대표자·사업자등록번호(검증 숫자 확인)·주소 등. 공급받는 자: 승인 사업자 가입 정보.
- 상품마다 과세(taxable)·면세(exempt) 구분이 있음.

| 서비스 | 키 주인 | 최상위 규칙(운영자 본인 계정·키) | 시험 | 요금 |
|---|---|---|---|---|
| **볼타 Bolta** | 가입한 계정(워크스페이스)마다 키, 계약 없이 발급(`test_`·`live_`) | **맞음** — 몰 운영자가 본인 계정·키·공동인증서로 발행, 포인트도 운영자가 충전 | `test_` 키: 국세청 전송·과금 없음 | 정발행·수정발행 건당 90원, 역발행 200원(VAT 별도), 최소 사용료 없음 |

## 3. 결정 항목 (주인님께 여쭐 것)
1. **방식**: (추천) 볼타 운영자 본인 키로 자동 발행 + 홈택스 엑셀 내려받기(키 없는 몰용) 둘 다 / 엑셀만 / 볼타만
2. **발행 시점**: (추천) 손님 요청 뒤 운영자가 「발행」 버튼(금액 확인 후) / 결제 완료되면 자동 / 구매 확정되면 자동
3. **취소·부분 취소된 발행 건**: (추천) 운영자 화면에 「수정 세금계산서 발행」 버튼과 안내(자동으로 하지 않음) / 자동 수정 발행
4. **면세 상품이 섞인 주문**: (추천) 과세 품목만 세금계산서, 면세 품목은 「계산서는 홈택스에서」 안내 / 면세 포함 주문은 막기
5. **시험**: 주인님이 볼타에 가입해 `test_` 키를 발급해 주시면(무료, 국세청 전송 없음) Lab 시험 몰 설정에 넣어 실제 호출 시험
