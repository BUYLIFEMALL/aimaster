## 프론트 확인 결과 (2026-11-15, [역할: mall-design-builder])
- ✅ 7종 × 12색 = 84조합 모두 저장 검사 통과, 갤러리 7장, 편집기 미리보기(실제 상품) 3종 모두 정상. 구성·색·모양은 그대로 두었습니다.
- **고친 것(문구만)**
  - 띠·제목에 **몰마다 다른 사실 주장**(「식약처 안심 인증」「100% 정품 보증」「첫 구매 5,000원 쿠폰팩 증정」「오늘 주문 시 오늘 출발」)이 있으면, 템플릿을 고른 몰이 그대로 게시할 때 허위·과장 광고가 됩니다. 그래서 중립 문구로 바꿨습니다.
    - 클린 웰니스: 「건강한 일상을 위한 클린 셀렉션」
    - 럭셔리: 「○○ 프라이빗 컬렉션」
    - 트렌디 팝: 「오늘의 새로운 발견을 만나 보세요」
    - 공지 제목: 「원료·품질 안내」
    - 같은 문제가 있던 프론트 「마켓 데일리」 띠도 함께 고쳤습니다.
  - 트렌디 팝 쇼윈도 제목이 `esc(storeName)`을 써서 몰 이름의 `&`가 `&amp;`로 보이던 버그를 고쳤습니다. 제목·띠는 일반 글자라 이스케이프하지 않고, `esc`는 html 블록 안에만 씁니다.
  - 「내돈내산 포토 후기」 → 「생생한 구매 후기」로 바꿨습니다(후기 블록은 사진을 보여 주지 않음).
- **시험 추가(다음 템플릿도 자동으로 막음)**
  - 띠·제목·탭 이름에 인증·보증·정품·증정·쿠폰·무료배송·당일·오늘 출발·최저가·1위·식약처·특허·100% 같은 말이 있으면 실패
  - 몰 이름 `A&B <샵>`으로 만들었을 때 일반 글자 칸에 `&amp;` 등이 나오면 실패
- **원본 시안과 맞춤(2026-11-15, 주인님이 클린 웰니스 + 에메랄드를 고르고 「이 시안이야」)**: 115 원본 `01_main.png`의 맨 위(작은 머리말·큰 제목 두 줄 중 둘째 줄 포인트색·단추 2개·오른쪽 대표 상품 카드·크림 배경)를 그대로 낼 블록이 없어 **「글 히어로」 블록**을 새로 만들고 클린 웰니스 맨 위에 넣었습니다(그림 없이, 단추는 아래 쇼윈도·탭으로 이동). 띠 색을 원본에 가깝게 `#047857`, 쇼윈도 제목은 원본처럼 왼쪽. 원본의 「신규 회원 15% 쿠폰」 띠·「LIMITED TIME OFFER」·`-25%` 같은 문구는 몰마다 다른 사실이라 넣지 않았습니다(가격·할인율은 대표 상품 카드가 실제 값으로 보여 줌). 캡처: `docs/evidence/d5-8-hero-1280.png`·`-390.png`. **다른 시안도 같은 블록을 쓰면 원본에 더 가까워집니다** — 113·114 맨 위를 바꾸실 때 이 블록을 써 주세요.
