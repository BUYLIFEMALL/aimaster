## 1. 문제
첫 화면 블록이 6종(띠 배너·슬라이드·단일 배너·상품 쇼윈도·글/HTML·공지)뿐이라 동영상·탭 상품·기간 행사·후기·카테고리 바로가기 같은 흔한 구성을 만들 수 없고, 행사 배너를 정해진 시간에만 보이게 할 방법이 없다(프로셀 「인덱스 배너·상품 쇼윈도·게시물·콘텐츠」).

## 2. 범위(안) — 기존 구조(등록표 `blocks.ts` + 손님 그리기 `home-blocks.tsx` + 편집 칸 `block-editor.tsx`) 그대로
| 새 블록 | 내용 | 데이터 |
|---|---|---|
| 동영상 | 유튜브·비메오 주소 → 반응형 영상(자동재생 끔, 유튜브는 쿠키 없는 주소) | 없음 |
| 탭 상품 | 탭 2~5개, 탭마다 신상품/카테고리/직접 선택(쇼윈도와 같은 규칙) — 누르면 탭 전환 | 서버(쇼윈도 재사용) |
| 타임세일 | 제목·끝나는 시각 → 남은 시간 카운트다운 + 상품 묶음, 끝나면 자동으로 숨김 | 서버(쇼윈도 재사용) |
| 구매 후기 | 최근/별점 높은 후기 n개(D13 후기, 사진·별점·상품 링크) | 서버 |
| 카테고리 바로가기 | 카테고리 고르고 아이콘 그림(또는 이모지) → 둥근 아이콘 줄 | 서버(카테고리 이름) |
| 사진 갤러리 | 그림 + 링크 격자(인스타 스타일, 운영자가 직접 올림) | 없음 |
**예약 노출(모든 블록 공통)**: 블록마다 「보이기 시작」「보이기 끝」(한국 시간, 분 단위, 둘 다 선택). 손님 화면은 서버 시각으로 걸러서 그림. 편집기에 「예약됨 / 끝남」 표시.

- 블록 저장 모양 `schema_version`은 그대로 1(새 칸은 선택이라 옛 저장본 그대로 읽힘)
- DB 변경: 블록 저장은 그대로 `mall_builder_pages` JSON. **플랜과 다른 점 1건** — 「구매 후기」 블록이 몰 전체 최근 후기를 읽어야 해서 읽기 전용 함수 `0048_store_recent_reviews.sql`(`mall_builder_store_recent_reviews`, 이름 가림·볼 수 있는 상품만·숨긴 후기 제외)을 하나 추가했다(쓰기 없음, Lab DB에 적용)
