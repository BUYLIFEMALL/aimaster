## 쓰는 법
- 작업을 시작·끝낼 때마다 **§1 작업표의 상태**를 고친다. 상태: ⚪ 대기 · 🔵 진행 중 · ✅ 완료 · ⏸ 보류 · ❌ 안 함(이유 적기)
- 작업 중 문제·더 나은 방법을 찾으면 **바로 §2(개선사항)**에, 새로 하면 좋을 기능은 **§3(추가 기능)**에 한 줄 넣는다. 번호는 이어서 붙이고 지우지 않는다(끝난 것은 상태만 바꿈).
- 개선·추가 기능을 하기로 정하면 §1의 해당 단계에 작업 줄을 넣고 「출처」 칸에 I번호·E번호를 적는다.
- 주인님 결정은 §4, 백엔드 담당에게 부탁할 일은 §5, 하루 단위 기록은 §6.
- 다른 CLI가 이어받아도 이 문서만 보면 어디까지 했는지 알 수 있게 한다.
