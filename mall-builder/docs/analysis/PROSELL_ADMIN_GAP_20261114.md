## 13. 없음·부분 항목 우선순위 (운영 안정성 관점)

6. **주문 기록 보관 기간 정책 확인** — 전자상거래법상 계약·결제·분쟁 기록 5년 보관 대상. AIMaster 「생성 데이터 30일 자동 삭제」 규칙이 쇼핑몰 주문 표에 적용되지 않도록 문서로 못박고 확인 필요(현재 몰 사진은 자동 삭제 없음으로 정해짐).
7. **반품·취소 클레임 관리 강화** — 반품 회수 단계·회수 송장·반품비 청구(환불에서 차감), 무통장 환불 계좌 받기와 「환불 대기」 목록.

## 14. AIMaster 방식 확장 제안 (운영자·공급사·벤더·손님 입장, 프로셀보다 한 단계 더)

| 대상 | 제안 | 근거 |
|---|---|---|
| 운영자 | 대시보드 「오늘 할 일」 한 화면 + 버튼 한 번 처리(입금 확인 여러 건·송장 엑셀 올리기·문의 AI 답변 초안 일괄) | 자동화 최소 설정 지침(매일 조작 0~3번) |
| 운영자 | 송장 엑셀 대신 택배사 API 송장 자동 발급(운영자 본인 계약 키) — 엑셀 일괄 등록은 1단계, API는 2단계 | 프로셀은 엑셀만 |
| 운영자 | 상품정보제공고시를 AI가 상품 이름·상세 그림에서 초안 작성(운영자 본인 키, 확인 후 저장) | 이미 `ai-fill.tsx` 있음 |
| 공급사 | 공급사 포털에 「송장 엑셀 올리기」·「발주서 엑셀 받기」 — 포털 쓰는 공급사도 대량 처리 | 프로셀은 메일·엑셀만, 우리는 포털만 → 둘 다 |
| 공급사 | 공급사별 반품·교환 처리 권한(회수 송장 입력·검수 결과) | 반품 흐름 강화와 함께 |
| 벤더(리셀러·분양자) | 분양자 대시보드에 「내 몰 매출·수수료 예상·출금 가능액」 한 장 | 분양 수수료율 정산(P1)과 연결 |
| 손님(B2B) | 견적·외상·정기 주문을 마이페이지 한 화면에서(「다음 정기 주문일·외상 잔액·회신 온 견적」) | 우리만의 B2B 강점을 손님 쪽에서 묶음 |
| 손님(소비자) | 배송 조회 링크·교환 신청·사진 후기 → 후기 적립 자동 | 소비자 몰 기본 기대치 |
