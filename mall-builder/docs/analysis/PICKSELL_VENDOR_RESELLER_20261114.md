## 0. 핵심 발견
1. **3자 구조가 우리 정의와 같다**(공급사 상품·배송 / 리셀러 링크 판매 / 운영사 결제·정산). 차이: 픽셀은 공급사 쇼핑몰로 결제되고 운영사가 리셀러 몫만 선지급 후 공급사 정산에서 차감. 우리는 본사가 결제 → 공급가만 입금, 리셀러 몫은 본사 지급(더 단순).
2. 픽셀에는 공급가 칸이 없고 공급사는 **판매가 + 리셀러 기본 수수료 %**만 넣음(운영사 수수료 없음). 우리는 같은 입력에 본사율을 더해 **공급가를 자동 계산·미리 보여 줌**(지금 우리 폼은 공급가 직접 입력 → 바꿔야 함).
3. 수수료 4단: 상품 기본 → 그룹별 추가 → 리셀러별 추가 → 지정 리셀러만 보이기(스페셜).
4. 상품마다 **바로판매 / 승인필요** — 승인필요 상품은 리셀러가 판매 승인 요청 → 공급사 승인·거절(페널티 없음, 재요청 가능).
5. **샘플** 옵션 5종(조건부취소·협의·반납조건·무료·불가). 조건부취소 = 샘플 결제 후 N개 이상 팔면 샘플 결제 자동 취소, 상태 14단계.
6. 리셀러 행동의 중심은 **「픽」** → 링크 공유·샘플 구매·링크샵·전용몰 진열. 공급사는 「내 상품 픽한 리셀러」에게 알림·채팅.
7. 리셀러 상품 카드에 **마진 %·금액**, 평균 배송일, 픽 수, 누적 판매 수.
8. **전용몰 = 링크 하나**(픽 상품 + 운영사 기준 상품 자동 채움). 리셀러 의견 「손님에게 플랫폼·위탁 느낌이 보이면 안 산다」「후기·판매자 정보 없음」 → 주인님 「겉으로는 종합몰」 정의의 근거.
9. 정산 = **최초 1회 인증(사업자등록증 + 본인·대표 명의 계좌) → 월 자동 지급 + 증빙 자동 발행**, 화면은 예상수익 / 정산대기 / 정산완료.
10. 공급사 화면은 사실상 **리셀러 관리 도구**(찾기·영향력/판매력 지수·그룹·차단·메모·일괄 알림·채팅·게시판·검색 트렌드·초대 보너스). 우리 공급사 화면은 내 정보·내 상품·내 주문·정산 4메뉴.

## 3. 흐름 정리 (우리 구현 위치)
- 픽 → 판매 → 정산: 마진 보고 Pick(승인필요는 요청) → 링크 공유(링크샵·전용몰 자동 포함) → 손님 결제(주문에 리셀러 기록) → 배송 진행 기준 정산 → 취소 상계. 우리: 링크·주문 기록 M1-5, 지급 예정·완료·보류 M1-6, 픽·카드 마진·승인 요청 C2·S4.
- 전용몰·링크샵: 리셀러용 가벼운 진열 페이지 `/s/<몰>/r/<코드>` 제안(본사 몰 안 한 화면, 결제 본사, 리셀러 코드 자동, 손님에겐 「○○님 추천」만) — 분양몰(사업자가 몰 통째 운영)과 구분.
- 정산 인증: M1-4 리셀러 신청·승인 때 계좌·서류 1회 저장 → 출금·자동 정산에 사용, 개인은 원천징수 공제.
- 마진 표시: 리셀러에게 보이는 마진 = 판매가 × 리셀러율(본사율·공급가는 숨김).
- 승인·샘플: 상품 `sale_approval` + 요청 표, 승인 전 링크·리워드 막기. 샘플 조건부취소는 카드 부분 환불 연동이 필요해 난도 있음.

## 4. AIMaster 추가 제안
- 공급사: 수수료 계산기 폼(판매가·리셀러율 → 본사 수수료·리셀러 몫·내 공급가 즉시 표시), 같은 카테고리 평균 리셀러율 비교, AI 판매가이드·홍보글(본인 키), 스마트스토어 URL·엑셀 가져오기, 자동 승인·자동 샘플 환불 규칙, 주문·승인·샘플 알림(문자·알림톡 코어).
- 리셀러: 「내가 벌 돈」 크게·예상수익순 기본, 홍보 키트(링크·짧은 링크·QR → AIMaster 카드뉴스·쓰레드·인스타 자동화), 가벼운 진열 페이지(종합몰처럼, 후기·본사 판매자 정보 그대로), 계좌 1회 인증 → 매달 자동 정산, 모바일 하단 탭(홈·상품·내 링크·수익·메뉴).
- 운영사: 공급사별 본사율 일괄 관리·리셀러율 상한 검사, 리셀러 판매력 등급·부정 클릭 경고·외부 거래 유도 감지, 리셀러 대상 기획전·MD 추천.
- 고객: 리셀러 링크로 와도 본사 몰과 같은 후기·배송·교환·고객센터 정보, 리셀러가 켜면 「추천 모아보기」.

## 5. 개발 단계 제안 (마스터 플랜 M3·M4로 옮김)
- 공급사 S1 수수료 입력·공급가 자동 계산 폼 → S2 정산 품목별 분해·주문 검색·요약 → S3 대시보드 → S4 판매 승인제 → S5 리셀러 보기·그룹·지정 수수료 → S6 알림·게시판 → S7 샘플·판매 기간·판매가이드·AI 홍보글 → S8 채팅·커뮤니티·검색 트렌드·초대·외부 가져오기.
- 리셀러 C1 화면 틀(`/s/<몰>/reseller`, 모바일 하단 탭·PC 넓은 화면)·수익 3칸·출금 → C2 상품 고르기(마진·링크·QR·픽) → C3 판매내역·랭킹 → C4 진열 페이지 → C5 승인 요청·스페셜·공급사 목록 → C6 홍보 키트·링크샵 → C7 샘플·기획전·채팅·초대·증빙.
- 권장 순서: M1(R1~R4) → S1 → C1+C2 → S2+S3+C3 → C4 → S4+C5 → S5+S6 → C6 → S7+C7·S8. **첫 배포 묶음 = M1 + S1 + C1 + C2**(상품 보기 → 링크 복사 → 판매 → 수익 확인 → 출금 한 바퀴).
