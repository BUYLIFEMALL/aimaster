## 2. 쇼핑몰 디자인 (PC) 탭 7개
### 2-1. 템플릿/스킨 (`prosell-design-pc.png`)
- **템플릿 선택**: 썸네일 13종 라디오(`template` = basic·colorful·hidden_menu·hoya·modern·simple·smart·star·two_tone·wide_main·z1·z2·z3). 고르면 큰 미리보기 그림 + 「템플릿 설정 정보」「제작/운영 가이드」 단추.
- 안내 문구: **템플릿 = header·footer 담당, 스킨 = 메인 아래 Container와 서브 페이지 Skin 담당**, 둘을 조합. 템플릿은 PC·모바일이 구분되고 각각 독립 파일·URL.
- **템플릿 커스터마이징**: 하단(footer) 아이콘 바꾸기. 도움말 — 카테고리 이미지·템플릿 색상(BG·Line·Font·etc)·아이콘을 코딩 없이 바꿈.
- **스킨 설정**(화면 종류별 드롭다운, 지금 전부 `basic` 한 벌 + 미리보기 단추): 가입/로그인 · 마이페이지 · 장바구니/주문/결제 · 상품 검색결과 · 전체 상품평. 「상품목록·상품페이지 스킨은 상품 카테고리에서」 링크.

### 2-2. 쇼핑몰 로고 (`/pc/logo`)
- 상단 로고(권장 560×120 이하) · 하단 로고(250×120) · **페이지 로고**(400×180, 로그인·회원가입처럼 상단 메뉴 없이 단독으로 열리는 화면과 상품 없음 안내 화면용).
- 로고가 없으면 몰 이름을 글자로 출력. PNG·GIF·JPG, 투명 PNG 권장, 큰 그림은 비율 맞춰 자동 축소.

### 2-3. 메뉴 관리 (`prosell-design-pc_menu.png`)
- 화면 위쪽에 **눈금자 달린 상단 미리보기**(실제 헤더 그림), 아래 「상단메뉴 관리」 = 상단 메뉴A·상단 메뉴B 설정 단추.
- 하단도 같은 구조: 하단 미리보기 + 하단 메뉴A·B.
- 메뉴 설정 창: 노출순서·메뉴 설정·관리 표, 「메뉴 추가하기」 — **기본 메뉴 최대 5개, 더 필요하면 그룹 메뉴(2단)**. 메뉴 유형은 직접입력·고객센터·생성한 게시판/페이지.
- 상품 카테고리 메뉴는 카테고리 순서가 그대로(별도 관리 아님).

### 2-4. 템플릿 배너 (`prosell-design-pc_banner.png`, 24개)
- **모든 페이지**(템플릿 영역·카테고리·게시판·페이지)에 나오는 배너. 목록 칸: 노출·노출 페이지·노출 영역(템플릿 영역 A~D 배너)·이미지·배너명·제작방식(이미지/동영상 YouTube·URL)·**권장 크기(고정/이하)**·첨부 크기·배경 색상.
- 시즌 배너는 지우지 말고 OFF(재사용). 템플릿을 바꾸면 권장 크기가 달라져 재등록 필요.

### 2-5. 인덱스 배너 (`prosell-design-pc_mainbanner.png`, 18개)
- **첫 화면 전용**. 첫 화면은 「디스플레이 영역」(=블록 프레임)으로 나뉘고, 배너는 디스플레이에 들어간다.
- 목록 칸: 노출·**노출 영역(디스플레이 3단·4단 …)**·타이틀(BEST COLLECTION·LINE BANNER)·**적용스킨(5개의 정사각형·초보용 띠 배너 …)**·출력개수(1·5개씩)·정렬방식(최근 등록순)·이미지·서브 이미지·배너명.
- 등록 창: 노출 영역을 먼저 고르면 그 디스플레이의 타이틀·적용스킨이 자동으로 따라오고, 배너명·이미지·(스킨에 따라) 슬로건·서브 이미지·배경색을 넣는다. **등록 옵션 칸은 디스플레이 스킨이 정한다.**
- 「디스플레이 추가」 단추로 영역을 늘림. 영역 추가·삭제·배치는 손님 화면 편집 모드에서.
- 디스플레이 스킨을 바꾸면 기존 배너 비율이 깨질 수 있어 재등록 안내.

### 2-6. 팝업창
- 이미지 또는 에디터로 제작, 시작·종료 일시, 창 크기·위치(X·Y), ON/OFF(다시 ON 하면 기간이 오늘~D+7 자동). PC·모바일 따로, ON 여러 개면 동시에 뜸.

### 2-7. 인트로
- 첫 화면 앞에 끼우는 페이지: 사용 안 함 · 오픈 예정 안내 · 사이트 점검 안내 · 성인몰 · 폐쇄몰(로그인 요구). 서브 주소로 들어와도 인트로로 보냄. 관리자 로그인 상태에서는 건너뜀.

## 3. 디자인 공통설정 (`prosell-design-common.png`)
| 묶음 | 칸 |
|---|---|
| 색상/아이콘 | 추천 색상 9개 견본 · **포인트 색상**(`color1`, 글자·버튼 강조·오버) · 아이콘 색상(Red 등, PNG 아이콘용 — SVG는 포인트색 따름) · **배경 색상**(`bgcolor`, 명도 95% 이상 권장) |
| 폰트 설정 | Light·Regular·Medium·Bold 4단계마다 글꼴(Malgun Gothic 등 + 구글 웹폰트)·굵기. 웹폰트는 6~20MB라 속도 경고 |
| 상품 이미지 비율 | 5:5(정사각형) 등 — 쇼윈도·목록·상세 대표 사진에 공통, 장바구니·주문내역은 5:5 고정 |
| 외부연동 이미지 | 파비콘 ICO·PNG, OG 이미지(800×420), 메일 상단·하단 로고 |

→ 공개 분석에서 본 `root.css` 변수(`--color1`·`--bgcolor`·`--family-*`)가 바로 이 화면 값이다. **색 3개 + 글꼴 4단계 + 사진 비율**이 몰 테마의 전부.

## 4. 목록·상세 = 상품 카테고리 화면 (`prosell-design-list_pc.png`, `prosell-design-detail_pc.png`)
- 카테고리마다: 전시 여부·전체/베스트 노출·줄임 명칭·검색 필터(색상·사이즈)·**접근 권한(등급 이하 차단)**.
- **스킨 및 세부설정**: 상품목록 스킨 PC/Mobile, 상품페이지 스킨 PC/Mobile 각각 드롭다운(지금 전부 basic) + 각 「세부설정」 창. 「설정 항목은 스킨에 따라 다름」.
- **상품목록 세부설정**(PC, basic): 목록타입(이미지형…) · 기본 진열방식(전시순서순…) · 품절상품 전시/안함 · 메뉴/필터(현재 카테고리·브랜드·상품 아이콘·판매자 정보) · **출력항목 8개**(할인율·브랜드·상품 아이콘·판매자 정보·판매가(할인전)·상품평/평점·배송정보·판매수량) · 페이지 이동 방식(더 보기/이어보기…) · **적용 범위(현재 카테고리만 / 전체)**.
- **상품페이지 세부설정**(PC, basic): 상품 구매정보(판매가 할인전·옵션별 재고·포인트 적립 안내) · 부가정보/옵션 11개(브랜드·상품 아이콘·판매자·이미지 확대·SNS 공유·불편신고·만족도·카드 할부·네이버페이·카카오페이 즉시구매) · 옵션 선택창(기본+확장형) · 평점/구매분석(평점+구매자 통계) · 상품평 출력 개수 · 상품문의 출력 개수.
- 카테고리마다 **상단내용·하단내용**(미등록 / 공통 / PC·모바일 개별) · **상단진열 1단·2단**(PC·모바일 체크).
- 맨 위에 공통 단추 「상품목록 설정(PC/모바일)」「상품페이지 설정(PC/모바일)」 = 전체 카테고리 기본값.
