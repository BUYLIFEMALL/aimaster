# 주문·결제 기록 5년 보관 — 원칙과 점검 기록 (M2-6, 2026-11-15)

- 대상: `mall-builder`(운영 DB `esgxyikcnnvmlhygjkth`, Lab `rjjtjakljjxsgjelqgek`)
- 근거: 전자상거래 등에서의 소비자보호에 관한 법률 제6조·시행령 제6조 — 계약·청약철회 기록 5년, 대금결제·재화 공급 기록 5년, 소비자 불만·분쟁 처리 기록 3년
- 담당: [역할: mall-builder] 세션 `claude-win-20261025-workspace`

## 1. 원칙
1. **주문·결제·정산 기록은 AIMaster 「30일 자동 삭제」 대상이 아니다.** 회원 생성 콘텐츠(글·이미지 등)의 30일 보관 규칙(루트 CLAUDE.md)과 별개로, 법정 보관 기록이다.
2. 보관하는 표: `mall_builder_orders`·`order_items`·`order_events`·`card_payments`·`order_item_supply`(주문·결제·공급), `credit_ledger`(외상), `point_ledger`(포인트), `reseller_ledger`·`reseller_payouts`(리셀러 수수료·지급), `resale_ledger`·`resale_payouts`(분양 수수료·지급), `tax_invoices`(세금계산서).
3. 유저가 몰에서 탈퇴해도 위 기록은 남기고 유저 연결만 비운다(SET NULL). 개인 자료(배송지·후기·문의·쿠폰·전용가·정기주문)는 탈퇴 때 지운다.
4. 정리 안 된 돈(진행 중 주문·외상 잔액·받을 수수료·지급 대기)이 있으면 탈퇴를 막는다.
5. 몰은 지우지 않고 정지한다(앱에 몰 삭제 기능 없음). 몰 행을 지우면 그 몰 주문이 연쇄로 지워지므로, DB에서 몰을 지우는 일은 5년이 지난 뒤 주인님 승인으로만.

## 2. 점검 결과 (2026-11-15, 운영 DB 읽기)
| 점검 | 결과 |
|---|---|
| 앱의 정리 작업(`src/app/api/cron/**`) | `deposit-expire` 하나 — 입금 기한 지난 주문을 「취소」 상태로 바꿀 뿐 지우지 않음 ✅ |
| 운영 DB 예약 작업(`cron.job`) | 몰 표를 건드리는 작업 없음(전부 다른 프로그램의 30일 정리) ✅ |
| 앱 코드의 삭제 | 주문·장부를 지우는 코드 없음. 몰 탈퇴(`leaveStoreAction`)만 유저 행 삭제 |
| 유저 행 삭제 → 주문 | `orders.customer_id` SET NULL — 주문은 남음 ✅ |
| 유저 행 삭제 → 외상·포인트 장부 | **CASCADE(함께 삭제)** ❌ → 0098로 SET NULL |
| 유저 행 삭제 → 리셀러 행 → 수수료 장부·지급 기록 | **연쇄 CASCADE** ❌ → 0098로 SET NULL |
| 탈퇴 조건 | **아무 조건 없이 탈퇴 가능** ❌ → 0098로 정리 안 된 돈이 있으면 막음 |
| AIMaster 계정 삭제 → 주문 | `orders.user_id` NO ACTION — 주문이 있으면 계정 삭제가 막힘(기록은 지켜짐). 메인 사이트 탈퇴 흐름과 맞출 일은 남은 과제 |
| 몰 삭제 → 주문 | CASCADE — 앱에 몰 삭제 기능이 없어 원칙 5로 관리 |

## 3. 조치 — DB 0098 (`supabase/migrations/0098_keep_money_records_on_leave.sql`)
- 장부 4종(외상·포인트·리셀러 수수료·리셀러 지급)의 연결을 SET NULL로(칸은 비울 수 있게).
- 유저 행 삭제 전 검사 트리거: 진행 중 주문(입금 대기~배송 중·취소/반품 요청), 외상 잔액 ≠ 0, 받을 리셀러 수수료 > 0 또는 지급 대기 → 이유를 알려 주며 막음. 몰 삭제 같은 연쇄 삭제 중에는 검사하지 않음.
- 로컬 시나리오 `scripts/scenario-0098-keep-money-records.sql` K1~K7 통과.

## 4. 남은 과제
- AIMaster 계정 삭제(메인 사이트 탈퇴)가 몰 주문 때문에 막히는 경우의 처리 — 메인 사이트 담당과 협의(주문의 `user_id`를 비우고 기록은 남기는 방식 등).
- 5년이 지난 기록의 파기 절차(지금은 자동 파기 없음 — 몰 운영 5년 뒤 정함).
- 리셀러 장부 화면은 유저 연결이 비워진 행을 목록에 보이지 않음(기록은 DB에 있음) — 필요하면 「탈퇴한 리셀러」 묶음으로 보여 주기.
