## 3. ② 분양몰(T2) — 「분양자가 ① 상품을 자기 이름의 몰에서 판다」

### 3-1. 구조(안)
- 분양몰 = 몰 하나(`mall_builder_stores`에 몰 유형 `resale`·원본 몰 `source_store_id`). 몰 만들기·꾸미기·주문·결제·알림은 공통 코어 그대로.
- **상품**: 분양자가 ① 상품을 골라 담으면 분양몰에 「연결 상품」으로 진열 — 이름·사진·설명·옵션·재고는 ① 상품을 그대로 읽고(복사하지 않음 → 품절·가격 변경이 바로 반영), 분양자는 **판매가만** 정함(① 판매가 기준 범위 — 결정 4).
- **주문**: 손님이 분양몰에서 주문·결제 → 분양몰 주문 생성 → ①에 「전달 주문」 자동 생성(배송지 그대로, 결제는 분양 정산으로) → 공급사·본사가 지금처럼 발송(D36 품목 송장) → 송장이 분양몰 주문에도 표시.
- **정산**: 분양자 마진 = 분양몰 판매가 − ① 기준가. 구매 확정 때 분양자 장부에 적립, 반품이면 회수, 출금 신청·지급 완료 — **리셀러 장부(D33) 구조 재사용**.
- **분양 신청·승인**: 회원이 분양 신청 → 관리자 승인 → 이용 기간(관리자 지정, 기본 14일 시험 — 관리자 지침) → 만료되면 분양몰 손님 화면 「준비 중」.
- 결제: 분양몰도 처음엔 무통장(분양몰 계좌 = ① 본사 계좌 — 결정 5) — 카드는 본사 토스 키.

### 3-2. 단계
| 단계 | 내용 |
|---|---|
| T2-1 | 몰 유형·원본 몰 칸, 분양 신청·승인·이용 기간(관리자 화면) |
| T2-2 | 연결 상품(골라 담기·판매가·자동 품절), 분양몰 손님 화면에서 연결 상품 판매 |
| T2-3 | 주문 전달(분양몰 → ①)·송장 공유·취소/반품 연동 |
| T2-4 | 분양자 마진 장부·출금(리셀러 장부 재사용), 분양자 화면 「매출·정산」 |
| T2-5 | Lab 시험 → 로컬 전체 실행 검사 → 운영 DB·배포 → 실제 흐름 검수(분양 신청 → 담기 → 주문 → 발송 → 확정 → 마진) |
