## 1. 문제
거래처는 품번과 수량 목록(발주서)으로 한 번에 주문한다. 지금은 상품 화면을 하나씩 열어 담아야 하고, 지난번과 같은 품목을 다시 주문할 방법도 없다.

## 2. 범위(안)
**손님 화면 「빠른 주문」(`/s/<몰>/quick-order`)**
1. 입력 두 가지: ① 엑셀에서 복사해 붙여 넣기(품번·수량 두 칸, 탭·쉼표·공백으로 나뉜 줄) ② `.xlsx` 파일 올리기(첫 시트, 「품번」「수량」 머리글) + 양식 내려받기
2. 품번으로 상품을 찾는다(D23 품번). 옵션 상품은 **조합 품번**(옵션 표의 조합 품번)으로 찾거나 「품번 + 옵션 값」(예: `P00002 검정`)으로 찾는다
3. 미리보기: 줄마다 상품명·옵션·단가(등급가·거래처 특가 반영)·합계·오류(없는 품번·품절·최소 수량·주문 단위·재고·사업자 전용 등). 같은 품번이 여러 줄이면 합친다
4. 「장바구니에 담기」 → 기존 장바구니 담기와 같은 규칙(같은 상품·옵션이면 수량을 더함, 담을 때 다시 검사) → 장바구니로 이동해 평소처럼 주문
**주문 상세 「다시 담기」**
5. 지난 주문의 품목을 같은 수량으로 장바구니에 담는다(가격은 **지금 가격**). 판매 중단·품절·옵션이 없어진 품목은 빼고 이유를 알려 준다
- 금액은 지금처럼 주문 DB 함수가 다시 계산한다(빠른 주문은 장바구니까지만 채움) → **DB 변경 없음**
- 1차에서 하지 않음: 정기 발주(자동 반복 주문), 「자주 산 상품」 목록, 비회원 빠른 주문

## 3. 결정 항목 (주인님)
| 번호 | 결정할 것 | 추천안 | 다른 안 |
|---|---|---|---|
| 1 | 입력 방법 | **붙여 넣기 + 엑셀 파일 둘 다** | 붙여 넣기만 |
| 2 | 오류 줄이 섞였을 때 | **정상 줄만 담기**(오류 줄은 이유와 함께 남겨 두어 고쳐 다시 담을 수 있게) — 주문 전 장바구니에서 한 번 더 보므로 | 오류가 하나라도 있으면 담기 막음(상품 엑셀처럼) |
| 3 | 장바구니에 같은 상품이 이미 있을 때 | **수량을 더함**(지금 담기와 같음) | 엑셀 수량으로 바꿈 |
| 4 | 다시 담기 대상 주문 | **모든 주문**(취소된 주문 포함 — 「그때 그 품목」을 다시 담는 용도) | 배송 완료·구매 확정 주문만 |
| 5 | 한 번에 담는 줄 수 | **300줄** | 100줄 |
