## 1. 무엇을 만드나
첫 화면 디자인 편집기에서 **블록 몇 개를 골라 이름을 붙여 저장**하고(예: 「명절 세일 묶음」 = 띠 배너 + 타임세일 + 쇼윈도), 나중에 **같은 몰의 다른 때나 다른 몰 편집기에서 한 번에 넣는** 기능. 몰 여러 개를 운영하는 운영사(D31)가 같은 구성을 반복해서 만들지 않게 한다.

## 2. 지금 구조와 왜 새 표가 필요한가
- 디자인은 몰마다 `mall_builder_design`(0080)에 저장되고, 저장 함수는 **그 몰의 직원**인지 검사한다.
- 「내 섹션」은 **여러 몰에서 다시 쓰는 것**이 목적이라 몰에 묶인 표로는 안 된다 → **회원 본인 소유의 새 표 하나**가 필요하다.

## 3. 설계
| 항목 | 내용 |
|---|---|
| DB | 새 표 `mall_builder_sections`(마이그레이션 **0095**, 번호는 백엔드와 맞춤): `id`, `owner_id`(=`auth.uid()`), `name`(40자), `blocks`(jsonb, 블록 배열), `created_at`. RLS: 본인 것만 읽기·쓰기·지우기. 저장·삭제는 보안 함수(`security definer`, 로그인 확인·개수·크기 검사) |
| 한도 | 회원당 30개, 섹션 하나 20KB(첫 화면 저장 한도와 같음), 블록 10개까지 |
| 저장 | 편집기 머리 단추 「💾 내 섹션으로 저장」 → 지금 첫 화면 블록 목록에 체크 → 이름 입력 → 저장. 저장 전 `validateDoc`으로 검사(위험한 글은 이미 지워진 상태) |
| 넣기 | 「📥 내 섹션 넣기」 → 내 섹션 목록(이름·블록 수·날짜, 지우기 단추) → 고르면 **지금 편집 중인 첫 화면 맨 끝에 추가**(블록 번호는 새로 붙임). 편집기 안에서만 바뀌고, 저장·게시는 평소처럼 운영사가 누름 |
| 다른 몰에 넣을 때 | 「직접 고른 상품」·「카테고리」 출처는 그 몰에 없는 번호라 **「신상품」으로 바꿔** 넣고 안내 한 줄. 그림 주소·글은 그대로 |
| 분양몰 | 넣은 뒤 저장할 때 기존 분양몰 잠금 검사(0081)가 그대로 적용 |
| 회원 데이터 | 회원 본인 소유로 격리(다른 회원과 공유 없음). 생성 콘텐츠라 **30일 보관 규칙 대상인지** 주인님 결정 필요(아래 결정 3) |

## 4. 하지 않는 것
- 다른 회원과 섹션 공유·판매(E12 본사 템플릿과 별개)
- 첫 화면 말고 다른 화면(목록·상세) 섹션 — 첫 화면 블록만

## 5. 순서·검수
1. 시험 먼저(`tests/my-sections.test.mjs`): 섹션 검사(한도·블록 수·이름), 다른 몰에 넣을 때 출처 바꾸기, 새 번호 붙이기
2. 마이그레이션 0095 작성 → **Lab DB 적용**(승인 후) → 시나리오 SQL(본인만 보임·한도·남의 섹션 지우기 거절)
3. 서버 함수(`design-actions.ts`에 저장·목록·삭제) + 편집기 단추 2개
4. ego로 Lab 편집기에서 저장 → 다른 몰(aimaster-b2b Lab) 편집기에서 넣기 → 저장하지 않고 미리보기만 확인
5. 운영 DB 0095는 다음 백엔드 「함께 배포」 때(승인)
