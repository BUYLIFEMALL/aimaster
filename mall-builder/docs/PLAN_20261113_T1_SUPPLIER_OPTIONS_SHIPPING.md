## 2. 바꿀 것
### A. 공급사 상품 옵션
- 공급사 상품 등록 화면에 옵션 입력(몰 상품과 같은 3단 조합 편집기 재사용)
- 조합마다: **추가 공급가**(공급사가 적음) · 재고 · 판매 여부
- 운영자 승인 화면: 조합마다 **추가 판매가**를 정함(기본값 = 추가 공급가 × 상품의 판매가/공급가 비율, 고칠 수 있음)
- 옵션 구성이나 추가 공급가가 바뀌면 다시 승인 대기, **재고만 바뀌면 그대로 판매**(지금 규칙과 같음)
- 정산: (공급가 + 고른 조합의 추가 공급가) × 수량 — 주문 때 값을 품목에 저장해 나중에 바뀌어도 그대로

### B. 공급사별 배송비
- 공급사마다 배송비 정책 하나(무료·고정·조건부 무료 + 제주·도서산간) — 기존 배송비 정책 표를 그대로 씀(새 표 없음)
- 그 공급사 상품은 자동으로 그 정책 → 기존 「같은 정책끼리 묶어 한 번」 계산 덕에 **공급사마다 따로 한 번씩** 매겨짐(손님은 한 번 결제, 주문서에 공급사별 배송비 줄 표시)
- 주문 확정 때 그 공급사 묶음 배송비를 **공급사 정산에 더함**, 취소되면 함께 회수
- 정책이 없는 공급사는 지금처럼 몰 기본 정책(몰 몫)

## 3. 주인님 결정 항목
1. **공급사 배송비 정책은 누가 정하나** — (추천) 공급사가 자기 화면에서 정하고 운영자가 공급사 관리 화면에서 보고 고칠 수 있음 / 운영자만 정함
2. **공급사 묶음 배송비는 누구 몫인가** — (추천) 공급사 정산에 더함(공급사가 직접 발송하므로) / 몰 몫(지금처럼)
3. **옵션 추가 판매가 기본값** — (추천) 상품 판매가/공급가 비율을 따라 자동 계산, 운영자가 고침 / 추가 공급가와 같은 금액
