## 순서(약 3분)
1. 위 주소로 SQL 편집기를 엽니다(새 쿼리).
2. `precheck.sql` 내용을 붙여 넣고 **Run** → 7줄 모두 「OK」인지 봅니다. 하나라도 「멈춤」이면 여기서 멈추고 알려 주세요.
3. 편집기를 비우고 `apply.sql` 내용 전체를 붙여 넣고 **Run** 한 번. 「파괴적 작업」 확인 창이 뜨면 실행을 승인합니다(트리거 다시 만들기 때문에 뜰 수 있음).
   - 성공: 결과 없이 「Success」.
   - 「[멈춤] …」 오류: 사전 점검이 막은 것 — 아무것도 바뀌지 않았습니다. 문구를 알려 주세요.
   - 그 밖의 오류: 한 트랜잭션이라 **전부 취소**됩니다. 오류 문구를 그대로 알려 주세요. 다시 실행하지 마세요.
4. 편집기를 비우고 `verify.sql` → **Run** → 마지막 줄 「전체 9/9 OK」인지 봅니다.
5. 채팅에 「0100 실행했어」(또는 화면에 나온 결과)를 알려 주시면, 에이전트가 읽기 확인을 다시 한 뒤 v1.16 빌드 1번을 진행합니다.
