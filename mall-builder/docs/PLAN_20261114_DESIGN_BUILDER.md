## 0. 한눈에 보기
1. **편집기는 Puck(MIT)을 이식해 쓰고, 저장 형식의 기준은 지금의 `src/lib/blocks.ts` 등록표로 유지**한다(편집기는 바꿔 끼울 수 있게 변환층 하나로 잇는다).
2. **색·글꼴 테마는 Tailwind v4의 CSS 변수를 몰마다 덮어쓰는 방식**으로 한다 — 손님 화면 코드 수백 곳을 고치지 않아도 되고, 지금 106 스타일이 그대로 「기본 테마」가 된다.
3. **세 몰은 같은 빌더 코어**를 쓰고, 몰 종류(`mall_builder_stores.kind`)별 「고칠 수 있는 영역」 표 하나로 나누며, 금지 영역은 **DB 저장 함수가 거절**한다.
4. 프로셀보다 나은 점: 초안→게시(프로셀은 누르는 즉시 실제 화면 반영), 게시 기록·되돌리기, 실행 취소, 휴대폰/PC 같은 코드로 미리보기.
5. 단계는 D0(분석 보완) → D1(테마 층) → D2(편집기·첫 화면) → D3(헤더·바닥글·팝업) → D4(목록·상세 표시) → D5(템플릿·분양몰 잠금) → D6(기록·되돌리기) → D7(손님 화면 위 바로 편집, 확장).

### 1-2. 프로셀 손님 화면 — 직접 다시 확인 (공개 화면만, 읽기만)
- 편집 모드 `sst`: 관리자 로그인 때만 `web.is_sst = true`. 구역마다 `data-sst-item`(banner·menu·logo·mainbanner·showwindow·board·contents)·`data-sst-id`가 붙고, 그 위에 설정·올리기·내리기·삭제 단추, 구역 사이 「+ 끼워 넣기」.
- 순서 바꾸기 = `adm/sst/update/position`에 구역 id 목록을 보내 **즉시 저장(초안 없음)**, 다시 그리기 = `adm/sst/container`가 서버에서 그린 HTML과 스킨 CSS/JS를 받아 통째로 갈아 끼움(jQuery).
- 블록 4종(쇼윈도·메인배너·게시물·콘텐츠) × **스킨 여러 벌**(`skin/pc/main/banner/190802s` 처럼 날짜형 id, 스킨마다 CSS·JS 따로).
- 구역마다 `padding-top/bottom`·`width:100%`(전체 폭) 또는 `1200px`(본문 폭).
- 테마 변수는 적다: `--color1/2`(포인트색)·`--rgb-color1`·`--bgcolor`·`--main-width:1200px`·`--layout-width`·글꼴 4단계(`--family-*`)·굵기 4단계(`--weight-*`)·아이콘 그림 변수.
- PC·모바일 사이트가 따로(`/m`) — 우리는 반응형 한 벌 + 블록별 PC/휴대폰 보이기로 간다.
- 관리자 디자인 편집기 본문(로그인 필요)은 **D0에서 주인님 로그인 뒤 읽기만** 보완한다.

## 3. 설계

### 3-1. 디자인 문서 구조 (몰 하나)
```
theme   : { preset, colors{primary, accent, bg, surface, text}, radius, button(3d|flat), font, width }
header  : { topbar[], logo_align, menu[], search_style, show_categories }
footer  : { columns[], show_bank, icons[] }        // 사업자 정보는 쇼핑몰 정보에서 자동, 지우기 불가
popup   : { items[{image, link, position, hide_today}] }
home    : BlocksDoc (지금 그대로 + 블록 공통 겉모양 칸)
list    : { columns, card_style, badges[], sort_default }
detail  : { tab_order[], sections_visible{} }
```
- 저장 위치: 기존 `mall_builder_pages`에 `kind` 값을 늘림(`theme`·`header`·`footer`·`popup`·`list`·`detail`, `home`은 그대로). 각 `kind`가 초안/게시를 따로 가지되, 편집 화면의 「게시」는 바뀐 것 전부를 **한 번에** 게시(DB 함수 하나).
- 블록 공통 겉모양: 블록 `settings` 옆에 선택 칸 `style?: { pad_top, pad_bottom, width: "full"|"content", bg_color, bg_image, show_pc, show_mobile }` — 옛 저장본은 칸이 없어도 그대로 읽힘(`schema_version` 1 유지, 없으면 기본값).

### 3-2. 테마 층 (D1)
- `src/lib/theme.ts`: 테마 값 검사 + 포인트색 하나로 50~950 단계 자동 계산(OKLCH) → `--color-blue-*`·`--color-slate-*`(배경 계열)·`--mall-radius`·`--mall-font`·`--mall-width`.
- 손님 화면 바깥 상자(`(shop)/layout.tsx`)와 분양 화면에 `style`로 변수 주입(서버에서 그림 → 깜빡임 없음).
- **기본 프리셋 = 지금 106 값 그대로** → D1 배포 뒤 화면 변화 0이 목표(화면 비교로 확인).

### 3-4. 템플릿 (D5)
- 템플릿 = 위 디자인 문서 전체의 묶음(코드 안 등록표 `src/lib/builder/templates.ts`). 고르면 **초안에 복사**(게시는 운영자가).
- 처음 3종: 「106. 네오 모던 B2B 커머스」(지금) + 시안 2종(디자인 담당 agy와 나눔). 분양몰 신청 화면·분양자 관리 화면에서 고르기.
