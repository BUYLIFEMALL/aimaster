## 2. 구조 — 「거울 상품」

플랜 §3-1의 「복사하지 않고 연결」은 바꾼다: 장바구니·주문·재고·가격·쿠폰 코드가 모두 「몰 안 상품」 기준이라 연결 방식이면 전부 고쳐야 한다. 대신 **분양몰 안에 원본과 자동으로 맞춰지는 거울 상품**을 둔다(주인님 요구 「품절·가격 자동 반영」은 그대로).

| 대상 | 방법 |
|---|---|
| 몰 | `mall_builder_stores`에 `kind`('standard'·'resale'), `source_store_id`, `resale_expires_at` 칸 추가 |
| 거울 상품 | `mall_builder_products`에 `source_product_id` 칸. 분양자가 담으면 원본의 이름·요약·설명·사진·과세·옵션 구성·재고를 복사해 만들고 판매가만 분양자 값 |
| 자동 맞춤 | 원본 상품·옵션이 바뀌면 트리거가 거울에 반영(이름·설명·사진·상태·재고·옵션). 원본이 판매 중지·삭제되면 거울도 판매 중지. 원본 판매가가 올라 거울 판매가보다 높아지면 거울 판매가를 원본가로 올림(하한 유지) |
| 재고 | 거울 재고 = 원본 재고 복사. 분양몰 주문은 거울 재고를 줄이고(기존 주문 함수), 본사 전달 주문이 원본 재고를 줄이면 다시 거울로 복사 |
| 분양자 기준가 | 거울 상품 별도 표 `mall_builder_resale_cost`(거울 상품 → 원본 판매가 당시 값) — 손님이 못 읽음 |

## 3. 주문 흐름

1. 손님이 분양몰에서 주문(기존 주문 함수 그대로) → 분양몰 주문 「입금 대기」. 입금 계좌 = 본사 계좌(분양몰 설정에 본사 계좌 복사).
2. **입금 확인**(본사 관리자가 분양몰 주문 화면 또는 본사 「분양 주문」에서) → 트리거가 **본사 몰에 전달 주문** 생성: 손님 = 분양자(본사 몰 회원), 받는 분 = 분양몰 손님 배송지, 품목 = 원본 상품·옵션, 단가 = 원본 판매가, 상태 「결제 완료」, 원본 재고 차감.
3. 본사 전달 주문은 지금처럼 본사·공급사가 발송(D36 품목 송장). 송장·배송 상태는 분양몰 주문에 그대로 비춰 보임.
4. 분양몰 주문 구매 확정 → **분양자 마진 적립** = 분양몰 결제 − 배송비 − 원본가 합계. 반품·취소면 회수. 출금은 리셀러 장부와 같은 방식(신청 → 본사 지급 완료).
5. 분양몰 주문 취소(발송 전) → 본사 전달 주문도 취소·재고 복구.
