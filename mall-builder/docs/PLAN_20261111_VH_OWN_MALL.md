# 개발 플랜 — V-H 바이라이프 자체몰(프로셀 몰 대체) (2026-11-11)

> 주인님 결정(2026-11-11): 버전 계열 중 **V-H 자체몰을 먼저**.
> 근거: `docs/mall/ROADMAP_AND_VARIANTS.md` V-H — 「V-G와 같은 단일 몰 모드, 선행 v1 + 카드 결제 + 알림 + 프로셀 상품 이전, **운영 이전은 주인님 명시 지시가 있을 때만**」.

## 1. 왜 따로 정해야 하나

지금 몰은 **Lab**(`AIMaster_dev`, 누구나 가입·언제든 삭제 가능한 시험 환경)에서 돈다. 실제 손님 개인정보·주문·결제가 오가는 몰은 Lab에 두면 안 된다(Lab 지침). 그래서 「어디서 실제로 운영할지」부터 정해야 한다.

## 2. 단계(안)

| 단계 | 내용 | 어디서 |
|---|---|---|
| H1 단일 몰 모드 | 환경 설정 하나로 「몰 하나만 있는 사이트」로 바뀜 — 첫 화면이 바로 그 몰, 「몰 만들기·다른 몰」 숨김, 주소 `/s/<몰>` 없이 바로 열림. 같은 코드가 Lab(여러 몰)과 자체몰(몰 하나) 둘 다 됨(V-G 수강생판도 이걸 그대로 씀) | 코드(Lab에서 개발·시험) |
| H2 프로셀 상품 이전 | 프로셀 「상품 엑셀 내려받기」 파일 → 우리 「상품 엑셀 올리기」(D23) 양식으로 바꿔 주는 변환기(카테고리·옵션·가격·재고·사진 주소) | 코드 + 주인님이 프로셀 엑셀 1개 제공 |
| H3 회원 이전 | 프로셀 회원 엑셀 → 손님 목록(이름·연락처·사업자 정보·등급). **비밀번호는 옮길 수 없어** 첫 로그인 때 「비밀번호 설정」 메일·문자 안내 | 코드 + 회원 엑셀 |
| H4 운영 환경 설치·리허설 | 결정 1의 운영 환경에 설치 → 상품·회원 옮겨 넣고 주인님과 실제 주문·결제·발송 리허설 | 운영 환경(주인님 명시 지시 뒤) |
| H5 전환 | 도메인 연결, 실제 토스 키, 프로셀 몰 공지·종료 | 주인님 지시 뒤 |

H1~H3은 Lab에서 개발·시험(실제 손님 정보 없이, 시험 데이터로). H4부터 실제 데이터가 들어간다.

## 3. 결정 항목 (주인님)

| 번호 | 항목 | 추천 | 다른 안 |
|---|---|---|---|
| 1 | 실제 운영 위치 | **새 전용 Supabase 프로젝트 + 전용 Vercel 프로젝트**(Lab과 분리, V-G 수강생판과 같은 방식 — 몰 하나만 담음) | AIMaster 운영 DB(회원 사이트와 같은 DB)에 넣기 / Lab 그대로 쓰기(비추천 — 실제 개인정보) |
| 2 | 이번에 할 범위 | **H1~H3(코드·Lab 시험)까지 하고, H4 운영 설치는 그때 다시 여쭘** | H1만 먼저 / H5 전환까지 한 번에 |
| 3 | 주소 | **지금 프로셀 몰 도메인을 그대로 옮김(H5 때)** — 손님 즐겨찾기·검색 유지 | `shop.buylife.xyz` 같은 새 주소 |
| 4 | 회원 이전 방식 | **이름·연락처·사업자 정보·등급만 옮기고, 첫 로그인 때 비밀번호 새로 설정** | 회원 안 옮기고 새로 가입 받기 |

## 4. 비용

- H1~H3: 없음(Lab DB·로컬 시험, 배포는 미배포로 모았다가 승인 때 빌드 1회).
- H4(결정 1 추천안): **Supabase 새 프로젝트 — 무료 요금제는 계정당 2개 제한이라 유료(Pro 약 월 $25)가 필요할 수 있음**, Vercel은 기존 팀 사용. 실제 비용은 H4 시작 전에 다시 확인해 여쭘.
- 결제 수수료(토스)·문자 비용은 몰 운영자(주인님) 부담 — 지금 프로셀과 같음.
