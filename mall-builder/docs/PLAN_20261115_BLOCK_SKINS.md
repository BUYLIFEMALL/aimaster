# 플랜 — 블록 스킨(모양 여러 벌) + 스킨마다 다른 편집 칸 (I14 + E9, 2026-11-15)

> 주인님 지시: 「I14 스킨마다 다른 편집 칸 … E9와 묶어 진행 — 이것부터 진행하고 나머진 그다음」
> 작성: [역할: mall-design-builder] 세션 `claude-win-20261114-mall-design`

## 문제
블록마다 모양이 한 가지뿐이라 같은 템플릿끼리 비슷해 보인다(프로셀은 블록마다 스킨 여러 벌 — 모듈 분석 §2-3·§2-5). 스킨마다 필요한 칸(예: 글 얹은 배너의 문구)도 다르다.

## 범위 (1차 — 효과 크고 서버 데이터 변경이 없는 3블록)
| 블록 | 스킨 | 스킨마다 달라지는 편집 칸 |
|---|---|---|
| 단일 배너 | 둥근 카드(기본) / 꽉 찬 띠 / 글 얹은 배너 | 꽉 찬 띠는 「최대 너비」 숨김, 글 얹은 배너는 큰 글·작은 글·단추 이름 칸이 생김(큰 글 필수) |
| 카테고리 바로가기 | 둥근 사각(기본) / 동그라미 / 글자 칩 | 글자 칩은 그림·이모지 칸 숨김(카테고리 이름만) |
| 공지 | 목록(기본) / 한 줄 띠 | 칸 차이 없음(모양만) |

- 저장: 각 블록 설정에 `skin`(기본은 저장하지 않음 → 옛 저장본·기본 블록은 그대로), 글 얹은 배너만 `headline`·`sub`·`button_label`. DB 변경 없음(설정 JSON 안).
- 스킨 목록은 `src/lib/blocks.ts`의 `BLOCK_SKINS` 한 곳 — 다음에 블록·스킨을 늘릴 때 여기에 한 줄.
- 편집 칸: 공용 `SettingsForm` 한 곳(첫 화면 편집기·디자인 편집기가 함께 씀)에 스킨 고르기 + 조건부 칸.
- 바로 편집(D7): 글 얹은 배너의 큰 글·작은 글도 연필로 고칠 수 있게 `INLINE_FIELDS`에 추가.

## 하지 않는 것(이번)
- 상품 진열·탭·후기 블록 스킨(이미 카드 모양·가로 넘김 옵션이 있음) — 다음 묶음 후보.
- 템플릿 13종의 블록 스킨 변경(주인님이 고른 115 등 기존 모양 유지). 새 스킨은 편집기에서 고름.

## 순서와 검사
1. `blocks.ts` 타입·검사·`BLOCK_SKINS` → 시험(기본 스킨은 저장 안 함, 글 얹은 배너 큰 글 필수, 칩은 그림 없이 통과, 이상한 스킨 값은 기본으로)
2. 유저 화면 그리기(`home-blocks.tsx` 배너, `home-slots.tsx` 카테고리·공지)
3. 편집 칸(`block-editor.tsx` SettingsForm)·바로 편집 칸
4. `tsc`·전체 시험·Lab ego 화면 확인(스킨 바꾸면 칸이 바뀌는지, 미리보기 모양)
5. 커밋(미배포 대기), 작업표 I14·E9 갱신
