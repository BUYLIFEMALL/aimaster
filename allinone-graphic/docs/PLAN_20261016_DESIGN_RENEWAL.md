## 1. 개요 및 배경

### 1.1 프로그램 분석 요약
- **프로그램 성격**: 회원 본인의 Gemini API 키를 기반으로 19개 직군 123종의 전문 그래픽 템플릿 생성, 기획서 파일(.txt, .md, .pdf) 자동 분석 AI 입력 도우미, 캔버스 마스크 브러시 스마트 매직 에디터(인페인팅)를 지원하는 원스톱 AI 그래픽 디자인 스튜디오.
- **핵심 아키텍처 (4컬럼 스튜디오)**:
  1. 좌측 사이드바: 5대 카테고리 19개 직군 필터 & 키/가이드 유틸리티
  2. 템플릿 탐색기: 실시간 검색 & 123종 프리셋 카드 갤러리
  3. 중앙 제어 콘솔: 화풍 10종, 비율/해상도 옵션, 기획서 파일 업로드 및 AI 자동 채우기
  4. 캔버스 뷰포트 & 매직 에디터: 마스크 브러시 부분 수정/삭제, 고화질 다운로드, 생성 히스토리

### 1.2 리뉴얼 배경 및 필요성
1. **정식 `/guide` 사용 매뉴얼 라우트 미구현**:
   - 현재는 사이드바의 가이드 버튼 클릭 시 작은 팝업 모달(`GuideModal.tsx`)만 열림.
   - 메인 지침에 명시된 `📖 연동 & 사용 매뉴얼` 라우트(`/guide`)가 없어, 초보 사용자가 전체 5단계 파이프라인, 123종 템플릿 맵, 매직 인페인팅 에디터 사용법을 체계적으로 숙지하기 어려움.
2. **크리에이티브 아틀리에 스타일 고도화**:
   - `DESIGN.md` 공식 카탈로그에 지정된 **크리에이티브 아틀리에 스타일(대형 캔버스 뷰포트 중심, 프리셋 갤러리 그리드, 비비드 앰버 골드 `#f59e0b` & 미드나잇 다크 액센트)**을 강화하여 하이엔드 전문가용 그래픽 스튜디오 감성 부여.
3. **사이드바 레이아웃 표준화 준수**:
   - 폭 244px 표준 너비 준수, 유틸리티 메뉴 `📖 연동 & 사용 매뉴얼` 정식 링크 탑재, 계정 블록 8~16px 밀착 배치.

## 2. 작업 범위 및 세부 계획

### 2.1 신규 사용 매뉴얼 (`/guide`) 비주얼 가이드북 전면 구축 (`src/app/guide/page.tsx`)
1. **크리에이티브 아틀리에 골드 앰버 히어로 (`.atelier-hero`)**:
   - 딥 미드나잇-앰버 그라데이션(`linear-gradient(135deg, #0f172a 0%, #1e1b4b 50%, #451a03 100%)`) 배너.
   - 알약 뱃지: `✨ 크리에이티브 아틀리에 스타일`, `19개 직군 123종 전문 템플릿`.
2. **5단계 올인원 그래픽 제작 파이프라인 인포그래픽**:
   - `1. 직군 템플릿 탐색 ➔ 2. AI 자동 기획서 분석 ➔ 3. 렌더링 옵션 세팅 ➔ 4. 초고화질 생성 ➔ 5. 스마트 매직 에디터 부분 수정` 5단계 시각적 흐름도.
3. **시작 전 필수: 본인 Gemini API 키 연동 가이드**:
   - Google AI Studio 무료 키 발급 방법, 보안 보관 원칙, 모델별 티어 안내.
4. **5대 직군 그룹 123종 템플릿 맵 치트시트**:
   - IT/개발자, 게임/엔터테인먼트, 크리에이티브/예술, 비즈니스/마케팅, 라이프스타일/커머스 19개 직군 카드 정리.
5. **스마트 매직 에디터 (Inpainting) 실전 가이드**:
   - 마스크 브러시 칠하기 ➔ 프롬프트 수정 ➔ 부분 렌더링 노하우.
6. **자주 묻는 질문 (FAQ) 아코디언 4종**:
   - Gemini 키 무료 사용량, 한글 텍스트 렌더링 팁, 매직 에디터 마스크 팁, 상업적 이용 등.

### 2.2 사이드바 (`src/components/layout/Sidebar.tsx`) 표준화
- 유틸리티 메뉴에 `📖 연동 & 사용 매뉴얼` (`/guide` 링크) 정식 탑재.
- `🔑 API키등록·플랫폼연동` 팝업 연동 유지.

- 모바일(375~390px) 햄버거 메뉴 터치 및 드로어 스크롤 최적화.
