## 3. 핵심 기능 사용법

### 1) 3단계 워크플로우
1. **직군 & 템플릿 선택**:
   - 좌측 사이드바에서 본인의 직군(또는 대분류)을 클릭하고 123종의 전문 프리셋 중 원하는 카드를 선택합니다.
2. **옵션 설정 & AI 입력 도우미**:
   - 화면 비율(1:1, 16:9, 9:16, 4:3, 3:4), 해상도(1K, 2K, 4K), 화풍 스타일(11종)을 선택합니다.
   - 기획서 문서(.txt, .md, .pdf, 이미지)를 첨부하고 **[AI 자동 입력]** 버튼을 누르면 AI가 본문을 분석하여 입력창을 100% 자동으로 채워줍니다.
3. **생성 & 매직 인페인팅 편집**:
   - **[이미지 생성하기]**를 눌러 즉시 렌더링합니다.
   - 수정이 필요한 경우 **[편집 모드]**로 전환하여 브러시로 원하는 영역을 칠하고 수정 요청을 입력하면 해당 부분만 정밀 교체됩니다.

## 4. 보안 및 회원 본인 API 키 연동 규칙

- **최상위 불변 원칙**:
  - 회원은 본인의 Google Gemini API 키를 직접 등록하여 사용합니다 (`user_api_keys.provider = 'gemini'`).
  - 운영자 키나 타인의 키로 폴백하지 않으며, API 키 등록 모달에서 3단계(텍스트/표준 이미지/Pro 이미지) 사전 진단을 지원합니다.
