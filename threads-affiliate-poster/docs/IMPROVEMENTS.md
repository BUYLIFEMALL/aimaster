## 1. 본 프로그램 추가개선 제안 (필수 3대 항목)

### ① 프로그램 로직 및 기능 개선
1. **제휴 링크 유효성 실시간 자동 검증**:
   - 사용자가 등록한 쿠팡/알리 상품 URL이 품절되거나 판매 중지될 경우 알림을 주는 배치 체크 기능 추가 제안.
2. **트렌드 떡상글 자동 스크랩 시 AI 감성/카테고리 분류 태깅**:
   - 트렌드 메뉴에서 수집된 떡상글을 "뷰티/패션", "리빙/생활", "IT/전자기기" 등으로 자동 클러스터링하여 원하는 카테고리의 제휴 상품과 매칭하는 기능 제안.
3. **생성 데이터 30일 보존 후 자동 정리 배치**:
   - `tap_posts` 중 생성/발행된 지 30일이 지난 임시 파일 및 미디어 URL을 RLS 및 회원 격리 원칙에 맞춰 정리하는 Supabase Cron 연동 제안.

### ② 사용자 인터페이스 / UI 가독성 및 사용편리성 개선
1. **상품 등록 시 URL 자동 완성 및 썸네일 미리보기 확대**:
   - 쿠팡 직링크 입력 즉시 상품명과 썸네일을 모달에서 미리 확인하고 즉시 글 작성으로 넘어가는 퀵 플로우 버튼 제공.
2. **글 작성 화면(`/posts/new`) 다크 캔버스 컴포넌트 추가 정돈**:
   - 본문 에디터 및 카드뉴스 프리뷰 영역에 다크 모노 테마 서페이스 적용.

### ③ 다른 자동화 프로그램과의 연계 가능 기능
1. **8번 `detail-page-12p` (AI 12단 상세페이지 자동화) 연계**:
   - 상세페이지에서 생성된 제품 핵심 장점 3줄 요약을 클릭 한 번으로 Threads 제휴 포스팅 캡션으로 가져오는 원클릭 가져오기 버튼.
2. **24번 `cardnews-studio` (INSTA Cardnews 자동화) 연계**:
   - 제휴 상품의 고화질 컷을 인스타 카드뉴스 템플릿과 연동하여 스레드-인스타 동시 발행 파이프라인 구축.
3. **46번 `threads-comment-reply` (Threads 댓글자동화) 연계**:
   - 쇼핑제휴 포스팅 발행 후, "구매 링크는 어디 있나요?", "가격 얼마인가요?" 등의 반응 댓글에 자동으로 제휴 단축링크를 대댓글로 달아주는 자동 응답 연동.
