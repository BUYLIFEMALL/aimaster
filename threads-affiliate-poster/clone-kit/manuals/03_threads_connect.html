쓰레드(Threads) 계정 연동하기

※ 이 문서의 <복제본-주소>는 복제한 프로그램의 실제 주소(예: my-tap.vercel.app)로 바꿔 읽으세요.

💡 Meta 앱 검수(App Review) 없이 본인 계정에서 쓰레드(Threads) 자동 포스팅·댓글 관리·쇼핑제휴 검색을 쓰기 위한 연동 매뉴얼입니다. (2026-09-28 갱신)

⚠️ 앱 ID 입력 시 필수 확인 사항!

Meta 앱 설정 화면 맨 위의 [앱 ID]가 아니라, 같은 화면 아래쪽에 있는 Threads 앱 ID 및 Threads 앱 시크릿 코드를 입력해야 합니다. 맨 위 앱 ID나 인스타그램 앱 ID를 넣으면 연결 시 "앱 ID가 전송되지 않았습니다"(오류 코드 4476002) 오류가 납니다. 쓰레드 프로그램의 Threads 앱 ID는 인스타그램 프로그램의 앱 ID와 따로 저장되므로 서로 덮어쓰지 않습니다.

1단계: Meta 개발자 센터에서 앱 만들기

  1. Meta Developer Portal 접속 ➔ 로그인
  2. 우측 상단 [내 앱] ➔ [앱 만들기] 클릭
  3. 앱 유형을 비즈니스(Business)로 선택하고 생성 완료

2단계: Threads API 액세스 이용 사례 추가

  1. 앱 대시보드 ➔ 왼쪽 메뉴 [이용 사례] (또는 제품 추가) 클릭
  2. Threads API 액세스 이용 사례를 선택하고 추가합니다.

3단계: Threads 앱 ID & Threads 앱 시크릿 코드 확인 및 등록

  1. 왼쪽 메뉴 [앱 설정] ➔ [기본 설정]으로 이동합니다.
  2. 화면을 아래로 내려 Threads 앱 ID 및 Threads 앱 시크릿 코드를 복사합니다.
  3. 복사한 두 값을 사용하는 쓰레드 프로그램의 API키등록·플랫폼연동 페이지에 입력하고 저장합니다. (한 번 저장하면 쓰레드 프로그램 3개가 같은 값을 함께 씁니다)

4단계: 리디렉션 콜백 URL 설정

  1. 왼쪽 메뉴 [이용 사례] ➔ [Threads API 액세스] ➔ [설정]으로 이동합니다.
  2. 리디렉션 콜백 URL 칸에 사용하는 프로그램의 주소를 추가합니다(여러 개 추가 가능):
    https://threads-nu-dusky.vercel.app/api/threads/callback
    https://threads-comment-reply.vercel.app/api/threads/callback
    https://<복제본-주소>/api/threads/callback
  3. (권장) 같은 화면의 제거 콜백 URL과 삭제 콜백 URL에 아래 주소를 넣으면, 앱을 제거하거나 데이터 삭제를 요청할 때 쓰레드 프로그램 3개의 연결 정보가 자동으로 정리됩니다.
    https://<복제본-주소>/api/threads/uninstall
    https://<복제본-주소>/api/threads/delete
  4. 저장을 누릅니다.

5단계: 필수 권한(Permissions) 확인

  1. [Threads API 액세스] ➔ [권한 및 기능]으로 이동합니다.
  2. 사용하는 기능에 맞는 권한이 추가돼 있는지 확인합니다: threads_basic, threads_content_publish(포스팅), threads_read_replies·threads_manage_replies(댓글), threads_keyword_search(쇼핑제휴 키워드 검색 — 8단계)

6단계: 본인 계정을 Threads 테스터로 추가

  1. [이용 사례] ➔ [Threads API 액세스] ➔ [설정] 화면 아래 [Threads 테스터 추가 또는 삭제]에서 본인 쓰레드 아이디로 초대합니다.
  2. 스마트폰 쓰레드(Threads) 앱 ➔ 설정 ➔ 계정 ➔ 웹사이트 권한 ➔ 초대에서 초대를 [승인]합니다. 이 단계를 빼먹으면 "권한이 없습니다" 오류가 납니다.

7단계: 웹 서비스 접속 & Threads 계정 연결 완료

  1. 쓰레드 프로그램의 API키등록·플랫폼연동 ➔ [Threads 계정 연결하기] 클릭
  2. 로그인 및 권한 동의를 허용하면 완료! 🎉

8단계 (쇼핑제휴 트렌드 검색을 쓸 때): 키워드 검색 권한 추가

  1. [Threads API 액세스] ➔ [권한 및 기능]에서 threads_keyword_search 옆 [추가]를 누릅니다.
  2. 쇼핑제휴 프로그램 [트렌드 & 떡상 탐지기]에서 검색하면 나오는 안내 박스의 [🔑 검색 권한 포함해서 Threads 다시 연결]을 눌러 권한을 승인합니다.
  3. 권한을 추가하지 않고 다시 연결 버튼만 누르면 Meta 화면에서 오류가 날 수 있으니 1번을 먼저 해주세요.
ℹ️ Meta 정책상 앱 검수 승인 전에는 본인 계정의 글만 검색됩니다. 다른 사람의 공개 글까지 검색하려면 Meta 비즈니스 인증·테크 제공업체 등록·앱 검수 승인이 필요합니다. 승인 전에는 트렌드 화면의 [🔗 떡상글 직접 가져오기]로 참고할 인기 글의 링크와 본문을 붙여넣어 활용하세요.

💡 핵심 요약 정리

  • 앱 ID 구별: 맨 위 앱 ID가 아닌 아래쪽 Threads 앱 ID와 Threads 앱 시크릿 코드를 입력하세요.
  • 리디렉션 URL: Threads API 액세스 설정의 리디렉션 콜백 URL에 사용하는 프로그램 주소를 추가하세요.
  • 테스터 승인: 본인 계정을 Threads 테스터로 추가하고 쓰레드 앱에서 초대를 승인해야 검수 없이 바로 동작합니다.
  • 키워드 검색: threads_keyword_search 권한 추가 후 "검색 권한 포함해서 다시 연결"을 눌러야 합니다(승인 전에는 본인 글만 검색).
