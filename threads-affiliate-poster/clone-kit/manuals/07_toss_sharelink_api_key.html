토스쇼핑 쉐어링크 API 키 발급받기

※ 이 문서의 <복제본-주소>는 복제한 프로그램의 실제 주소(예: my-tap.vercel.app)로 바꿔 읽으세요.

토스쇼핑 쉐어링크는 베스트/카테고리/오늘의특가 상품을 조회하고 제휴 링크를 발급하는 기능에 사용됩니다.

  1. sharelink.toss.im에서 크리에이터로 신청/가입합니다.
  2. 좌측 메뉴 연동 > API 키 발급으로 이동합니다.
  3. "API 연동 키 만들기"를 누르면 출발지 IP를 먼저 등록하라는 안내가 나옵니다. 여기에 이 프로그램가 사용하는 고정 IP 2개(52.87.82.133, 52.5.155.132)를 그대로 추가해주세요. (본인의 개인 IP가 아니라 이 플랫폼이 사용하는 공용 고정 IP입니다 — 모든 회원이 동일하게 이 값을 등록합니다.)
  4. "키 만들기"를 누르면 Access Key, Secret Key, 회원 연동 ID 3가지가 한 번에 발급됩니다.
  5. 3가지 값을 이 프로그램 설정 페이지의 토스쇼핑 쉐어링크 항목에 각각 등록합니다.

⚠️ 출발지 IP를 등록하지 않으면 API 호출이 전부 거부됩니다. 잊지 말고 먼저 등록해주세요.
