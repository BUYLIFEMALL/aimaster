OpenAI API 키 발급받기

※ 이 문서의 <복제본-주소>는 복제한 프로그램의 실제 주소(예: my-tap.vercel.app)로 바꿔 읽으세요.

OpenAI API 키는 이 프로그램의 캡션/콘텐츠 자동 생성 기능(GPT)에서 사용됩니다. 본인 명의로 발급받아 설정 페이지에 등록하면 됩니다.

  1. platform.openai.com에 접속해 회원가입 또는 로그인합니다. 최초 가입 시 이메일 인증과 휴대폰(SMS) 인증이 필요할 수 있습니다.
  2. 우측 상단(또는 좌측 메뉴)의 Billing 메뉴에서 결제 카드를 등록하고, 소액(5달러 정도)을 충전합니다. 결제수단이 등록되어 있지 않으면 API 키를 발급받아도 실제 호출이 실패합니다.
  3. 좌측 메뉴에서 API keys로 이동합니다(platform.openai.com/api-keys).
  4. Create new secret key 버튼을 클릭하고, 키 이름을 입력한 뒤 생성합니다.
  5. 발급된 키(sk-...로 시작)는 이 순간에만 전체가 보이므로 바로 복사해서 안전한 곳에 저장해두세요. 창을 닫으면 다시 볼 수 없습니다.
  6. 복사한 키를 이 프로그램의 각 프로그램 설정 페이지 "OpenAI" 항목에 붙여넣고 저장하면 연동이 완료됩니다.

💳 자동 충전(Auto recharge) 설정 추천: Billing 메뉴에서 "잔여 크레딧이 5달러 미만이 되면 자동으로 10달러씩 충전, 월 30달러 이상은 결제되지 않도록 한도 설정"처럼 자동 충전 + 월 한도를 함께 걸어두면, 잔액 부족으로 서비스가 갑자기 멈추는 것도 막고 과도한 과금도 방지할 수 있습니다.

🖼️ 이미지 생성(GPT Image 1)을 쓰려면 별도로 조직 인증이 필요합니다. platform.openai.com/settings/organization/general에서 "Verify Organization" → "Start ID Check"를 눌러 신분증 인증을 진행하세요(휴대폰으로 셀카를 촬영해야 해서 모바일에서 진행하는 것을 추천합니다). 인증 전에는 GPT Image 1 모델 호출이 거부됩니다.

⚠️ API 키는 비밀번호와 같습니다. 캡쳐본이나 공개 저장소에 절대 노출하지 마세요.
