네이버 브랜드커넥트 링크 등록하기

※ 이 문서의 <복제본-주소>는 복제한 프로그램의 실제 주소(예: my-tap.vercel.app)로 바꿔 읽으세요.

네이버 브랜드커넥트(쇼핑 커넥트)는 공식 API가 없어서, 브랜드커넥트 사이트에서 직접 발급받은 제휴 링크를 상품 등록 화면에 그대로 붙여넣는 방식으로 이용합니다. 다른 플랫폼처럼 API 키를 발급받아 설정 페이지에 등록하는 절차가 아닙니다.

  1. 네이버에서 "브랜드 커넥트"를 검색해 brandconnect.naver.com에 접속한 뒤 "브랜드 커넥트 시작하기"를 눌러 약관에 동의합니다.
  2. "스페이스 개설하기"에서 본인 소유의 블로그(또는 인스타그램/유튜브 등) 채널을 최소 1개 연동합니다.
  3. 프로필 이미지, 스페이스명, 활동 주제(메인 1개 + 서브 최대 2개), 관심 상품 카테고리(최대 3개)를 순서대로 입력하고, 정산 정보 유형(개인/사업자)을 선택해 스페이스를 개설합니다.
  4. "쇼핑 커넥트 권한이 부여되었습니다" 안내가 뜨면 약관에 동의하고 "쇼핑 커넥트 시작하기"를 눌러 활성화합니다.
  5. "상품 찾기"에서 홍보할 상품을 검색해 선택하고, "링크 발급" 버튼을 눌러 제휴 링크를 발급받습니다.
  6. 발급받은 링크를 이 프로그램의 상품 등록 화면에서 플랫폼 "네이버 브랜드커넥트"를 선택한 뒤, 상품명과 함께 "네이버 브랜드커넥트 링크" 입력란에 그대로 붙여넣고 등록합니다.

⚠️ 게시물에는 제휴 링크임을 알리는 경제적 이해관계 고지 문구를 반드시 표시해야 합니다. 비정상적인 트래픽 유도나 스팸성 자동 발송은 모니터링 대상이 되어 제재를 받을 수 있으니, 상품은 직접 확인하고 링크를 발급받는 것을 권장합니다.
