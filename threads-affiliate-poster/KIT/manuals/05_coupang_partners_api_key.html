쿠팡파트너스 API 키 발급받기

※ 이 문서의 <복제본-주소>는 복제한 프로그램의 실제 주소(예: my-tap.vercel.app)로 바꿔 읽으세요.

쿠팡파트너스 API는 상품 검색, 딥링크(제휴 링크) 자동 생성에 사용됩니다. 사업자 등록 없이 개인도 가입할 수 있습니다.

  1. partners.coupang.com에서 이메일과 비밀번호로 회원가입합니다.
  2. 가입 후 "활동 페이지"(제휴 링크를 게시할 블로그/SNS/쓰레드 계정 등)와 "활동 스크린샷"(경제적 이해관계 표시 문구가 보이는 화면)을 등록합니다.
  3. API 키는 회원가입만으로는 발급되지 않습니다. 발급받은 제휴 링크를 통해 실제 누적 판매금액이 15만원 이상이 되어야 자동으로 최종 승인 심사가 진행되고, 승인이 나야 API 키가 활성화됩니다.
  4. 최종 승인 전까지는 API 호출 시 "키가 등록되지 않았다"는 오류가 나는 게 정상입니다 — 코드 문제가 아니라 매출 요건 미충족 때문입니다.
  5. 승인 후 쿠팡파트너스 홈페이지에서 Access Key와 Secret Key를 확인해 이 프로그램 설정 페이지에 등록합니다.

⏱️ 시간당 호출 횟수 제한이 있으니, 검색을 너무 자주 반복하지 않는 것이 좋습니다.
