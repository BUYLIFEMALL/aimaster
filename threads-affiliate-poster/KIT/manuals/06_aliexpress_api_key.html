알리익스프레스 API 키 발급받기

※ 이 문서의 <복제본-주소>는 복제한 프로그램의 실제 주소(예: my-tap.vercel.app)로 바꿔 읽으세요.

알리익스프레스 어필리에이트 API는 상품 URL을 제휴 추적 링크로 바꿔주는 기능에 사용됩니다.

  1. portals.aliexpress.com에서 어필리에이트 계정으로 가입/로그인합니다.
  2. 좌측 메뉴 Tools > API로 이동해 "Apply Now"를 클릭하고, 이름/생년월일/신분증/주소/연락처 등 신청 양식을 작성합니다.
  3. 신청 후 승인까지 보통 2~5일 정도 걸립니다.
  4. 승인되면 "Create" → "Create APP"을 눌러 앱을 하나 만듭니다. 앱 이름과 로고를 입력해야 합니다.
  5. 앱 생성이 끝나면 App Key와 App Secret이 발급됩니다.
  6. 같은 포털의 계정(Account) 메뉴에서 Tracking ID도 함께 확인해두세요 — 어떤 채널에서 발생한 클릭인지 구분하는 값으로, 실적 추적에 필요합니다.
  7. 발급받은 App Key/App Secret/Tracking ID 3개를 이 프로그램 설정 페이지에 모두 등록해야 정상 작동합니다.
