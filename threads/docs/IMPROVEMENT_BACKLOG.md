## 1. 디자인 및 UX 백로그
- [ ] 본문 작성기 화면 우측에 실시간 모바일 피드 프리뷰(WYSIWYG 목업) 컴포넌트 추가
- [ ] 500자 제한 임박 시 동적 경고를 표시하는 원형 프로그레스 바(Circular Character Counter) 적용
- [ ] 예약 목록을 날짜별/시간별로 한눈에 볼 수 있는 주간/월간 캘린더 그리드 뷰 구현

## 2. 기능 및 비즈니스 로직 백로그
- [ ] 다중 이미지(캐러셀, 최대 10장) 일괄 업로드 및 Threads 컨테이너 연동
- [ ] 500자 초과 시 자동으로 첫 번째 댓글(타래, Thread Chain)로 연결하여 게시하는 연쇄 포스팅 엔진
- [ ] 발행 완료된 게시글의 좋아요, 리포스트, 댓글 수를 주기적으로 가져오는 성과 동기화 크론 작업

## 3. 다른 프로그램과의 연계 백로그
- [ ] `threads-creator` (기획 자동화)에서 작성된 고효율 초안 원클릭 불러오기 버튼
- [ ] `ai-image-studio`의 나노바나나 고화질 이미지 생성 모듈 직접 호출 연동
