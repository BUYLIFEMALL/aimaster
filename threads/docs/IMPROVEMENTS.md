## 1. 본 프로그램 핵심 3대 개선 과제

### 1) 프로그램 로직 및 기능 개선
- **다중 이미지(캐러셀) 및 영상 포스팅 파이프라인 확장**: 현재 단일 이미지 또는 텍스트 위주의 포스팅에서 최대 10장까지의 슬라이드 캐러셀(Carousel) 포스팅 컨테이너 및 비디오(`video_container`) 자동 업로드 API 로직 연동.
- **자동 타래(First Reply / Thread Chain) 작성 엔진**: 본문 500자 제약을 넘어서는 긴 인사이트를 위해 1번 게시글 업로드 후 즉시 대댓글(타래)로 2번, 3번 포스트 및 외부 링크를 연쇄 포스팅하는 체인 로직 구현.
- **포스팅 발행 후 실시간 성과 추적 웹훅**: Meta Graph API 웹훅 또는 주기적 폴링을 통해 발행된 게시글의 조회수, 좋아요, 리포스트 수를 대시보드에 실시간 반영.

### 2) UI / UX 가독성 및 사용 편의성 개선
- **실시간 모바일 Threads 피드 미리보기(WYSIWYG Mockup)**: 본문 입력 시 Threads 공식 앱과 1:1로 일치하는 실시간 스마트폰 피드 프리뷰 화면을 우측에 배치하여 줄바꿈 및 텍스트 후킹 위치 사전 점검 지원.
- **500자 카운터 시각화 링**: 500자 제한 임박 시(450자 이상) 노란색/빨간색으로 변하는 동적 원형 프로그레스 바 제공.
- **예약 캘린더 뷰(Calendar Schedule View)**: 날짜별/시간별 예약 현황을 한눈에 드래그앤드롭으로 조작할 수 있는 풀 캘린더 UI 도입.

### 3) 다른 서브프로그램과의 연계/병합 기능 제안
- **`threads-creator` (기획 자동화) 원클릭 임포트**: `threads-creator`에서 생성된 고효율 페르소나 바이럴 초안을 API 또는 공유 DB 테이블을 통해 본 `auto-threads-posting` 스케줄러로 직접 1초 만에 가져와 발행 예약.
- **`ai-image-studio` (나노바나나 레퍼런스) 연동**: 본문 주제 키워드를 바탕으로 `ai-image-studio`의 `gemini-nano-banana-2.1` 어댑터를 통해 고화질 1:1 일러스트를 자동 생성하여 바로 첨부.
- **`threads-affiliate-poster` (제휴 자동화)와의 하이브리드 운영**: 정보성 바이럴 글 사이사이에 수익형 쿠팡/제휴 링크 타래를 적절한 황금 비율(예: 8:2)로 섞어주는 자동 믹서 스케줄러 연계.

## 2. 타 프로그램 탐색 기반 추가 개선 제안

### 1) `threads-analytics` (Threads 성과 분석) 연계
- 본 프로그램에서 자동 발행된 포스트 ID(`threads_media_id`)를 `threads-analytics`에 자동으로 넘겨주어, 어떤 키워드와 시간대의 글이 바이럴을 탔는지 교차 분석하고 최적의 발행 피크 타임을 본 프로그램의 스케줄러에 피드백하는 닫힌 루프(Closed-loop) 자동화 구축 필요.

### 2) `viral-post-maker` (SNS 바이럴 제작) 프롬프트 템플릿 공유
- `viral-post-maker`에서 검증된 최신 SNS 후킹 및 호기심 유발 카피라이팅 템플릿을 `auto-threads-posting`의 RSS 및 트렌드 키워드 요약 엔진에 사본 모듈로 탑재하여 본문 퀄리티 향상.
