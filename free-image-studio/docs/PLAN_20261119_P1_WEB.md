## 5-1에서 정한 것

- 프로그램이 `programs`에 등록되기 전에는 `not_found` → 메인 사이트 프로그램 목록으로 보낸다(관리자 포함). 배포를 먼저 하고 등록을 나중에 해도 문이 열리지 않는다.

- 미들웨어(`src/proxy.ts`)는 쿠키 갱신만 하고 차단은 레이아웃·API 판정이 맡는다(쿠키를 지우는 처리 없음 — 2026-10-10 사고 재발 방지).
- 맥미니 검수(`.ai/results/IMG-P1-5-1-CX-QA-01.md`) P2 세 건 보완: 미들웨어가 갱신된 쿠키를 다음 단계로 넘김, 세션 응답에 캐시 헤더, 로그인 액션이 `safeInternalPath` 하나만 사용(정규화 뒤 `//바깥`이 되는 입력도 거절). P3(로그인 화면 규격·label)은 5-5.
- 로그아웃은 Server Action(`signOutAction`)이라 별도 API 주소가 없다.
