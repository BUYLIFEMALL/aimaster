# 엔진 설치 파일 플랜 (2026-11-04)

주인님 지시: 「나중에 이 엔진 띄우는 건 어떻게 할 거야? 사용자들은 쉽게 해야 할 듯한데」 → 「설치 파일 먼저 진행해, 플랜 보여줘」. 로드맵 9단계(설치 파일)를 4단계 나머지보다 먼저 한다.

## 1. 목표 — 회원이 하는 일

| 지금 | 바꾼 뒤 |
|---|---|
| Node·uv 설치, 압축 풀기, PowerShell `node src/main.mjs` | 사이트에서 설치 파일 받기 → 더블클릭 → [다음] 몇 번 |
| 검은 명령창을 켜 두어야 함 | 명령창 없음. 작업 표시줄 오른쪽 아래 아이콘 + 작은 상태 창 |
| PC를 켤 때마다 다시 실행 | 「PC 켤 때 자동 실행」(기본 켬) |
| 「이미 켜져 있습니다」 → `taskkill` | 두 번 실행하면 켜진 엔진 창을 앞으로만 |
| 엔진이 꺼져 있으면 사이트에서 막힘 | 사이트 [엔진 켜기] 버튼(설치된 엔진을 바로 실행) |
| 새 버전이면 압축을 다시 받음 | 엔진 창·사이트에 「새 버전」 알림 + [받기] |

## 2. 구조 (기존 코드 재사용)

- **껍데기 = Electron**(기존 `naver-blog-auto-poster_app`과 같은 도구). 하는 일: 작업 표시줄 아이콘·상태 창(연결 코드·상태·저장 폴더·기록 보기·끄기), 한 번만 실행, 자동 실행(`setLoginItemSettings`), 사이트 [엔진 켜기]용 주소 등록(`freemusic-engine://`).
- **엔진 = 지금 `engine/src` 그대로.** 껍데기가 Electron 안의 Node로 `main.mjs`를 자식으로 띄우고(`ELECTRON_RUN_AS_NODE`), 출력에서 연결 코드·상태를 읽어 창에 보인다. 끌 때 자식(ACE-Step·YuE2까지) 함께 끔. 엔진 코드는 도구 경로만 받게 조금 고친다.
- **도구(uv·ffmpeg)는 설치 파일에 넣지 않고 처음 켤 때 받는다** — 고정 버전 주소 + SHA-256 확인(YuE2와 같은 `downloadVerified`). 이유: 설치 파일을 작게(약 90MB), ffmpeg는 LGPL 빌드만 써서 배포 조건 문제 없이. 파이썬·ACE-Step은 지금처럼 uv가 받는다.
- **설치 형식 = NSIS 설치 파일(exe)** — 관리자 권한 없이 내 계정에 설치, 바탕화면·시작 메뉴 바로 가기, 제거 프로그램 등록(제거해도 받은 모델·곡 폴더는 남김, 지우는 방법 안내). 이름은 「AI 무료음악 자동화 엔진」(프로그램명과 맞춤).
- **위치** `free-music-studio/desktop/`(프로그램 서브폴더 규칙). 만든 exe는 저장소에 넣지 않는다.
- **원본 참고:** `electron/download.mjs`·`verified-files.mjs`(받기·확인), `package.json` `build.nsis` 설정. 코드는 옮기지 않고 우리 방식으로 새로 쓴다.

## 4. 비용

| 항목 | 비용 |
|---|---|
| Electron·electron-builder·포장 | 무료(내 PC) |
| uv·ffmpeg 받기 | 무료(회원 PC) |
| 설치 파일 올리기 | 사이트 `public/downloads/`(기존 방식) — 파일이 너무 크면 공용 저장소로(그때 여쭘) |
| Vercel 빌드 | 1회(D단계, 미배포 대기 「ACE-Step 음악 모델 구성」 제목도 함께) |
| 코드 서명 인증서 | **이번엔 안 함**(연 수십만 원) — 윈도우 「알 수 없는 게시자」 경고를 안내로 처리, 회원이 늘면 따로 여쭘 |
| AI 호출 | 없음 |

## 5. 위험·주의

- 서명 없는 exe는 SmartScreen 경고와 일부 백신 오탐이 있을 수 있다 → 안내 그림·SHA-256 값 공개.
- 회원 PC에 이미 손으로 설치한 엔진(0.1.x·0.2.x)이 켜져 있으면 부딪힌다 → 설치 파일이 처음 켤 때 예전 엔진을 찾아 끄고 알린다(받아 둔 모델·곡·연결은 같은 데이터 폴더 `%LOCALAPPDATA%\FreeMusicEngine`라 그대로 이어 씀).
- 자동 실행은 끌 수 있게, 끄기(X)는 작업 표시줄로 숨기기·[끄기]는 완전 종료로 구분.
- 엔진을 고칠 때는 [`IMPROVEMENT_HANDOFF_20261104_ENGINE_ERRORS.md`](IMPROVEMENT_HANDOFF_20261104_ENGINE_ERRORS.md) 먼저.
