## 3. 단계마다 지키는 것

- 플랜(이 표의 그 줄) 확인 → 구현 → 시험(엔진·웹) → `tsc`·`build` → 미니PC 실물 → 배포(빌드 1회, 직전 승인) → ego lite 화면 확인(시험 계정) → 문서·커밋·요청함 보고.
- 원본에서 옮긴 파일은 맨 위 주석에 「원본 기능을 옮김(2026-11-03)」만 적고 원작자 이름은 적지 않는다.
- 회원 본인 키, 회원별 데이터 격리, 관리자·시험 계정 30일 예외, 장비 이름(미니PC·마스터PC), 동그라미 숫자 금지.
- 공용 모듈 사본을 가져오면 `docs/SHARED_MODULES.md` 사본 목록에 free-music-studio 추가.

## 4. 검수 장비

- 미니PC(Intel 내장 그래픽, CPU 모드): 모든 단계 기본 시험. 7단계 정렬·분리는 느릴 수 있어 30초 곡으로 시험.
- 마스터PC(RTX 5080 16GB): 1단계 추천 구성 화면, 6~8단계 속도 — 주인님이 실행하고 화면 캡처.

## 6. 확인 못 한 것

- 원본 커버의 세기 같은 설정값, 생성 개수 최대값, 홈 카드 세부 구성.

- **모델 이용 조건(상업 이용) — 단계 시작 전에 공식 모델 카드로 확인해 이 표에 적는다**: 가사 정렬 Qwen3-ForcedAligner-0.6B·Qwen3-ASR-1.7B(7단계), 음원 분리 BS-RoFormer 체크포인트(7·9단계), 앨범 커버 PC 이미지 엔진(5단계 이후). 비상업이면 쓰지 않고 대안을 찾는다.
