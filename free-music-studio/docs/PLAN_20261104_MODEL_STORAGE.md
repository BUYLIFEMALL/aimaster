# 개발 플랜 — 모델 저장 공간 관리(쓰지 않는 모델 지우기 · 모델 저장 폴더 고르기)

- 날짜: 2026-11-04 · [역할: music] `claude-win-20261024-music`
- 주인님 지시: 「용량이 커서 사용안하는건 찾아서 삭제해야 할것 같아 아님 삭제 기능을 넣어주던가」 「사용안하는 모델 삭제기능과 관련 내용을 표시해줘야 할것 같고 만약 가능하다면 설치할 폴더를 사용자가 지정하게 해주면 더 좋아 — 여유있는 다른 드라이브에 다운로드 받아 둘수 있으니까」
- 상태: **플랜 — 주인님 승인 대기**

## 1. 지금 문제
| 무엇 | 지금 | 문제 |
|---|---|---|
| 저장 위치 | 전부 `%LOCALAPPDATA%\FreeMusicEngine`(C 드라이브) 고정. 설치 때 받는 패키지 보관함은 `%LOCALAPPDATA%\uv\cache` | 엔진을 다 받으면 100GB 넘게 C 드라이브를 씀. 다른 드라이브로 못 옮김 |
| 지우기 | 추가 엔진 3개(HeartMuLa·Stable Audio 3·LeVo 2)만 「받은 모델 지우기」 | YuE2, ACE-Step의 안 쓰는 구성(XL 등), 패키지 보관함, MP3 변환 보관은 못 지움 |
| 용량 표시 | 「처음 쓸 때 약 ○GB 받음」(예상값)만 | 실제로 무엇이 몇 GB인지, 얼마나 남았는지 모름 |

## 2. 만들 것
### 2-1. 「저장 공간」 상자(내 PC 엔진 화면, 새로)
- 맨 위: **모델 저장 폴더 경로 · 그 드라이브 남은 공간 · 엔진이 쓰는 전체 용량**
- 아래 표: 항목마다 **이름 · 실제 크기 · 상태(지금 사용 중 / 받아 둠 / 안 씀) · [지우기]**
  - ACE-Step 실행 환경(지우면 다음에 다시 설치)
  - ACE-Step 음악 모델 구성별(지금 쓰는 구성은 「사용 중」으로 지우기 막음, 안 쓰는 XL 등은 지우기 가능)
  - YuE2 모델·실행 도구
  - HeartMuLa · Stable Audio 3 · LeVo 2 (모델 / 실행 환경)
  - 설치 패키지 보관함(uv) — 「다시 설치할 때 받기만 다시 함」 안내
  - MP3 변환 보관
- 지우기는 두 번 눌러 확인, 「다시 쓰면 약 ○GB를 다시 받습니다」 표시. **만드는 중인 작업이 쓰는 엔진은 지우기 막음**
- 지운 뒤 크기·남은 공간 다시 계산

### 2-2. 모델 저장 폴더 고르기
- 「노래 저장 폴더」처럼 사이트 안 한글 폴더 고르기(이미 있는 `FolderPanel` 방식 재사용) → 예: `E:\AI무료음악\모델`
- **옮기는 것(무거운 것)**: ACE-Step·YuE2·추가 엔진 폴더, 설치 패키지 보관함(`UV_CACHE_DIR`), MP3 변환 보관
- **그대로 두는 것(가벼운 것)**: 연결 정보·설정·대기열·기록 파일 — C 드라이브 원래 자리. 그래서 폴더를 바꿔도 사이트 연결이 끊기지 않음
- 바꿀 때 고르기 두 가지:
  1. **받은 모델 옮기기**(추천): 모델 파일만 새 폴더로 옮기고, 실행 환경은 새 자리에서 자동으로 다시 만듦(파이썬 실행 환경은 옮기면 고장 나는 구조라 다시 만듦 — 받기 없이 수 분)
  2. **새로 받기**: 옛 폴더는 지우고 다음에 쓸 때 새 폴더로 받음
- 옮기기 전 확인: 새 드라이브 남은 공간 ≥ 옮길 크기, 만드는 중인 작업 없음. 옮기는 동안 진행 막대(이번에 만든 `StageProgress`) 표시, 중간에 끊기면 옛 폴더를 지우지 않고 다음에 이어서
- 설정은 `engine-settings.json`에 `modelsDir`로 저장

## 3. 구현 순서
1. 엔진: 무거운 폴더 위치를 `modelsDir` 한 곳에서 받도록 정리(`acestep.mjs`·`yue2.mjs`·`pyengines.mjs`·`main.mjs`, `UV_CACHE_DIR` 지정) → 시험
2. 엔진: `GET /storage`(항목별 실제 크기·사용 중 여부·드라이브 남은 공간), `POST /storage/<항목>/remove`, `POST /storage/move`(옮기기·진행 상황) → 시험(가짜 폴더로 크기·지우기 막기·옮기기 중단 후 이어서)
3. 사이트: 「저장 공간」 상자 + 모델 저장 폴더 고르기, 곡 만들기의 「약 ○GB 받음」 옆에 받을 드라이브 표시
4. 함께: 이번 진행 막대(미배포 대기 `c4468c688`), 설치 파일 개선 2개(확인 창 없이 엔진 끄고 설치, 이미 연결된 PC는 상태 창 안 띄움)
5. 엔진 0.5.0 설치 파일 → 사이트 v1.14 배포 1회 → 미니PC에서 설치·목록·지우기 확인 → 마스터PC 실물(주인님): 모델 폴더를 다른 드라이브로 옮기기·곡 1개 만들기

## 4. 검수
- 자동 시험: 폴더 위치 계산, 사용 중 항목 지우기 막힘, 옮기기 중 끊김 → 옛 폴더 유지, 남은 공간 부족이면 시작 안 함
- 미니PC(그래픽카드 없음): 저장 공간 목록·크기·지우기·폴더 바꾸기(작은 항목)
- 마스터PC(주인님): 실제 모델(수십 GB)을 다른 드라이브로 옮긴 뒤 ACE-Step·HeartMuLa로 곡 만들기
