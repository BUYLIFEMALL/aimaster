# PC 검사·음악 모델 고르기 플랜 (v1.07 · 엔진 0.1.5)

2026-11-03 주인님 지시: 「설치 가능한 PC인지 체크해주는 기능 넣어줘야 할 것 같고」「엔진 선택할 수 있는 기능 있으면 좋을 듯」(참고 화면: 다른 음악 프로그램의 환경설정 — 추천 구성 표·모델 고르기·설치 가능 판정·필요 저장 공간·시스템 재검사).

## 문제
- 지금은 엔진을 켜야만 음질이 정해지고, 회원은 설치 전에 「내 PC에서 되는지」 알 수 없다.
- 엔진이 그래픽 메모리를 보고 음질을 자동으로 고르지만, 회원이 다른 구성(더 빠른 것·더 가벼운 것)을 고를 방법이 없다.

## 범위
1. **설치 전 간단 검사(웹만)** — 엔진이 꺼져 있어도 브라우저가 아는 것으로 판정: 운영체제·64비트·그래픽카드 종류(WebGPU 어댑터 정보)·CPU 코어. 결과 「설치 가능 / 확인 필요 / 지원 안 함(Intel 맥 등)」. 그래픽 메모리·저장 공간은 브라우저가 알 수 없으므로 「엔진을 켜면 정확히 검사」라고 밝힌다.
2. **정밀 검사(엔진 0.1.5, `GET /system`)** — 운영체제·CPU·메모리·그래픽카드 이름·그래픽 메모리·저장 공간 여유·MP3 변환 도구. 항목마다 통과/주의/실패와 이유, 종합 판정.
3. **음악 모델 구성 고르기** — 구성 6단계(최고 품질 4B · 최고 품질 · XL 고품질 · 고품질 · 표준 · 기본). 이 PC 그래픽 메모리로 되는 것만 고를 수 있고(나머지는 이유와 함께 흐리게), 추천은 「이 PC에 추천」 표시, 구성마다 필요 저장 공간. 고르면 엔진이 설정을 저장하고 음악 엔진을 다시 켠다(`POST /quality`). 새 모델은 첫 생성 때 받는다.
4. **화면** — 「내 PC 엔진」 화면 맨 위에 「이 PC 검사」 카드(추천 구성 표 + 다시 검사), 그 아래 「음악 모델 구성」 고르기 + 설치 가능 판정 + 「이 구성으로 바꾸기」.

## 하지 않는 것
- 기능별 다른 엔진(음원 분리·가사 맞춤 등) — 지금 엔진은 하나이고 생성·커버를 함께 처리한다. 다른 엔진이 생기면 같은 칸에 추가.
- 모델 미리 내려받기 버튼 — 0.2 설치 파일 작업 때.

## 구현 순서
1. `engine/src/device.mjs`: 구성 표 `QUALITY_TIERS`, `availableTiers()`, `systemCheck()`(순수 함수, 시험 추가)
2. `engine/src/acestep.mjs`: 그래픽카드 이름·저장 공간 여유 읽기
3. `engine/src/main.mjs`: 고른 구성 저장(`engine-settings.json`)·음악 엔진 다시 켜기, `features`에 `system`
4. `engine/src/gateway.mjs`: `GET /system`, `POST /quality`(연결 코드 토큰 필요)
5. 웹 `src/lib/pcCheck.ts`(브라우저 검사 판정, 시험), `src/lib/engine.ts`(getSystem·setQualityTier), `components/engine/PcCheckPanel.tsx`, 엔진 화면 연결
6. 시험(엔진·웹) → tsc·build → 미니PC 엔진 0.1.5 실물(구성 바꾸기 포함) → 배포 v1.07(미배포 대기 `d906dc95b` 함께) → ego lite 화면 확인

## 검수
- 미니PC(Intel 내장 그래픽): 브라우저 검사 「설치 가능 — CPU 모드 예상」, 엔진 검사 「기본」만 선택 가능, 나머지 흐림.
- 마스터PC(RTX 5080 16GB): 주인님이 엔진 0.1.5로 실행 → 「XL 고품질」 추천, 최고 품질(20GB 이상)은 흐림 — 화면 캡처만 받으면 됨.

## 비용
- Vercel 빌드 1회(v1.07, 미배포 대기분 포함) — 배포 직전 승인.
- AI 호출·외부 서비스 없음. 회원 부담 없음(모델은 회원 PC에 무료로 받음).

## 모델 크기 근거
미니PC 실측(2026-11-03): 표준 음악 모델 4.5GB, 1.7B 언어 모델 3.5GB, 공통(VAE·임베딩) 1.4GB, 실행 환경 약 4.3GB. XL 음악 모델·4B·0.6B 언어 모델은 공식 모델 크기 기준 추정(약 10GB·8GB·1.3GB) — 마스터PC 실측 뒤 고친다.
