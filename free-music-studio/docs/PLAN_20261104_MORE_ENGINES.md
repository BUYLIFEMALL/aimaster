# 음악 엔진 더 넣기 플랜 (2026-11-04)

주인님 지시: 「공개된 건 써도 된다는 얘기야」「다 넣고 개인용과 상업용으로 나누면 되잖아」.
근거 조사: [`RESEARCH_20261104_MUSIC_MODELS.md`](RESEARCH_20261104_MUSIC_MODELS.md).

## 1. 원칙

- **가중치가 공개돼 회원 PC에서 돌릴 수 있는 모델은 모두 넣는다.** 가중치가 공개되지 않은 Seed-Music·JEN-1은 넣지 않는다.
- **이용 조건에 따라 「상업용」·「개인용(비상업)」 두 묶음으로 나눈다.** 조건이 분명하지 않은 모델은 안전하게 개인용으로 둔다. 나중에 원문으로 상업용이 확인되면 그때 옮긴다.
- 「조건부 상업용」(매출 기준이 있는 것)은 상업용 묶음에 넣되 조건 문구를 화면에 함께 보인다.
- 각 모델은 **넣기 직전에 공식 모델 카드·LICENSE 원문을 다시 확인**하고 판정을 표에 적는다(로드맵 「모델 이용 조건」 규칙).
- 모델은 회원이 그 엔진을 처음 고를 때만 받는다(설치 파일은 그대로 106MB). 받는 동안 진행 표시를 보인다(0.2.1 방식).
- 그래픽 메모리가 모자란 PC에는 그 모델을 「이 PC에서는 어려움」으로 보이고 고르지 못하게 한다.
- **노래(보컬) 모델은 한국어 가사를 불러야 넣는다(2026-11-04 주인님: 「기본적으로 한글이 되는 모델이어야지」「앞으로도 한글지원 안되는 모델은 선택지에서 제외해」).** 공식 지원 언어에 한국어가 없으면 후보에서 뺀다. 언어 목록이 없으면 넣기 전에 마스터PC에서 한국어 한 곡을 시험하고, 발음이 안 되면 선택지에서 뺀다(사이트 `korean: "no"`). 첫 사례: LeVo 2(v1 base-full, 공식 zh·en만) — 한글 대신 영어 단어만 반복. 연주곡 모델은 해당 없음.

## 3. 구조 (기존 코드 재사용)

- **엔진 공통 실행 틀 하나**를 만든다. 모델마다 목록 한 줄(원본 저장소와 고정 판, 가중치 저장소와 고정 판, 확인값, 파이썬 판, 필요한 그래픽 메모리, 분류, 종류, 최대 길이)과 짧은 실행 스크립트(입력 JSON → WAV)만 추가한다.
  - 실행 환경은 모델마다 데이터 폴더 아래에 따로 만들고 uv로 받는다(ACE-Step 방식).
  - 받기·확인은 `downloadVerified`, 진행 표시는 `watchGrowth`·`progressText`를 그대로 쓴다.
- **그래픽 메모리는 한 번에 모델 하나만 쓴다.** YuE2 때 만든 「ACE-Step 잠시 멈춤 → 끝나면 다시 켜기」(`yue2Pausing`·`resumeAce`)를 모든 엔진 공통으로 넓힌다.
- 대기열 작업의 `engine` 값에 새 모델 이름을 더하고, `license`는 지금처럼 `commercial`/`noncommercial` 두 값을 쓴다. 조건부 상업용은 `commercial`로 저장하고 조건 문구는 엔진 목록에서 보인다(DB 변경 없음).
- 웹
  - 「곡 만들기」 엔진 고르기를 **「상업용」·「개인용」 두 묶음**으로 나눈다. 엔진마다 「보컬/연주곡」, 이 PC에서 되는지, 처음 받을 크기를 보인다.
  - 개인용 엔진은 YuE2처럼 처음 한 번 비상업 동의를 받는다(동의 저장은 엔진별).
  - 「PC 검사」 화면의 엔진 목록도 같은 두 묶음으로 바꾼다.
  - 보관함·대기열의 「비상업용」 표시는 그대로 쓴다.
- 엔진 버전은 차수마다 올리고(0.4.0 → 0.5.0 → 0.6.0), 새 설치 파일을 낸다. 회원 PC의 엔진 실행 프로그램이 새 버전 알림을 띄운다(미배포 `9d0d6fae9`를 1차 배포 때 함께 내보냄).

마스터PC에서 안 되는 모델(그래픽 메모리 부족, RTX 50 호환 문제)은 목록에서 「이 PC에서는 어려움」으로 남기고 다음 모델로 넘어간다. 3차의 불안정한 모델은 시험 결과를 보고 드린 뒤 남길지 정한다.

**2차 진행 상태(2026-11-04, 주인님 「2차 진행해」):** 가~다 ✅ 코드 반영(미배포 — 마스터PC 1차 LeVo 2·Stable Audio 3 결과를 본 뒤 남은 빌드 1회로 함께 배포, 엔진 0.6.0)
- **MiniMax Music 3 → 넣음, 상업용(조건부).** LICENSE 원문(HF 판 `fbdf52f` = 최신 `1b525cc`, 그 사이는 설명 문서만 바뀜): 상업 서비스 화면에 「MiniMax-Music3」 표시, 연매출 2천만 달러 초과 시 별도 허가(주인님 「연매출 2000만 달러 넘어갈일 절대 없어」), 이용 정책 11항 공개할 때 AI 생성 표시. 원본 코드 없이 정식 diffusers **0.41.0**(10-06, MiniMax 들어 있음) + transformers **5.19.0**(같은 날) — 윈도우 판 맞춤 49개 성공. 모델은 diffusers용 구성만 받음(57GB → 약 28.5GB, `allow`). 그래픽 메모리 24GB 미만은 공식 낮은 메모리 방식(자동 CPU 오프로딩, 22GB 미만은 언어 모델 층마다) — 마스터PC 16GB는 느릴 수 있음. 결과 44.1kHz 스테레오. 구간 표시는 소문자 한 줄, 노래인데 설명에 목소리가 없으면 리드 보컬 문구를 덧붙임(문서 Tips). `minVramGb` 12.
- **DiffRhythm 2 → 3차로 미룸.** Apache 2.0, 한국어 발음 변환은 있으나 불러올 때 `espeak-ng`(윈도우 MSI)와 `pyopenjtalk`(윈도우 바이너리 없음, C++ 빌드 필요)가 꼭 필요 — 회원 PC 설치가 어려움. 우회(`espeakng-loader` 0.2.4 윈도우 휠 + `pyopenjtalk` 대체 모듈, 일본어 제외)는 가능, 보컬이 약하다고 논문 스스로 밝혀 MiniMax 결과 뒤 결정.
- **InspireMusic → 보류.** 공식 Hugging Face 저장소(FunAudioLLM)가 내려가고 남이 올린 복사본만 있음, GitHub은 `QwenAudio/FunMusic`로 옮겨 2025-05 이후 멈춤 — 믿을 수 있는 받을 곳이 없음. 연주곡은 Stable Audio 3가 있음.

**진행 상태(2026-11-04):** 1차 가~바 ✅ 배포 v1.12 `free-music-studio-jma2o97ob`, 엔진 0.4.0 — 마 단계(마스터PC 실물)만 남음.
- 원문 확인 결과: HeartMuLa 코드·가중치 Apache 2.0(LICENSE·모델 카드) → 상업용. Stable Audio 3 Medium `stable-audio-community`, 저장소 잠김(`gated: auto`, 약관 동의 즉시 허용) → 회원 본인 Hugging Face 토큰 필요, 상업용(조건부). LeVo 2 `levo-demo/LeVo` LICENSE 「academic, research and education purposes … refrain from using it for any commercial or production purposes」 → 개인용.
- 고정 판: heartlib `5858ca8`(10-08), stable-audio-3 `77e0398`(10-11, 최신 11-02는 2주 안 돼 제외), LeVo `653cbcf`(06-29). 판을 안 정한 패키지는 `--exclude-newer 2026-10-20`.
- 윈도우 판 맞춤(받지 않고 `uv pip compile`, 바이너리만): HeartMuLa·Stable Audio 3 성공(torch cu128). LeVo 2는 `flashy`·`argbind`가 원본 코드만 있어 회원 PC에서 빌드(순수 파이썬) — 확인은 남이 만든 빌드 코드를 실행해야 해 자동 권한 검사가 막아 마스터PC 실물로.
- 마스터PC에서 확인할 것: 세 모델 처음 받기(진행 표시), HeartMuLa 16GB에서 차례 올리기(`lazy_load`), Stable Audio 3 토큰·오프라인 실행(`refs/main` 적어 둠), LeVo 2 폴더 이름·`--low_mem`·torch 2.7.1 덮어쓰기, 만든 곡 소리·길이·걸린 시간.

## 6. 위험·주의

- 이 PC(미니PC)는 내장 그래픽뿐이라 모델 실물 시험은 마스터PC에서만 할 수 있다. 차수마다 주인님 확인이 필요하다.
- 비교 수치는 YuE2 쪽 논문이 낸 것이라 실제 청취 결과와 다를 수 있다.
- 조건이 불명확한 모델은 개인용으로만 쓰고, 회원 화면에 「개인 감상용, 판매·수익 활동 불가」를 분명히 보인다.
- 엔진을 고칠 때는 [`IMPROVEMENT_HANDOFF_20261104_ENGINE_ERRORS.md`](IMPROVEMENT_HANDOFF_20261104_ENGINE_ERRORS.md)를 먼저 읽는다.
