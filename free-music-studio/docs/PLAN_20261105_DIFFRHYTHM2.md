# DiffRhythm 2 넣기 플랜 (2026-11-05, [역할: music])

주인님 지시: 「1번부터 순차적으로 해」(Stable Audio 3 → HeartMuLa 재측정 → DiffRhythm 2). 규칙: 노래 엔진은 한국어를 불러야 선택지에 넣는다(`PLAN_20261104_MORE_ENGINES.md` §1).

## 1. 조사 결과
- 원본: `ASLP-lab/DiffRhythm2`(마지막 커밋 2025-11-09, 1년 가까이 지나 판 고정 가능), 가중치 Hugging Face `ASLP-lab/DiffRhythm2`, **Apache 2.0(상업용 가능)**.
- 한국어: 공식 안내에 지원 언어 목록 없음, 데모는 확인 전. 코드에 `g2p/g2p/korean.py`(여러 언어 공용 발음 변환기)가 있으나 **학습 데이터에 한국어가 있었다는 근거는 아님** — LeVo 2처럼 실물로 확인해야 한다.
- 윈도우: `espeak-ng`(MSI 설치)가 필요 — 회원 PC에 따로 설치시키지 않고 `espeakng-loader` 휠(라이브러리 포함)로 대신한다(2026-11-04 조사). 일본어용 `pyopenjtalk`는 윈도우 빌드가 없어 빼거나 대체 모듈.
- 그래픽 메모리·곡 길이·속도: 공식 안내에 숫자 없음 → 실물로 잰다(1판은 8GB에서 동작).

## 2. 순서
1. **한국어부터 확인(비용 없음)**: 공식 데모·이슈에서 한국어 곡 사례를 찾는다. 「한국어 안 됨」이 확실하면 여기서 멈추고 후보에서 뺀다.
2. 엔진 목록(`pyengines-catalog.json`)에 `diffrhythm2` 추가 — 원본 커밋 고정, 실행 단계(torch cu128 + requirements, espeak 대체), 모델 판 고정, `korean: "untested"`.
3. `run_diffrhythm2.py`(가사 형식 변환·스타일 설명·길이) + 엔진 시험.
4. 사이트 `MUSIC_ENGINES`에 추가(상업용, 「한국어 확인 전」 안내).
5. 엔진 설치 파일 + 사이트 배포(빌드 1회, 승인 필요) → 마스터PC에서 한국어 2분 곡 1곡 → 한국어가 되면 `"yes"`, 안 되면 `"no"`(선택지에서 빠짐).

## 3. 비용
- 개발·시험: 비용 없음(공개 모델, 회원 PC에서 실행).
- 배포: Vercel 빌드 1회(사전 승인).
- 회원: 없음(모델 무료, 처음 한 번 받기).

## 4. 위험
- 한국어 실패 가능성(LeVo 2 전례). 그래서 1단계에서 먼저 근거를 찾는다.
- 이 PC에는 그래픽카드가 없어 실행 시험은 마스터PC 몫. 오프라인 실행·골라 받기 조건을 미리 따져 MiniMax 같은 반복 배포를 줄인다(`docs/ERROR_LESSONS.md` 2026-11-04).
