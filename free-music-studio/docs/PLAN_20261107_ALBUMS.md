# 앨범 메뉴 플랜 (2026-11-07, [역할: music], 세션 claude-win-20261024-music)

## 주인님 지시·결정
- 「모든 음악보다 음악 앨범 메뉴를 좌측에 만들고 여기서 앨범을 만들거나 만들어놓은 앨범이미지를 곡을 생성할때 가져오거나 앨범이미지를 베이스로 곡을 만들수 있게」
- 「곡을 만들때 곡 앨범을 만들어야 하는 것도 아니고 앨범만 만들고 곡은 안만들수 있는 상황이니 별도의 기능 아냐?」 → **앨범 = 별도 기능(그림 보관함)**, 곡 묶음은 지금처럼 프로젝트
- 「곡을 만들때 어울리는 앨범을 선택하게 하거나 곡을 다 만들고 그 상태에서 곡제목,가사를 베이스로 이미지 앨범을 만들게 하거나 이미 만들어놓은 앨범이미지에서 선택해서 사용하게」
- 「진행해」 — 운영 DB 표 1개 추가 승인, 순서: 1단계(앨범 메뉴·곡과 연결) → 2단계(그림으로 곡 만들기)

## 구조
| 무엇 | 어디 | 비고 |
|---|---|---|
| 앨범 기록(이름·그림 설명·만든 날) | 운영 DB `free_music_albums`(회원별, 본인만 RLS) | 그림 파일은 넣지 않음 |
| 앨범 그림 파일 | 회원 PC 노래 저장 폴더 안 `Albums/<앨범 번호>.png` | 엔진 0.7.3 `/library/albums` — 서버에 그림을 올리지 않는 원칙 유지 |
| 곡 표지 | 곡 파일 옆 같은 이름 그림(엔진 0.6.8~0.6.9 기존 기능) | 앨범 그림을 고르면 그 그림을 곡 표지로 복사 |

## 1단계 (이번)
1. 좌측 메뉴 **「앨범」**(`/albums`, 곡 만들기 다음 칸): 이름 + 그림 설명(한글 가능) → 기존 앨범 그림 만들기(Gemini·GPT·Replicate·내 PC) → **[앨범에 저장]**. 아래에 만든 앨범 그림 모아 보기(받기·이름 바꾸기·지우기).
2. **곡 만들 때 앨범 고르기**: 곡 만들기 화면의 그림 칸을 「앨범 고르기」로 바꿈 — 고른 앨범 그림을 그 곡 제목 이름(`곡 제목.png`)으로 노래 폴더에 넣어 완성되면 표지가 됨(기존 저장 방식 그대로). 곡 기획이 만든 그림 설명은 [이 설명으로 새 앨범 만들기]로 앨범 화면에 넘김.
3. **곡을 다 만든 뒤**: 「모든 음악」 곡 메뉴(⋯)에
   - 「앨범 그림 만들기(곡 제목·가사로)」 → 앨범 화면을 그 곡 제목·가사로 채워 열고, 저장하면 그 곡 표지도 함께 바뀜
   - 「앨범에서 표지 고르기」 → 만들어 둔 앨범 그림 가운데 하나를 그 곡 표지로(엔진 `POST /library/<곡>/art`)
4. 30일 자동 정리(최상위 규칙)에 앨범 기록 포함, 관리자·시험 계정 제외. 그림 파일은 회원 PC라 정리 대상 아님.

## 2단계 (v1.36 구현, 2026-11-08)
- 「이 그림으로 곡 만들기」: 회원 AI 키(그림 읽기 모델) 1번으로 그림의 분위기·장르·주제를 읽어 곡 만들기 칸(스타일·분위기·가사 주제)을 채움 — 음악 엔진은 그림을 직접 읽지 못하므로 「그림 → 글 → 음악」.
- 구현: 앨범 카드 「이 그림으로 곡 만들기」·곡 만들기 「그림으로 곡 만들기」 → `/api/albums/read`(768px JPEG, 서버 저장 없음) → 제목·주제·장르·분위기·빠르기·목소리·스타일 채움 + 같은 그림을 그 곡 표지로. 비용: 회원 본인 키 1번(가성비 모델이면 1원 안팎).
