# 앨범 그림 만들기 플랜 (2026-11-05, [역할: music])

주인님 지시: 「앨범 그림 만들기 기능도 넣어줘」. **승인 전 — 코드 수정 없음.**

## 1. 지금 상태
- AI 작곡 기획(`/api/plan`)이 곡마다 영어 「앨범 그림 설명(art)」을 주지만 화면에만 보이고, [모두 곡으로 저장]·[불러오기] 때 **버려진다**(곡 표 `free_music_songs`에 칸 없음).
- 이 프로그램은 음원을 회원 PC(엔진 보관함)에 두고 서버엔 글만 저장한다(플랜 §3).

## 2. 만들 것
| 순서 | 내용 |
|---|---|
| 1 | 곡에 「앨범 그림 설명」 칸 저장 — 곡 표에 `art_prompt` 글 칸 추가(SQL 1회), 기획 저장·불러오기 때 함께 저장, 곡 편집 화면에서 고칠 수 있게 |
| 2 | 「🖼 앨범 그림 만들기」 버튼 — 회원 본인 **Gemini 키**로 정사각형 1장(나노바나나 2.1, 1K). 설명이 없으면 곡 제목·스타일로 이 프로그램 전용 틀을 채워 만든다(추가 AI 호출 없음). 글자·로고·실존 인물 금지, 인물은 한국인 기본(핵심 원칙 3) |
| 3 | 공용 기준 코드 사본 — `ai-image-studio/lib/providers/geminiImage.ts`·`nanoBananaModels.ts`를 `check-shared-modules.mjs --sync`로 가져옴(호출·모델·대기 시간만, 그림 설명은 이 프로그램 것) |
| 4 | 저장 — **음원과 같이 회원 PC에**: 엔진에 그림 받기 연결 문을 더해 노래 저장 폴더에 「곡 제목.png」로 저장, 「모든 음악」에 작은 표지 표시. 서버에는 그림을 남기지 않는다(30일 정리·저장 공간 비용 없음) |
| 5 | (선택) MP3 320k 받기에 표지를 넣기 — ffmpeg로 이미 변환 중이라 추가 가능 |

## 3. 비용
- 회원: 그림 1장당 Gemini 약 $0.034(1K, `docs/AI_MODEL_CATALOG.md` 11-03 기준) — 회원 본인 키.
- 운영: Vercel 빌드 1회 + 엔진 설치 파일 1회(0.6.7), 운영 DB SQL 1회(칸 추가). 시험: 주인님 계정 키로 그림 1~2장.

## 4. 결정할 것
- 저장 위치: **회원 PC(추천)** / 서버 저장소(어디서나 보이지만 30일 정리·용량 관리 필요).
- 그림 모델: Gemini 나노바나나만(추천, 공용 코드 있음) / OpenAI 그림도 함께.
