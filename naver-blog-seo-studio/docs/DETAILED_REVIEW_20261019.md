## 현재 기능과 보존할 장점

주제·키워드·전략과 정보형·후기형·초보자 안내형 같은 페르소나를 고르면 제목을 추천받고 소제목 4개의 완성형 초안을 만듭니다. 확인되지 않은 사실은 [확인 필요]로 남깁니다. / 이미 쓴 글은 바로 최적화하거나, 붙여 넣은 글·공개 블로그 주소를 분석해 핵심 주제·키워드·보완점을 뽑고 원문을 베끼지 않는 새 초안으로 다시 씁니다. / 대표 이미지 1장과 본문 핵심 문장 이미지 2~3장을 만들고 크롬 확장으로 네이버 편집기에 입력하며, 생성 기록은 30일간 검색·복제할 수 있습니다.

**보존할 장점:** 검색 전략·페르소나 기반 SEO 초안/재작성

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.

1. 최신 공통 지침·ACTIVE_WORK·이 프로그램 AGENTS/README·개선 원장을 읽고 다른 CLI 변경과 대조합니다.
2. 위 첫 항목부터 실제 남은 문제인지 확인하고, 이미 완료됐으면 완료 증거를 연결합니다. 수정 전 개발 플랜을 제시합니다.
3. 모의 응답·합성 파일 등 비용 없는 재현을 우선합니다. 운영 권한/DB/외부 발송이 필요한 검사는 기존 승인 범위를 확인합니다.
4. 기존 기능을 보존하며 한 프로그램씩 적용하고 실제 수정 후 빌드·검수·커밋·푸시·배포·운영 확인을 진행합니다. 문서 분석만 한 이번 작업에는 앱 배포가 없습니다.
5. 처리한 ID·실제 시험·미검수·새 인사이트·라이브 링크를 프로그램 원장과 공통 인수인계에 남깁니다.
