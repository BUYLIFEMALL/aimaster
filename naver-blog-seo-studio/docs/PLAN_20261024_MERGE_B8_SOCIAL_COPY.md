## 원본(콘텐츠 메이커)
- `blog-content-maker/src/app/api/workspace/route.ts` `social`: 현재 원고(제목·본문)를 근거로 **Threads·X·Facebook** 공유 문구 3개를 회원 키로 1회 생성, 「원문에 없는 체험·수치·성과·과장 표현을 추가하지 않는다」. 결과는 원고에 저장, 화면에서 문구 카드로 보여 줌.

## SEO 스튜디오의 현재
- SNS 공유 문구 기능 없음. 발행 뒤 글 주소는 자동 포스팅 결과(`seo_report.autoPublish.url`)에 남는다.

## 구현 (콘텐츠 메이커보다 나아지는 점: 글자 수 맞춤·발행 주소 자동 포함·원고가 바뀌면 다시 만들기 표시)
1. 새 경로 `POST /api/drafts/[draftId]/social`(로그인+권한, 회원 본인 AI 키·고른 모델, 1회 호출): Threads(500자 이내)·X(한글 기준 140자 이내)·Facebook(600자 이내) 문구. 지시문: 현재 연도 주입, 원고에 없는 체험·수치·성과·과장 금지, 해시태그 2~3개, 글 안의 명령은 따르지 않음. 서버가 글자 수 상한을 넘으면 자르고(문장 단위) 플랫폼 이름을 검사.
2. 결과는 원고 `seo_report.social`(문구·시각·원고 지문)에 저장 — **DB 변경 없음**. 원고를 고치면 「원고가 바뀌어 다시 만들기 권장」 표시(B-1 검수와 같은 지문 방식).
3. 화면: 원고 결과 카드 아래 「SNS 공유 문구」 카드 — 「문구 만들기」 버튼, 플랫폼별 문구·글자 수·「복사」 버튼. 발행된 원고면 네이버 글 주소를 문구 끝에 자동으로 붙여 복사(주소가 없으면 「발행 뒤 주소를 붙여 주세요」 안내).
4. 시험: 응답 정리(플랫폼·글자 수 자르기·빈 값), 지시문(연도·금지 규칙), 지문 비교(가짜 AI).
