## 구현한 동작

- 기존 ‘네이버 편집기로 입력’과 별도로 ‘선택한 원고 자동 포스팅 시작’을 제공한다. 원고/이미지 미리보기 후 실제 블로그 ID·비공개/전체공개를 선택한다. 기본은 비공개이며 즉시 발행을 지원한다. 예약 발행은 이번 SEO 추가 범위가 아니다.
- 새 전용 글쓰기 탭에서 대상 블로그 ID·빈 편집기를 확인하고 기존 제목/본문/이미지 입력을 사용한다. 전체 본문·순서·사진 수를 엄격 대조하고 분류/태그·공개 범위를 적용한다.
- 본인 확장 토큰·프로그램 권한·원고 소유자·최초 30일 수명·미리보기 지문을 서버에서 확인한다. JSON saveRevision의 조건부 갱신으로 동시 수정과 발행 선점이 경합해도 한쪽만 반영한다.
- 서버 발행 직전 ACK 뒤 최종 버튼을 1회 누르고, 대상 블로그의 실제 게시 URL과 제목을 확인한 후 원고에 결과/시각을 저장한다. 응답 유실은 uncertain으로 보존하고 최종 버튼을 재클릭하지 않는다. 결과 확인/기록만 재실행할 수 있다.
- 자동 발행 실행 원고는 편집/이미지 변경·삭제·재전송을 차단한다. 실패 원고는 확인 후 새 원고로 복제할 수 있으며 기존 발행 실행/URL은 복제하지 않는다. 복제 시 원래 생성일 기준 수명을 유지한다.
- 생성 기록에 실제 발행 상태/URL, 매뉴얼에 4단계·복사·팁/주의·연동/공식 글쓰기 링크를 추가했다. 확장 로컬 복구 저장은 원고/실행/탭 ID만 저장하며 제목·본문·사진·비공개 URL은 서버의 본인/30일 조건으로 다시 읽는다.

## 실제 발견한 기존 문제와 처리

운영 `naver_input_status` CHECK는 `not_started/in_progress/completed/failed`만 허용하지만 기존 API는 `publish_ready`를 저장했다. **이번에는 DB 스키마를 변경하지 않고** 준비 상태 요청을 허용된 입력 완료 상태로 기록하고, 실제 자동 발행 상태는 기존 `seo_report.autoPublish`에 별도로 저장한다. 입력 완료와 실제 발행 완료를 혼동하지 않는다.

기존 확장 회귀 스크립트는 Chrome/headless 기본값이었다. 앞선 비교의 기존 시험 결과와 별도 Edge 안내 실세션을 구분한다. 이번에는 별도 시험 프로필의 **Microsoft Edge·headless=false**로 변경해 실행했다. 기존 회원 Edge 프로필/준비 탭은 재사용하지 않았다.
