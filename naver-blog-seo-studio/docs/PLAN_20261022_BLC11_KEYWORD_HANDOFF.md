# BLC-11 키워드 도구 → SEO 스튜디오 같은 회원 작업 넘기기 (2026-10-22, Claude Code 윈도우)

주인님 승인: 2026-10-22 「진행해」. 대상: `blog-keyword` v1.06 → `naver-blog-seo-studio` v2.02.

## 문제
키워드 결과(실측 검색량·문서 수·데이터랩 지수, AI 추정 점수)를 글쓰기에 쓰려면 회원이 다시 입력해야 했고, 실측과 추정이 한 칸(`documentCount`)에 섞이기도 했습니다.

## 방식
- 주소에는 기록 번호만 싣습니다(`/dashboard#title&keyword-report=<번호>`). 내용·키워드는 주소에 넣지 않습니다.
- SEO 서버가 같은 공용 DB의 `blog_keyword_reports`를 회원 세션(RLS)과 `user_id`로 다시 읽습니다. 두 프로그램 이용 권한을 모두 확인하고, 만든 지 30일이 지난 기록은 410으로 거절합니다(키워드 쪽 30일 삭제 BC-05는 별도 결정 대기).
- 응답은 정해진 모양(`KeywordEvidence`): 실측(값·단위·출처), 값 없음(0과 구분), 실측 안내, AI 추정, 후보 키워드, AI 제안 제목, 생성일·만료일·남은 날. 새 종합 점수는 만들지 않습니다.
- SEO DB에는 저장하지 않습니다(DB 스키마 변경 없음).

## 하지 않은 것
- `blog-keyword` 30일 자동 삭제(BC-05) — 즐겨찾기 처리 결정 필요.
- 작업 묶음 ID(BLOG-WORK-BUNDLE-01).

## 검수
- 단위 시험 6(남의/없는 기록 404, 30일 경계 410, 0과 값 없음 구분, 추정 분리·섞인 문자열 제외, 실측 없는 종류, 해시·제목 칸 값).
- 웨일 실검수: IMPROVEMENTS v2.02 항목 참고.

## 비용
Vercel 빌드 2회(blog-keyword 1, SEO 1), 키워드 분석 1회(시험 계정 본인 Gemini 키, 약 0~5원).
