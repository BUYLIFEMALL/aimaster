# 웹 초안 추천 태그

**2026-10-21 v1.81 변경:** 입력 전용 흐름과 별도로 실제 자동 포스팅·발행 결과 URL 기록을 추가합니다. [최신 플랜/검수 범위](PLAN_20261021_AUTO_PUBLISH.md). 아래 버전별 수동 최종 버튼 설명은 입력 전용 조작의 이력입니다. 자동 포스팅은 새 전용 탭·본인 대상/공개 범위·원고 지문·발행 직전 서버 ACK를 확인한 뒤 실행하며, 결과 불확실 시 재클릭하지 않습니다.

확장 v1.0.36부터 웹 대시보드에서 불러온 초안의 핵심 키워드는 추천 태그 후보로 표시된다.

1. 확장에서 웹 초안을 불러온다.
2. `추천 태그를 발행 정보에 넣기`를 사용자가 직접 누른다.
3. 카테고리와 태그를 확인·수정한다.
4. 네이버 발행 설정창을 연 뒤 `카테고리·태그 입력`을 실행한다.
5. 최종 발행 버튼은 사용자가 직접 누른다.

자동 적용이 아니라 사용자가 버튼을 눌렀을 때만 발행 정보 입력칸을 채운다. 기존에 저장해둔 발행 태그는 초안 불러오기만으로 변경되지 않는다.
