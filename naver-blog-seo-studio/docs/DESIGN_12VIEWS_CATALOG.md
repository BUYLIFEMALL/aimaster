2. **크롬 확장 스마트에디터 ONE 자동 전송**: 회원이 웹에서 완성한 원고를 `sendDraftToExtension`을 통해 전송함에 적재.

   - ⚡ **즉시 포스팅**: 자동 입력 후 즉시 발행 및 최종 등록 게시글 URL 자동 수집·기록.
