## 1. 디자인 업그레이드 개요

기존의 단조롭고 무거운 틸(`--brand: #0f766e`) 중심 인터페이스에서 탈피하여, 장시간 글을 기획하고 퇴고하는 블로거에게 최적의 시각적 안정감과 몰입감을 제공하도록 **포커스 스튜디오 스타일(Focus Studio Style)**을 적용하였습니다. 또한, 텍스트 줄글로만 되어 있던 사용 매뉴얼을 **8단계 올인원 집필 파이프라인 인포그래픽, 네이버 API 연동 가이드, 골드키워드 판정 공식 치트시트, FAQ 아코디언**을 갖춘 전면 비주얼 가이드북(`/guide`)으로 전면 개편하였습니다.

## 3. 주요 화면별 디자인 구현 내역

### 3.1 좌측 사이드바 (`Sidebar.tsx`)
1. **레이아웃 표준 준수**:
   - 데스크톱 너비 244px 고정 (`SIDEBAR_LAYOUT_STANDARD.md`).
   - 1~8단계 넘버링 배지(`step-number`)에 활성 시 인디고 그라데이션 및 명확한 3px 좌측 활성 인디고 바 적용.
2. **유틸리티 메뉴 & 계정 영역 밀착 배치**:
   - `KeyRound` 아이콘(앰버 `#d97706`), `BookOpen` 아이콘(인디고 `#4f46e5`)으로 시각적 차별화.
   - 명칭을 `📖 연동 & 사용 매뉴얼`로 표준화.
   - 로그인 계정(`buylifemall@naver.com`) 및 로그아웃 버튼을 유틸리티 메뉴 바로 아래(12px 간격)로 바짝 밀착 배치 (`margin-top: auto` 제거).
3. **모바일 반응형 드로어**:
   - 375~390px 화면에서 상단 고정 헤더(`AI 블로그 작업실 자동화 v1.05 ☰`) 제공.
   - 단일 스크롤 컨테이너 최적화로 모바일에서 하단 메뉴와 계정 정보가 잘림 없이 매끄럽게 스크롤.

### 3.2 사용 매뉴얼 (`/guide`) 비주얼 가이드북
1. **포커스 스튜디오 그라데이션 히어로 (`.guide-hero`)**:
   - 딥 인디고 그라데이션(`linear-gradient(135deg, #4f46e5 0%, #3730a3 50%, #1e1b4b 100%)`)으로 전문가용 작업실 분위기 연출.
   - 반투명 블러 알약 뱃지 2종: `✨ 포커스 스튜디오 스타일`, `네이버 서치어드바이저 최적화`.
2. **8단계 올인원 블로그 집필 파이프라인 인포그래픽 (`.guide-pipeline-track`)**:
   - 1. 내 스타일 분석 ➔ 2. 키워드 탐색 ➔ 3. 트렌드 관측 ➔ 4. 블로그 벤치마킹 ➔ 5. 글 작성 준비 ➔ 6. 구간별 작성 ➔ 7. 6영역 최종검수 ➔ 8. AI 이미지 제작으로 이어지는 시각적 흐름도.
3. **시작 전 필수: 네이버 & AI API 연동 가이드 카드**:
   - AI 엔진(OpenAI/Gemini), 네이버 Developers(검색 API 무료 일 25,000회), 네이버 검색광고(Searchad API 무료) 3종 카드 및 원클릭 연동 이동 버튼 배치.
4. **8대 단계별 심층 비주얼 가이드 카드 (`.guide-grid`)**:
   - 각 단계마다 대표 아이콘 아바타와 `1~8` 원형 넘버링 배지, 분류 태그, 볼드 키워드 불릿 포인트, 실전 꿀팁 박스(`💡`) 배치.
5. **골드키워드 판정 공식 및 4등급 치트시트**:
   - `골드 (<10, 월 1천↑)`, `실버 (<30)`, `일반 (<150)`, `경쟁 (150↑)` 등급 기준표 시각화.
6. **자주 묻는 질문 (FAQ) 아코디언**:
   - 네이버 API 무료 여부, 저품질 방지 원리, 자동 포스팅 지양 사유 등 4종 아코디언 제공.
