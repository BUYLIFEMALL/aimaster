## 1. 개요 및 배경

### 1.1 프로그램 분석 요약
- **프로그램 성격**: 회원 본인의 AI 키(OpenAI/Gemini) 및 네이버 키(검색 API + 검색광고 API)를 연동하여 블로그 스타일 분석부터 골드키워드 발굴, 트렌드 관측, 경쟁사 벤치마킹, AI 글쓰기 및 6영역 심층 검수, 이미지 제작까지 원스톱으로 지원하는 전문가용 AI 블로그 글쓰기 작업실.
- **핵심 파이프라인 (8단계 작업 흐름)**:
  1. `/style` — **내 블로그 스타일**: 본인 블로그 RSS/글 수집 ➔ 문체/톤 분석 ➔ 승인
  2. `/keywords` — **키워드 탐색**: 골드키워드(문서수÷검색량 < 10) 발굴 ➔ 보관함
  3. `/trends` — **트렌드 관측**: 최신 뉴스/웹자료 ➔ 신규 키워드 ➔ 14일 데이터랩 급상승 추이 검증
  4. `/benchmark` — **블로그 벤치마킹**: 동일 주제 상위 블로그 50건 분석
  5. `/research` — **글 작성 준비**: 상위 글 5개 + 뉴스 5개 ➔ 사실/출처 근거 구절 사전 지식화 ➔ 승인
  6. `/write` — **글 작성**: 승인 자료 기반 소제목별 구간 분할 작성 (중지/이어쓰기)
  7. `/review` — **최종 검수**: 내 블로그 스타일, 검색 로직, 사실·출처, 경험 표현 등 6영역 검수 ➔ TXT 내보내기/복사
  8. `/images` — **이미지 제작**: 대표 1장 + 본문 5~10장 노드 기획 ➔ Gemini 이미지 생성
  - `/settings` — **API키등록·플랫폼연동**: 7종 키 상태 및 글작업/이미지 모델 설정
  - `/guide` — **사용 매뉴얼**: 작업 흐름 및 연동 안내

### 1.2 리뉴얼 배경 및 필요성
1. **단조롭고 투박한 틸(Teal) 색상 체계 탈피**:
   - 기존의 평면적인 초록/틸 톤(`--brand: #0f766e`)에서 벗어나, 고품격 글쓰기 에디터에 최적화된 **포커스 스튜디오 템플릿(소프트 화이트/크림 배경 + 딥 인디고 & 바이올렛 포인트 + 세련된 에디토리얼 타이포그래피)**으로 격상 필요.
2. **가이드북(`/guide`) 전면 비주얼 시각화 의무 준수**:
   - 현재 가이드 페이지는 12~14px 단순 줄글 카드 9개뿐으로, 시각적 다이어그램, 뱃지, 연동 가이드, FAQ가 전무함.
   - 초보자도 한눈에 따라할 수 있는 8단계 시각적 파이프라인 다이어그램, 네이버 API 발급 가이드 카드, 단계별 핵심 팁, FAQ 아코디언 전면 구축 필수.
3. **사이드바 레이아웃 표준 준수**:
   - 폭 244px 고정, 1~8단계 작업 흐름 넘버링 인디고 하이라이트, 계정 정보 8~16px 밀착 배치, 모바일(375~390px) 햄버거 메뉴 반응형 보장.

## 2. 작업 범위 및 세부 계획

### 2.1 디자인 시스템 및 토큰 리뉴얼 (`globals.css`)
- **포커스 스튜디오 에디토리얼 인디고 토큰 정의**:
  - `--bg`: `#fafbfc` (편안한 소프트 화이트 캔버스)
  - `--surface`: `#ffffff` (순백색 클린 카드)
  - `--surface-soft`: `#f8fafc` (부드러운 슬레이트 표면)
  - `--brand`: `#4f46e5` (딥 인디고)
  - `--brand-dark`: `#3730a3` (인디고 다크)
  - `--brand-soft`: `#eef2ff` (인디고 틴트 배경)
  - `--brand-line`: `#c7d2fe` (인디고 소프트 보더)
  - `--accent-purple`: `#8b5cf6` (바이올렛)
  - `--naver-green`: `#03c75a` (네이버 연동 상징 컬러)
  - `--amber-gold`: `#d97706` (골드키워드 상징 컬러)
  - `--line`: `#e2e8f0` (섬세한 구분선)
- **카드 및 컴포넌트 고도화**:
  - 부드러운 엘리베이션 섀도우 (`0 1px 3px 0 rgb(0 0 0 / 0.05)`)
  - 라운드 코너(12px~14px) 및 명확한 포커스 링

### 2.2 사이드바 (`Sidebar.tsx`) 디자인 개편
- 1~8단계 작업 흐름 번호 원형 배지(`step-number`)에 활성 시 인디고 그라데이션 및 명확한 활성 바 제공.
- 유틸리티 메뉴(`API키등록·플랫폼연동`, `사용 매뉴얼`)의 아이콘을 브랜드 컬러와 조화롭게 배치.
- 하단 로그인 계정 정보 및 로그아웃 버튼을 유틸리티 메뉴 바로 아래에 12px 간격으로 바짝 밀착 배치 (`margin-top: auto` 제거).
- 모바일 햄버거 메뉴 열림/닫힘 애니메이션 및 슬라이드 드로어 개선.

### 2.3 사용 매뉴얼 (`/guide`) 비주얼 가이드북 전면 개편
1. **대형 8단계 올인원 파이프라인 인포그래픽 (`.guide-pipeline-banner`)**:
   - `스타일분석 ➔ 골드키워드 ➔ 트렌드관측 ➔ 벤치마킹 ➔ 사전지식 ➔ 구간작성 ➔ 6영역검수 ➔ AI이미지` 8단계 시각적 연결 흐름도.
2. **네이버 & AI API 연동 가이드 카드**:
   - 네이버 Developers(검색 API) 무료 일 25,000회 연동 가이드.
   - 네이버 검색광고(Searchad API) 연동 및 무료 쿼터 안내.
   - OpenAI / Gemini 키 선택 가이드.
3. **8대 단계별 심층 비주얼 가이드 카드**:
   - 각 단계별 고유 아이콘, 알약 뱃지, 핵심 요약 불릿 포인트, 실전 꿀팁 박스.
4. **골드키워드 공식 & 등급 판정 치트시트**:
   - `골드` (문서수÷검색량 < 10, 월 1,000↑), `실버`, `일반`, `경쟁` 시각적 배지 정리.
5. **트러블슈팅 FAQ 아코디언**:
   - 네이버 API 키 오류 시 해결법, AI 스타일 반영 원리, 검수 통과 기준 등.
