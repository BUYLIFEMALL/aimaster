## 2. 네이버 블로그 최우선 원칙 반영 내역 (v1.15)

1. **원문과 이미지의 완성**: AI 블로그(원문)과 대표/본문 이미지 생성을 웹 스튜디오 안에서 100% 완성·검토.
2. **크롬 확장 스마트에디터 ONE 자동 전송**: 회원이 웹에서 완성한 원고를 크롬 확장을 통해 네이버 스마트에디터 ONE에 직접 타이핑 방식으로 전송.
3. **회원 선택 3종 포스팅 모드 칩셋**:
   - 📝 **발행 전까지**: 네이버 스마트에디터 ONE에 글/서식/이미지 입력만 완료하고 회원이 최종 검토 후 발행.
   - ⚡ **즉시 포스팅**: 자동 입력 후 즉시 발행 및 최종 등록 게시글 URL 자동 수집·기록.
   - ⏰ **예약 포스팅**: 지정한 예약 일시에 맞춰 자동 예약 등록.
4. **3D 입체 엠보싱 버튼 규격화**:
   - `WriteView.tsx`: 글 구성 만들기 및 이어서 작성 `.btn-3d-blue`, `.btn-3d-green`
   - `ReviewView.tsx`: 검수하기 `.btn-3d-blue`, 최종본 저장 및 스마트에디터 전송 `.btn-3d-green`
