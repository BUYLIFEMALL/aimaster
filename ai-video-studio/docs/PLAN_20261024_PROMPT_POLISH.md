## 1. 문제
1. **설명 다듬기 기능이 없음**: 설정 화면의 Gemini 공급자 설명(`lib/providers/catalog.ts`)에는 이미 「프롬프트 다듬기에 씁니다」라고 적혀 있지만, 실제 기능은 없습니다. 지금은 회원이 쓴 한국어 한 줄 뒤에 화풍·카메라 영문 문구를 붙여 그대로 보냅니다(`composePrompt`). 짧은 한국어 설명은 영상 모델이 장면·동작·빛을 덜 구체적으로 만들어 결과가 밋밋해지기 쉽습니다.
2. **오래 걸릴 때 안내가 없음**: 진행 카드(`GenerationCard.tsx`)는 시간과 상관없이 「보통 1~5분」만 보여 줍니다. 업체가 붐비거나 크레딧이 모자라 오래 멈춰 있으면 회원이 원인을 알 수 없습니다.

## 2. 범위
### A. 영상 설명 AI 다듬기(Gemini, 회원 본인 키)
- **새 API** `app/api/prompt/polish/route.ts`(POST)
  - `checkProgramAccessApi()` + `dynamic`·`fetchCache` 두 줄(멀티테넌시 원칙 1).
  - 회원 본인 `gemini` 키만 사용합니다. 키가 없으면 「Gemini API 키가 없습니다…」 안내와 `needKey`를 돌려줍니다(운영자 키로 대신 처리하지 않음).
  - 모델은 `gemini-3.5-flash-lite`입니다(가볍고 싼 글 모델, 블로그 작업실·카드뉴스·문서 번역에서 운영 중). 시간 제한은 30초, **자동 재시도는 없습니다**.
  - 입력: 회원 설명, 고른 화풍·카메라 이름, 길이(초), 사진 유무. 출력: ① 영상 모델용 영어 설명 1개 ② 무엇을 보강했는지 알려 주는 한국어 한 줄.
  - 프롬프트는 이 프로그램 고유의 것입니다(공유하지 않음, `docs/IMAGE_PROMPT_RULES.md`). 내용: 주제·동작·배경·빛·카메라 흐름을 길이에 맞게 쓰고, 사람이 나오면 한국인으로, 화면 글자·자막·로고는 넣지 않습니다(핵심 원칙 3).
  - 사용 기록은 `logProgramUsage(user.id, "prompt_polish")`로 남깁니다.
- **순수 함수** `lib/promptPolish.ts`: 요청 본문 만들기와 응답 해석(JSON 파싱 실패, 빈 값, 길이 1200자 자르기)을 맡습니다. 화면·서버 양쪽에서 시험할 수 있게 분리합니다.
- **화면**(`CreateStudio.tsx` 1단계)
  - 설명 입력칸 아래에 「✨ AI로 설명 다듬기」 버튼을 둡니다. 누르면 결과 상자가 열립니다. 영어 설명은 고칠 수 있고, 한국어 한 줄로 무엇을 보강했는지 보여 줍니다.
  - 「다듬은 설명으로 만들기」를 켜면, AI에 보낼 설명이 다듬은 영어 설명과 기존 안전 문구로 바뀝니다. 끄면 지금 방식 그대로입니다.
  - 설명·화풍·카메라를 바꾸면 「설명이 바뀌었습니다 — 다시 다듬기」 표시를 띄웁니다. 결과를 저절로 지우지는 않습니다.
  - Gemini 키가 없으면 지금처럼 설정 화면으로 가는 링크를 보여 줍니다. 글 다듬기는 무료 등급 Gemini 키로도 됩니다(영상과 다름)는 점을 안내 문구에 적습니다.

### B. 4분 넘으면 업체 사용량 확인 안내(화면만, 비용 없음)
- `GenerationCard.tsx`: 만드는 중이고 4분(240초)을 넘기면, 「보통 1~5분」 문구를 주황색 안내로 바꿉니다. 문구는 「4분이 넘었습니다. 업체가 붐비거나 크레딧이 모자라면 오래 걸릴 수 있습니다. 화면을 닫아도 계속 만들어지며, ○○ 콘솔에서 사용량과 작업 상태를 확인해 보세요」이고, 공급자별 콘솔 링크를 답니다.
- 콘솔 링크는 `catalog.ts` `PROVIDERS`에 `usageLink` 칸으로 추가합니다(gemini·fal·replicate). 주소는 구현할 때 실제로 열어 보고 정합니다.
- 기준 시간 판단은 순수 함수(`isSlow(createdAt, now)`)로 만들어 시험합니다.

### 범위 밖
- 공용 기준 코드(`lib/video/*`)는 고치지 않습니다. 사본을 쓰는 다른 프로그램에는 영향이 없습니다.
- DB 표 변경은 없습니다.
- 뮤직비디오는 다른 세션이 작업 중이라 건드리지 않습니다.
