## 참고한 기존 구현 — AI 이미지 스튜디오 `/prompts`
- 「기본 프롬프트」: DB 표 `style_preset_prompts`(관리자만 고침, 모든 회원이 봄) · 「내 프롬프트」: DB 표 `ais_user_style_prompts`(회원별 RLS, 30일 자동 삭제).
- 영상 스튜디오에 같은 구조를 만들려면 **새 DB 표 2개**가 필요 → DB 구조 변경이라 승인 사항.

## 안 B (추천) — 기본 프롬프트 게시판, DB 변경 없음
- 새 메뉴 「📝 영상 프롬프트 게시판」(`/prompts`): 이 프로그램 고유의 영상 장면 예시 24개를 6개 분류(풍경·자연 / 도시·야경 / 음식·카페 / 제품 광고 / 사람·일상(한국인) / 동물·판타지)로 보여 줌. 각 항목 = 한국어 장면 설명 + 추천 화풍·카메라 + 「글만 가능/사진 추천」 표시.
- 「이 설명으로 만들기」 → `/create?preset=<id>`가 설명·화풍·카메라를 채움(v1.11 「다시 만들기」와 같은 흐름). 이어서 「AI로 설명 다듬기」로 영어 설명을 다듬을 수 있음.
- 검색·분류 거르기, 휴대폰 1열.
- 목록은 코드 파일(`lib/promptBoard.ts`)에 두고 시험으로 형식(분류·화풍·카메라 ID가 실제로 있는지)을 확인. 관리자 편집 화면은 없음(고칠 때는 코드 수정).
- 「내 프롬프트 저장」은 이번에 만들지 않음 — 지금은 갤러리 「이 설정으로 다시 만들기」가 그 역할을 대신함.
- 사람 장면은 한국인으로(핵심 원칙 3), 연도 표기 없음, 브랜드·실존 인물 없음(`docs/IMAGE_PROMPT_RULES.md`).

## 안 A — 이미지 스튜디오와 같은 구조(DB 표 2개 추가)
