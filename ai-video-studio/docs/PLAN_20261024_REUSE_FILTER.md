## 0. 조사 결과 (제안을 조정한 이유)
- **생성 기록**: `avs_generations.prompt`에는 화풍·카메라·안전 문구까지 합친 **최종 설명만** 저장됩니다. 회원이 처음 쓴 한국어 설명과 다듬었는지 여부는 남지 않습니다. 그래서 「다시 쓰기」를 하려면 저장을 먼저 보강해야 합니다. `options`(jsonb) 칸에 넣으면 **DB 표 변경이 없습니다.**
- **모델 카드 결과 예시**: 지금 보여 줄 예시 영상이 없습니다. 예시를 만들려면 모델마다 실제로 생성해야 해서 **비용이 듭니다**(9개 모델 × 5초, 약 $3~5). 글로 된 예시는 근거 없이 쓰면 틀릴 수 있습니다. → **이번 묶음에서 빼고**, 따로 비용 승인을 받는 작업(묶음 B)으로 나눕니다.
- **원스톱 쇼츠·Shots 연계**: 두 프로그램의 AI 장면은 회원이 설명을 적지 않습니다. 장면 이미지 설명에서 움직임 설명을 **자동으로** 만듭니다(`shots/src/app/api/video/scene/route.ts` `motionPrompt`, `shorts-onestop-studio/src/lib/videoGen.ts`). 다듬기 버튼을 넣을 자리가 없고, 장면마다 Gemini 호출을 하나 더 하는 만큼 효과가 불확실합니다. → **이번에는 하지 않고** 공통 아이디어 표에 「검토 대기」로 등록만 합니다(묶음 C).

## 1. 묶음 A — v1.11 (이번 배포 1회)
### A1. 생성 기록에 다시 쓸 정보 남기기 (DB 변경 없음)
- `POST /api/generations`가 `options`에 `idea`(처음 쓴 한국어 설명)·`styleId`·`cameraId`·`polished`(다듬은 설명을 썼는지)·`polishedPrompt`(안전 문구 붙이기 전 다듬은 설명)를 함께 저장합니다. 각각 길이를 제한하고, 형식이 틀리면 버립니다.
- 화면 응답(`ClientGeneration`)에 `reuse` 묶음으로 내보냅니다. 서버 전용 값은 내보내지 않습니다.

### A2. 갤러리 「이 설정으로 다시 만들기」
- 완성·실패 카드에 버튼을 두고, 누르면 `/create?from=<id>`로 갑니다.
- 생성 화면은 그 기록을 불러와 설명·화풍·카메라·다듬은 설명·모델·길이·비율·해상도·소리를 채웁니다. 끝나면 「이전 설정을 불러왔습니다. 사진은 다시 넣어 주세요」라고 안내합니다. 시작·끝 사진은 비공개 저장소에 있고 30일 뒤 지워지므로 다시 넣게 합니다.
- **옛 기록**(v1.10 이전, `idea` 없음): 최종 설명 전체를 다듬은 설명 칸에 넣어 그대로 다시 쓸 수 있게 합니다.
- 자기 기록만 불러옵니다. 지금 있는 `GET ?ids=`가 이미 `user_id`로 거릅니다.

### A3. 다듬기 3안 중 고르기 (호출 횟수 그대로)
- 다듬기 1번에 서로 다른 3안(차분함·역동적·분위기 중심 등)을 받습니다. 호출은 1회 그대로이고, 출력 글자가 늘어 1회 1~2원 수준입니다.
- 화면에 「안 1·2·3」 버튼을 두고, 고른 안이 편집 칸에 들어갑니다. 3안을 받지 못하면 1안만 보여 줍니다(예전 형식도 받음).

### A4. 갤러리 모델별 거르기
- 지금 있는 상태 거르기(전체·완성·만드는 중·실패) 옆에, 갤러리에 실제로 있는 모델만 「모델명 개수」 버튼으로 보여 줍니다. 두 거르기는 함께 적용됩니다. 화면만 바꾸고 서버는 바꾸지 않습니다.

### 시험·검수
- 순수 함수: 저장 옵션 정리(`sanitizeReuse`), 기록 → 화면 값(`reuseFromGeneration`, 옛 기록 포함), 3안 응답 해석. `npm test`·`tsc`·`build`.
- 운영 크롬(시험 계정): 다듬기 3안 고르기 1회, 옛 기록으로 「다시 만들기」 채움 확인(비용 없음), 모델 거르기. 새 기록에 `idea` 저장을 확인하려면 가장 싼 영상 1개(Replicate Seedance 1 Lite 5초, 약 $0.18)를 만들어야 합니다. **선택**이며, 안 하면 시험과 코드로만 확인합니다.
