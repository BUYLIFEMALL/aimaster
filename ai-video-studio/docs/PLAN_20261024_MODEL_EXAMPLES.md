# AI 영상 스튜디오 v1.13 플랜 — 모델 카드 예시 영상

> 대상: ① AIMaster 운영 `ai-video-studio`(DB `esgxyikcnnvmlhygjkth`) · 현재 v1.12

## 목적
생성 화면 2단계 모델 카드에 같은 장면의 4초 미리보기를 붙여, 회원이 돈을 쓰기 전에 모델별 화질·움직임·색감 차이를 보고 고르게 한다.

## 방법
1. 장면: 사람 없는 「한옥 마당에 내리는 첫눈」 + 화풍 「시네마틱 실사」 + 카메라 「천천히 다가가기」(다듬기 없이 같은 문장).
2. Gemini Omni Flash 글만 5초 16:9를 먼저 만들고, 첫 장면을 `ffmpeg`로 뽑아 나머지 9개 모델의 시작 사진으로 쓴다(사진 필수 모델 5개 포함, 비교 조건 통일).
3. 시험 계정 `buylifemall@naver.com` 본인 키로 운영 화면에서 1개씩 생성(가장 짧은 길이·가장 낮은 해상도, 소리 끔). 다시 시도하지 않는다 — 실패한 모델은 예시 없이 두고 보고.
4. 결과 MP4 → 가로 480px·최대 4초·소리 없음 H.264 + 첫 화면 JPG → `public/examples/<모델 키>.mp4|jpg`.
5. 모델 카드: 첫 화면 이미지만 먼저 보이고, 마우스 올림·누름 때 영상을 불러와 소리 없이 반복 재생(`preload="none"`). 「같은 장면 예시 — 실제 결과는 설명에 따라 다릅니다」.
6. 예시 파일은 프로그램 안내용 자산(회원 데이터 아님, 30일 삭제 대상 아님). 시험 계정 갤러리 원본은 기존대로 30일 뒤 삭제.
