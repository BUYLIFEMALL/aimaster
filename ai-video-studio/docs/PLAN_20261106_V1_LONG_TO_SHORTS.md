## 1. 사전 검증(저장소 밖, 운영 코드 수정 없음)
### 1-1. 시험 재료
- 영상: 윈도우 기본 한국어 음성(Microsoft Heami, 무료)으로 직접 쓴 상품 리뷰 원고(444자)를 읽힌 **2분 6초** 영상. 원고에 2~3초 쉬는 곳 11곳, 준비 멘트(「잠깐만요, 조명이…」) 1곳을 일부러 넣음. 남의 영상은 쓰지 않음.
- 호출: **시험 계정(`buylifemall@naver.com`) 본인 키**로 받아쓰기 1회(OpenAI `whisper-1`, `verbose_json` + 낱말·문장 시각) + 구간 고르기 1회(Anthropic `claude-haiku-4-5`).

### 1-2. 결과
| 확인 항목 | 결과 | V1에 주는 뜻 |
|---|---|---|
| 받아쓰기 속도 | 2분 6초 영상 → 9.4초 | 10분 영상도 1분 안팎 예상 |
| 글자 정확도 | **98.4%**(틀린 곳: 「꺼내」→「권해」 1곳) | 회원이 문장을 고칠 수 있게 두면 충분 |
| 끝부분 없는 말 | 마지막에 원고에 없는 「고맙습니다」(0.1초짜리 문장)가 붙음 | 길이 0.5초 미만·무음 안의 마지막 문장은 버린다 |
| 문장 경계 | 15문장, 경계가 무음 구간과 맞음 | 자르는 단위 = 문장 |
| 낱말 시각 | 무음 가장자리에서 **최대 0.7초 어긋남**(158낱말 중 6개가 무음과 0.3초 넘게 겹침) | 자르는 위치는 브라우저가 잰 무음에 맞추고, 자막은 기본 **문장 단위**(낱말 단위는 선택) |
| 무음 측정 | ffmpeg `silencedetect`(-35dB·1.2초)로 11곳 모두 원고와 일치 | 브라우저 Web Audio로 같은 방식 측정 → 무음 줄이기 |
| 구간 고르기 | 3.7초, 장점(85점)·소음(78점)·단점(72점) 3구간, **준비 멘트는 제외** | 쓸 만함. 단 3번째가 14.0초로 15초 규칙을 어김 → 코드가 이웃 문장을 붙여 15~45초로 맞춘다 |
| 비용(실제) | 받아쓰기 2.1분 ≈ $0.013, 구간 고르기 입력 1,172·출력 323토큰 ≈ $0.003 → **약 22원** | 회원 비용 10분 영상 기준 약 100원 |

## 2. 구현 플랜(`ai-video-studio`, 새 메뉴 「✂️ 긴 영상 → 쇼츠」)
| 단계 | 내용 | 비고 |
|---|---|---|
| 1 | 회원 파일 넣기(본인이 찍었거나 권리가 있는 영상 체크), **최대 10분** | 남의 영상 주소 받기 없음 |
| 2 | 브라우저에서 소리만 뽑기(16kHz 모노) + 무음 측정 | 공용 `browser-video-extract` 사본 재사용 |
| 3 | 소리를 회원 폴더에 일회용 업로드 → 서버가 회원 본인 OpenAI 키로 받아쓰기 → 소리 파일 바로 삭제 | Vercel 요청 본문 4.5MB 제한 때문에 직접 보내지 않음(shorts-onestop BGM 업로드 방식) |
| 4 | 문장 정리: 끝부분 없는 말 제거, 문장 경계를 무음에 맞춤 | 사전 검증 결과 반영 |
| 5 | AI 구간 고르기(회원이 고른 AI, 기본 Claude) → 문장 번호로 답 → 코드가 15~45초로 보정, 점수·이유 표시 | 재시도 0(이중 과금 방지) |
| 6 | 회원이 구간 고치기(시작·끝 문장), 무음 줄이기 켜고 끄기(1.2초 넘는 무음 → 0.3초) | |
| 7 | 세로 9:16 MP4(가운데 맞춤 자르기) + 문장 자막, 브라우저 렌더 | 기존 영상 합치기 엔진 재사용 |
| 8 | MP4·SRT 내려받기 | 서버에 영상 저장 안 함 |

- **이번에 안 하는 것**: 화자를 따라가는 세로 재구성(다음 단계), 낱말 단위 자막 기본값(0.7초 오차), 남의 영상 다운로드.
- **결정(기본값으로 진행)**: 최대 10분 · 자막 문장 단위 · 화자 추적은 다음 단계.
- **비용**: 개발 중 시험은 시험 계정 본인 키로 1~2회(수십 원). 배포 빌드 1회는 승인 뒤. 운영자 비용 없음(소리 파일은 받아쓰기 직후 삭제).
- **처음 설정·매일 조작**: 처음 설정 1단계(OpenAI 키, 이미 공용 저장소에 있으면 0) · 매일 조작 3번(파일 넣기·구간 확인·만들기) · 동의 1번(권리 체크).
