## 4. 개선 플랜 (단계별, 승인 필요)
**1단계 — 진단·안내 (v1.21에 묶음, 빌드 추가 0회)**
- ① 진행 막대에 **남은 예상 시간** 표시(라이브러리 `renderEstimatedTime` 사용). 20초 뒤 예상이 3분을 넘으면 「이 PC에서는 약 N분 걸립니다」 안내.
- ② **진단 기록**: 렌더 끝(또는 멈춤)에 `renderedFrames`·`encodedFrames`·걸린 시간·하드웨어 설정을 콘솔에 한 줄로 남김 → 장면 그리기와 인코딩 중 어디서 막히는지 구분.
- ③ **하드웨어 가속 바꿔 보기**: 주소 끝 `?render=software`면 `hardwareAcceleration: "prefer-software"`로 렌더(회원 화면은 그대로, 시험용).
- 맥미니 요청 절차: 같은 영상으로 기본값·`?render=software` 두 번 재기 → 결과 기록.
**2단계 — 원인 확정 뒤 (별도 승인)**
- 인코딩이 원인이면: 맥에서 자동으로 소프트웨어 인코딩, 또는 「⚡ 내 PC 렌더러로 만들기」 권장 버튼(이미 있는 `compress`로는 자막·음악 합성이 안 되어 새 명령 필요 — 큰 작업).
- 글꼴: 자막 글자만 받기(첫 화면 121건 → 몇 건)는 첫 화면 속도 개선으로 따로 다룸(작은 작업).
