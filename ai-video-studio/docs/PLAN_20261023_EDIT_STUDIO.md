# AI 영상 스튜디오 2차 — 편집·합치기 스튜디오 개발 플랜 (2026-10-23, Claude Code 윈도우)

> 상태: **플랜(주인님 승인 대기)**. 대상: ① AIMaster 운영(`ai-video-studio`, DB `esgxyikcnnvmlhygjkth`). 근거: 루트 `docs/PLAN_20261023_FREE_VIDEO_RENDERING.md` 10절(A-0 결과)·11절(R1 원인), 1차 플랜 `PLAN_20261023_AI_VIDEO_STUDIO.md` 「2차」.

## 1. 무엇을 만드나 (문제와 목표)
- **문제**: 1차에서 만드는 영상은 4~10초짜리 클립 한 개다. 쇼츠·릴스·뮤직비디오로 쓰려면 클립 여러 개를 이어 붙이고 음악·자막을 얹어야 하는데, 지금은 회원이 MP4를 내려받아 캡컷 등 다른 편집기로 옮겨야 한다.
- **목표**: 「🎞️ 영상 합치기」 작업실에서 갤러리 클립 + 내 PC 영상 + 음악 + 자막(+2-나: 내레이션·자동 자막)을 한 편으로 묶어 **회원 PC 브라우저에서 MP4로 렌더**한다. 운영 서버 비용 0, 회원 비용 0(렌더는 무료, 음성 합성만 본인 키).

## 3. 기능 상세

### 2-가 (v1.04) — 핵심 합치기
1. **클립 고르기**: 내 갤러리 완성 영상(`avs_generations`, 본인 행만, 1시간 서명 주소) + 내 PC 영상 올리기(서버에 올리지 않고 브라우저 안에서만 사용). 최대 20개, 총 3분.
2. **타임라인**: 순서 바꾸기(끌기·위아래 버튼), 클립별 앞뒤 자르기, 장면 전환(없음 / 0.3초 페이드).
3. **배경음악**: 내 PC 음악 파일 또는 **AI 음악 스튜디오 내 곡**(쇼츠 원스톱·뮤직비디오에서 검증된 `ams_generations` 읽기 방식 재사용, 서명 주소만 받고 복사하지 않음). 음량, 끝 1초 페이드아웃, 영상 길이에 맞춰 자르기.
4. **자막**: 클립마다 한 줄 직접 입력, 위치(위·가운데·아래), 스타일 4종(원스톱 `CAPTION_STYLES`와 같은 이름). 한글은 SVG `<text>` + `@remotion/google-fonts` Noto Sans KR 굵기 1개만 미리 불러오기(A-0에서 확인한 방식).
5. **미리보기·렌더**: Remotion Player 미리보기 → `renderMediaOnWeb` MP4(9:16·16:9·1:1, 720p/1080p). 진행률·남은 시간 표시, 완성 후 내 PC로 내려받기.
6. **R1 대책(필수)**: 영상을 넣을 때마다 첫 1초 시험 추출 → 멈추면 Mediabunny `Conversion`으로 소프트웨어 재인코딩(「형식 맞추는 중」 진행 표시) 뒤 사용. 렌더가 28초 시간 초과에 걸리면 원문 오류 대신 「영상 형식 변환 후 다시 시도」 안내.

### 2-나 (v1.05) — 소리·자막 자동화
7. **내레이션(회원 본인 키)**: OpenAI·Gemini·ElevenLabs 음성 — 쇼츠 원스톱 `tts.ts`·`voice.ts` 방식 재사용, 비공개 버킷 `{user}/voice/`.
8. **자동 자막**: 내레이션 단어 시간(원스톱 `wordStarts`, OpenAI 받아쓰기)으로 자막을 자동으로 나눠 표시.
9. **편집 저장·불러오기**: 새 표 `avs_edits`(편집 구성 JSON, RLS 본인만, 30일 자동 정리 cron에 포함).
10. **완성본 갤러리 저장**: 렌더 결과를 회원 버킷 `{user}/edits/{id}.mp4`에 올려 갤러리에 「편집본」으로 표시(30일).

## 4. 구조
- 화면: 사이드바에 「🎞️ 영상 합치기」(`/edit`) 추가, 갤러리 카드에 「합치기에 넣기」 버튼. Remotion 관련 코드는 `/edit` 화면에서만 동적 불러오기(`ssr: false`) → 다른 화면 무게 불변.
- 파일(예정): `lib/edit/timeline.ts`(길이·자르기·자막 시간 계산, 순수 함수 → 단위 시험), `components/edit/Composition.tsx`(Remotion 구성), `components/edit/EditStudio.tsx`(화면), `lib/edit/probe.ts`(R1 시험 추출·재인코딩), `app/api/edit/sources/route.ts`(갤러리·AI 음악 스튜디오 곡 서명 주소 목록, 읽기만).
- 권한: 모든 API에 `checkProgramAccessApi` + `dynamic`/`fetchCache` 두 줄. 회원 본인 행만(`user_id`).
- **인코딩 엔진은 Remotion에 묶지 않는다**(무료 렌더 플랜 8절): 타임라인 계산·R1 처리·소스 받기는 Remotion 밖 순수 코드로 두어, 나중에 라이선스가 바뀌어도 그리기 층만 공용 캔버스 엔진(`browser-mp4-encoder`)으로 바꿀 수 있게 한다.
- Remotion 무료 조건: 개인·3명 이하(주인님 확인). Player에 `acknowledgeRemotionLicense`. 브라우저 렌더 사용량 기록(도메인별 렌더 수)이 Remotion으로 전송된다는 점을 `AGENTS.md`에 기록. 회원이 Remotion 코드를 올리는 기능은 만들지 않는다.
