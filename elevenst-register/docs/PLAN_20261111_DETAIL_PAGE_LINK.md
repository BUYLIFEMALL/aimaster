# 개발 플랜 — 상세페이지 자동화 연계 강화 (2026-11-11, `claude-win-sdp`, 역할 ecommerce-image)

주인님 지시: 「상세페이지 자동화와 연계해서 더 편리한 기능으로 구현해줘」 — 결정 전, 코드 수정 없음.

## 1. 지금 상태 (v1.04)
- 상세페이지 상품에서 가져오는 것: 상품명, 판매가(`sale_price` → 없으면 `price`), 대표·상세 이미지(검사용 자리표시).
- 회원이 매번 직접 하는 것: 카테고리 찾기(상품명만으로 검색 — 합성어면 0건), 브랜드, 고시 유형·항목, 원산지.
- 상세페이지 쪽에는 11번가로 가는 버튼이 없음(`shop-detail-page/lib/markets.ts`에 스마트스토어·쿠팡만).

## 2. 상세페이지가 이미 가진 정보 (운영 DB `shop_products` 실측)
`category`(예: 「패션잡화 > 남성가방 > 백팩」) · `price`/`sale_price` · `specs`(「품명: … / 품번: … / 소재 / 색상 / 사이즈 / 중량」 줄글) · `key_features` · `how_to_use` · `target_customer` · 이미지(`source_image_url`·`reference_image_urls`·섹션 이미지).

## 3. 할 일 (추천 범위 A)
| # | 기능 | 회원이 얻는 것 | 위치 |
|---|---|---|---|
| A1 | **카테고리 자동 추천** — 상세페이지 카테고리 경로 + 상품명으로 찾고, 점수가 확실하면 첫 후보를 미리 골라 둠(바꿀 수 있음) | 카테고리 고르기 0~1번 클릭 | `category.ts`·`CategoryPicker` |
| A2 | **고시 자동 채움** — 카테고리로 고시 유형 자동 선택(가방·의류·주방용품…), `specs`의 품명·품번·소재·색상·크기·제조국을 해당 고시 항목에 넣음. 못 찾은 항목만 「상품상세설명 참조」 | 고시 입력 0번 | `notification.ts`·새 `specsMap.ts` |
| A3 | **브랜드·원산지·모델명 미리 채움** — `specs`의 「브랜드/제조국/원산지/품번」 줄 | 칸 3개 자동 | 같은 파일 |
| A4 | **정가 → 할인 표시** — 상세페이지 `price`(정가) > `sale_price`면 11번가 즉시할인으로 넣을지 선택(기본: 끔, 판매가만) | 상세페이지 가격 그대로 | `product.ts` |
| A5 | **상세페이지 「🟠 11번가에 등록하기」 버튼** — `markets.ts` 한 줄 + 결과 배지(「등록됨·전시중지」) | 상세페이지에서 한 번에 이동·결과 확인 | `shop-detail-page`(같은 역할) |
| A6 | **쇼핑몰 흐름 띠** — `?flow=shop`으로 들어오면 소싱→상세→마켓→주문→라벨 띠(공용 기준 코드 `shop-flow` 사본) | 다음 단계로 바로 이동 | 공용 사본 추가 |

결과: 「검토 완료」 → 상세페이지 버튼 → 11번가 화면에 거의 다 채워져 있음 → 배송 확인 → 검사. **처음 설정 2단계(키 → 연결 시험) · 매일 조작 약 3번(버튼 → 확인 → 검사/보내기) · 동의 0번.**

AI 호출 없음(규칙 기반 매칭). 정확도가 모자라면 다음 단계로 「회원 본인 Claude 키로 카테고리 추천」을 선택 기능으로 검토.

## 4. 순서·검수
1. A1~A4(11번가 등록기 안) → 시험 추가(실제 전체 카테고리·실제 `specs` 표본), `tsc`·build
2. A5·A6 → 상세페이지는 결과 배지 상태 매핑만(등록 기록 `elevenst_register_jobs` 읽기, RLS 본인 행)
3. ego 운영 검수: 검토 완료 상품 → 버튼 → 칸이 채워져 있는지 → 검사 통과

## 5. 배포·비용
- 빌드: 11번가 등록기 1회 + 상세페이지 1회 = **2회**(순차). 아니면 **4단계 보내기와 묶어 배포**(권장 — 빌드 절약, 버튼이 「보내기」까지 되는 상태로 회원에게 보임).
- 미배포 대기 2건(합성어 보조 검색·비공개 안내 화면)도 함께.
- DB 변경 없음. AI·외부 유료 호출 없음.
