# AI 프롬프트 템플릿 자동화 (AI Prompt Template Studio) — 사용자 매뉴얼 (MANUAL.md)

> **버전**: v1.01  
> **공식 명칭**: AI 프롬프트 템플릿 자동화  
> **주요 기능**: 동적 변수(`{{...}}`) 기반 맞춤형 프롬프트 라이브러리 보관함, AI 자동 채우기 및 원클릭 즉시 실행 스튜디오

---

## 1. 개요 (Overview)

**AI 프롬프트 템플릿 자동화**는 자주 사용하는 고품질 프롬프트를 템플릿 형태로 보관하고, 변경이 필요한 부분만 동적 변수(`{{variable}}`)로 지정하여 **원클릭으로 AI 실행 및 결과물 추출까지 끝내는 올인원 프롬프트 라이브러리 스튜디오**입니다.

- **핵심 가치**: 매번 프롬프트를 새로 쓸 필요 없이, 검증된 템플릿에 키워드나 코드만 쏙 넣으면 번개처럼 AI 답변을 받아볼 수 있습니다.
- **최상위 불변 규칙**: 모든 회원은 본인의 Google Gemini API 키를 직접 등록하여 독립적으로 사용합니다. (타인/운영자 키 공유 금지)

---

## 2. 핵심 기능 안내

### ① 템플릿 라이브러리 & 카테고리 관리
- 카테고리별 필터: `Writing`, `Coding`, `Business`, `Marketing`, `Personal` 등 자유로운 카테고리 분류
- 카테고리 동적 추가: `+ 추가` 버튼으로 나만의 카테고리를 무제한 생성
- 실시간 통합 검색: 프롬프트 제목, 설명, 본문, 변수명을 실시간으로 검색

### ② 동적 변수 문법 (`{{변수명}}`)
- 템플릿 본문 작성 시 중괄호 2개(`{{topic}}`, `{{role}}`, `{{code}}` 등)를 감싸면 변수로 자동 인식됩니다.
- 본문을 작성하는 즉시 하단에 **감지된 변수 칩 목록**이 자동으로 태깅됩니다.

### ③ 제작 시 AI 3단 어시스턴트
- **제목 AI 제안**: 본문과 설명을 분석하여 가장 직관적인 제목을 추천
- **설명 AI 제안**: 템플릿의 용도와 특징을 깔끔한 한 문장으로 요약
- **본문 AI 제안**: 제목과 설명을 바탕으로 `{{변수명}}`이 최적의 위치에 포함된 완성형 프롬프트 템플릿 자동 작성

### ④ 실행 시 AI 변수 자동 채우기 & 원클릭 실행
- 프롬프트 카드의 **`[▶ 실행]`** 버튼 클릭 시 변수 입력 모달 오픈
- **`[✨ AI 자동 채우기]`**: AI가 프롬프트 목적을 분석하여 변수별 현실적이고 창의적인 예시 데이터를 자동으로 쏙 채워줌
- **`[프롬프트 실행]`**: 변수가 치환된 완성형 프롬프트를 Google Gemini 2.5 Flash 모델로 즉시 실행하여 마크다운 결과물 생성
- 결과물 원클릭 복사 및 마크다운 파일(`.md`) 다운로드 지원

### ⑤ 라이브러리 백업 및 복원
- 보관된 전체 프롬프트 목록을 표준 JSON 파일(`Prompt_Library_Backup.json`)로 원클릭 백업
- 이전에 백업한 JSON 파일을 업로드하여 라이브러리에 손쉽게 복원(병합 또는 덮어쓰기)

---

## 3. 시작하기 (Quick Start)

1. 좌측 메뉴의 **`🔑 API키등록·플랫폼연동`**을 클릭하고 본인의 Google Gemini API 키를 등록합니다.
2. 메인 화면에서 원하는 템플릿 카드의 **`[▶ 실행]`**을 누릅니다.
3. 변수 입력창에서 **`[AI 자동 채우기]`**를 누르거나 직접 값을 입력합니다.
4. **`[프롬프트 실행]`**을 누르면 몇 초 만에 고품질 AI 결과물이 완성됩니다!
5. 새로운 나만의 템플릿을 등록하고 싶다면 우측 상단의 **`[+ 새 프롬프트]`**를 눌러 자유롭게 추가하세요.
