# 병합 묶음 A-6: 대표 이미지에 제목 글자 넣기 (올인원 → 에이전트) — 개발 플랜 (v2.18 후보, 2026-10-24)

- 작성: Claude Code(윈도우) 블로그 전담 `claude-win-20261023-blog2`
- 상태: **플랜 보고 — 주인님 승인 대기(코드 미수정)**
- 근거: 블로그 병합 묶음 A([REPORT](../../docs/analysis-blog-consolidation-20261020/REPORT.md#blog-merge-independent-20261023)), A-5 다음 순서.

## 원본(올인원)의 기능
- `naver-blog-allinone/src/lib/blog/canvas.ts` `overlayThumbnailTitle`: 대표 이미지 아래쪽에 어두운 그라데이션 띠 + 테마 색 세로 막대 + 흰 제목 글자(최대 3줄, 이미지 폭의 5.5% 크기)를 **브라우저 캔버스로** 그린다. AI는 한글 글자를 깨뜨리므로 그림 생성 뒤 따로 합성한다.
- 「썸네일에 제목 글자 넣기」 체크(`settings.withThumbnailText`)를 켜면 대표 이미지를 만들 때 자동으로 합성.

## 에이전트의 현재
- 대표 이미지 지시문은 `no text`(글자 없음). 서버(`/api/generate-image`)가 만들어 바로 저장소에 올리고 주소만 돌려준다. 제목 글자를 넣는 기능은 없음.
- 회원 전용 업로드 경로 `/api/upload-image`(로그인+권한, 15MB, `naver-blog-agent/<회원>/`)가 이미 있다.

## 구현
1. `src/lib/thumbnailTitle.ts`: 올인원 `overlayThumbnailTitle`과 줄바꿈 함수를 가져온다(에이전트에 맞게 색은 고정 강조색 하나, 결과는 PNG `Blob`). 글자 줄 나누기는 순수 함수로 떼어 시험한다.
2. 화면(생성된 이미지 카드 — 대표 썸네일에만): **「제목 글자 넣기」 버튼**. 누르면 이미 만든 대표 이미지를 불러와 원고 제목을 합성 → `/api/upload-image`로 올림 → 대표 이미지 주소를 새 주소로 바꿔 기존 `persistImages`로 저장. **이미지를 다시 만들지 않으므로 AI 비용이 들지 않는다.** 올인원의 「만들 때 자동 합성」 대신 버튼 방식으로 정한 이유: 생성 뒤 결과를 보고 고를 수 있고, 다시 만들기 비용 없이 켜고 끌 수 있다.
3. 「글자 없는 원본으로 되돌리기」: 합성 전 원본 주소를 이미지 항목에 같이 저장(선택 항목 `originalUrl`, 예전 원고는 그대로 열림)해 되돌릴 수 있게 한다.
4. 시험: 줄 나누기(긴 제목 3줄 자르기·빈 제목), 대표 이미지 주소 바꾸기·되돌리기(본문 이미지 순서 불변). 캔버스 그리기는 화면에서 확인.

## 범위 밖
- 글자 위치·크기·색 고르기(올인원도 고정). 본문 이미지에 글자 넣기.

## 주의
- 저장소 이미지를 브라우저에서 불러와 캔버스에 그리므로 교차 출처(CORS) 허용이 필요하다 — Supabase 공개 저장소는 허용하지만, 막히면 「이미지를 불러오지 못했습니다」로 알리고 원본은 그대로 둔다.
- 원본·합성 파일 모두 `naver-blog-agent/<회원>/`에 있어 30일 정리(`api/cron/cleanup`)에 함께 지워진다.
- 확장은 대표 이미지 주소를 그대로 받아 발행하므로 확장 코드는 바꾸지 않는다(버전만 v2.18로 맞춤).
