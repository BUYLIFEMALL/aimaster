# 최신 기능 사용 안내 업데이트 — v1.81

주인님 요청: https://naver-blog-agent.vercel.app/guide 에 새로 추가된 사용 방법을 보기 쉽게 정리.

## 조사 및 변경

기존 안내는 다운로드 v1.27 고정값, 자동 발행/직접 발행 혼용, 100% 보안 통과 및 영구 저장 표현이 실제 상태와 달랐습니다. page.tsx, NaverPublishSettings, PostReviewGate, ExecutionProgress, 보관함, 확장 connect, 페어링 API, 보관 정책 코드를 대조해 안내만 개편했습니다.

- 빠른 시작5단계: 생성 → 수정·저장 → 최종 검수 → 발행 전 준비 → 직접 발행.
- 8개 구간과 페이지 내부 목차: 최초 연결, 생성, 이미지, 저장/검수, 준비/발행, 상태, 문제 해결, 보관/백업.
- prepare/publish 비교표. 기존 원고는 자동 발행일 수 있으므로 준비 모드 선택 후 설정 저장을 분명히 안내.
- 새 이미지 미생성 컷만 생성, 개별 이 컷만 생성/삭제, 저장 성공 안내 및 다시 검수.
- 파란 서식 보기/회색 원본, 최종원고 수정 및 확인 완료 + 직접 검수 완료 기록의 차이.
- 보관함 공개 범위 선택 위치, 네이버 준비 원고에서 예약 설정/최종 버튼 직접 확인.
- 보관함 진행/만료 복구, 저장 충돌/응답 불확실 때 화면 보존과 최신 원고 확인.
- 준비 완료와 발행 완료 구분, 직접 발행 후 웹 상태가 prepared로 남을 수 있음.
- 개인 계정/개인 키 필수, 연결 코드10분/일회용, 확장 설치·덮어쓰기/새로고침.
- 서버 저장 확인과30일 보관 정책. 글감 책갈피 보호를 원고/이미지 영구 보호로 안내하지 않음.
- 버전 APP_VERSION, 보관일 RETENTION_DAYS, 연도 new Date().getFullYear() 동적 표시.

변경 위치: src/app/(dashboard)/guide/page.tsx. 로그인/권한 layout 유지. 원고/자동화/API/회원 데이터 변경 없음. 확장은 버전/ZIP만 동기화하며 실행 코드는 그대로입니다.
