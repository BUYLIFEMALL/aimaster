## 에이전트의 현재 사진 후기
- `src/lib/photoReview.ts` 입력: 장소·방문 메모·말끝·분량·대표 사진·사진 설명만.
- `src/lib/ai/photoReviewPipeline.ts`: 문단마다 근거(사진 ID 또는 `member-notes`)가 있어야 결과로 인정하는 엄격한 구조. 확인이 필요한 것은 `confirm`(직접 확인할 내용)으로 분리.

## 구현(올인원 장점 + 에이전트 근거 규칙)
1. 입력 형식에 선택 항목 `visit` 추가: 분류(맛집·카페·여행·체험·기타)·지역(60자)·방문일(날짜)·동행(40자)·한 줄 소감(120자). 선택 항목 `includeFaq`(기본 꺼짐).
2. 지시문: 방문 정보는 「회원이 직접 준 사실」로 넣고 그 내용을 쓴 문단의 근거는 `member-notes`. 분류에 맞는 문단 흐름 안내(맛집=메뉴·맛 표현은 메모에 있을 때만 등).
3. FAQ를 켜면 마지막 문단 하나를 「자주 묻는 질문」으로: **회원 정보·사진으로 답할 수 있는 질문만** 쓰고, 답할 수 없는 질문(주차·웨이팅·가격 등 정보가 없는 것)은 FAQ에 넣지 않고 `confirm`으로 보냄.
4. 근거 검사: 방문 정보가 있으면 `member-notes` 근거를 허용(지금은 메모·사진 설명이 있을 때만).
5. 화면 `src/components/PhotoReviewDraft.tsx`: 장소 칸 아래 방문 정보 칸 5개·FAQ 체크. 저장·다시 열기·검수(BLC-04) 흐름에 같이 실림(입력 형식이 바뀌면 기존처럼 다시 검수).
6. 예전 결과(방문 정보 없음)는 그대로 열림(선택 항목).
7. 시험: 입력 검사(길이·날짜·분류)·예전 결과 호환·근거 허용 조건·FAQ 지시 문구. 기존 시험 24종 유지.
