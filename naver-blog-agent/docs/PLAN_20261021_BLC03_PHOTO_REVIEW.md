# BLC-03 사진·방문 메모 기반 후기 초안

## 문제·범위

현재 사진 준비는 가능하지만 글 생성에는 사용되지 않습니다. 기존 일반 글 생성과 구분되는 사진 후기 초안을 추가합니다. 사진 1~6장·대표/순서/설명·방문 장소/본인 메모·선택한 본인 모델/키를 사용합니다. 사진 관찰은 AI 해석이며 회원 경험·가격·맛·방문일을 대신 증명하지 않습니다. 입력하지 않은 경험을 만들지 않고 확인 필요 항목을 별도 표시합니다.

원고 편집/서버 저장/대기열/확장 연결은 BLC-04 범위입니다. 이번 결과는 화면에서 확인·복사하는 초안으로만 제공하며 새로고침/화면 이동 시 사라짐을 안내합니다. 기존 일반 글 생성·저장·발행 동작은 유지합니다. 사진 생성 API는 호출하지 않습니다.

## 구현 순서·검수

1. 공용 사진 준비 데이터와 현재 모델 선택을 작은 후기 영역에 연결합니다. 외부 API 키는 공용 `user_api_keys`에서 로그인 회원/명시한 공급사만 조회하고 환경변수·운영자·다른 공급사 폴백은 금지합니다.
2. 서버에서 ID/중복/장수/메모/모델을 검증하고 사진별 소유권·실제 Storage 등록일/만료·형식/크기를 재검증합니다. 외부 URL을 입력받아 내려받지 않습니다. 사진 바이트는 요청 내에서만 사용하고 저장·로그·캐시에 남기지 않습니다.
3. 사진 관찰 JSON → 검증된 관찰+회원 메모를 바탕으로 초안 JSON, 최대 2회 호출. 사진별 ID를 보존하고 잘못된/누락된 AI 응답은 성공으로 처리하지 않습니다. 프롬프트에 자료 안 지시 무시·허위 경험/수치 금지·근거 분리를 명시합니다.
4. 취소/입력 변경/화면 이탈 시 늦은 결과를 무시합니다. 결과에 회원 메모·사진별 관찰·확인 필요·항상 직접 검수 필요 상태를 표시합니다. 사용 안내는 메타정보·개요·4단계 카드/상세·복사·팁/주의·회원 설정 직링크를 갖춥니다.
5. 무료 시험: 비로그인/타 회원/만료/잘못된 경로·형식·중복·장수·미지원 모델·키 없음 차단, 6장 순서/ID 연결, 응답 오류/취소/늦은 결과, AI 요청의 선택 모델/바이트 형식·재시도 0·시간 제한 확인. 기존 회귀·타입·빌드 후 Edge 실제 회원 최소 생성과 좁은 화면 확인.
