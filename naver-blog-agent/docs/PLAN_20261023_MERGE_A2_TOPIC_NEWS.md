- 근거: 블로그 병합 묶음 A([REPORT](../../docs/analysis-blog-consolidation-20261020/REPORT.md#blog-merge-independent-20261023)), A-1 다음 순서.

## 원본(BLOG)의 기능
- `ai-auto-blog/utils/news/collector.ts` `collect24HourNews`: 주제로 구글 뉴스 RSS 검색(`news.google.com/rss/search?q=…&hl=ko&gl=KR`) → 최근 24시간 기사 제목·요약을 글 지시문에 넣음. 글감을 고르지 않아도 최신 사실을 근거로 쓸 수 있는 것이 장점.
- 가져오지 않을 것: 같은 함수의 `socialMentionScore`(실제 SNS 측정이 아니라 언론사 수로 만든 추정 점수 — BC-08).

## 에이전트에 지금 없는 것
- 글감 보관함에서 자료를 고르거나(A-1부터는 참고 URL을 넣거나) 해야만 근거가 생김. 주제만 넣으면 근거 없이 일반 지식으로 씀.

## 구현
1. 생성 화면에 체크 「주제로 최근 뉴스 근거 자동 수집」(기본 꺼짐, 생성 설정 저장에 포함).
2. 서버: 켜져 있고 주제가 있으면 구글 뉴스 RSS 검색을 에이전트의 공개 피드 읽기(`src/lib/rss.ts`, 안전한 수집)로 읽어 최근 72시간 기사 최대 8건(제목·언론사·날짜·요약)을 근거 자료에 합침. 순서: 글감 → 참고 URL → 뉴스, 전체 4,000자 안.
3. 뉴스를 읽지 못하거나 0건이면 생성을 멈추지 않고 화면에 알림(A-1과 같은 방식).
4. 원고 기록에 사용한 기사 제목·주소를 남김(`research_summary.news_sources`).
5. 시험: 피드 해석·72시간 거르기·최대 8건·합치기 순서·실패 처리(가짜 피드). 기존 시험 23종 유지.

## 검수
1. 무료: tsc·빌드·시험 전체.
2. 실제 생성 1회: 시험 계정 본인 키, gpt-4o-mini, 주제만(글감·URL 없이)+뉴스 근거 켬 → 본문에 최근 기사 사실이 들어가는지, 검수가 근거 밖 문장을 잡는지. 저장 안 함.
3. A-1과 함께 v2.16 배포(빌드 1회) → 크롬에서 입력칸·체크·안내 확인.
