## 수정과 검사

extension/background.js의 prepareFinalEditorUi를 본문 입력 완료 후 imageAi 전에 호출합니다. 현재 실행의 서버 상태/로컬 runId/탭/원고 화면을 확인하고 **해당 작업 탭만 한 번 앞으로 가져와** AI표시와 전체 원고/발행 설정을 확인합니다. 최소화된 작업 창은 복원합니다. 문단마다 전면으로 가져오지 않으며 입력 완료 전에는 새 동작을 추가하지 않습니다. 최종 발행 버튼을 누르는 코드나 준비 모드의 경계는 바꾸지 않습니다. 사용자 입장에서는 완료 단계에 네이버 원고가 앞으로 열리며 직접 최종 검토할 수 있습니다.
