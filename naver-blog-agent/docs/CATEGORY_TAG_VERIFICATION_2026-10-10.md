# 네이버 카테고리·태그 구현 및 실제 검수 보고

최종 버전: **v1.62** · 운영 주소: https://naver-blog-agent.vercel.app

## 구현 결과

- 생성 결과 및 보관함 「발행 설정」에 카테고리·태그 설정 카드를 추가했습니다. 보관함 모달에서는 긴 본문보다 먼저 표시됩니다.
- 본인 네이버 블로그에 실제로 등록된 카테고리를 확장으로 불러와 선택합니다. 원고별로 저장하며, 선택하면 해당 블로그의 기본 카테고리로도 저장할 수 있습니다. 원고별 설정이 기본값보다 우선합니다. 글감 분류 카테고리와는 별개입니다.
- 저장한 설정은 다음 발행 전송에 자동으로 적용합니다. 카테고리 ID와 이름을 확인하므로 삭제되거나 이름이 바뀐 경우에는 원고를 보존하고 중지합니다.
- 태그는 추가·삭제할 수 있으며 최대 10개입니다. #·공백을 정리하고 중복을 제거합니다. 네이버에 이미 등록된 태그는 유지하고, 실제 등록된 태그 칩으로 성공을 검증합니다.
- 수정 내용이나 입력 중인 태그가 남아 있으면 설정 화면의 발행 전송을 막고 먼저 저장하도록 안내합니다.

## 검수 중 발견한 추가 문제와 조치

확장의 `busy` 잠금을 주기적인 상태 확인과 발행 작업이 공유하므로, 실제 발행 중이 아니어도 웹 카테고리 조회가 거절되는 문제를 실제로 발견했습니다. v1.62에서는 단순 상태 확인이 끝날 때까지 최대 10초 기다린 후 조회 잠금을 잡습니다. 실제 발행 작업이 있으면 즉시 차단합니다. 자동 검사에 두 경우를 모두 추가했습니다.

## 사용 순서

1. 보관함 원고의 「발행 설정」을 누릅니다.
2. 「네이버 카테고리 불러오기」를 누르고 실제 카테고리를 선택합니다.
3. 필요한 태그를 추가·삭제합니다. 블로그 공통 기본값으로 쓰려면 체크박스를 선택합니다.
4. 파란색 「발행 설정 저장」을 누릅니다.
5. 이후 발행 전송 시 저장한 설정이 자동 적용됩니다.

다른 PC에서는 최신 ZIP 재다운로드→기존 확장 폴더에 덮어쓰기→`chrome://extensions` 새로고침→프로그램 웹 페이지 새로고침이 필요합니다.
