## 범위와 순서

1. 기존 안전한 공개 페이지 요청기를 재사용해 공개 RSS/Atom 항목(최대 5개)을 읽고 글감으로 정리. 로그인 피드·NewsBlur 신규 연동은 이번 범위 아님. 실패/빈 원문이면 성공으로 표시하지 않음.
2. `nba_collected_materials`를 새로 추가: 회원 소유자·서버 수집 시각·30일 원래 만료·변경 버전·후보·원문/출처 객체. RLS는 본인 미만료 조회, 쓰기는 인증된 앱 서버에서 소유자 조건. 원문과 수명은 편집으로 교체 불가. 동시 수정은 버전 충돌로 거절.
3. 모든 기존 수집 경로도 같은 서버 저장과 목록을 사용. 출처를 확인할 수 없는 기존 공용 브라우저 목록은 자동으로 어느 회원에게도 귀속/업로드하지 않음. 새 목록은 서버에서만 읽음. 보관/편집/사용 표시가 30일을 연장하지 않음.
4. 글감 ID로 생성 요청 → 서버가 본인 원문/출처를 재조회해 기획·작성·검수에 전달. 원고 `research_summary.source_bundle`에 근거를 보존, 생성 실패·저장 실패 구분. 원고 수명은 원래 수집일부터 30일, 편집/복사로 연장 금지. 원고 다시 열기와 보관함에 출처/원문 대조 표시. 이 원고는 공용 브라우저 캐시에 남기지 않음.
5. 기존 콘텐츠 정리 Cron에 새 표의 만료 정리 추가(기존 정책 유예와 분리). 기존 운영 원고/사진/회원 설정 보존.
6. 4단계 시각 카드·상세 단계·규칙 복사·팁/주의·설정 직링크 안내 추가. v2.06 코드/확장/ZIP/DB 메타데이터 일치, 배포 후 Edge 실제 회원 검수.

## 검수·비용·산출물

- 합성 RSS/Atom, 주소/빈 응답/부분 실패, 회원 소유권·만료·동시 편집, 원문 변조 거절, 생성/재저장/원래 만료 보존, 기존 저장/검수/확장 회귀 및 타입·빌드.
- 실제 Edge 포그라운드 회원 계정의 공개 피드 수집 최소 1회. 가능한 최저 비용 본인 모델 사용, 유료 글 생성은 필요 최소 1회(추가 이미지 생성·최종 발행 없음). 생성 원문은 Git에 저장하지 않고 검수 메타데이터만 기록.
- DB는 새 표/RLS/한정된 원자적 수정 함수 및 버전 메타데이터만. 기존 권한/키/계정/환경변수·서비스 중단 없음. DB 원본 프로그램 메타데이터 백업, 마이그레이션·회귀 결과·배포 ID·Edge 증거·인수인계/아이디어표/작업목록 갱신·본인 변경만 커밋/푸시.
- 운영 완료는 실제 확인한 범위로만 표기. BLC-06 편집 확장 및 이후 작업은 이번 단계에 섞지 않음.

## 운영 검수에서 발견한 주소 검사 보완 — v2.07

v2.06 배포/검수 중 NASA 공개 RSS 요청 2회가 AI 호출 전에 `내부 주소는 사용할 수 없습니다`로 거절됐습니다. 로컬 단순 HTTP 사전 확인만 했던 한계를 인정하고, 실제 안전 검사 자체를 회귀에 포함합니다. DNS `www.nasa.gov → 192.0.66.108` 재현, 기존 IPv4 검사 `(a===192 && b===0)`가 /16 전체를 막는 것이 원인입니다. [IANA 특별 IPv4 목록](https://www.iana.org/assignments/iana-ipv4-special-registry)의 `192.0.0.0/24`·`192.0.2.0/24`를 기준으로 범위를 한정하고 기존 사설·혼합 DNS·리다이렉트 검사는 유지합니다. 영향 범위는 에이전트 수집기만이며 공용 기준 등록/다른 프로그램 수정은 이번 범위가 아닙니다. v2.07로 +0.01·확장/ZIP/DB 일치·재검수. 운영 검수에서 실제 발견된 오류 수정으로 추가 배포 1회가 필요합니다.
