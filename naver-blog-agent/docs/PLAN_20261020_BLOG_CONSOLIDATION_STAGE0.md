## 문제와 범위

`readNaverExecutionMode`는 설정 없는 옛 원고를 publish로 해석합니다. 기존 회원이 사용하는 옛 자동 발행을 일괄 바꾸지 않고, **이번 변경 이후 새로 만드는 원고만 prepare를 명시적으로 저장**합니다. 생성 API 저장과 생성 후 저장 실패를 복구하는 원고 생성 API 둘 다 적용합니다. 서버에 실제 존재하는 원고의 업데이트는 기존 선택을 보존합니다.

## 구현·검수 순서

1. 새 원고용 준비 모드 초기화 함수를 기존 발행 설정 모듈에 추가합니다. 생성 API와 최초 저장 경로에서만 사용합니다.
2. 신규 원고→준비 모드, 저장 재시도→같은 원고/같은 설정, 기존 publish/prepare→보존, 다른 회원→수정 불가, 회원이 이후 publish로 선택→정상 동작을 모의 DB로 검증합니다.
3. 타입 검사·관련 회귀 검사·로컬 빌드. 가능하면 보이는 Edge에서 로컬 설정 동작 확인. 실제 회원 E2E와 가짜 세션/모의 DB 검수를 구분합니다.
4. 검수 결과·제한·다음 단계를 인수인계와 공통 아이디어 표에 기록합니다. 배포가 가능할 때만 버전/확장 ZIP/운영 DB/라이브 검증을 함께 처리합니다.
