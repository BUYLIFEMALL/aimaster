## 문제
v2.12에서 이미지 저장 버킷을 `naver-blog-agent-media`(공개)로 바꿨지만, 그 전에 만든 미발행 글 23건(회원 3명: 시험 회원 21·관리자 1·일반 회원 1, 상태 초안 12·발행 준비 5·실패 6)이 옛 버킷(10-21 비공개 전환) 주소 76곳을 그대로 쓴다. 이대로 발행하면 이미지가 빠진다.

## 범위·순서
1. 옛 버킷 `ai-image-generations/naver-blog-agent/<회원>/<파일>` 중 글이 참조하고 아직 남아 있는 파일을 새 버킷의 **같은 경로**로 복사(내려받아 올림). 원본 없는 파일은 그대로 둠.
2. `nba_posts`에서 **소유자(user_id) + 행 id + 읽을 때의 updated_at**이 같은 행만, 복사에 성공한 파일의 주소 앞부분(`…/public/ai-image-generations/` → `…/public/naver-blog-agent-media/`)만 바꿈. 상태·생성일·소유자는 그대로. 바뀐 행 수를 기대값과 대조.
3. 30일 기한 유지: 복사본은 저장소 생성 시각이 이관 시점이 되므로, `cron/cleanup`이 파일 이름의 13자리 생성 시각(`<ms>-…`, `attached-<ms>-…`)이 있으면 그 시각으로 판정하도록 수정(작은 수정 → 미배포 대기). 54개 파일 모두 이름 시각과 실제 생성 시각 차이 2초 이내 확인.
4. 미리 보기(쓰기 없음) → 실제 실행 → 재확인(옛 주소 남은 행 수, 새 주소 열림).
