## 원본(BLOG)의 기능
- `ai-auto-blog/app/write/ai-form/page.tsx`: 생성 직후 「빠른 수정」에서 소제목 단락 단위로 위아래 이동·단락마다 이미지 다시 생성·삭제. 이미지가 어느 단락에 붙는지 회원이 정할 수 있음.

## 에이전트의 현재
- 본문에 `[IMAGE INSERT - 설명]` 표시를 고르게 자동 배치(`src/lib/draftImages.ts` `placePlannedImages`), 화면·확장은 **N번째 표시에 N번째 본문 이미지**를 끼움.
- 한 장 다시 만들기·지우기는 있으나 **이미지를 다른 문단 아래로 옮기는 기능이 없음**(비주얼 편집기에서 직접 옮겨야 함).

## 구현
1. `src/lib/draftImages.ts`에 `moveImageMarker(content, slot, "up"|"down")`: N번째 표시를 바로 위/아래 문단 앞으로 한 칸 옮김. 다른 이미지 표시를 지나치면 **새 순서(from→to)를 돌려주고 본문 이미지 목록 순서도 같이 바꿔** 각 사진이 제 자리를 따라감. 맨 위·맨 아래에서는 바뀌지 않음. 본문 글자는 한 줄도 바뀌지 않음(표시 줄 위치만).
2. 생성 결과의 이미지 카드에 「▲ 위 문단으로」「▼ 아래 문단으로」 버튼 — 기존 지우기와 같은 저장 흐름(`persistImages`, 본문이 바뀌면 검수 표시 초기화 = 다시 검수).
3. 시험: 위/아래·경계·다른 이미지 지나칠 때 순서 교환·본문 글자 불변·소제목 줄 건너뛰기.

## 범위 밖
- 소제목 단락 자체를 위아래로 옮기기(BLOG의 단락 이동) — 비주얼 편집기에서 가능, 이번에는 이미지 위치만.

## 검수
1. 무료: tsc·빌드·시험 전체. **AI 호출 없음**(순수 위치 계산).
2. 배포 뒤 크롬: 시험 계정에서 기존 원고를 열어 이미지 위/아래 이동 → 화면에서 사진이 따라 움직이는지, 저장 뒤 다시 열어도 유지되는지. (시험 계정 본인 원고만 수정)
