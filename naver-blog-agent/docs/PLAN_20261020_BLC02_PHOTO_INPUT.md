# BLC-02 사진 준비 UI 개발 계획

2026-10-20 Codex(윈도우). 주인님 ‘계속 작업 진행’ 요청, BLC-01 운영 완료 후 순차 착수. 대상 AIMaster 운영 ref `esgxyikcnnvmlhygjkth`. 기존 Storage/API를 사용하며 DB 구조·정책·회원 권한·키/환경변수 변경 없음.

## 문제와 범위

현재 회원별 비공개 업로드/조회/30일 정리·실제 확장 준비는 검증됐지만 일반 회원이 사진을 선택·정리할 UI가 없습니다. 기존 글 생성 화면에 접을 수 있는 ‘사진 준비’ 공간을 추가합니다. 최대 6장, 장당 4MB, JPEG/PNG/WebP, 대표 선택·앞뒤 순서·사진별 캡션·목록 제거·전체 취소를 제공합니다. 기존 AI 생성 이미지 장수(1~5)와 별개입니다.

이번에는 사진 입력과 정리까지만 만듭니다. 사진의 내용·본인 경험으로 글쓰기(BLC-03), 완성 원고 편집/저장 연결(BLC-04), 기존 도구 중단은 하지 않습니다. 준비한 사진이 기존 주제 글 생성에 자동 사용되지 않는다는 현재 범위와 화면을 닫으면 선택/캡션이 사라진다는 점을 회원이 결정할 수 있도록 안내합니다. 입력 사진은 localStorage/공유 캐시에 저장하지 않습니다.

## 구현 순서

1. 사진 형식/용량/장수 규격을 서버·브라우저에서 같이 쓰는 작은 파일로 분리합니다. 기존 서버 검증을 약화하지 않습니다. 공용 `image-file-check` 기준 사본으로 브라우저 실제 판독을 재사용하고 사본 등록/일치를 확인합니다.
2. 안정된 사진 ID를 기준으로 업로드/조회 상태·대표·순서·캡션을 관리합니다. 삭제/취소/화면 이탈 시 요청을 취소하고 늦은 응답을 무시합니다. 조회만 실패했을 때 이미 업로드된 파일을 다시 보내지 않고 조회만 재시도합니다. 업로드 실패를 자동 재시도하지 않습니다.
3. 로컬 미리보기와 서버 정적 경로/최초 생성일/30일 만료를 분리합니다. 미리보기 URL은 화면 해제 시 반납합니다. 순서 변경·대표 교체·설명 수정으로 최초 만료를 갱신하지 않습니다. ‘제거’는 선택 목록에서만 제외하며 이미 전송된 파일은 기존 30일 정리 대상임을 안내합니다.
4. 선택기 컴포넌트·접이식 진입·간단 사용 안내를 기존 밝은 그린 테마에 맞춥니다. 캡션은 ID에 결합하며 키보드로도 대표·순서·제거를 조작할 수 있게 합니다. 매뉴얼은 기존 시각 카드 규격을 참고해 사용 범위·팁·함정 방지를 추가합니다.
