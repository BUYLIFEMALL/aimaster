# BLC-02 사진 준비 UI — v2.02 릴리스 검수

2026-10-20 Codex(윈도우). BLC-01 운영 완료 후 주인님 ‘계속 작업 진행’ 요청으로 착수. 대상 AIMaster 운영 ref **`esgxyikcnnvmlhygjkth`**. [개발 계획](PLAN_20261020_BLC02_PHOTO_INPUT.md).

## 구현·범위

- 기존 콘텐츠 생성 화면에 접을 수 있는 ‘내 사진 준비’를 추가했습니다. JPEG/PNG/WebP 장당 4MB·최대 6장, 대표·앞뒤 이동·500자 설명·사진별 제거/업로드 취소·전체 취소·보관 상태 재조회입니다. AI 생성 이미지 장수와 별개입니다.
- **사진으로 AI 글쓰기와 완성 원고 저장은 아직 미구현(BLC-03·04)**입니다. 사진이 기존 글 생성에 사용되지 않는다는 현재 범위, 새로고침/화면 이동 시 선택·설명 초기화를 화면과 매뉴얼에 명시했습니다.
- 사진 ID로 요청 결과·순서·설명을 결합합니다. 취소한 요청의 늦은 응답은 무시하고 업로드 성공 후 조회만 실패하면 재업로드 없이 조회만 재시도합니다. 대표 제거 시 남은 첫 사진을 선택하고 부분 실패를 전체 준비 완료로 처리하지 않습니다.
- 로컬 Blob 미리보기와 서버 정적 경로/최초 생성일·30일 만료를 분리했습니다. 제거/취소/화면 이동 시 미리보기를 반납합니다. 선택 데이터에 서명 URL·파일 내용/공용 캐시/localStorage 저장 없음. ‘제거’는 목록에서만 제외하며 이미 전송된 파일은 원래 30일 정리 대상입니다.
- `image-file-check` 기준/시험 사본 재사용, 기준 파일·다른 프로그램 변경 없음. 서버 헤더/MIME·크기·소유권 검증 유지, 장수·크기 상수만 브라우저와 공유합니다.
- 매뉴얼: 메타데이터·개요·STEP 1~4 시각 카드/상세·규격 복사·팁/주의·사진 준비/계정 설정 직링크. 외부 키가 필요 없는 기능이므로 운영자 Supabase 콘솔 대신 회원 본인의 앱 설정으로 안내합니다.
