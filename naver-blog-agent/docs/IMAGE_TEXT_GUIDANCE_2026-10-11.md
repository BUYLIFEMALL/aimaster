# v1.78 — 이미지 속 글자·가짜 화면 방지 지시 보강

## 확인한 문제와 수정

v1.77 실제 회원 화면에서 4장 원고 e933ffeb-61bb-4375-97fb-3482d36a24e4의 BODY1 ‘이 컷만 생성’을 실행했습니다. 서버 ACK 뒤 URL은 1791696812012-tei1da.png에서 1791714143889-vskifi.png로 바뀌었고 다른3개/본문/장수4는 동일했습니다. 따라서 개별 교체와 저장은 실제 통과입니다. 그러나 새 이미지에도 화이트보드 글자/가짜 화면이 남았고 BODY2의 메모·BODY3의 인포그래픽에도 글자가 있습니다. HTTP200/장수/교체 성공을 이미지 품질 통과와 구분합니다.

src/lib/ai/imageGenerator.ts finalizePrompt의 기존 ‘글자 없음’ 규칙에 구체적인 장면 지시를 추가했습니다. 제목/주제를 장면 속 글자로 옮기지 않고 물건·배치·동작으로 표현합니다. 종이/노트/카드/보드/간판은 빈 면, 화면은 꺼진 상태 또는 추상 형태로 표현하며 가짜 앱 화면·글자 체크리스트·말풍선·지시 도표·전후 비교 글자·지어낸 필기를 피합니다. 요청한 화풍/구도는 유지합니다. 공급사별 공통 경로에 적용하며 자동 유료 재시도/OCR/성공 보장은 추가하지 않았습니다. 완성 이미지의 육안 검수가 계속 필요합니다.

본인 키만 사용하는 구조, 이미지 개별 교체·저장 경계, 서버/옛 확장 호환은 유지합니다. DB 스키마/환경변수/키/다른 프로그램 변경 없음. 프로그램·확장·다운로드ZIP·DB 릴리스 메타데이터를 v1.78로 함께 관리합니다.

## 검사

실제 이미지 생성 함수에 공급사 fetch만 모의해 Gemini/OpenAI/FLUX/Z-Image 요청에 공통 지시가 전달되고 주어진 회원 키만 사용하며 유료 생성1회/다른 공급사 폴백0임을 확인했습니다. 긴 원본 프롬프트도 마지막 규칙을 잘라내지 않습니다. 새2개·전체 Node133개 통과, 로컬 빌드/TypeScript 통과. 공급사 실제 결과를 보장하는 검사는 아닙니다. v1.77 worker40개와 Node 집계는 중복 합산하지 않습니다.
