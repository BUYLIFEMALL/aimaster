## 변경과 보존 범위

- 공개 RSS/Atom 항목 최대 5개를 기존 SSRF/리다이렉트·크기/시간 제한 요청기로 읽습니다. 외부 XML 엔티티/기사 이미지 추가 요청은 하지 않습니다. 기존 URL·랭킹·Perplexity·쇼츠도 같은 서버 목록으로 저장합니다. Perplexity는 제공된 참고 주소를 별도 보존하고 AI 보고서/영상 설명·댓글을 사실·체험 증거로 단정하지 않습니다.
- `nba_collected_materials`: 본인 소유·서버 수집일·원래 30일 만료·수정 버전·후보/출처 객체. 클라이언트에는 본인 미만료 SELECT만 허용, 쓰기/RPC는 앱 서버만 소유자 조건으로 처리합니다. 일괄 수정은 한 트랜잭션이며 충돌/외부 회원/만료 ID이면 전체 취소됩니다. 네트워크 ACK 유실은 미저장으로 단정하지 않습니다.
- 제목/요약/분류·보관·사용 표시를 편집해도 최초 원문/출처/만료는 바뀌지 않습니다. 과거 `nba_viral_candidates` 공용 캐시는 소유자 불명이므로 새 회원에게 자동 귀속/업로드/사용하지 않습니다. 기존 키 자체를 일괄 삭제하지도 않았습니다. 서버 목록은 최근 최대 500건입니다.
- 글감 ID → 서버 본인 원문 재조회 → 기획/작성/검수 → `research_summary.source_bundle` 저장. 원고 생성일은 원래 수집일로 고정하고 재저장/원고 재열기/편집 시 보존합니다. 최초 출처 교체·다른 원고에 덧씌우기는 거절합니다. 만료된 출처는 원고 목록/저장/신규 확장 선점에서 거절합니다. 기존 Cron에 글감 만료 삭제를 추가했고 보관도 예외가 아닙니다.
- 원문 객체는 최대 4,000자, AI 입력은 출처/시각·원문 일부 최대 2,800자·편집 요약 일부로 4,000자 이내입니다. 긴 편집 요약이 원문을 밀어내지 않습니다. 여러 기사에서 정확한 후보 매칭이 안 되면 묶음 일부를 보존하는 기존 한계는 남고 UI에서 원문 일부/직접 대조를 안내합니다. 정밀 다대다 대조 완료로 주장하지 않습니다.
- 원고 `source_bundle`은 보관함과 원고 재열기에서 원문/출처/수집/만료를 표시하며 공용 브라우저 원고 캐시에는 남기지 않습니다. 기존 일반 원고 저장 지문은 출처가 없을 때 동일하고 사진/확장 실행 방식은 보존합니다.
- 새 표/RLS/서비스 전용 한정 수정 함수, 버전 메타데이터만 DB 적용. 기존 원고·등록 계정·공용 키·권한·환경변수·Vercel Cron 일정 변경 없음. [원본 프로그램 메타데이터](evidence/blc05-source-materials/programs-before.json). `ai-auto-blog` v1.75는 읽기 비교만, 배포/중단/데이터 이관 없음.

## 실제 실패에서 고친 것 / 남은 것

1. **v2.06 첫 실제 RSS 검수 실패**: 공개 `192.0.66.108`을 기존 `/16` 내부 주소 검사로 오차단. 요청 2회 모두 AI 호출 전 거절·자료 0. 단순 로컬 HTTP 사전 확인만으로 안전 검사 동작을 확인하지 못한 한계를 보완했습니다. [IANA 특별 주소 범위](https://www.iana.org/assignments/iana-ipv4-special-registry)에 따라 `/24` 범위를 한정하고 사설/혼합 DNS/리다이렉트 재차단 회귀를 추가, v2.07 실제 성공 확인. 배포는 이번 단계 2회이며 두 번째는 이 실제 오류 수정입니다.
2. **이미지 연결 오류 미해결**: Replicate 인증/모델 사용 권한 거절. 원인을 유효하지 않은 키로 단정하지 않았으며 운영자/다른 회원 키로 대체하지 않았습니다. 이번 출처 기능 검수는 실패 후 원고/출처 보존으로 확인, 이미지 생성 성공 검수는 미완료입니다. 실제 회원 이미지 연결 작업 때 해당 본인 키/모델 권한만 확인합니다.
3. **BLC-INS-10 제안**: 일반 글 생성 뒤 이미지 자동 실행과 하단 버튼 설명 차이. BLC-06 비교에서 실행 전 비용/이미지 여부 분리를 검토하되 이번 단계는 기존 이미지 실행 방식을 변경하지 않았습니다.
4. **범위 유지**: BLOG의 NewsBlur 로그인 피드는 이전하지 않았고 원본 계정/자료/서비스를 유지합니다. 이 경로의 기능 동등성·공용 연결 전환은 BLC-14 이전 비교에서 미완료로 취급하며, 공개 RSS 추가만으로 BLOG 전체 동등/중단 완료라 표시하지 않습니다. 원래 BLC-INS-05/08/09(별칭 ID·세션 갱신 추정·원본 사진 AI 표시)는 BLC-04 인수인계대로 미확정/후속 검토, 이번 코드로 해결했다고 하지 않습니다.
