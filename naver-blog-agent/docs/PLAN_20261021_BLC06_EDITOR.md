## 구현 순서·범위

1. 비주얼 편집이 실제 발생한 경우만 코드 모드에 최신 HTML을 이어 줌. 수정 없이 왕복하면 원래 텍스트/이미지 위치 표시 보존. 코드→비주얼→코드, 링크/이미지/소제목 순서·취소/실패·늦은 응답 검증. HTML로 이어질 때 코드 모드 안내를 표시. 비공개 사진 원고의 코드 전용 제약은 유지.
2. 기존 일반 생성 화면에 ‘이번 원고 이미지도 생성’ 선택 추가(기본 켜짐으로 기존 동작 유지). 해제하면 기존 글 생성/서버 저장을 완료하고 이미지 생성 요청만 건너뜀. 나중에 기존 이미지 버튼으로 실행 가능. 생성 중 선택을 바꾸지 못하고 회원 기본 모델 저장 구조/DB/기존 계정·권한은 변경하지 않음.
3. 4단계 시각 안내·상세 설명·규칙 복사·팁/주의·공식 콘솔/설정 직링크. 코드를 입력할 때 HTML과 원본 텍스트의 차이, 저장 ACK/재열기·재검수를 안내.
4. v2.08 코드/manifest/ZIP·운영 DB 버전 메타데이터 일치, 로컬 회귀/타입/빌드 → 한 묶음 배포 → 실제 Edge 회원 모달 편집/왕복/저장/재열기·글만 생성 선택·516px 안내 확인 → 인수인계/공통 아이디어/작업목록·비교 보고서·커밋/푸시.

- 실제 모드 전환 함수/생성 실행 함수를 무료 모의 응답으로 검증: 비주얼 변경 보존, 미편집 원문 보존, 코드 수정 반영, 이미지 자동 선택 꺼짐→글 저장은 실행/이미지 요청 0, 켜짐→기존 이미지 처리, 저장 실패 시 이미지 미실행. 기존 사진·출처·원고/검수·확장 회귀와 타입/빌드.
