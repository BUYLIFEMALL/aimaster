## 2026-10-21 BLC-INS-08 — 새로고침 후 회원 세션 재확인 필요 (P1 조사)

- v2.04 배포 전 Edge의 기존 페이지는 시험 회원을 표시했으나 새로고침 직후 `/login?redirect=%2Fdashboard`로 이동했습니다. 브라우저 제어 실패가 아니라 현재 서버 인증 세션이 없는 상태입니다. 비밀번호는 사용자가 입력하므로 로그인 요청을 드렸습니다. 저장/후기 생성/실제 확장 준비는 실행하지 않았습니다.

- **원고 편집 시 자동 임시 저장(Auto-Save) 알림**:
  - 리치 텍스트 에디터에서 작성 중 30초마다 로컬 브라우저에 자동 백업하여 브라우저 종료나 새로고침 시에도 미저장 원고 복원 지원.
