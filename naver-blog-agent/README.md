# 네이버 블로그 에이전트 (Naver Blog Agent)

크롬 확장프로그램과 5단계 멀티 AI 에이전트로 봇 탐지 및 아이디 보호조치 없이 네이버 스마트에디터 ONE에 글을 자동 기획·작성·윤문·발행하는 마케팅 자동화 프로그램입니다.

- **현재 버전**: `v1.40` (`src/lib/version.ts` 및 DB `programs.version`)
- **라이브 URL**: `https://naver-blog-agent.vercel.app`
- **아키텍처**: Next.js 16 (Turbopack, App Router) + Supabase + Chrome Extension (Manifest V3)
- **인수인계 문서**: [`AGENTS.md`](./AGENTS.md) 및 [`docs/CONTINUATION.md`](./docs/CONTINUATION.md)

---

## 🚀 핵심 특징 및 주요 기능

1. **회원 브라우저 기반 확장 연동**:
   - Playwright·헤드리스 브라우저를 사용하지 않고, 회원이 직접 로그인한 **Chrome 브라우저 세션**에서 확장이 동작합니다.
   - 네이버의 정책과 에디터 변경 사항은 별도로 확인해야 하며, 발행 전 원고와 설정은 회원이 직접 검토합니다.
2. **🔥 1단계: 떡상 글감 수집소 (`/collector`)**:
   - 네이버 실시간 화제 트렌드 검색어, 네이버 뉴스 속보/이슈 기사, 타겟 URL 웹문서 3대 수집 채널을 통한 실시간 글감 발굴.
   - 수집 글감 카테고리 태깅 & 관리, **중요 글감 보관함(초록색 책갈피) 영구 보호**, '이 글감으로 포스팅 작성' 원클릭 연계.
3. **✍️ 2단계: 5단계 멀티 AI 글 생성 & 멀티 AI 이미지 스튜디오 (`/`)**:
   - **텍스트 엔진 선택**: GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro 자유 선택.
   - **멀티 AI 이미지 플랫폼**: NanoBanana(포토리얼리즘), GPT Image(DALL-E 3), FLUX 2.0, Z-Image 지원 및 본문 문맥 맞춤 프롬프트 생성/클라우드 업로드.
   - **5단계 파이프라인**: Research ➔ Writer ➔ Humanizer (17대 윤문 규칙) ➔ Reviewer ➔ Image.
   - **기본 모델 설정 저장**: 생성 시작 버튼 아래 독립 박스에서 글 엔진·세부 모델과 이미지 모델·비율·장수를 선택하고 함께 저장합니다. 회원별 DB에 보관하며 다음 접속에 자동 복원합니다. 저장 버튼은 AI 생성이나 글 발행을 실행하지 않습니다.
   - **원고 말끝·문체 설정**: 생성 버튼 위에서 말끝 4종과 문체 8종을 독립 선택합니다. 페르소나 변경에도 선택이 유지되며 폼·즉시 생성 모두 적용됩니다. 선택 시 표시되는 문장은 표현 예시이지 실제 생성 원고가 아닙니다. 작성·윤문·검수에 공통 지침이 반영됩니다. 말끝·문체는 화면별 선택값이며 모델 기본값 저장 버튼의 저장 대상에는 포함되지 않습니다.
   - **카테고리 선택**: 콘텐츠 보관함(`/queue`)·글감 수집소(`/collector`)에서 사용자가 등록한 분류 목록을 그대로 고릅니다. 네이버 계정의 실제 블로그 메뉴와는 별개입니다. 계정·페르소나를 바꿔도 선택 분류가 유지되고 생성 요청·원고 저장·편집기에 연결됩니다. 분류 선택으로 키워드·발행 목적·문체를 덮어쓰지 않습니다. 세 화면은 공통 훅과 기존 브라우저 저장 키(`nba_collector_categories`)를 공유하며 다른 탭 변경도 반영합니다. 다른 기기와 서버 동기화는 아직 지원하지 않습니다.
   - **생성 화면에서 카테고리 관리**: 선택 상자 옆 `카테고리 추가·수정·삭제 (순서 정렬)` 버튼으로 수집소·보관함과 동일한 관리 창을 엽니다. 세 화면의 분류 목록이 함께 갱신됩니다. 선택 항목의 이름을 수정하면 현재 선택도 갱신되며 삭제하면 선택만 해제합니다. 기존 원고·글감 본문 삭제나 기존 기록 분류명 일괄 변경은 하지 않습니다.
   - **기획 입력 폼 정렬**: 첫 행은 블로그 ID와 카테고리 선택·관리, 두 번째 행은 특정 주제와 발행 목적 및 독자 타깃을 나란히 배치합니다. 검색 키워드는 아래 전체 너비 행입니다. 입력 높이를 맞추고 좁은 화면에서는 세로로 배치합니다.
   - **2026년 당해 연도 3중 방어막**: 과거 연도(2023, 2024년) 퇴행 원천 차단.
   - **서버 DB 100% 자동 영구 저장 (Auto-save)**: 생성 즉시 Supabase DB 저장 및 `[최근 원고 열기]` 퀵 모달 지원.
4. **📑 3단계: 생성 원고 보관함 & 스마트 에디터 원고 편집 (`/queue`)**:
   - 서버 DB 기반 원고 보관소 (`/api/posts`), 카테고리별 탭 필터링 및 체크박스 다중 선택 일괄 이동(Bulk Move).
   - **Tiptap 기반 듀얼 스마트 에디터**: 비주얼 위지윅/코드 화면으로 제목, 서식, 본문 수정, PC 사진 드래그 첨부, ✨ AI 이미지 추가 생성 (커서 위치 삽입).
   - 스마트에디터 ONE 자동 발행 전송 큐 관리.
5. **👥 네이버 블로그 계정 연결 (`/settings`)**:
   - 다중 네이버 블로그 ID 등록·수정은 API키등록·플랫폼연동에서 관리합니다. `NaverAccountManager`는 페이지가 아닌 독립 컴포넌트입니다.
   - 불필요한 `/accounts` 화면과 작업 메뉴는 제거했습니다. 기존 주소는 `/settings`로 연결되며 저장된 계정/옛 카테고리 데이터는 유지합니다.
   - 사용자 콘텐츠 분류는 생성·수집소·보관함의 공통 관리 창에서 관리합니다. 기존 계정별 키워드/목적 설정은 현재 생성에 자동 적용되지 않습니다.
6. **🗓️ 30일 보관 및 자동 삭제(Content Retention) 정책**:
   - DB 최적화를 위해 생성 콘텐츠(글감, 원고, 이미지)는 30일간 보관 후 매일 새벽 자동 정리 (`/api/cron/cleanup`).
   - 각 항목별 `🗓️ D-xx (xx일 후 자동삭제)` 배지 안내, 보관함(초록색 책갈피) 글감은 영구 보호.
7. **좌측 사이드바 표준 Stepper 레이아웃 (`Sidebar.tsx`)**:
   - 최상단 대시보드 ➔ 1~3 번호 배지 & 세로선(떡상 콘텐츠 수집 ➔ 콘텐츠 생성 ➔ 콘텐츠 보관함) ➔ 구분선 아래 `🔑 API키등록·플랫폼연동` 및 매뉴얼/로그아웃 분리 배치.
