## 3. 범위 (권장안)

1. **열기**: `stagePolicy`에서 에이전트 명령 열기(공유·관리자·바깥 주소 관련 명령은 계속 닫음), 자동화 동작 `agent` 열기.
2. **실행 환경**: 대기열 처리를 `after()` + 회원 정시 실행 주소로 옮김. 처리 때 **에이전트 주인 회원의 키를 서버가 읽어** `withMemberAiKeys`로 감싸 실행. 한 번에 1건, 단계 수·시간 상한으로 Vercel 300초 안.
3. **비용 안전**: 처음 켤 때 비용 안내 1번(회원 본인 키로 과금됨·대략 단가), 월 상한(회원 설정, 기본값 낮게), 시간당 실행 상한(원본), 재시도 0, 키 없으면 「본인 키를 등록해 주세요」 안내.
4. **한국어화**: 에이전트 화면·템플릿·알림 문구(U11에서 발견한 자동화 화면 영어도 함께).
5. **30일 정리**: `agent_runs`·에이전트 대화 기록.
- 제외: 메일 트리거, 바깥 주소 가져오기, 회원 간 공유, MCP.

## 4. 자동화 최소 설정 지표

처음 설정 **3단계**(템플릿 고르기 → 일정·트리거 확인 → 켜기, 비용 안내 동의 포함) · 매일 조작 **0번** · 동의 **1번**(처음 켤 때 비용 안내).

## 5. 검수·비용·배포

- 시험: 연결부 통합 시험 — 회원 키로만 실행(키 없으면 막힘), 다른 회원 키·기록 안 섞임, 월 상한 도달 시 일시정지, 시간당 상한, 정시 실행 주소에서 에이전트 처리, 30일 정리. 기존 시험 전부 + 타입 검사 + 로컬 빌드.
- 운영 확인(ego, 시험 계정): 템플릿 하나로 에이전트 만들기 → 직접 실행 → 결과 페이지·알림 / 정시 실행 1번 / 사용량 표시.
- 비용: Vercel 빌드 **1~2회**. **유료 AI 시험 호출 5~10회**(시험 계정 본인 키, 저가 모델 — 시험 계정 OpenAI 키는 잔액 없음, Claude·Gemini 키로). 실행 전에 다시 보고합니다.
- DB: 원본 표(`agent_runs` 등)는 워크스페이스 스키마에 이미 있음 — 새 운영 표가 필요해지면 추가만 하는 SQL로 미리 보고.
- 버전: v1.24(코드·DB).
