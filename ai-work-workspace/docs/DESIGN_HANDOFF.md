## 1. 디자인 컨셉 및 스타일 가이드

- **프로그램 성격 분석**:
  - 기존의 단조로운 무채색 텍스트 중심 블록 에디터에서, **41종 블록 에디터 + 12종 스마트 데이터베이스 뷰 + 회원 본인 키 기반 지능형 AI 비서(Ask AI / Write with AI)**가 유기적으로 융합된 **실리콘밸리 하이테크 감성의 스마트 오피스 워크스페이스**로 전면 리뉴얼.
- **배경색 및 메인 테마**:
  - **라이트 모드 (기본)**: 퓨어 웜 슬레이트 (`#f8fafc`) + 클린 화이트 (`#ffffff`), 은은한 24px 모눈 그리드 패턴 (`linear-gradient` 투명 격자선), 부드러운 테두리 (`#e2e8f0`).
  - **다크 모드**: 딥 옵시디언 나이트 (`#0b0f17`) + 다크 서피스 (`#131926`, 테두리 `#222f46`).
- **브랜드 및 포인트 컬러**:
  - `--brand-primary: #4f46e5` (**스마트 인디고**): 주요 액션 버튼, 활성 탭, AI 비서 발광 테두리, 포커스 링
  - `--brand-violet: #8b5cf6` (**일렉트릭 바이올렛**): AI 자동화 배지, 그라데이션 글로우
  - `--brand-emerald: #10b981` (**프로덕티브 에메랄드**): 실시간 클라우드 동기화 완료(`● 저장됨`), 할 일 완료 체크, 성공 배지
  - `--brand-amber: #f59e0b` (**포커스 앰버**): API 키 미연동 알림, 즐겨찾기 별표, 중요 공지

## 2. 시그니처 컴포넌트 및 레이아웃 구조

### 1) 온보딩 웰컴 퀵스타트 허브 (`src/litpage/web/features/page/GetStartedBar.tsx`)
- **초보자 눈높이의 빈 페이지 웰컴 카드 4종 탑재**:
  1. `📝 회의록 템플릿`: 일시/참석자/안건 1초 자동 생성.
  2. `🗂️ 프로젝트 보드`: 할 일 · 진행 중 · 완료 3단 칸반 데이터베이스 원클릭 생성.
  3. `📊 업무 스프레드시트`: 속성 필터, 정렬, 집계 기능 표 데이터베이스 즉시 구성.
  4. `⚡ 템플릿 둘러보기`: 사내 위키, 기획서, 회고 템플릿 갤러리 팝업 연결.
- **하단 도구 칩 바**:
  - `[✨ AI 비서와 시작하기]`, `[🗂️ 데이터베이스]`, `[⚡ 템플릿 갤러리]`, `[외부 파일 가져오기 (Markdown·CSV)]`, `[••• 더보기]`.

### 2) 상단 툴바(Topbar) 퀵 액션 그룹 (`src/litpage/web/features/shell/Topbar.tsx`)
- `[🔑 AI 비서 연동]`: 클릭 시 `/settings/keys`로 즉시 연결되어 API 키 상태 확인 및 등록 가능.
- `[📖 사용 가이드]`: 클릭 시 `/guide` 3분 마스터 가이드북으로 원클릭 이동.
- `[● 저장됨]`: 에메랄드 인디케이터를 통해 클라우드 동기화 상태 실시간 제공.

### 3) 좌측 사이드바(Sidebar) 브랜드 강화 (`AimasterSidebar.tsx`, `aimaster.css`)
- **상단 헤더**: `🏢` 브랜드 아이콘 박스, `AI 업무 워크스페이스` 타이틀, `v1.10` 인디고 알약 배지 부착.
- **하단 유틸리티 카드**: `🔑 API키등록·AI연동`, `📖 연동 & 사용 매뉴얼`을 카드형 서피스로 묶어 시인성 극대화.
- **계정 정보**: 실시간 연결 상태 초록 점(`●`)과 이메일, 세련된 로그아웃 버튼 배치.

### 4) 공식 표준 로그인/회원가입 화면 (`src/app/login/page.tsx`, `globals.css`)
- `DESIGN.md` 규칙 14번 100% 준수:
  - 24px 모눈 격자 배경 및 `max-w-[440px]` 중앙 카드.
  - 상단 알약형 `[로그인]` / `[회원가입]` 2버튼 탭 토글 바.
  - 이메일(Mail), 비밀번호(Lock + "비밀번호 찾기?"), 풀 위드 스마트 인디고 액션 버튼.
  - 약관 푸터 및 회원가입 모드 전환 시 AIMaster 회원가입 직링크 제공.

### 5) 독립 비주얼 가이드북 (`src/app/guide/page.tsx`, `guide.css`)
- **8대 매뉴얼 표준 규격 완벽 적용**:
  - 헤더 메타데이터 바(소요시간 3분, 난이도, 바로가기 버튼).
  - 개요 히어로 카드(고화질 썸네일 + 3대 배지).
  - Step 1~4 시각화 카드(단계별 태그 및 요약).
  - **하이테크 키보드 키캡 치트시트 (`kbd`)**: `/`, `Ctrl+K`, `Ctrl+Z`, `[]` 등을 실제 키캡 형태로 시각화.
  - **FAQ 5종 골드/인디고 아코디언 인터랙션 (`FaqAccordion.tsx`)**.
