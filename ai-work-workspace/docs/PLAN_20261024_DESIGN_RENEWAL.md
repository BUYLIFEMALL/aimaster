## 1. 프로그램 성격 및 기능 사전 심층 분석 (최상위 불변 원칙 0-①)

### 1.1 프로그램 구동 메커니즘 및 아키텍처 본질
1. **웹 SPA 기반 단독 올인원 워크스페이스**:
   - 별도 로컬 설치나 크롬 확장 없이 브라우저 내에서 즉시 구동되는 **Next.js 16 (App Router) + React 19 기반의 노션(Notion)형 업무 공간**.
   - 41종 블록 편집기(`/` 단축키, 마크다운 실시간 변환, 드래그앤드롭 블록 재배치)와 12종 데이터베이스 뷰(표, 칸반 보드, 갤러리, 캘린더, 타임라인 등)를 제공.
2. **회원 본인 키 기반 지능형 AI 비서 연동**:
   - OpenAI, Anthropic Claude, Google Gemini 등 회원 본인이 등록한 API 키(`user_api_keys`)를 사용하여 문서 초안 작성, 회의록 요약, 브레인스토밍, 문체 다듬기를 지원.
3. **완벽한 회원별 데이터 격리 및 보안**:
   - Supabase 공용 DB 내 전용 격리 스키마(`aww`)를 사용하며, 회원마다 고유 워크스페이스를 자동 생성하여 타 회원과 데이터가 절대 섞이지 않음.
4. **사용자 타깃 및 심리적 요구**:
   - 회의록, 업무 위키, 프로젝트 일정을 정리하는 1인 사업자, 직장인, 팀 리더.
   - 복잡하거나 삭막한 화면 대신 **"업무에 완벽히 몰입할 수 있으면서도 세련되고 직관적인 현대적 오피스 감성"**을 원함.

## 2. 현행 UI/UX의 5대 핵심 문제점

1. **단조롭고 삭막한 원본 오픈소스 무채색 스타일**:
   - 원본 `litpage`의 기본 CSS 토큰(`--lp-*`)이 그대로 노출되어 밋밋한 텍스트 위주 구성으로, AIMaster 플랫폼의 타 전문 스튜디오(시네마틱 렌더, 포커스 스튜디오 등) 대비 시각적 완성도와 브랜드 아이덴티티가 부족함.
2. **초보자 온보딩 및 웰컴 허브 부재**:
   - 처음 접속했을 때 빈 화면만 덩그러니 놓여 있어, 초보자가 회의록을 써야 할지, 프로젝트 보드를 만들어야 할지 즉시 알기 어려움.
3. **비표준 로그인 화면 (`app/login/page.tsx`)**:
   - `DESIGN.md` 규칙 14번인 "공식 표준 탭 토글 레이아웃 (로그인/회원가입 탭, 24px 격자 모눈 배경, 풀 위드 버튼)"을 따르지 않고 단순 텍스트 카드 형태로 방치되어 있음.
4. **상단 툴바 및 사이드바의 시각적 위계 약화**:
   - `[🔑 API키등록]`, `[📖 사용 매뉴얼]`, `[⚡ 템플릿 갤러리]` 등 핵심 액션이 사이드바 하단에만 숨겨져 있어 빠른 접근성이 떨어짐.
5. **매뉴얼(`/guide`) 페이지의 비주얼 강화 여지**:
   - 4단계 카드와 단축키 상자가 단순 나열식으로 되어 있어, 현대적인 키캡 치트시트 뷰어와 인터랙티브 아코디언으로의 고도화가 필요함.

## 3. 리뉴얼 디자인 컨셉 및 스타일 템플릿

### 3.1 템플릿 고유 명칭: **「13. 프로 워크스페이스 스튜디오 스타일 (Pro Workspace Studio Style)」**
- **디자인 철학**:
  - **"복잡한 업무를 가장 직관적이고 아름답게 정리하는 스마트 오피스"**
  - 군더더기 없는 미니멀리즘과 하이테크 생산성 툴(Linear, Notion, Raycast)의 장점을 결합하여, 업무 피로도를 최소화하고 집중도를 극대화.

### 3.2 컬러 시스템 및 테마 스펙
- **라이트 모드 (기본 업무 테마)**:
  - 메인 배경: 퓨어 웜 슬레이트 (`#f8fafc`) 및 클린 화이트 (`#ffffff`)
  - 모눈 배경: 은은한 24px 모눈 그리드 패턴 (`linear-gradient(to right, rgba(0,0,0,0.03) 1px, transparent 1px)`)
  - 카드 서피스: 퓨어 화이트 (`#ffffff`), 테두리 `#e2e8f0`, 부드러운 그림자 `0 4px 20px -2px rgba(0, 0, 0, 0.05)`
- **다크 모드 (야간 몰입 테마)**:
  - 메인 배경: 딥 옵시디언 나이트 (`#0b0f17`)
  - 카드 서피스: 딥 차콜 네이비 (`#131926`), 테두리 `#222f46`
- **시그니처 포인트 컬러**:
  - `--brand-primary: #4f46e5` (스마트 인디고): 주요 액션 버튼, 활성 탭, AI 비서 발광 테두리
  - `--brand-violet: #8b5cf6` (일렉트릭 바이올렛): AI 자동화, 템플릿 마커
  - `--brand-emerald: #10b981` (프로덕티브 에메랄드): 실시간 저장 완료, 할 일 체크, 성공 칩
  - `--brand-amber: #f59e0b` (포커스 앰버): API 키 연동, 즐겨찾기, 중요 공지

## 4. 세부 화면별 5단계 리뉴얼 실행 계획

### Step 1. 공식 표준 로그인/회원가입 레이아웃 전면 이식 (`src/app/login/`)
- `DESIGN.md` 규칙 14번 공식 기준(`threads-comment-reply/app/(auth)/login/page.tsx`) 100% 동일 적용:
  - 24px 은은한 격자 모눈 배경 + `max-w-[440px]` 중앙 반응형 카드.
  - 상단 알약형 `[로그인]` / `[회원가입]` 2버튼 탭 토글 바.
  - 이메일/비밀번호 필드 아이콘(Mail, Lock) 및 "비밀번호 찾기?" 링크.
  - 브랜드 인디고 컬러 풀 위드 `로그인 ->` 액션 버튼 및 호버 애니메이션.
  - 회원가입 탭 클릭 시 AIMaster 회원가입 안내 및 직링크 버튼 제공.

### Step 2. 온보딩 웰컴 퀵스타트 허브 구축 (`WelcomeHub.tsx`)
- 빈 워크스페이스 또는 홈 진입 시 상단에 노출되는 **「스마트 업무 퀵스타트 허브」** 신설:
  1. `📝 회의록 템플릿` (일시/참석자/안건/결정사항 1초 생성)
  2. `🗂️ 프로젝트 칸반 보드` (할 일 / 진행 중 / 완료 3단 보드)
  3. `📚 사내/개인 업무 위키` (구조화된 계층형 문서)
  4. `✨ AI 비서와 글쓰기` (주제만 입력하면 초안 자동 작성)
- 원클릭으로 해당 템플릿 블록을 즉시 삽입하고 작업을 시작할 수 있도록 구현.

### Step 3. 상단 툴바(Topbar) 및 좌측 사이드바(Sidebar) 비주얼 고도화
- **상단 툴바 (`Topbar.tsx`)**:
  - `[🔑 AI 연동 상태 칩]` (API 키 등록됨: 초록 불 / 미등록: 앰버 불 클릭 시 `/settings/keys` 팝업 이동).
  - `[📖 3분 사용 매뉴얼]` 퀵 버튼 배치.
  - 현재 열려 있는 문서의 상태(실시간 저장됨 `● Saved`) 인디케이터 탑재.
- **좌측 사이드바 (`AimasterSidebar.tsx`, `Sidebar.tsx`)**:
  - 상단 헤더: `AI 업무 워크스페이스` 타이틀에 세련된 그라데이션 배지 및 버전 칩 부착.
  - 메뉴 아이템에 시인성 높은 이모티콘 및 아이콘 컬러화.
  - 하단 유틸리티: `🔑 API키등록`, `📖 연동 & 사용 매뉴얼`, 계정 카드를 고급스러운 서피스 박스로 정돈.

### Step 4. 독립 비주얼 가이드북 (`src/app/guide/`) 전면 고도화
- `docs/MANUAL_AND_INTEGRATION_GUIDELINES.md` 표준 8대 템플릿 완벽 적용:
  - **헤더 메타 바**: 📖 아이콘, 소요시간(약 3분), 난이도(초급), 바로가기 액션 버튼.
  - **개요 히어로 카드**: 고화질 실사 썸네일 + 3대 핵심 가치 칩.
  - **4단계 시각화 카드 (Step 1~4)**: 카드형 일러스트 및 단계별 핵심 요약.
  - **하이테크 키캡 치트시트 (Keyboard Shortcuts Hub)**: `/`, `Ctrl+K`, `Ctrl+Z`, `[]` 등을 실제 키보드 키캡 모양(`kbd`)으로 시각화하여 1초 만에 외울 수 있도록 배치.
  - **FAQ 5종 골드 아코디언 인터랙션**: 자주 묻는 질문 즉각 토글.

### Step 5. 모바일(375px~390px) 반응형 완벽 대응 & 포그라운드 실세션 검수
- 햄버거 메뉴(`☰`) 터치 반응성 보강 및 슬라이드 드로어 애니메이션 최적화.
- 모바일 뷰포트에서 가로 스크롤 넘침(overflow-x) 전면 차단.
- Microsoft Edge 포그라운드(화면 노출)로 데스크톱(1440px) 및 모바일(375px) 실세션 검수.

## 5. 비용 및 리스크 관리

- **테스트 및 빌드 비용**:
  - UI/UX 리뉴얼 작업은 순수 프론트엔드 React/CSS/컴포넌트 작업으로 **유료 AI API 호출 비용 0원 (비용 발생 없음)**.
  - Vercel 배포 빌드는 작업 완료 후 1회만 단독 순차 배포하여 추가 동시 빌드 비용 방지.
- **데이터베이스 보존**:
  - 기존 회원 데이터 및 `aww` 스키마 테이블 구조는 일체 변경하지 않으며 100% 안전하게 유지.
