# 에이전트(정시 실행) 바깥 MCP 연결 열기 — 개발 플랜 (2026-11-16)

## 1. 지금 상태 (코드 확인)
- 에이전트 자체·정시 실행(트리거 `recurrence` 등)은 U12(2026-11-10)에서 열려 있음.
- 닫힌 것: 에이전트 연결 명령 4개 `addAgentConnection`·`refreshAgentConnection`·`updateAgentConnection`·`removeAgentConnection`(`src/server/stagePolicy.ts` `AGENT_CLOSED_RPCS`), MCP 프리셋.
- 원본의 안전장치(`src/litpage/server/agents/tools.ts` `mcpTool`): 도구마다 모드가 있음 — 읽기 도구 기본 「자동」, 쓰기 도구 기본 「확인」. 회원이 없는 실행(정시·이벤트)에서 「확인」 도구는 실행하지 않고 실행 기록에 「검토 필요」로 남김 → 회원이 「허용」을 누르면 그 호출만 다시 실행.
- 빈틈 두 가지
  1. 회원이 쓰기·삭제 도구를 「항상 허용」으로 바꾸면 회원이 없을 때도 바로 실행됨.
  2. 호출 한도(`aimasterMcpGuard.ts` 1분 30번·하루 500번)가 `callMcpTool(ownerId)`의 `ownerId`로 세는데, 에이전트는 이 값이 회원이 아니라 에이전트 봇 id → 에이전트를 여러 개 만들면 한도를 넘길 수 있음.

## 2. 할 일
1. 에이전트 연결 명령 4개 엶. 프리셋·에이전트 공유는 계속 닫음.
2. 회원이 없는 실행에서는 쓰기·삭제 도구를 「항상 허용」으로 해 두었어도 「검토 필요」로 멈춤(읽기 도구만 혼자 실행). 회원이 채팅으로 에이전트와 대화할 때는 지금처럼 회원 설정을 따름.
3. 호출 한도를 에이전트 주인 회원 기준으로 셈 — 채팅과 에이전트가 같은 하루 500번을 나눠 씀.
4. 에이전트 연결 화면·실행 기록의 영어 문구 중 이번에 회원 눈에 처음 보이는 것 한국어화(「Awaiting your approval」 등 사전에 없는 것만).
5. 매뉴얼에 「에이전트에 바깥 MCP 연결하기」 안내(읽기는 혼자, 쓰기는 검토 필요로 멈춤).
6. 시험: 연결 명령 열림·프리셋 닫힘, 혼자 실행에서 「항상 허용」 쓰기 도구가 멈추는지, 한도가 회원 기준인지.
