# 2026-11-15 할 일 플래너 2번 — 표에서 여러 행 보내기·중복 보내기 막기 ([역할: workspace])

주인님 지시: 「진행해」(플래너 2번 「워크스페이스 → 플래너 보내기」 중 빠진 범위부터).

## 확인한 현재 상태 (v1.19 U8-B부터)
- 페이지 「⋯」 → 「📨 다른 프로그램으로 보내기」 → 할 일 플래너: 체크 안 된 할 일 항목(최대 30개) / 이 페이지를 할 일 하나로.
- 빠진 것: ① 표 보기에서 여러 행을 한 번에 보내기(행 페이지를 하나씩 열어야 했음) ② 같은 항목을 다시 보내면 플래너에 중복으로 쌓임(개선 인수인계 20261025 §6 「같은 항목 다시 보내기 막기」).

## 구현
1. 표 행 「•••」 메뉴·여러 행 선택 막대 「•••」에 「📨 할 일 플래너로 보내기 (N개)」 — 서버 `workInboxSendToPlanner` `mode: "rows"`, `pageIds` 최대 50개, 행마다 `pageAsTask`(마감일·우선순위). 회원 본인 공간의 행만.
2. 중복 막기: 보내기 전 공용 표 `work_inbox`에서 회원 본인·보낸 곳 워크스페이스·받는 곳 플래너·아직 안 가져간 줄의 (원본 주소, 제목)을 읽어 같은 항목과 묶음 안 겹침을 건너뜀(`skipPendingPlanner`·`plannerKey`). 알림 「할 일 N개를 보냈습니다 · 이미 대기 중인 M개는 건너뜀」. 페이지 메뉴 두 방식에도 적용.
3. 화면 보내기 함수를 `features/page/sendToPlanner.ts`로 빼서 페이지 메뉴·행 메뉴가 함께 씀. 선택 막대 「N selected」→「N개 선택됨」, 행 메뉴 제목 「N pages」→「N개 페이지」. 매뉴얼 카드 갱신.
