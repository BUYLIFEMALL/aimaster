## A. 공개 폼 (구현 2026-11-15)
- 원본에 있던 것: 폼 대상(워크스페이스 사람만 / 누구나), 익명 응답, 응답 한도(응답자 분당 30·폼 분당 600), 응답 사본 메일.
- 결정(권장안 그대로): ① 응답자(IP)당 1분 5번·폼당 하루 300건 ② 개인정보 수집·이용 동의 필수(수집 항목은 질문에서 자동, 목적·보관 기간은 회원이 공유 메뉴에서 고침) ③ 응답 사본 메일 닫음 ④ 응답 파일 올리기 닫음(원본이 익명 응답에서 이미 막음) ⑤ 검색 노출 안 함(noindex).
- 구현
  - 로그인 없는 화면 `/form/<폼 보기 id>`(`src/app/form/[...path]/page.tsx`): 이 프로그램 회원이면 원래 입구, 아니면 회원 이메일을 비워 공개 입구로(`api.ts isPublicView`).
  - 공개 입구 `/api/public`에 폼 명령 3개(`getPublicForm`·`submitFormResponse`·`awwReportPublicForm`) — 판정 `src/server/publicForms.ts`(공개 폼만, 관리자 내리기 `aww_public_takedowns` 키=폼 보기 id, 주인 이용 기간, 동의·한도 `aww_public_form_usage`).
  - 회원 입구(`runtime.ts`): 남의 공개 폼에 응답할 때도 같은 동의·한도(`memberFormGate`). `stagePolicy`에서 폼 보기·제출 엶, `emailFormResponse`는 계속 닫음.
  - 화면: 응답 화면 아래 「개인정보 수집·이용 동의」(받는 곳·항목·목적·보관 기간, 체크해야 제출), 공유 메뉴에 목적·보관 기간 입력, 관리자 「공개 페이지」 목록에 「📝 폼: …」 + 내리기·신고, 키 화면 「오늘 쓴 횟수」에 공개 폼 응답(가장 많은 폼).
- 검수: 시험 186(이번 5개: 공개 폼만 열림·동의 문구·사본 메일 꺼짐, 동의 없으면 거절·동의하면 주인 표에 행, 1분 5번, 내리기·이용 기간 종료·신고, 다른 회원도 동의 필요), tsc, 로컬 빌드.
- 남은 한계: 응답자 IP 기준 한도라 같은 회사망(IP 하나)의 여러 사람은 1분 5번을 나눠 씀.
