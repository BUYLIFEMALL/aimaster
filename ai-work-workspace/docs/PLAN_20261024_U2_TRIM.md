## 2. 그대로 두는 것
- 템플릿 갤러리 창, 가져오기·내보내기, 휴지통, 버전 기록, 위키 확인, 스프린트, 화면 안 알림함.
- 설정 「일반」·「멤버」·「팀 공간」·「사이드바」·「가져오기」·「보안」·「감사 기록」 등 관리 화면(협업 단계 전이라 대부분 혼자 쓰지만 기능은 정상).
- 이미 만들어진 회원 데이터(지도 보기, 게시 설정이 있던 페이지 등)는 지우거나 바꾸지 않는다.

## 3. 구현 순서
1. `trimPolicy.ts`에 숨김 목록 정의(설정 탭 키, 사진 탭, 보기 종류, 마켓플레이스 경로).
2. 설정 탭: `visible()`에 숨김 목록 확인 추가. 「내 계정」 탭은 안내 화면으로 교체.
3. 공유 메뉴 게시 탭, 마켓플레이스 경로·버튼, 계정 추가·전환, 알림 메일 묶음 숨김.
4. 사진·표지 고르기: AI·Unsplash·GIPHY 탭 빼고 「AI 이미지 자동화에서 만들기 ↗」 링크 추가.
5. 지도 보기: 보기 추가 목록·대시보드 위젯 종류에서 제외.
6. 업그레이드 버튼·배지 숨김(9개 파일, 각 줄에 「이식판: U2」 주석).
