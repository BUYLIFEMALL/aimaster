## 1. 기능 1 — 간이영수증·거래명세서 발행 (쉬움, 먼저)

| 항목 | 내용 |
|---|---|
| 입력 | 공급자(내 사업자: 상호·사업자번호·대표·주소·업태·종목 — 회원별 1회 저장), 공급받는자, 품목(여러 줄: 품명·수량·단가·금액·날짜), 합계(자동·부가세 포함/별도 선택) |
| 출력 | 간이영수증·거래명세서 서식을 채워 **PDF 생성**(브라우저에서 생성, 회원 본인 다운로드). 회원별 발행 이력 저장(번호·날짜·거래처·금액) |
| 저장 | 회원 사업자 정보·발행 이력은 회원별(스키마 `aww`, owner-only). 생성 PDF는 회원이 받고 서버 장기 보관은 안 함(또는 30일) |
| 비용 | AI·외부 호출 없음. 서버 비용 없음 |
| 주의 | 「간이영수증은 법정 세금계산서가 아니다」를 화면에 명시. 실제 세금 신고용은 기능 2 |

## 2. 기능 2 — 홈택스 전자세금계산서 발행 자동화 (복잡, 법·보안 주의)

전자세금계산서는 **국세청 홈택스(또는 공인 대행)**를 통해서만 법적 효력이 있다. 방식을 둘로 나눠 본다.

### 2-1. 방식 비교
| 방식 | 내용 | 장점 | 단점·위험 |
|---|---|---|---|
| **ⓐ 홈택스 화면 자동 입력(회원 PC 확장)** | 회원이 본인 공인인증서로 홈택스에 로그인한 상태에서, 우리가 만든 입력값을 홈택스 세금계산서 작성 화면에 자동으로 채움 | 별도 계약·비용 없음, 회원 본인 공인 발행 | 홈택스 화면·보안모듈이 자주 바뀜, 자동화가 약관·보안프로그램(키보드 보안 등)과 충돌 가능, 공인인증서 취급 민감 |
| **ⓑ 전자세금계산서 발급대행 API(국세청 승인 사업자)** | Popbill·바로빌 등 **국세청 공인 발급대행사 API**로 발행(회원이 그 서비스 가입·본인 키) | 안정적·법적 효력 확실·공식 지원 | 회원이 대행사 가입·요금(건당), 우리는 연동만 |
| **ⓒ 홈택스 「엑셀 일괄 발급」 양식 만들어 주기** | 홈택스가 제공하는 대량 발급용 엑셀 양식에 맞춰 파일을 만들어 주고, 회원이 홈택스에 직접 업로드 | 자동 입력·인증서 안 건드림, 가장 안전 | 업로드는 회원이 수동, 완전 자동은 아님 |

### 2-2. 제안 (안전 우선)
- **1순위 ⓒ(엑셀 일괄 발급 양식) + 2순위 ⓑ(발급대행 API)**를 권한다.
  - ⓒ: 우리가 거래 정보를 입력받아 **홈택스 일괄 발급 엑셀**을 정확히 만들어 주면, 회원이 홈택스에 올려 한 번에 발행. 인증서·화면 자동조작이 없어 안전하고 약관 충돌이 적다.
  - ⓑ: 더 자동화를 원하면 회원 본인 Popbill/바로빌 계정·키를 연동해 API로 발행(요금은 회원 부담, 회원 본인 계정 — 최상위 규칙과 맞음).
- **ⓐ(홈택스 화면 직접 자동화)는 보수적으로.** 공인인증서·보안모듈·약관 때문에 위험이 크다 — 주인님이 꼭 원하면 회원 PC 확장으로, 회원 본인 로그인·회원 책임·고지 전제(마케팅 예외 지침 §3 방식과 같은 원칙)로만.

### 2-3. 공통
- 회원별 사업자 정보·공급받는자 주소록·발행 이력(회원별, owner-only). 세금계산서 필수 항목(공급자·공급받는자 사업자번호·작성일자·공급가액·세액·품목) 검증.
- AI는 품목명 정리·거래처 자동 완성 정도만(회원 본인 키, 선택).
- **법적 책임·세무 정확성은 회원에게** 있음을 고지(우리는 입력·양식·연동 도구).

## 2-4. 기능 3 — 거래처·항목 등록 + 📷 사진으로 자동 세금계산서 발행 (2026-10-27 주인님 지시, 핵심 편의 기능)

주인님: 「사업자명·금액 등 기본 세금계산서 발행 항목을 등록하거나, 해당 이미지를 사진 찍어 올리면 자동 세금계산서까지 발행해 주는 자동화. 자주 쓰고 편한 기능.」

| 항목 | 내용 |
|---|---|
| ① 자주 쓰는 항목 등록 | 내 사업자 정보, **거래처 주소록**(상호·사업자번호·대표·주소·이메일), 자주 쓰는 품목·단가를 미리 등록 → 발행 때 고르기만 하면 자동 채움 |
| ② 📷 사진으로 자동 입력 | 영수증·거래명세서·명함·견적서 등을 **사진으로 찍어 올리면** 회원 본인 AI 키(Gemini/OpenAI 비전)로 글자를 읽어(OCR) **공급받는자·품목·금액·날짜를 자동 추출** → 발행 항목에 자동 채움 |
| ③ 확인 후 발행 | 자동 채운 값을 **회원이 화면에서 확인·수정**한 뒤, 기능 2 방식(ⓒ 홈택스 일괄 엑셀 / ⓑ 발급대행 API)으로 세금계산서 발행. 등록된 거래처면 사업자번호·주소 자동 매칭 |
| 흐름 요약 | 사진 올리기 → AI가 읽어 자동 입력 → 회원 확인·수정 → 세금계산서 발행 (반복 거래는 거래처·품목 등록으로 더 빨라짐) |
| 안전 | 자동 추출은 틀릴 수 있으므로 **반드시 회원 확인 단계**를 거친다(바로 발행하지 않음). 사진·추출 결과는 회원별 저장(owner-only), 민감 정보라 발행 뒤 정리(기본 30일). AI는 회원 본인 키 |
| 비용 | 사진 1장당 회원 본인 AI 비전 호출(수 원~수십 원, 회원 키). 운영자 비용 없음 |

이 「사진 → 자동 발행」이 주인님이 말한 「자주 쓰고 편한」 핵심 기능이다. 등록(①)으로 반복 입력을 줄이고, 사진(②)으로 1장만으로 발행 준비가 끝나게 한다.
