# 플랜 — 실거래가 비교 (v1.19, 2026-10-25)

주인님 선택: 남은 작업 중 「📈 실거래가 비교」, 키는 「회원 본인 키 + 없으면 운영자 공용 키(추천)」. PC 프로그램은 「사용자가 설치해야 하면 패스」(제외). AI 시세 요약은 다음 순서.

## 조사
- 기존 `real_estate_sales` 실거래는 **서울 열린데이터(서울만)** → 일산 등 경기 단지는 없음 → **국토교통부 아파트 매매 실거래가(공공데이터포털, 전국)** 사용.
- 단지 위치: 지역 감시는 `cortar_no`(법정동 10자리) 보유, 단지 감시는 확장이 단지 화면 응답(`/api/complexes/…`)에서 `cortarNo`를 줍고, 없으면 탭 안에서 단지 정보를 한 번 부름 → 회원 PC `complexInfo`에 기억. 앞 5자리 = 시군구(LAWD_CD).

## 구현
- 서버 `app/api/extension/trades/route.ts`: 확장 연결 코드 확인 → 「단지 이름 + 시군구」만 받아 최근 6개월 조회(지역 10곳·단지 30곳 상한) → `lib/trades.ts`로 이름 맞추기(띄어쓰기·「아파트」·괄호 무시, 포함 관계)·해제 거래 제외·면적(반올림 ㎡)별 ㎡당 중간값. 저장 안 함.
- 확장: `collector.js` `findCortarNo`·`needLocation`, `background.js` `attachTradeGaps`(하루 1번 조회·회원 PC `tradeCache` 30일 정리) → 매매 매물에 「실거래 대비 +8%」(±3㎡ 가장 가까운 면적대), 엑셀 칸·텔레그램·메일에도 표시, 통계 요약에 단지별 평균.
- 웹: 결과 표·변동 기록·단지 비교표 「실거래 대비」(파란 ▲ 높음 · 빨간 ▼ 낮음 — 가격 변동과 같은 색), 설정 「🏛 공공데이터 키(선택)」 카드, 매뉴얼 질문.
