## 1. 실제로 막힌 곳 (2026-10-25 시험)
| # | 막힌 곳 | 원인 |
|---|---|---|
| 1 | 단지를 어떻게 추가하는지 모름 | 「네이버 단지 화면 주소」를 알아야 하는데, 검색 목록 주소에는 단지 번호가 없음 |
| 2 | 팝업 「이 단지 감시 추가」가 안 켜짐 | 지도·검색 목록 상태에서는 단지 번호가 없음 → 단지를 눌러 연 뒤 팝업을 **다시 열어야** 함(알기 어려움) |
| 3 | 해야 할 순서를 모름 | 확장 설치·연결·텔레그램·단지·예약이 메뉴 5곳에 흩어짐, 어디까지 했는지 안 보임 |
| 4 | 화면에 낯선 말 | 「단지 번호」「연결 코드」「complexes/숫자」 |

## 2. 바꿀 것
| # | 무엇 | 어떻게 |
|---|---|---|
| A | **🚀 시작하기 체크리스트**(대시보드 맨 위) | 5단계 ① 확장 설치 ② 웹과 연결 ③ 텔레그램 연결 ④ 단지 추가 ⑤ 예약 켜기 — 각 단계가 자동으로 ✅(설치·연결은 확장에 물어보고, 나머지는 저장값). **다음 할 일 버튼 하나만 크게** 보여 준다. 다 끝나면 접히고 「🖥 내 PC 수집」 상태가 맨 위로 |
| B | **네이버 단지 화면 위에 「➕ 매물 알림에 추가」 버튼**(확장) | 회원이 네이버 부동산에서 단지를 열면 화면 오른쪽 아래에 초록 버튼이 떠 있다. 누르면 바로 추가(번호·주소를 몰라도 됨). 이미 추가한 단지면 「✅ 감시 중」. 지도·목록 상태면 「단지를 눌러 열면 추가할 수 있어요」 작은 안내. 매물 데이터는 읽지 않고 주소의 단지 번호만 씀(§0 그대로) |
| C | 감시 대상 화면 단순화 | 맨 위 큰 버튼 「🏠 네이버 부동산에서 단지 찾기」 + 그림 3장(①검색 ②단지 누르기 ③초록 버튼). 주소 붙여 넣기는 「직접 입력」 접는 칸으로. 가격·면적 조건은 「조건 더 정하기」 접기 |
| D | 확장 팝업 정리 | 맨 위 상태 한 줄(「✅ 준비 완료 · 2곳 감시 중 · 다음 수집 14:00」 또는 「⚠ 텔레그램 연결이 필요해요 → 바로가기」), 큰 버튼 2개(🔍 지금 수집 / 🏠 네이버 부동산 열기), 나머지는 작게 |
| E | 쉬운 말로 바꾸기 | 「단지 번호」 → 「단지」, 「연결 코드」 → 표시 안 함, 오류 문구는 「무엇을 하면 되는지」로 |
| F | 매뉴얼(`/guide`) | 위 흐름 그대로 Step 1~5 그림 카드 + 자주 막히는 곳 FAQ(「추가 버튼이 안 보여요」) |
