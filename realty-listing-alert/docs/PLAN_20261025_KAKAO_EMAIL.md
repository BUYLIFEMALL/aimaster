# 개발 플랜 — 카톡 받기 · 이메일 받기 (2026-10-25, [역할: realty] `claude-win-20261024-realty`)

> 대상: ① AIMaster 운영(ref `esgxyikcnnvmlhygjkth`). 지금 v1.07. 주인님 결정: 카톡은 요약만(파일 불가), 이메일은 **방식 A**(회원 본인 메일 발송 키, 확장이 회원 PC에서 직접 보냄 — 서버 SMTP 경유 안 함).
> 절대 결정(§0) 유지: 매물 내용은 서버를 거치지 않는다. 회원 본인 계정·본인 키만 쓴다.

## 1. 지금 있는 것(재사용)
| 무엇 | 위치 | 쓰는 법 |
|---|---|---|
| 공용 카카오 계정(「나에게 보내기」 `talk_message`) | `member_platform_accounts`(platform `kakao`), 기준 `lib/memberIntegrations.ts` | 「카카오 자동화」(`kakao-auto-posting`)에서 회원이 **본인 카카오 앱 REST 키**로 한 번 연결 → 다른 프로그램이 읽음 |
| 카카오 토큰 갱신 | `kakao_auto_poster/src/lib/kakao/account.ts`·`client.ts` | 회원 본인 REST 키(`user_api_keys.kakao_rest_api_key`)로만 갱신, 같은 앱일 때만 공용 토큰 사용 |
| 회원 키 저장 | `user_api_keys` + `resolveApiKey()`(폴백 없음) | 새 항목 `resend_api_key` 추가 |

## 2. 카톡 받기(요약만)
1. **연결**: 공용 카카오 계정을 그대로 쓴다. 없으면 「💬 카카오 자동화에서 한 번 연결해 주세요」 안내 + 바로가기(공용 연동 규칙).
2. **발송 경로(매물이 서버를 안 거치게)**: 수집이 끝나면 확장이 웹 API `/api/extension/kakao-token`(확장 연결 토큰 확인)에 **회원 본인 카카오 access token**을 요청 → 서버는 만료 직전이면 회원 본인 REST 키로 갱신해서 돌려줌 → **확장이 `kapi.kakao.com` 「나에게 보내기」를 직접 호출**.
3. **내용**: 「🏠 [매물 알림] 신규 3 · 가격 내림 1 · 사라짐 2 (백송건영 외 2곳)」처럼 200자 안 요약 + 「결과 보기」 버튼(웹 최근 결과). 파일은 못 보내므로 안내 문구에 「엑셀 파일은 텔레그램·이메일로」.
4. 차단·하루 한도 알림도 카톡으로 함께(켜 둔 경우).
5. 확장 권한에 `https://kapi.kakao.com/*` 추가(확장 다시 받기 필요).

## 3. 이메일 받기(방식 A, 엑셀 첨부)
1. **키 등록**: 「API키등록·플랫폼연동」에 **Resend API 키** 입력칸 + 연동 매뉴얼(가입 → API 키 만들기 → 붙여 넣기, 4단계 카드). 공용 항목 `resend_api_key`라 다른 프로그램도 재사용 가능.
2. **받는 주소**: 무료 요금제는 **Resend에 가입한 본인 메일 주소로만** 보낼 수 있어서, 받는 주소 = 가입 주소(회원이 입력, 기본값은 로그인 이메일).
3. **발송 경로**: 확장이 웹에서 키를 받아(확장 연결 토큰 확인, 회원 본인 키만) **`api.resend.com`을 직접 호출** — 요약 본문 + 엑셀(.xlsx) 첨부. 서버는 매물을 보지 않는다.
4. 확장 권한에 `https://api.resend.com/*` 추가.

## 4. 받는 방법 화면(STEP 3) 바꾸기
- 채널 3개를 켜고 끄는 카드: 📨 텔레그램(지금) · 💬 카톡(연결 상태 배지) · ✉️ 이메일(키 상태 배지, 받는 주소).
- DB `realty_alert_settings`에 칸 추가: `notify_kakao boolean`, `notify_email boolean`, `email_to text`(마이그레이션, 주인님 Run).
- 「시험 보내기」 버튼: 확장에 시험 메시지 1통 보내기 요청(카톡·이메일 각각).

## 7. 주인님 결정이 필요한 것
1. 카카오 연결이 없을 때: **추천 = 1차는 「카카오 자동화에서 한 번 연결」 안내만**. (이 프로그램 안에 직접 연결 버튼을 두려면 회원 카카오 앱에 이 프로그램의 리디렉션 주소를 하나 더 등록해야 해서 초보자에게 어렵다)
2. 메일 발송 서비스: **추천 = Resend**(무료로 본인에게 보내기 충분, 첨부 가능, 키 하나만 넣으면 됨).
3. 시험: 시험 계정(`buylifemall@naver.com`)에 카카오 연결·Resend 키가 없으면 주인님이 연결·가입해 주셔야 한다(비밀번호·키 입력은 주인님).
