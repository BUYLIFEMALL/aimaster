## 1. 만들 것

### A. 웹(서버는 설정·상태만) — 새 API 4개, 모두 확장 연결 코드(`personal_access_tokens`) 인증 + 이용 권한 확인
| 주소 | 하는 일 |
|---|---|
| `GET /api/extension/settings` | 켜진 감시 대상(번호·이름·거래 종류·가격/면적 조건) · 예약(켜기·간격·시간대) · 알림 기준·보낼 것·파일 형식 · **회원 본인 텔레그램 봇 토큰·chat id**(`user_telegram_links`, 이 회원 행만) · 수집 규칙 버전 |
| `GET /api/extension/collect-rules` | 수집 규칙 JSON(목록 주소 형식 `/api/articles/complex/`, 칸 이름 `articleList`·`isMoreData`·`dealOrWarrantPrc`…, 페이지 상한 10, 쉼 시간) — 네이버가 바뀌면 확장 재설치 없이 이 파일만 고침 |
| `POST /api/extension/status` | `realty_alert_device_status`에 숫자만 기록(마지막 수집 시각·결과 `ok/blocked/rule_mismatch/error`·건수·확장 버전·오류 문구 200자 이내). 매물 내용 받으면 거절 |
| `POST /api/extension/targets` | 확장 팝업 「이 단지 감시 추가」 — 단지 번호·이름만 받아 저장(10개 상한·중복은 2단계 규칙 그대로) |
- 대시보드: 「🖥 내 PC 상태」 카드에 마지막 수집 시각·결과·건수·다음 수집 예정 표시(`realty_alert_device_status`).

### B. 확장(MV3) — 사전 검증 메뉴를 걷어내고 실제 엔진으로 교체
| 모듈(`extension/lib/`) | 내용 | 시험 |
|---|---|---|
| `privacy.js` | 상호 전화번호 지우기(완료) | 3개 완료 |
| `schedule.js` | 간격·시간대·차례 판정(웹 `lib/schedule.ts`와 같은 함수) | 자정 넘김·밀린 회차 1번만 |
| `price.js` | 「3억 9,800」→ 39800(만 원), 월세 「보증금/월세」 | 억·천·쉼표·월세 |
| `filter.js` | 거래 종류·가격·면적 조건 거르기 | 경계값 |
| `compare.js` | 지난 결과와 `articleNo`로 대조 → 신규·가격 내림/오름·사라짐, 알린 매물 기록(같은 매물 1번만), 30일 지난 기록 정리 | 중복 알림 없음 |
| `sheet.js` | 결과 표 → **xlsx(자체 생성, 압축 없는 zip)** / CSV(UTF-8 BOM). 칸: 단지명·동·거래 종류·가격·면적·층·방향·특징·확인일·상호(전화 지움)·상태·이전 가격·첫 발견일·매물 주소. 개인 정보 칸 없음 | 파일 열림(엑셀) |
| `telegram.js` | `sendMessage`(요약, 앞에 「🏠 [매물 알림]」) + `sendDocument`(파일). 실패 시 다음 회차에 「지난 알림 실패」, 같은 알림 반복 재발송 없음 | 모의 응답 |
| `stop.js` | 멈춤 판정(상태 코드·확인 화면 주소·응답 모양이 규칙과 다름) | 모의 401·429·확인 화면 |
| `collector.js` | 단지 탭을 **보이는 창의 새 탭(배경)**으로 열기 → 디버거 붙임 → `Network.responseReceived`+`getResponseBody`로 목록 응답 읽기 → 목록 영역을 사람처럼 스크롤(2~5초 무작위) → `isMoreData`=false 또는 10페이지면 멈춤 → 디버거 뗌 → 확장이 연 탭만 닫기. 단지 사이 10~30초 쉼 | 실제 1단지(주인님 클릭) |
- `background.js`: ES 모듈로 바꿈(`"type": "module"`). `chrome.alarms` 1분마다 깨어나 차례 판정 → 수집 → 비교 → 보내기 → 상태 보고. 수집 중 깨어 있기(keepalive), 겹침 방지.
- 팝업: 연결·예약 상태, 마지막/다음 수집, **지금 수집**, **이 단지 감시 추가**(지금 탭이 단지 화면일 때), **최근 결과 보기**(`result.html`, 확장 안 표 + 파일 받기), 새 버전 알림. 처음 실행 때 필수 문구 동의 체크(인수인계 §10).
- 권한: 지금 그대로(`debugger`·`alarms`·`storage` + 네이버 부동산·텔레그램·우리 주소). 새 권한 없음.
