## 1. 무엇을
「수집 결과」 화면 통계(`app/results/StatsDashboard.tsx`)의 단지마다 **「📝 블로그 글로 쓰기 ↗」** 버튼.
누르면 「블로그 포스팅 자동화」(`ai-auto-blog`, FREE) 글쓰기 화면이 새 창으로 열리고 **주제·키워드가 미리 채워진다.**
글·이미지 생성, 확장 자동 입력, 발행 방식 선택은 블로그 프로그램이 그대로 맡는다(블로그 핵심 지침 — 웹에서 완성 → 확장 입력 → 회원이 고른 방식).

## 2. 재사용(새로 만들지 않음)
- 블로그 쪽 입구: `ai-auto-blog/app/write/ai-form/page.tsx`가 이미 `?topic=`·`?keywords=`(쉼표)를 읽는다(같은 입구가 `tistory-auto-blog`에도 있음). **블로그 코드 변경 없음** → 블로그 담당 세션과 겹치지 않음.
- 매물 알림 쪽 숫자: 통계 화면이 이미 web-bridge `stats`로 받은 요약(단지별 매물 수·매매 평균·변화 수·실거래 대비)만 쓴다.

## 3. 넘기는 내용(개인정보 없음)
- 주제 예: 「2026년 10월 마두동 백송마을 아파트 매물 시세 — 매매 평균 4억 2천, 이번 주 새 매물 3건·가격 내림 2건」
- 키워드 예: 「백송마을, 마두동 아파트, 일산 아파트 시세」
- **넘기지 않음**: 중개사 이름·전화번호, 매물 번호, 동·호, 회원 설정. 숫자는 요약 통계만.
- 당해 연도는 `new Date().getFullYear()`로 넣는다(핵심 원칙 8).

## 4. 순서
1. `lib/blogDraft.ts` 순수 함수 `buildBlogDraftLink(stat, now)` — 주제·키워드 만들기, 길이 제한(주제 120자), 금지 정보 없음
2. 시험 `tests/blogDraft.test.ts`(전화번호·매물 번호가 섞이지 않음, 연도, 주소 인코딩)
3. `StatsDashboard.tsx` 단지 카드에 버튼(새 창, `rel="noopener noreferrer"`)
4. `npm test`·`tsc` → 커밋 → v1.36 배포(확장 변화 없음, 버전만 맞춤) → 크롬에서 버튼 눌러 블로그 화면에 주제가 채워지는지 확인
