## 6. 다른 매물 종류(건물·상가·토지) — 별도 프로그램으로
- 2026-10-25 주인님 결정: 「기존 아파트 프로그램은 이대로 계속 개발 업그레이드하고, 별도의 프로그램으로 건물/상가/토지 순으로 개발해 보고, 나중에 가능하다면 하나로 합치는 방식으로 개발 난이도를 낮추어 진행」.
- 이 프로그램(아파트)은 그대로 업그레이드한다. 건물·상가·토지는 단지 단위가 없고(지역 단위), 비교 기준·실거래 자료(상업업무용·토지, 활용신청 따로)·엑셀 칸이 달라 **새 프로그램으로 건물부터** 만든다. 공용으로 쓸 수 있는 것: 확장 연결·예약·받는 곳(텔레그램·메일·카톡)·AI 요약·하루 상한·설정 표 컴포넌트.
- 시작 전: 개발 플랜(이름 후보·비용) 승인 → 사전 검증 페이지로 읽기 방식과 네이버 이용 조건(회원 PC·본인 로그인·하루 상한) 점검.
