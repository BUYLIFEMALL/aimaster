| 전 | 후 |
|---|---|
| 중개사 전화·주소·대표자 이름은 모으지 않는다(인수인계 §0·§57, 상호에 섞인 번호도 지움) | **새 매물·가격 변동 매물의 중개사 사무실 번호·휴대폰**은 회원 PC 파일(엑셀/CSV)과 회원 본인 알림(텔레그램·이메일)에만 넣는다. **서버에는 보내지 않는다**(§0 그대로). 주소·대표자 이름은 계속 넣지 않는다 |

## 2. 방법 — 변동 매물만 상세를 한 번 더 읽기
- 번호는 매물 목록에 없고 매물 상세(`/api/articles/{매물번호}?complexNo=`)의 `realtorPhone`·`cellPhoneNo`에만 있다(0단계 분석).
- 단지 수집 중 **목록을 다 읽은 뒤, 탭을 닫기 전에** 지난 결과와 비교해 「신규·가격 내림·가격 오름」 매물만 골라 상세를 **탭 안 요청**(지금 다음 페이지 읽기와 같은 방식 — 페이지가 쓰는 인증 정보를 그대로 실음)으로 읽는다.
- 요청 사이 사람처럼 쉬기(1~2초), **한 회차 상세 최대 20건**(넘으면 나머지는 링크만), 상세 요청도 **하루 한도(300페이지)에 함께 센다**. 차단·확인 화면이면 기존처럼 멈춘다.
- 「변동 없음」·「사라짐」 매물은 읽지 않는다. 첫 수집(기준 저장)은 매물이 많아 읽지 않는다.

## 3. 어디에 보이나
| 받는 곳 | 모양 |
|---|---|
| 엑셀/CSV | 새 칸 「사무실 번호」·「휴대폰」(없으면 빈칸) + 「네이버 매물 주소」는 **누르면 바로 열리는 링크**로 |
| 텔레그램·이메일 요약 | 매물 줄 아래 `📞 031-917-1234 · 010-1234-5678`(있는 것만) + 링크 |
| 카톡 | 그대로(요약 200자 제한) |

## 4. 바꿀 곳
- `extension/lib/collector.js`: 목록 뒤 상세 읽기 함수(탭 안 요청, 인증 정보 재사용, 간격·상한)
- `extension/background.js`: 비교 결과로 상세 대상 고르기 → 번호 붙이기, 하루 한도에 더하기
- `extension/lib/listing.js`·`sheet.js`·`telegram.js`: 번호 칸·줄, 엑셀 하이퍼링크
- `extension/lib/privacy.js`: 상호 속 번호 지우기는 유지(상호 칸은 깔끔하게, 번호는 번호 칸에)
- `lib/collectRules.ts`: 상세 주소·필드 이름·상한(`maxDetailsPerRun: 20`)을 규칙 파일로(네이버가 바꾸면 웹만 배포)
- 매뉴얼·개인정보 FAQ 문구, 인수인계 §0 갱신, 시험(`tests/stage3`·`privacy`)
