# 구현 계획 — AI 포토 리메이크 자동화 v1.01

2026-10-14 주인님 지시로 원본 분석 문서의 이름 2번을 확정하고 별도 앱을 구현합니다. 분석 후 기존 프로그램 보강을 권했으나 주인님이 새 프로그램 진행을 선택했습니다.

## 화면

표준 사이드바: 1 사진 복원, 2 사물 합성, 3 내 보관함, API키등록·플랫폼연동, 사용 매뉴얼, 로그인 계정·로그아웃. 휴대폰 폭에서는 위쪽 접는 메뉴로 전환합니다.

복원: 사진 클릭/드래그 업로드 → 손상 복원·흑백 컬러화·확대(원본/2배/4배) → 얼굴/구도 보존 지시·추가 요청 → 본인/동의받은 사진 확인 → 생성 → 비교·실제 크기·다운로드·브라우저 보관.

합성: 기본 사진 1장 + 사물 최대 5장 → 개별 사물 지시 입력 → 배경 유지/변경 → 직접 지시 또는 AI 제안 → 생성 → 비교·다운로드·보관. 원본 디자인/색/형태·모든 사물 포함과 얼굴 보존을 지시합니다.

보관함: 회원별 IndexedDB, 최근 20개. 결과·시각·옵션·사용 모델만 보관, 원본/키 미보관. 개별 다운로드·삭제. 새로고침 유지, 다른 기기 공유 없음.

## 서버/보안

Next.js·React·Supabase SSR은 portrait-photo 공통 인증 구조 재사용. 모든 작업 API에서 회원 세션·프로그램 권한·전화번호 정책을 확인합니다. 요청 출처·JSON 크기·사진 실제 바이트/형식/픽셀·사물 수·동의 값·모델을 검사합니다.

회원 본인 Gemini 키를 서버에서 읽어 호출합니다. 선택 모델 실패 시 임의 모델/키 변경 없이 안내합니다. 최신 공식 모델 ID를 선택 목록에 사용합니다. 본문에 원본 base64를 포함하되 브라우저에서 축소/압축하고 총 요청은 3.8MB 이하로 제한합니다. 원본·키·AI 원시 응답은 로그/문서에 남기지 않습니다.

sharp로 반환 이미지 형식·크기를 검사하고 실제 확대(긴 변 8192px 상한), 전송 용량에 맞게 JPEG 압축합니다. 결과 크기와 제한 적용 여부를 함께 반환합니다. 확대 품질은 AI 추정이며 얼굴 정확도나 사물 원형을 보장하지 않습니다.

## 검수

프롬프트: 얼굴/사물 보존·배경·당해 연도·단일 출력. 입력: 장수·용량·부적절한 MIME/base64·동의·모델·옵션 범위. 이미지: 실제 확대·MIME/확장자·출력 크기. 권한: 비로그인401·키 미등록 안내·설정 미완료 닫힌 화면. 브라우저: 사진 입력·옵션·합성 소스 삭제·전후 비교·보관/복원/삭제·다운로드·767px 전환. 모의 AI와 실제 회원 AI 결과를 구분합니다.
