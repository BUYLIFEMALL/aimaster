# AI G마켓·옥션 상품 자동등록기 (`esm-register`)

AI 상세페이지 자동화로 만든 상품을, 회원 본인 크롬의 확장이 회원 본인 ESM+ 「상품등록」 화면에 채워 G마켓·옥션에 한 번에 올리는 등록 도우미입니다. 개발·인수인계는 [`AGENTS.md`](AGENTS.md)를 보세요.

- 주소: https://esm-register.buylife.xyz (운영 v1.01, 2026-11-16 배포 · 크롬 확장 방식 · 실제 ESM+ 화면 시험 진행 중 · ESM Trading API 방식은 승인 회신 대기·미구현)
- 실행: `npm run dev`(포트 3036) · 시험: `npm test` · 빌드: `npm run build`
