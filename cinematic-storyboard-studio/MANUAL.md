# 시네마틱 스토리보드 자동화 — 사용 매뉴얼

> 대상: 이 프로그램을 쓰는 회원과, 회원 문의를 받는 운영 담당자. (개발·배포 인수인계는 [`AGENTS.md`](AGENTS.md))
> 주소: https://cinematic-storyboard-studio.buylife.xyz · 현재 버전 v1.03 · FREE (가입 회원 누구나, 핸드폰 번호 등록 필수)

## 1. 한 줄 설명
레퍼런스 이미지 **한 장**으로 영화 같은 **9컷 스토리보드**와 AI 영상 생성용 **프롬프트**를 만들어 줍니다.

## 2. 시작 전 준비 (한 번만)
1. AIMaster에 가입하고 **핸드폰 번호**를 등록합니다(없으면 프로그램을 쓸 수 없습니다).
2. 왼쪽 메뉴 **API키등록·플랫폼연동**에서 본인의 **Google Gemini API 키**를 등록합니다. 같은 화면의 "📖 연동 매뉴얼" 버튼에서 키 발급 방법을 팝업으로 보며 따라 할 수 있습니다.
   - 이 프로그램의 AI 비용은 **회원님 본인 Google 계정**으로 나갑니다. 운영자나 다른 회원의 키는 쓰이지 않습니다.
   - 키를 등록하지 않고 생성을 누르면 "Gemini API 키 등록이 필요합니다" 안내가 뜹니다.

## 3. 사용 순서
### 3-1. 이미지 올리기
- 왼쪽 메뉴 **새 스토리보드** → 이미지 영역을 눌러 고르거나 끌어다 놓습니다(JPG·PNG·WebP, 15MB 이하).
- **주제/컨셉**은 선택입니다. 적으면 그 주제에 맞춰 스토리가 만들어집니다. 막막하면 **AI 제안**을 누르세요(이미지와 적은 키워드를 보고 한 문장을 제안합니다).
- **렌더링 엔진**을 고릅니다.
  - **Nano Banana**: 빠르게 생성합니다(기본).
  - **Nano Banana Pro**: 고화질(2K)이지만 **본인 Google 계정에 결제(Billing) 연결이 필요**합니다. 권한이 없으면 안내 문구가 뜨며, 그때는 Nano Banana를 선택하세요.

### 3-2. 스토리보드 생성
**스토리보드 생성**을 누르면 순서대로 진행됩니다(전체 1~2분).
1. 이미지 저장 → 2. 구도·서사 분석 → 3. 9컷 마스터 시트 이미지 생성

분석 결과는 이미지가 그려지는 동안 먼저 화면에 나옵니다.
- **A) 장면 분석**: 환경, 주요 피사체, 시각적 앵커(모든 컷에서 유지되는 요소)
- **B) 테마와 스토리**: 로그라인, 테마, 4단계 감정선(기·승·전·결)
- **C) 연출 방식**: 샷 진행, 카메라 움직임, 렌즈·노출, 조명·색감
- **D) 키프레임 9컷**: 컷마다 길이·샷 종류·구도·행동·카메라·조명
- **E) 마스터 콘택트 시트**: 9컷이 3×3으로 한 장에 담긴 이미지(컷마다 `KF#01 | 2s | ELS` 자막)

중간에 실패하면 안내 문구가 나오고, 같은 버튼을 다시 누르면 **실패한 단계부터 이어서** 진행됩니다.

### 3-3. 이미지 저장·자르기
- **마스터 이미지 저장**: 9컷 시트 전체를 JPG로 저장합니다.
- **자르기 및 다운로드**: 슬라이더로 가로 여백(왼쪽·오른쪽)과 3개 행의 위·아래 경계를 맞추면, 어두운 영역은 잘려 나가고 밝은 영역이 컷이 됩니다. **ZIP 다운로드**를 누르면 `keyframe_01.jpg ~ keyframe_09.jpg` 9장이 들어 있는 ZIP을 받습니다. (자르기는 모두 내 브라우저 안에서 처리됩니다.)
- **이미지 다시 생성**: 같은 분석으로 마스터 시트만 새로 그립니다.
- **다시 분석**(키프레임 영역 우측 위): 이미지를 처음부터 다시 분석합니다(마스터 시트와 영상 프롬프트는 새로 만들어야 합니다).

### 3-4. 영상 프롬프트 만들기
마스터 시트 아래 **영상 설정**에서 고릅니다.
- **영상 길이**: 5초 / 8초(Veo 3.1) / 10초(Sora 2) / 15초(Sora 2). 선택한 총 길이에 맞게 9개 장면의 길이가 자동으로 나뉘며 합이 정확히 총 길이가 됩니다. 장면 1이 가장 깁니다.
- **대사**: 없음 / KR / EN. 대사를 고르면 장면 1과 장면 9는 비워 두고(영상만), 나머지 장면에 대사가 들어갑니다.

**영상 프롬프트 만들기**를 누르면 결과가 나옵니다.
- **마스터 프롬프트**: 영상 전체의 스타일·등장인물·환경(일관성 유지용). 복사 버튼이 있습니다.
- **장면별 프롬프트 표**: 장면 ID, 길이, 샷, 프롬프트(각 줄마다 복사 버튼), 대사.
- **JSON 데이터**: 자동화용. **JSON 다운로드** 또는 복사.

사용 팁
- Runway, Kling, Luma, Veo, Sora 같은 영상 AI에서 **장면 1은 업로드한 원본 이미지를 시작 이미지(Start Image)로** 쓰세요. 장면 1 프롬프트는 정지 샷이나 아주 느린 줌으로 시작하도록 만들어집니다.
- 프롬프트에는 "storyboard, panel, frame, grid" 같은 단어가 들어가지 않도록 처리됩니다(영상 AI가 스토리보드 종이를 그리는 현상을 막기 위해서입니다).
- 9컷을 5~8초에 나누면 일부 장면이 0.5~1초로 짧습니다. 영상 AI는 보통 한 클립이 5초 이상이므로, 인접 장면을 묶어 하나의 클립으로 생성하세요.

## 4. 내 프로젝트
- 만든 결과는 **내 프로젝트**에 자동 저장됩니다(최대 **30개**). 카드를 누르면 분석·마스터 시트·영상 프롬프트가 그대로 복원됩니다(주소의 `?p=…`).
- 휴지통 버튼으로 삭제하면 저장된 이미지도 함께 지워집니다. 30개가 차면 오래된 프로젝트를 삭제해야 새로 만들 수 있습니다.
- 이미지는 비공개로 저장되며 본인만 볼 수 있습니다.

## 5. 언어
오른쪽 위 **한국어 / English** 버튼으로 화면과 분석 결과의 언어를 바꿉니다. 영상 프롬프트의 마스터·장면 프롬프트는 영상 AI에 잘 맞도록 항상 영어로 만들어지고, 대사만 선택한 언어로 나옵니다.

## 6. 자주 묻는 질문 / 문제 해결
| 증상 | 원인과 해결 |
|---|---|
| "Gemini API 키 등록이 필요합니다" | API키등록·플랫폼연동에서 본인 키를 등록하세요. |
| "Gemini API 키가 올바르지 않습니다" | 키를 다시 복사해 교체하세요. 키 제한 설정에서 Generative Language API가 허용돼 있어야 합니다. |
| Pro 선택 후 "Pro 이미지 모델 권한이 없습니다" | 본인 Google 계정에 결제 계정 연결이 필요합니다. 연결하거나 Nano Banana를 선택하세요. |
| "Gemini 사용 한도를 넘었습니다" | 잠시 후 다시 시도하거나 본인 키의 사용 한도를 확인하세요. |
| "AI가 안전 정책으로 이 이미지의 처리를 거부했습니다" | 다른 이미지로 시도하세요(실존 인물 사진 등은 거부될 수 있습니다). |
| "AI가 키프레임 9개를 완성하지 못했습니다" | 일시적인 응답 오류입니다. 같은 버튼으로 다시 시도하세요. |
| "프로젝트는 30개까지 저장할 수 있습니다" | 내 프로젝트에서 오래된 것을 삭제하세요. |
| 이미지 생성이 오래 걸림 | Nano Banana는 약 30~60초, Pro는 1~2분까지 걸릴 수 있습니다. 화면을 닫지 마세요. |
| 프로그램에 들어가면 "핸드폰 번호를 입력 후 사용해주세요!" | 메인 사이트 설정에서 핸드폰 번호를 등록하세요. |

## 7. 운영 담당자 메모
- 이미지 보관은 운영자 저장소를 쓰므로 사용자당 30개로 제한했고, 참조 이미지는 긴 변 1600px, 마스터는 2400px의 JPEG로 압축해 저장합니다.
- AI 호출 비용은 모두 회원 본인 키로 나갑니다(운영자 비용 없음). 프로그램은 FREE 배지로 운영 중이며, 관리자 프로그램 편집 화면에서 배지를 켜고 끌 수 있습니다.
- 문의 대응 시 확인할 것: ① 핸드폰 등록 여부 ② Gemini 키 등록 여부 ③ Pro 사용 시 결제 연결 여부 ④ 프로젝트 수 한도.
- 개발·DB·배포 상세는 `AGENTS.md`.
