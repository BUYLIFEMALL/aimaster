## 2. 상세 내역

### IMP-01: 전 화면 딥 시네마틱 차콜(`bg-[#0b0f17]`) 단일 배경색 및 아틀리에 테마 통일
- **발견 근거**: 현재 `layout.tsx`가 `bg-gray-50/60` 라이트 모드로 설정되어 있어 전문 영화 연출 스튜디오의 몰입감이 떨어지며, 최상단 디자인 지침 11번(단일 배경색 준수 의무)을 위반할 위험이 있음.
- **개선 내용**: 전 화면(스튜디오, 내 프로젝트, 설정, 가이드)의 배경색을 `bg-[#0b0f17]`로 통일하고, 카드 서피스(`bg-[#131926]`), 폼 인풋(`bg-[#182030]`), 앰버 골드 네온 액센트(`from-amber-500 to-amber-600`)로 일체화.
- **예상 효과**: 영화 감독실/스튜디오 감성의 시각적 몰입도 극대화.

### IMP-02: `📖 연동 & 사용 매뉴얼` (`/guide`) 비주얼 가이드북 전면 신설 및 사이드바 표준화
- **발견 근거**: 기존 `/guide` 페이지가 단순 텍스트 줄글로 되어 있어 초보자가 9컷 스토리보드 생성 및 비디오 AI 연동 흐름을 직관적으로 이해하기 어려움.
- **개선 내용**: 5단계 시네마틱 파이프라인 인포그래픽, Gemini API 키 연동 안내, 촬영/앵글/무빙 용어 치트시트, 비디오 AI 툴 연동 팁, FAQ 4종을 인터랙티브 비주얼로 구축. 사이드바 유틸리티 최상단에 표준 메뉴 배치.
- **예상 효과**: 초보자도 1분 안에 헐리우드급 스토리보드와 영상 프롬프트를 기획할 수 있도록 사용성 대폭 개선.

### IMP-03: 비디오 생성 AI 원클릭 프롬프트 복사 UX 강화
- **발견 근거**: 현재 영상 프롬프트 탭에서 마스터 프롬프트와 컷별 프롬프트가 나뉘어 있으나, 사용자가 어떤 생성 툴(Runway vs Kling vs Luma)을 쓰는지에 따라 최적화된 형식으로 원클릭 복사할 수 있는 프리셋 버튼이 있으면 더욱 편리함.
- **개선 제안**: Runway용/Kling용/Luma용 원클릭 복사 포맷 옵션 버튼 추가.
