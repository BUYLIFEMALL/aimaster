# AI 웹툰 자동화 (ai-webtoon-studio)

시놉시스 기획부터 캐릭터 일관성 시트, 컷별 콘티 생성, 세로 스크롤 완성 원고 렌더링 및 롱스크롤 이어붙이기(JPG)까지 한 곳에서 완성하는 AI 웹툰 제작 자동화 프로그램입니다.

- **배포 주소**: `https://ai-webtoon-automation.buylife.xyz` (기존 `https://ai-webtoon-studio.buylife.xyz` 병행 지원)
- **Vercel 주소**: `https://ai-webtoon-automation.vercel.app`

## 핵심 기능 (v1.05)

v1.05: 기본 캐릭터 이름 ‘강민우’ 제거, 이름 직접 입력. [검수·릴리스 기록](docs/UI_RELEASE_V1_05.md).

v1.04: 불필요한 날짜·시간·날씨 표시와 갱신 타이머 제거. [검수·릴리스 기록](docs/UI_RELEASE_V1_04.md).

v1.03: 상단 모델 안내 배지 제거, 상단/4단계 ZIP·JPG 저장 버튼 노란색 강조. [검수·릴리스 기록](docs/UI_RELEASE_V1_03.md).

1. **기획 & 컨셉 설정 (STEP 1)**:
   - 작품 제목, 작가명, 핵심 시놉시스 (AI 자동완성/아이디어 확장 마법봉)
   - 5대 웹툰 아트 스타일: 현대 한국 웹툰 풍, 소년 만화 풍, 로맨스 순정 풍, 귀여운 SD/캐주얼 풍, 미국 히어로 코믹스 풍
   - 2대 레이아웃 모드: 세로 스크롤 (Webtoon), 그리드 (Comic Page)
   - 3대 말풍선 스타일: 부드러운 원형, 클래식 사각형, 강렬한 액션형
   - 메인 표지 포함 생성 토글
2. **캐릭터 일관성 시트 (STEP 2)**:
   - 등장인물 1~3명 외형 묘사 (옷, 머리색, 얼굴 특징, 나이, 체형 등) + AI 묘사 보강
   - 턴어라운드 캐릭터 모델 시트 생성 & 사용자 보유 사진 로컬 업로드
3. **시나리오 콘티 생성기 (STEP 3)**:
   - 챕터(화) 및 장(컷) 수 조절, 추가 연출 지시
   - LLM 기반 컷별 연출·지문·대사·구도 자동 분할 콘티 생성 및 인라인 편집기
4. **웹툰 제작 & 뷰어 (STEP 4)**:
   - 메인 표지 및 각 컷 일괄 고화질 렌더링
   - 세로 스크롤 웹툰 프리뷰어 (실제 네이버/카카오 웹툰 뷰어 동일 경험)
   - 원클릭 롱스크롤 단일 JPG 병합 다운로드 (HTML5 캔버스 자동 합성)
   - 컷별 이미지 및 콘티 대본 일괄 ZIP 압축 다운로드
5. **프로젝트 관리 & 개인 키 격리**:
   - JSON 프로젝트 전체 설정 내보내기/불러오기
   - 사용자 본인 Google Gemini API 키 브라우저 격리 보관
