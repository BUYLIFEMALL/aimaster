## 범위
| 구분 | 내용 |
|---|---|
| 예약 게시 | 게시 칸에 「지금 게시 / 예약 게시」, 예약 날짜·시간(한국 시간 10분 뒤~60일), 실행 상태 줄(일시정지·재개·실행 방식 바꾸기) |
| 게시 기록 | 최근 30일(예약됨·게시 중·게시됨·실패·취소), 게시물 보기, 예약 취소. 즉시 게시도 기록 + 중복 게시 확인 |
| 설정 | 「API키등록·플랫폼연동」(SettingsModal) 아래 「⏰ 예약 발행」 — 실행 방식(Vercel 기본 / 내 cron-job.org) + 공용 cron-job.org 키 한 줄 |
| 장 미리보기 | 「미리보기」를 누르면 실제로 올라갈 4:5 장을 그려서 넘겨 보기(게시와 같은 그리기 함수) |
| 화면 정리 | 칸 제목의 카메라 아이콘·📤 이모지 겹침 → 이모지 하나로 |
