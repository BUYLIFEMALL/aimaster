# 개발 플랜 — 인스타 자동 포스팅 1차: 웹툰 컷 캐러셀 즉시 게시 (v1.15)

- 근거 지시: 「모든 인스타 자동화 프로그램은 자동 포스팅까지」(2026-10-19) → 확대 순서 인플루언서(v1.14·v1.15 완료) → **웹툰** → 4컷. 주인님 「진행해줘」(2026-10-20)
- 기준 구현(복사 후 맞춤): `ai-influencer-studio` v1.14(연결 상태·서명 업로드·게시·임시 사진 삭제), 공용 기준 코드 `instagram-publish`(`insta_auto_poster/src/lib/instagram/publish.ts` 사본)

## 1. 문제
웹툰을 만든 뒤 인스타에 올리려면 ZIP·긴 JPG를 내려받아 INSTA나 휴대폰에서 다시 올려야 합니다. 긴 세로 원고는 인스타 피드 비율(4:5~1.91:1)에 맞지 않아 그대로 올릴 수도 없습니다.

## 2. 설계 — 「1컷 = 캐러셀 1장」
| 방안 | 판단 |
|---|---|
| 긴 세로 원고를 4:5 높이로 잘라 여러 장 | 컷·말풍선이 장 경계에서 잘림 → 채택 안 함 |
| 컷 그림을 가운데 기준 4:5로 자르기 | 가로 컷(4:3)·세로 컷(3:4) 가장자리와 대사가 잘림 → 채택 안 함 |
| **흰 4:5 판(1080×1350)에 컷 전체 + 아래 대사 말풍선** | 원고의 「전체 이어붙여 저장」과 같은 모양, 넘겨 보는 웹툰 형태 → **채택** |

- 표지(있으면) + 그림이 있는 컷을 원고 순서대로 최대 10장(인스타 캐러셀 한도). 넘치면 회원이 체크를 풀어 고름(순서는 항상 원고 순서)
- 캡션 기본값: 제목 + 줄거리 + 해시태그(#웹툰 #AI웹툰 #인스타툰) — 회원이 고칠 수 있음, 2200자
- 공개 게시 확인 체크 후 [게시]. 연결은 INSTA에서 한 번 한 값(공용 `insta_accounts`), 없으면 「INSTA에서 연결하기」

## 3. 구현 순서
1. 공용 `instagram-publish` 사본 추가(`scripts/check-shared-modules.mjs` 등록 → `--sync`), `memberAccount.ts` 인플루언서 사본
2. 순수 함수 `src/lib/instagram/slides.ts` — 판 배치 계산·대사 줄바꿈·기본 캡션·임시 경로 검사 + 시험
3. 서버 `posting.ts`, API `/api/instagram`(연결 상태)·`/upload`(서명 업로드 주소)·`/publish`(게시 후 임시 사진 삭제) — 모두 `checkProgramAccessApi` + `dynamic`·`fetchCache`
4. 화면 `InstagramPublishPanel` — STEP 4(웹툰 제작) 화면 아래
5. 시험·타입·빌드 → 배포 → DB 버전 v1.15 → 크롬 검수 → 문서·커밋
