# 플랜 — 문구 고치기 「덮는 색」 선택지 + 사용 안내 FAQ (v1.26, 2026-10-22 주인님 승인: 「FAQ도 함께 넣어서 진행해」)

## 문제
v1.25 실검수에서 「런칭 특가」 녹색 배지보다 넓게 지정하자 덮는 색이 바깥 회색으로 정해져 배지까지 사라짐. 덮는 색은 바깥 점들의 **평균**이라 색이 섞이면 탁한 중간색도 나옴. 바꿀 방법은 색상표뿐.

## 범위 (`components/products/ImageTextEditor.tsx`, `lib/dominantColor.ts`, `components/guide/CommerceUsageGuide.tsx`)
1. 「💧 찍기」 — 누른 뒤 이미지를 한 번 누르면 그 자리(3×3 점, 원본 이미지 기준) 색이 덮는 색. 찍는 동안 영역을 새로 잡지 않음, 안내 띠·테두리 강조.
2. 자동 색을 평균 → 가장 많은 색(채널당 16단계로 묶은 가장 큰 묶음의 평균).
3. 「바깥 색」「안쪽 색」 빠른 버튼(사각형 테두리 바로 바깥/안쪽).
4. 편집 창 안내 문구, 사용 안내 FAQ 「이미지 속 글자만 고칠 수 있나요?」 추가.
- 서버·DB·AI·저장 방식 변경 없음.
