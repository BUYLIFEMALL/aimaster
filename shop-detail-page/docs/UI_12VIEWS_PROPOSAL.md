## 1. 리뉴얼 추진 배경 및 사용자 지시사항

1. **사용자 핵심 지시**:
   - `"https://shop-detail-page.buylife.xyz/products 디자인 다시 잡도록 하고"`
   - `"좀더 쉽고 직관적인 UI로 다 잡아"`
   - `"우선 하나씩 시안 만든후에 보여줘"`
2. **현행 UI의 주요 페인포인트 분석**:
   - **메인(`/products`)**: 텍스트 위주의 단순 카드 목록 형태로, 셀러가 상품 등록 후 어떤 단계(AI 분석 ➔ 섹션 생성 ➔ 통이미지 병합)로 이어지는지 한눈에 파악하기 어려움.
   - **상세 에디터(`/products/[id]`)**: 15단/12단 섹션이 길게 나열되어 스크롤 피로도가 높고, 모바일 환경에서 실제 소비자가 보게 될 비주얼(스마트폰 목업)을 실시간으로 확인하기 어려움.
   - **액션 CTA 버튼**: 롱이미지 1장 원클릭 병합, HTML 복사 등 핵심 액션 버튼의 입체감과 위계가 약해 클릭 유도가 미흡함.
