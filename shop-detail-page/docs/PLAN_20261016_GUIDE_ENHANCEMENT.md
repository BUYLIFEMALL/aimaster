# AI 상세페이지 자동화 (shop-detail-page) 사용 가이드북 전면 고도화 개발 플랜

- **작성일시**: 2026-10-16
- **작업 CLI**: Antigravity (Windows)
- **대상 프로그램**: `shop-detail-page/` (`https://shop-detail-page.vercel.app/guide`)
- **목표 버전**: `v1.07` ➔ `v1.08`

---

## 1. 배경 및 문제점
- 현재 `/guide` 페이지는 4개 단계의 요약 문장과 15개 섹션 명칭, 간단한 꿀팁 3줄로만 구성되어 있어, 회원이 실제 각 스텝마다 **어떤 데이터를 준비해야 하는지**, **어떤 버튼을 어떤 순서로 눌러야 하는지**, **AI 분석 필드 수정 및 모델 선택 팁**, **개별 재생성/직접등록/히스토리 롤백 기능**, **세로 롱 이미지 병합 다운로드 활용법**을 구체적으로 알기 어려움.
- 따라서 실제 프로그램의 소스 코드와 백엔드 로직(`ProductAnalyzeForm`, `SectionImageGrid`, `uploadImageClient`, `export/route.ts`)을 정확히 파악하여, **초보 셀러도 화면을 보며 100% 쉽게 따라 할 수 있는 디테일한 단계별 실전 매뉴얼**로 전면 보강이 필요함.

## 2. 작업 범위 (Scope)

### ① 5단계 완벽 실전 가이드 파이프라인 (Step-by-Step Manual)
1. **STEP 00. 사전 준비 (Gemini API 키 등록)**:
   - 회원 본인 Google Gemini API 키 발급 방법 (Google AI Studio 링크 안내).
   - 좌측 메뉴 `API키등록·플랫폼연동` 경로 및 저장 로직.
   - 키 미등록 시 자동 감지 및 등록 안내 모달 동작 원리.
2. **STEP 01. 상품 등록 및 대표/참고 이미지 업로드**:
   - 대표 이미지(필수): 누끼컷(투명 배경 PNG) 또는 단색 배경 권장 이유(15개 섹션 합성의 기준 베이스 이미지로 사용).
   - 참고 이미지(선택, 최대 10장): 패키지, 마감 디테일, 부속품, 다른 각도 컷 업로드 시 장점(재질과 디테일 표현력 극대화).
   - 보조 텍스트: 상품명, 카테고리, 규격, 소구점 입력 방법.
3. **STEP 02. Gemini Vision AI 정밀 분석 및 11개 필드 검토·수정**:
   - `[AI 상품 분석 시작]` 버튼 클릭 시 멀티모달 분석 동작.
   - 11대 자동 추출 필드 상세 안내 (상품명, 카테고리, USP, 스펙, 사용법, 타깃고객, 메인/서브컬러, 배경스타일, 무드키워드, 폰트/밀도).
   - 셀러가 직접 입력값을 수정·보완하고 가격(정상가/할인가)을 기입하는 방법.
   - `[상품 등록 및 15개 섹션 생성으로 이동]` 버튼으로 스튜디오 전환.
4. **STEP 03. 15단 섹션 스튜디오 및 모델별 생성·재생성·직접등록**:
   - AI 이미지 모델 비교 (Gemini 2.5 Flash 가성비 vs Gemini 2.5 Pro 고화질 정밀 텍스트).
   - 생성 방법 3가지:
     - `[15개 섹션 전체 자동 생성]`: 원클릭 배치 일괄 처리.
     - `[🔄 재생성]`: 마음에 안 드는 특정 섹션만 비용 절약하며 개별 다시 만들기.
     - `[+ 직접등록]`: 보유 중인 실제 사진으로 특정 섹션 교체.
   - 버전 히스토리 바: 생성했던 이전 버전들을 썸네일 클릭 한 번으로 선택/롤백.
   - 이미지 클릭 시 원본 라이트박스 팝업 확대 보기.
5. **STEP 04. 최종 15단 세로 롱 이미지 병합 & 마켓 등록**:
   - 세로 롱 이미지 합성 엔진 원리 (Canvas/Sharp 기반 순차 연결).
   - 하단 고정(Sticky) `[15단 상세페이지 세로 롱 이미지 병합 & 다운로드]` 버튼으로 고화질 PNG 저장.
   - 네이버 스마트스토어, 쿠팡, 11번가, 자사몰 상세페이지에 원클릭 등록하는 가이드.

### ② 15대 필수 섹션 상세 가이드북
- 15개 각 섹션의 목적, 추천 카피라이팅, 필수 시각 요소, 이커머스 매출 전환 전략 상세 기술:
  - 01. 인트로 헤더 / 02. 브랜드 스토리 / 03. 핵심 문제제기 / 04. 특장점 솔루션 / 05. 디테일 컷 / 06. 실사용법 가이드 / 07. 비포 & 애프터 / 08. 라이프스타일 컷 / 09. 규격 & 스펙표 / 10. 특허 및 품질인증 / 11. 실구매자 리얼 리뷰 / 12. 자주 묻는 질문(FAQ) / 13. 배송 & 패키지 / 14. 신뢰 보증 시스템 / 15. 구매전환 CTA.

### ③ 셀러 실전 팁 & 트러블슈팅 FAQ 아코디언
- 이미지 생성 실패 시 대처법, API 키 할당량 확인법, 과대광고 심의 주의사항, 고전환율 사진 촬영 꿀팁.

## 3. 구현 순서
1. `ACTIVE_WORK.md`에 작업 등록 (`shop-detail-page`).
2. `components/guide/CommerceUsageGuide.tsx` 전면 고도화 구현:
   - 탭형 또는 직관적인 아코디언/섹션 블록 레이아웃 구축.
   - 단계별 스크린샷형 다이어그램, 뱃지, 실전 체크리스트 UI 추가.
3. `app/(dashboard)/guide/page.tsx` 레이아웃 정돈 및 대시보드 인라인 가이드 연동 점검.
4. 버전 판올림: `v1.07` ➔ `v1.08` (`lib/version.ts` 및 Supabase DB `programs.version`).
5. 로컬 프로덕션 빌드 (`npm run build`) 검증.
6. Vercel 프로덕션 배포 (`npx vercel deploy --prod --yes`).
7. Microsoft Edge (`msedge.exe`) 실세션(`buylifemall@naver.com`) 검수 및 캡처 (데스크톱 및 모바일).
8. 산출물 인수인계 문서 갱신 (`DESIGN_HANDOFF.md`, `IMPROVEMENTS.md`, `AGENTS.md`, `DESIGN.md`, `HANDOFF.md`, `ACTIVE_WORK.md` 해제).
