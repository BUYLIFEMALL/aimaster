## 2. 향후 제안 및 기능 개선사항 (다음 CLI 이관용 백로그)
1. **섹션별 드래그앤드롭 순서 변경 (Section Reordering)**:
   - 현재는 01번부터 15번까지 고정된 순서로 병합됨.
   - 향후 `dnd-kit`을 활용하여 셀러가 원하는 순서대로 섹션 블록을 드래그해 재배치할 수 있는 기능 추가 추천.
2. **섹션 텍스트 오버레이 편집기 (Text Editor)**:
   - 이미지 생성 후 카피 문구나 가격, 이벤트 일자 등을 웹 캔버스에서 직접 타이핑하여 수정할 수 있는 간이 텍스트 에디터 도입 고려.
3. **HTML / 이미지 분할 다운로드 옵션**:
   - 현재의 단일 세로 롱 이미지 외에도, 네이버 스마트스토어/쿠팡 권장 사양에 맞춘 860px 너비 분할 슬라이스 이미지 ZIP 다운로드 기능 지원 고려.
