# INSTA Cardnews 자동화 (cardnews-studio)

주제만 넣으면 AI가 페이지별 문구와 배경 이미지를 만들고, 글자를 얹어 카드뉴스를 PNG로 완성하며 인스타그램 피드 캡션과 해시태그까지 원클릭으로 패키징하는 웹 프로그램입니다. 모든 AI 호출은 회원 본인의 Gemini·OpenAI·Claude 키로 이루어집니다(운영자·타인 키 사용 없음).

## 기능 (v1.06)

1. **기획** — 분야·핵심 주제(✨ AI 주제 추천)·어조(일반/진지/국뽕/유머/넉살)·페이지 수(4/6/8/10)·비율
2. **문구** — 페이지별 제목·보조 문구·**카드 아이콘**(24종 중 AI가 선택, 직접 변경)을 AI가 작성, 직접 수정
3. **디자인** — 화풍·구성·테마 컬러·텍스트 배치·표시 효과·폰트·글자 크기/굵기/위치/색, 실시간 미리보기, 내 템플릿 저장/불러오기
4. **배경 생성** — 페이지별 Gemini(나노바나나) 배경, 전체/개별 생성, 이력에서 선택 (WebP 최적화)
5. **내보내기 & 인스타 캡션** — 완성 카드를 PNG/ZIP으로 저장 및 인스타그램 피드 캡션(후킹 카피, 본문 요약, CTA, 해시태그 20~25개) 원클릭 AI 생성·복사
- 대시보드의 "내 프로젝트"에서 프로젝트를 다시 열어 고칠 수 있고(자동 저장), 삭제하면 이미지도 함께 지워집니다.

## 설계 메모
- 글자는 이미지에 굽지 않고 브라우저 캔버스로 얹습니다. 미리보기와 PNG 저장이 같은 그리기 함수를 쓰므로 결과가 같습니다.
- 자세한 구조·규칙·검수 기록은 `AGENTS.md`를 보세요.

## 개발
```bash
npm run dev     # http://localhost:3000 (.env.local 필요)
npm test        # 자동 검사 19개
npm run build
```



## 2026-10-16 DB 연동 변수 호환 — v1.09 (cardnews-studio)

작업 전 [최상위 데이터베이스 연동 지침](../docs/DATABASE_CONNECTION_POLICY.md)과 [전체 전환 인수인계](../docs/DATABASE_CONNECTION_HANDOFF.md)를 먼저 읽습니다. 공개 키는 새 PUBLISHABLE 이름 우선·기존 ANON 이름 호환, 서버 키는 새 SECRET 이름 우선·기존 SERVICE_ROLE 이름 호환입니다. 새 값 없음/공백일 때만 같은 종류의 기존 값을 사용하며, 인증 실패 후 다른 키로 재시도하지 않습니다. 기존 변수·실제 키·회원 권한·Cron은 유지합니다. 배포·회원 검수 결과는 전체 인수인계의 프로그램별 기록에서 확인합니다. 기존 변수 삭제와 실제 키 폐기는 별개이며 안정화 확인 전 삭제하지 않습니다.
