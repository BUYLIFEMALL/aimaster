# INSTA Cardnews 자동화 (`cardnews-studio`)

> **서비스 배포 URL**: https://cardnews-studio.buylife.xyz  
> **현재 버전**: `v1.15` (2026-10-17)  
> **디자인 테마**: **크리에이티브 아틀리에 스타일 (인스타 카드뉴스 변형)** 다크 테마

주제만 넣으면 AI가 기획, 카피라이팅, 고화질 나노바나나 배경 생성, 캔버스 글자 얹기, 인스타그램 피드 캡션 및 25개 해시태그 패키징까지 원클릭으로 제작해 주는 카드뉴스 자동화 프로그램입니다. 모든 AI 호출은 회원 본인 소유의 API 키로만 격리되어 안전하게 실행됩니다.

---

## 1. 프로그램 사용목적 및 대상
- **사용목적**: 전문 디자인 도구 없이도 비주얼 퀄리티가 높은 인스타그램 카드뉴스를 빠르게 양산하고 바이럴 피드 캡션을 원클릭으로 추출.
- **대상**: 인스타 크리에이터, SNS 마케터, 지식 콘텐츠 발행자, 블로그/유튜브 콘텐츠를 카드뉴스로 재가공하려는 크리에이터.

## 2. 개발 도구 및 기술 스택
- **프론트엔드**: Next.js 16.2.11 (App Router), React 19, Tailwind CSS v4, Lucide React
- **디자인 테마**: 크리에이티브 아틀리에 다크 테마 (`bg-[#0d0f17]`, 서피스 `#161922`, 보더 `#262c3d`)
- **반응형**: 데스크톱(1440px) 고정 사이드바, 모바일(375px) 상단 고정 헤더(`h-14`) 및 오버레이 드로어
- **백엔드/인프라**: Supabase SSR, PostgreSQL (RLS 소유자 격리), Supabase Storage (`cardnews-images`)
- **캔버스 엔진**: HTML5 Canvas 기반 클라이언트 렌더러 (`renderClient.ts`)
- **AI 모델**: Google Gemini (`gemini-nano-banana-2.1`, `gemini-3-pro-image`), OpenAI GPT-4o, Anthropic Claude 3.7 Sonnet

## 3. 핵심 기능 (5단계 파이프라인)
1. **기획 (`/plan`)**: 주제 추천, 분야, 어조, 매수(4/6/8/10), 해상도 비율(4:5 세로형 / 1:1 정방형) 선택
2. **문구 (`/copy`)**: AI 장별 제목/보조문구 작성 및 장별 카드 선 아이콘(24종) 자동 추천
3. **디자인 (`/design`)**: 4대 무드(정보형/감성형/볼드형/미니멀형), 화풍 4종, 폰트 및 위치 조절 실시간 프리뷰
4. **배경 생성 (`/background`)**: Gemini 나노바나나 2.1 고품질 이미지 생성 및 이력 선택
5. **내보내기 (`/export`)**: 고해상도 PNG 개별/ZIP 일괄 다운로드, AI 피드 캡션 & 해시태그 25개 원클릭 복사
6. **비주얼 가이드북 (`/guide`)**: 5단계 파이프라인 및 인스타그램 알고리즘 바이럴 공략 가이드
