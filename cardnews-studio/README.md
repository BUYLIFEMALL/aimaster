# CARDNEWS STUDIO (인스타 카드뉴스 자동화)

주제만 넣으면 AI가 페이지별 문구와 배경 이미지를 만들고, 글자를 얹어 카드뉴스를 PNG로 완성하며 인스타그램 피드 캡션과 해시태그까지 원클릭으로 패키징하는 웹 프로그램입니다. 모든 AI 호출은 회원 본인의 Gemini·OpenAI·Claude 키로 이루어집니다(운영자·타인 키 사용 없음).

## 기능 (v1.04)
1. **기획** — 분야·핵심 주제(✨ AI 주제 추천)·어조(일반/진지/국뽕/유머/넉살)·페이지 수(4/6/8/10)·비율
2. **문구** — 페이지별 제목·보조 문구를 AI가 작성, 직접 수정
3. **디자인** — 화풍·구성·테마 컬러·텍스트 배치·표시 효과·폰트·글자 크기/굵기/위치/색, 실시간 미리보기, 내 템플릿 저장/불러오기
4. **배경 생성** — 페이지별 Gemini(나노바나나) 배경, 전체/개별 생성, 이력에서 선택 (WebP 최적화)
5. **내보내기 & 인스타 캡션** — 완성 카드를 PNG/ZIP으로 저장 및 인스타그램 피드 캡션(후킹 카피, 본문 요약, CTA, 해시태그 20~25개) 원클릭 AI 생성·복사
- 대시보드의 "내 프로젝트"에서 프로젝트를 다시 열어 고칠 수 있고(자동 저장), 삭제하면 이미지도 함께 지워집니다.

## 설계 메모
- 글자는 이미지에 굽지 않고 브라우저 캔버스로 얹습니다. 미리보기와 PNG 저장이 같은 그리기 함수를 쓰므로 결과가 같습니다.
- 자세한 구조·규칙·검수 기록은 `AGENTS.md`를 보세요.
