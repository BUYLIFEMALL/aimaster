# INSTA Cardnews 자동화 (`cardnews-studio`) 디자인 핸드오프 문서

## 1. 템플릿 명칭 및 테마 개요
- **고유 템플릿 명**: **크리에이티브 아틀리에 스타일 (인스타 카드뉴스 변형)**
- **적용 버전**: `v1.15`
- **테마 컨셉**: 인스타그램의 감각적인 비주얼 콘텐츠 제작에 최적화된 다크 아틀리에 감성. 어두운 작업실에서 캔버스와 컬러 팔레트에 집중할 수 있도록 딥 다크 슬레이트 베이스에 인스타 핑크/로즈 그라디언트와 앰버 포인트를 조화롭게 배치함.

## 2. 디자인 토큰 사양
- **기본 배경 (`Background`)**: `#0d0f17` (`bg-[#0d0f17]`)
- **서피스 / 카드 (`Surface / Card`)**: `#161922` (`bg-[#161922]`)
- **카드 테두리 (`Border`)**: `#262c3d` (`border-[#262c3d]`)
- **내부 인풋 / 패널 (`Input / Sub-panel`)**: `#0d0f17` 및 `#1f2433`
- **포인트 액센트**:
  - 인스타 그라디언트: `bg-gradient-to-r from-rose-500 via-pink-500 to-purple-600`
  - 에메랄드 배지: `bg-emerald-500/10 border-emerald-500/30 text-emerald-400`
  - 앰버 배지: `bg-amber-500/10 border-amber-500/30 text-amber-400`
  - 로즈 텍스트 / 배지: `text-rose-400`, `border-rose-500/30`
- **타이포그래피**:
  - 기본 헤드라인: `font-bold text-slate-100`
  - 본문 텍스트: `text-slate-300`
  - 서브 / 보조 설명: `text-slate-400`

## 3. 화면별 반응형 레이아웃 구조
### 데스크톱 (1440px 이상)
- 좌측 `w-64` (260px) 고정 다크 아틀리에 사이드바 (앱 타이틀, 버전 배지 `v1.15`, 5단계 핵심 파이프라인 메뉴, 신규 `📖 연동 & 사용 매뉴얼` 메뉴, API 설정, 로그아웃)
- 우측 메인 작업 영역: `max-w-6xl` 중앙 정렬, 유연한 그리드 시스템 (대시보드 3열, 가이드 2열)

### 모바일 (375px ~ 768px 이하)
- 상단 `h-14` (56px) 고정 헤더:
  - 인스타 카드뉴스 브랜드 로고 및 타이틀
  - `v1.15` 버전 배지
  - 접근성 지원 햄버거 토글 버튼 (`aria-label="메뉴 열기"`)
- 슬라이드 오버레이 드로어:
  - 딤드 배경 클릭 시 닫힘 처리
  - 모바일 터치 환경에 최적화된 큰 탭 영역 및 라우트 이동 시 자동 닫힘 연동

## 4. 신설 및 전면 개편 페이지
- **비주얼 연동 & 사용 매뉴얼 (`/guide`)**:
  - 🤖 마스코트 안내 배너: 카드뉴스 제작 입문자를 위한 따뜻한 환영 및 파이프라인 안내
  - 5단계 카드뉴스 파이프라인 비주얼 카드 (주제 발굴 ➔ 문구 생성 ➔ 템플릿 디자인 ➔ AI 배경 생성 ➔ 고해상도 내보내기 & 캡션 복사)
  - 인스타그램 4:5(1080×1350) 세로형 vs 1:1 정방형 해상도 및 안전영역(Safe Zone) 가이드
  - 인스타 알고리즘을 타는 '저장 & 공유' 유도 공식 및 25개 타겟 해시태그 패키지 팁
  - BYOK (Gemini 이미지 필수 / OpenAI·Claude 문구 선택) 보안 가이드 및 원클릭 바로가기
  - 자주 묻는 질문(FAQ) 아코디언형 카드 4종
- **대시보드 (`/dashboard`)**:
  - 크리에이티브 아틀리에 환영 배너 및 빠른 새 프로젝트 시작 버튼
  - 5단계 단계별 워크플로우 안내 카드
  - 최근 작업 프로젝트 카드 그리드 및 빈 상태(Empty State) 비주얼
- **설정 페이지 (`/settings`)**:
  - 일관된 다크 서피스 토큰 적용, API 키 마스킹 및 실시간 연동 상태 인디케이터 정돈
