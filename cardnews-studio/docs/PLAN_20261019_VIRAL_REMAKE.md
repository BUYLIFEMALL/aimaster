## 1단계 — v1.16 (이번 작업)
- **기획 화면 시작 방식 2가지**: ✍️ 주제로 시작(기존) / 🔥 떡상 리메이크(신규).
- **레퍼런스 입력**(하나 이상): 캡션·대본·기사 본문 붙여넣기 · 주소(기사 → 서버가 본문 추출, 유튜브 → Gemini가 영상 직접 보기) · 떡상 카드뉴스 화면 캡처 이미지 최대 6장(브라우저에서 긴 변 1024px JPEG로 줄여 전송, 깨진 사진은 공용 `image-file-check`로 거름).
- **[떡상 분석]** `POST /api/cardnews/remake/analyze`(회원 본인 키, 권한 확인): 원문 요약·핵심 수치 · 떡상 이유(심리 트리거) · 차별화 전략 · **7대 관점**(경고·치트키·쉬운 요약·VS 비교·실화 스토리·타깃 맞춤·계산기/수치) 중 **TOP 3**(1장 후킹 카피·전개 방향·장별 줄거리) · 원본 목록 항목 수 · **추천 장수**(4~10).
- **관점 선택** → 핵심 주제·장수 자동 입력 → 문구 단계가 관점·줄거리·핵심 수치를 반영해 **원본 항목을 빠짐없이** 장에 나눠 씀(`/api/cardnews/copy`에 remake 정보 전달).
- 장수 선택지 4·6·8·10 → **4~10 모두**.
- 안전: 원본 문장·이미지 재사용 금지 안내, 지어낸 수치 금지, 올해 연도·한국 시간 주입, `<data>` 태그로 입력 격리, 기사 주소는 공용 `safe-fetch`(ghost-scraper 기준, 내부망 차단·리디렉트 재검사).
- 인스타 릴스 자동 수집(Apify)은 넣지 않음 — 화면 캡처·캡션 붙여넣기로 대체(필요하면 다음 단계 선택 기능).
