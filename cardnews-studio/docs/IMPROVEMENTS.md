# INSTA Cardnews 자동화 (`cardnews-studio`) 개선 및 특이사항 기록

## 1. 이번 버전 (`v1.15`) 주요 개선 사항 (2026-10-17)
- **디자인 테마 전면 리뉴얼**:
  - 기존 라이트/혼재 뷰에서 **크리에이티브 아틀리에 스타일 (인스타 카드뉴스 변형)** 다크 모드(`bg-[#0d0f17]`, 서피스 `#161922`, 보더 `#262c3d`)로 일체화.
  - 전역 토큰 및 대시보드, 설정 페이지, 컴포넌트 라이브러리(`ui.tsx`) 다크 아틀리에 톤 통일.
- **모바일 반응형 헤더 & 오버레이 드로어 구축**:
  - 모바일(375px) 상단 고정 헤더(`h-14`)와 햄버거 메뉴 토글 구축으로 스마트폰에서도 매뉴얼 및 프로젝트 관리가 원활하도록 개선.
- **비주얼 연동 & 사용 매뉴얼 (`/guide`) 완전 신설**:
  - 누락되어 있던 가이드 페이지를 5단계 파이프라인 안내, 4:5 vs 1:1 해상도 및 안전영역 가이드, 인스타 바이럴 알고리즘 팁, BYOK API 키 가이드, FAQ 4종을 포함하여 완전 신규 구축.
  - 사이드바 네비게이션에 `📖 연동 & 사용 매뉴얼` 메뉴 연결.
- **타입스크립트 및 패키지 무결성 확보**:
  - Next.js Turbopack 로컬 빌드 컴파일 에러 0건 통과, `package.json` 및 DB 버전 `v1.15` 동기화 완료.

## 2. 향후 추가 개선 제안 (3대 핵심 항목)
### 1) 프로그램 로직 및 기능 개선
- **상업용 무료 웹폰트 패키지 다양화**: 인스타그램 카드뉴스의 핵심인 타이포그래피 매력을 극대화하기 위해 눈누(Noonnu) 라이선스 프리 한글 폰트(프리텐다드, 지마켓산스, 블랙한산스, 여기어때 잘난체 등) 5종 이상 웹폰트 추가 탑재.
- **슬라이드 순서 드래그 앤 드롭 재정렬**: 기획 단계에서 슬라이드 카드 순서를 마우스 드래그나 위/아래 버튼으로 손쉽게 교체할 수 있는 인터랙션 기능 추가.
- **Instagram Graph API 직접 발행 지원**: 로컬 PNG 다운로드뿐만 아니라 인스타그램 비즈니스/크리에이터 계정 연동 시 즉시 또는 예약 캐러셀 자동 발행 기능 확장.

### 2) 사용자 인터페이스 (UI) 가독성 및 사용편리성 개선
- **캔버스 실시간 줌인/줌아웃 및 안전영역 가이드 오버레이 토글**: 4:5 캔버스 작업 시 모바일 상하단 UI 가림 영역(Safe Zone)을 점선 오버레이로 켜고 끌 수 있는 시각적 보조선 기능 제공.
- **모바일 스와이프 제스처 카드 미리보기**: 스마트폰 환경에서 완성된 카드뉴스를 좌우 스와이프로 실제 인스타 피드처럼 넘겨볼 수 있는 모바일 전용 시뮬레이터 뷰 제공.

### 3) 타 자동화 프로그램과의 연계 가능한 기능
- **`threads-posting` (Threads 포스팅 자동화) 연동**: 카드뉴스에서 생성된 5장의 본문 카피를 스레드(Threads) 타래글(Thread Chain) 형식으로 1클릭 자동 변환하여 동시 멀티 배포 지원.
- **`ai-image-studio` (AI 이미지 스튜디오) 연동**: 나노바나나 2.1 최신 레퍼런스 어댑터 규격을 공유하여 고품질 인스타 감성 3D 일러스트/미니멀 사진 배경을 일관되게 생성.
