---

## 1. 리뉴얼 배경 및 목표
- 기존의 단순 라이트 그레이 톤에서 벗어나, 현대적인 프론트엔드 개발자들이 몰입할 수 있는 **미드나잇 다크 네이비 아틀리에 에디션** 구축.
- 12대 컴포넌트 갤러리, 10종 인터랙티브 시뮬레이터, 코드 뷰어, AI 컴포넌트 생성기의 복잡한 리액트 컴포넌트 로직을 손상시키지 않고 **무결성 CSS 토큰 주입 및 상속 덮어쓰기** 기법으로 완벽 전환.
- 프로그램 전 페이지(갤러리, 가이드북, 설정, 로그인)의 배경색을 단일 미드나잇 다크 네이비(`#0a0d14`)로 일체화 (`DESIGN.md` 단일 배경색 원칙 준수).
- 비주얼 가이드북(`/guide`)을 에디토리얼 테마로 리뉴얼하여 4단계 파이프라인 및 12대 컴포넌트 Props 규격서 완비.

---

## 2. 디자인 토큰 및 스타일 가이드
```css
:root {
  --background: #0a0d14;       /* 미드나잇 다크 네이비 배경 */
  --surface: #111622;          /* 카드 및 모달 컨테이너 표면 */
  --surface-alt: #182030;      /* 활성 탭 및 서브 컨테이너 */
  --border: #222d42;           /* 슬레이트 네이비 테두리 */
  --text-main: #f1f5f9;        /* 메인 타이포그래피 */
  --text-sub: #94a3b8;         /* 보조 설명 텍스트 */
  --brand: #38bdf8;            /* 리액트 사이언 블루 포인트 */
  --brand-alt: #a855f7;        /* 인디고 바이올렛 포인트 */
  --radius-card: 16px;
}
```
