## 2. 향후 권장 개선 과제 (Backlog)
1. **플랫폼별 HTML 원클릭 복사 클립보드 기능 고도화**:
   - 네이버 스마트스토어 전용 HTML 태그 클린징 및 쿠팡 에디터 호환 태그 자동 변환 프리셋 추가.
2. **상세페이지 A/B 테스트 카피 생성 옵션**:
   - 하나의 제품에 대해 후킹 중심 카피 버전과 감성 스토리 중심 카피 버전 2가지를 동시 생성하여 비교 선택할 수 있는 멀티 베리에이션 기능.
3. **사용자 템플릿 저장 기능**:
   - 자주 판매하는 카테고리(뷰티, 전자기기, 식품 등)의 브랜드 스토리 및 보장 정책을 프리셋으로 저장해 재사용할 수 있는 기능.
