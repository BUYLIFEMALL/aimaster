## 1. 작업 개요 및 변경 사항
- **이커머스 셀러 스튜디오 스타일 리뉴얼**:
  - `auto-detail-page`의 단일 뷰 구조를 사이드바 기반의 표준 스튜디오 레이아웃으로 전면 개편.
  - 셀러 로열 블루(`#2563eb`)와 세일즈 앰버/오렌지(`#f97316`)의 시각적 계층 구축.
- **좌측 반응형 사이드바 신설 (`components/layout/DetailSidebar.tsx`)**:
  - 데스크톱 고정 사이드바: 로고 + `v1.20` 배지 + 3개 메뉴(제작, 가이드북, API 설정) + 4단계 파이프라인 + 사용자 계정/로그아웃.
  - 모바일(767px 미만): 상단 헤더 바(로고 + 햄버거 메뉴) + 부드러운 슬라이드 드로어 네비게이션.
- **메인 워크스페이스 대시보드 리뉴얼 (`app/page.tsx`)**:
  - `.studio-hero` 프리미엄 그라디언트 배너.
  - 3대 핵심 KPI 통계 카드 (기획 완성 시간 `30초`, 플랫폼 최적화 `3대 템플릿`, 전환 설득 파이프라인 `7단계`).
  - 4단계 상세페이지 제작 파이프라인 가이드 바.
  - `max-w-6xl` 중앙 정렬의 쾌적한 폼 레이아웃.
- **독립 비주얼 가이드북 구축 (`app/guide/page.tsx`)**:
  - 4단계 제작 워크플로우 카드 4종.
  - 쿠팡, 스마트스토어, 럭셔리몰 권장 규격 및 템플릿 매트릭스 표.
  - 전환율 극대화 7대 황금 기획 수칙 카드 7종.
  - 자주 묻는 질문(FAQ 5종) 아코디언.
- **버전 3중 동기화 (`v1.20`)**:
  - `package.json` (`1.20.0`), `lib/version.ts` (`v1.20`), Supabase DB `programs` (`v1.20`).
- **배포 및 Edge 검수**:
  - Next.js 14 로컬 빌드 성공, Vercel 프로덕션 배포 성공, Edge 브라우저 7종 캡처 수집 및 10분 화면 유지 세션 가동.
