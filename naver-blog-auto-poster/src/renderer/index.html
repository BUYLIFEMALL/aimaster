네이버 로그인 세션 확인

아이디/비밀번호는 자동으로 입력되지 않습니다. 버튼을 누르면 브라우저 창이 열리고, 로그인되어 있지 않으면 그 창에서 직접 로그인/보안확인을 완료해주세요. 한 번 로그인하면 다음부터는 이 앱을 다시 열어도 로그인 상태가 유지됩니다.

대기 중

에디터 구조 조사 (프로토타입 2)

위에서 연 브라우저 창에서 직접 블로그 글쓰기 화면(내 블로그 → 글쓰기)으로 이동한 뒤, 아래 버튼을 눌러주세요. 현재 화면 구조를 분석해서 로컬 파일로 저장합니다.

대기 중

제목/본문 자동 입력 (프로토타입 3)

위 브라우저 창이 블로그 글쓰기 화면에 있어야 합니다. 아래에 입력한 제목/본문을 사람처럼 한 글자씩 타이핑해서 채워 넣습니다(발행/저장은 절대 대신 누르지 않으니 결과 확인 후 직접 발행해주세요).

대기 중

이미지 업로드 (프로토타입 3 확장)

버튼을 누르면 내 컴퓨터에서 이미지를 고르는 창이 뜹니다. 고른 이미지를 블로그 본문에 자동으로 삽입합니다.

대기 중

태그 입력 (프로토타입 3 확장)

먼저 브라우저 창에서 "발행" 버튼을 직접 눌러서 발행 설정창을 열어주세요 (이 버튼은 앱이 대신 누르지 않습니다). 설정창이 열리면 아래에 태그를 쉼표로 구분해서 입력한 뒤 버튼을 눌러주세요.
