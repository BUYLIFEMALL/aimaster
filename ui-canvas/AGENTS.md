## 1. 프로그램 사용 목적 및 대상

### 1.1 사용 목적
- 웹 및 모바일 애플리케이션의 화면 설계를 코딩 없이 캔버스 위에서 마우스 드래그 앤 드롭으로 빠르고 자유롭게 프로토타이핑합니다.
- 버튼, 입력 필드, 카드, 테이블, 차트, 모달, 아코디언 등 25종의 전문 UI 컴포넌트를 제공하며, 실시간 그룹화(Ctrl+G), 레이어 Z-Index 순서 제어, 정렬 및 상대좌표 계산을 지원합니다.
- 업로드된 앱 스크린샷 이미지에서 Gemini Vision AI가 UI 시각 요소를 자동 분해해 캔버스에 복원하는 **AI 스크린샷 역공학**과 전체 화면의 기능과 흐름을 설명해 주는 **AI 앱 명세 자동 생성**을 원스톱으로 제공합니다.
- 완성된 화면은 무손실 1:1 고해상도 PNG 이미지 및 프론트엔드 개발팀 전달용 컴포넌트/명세 JSON 규격으로 내보낼 수 있습니다.

### 1.2 주요 대상
- UI/UX 기획서를 빠르게 작성하고 시각화해야 하는 서비스 기획자(PM/PO) 및 스타트업 창업가.
- 복잡한 디자인 툴(Figma 등)의 가파른 학습 곡선 없이 핵심 인터랙션과 레이아웃을 1분 만에 설계하고자 하는 개발자 및 마케터.
- 벤치마킹하고 싶은 타사 앱 화면의 컴포넌트 구조를 빠르게 역공학하여 자사 서비스 기획에 참고하고자 하는 모든 사용자.

## 2. 개발 구현에 사용된 도구 / 개발기법 / 플러그인 / 스킬

- **프레임워크 및 런타임**:
  - `Next.js 16.4.0` (Turbopack 탑재 App Router), `React 19.3.0`, `TypeScript 5.9.3`
  - 순수 고속 CSS 기반 반응형 캔버스 뷰포트 (`src/app/globals.css`)
- **캔버스 엔진 및 내보내기**:
  - `html2canvas 1.4.1` — 캔버스 배율 1:1 보정 후 무손실 PNG 고해상도 캡처
  - 상대좌표 기반 재귀 그룹(Group) 엔진 및 경계 박스(Bounding Box) 연산 로직 (`src/lib/canvas/model.ts`)
  - `lucide-react 1.48.0` — 25종 컴포넌트 툴박스 및 직관적인 상태 아이콘
- **AI 멀티모달 역공학 파이프라인**:
  - Google Gemini API (`@google/genai` 기반 `gemini-2.5-flash` 모델 체인)
  - 스크린샷 이미지 최적화(긴 변 1,600px 클라이언트 리사이즈 후 Base64 전송) 및 JSON 스키마 기반 구조화 UI 컴포넌트 역공학 (`/api/ai/from-image`)
  - 화면 명세서(Spec) 자동 생성 파이프라인 (`/api/ai/spec`)
  - `yearGuard()` 지침 주입: 최신 연도 자동 동기화 및 프롬프트 인젝션 방어벽
- **데이터베이스 및 보안 연동**:
  - Supabase Database (PostgreSQL RLS 완비: `ui_canvas_projects`)
  - 1.5초 디바운스 자동 저장 및 다중 창 충돌 감지(`expectedUpdatedAt`, 409 Conflict 처리)
  - 최상위 보안 원칙 (BYOK): 공용 DB `user_api_keys` AES 암호화 키 조회 연동
- **품질 검증 및 테스트**:
  - `Node.js built-in test runner`: 12개 순수 로직 단위 테스트 (컴포넌트 생성, 그룹화, Z-Index 레이어 이동, JSON 임포트, 캔버스 바운딩 보정, 마퀴 선택) 100% 통과
  - `Playwright` 기반 Microsoft Edge 브라우저 최전면 포그라운드 실세션 검수 스크립트

## 3. 핵심 기능 및 시스템 로직 / 아키텍처

### 3.1 시스템 아키텍처
```
[사용자 캔버스 조작 (드래그 생성 / 이동 / 그룹화)]
         │
         ├── [1.5초 디바운스] ──▶ [PUT /api/projects/[id]] ──▶ [Supabase DB RLS]
         │
         ├── [이미지 업로드] ──▶ [POST /api/ai/from-image] ──▶ [Gemini 2.5 Flash Vision] ──▶ [25종 컴포넌트 자동 복원]
         │
         ├── [AI 명세 채우기] ──▶ [POST /api/ai/spec] ──▶ [구조화 JSON 명세서]
         │
         └── [내보내기] ──▶ [html2canvas (PNG 캡처)] / [컴포넌트 JSON] / [명세 JSON]
```

### 3.2 핵심 기능
1. **25종 전문 UI 컴포넌트 라이브러리**:
   - 컨테이너, 텍스트, 버튼, 입력 필드, 목록 상자, 이미지, 탭, 아코디언, 드롭다운, 라디오, 체크박스, 토글, 슬라이더, 알림, 로더, 진행률, 툴팁, 모달, 팝오버, 아이콘, 막대 차트, 선 차트, 파이 차트, 기타, 그룹.
2. **다중 선택 & 상대좌표 그룹화 엔진**:
   - 마우스 드래그 마퀴(Marquee) 및 Shift 클릭 다중 선택 지원.
   - 단축키 <kbd>Ctrl</kbd>+<kbd>G</kbd>로 즉시 그룹화 및 해제, 그룹 내 요소 상대좌표 유지.
   - 방향키(1px) 및 Shift+방향키(10px) 정밀 이동 지원.
3. **Gemini Vision AI 스크린샷 역공학**:
   - 타사 앱이나 웹 캡처 이미지를 업로드하면 시각 요소를 자동 분해하여 캔버스 컴포넌트로 즉시 재배치.
4. **반응형 뷰포트 프리셋**:
   - 데스크톱(1440x900), 태블릿(768x1024), 모바일(375x812) 원클릭 전환 및 배율 줌, 다크/라이트 모눈 격자 토글.
5. **독립 비주얼 가이드북 (`/guide`)**:
   - 4단계 UI 프로토타이핑 파이프라인, 툴박스 쇼케이스, 단축키 치트시트, BYOK 보안 배너, FAQ 5종 제공.

### 3.3 장점 및 단점
- **장점**:
  - 설치 없이 웹에서 즉시 실행되며, 복잡한 기능 없이 직관적인 드래그 앤 드롭으로 1분 만에 고품질 화면 완성.
  - 앱 스크린샷에서 UI 구조를 역공학해 주는 강력한 AI 비전 기능 탑재.
  - 1:1 고해상도 PNG와 개발자용 구조화 JSON 명세를 모두 지원하여 기획-개발 인수인계 비용 70% 절감.
- **단점 및 한계**:
  - 그룹 내부 자식 컴포넌트의 개별 인라인 편집 시 일시 그룹 해제가 권장됨.
  - 375px 모바일 화면에서는 캔버스 마우스 조작이 데스크톱 대비 제한적이므로 데스크톱 환경 권장.

## 6. 기존 다른 프로그램과의 연계 / 기능 병합 제안 및 기능 확장 아이디어

1. **72번 AI 웹 UI 제작 자동화 (`ai-web-ui`) 연계**:
   - `ui-canvas`에서 시각적으로 기획하고 배치한 컴포넌트 JSON을 `ai-web-ui`(리액트 쇼케이스)로 전달하여 실제 동작하는 풀스택 React UI 코드로 자동 변환하는 파이프라인 연계.
2. **68번 AI 글쓰기 에디터 자동화 (`ai-writing-editor`) 연계**:
   - 기획서나 블로그 글 작성 중 필요한 UI 화면 목업을 `ui-canvas`에서 캡처하여 원클릭으로 글쓰기 에디터 본문에 이미지로 자동 삽입하는 협업 브릿지.
3. **69번 AI 랜딩페이지 기획 자동화 (`landing-architect`) 연계**:
   - 랜딩페이지 기획서의 각 섹션(히어로, CTA, 가격표) 레이아웃을 `ui-canvas` 프리셋으로 불러와 시각적 와이어프레임으로 즉시 검토하는 연계.
