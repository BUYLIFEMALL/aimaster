## 1. 프로그램 로직 및 기능 개선 (Logic & Feature Improvements)

### 1.1 그룹 내부 자식 컴포넌트 딥 셀렉트 (Deep Direct Select)
- **현상 및 문제점**:
  - 현재는 2개 이상의 요소를 그룹(<kbd>Ctrl</kbd>+<kbd>G</kbd>)으로 묶은 후, 내부의 특정 버튼 라벨이나 색상을 수정하려면 그룹을 해제하고 수정한 뒤 다시 묶어야 하는 번거로움이 있음.
- **개선 방안**:
  - 그룹을 더블 클릭하거나 <kbd>Ctrl</kbd>을 누른 채 클릭하면 그룹을 해제하지 않고도 내부 자식 컴포넌트만 직접 선택(Deep Select)하여 우측 속성 패널에서 인라인 수정할 수 있는 계층형 탐색 로직 추가.
- **예상 효과**: 복잡한 카드나 모달 컴포넌트의 수정 편의성 3배 향상.

### 1.2 스마트 가이드라인 및 자석 정렬 스냅 (Smart Alignment Snapping)
- **현상 및 문제점**:
  - 요소를 드래그하여 배치할 때 인접한 요소들과 높이나 중심선을 맞추려면 눈대중이나 X/Y 좌표 숫자에 의존해야 함.
- **개선 방안**:
  - 요소 이동 시 인접한 다른 요소와의 수평/수직 중심선, 상/하단 맞춤선을 감지하여 붉은색 스마트 가이드 라인을 실시간으로 표시하고 자석처럼 달라붙는 스냅 알고리즘 도입.
- **예상 효과**: 디자이너 수준의 정밀한 그리드 정렬을 비전문가도 1초 만에 구현 가능.

## 2. 사용자 인터페이스 / UI 가독성 및 사용편리성 개선 (UI/UX Improvements)

### 2.1 캔버스 무한 팬(Pan) & 마우스 휠 줌 (Canvas Infinite Viewport)
- **현상 및 문제점**:
  - 현재는 고정된 스크롤바와 상단 줌 셀렉트 박스로만 배율을 조절할 수 있어, 캔버스 이동 시 인터랙션의 자유도가 다소 제한적임.
- **개선 방안**:
  - 스페이스바를 누른 채 마우스 드래그 시 손바닥 툴(Hand Tool)로 캔버스를 자유롭게 패닝(Pan)하고, <kbd>Ctrl</kbd>+마우스 휠 스크롤로 포인터 위치 중심 부드러운 줌 인/아웃 지원.
- **예상 효과**: Figma/Miro와 같은 친숙하고 부드러운 캔버스 조작감 제공.

### 2.2 디바이스 프레임 프레젠테이션 모드 (Presentation Device Frame)
- **현상 및 문제점**:
  - 완성된 프로토타입을 타인에게 보여줄 때 편집 툴바와 패널이 함께 보여 실제 앱 느낌을 전달하기 어려움.
- **개선 방안**:
  - 상단에 [미리보기 / 프레젠테이션] 버튼을 두어 아이폰/맥북 목업 프레임 안에 캔버스 내용을 띄우고 전체화면으로 시연할 수 있는 뷰어 모드 제공.
- **예상 효과**: 클라이언트 미팅 및 팀 리뷰 시 시각적 설득력 극대화.

## 3. 현재 만들어져 있는 다른 자동화 프로그램과의 연계 가능한 기능 (Cross-Program Integration)

### 3.1 72번 AI 웹 UI 제작 자동화 (`ai-web-ui`) 연계
- **연계 시나리오**:
  - `ui-canvas`에서 시각적으로 배치한 25종 컴포넌트의 좌표와 스타일 JSON을 [React 코드로 내보내기] 버튼을 통해 `ai-web-ui`(리액트 쇼케이스)로 전달하여, 실제 브라우저에서 동작하는 인터랙티브 React + Tailwind CSS 코드로 자동 변환하는 파이프라인 구축.
- **구현 방식**:
  - 컴포넌트 JSON 스키마를 Tailwind 클래스로 변환하는 트랜스파일러 API 브릿지 연결.

### 3.2 68번 AI 글쓰기 에디터 자동화 (`ai-writing-editor`) 연계
- **연계 시나리오**:
  - 블로그나 서비스 소개서, 개발 명세 문서를 작성할 때 `ui-canvas`에서 설계한 화면을 원클릭으로 캡처하여 `ai-writing-editor`의 Tiptap 에디터 본문에 고해상도 이미지 블록으로 즉시 삽입.
- **구현 방식**:
  - Supabase Storage 공개 버킷 URL 공유 및 문서 에디터 임포트 브릿지.

### 3.3 69번 AI 랜딩페이지 기획 자동화 (`landing-architect`) 연계
- **연계 시나리오**:
  - `landing-architect`에서 도출된 랜딩페이지 섹션 구조(히어로, 특장점 그리드, 가격표 카드)를 `ui-canvas`의 프리셋 템플릿으로 원클릭 로드하여 시각 와이어프레임으로 즉시 검토하는 기능.
