# 개발 플랜 — 병합 D 후속 3건 (2026-10-21, Claude Code 윈도우)

주인님 지시: 「진행해줘」(병합 D 남은 제안 3건). 한 건씩 순서대로 끝내고 배포한다.

## 1. 반응형 코드 내보내기 (ui-canvas v1.12)
- [</> 코드] 창에 「배치 방식」: 캔버스 그대로(절대 위치) / 반응형(flex·grid).
- 반응형: 세로 위치가 겹치는 컴포넌트를 한 줄로 묶고 줄 안은 왼쪽부터 → `flex flex-wrap`, 간격은 실제 간격(가로·세로)으로. 휴대폰 폭은 세로로 쌓이고(`w-full`), 넓은 화면은 캔버스 크기(`md:w-[..px]`). 그룹은 안에서 같은 규칙.
- 검수: 모든 컴포넌트 종류의 반응형 출력 문법 테스트 추가, 빌드·배포 후 크롬 확인. 비용 없음.

## 2. 저장한 AI 컴포넌트를 캔버스에 놓기 + 코드 함수 이름 보완 (ui-canvas v1.13)
- 「저장한 AI 컴포넌트」에 [캔버스에 놓기] → 캔버스에 미리보기 상자(Misc 컴포넌트, 제목·설명 표시)를 추가하고, 코드 내보내기 때 그 자리에 저장한 컴포넌트 코드를 함께 넣는다.
- 함수 이름: 영문이 3자 미만이면 `CanvasScreen`, 아니면 영문 + `Screen`(예: `AiScreen` 대신 규칙 통일).

## 3. AI 랜딩페이지 기획 → 「UI Canvas로 보내 다듬기」
- 랜딩페이지 결과 화면에 버튼 → UI Canvas에 새 프로젝트를 만들고(회원 본인 계정, 같은 공용 DB 표 `ui_canvas_projects`) 섹션을 캔버스 컴포넌트로 배치해 연다. 상세 설계는 착수 때 이 문서에 추가.
