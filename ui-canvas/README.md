## 1. 프로그램 개요
웹과 모바일 애플리케이션의 화면 설계를 코딩 없이 캔버스 위에서 마우스 드래그 앤 드롭으로 쉽고 자유롭게 완성하는 UI/UX 프로토타이핑 및 AI 역공학 자동화 웹 애플리케이션입니다.

- **크리에이티브 아틀리에 다크 에디션**: 프로페셔널한 딥 미드나잇 다크 네이비(`#0c0f17`), 슬레이트 다크 서피스(`#131824`), 일렉트릭 시안 블루(`#06b6d4`), 아티스틱 바이올렛(`#8b5cf6`) 테마 완비.
- **25종 UI 컴포넌트 라이브러리**: 버튼, 입력창, 카드, 모달, 차트, 탭, 드롭다운 등 다양한 UI 부품 지원.
- **Gemini Vision AI 역공학**: 앱 스크린샷 이미지를 업로드하면 시각 요소를 자동 분해하여 캔버스에 즉시 복원.
- **1:1 무손실 내보내기**: 고해상도 PNG 캡처 다운로드 및 개발팀 전달용 컴포넌트/명세 JSON 내보내기.
- **독립 비주얼 가이드북 (`/guide`)**: 4단계 프로토타이핑 파이프라인, 툴박스 쇼케이스, 단축키 치트시트, BYOK 보안 배너, FAQ 5종 제공.

---

## 2. 주요 기능
1. **마우스 드래그 컴포넌트 생성 & 상대좌표 그룹화**: 캔버스에서 마우스 드래그로 크기를 지정해 생성하고 <kbd>Ctrl</kbd>+<kbd>G</kbd>로 즉시 묶거나 해제.
2. **반응형 뷰포트 프리셋**: 데스크톱(1440px), 태블릿(768px), 모바일(375px) 전환 및 다크/라이트 격자 모눈 지원.
3. **AI 앱 명세 자동 생성**: 캔버스에 배치된 컴포넌트의 기능과 목적을 AI가 분석하여 표준 기획 명세서 작성.
4. **실시간 1.5초 자동 저장**: Supabase 클라우드 DB 연동으로 변경 사항 자동 보관 및 충돌 방지.
5. **회원 본인 키 보안 (BYOK)**: 회원 본인의 Google Gemini API 키로만 동작하며 암호화 보관.

## 3. 기술 스택
- **프론트엔드**: Next.js 16.4.0 (Turbopack App Router), React 19.3.0, TypeScript 5.9.3, 순수 CSS
- **캔버스/렌더링**: html2canvas 1.4.1, Lucide React 1.48.0
- **AI 백엔드**: Google Gemini API (`@google/genai`, `gemini-2.5-flash` 비전 모델)
- **데이터베이스**: Supabase PostgreSQL (RLS 완비)
