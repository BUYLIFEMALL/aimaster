# Windows 인수 검수 플랜 — file-merge v1.07

맥미니 c8ee93a7의 스마트 매트릭스 라이트 변형을 인수합니다. 파일 처리 기능·회원 정책을 유지하고 실제 결과와 배포까지 확인합니다.

1. 최신 지침·인수인계·원격/로컬·공유 스테이징·ACTIVE_WORK를 확인하고 이 폴더만 예약합니다.
2. `npm test`, `npm run build`로 기존 파일 처리·서식·큰 행 수 회귀와 타입/컴파일을 확인합니다. 발견한 오류는 범위 안에서 수정하고 기록합니다.
3. 실제 일반 시험 회원·보이는 Microsoft Edge에서 로컬 1440px/375px 레이아웃·6개 화면·메뉴·매뉴얼을 확인합니다. 두 샘플 엑셀(열 순서 다름)을 실제 업로드·합치기·다운로드하고 결과를 다시 읽어 값·머리글·서식을 검증합니다. 필요하면 분할·텍스트 작업도 소형 샘플로 대조합니다.
4. 네트워크를 확인해 파일 처리가 브라우저 안에서 이루어지는지 검수합니다. 계정·파일 내용을 외부로 전송하거나 유료 API를 호출하지 않습니다. 정상 로그인/권한 경로를 재사용합니다.
5. 검수 소스와 인수인계를 커밋·푸시하고 고정 커밋의 file-merge 프로젝트만 운영 배포합니다. DB `programs.version`을 v1.07로 갱신하고 주소·FREE/권한 정책은 유지합니다.
6. 운영 회원·Edge 1440px/375px와 실제 샘플 결과를 재확인하고, 현황판 65번·프로그램 AGENTS/README·디자인/개선/CLI 인수인계·root HANDOFF에 결과와 미검수·다음 첫 단계·프로그램 링크를 남깁니다. 작업 줄 제거·최종 커밋/푸시 뒤 메인 설치 파일 보존 검사도 수행합니다.

유료 API 호출 0회. 현재 미출시 v1.07 인수 마무리이며, 같은 인수 릴리스 안에서 발견한 수정은 v1.07에 포함합니다. 이미 운영 v1.07이면 새 코드 변경 배포 시 v1.08로 올립니다. DB 스키마·API 키·환경변수 변경·회원 데이터 삭제는 범위 밖입니다.
