## 2. 원칙
- **서버 전송·저장 없음**: 파일은 브라우저 안에서만 처리(원본과 같음). AI·외부 API 키가 필요 없어 최상위 규칙(본인 키) 대상 기능이 없다. 운영자 비용도 없어 **FREE 배지 후보**(주인님 결정).
- 권한: 일반 프로그램과 같이 로그인·`requireProgramAccess()`(핸드폰·FREE·구독·등급 순서). 쓰기 API가 없으므로 API 라우트는 만들지 않는다.
- 화면: 흰색 작업 화면, 표준 사이드바(번호형 작업 흐름·계정 위치), **모바일 레이아웃 지침(원칙 19번) 처음부터 적용**.
- 라이브러리: SheetJS(`xlsx`)는 npm 공식 배포가 0.18.5에서 멈춰 보안 공지가 있으므로, **SheetJS 공식 CDN 배포판(최신)을 고정 버전으로 설치**하거나 대안(ExcelJS)을 구현 첫 단계에서 비교·결정한다. ZIP은 이미 검증된 의존성 없는 `zip.ts`(portrait-photo·four-cut-comics) 재사용.

## 3. 기능 (원본 4기능 + 확인한 한계 보완)
1. **엑셀 합치기**
   - 이어 붙이기: **머리글 이름 기준으로 열을 맞춤**(순서가 달라도 같은 열로), 머리글은 한 번만, 없는 열은 빈칸, 선택 시 `원본 파일`·`원본 시트` 열 추가.
   - 합칠 시트 선택(파일별 시트 목록 체크), 머리글 행 번호 지정(기본 1행), 파일 순서 끌어서 변경, CSV 입력 지원.
   - 시트별로 모으기: `파일명_시트명`(31자·금지문자·중복 처리).
2. **엑셀 나누기**: 시트별(원본 기능) / **특정 열 값별**(예: 지역별 파일) / **N행씩**(머리글 반복) → ZIP.
3. **텍스트 합치기**: 구분자 선택(빈 줄·구분선·직접 입력), 파일명 머리말 넣기, 순서 변경.
4. **텍스트 나누기**: **글자 수 기준(기본)** 또는 문장 수 기준, 문단·문장 경계를 넘지 않게 자르기, 조각 수 또는 조각당 글자 수 지정.
5. **공통**: 처리 전 미리보기(파일·시트별 행·열 수, 결과 상위 20행), 문자 인코딩 자동 인식(UTF-8/CP949, 직접 선택 가능), 결과 ZIP·파일명 지정, 사용 가이드 페이지, 한국어 화면.

## 4. 구조
- Next.js(기존 서브프로젝트 뼈대: four-cut-comics 셸·권한·사이드바 — **모바일 CSS 포함 확인**).
- 순수 함수(테스트 대상) `src/lib/files/`: `alignByHeader`, `mergeRows`, `splitByColumn`, `splitByRows`, `sheetNameSafe`, `splitText`(글자/문장), `detectEncoding`.
- 화면: `/studio`(탭 4개 → 번호형 흐름: ① 파일 올리기 ② 옵션 ③ 미리보기 ④ 저장), `/guide`.
- DB: `programs` 등록 + 요금제 3종 + 등급 접근(기존 체크리스트). 회원 데이터 테이블 없음.
