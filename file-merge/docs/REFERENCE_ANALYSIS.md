- 단일 페이지 React 19 앱(Vite 빌드, `assets/index-BFd8p0Gy.js` 705KB — 대부분 SheetJS `xlsx@0.18.5`와 `jszip@3.10.1`).
- Tailwind CDN, 폰트 Fredoka·Material Symbols, 파스텔 색 테마, 다크 모드, 한국어/영어 전환(앱 안 사전 객체).
- **서버 호출·저장 없음**(`fetch`·`localStorage` 사용 없음) — 파일은 브라우저 안에서만 처리. AI·API 키 없음.
- 제작자 표기: "Created by GPT PARK", 유튜브 `@AIFACT-GPTPARK` 링크.

## 2. 기능(탭 4개)과 실제 로직
| 탭 | 입력 | 처리(코드 확인) | 출력 |
|---|---|---|---|
| 엑셀 합치기 | .xls/.xlsx 여러 개 | "하나로 쭉 잇기": 모든 파일의 **모든 시트의 모든 행**을 순서대로 아래로 이어 붙임(머리글 구분·열 이름 맞춤 없음, 열 수는 최대값). "시트별로 모으기": `파일명_시트명` 탭으로 복사(31자 넘으면 `_1` 등으로 자르고 중복 회피) | `merged_result.xlsx`(이름 변경 가능) |
| 엑셀 나누기 | .xls/.xlsx 1개 | 시트가 2개 이상일 때 시트마다 새 통합문서 → ZIP | `<원본>_split.zip` 안 `<시트명>.xlsx` |
| 텍스트 합치기 | .txt 여러 개 | `File.text()`(UTF-8)로 읽어 구분자(기본 `\n\n---\n\n`, `\n`·`\t` 해석)로 join | `merged_text.txt` |
| 텍스트 나누기 | .txt 1개 | 정규식 `/([^.!?\n]+[.!?]?\s*|\n+)/g`로 문장 조각을 만든 뒤 **조각 개수**를 N등분(ceil) | `<원본>_split.zip` 안 `<원본>_01.txt`… |

- 같은 이름 파일은 추가할 때 말없이 제외. 파일 순서 변경 불가. 성공 후 선택 목록 비움.
- 가이드 모달: 서비스 소개·기능·사용법 5단계.

## 3. 실제 동작 확인(엣지, 페이지 안에서 같은 라이브러리로 시험 파일 생성)
- **엑셀 잇기**: 파일 A(이름·매출·지역 / 2행) + 파일 B(시트 "2월": 지역·이름·매출 / 1행, 시트 "메모": 비고 / 1행) → 결과 1개 시트에
  `이름,매출,지역` / 김철수 / 이영희 / **`지역,이름,매출`(머리글 반복)** / **`대구,박민수,300`(열 어긋남 — "지역" 값이 "이름" 열)** / **`비고`·`확인필요`(관련 없는 시트 섞임)**. 원본 파일 표시 없음.
- **텍스트 나누기**(3조각): "첫 문장입니다. 둘째 …마침표가 없습니다\n" / "셋째 줄! 넷째 줄? " / "다섯째 문장. 여섯째 문장." — 문장 수 기준이라 조각 길이가 들쭉날쭉하고, 마침표 없는 긴 문장은 통째로 들어감.
- 코드 기준 판단(실행 미확인): 텍스트는 UTF-8로만 읽어 한글 ANSI(CP949) 파일은 깨질 수 있음, CSV 미지원.
