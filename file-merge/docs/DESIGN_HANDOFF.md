# 디자인 개발완료 인수인계 — AI 엑셀·텍스트 합치기 자동화 (v1.07)

- **적용 디자인 템플릿**: **스마트 매트릭스 스타일 — 라이트 변형 (Smart Matrix Light)**. 골격·부품은 기준 구현(`longtail-keyword-expander`)·일반 CSS 이식 예(`blog-keyword`)와 같고 **색만 밝게**. 이 라이트 토큰은 다른 프로그램의 「라이트 테마」에 그대로 쓰는 기준값이다.
- **작업**: Claude Code(맥미니), 2026-10-17 · 상태: 🟠 메인(윈도우) CLI 마무리 작업요망

## 1. 라이트 토큰 (`src/app/globals.css :root`)
| 토큰 | 값 | 대비(WCAG) |
|---|---|---|
| `--mx-bg` / `--mx-surface` / `--mx-raised` | `#f6f7f9` / `#ffffff` / `#f1f4f8` | — |
| `--mx-border` | `#e2e6ee` | — |
| `--mx-text` / `--mx-muted` | `#0f172a` / `#5b6475` | 흰 바탕 17.9:1 / 5.96:1 (raised 위 5.4:1) |
| `--mx-primary` (+`-strong`) | `#2563eb` / `#1d4ed8` | 흰 글자 5.17:1 |
| `--mx-link` | `#1d4ed8` | 흰 바탕 6.7:1 |
| `--mx-accent` | `#b45309` | 흰 바탕 5.02:1 (다크의 `#f59e0b`는 흰 바탕에서 대비 부족 → 진하게) |
| `--mx-success` / `--mx-danger` | `#047857` / `#be123c` | 연한 배경 위 5.2:1 / 5.7:1 |
| 칩 쌍 `--mx-blue-bg/-fg` · `--mx-amber-bg/-fg` · `--mx-green-bg/-fg` · `--mx-red-bg` | `#dbeafe/#1e40af` · `#fffbeb/#92400e` · `#ecfdf5/#047857` · `#fff1f2` | 7.2 · 6.8 · 5.2 : 1 |

다크 변형과의 차이: 반투명 칩(`rgb(... / .6)`) 대신 **연한 배경 + 진한 글자 쌍**을 토큰으로 둔다. KPI 위쪽 색 막대는 다크와 같은 밝은 색(`#f59e0b`·`#10b981`) — 글자가 아니라 장식이라 대비 기준 대상 아님.
