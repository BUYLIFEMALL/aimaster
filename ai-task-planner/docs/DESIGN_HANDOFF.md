## 2. 주요 개선 및 구현 내용

1. **사용자 제공 레퍼런스 화면 100% 일치 구현 ("한눈에 주목도 있게 한 화면에서 전체 내용을 볼 수 있도록 세련되지만 차분한 느낌")**:
   - 상단 집중 툴바: `✨ 오늘의 할 일 & 성과`, 뽀모도로 3단 모드 탭(`Focus`, `Short Break`, `Long Break`), 대형 모노스페이스 시계(`25:00`), `START` 화이트 알약형 버튼, 일자 배지, 백업/CSV/정산 버튼.
   - 3열 그리드 레이아웃:
     - 좌측 열: 카테고리 탭 빠른 선택 + 미완료/진행중/완료 할 일 카드 리스트.
     - 중앙 열: 할 일 추가 입력 폼(`+ 추가` 버튼) + 오늘의 성과(완료율 게이지, 총 집중 시간, 예측 정확도, 성과 점수).
     - 우측 열: 시간대별 완료 수 바 차트 + AI 생산성 분석 카드 + 성과 노트(회고 텍스트에어리어).
2. **`📖 연동 & 사용 매뉴얼` 비주얼 가이드북 전면 구축 (지침 7번 준수)**:
   - 사이드바에 `연동 & 사용 매뉴얼` 메뉴 탑재 및 `/guide` 라우트 연결.
   - 5단계 파이프라인 인포그래픽:
     1. 1단계: 할 일 계획 & 우선순위 매트릭스
     2. 2단계: 뽀모도로 포커스 타이머 실행
     3. 3단계: 성과 지표 & 시간대 차트 실시간 모니터링
     4. 4단계: Gemini AI 생산성 분석 & 개선 피드백
     5. 5단계: 성과 노트 & JSON/CSV 안전 백업
   - 생산성 극대화 4대 골든 팁 카드 4종.
   - 자주 묻는 질문(FAQ) 4종 아코디언 컴포넌트.
   - 회원 본인 Gemini API 키 연동 보안 원칙 배너 탑재.
3. **단일 배경색 및 일관된 테마 스타일 준수 (지침 11번 엄수)**:
   - 대시보드, 계획, 집중, 성과, 백업, 설정, 가이드북 전체를 `#0b0f19` 딥 나이트 네이비 단일 배경으로 일체화.
4. **반응형 모바일 지원 (390px)**:
   - 1440px 데스크톱에서는 스크롤을 최소화한 3열 콘솔 레이아웃, 390px 모바일에서는 상단 바 + 햄버거 메뉴 + 유려한 1열 카드 배치 적용.
