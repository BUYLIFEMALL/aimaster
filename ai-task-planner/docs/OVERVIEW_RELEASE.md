# v1.03 통합 대시보드

2026-10-13. 주인님이 첨부한 원본 화면의 한눈에 보는 배치를 반영합니다. 작업 화면은 공통 지침의 흰색 베이스와 번호형 사이드바를 유지합니다.

## 변경 내용

- 상단에 집중·짧은 휴식·긴 휴식 모드, 남은 시간, 실행할 할 일 선택, 시작·정지·재개·종료 및 JSON 백업을 표시합니다.
- 왼쪽은 분류 빠른 선택과 미완료/진행중·완료 목록, 가운데는 할 일 작성/수정과 성과, 오른쪽은 완료 차트·AI 준비 안내·성과 노트입니다.
- 대시보드에서 추가·수정·집중 시작을 해도 대시보드에 머뭅니다. 기존 단계별 상세 화면도 유지합니다.
- 분류 탭·날짜·검색의 같은 범위를 목록·수치·차트에 적용합니다. 분류를 바꿔 목록이 비어도 실행 중 타이머와 대상 제목은 유지합니다. 노트는 기존처럼 날짜별 저장입니다.
- 1366px 화면에서 3열, 작은 데스크톱에서 2열, 390px 모바일에서 1열입니다. 긴 목록은 카드 안에서 스크롤합니다.
- AI 호출·JSON 복원·CSV는 기존 후속 범위입니다. 준비 중 표기와 비활성 버튼을 유지합니다. 새 AI 키·계정·DB 구조 변경은 없습니다.
- 코드 APP_VERSION·programs.version v1.03 및 package1.3.0 동기화. 기존 회원 기록과 집중 세션을 보존합니다.
