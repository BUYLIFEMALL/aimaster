## W01에서 확인할 현재 코드 관찰

아래는 `4acdce4d` 이후 문서 작성 초기의 **소스를 읽어 확인한 사항**입니다. 문서 작성 중 다른 CLI가 `Overview.tsx`·`Planner.tsx`·`TaskEditor.tsx`를 추가 수정하고 있어 일부는 이미 달라질 수 있습니다. 최신 Git·파일을 재확인합니다. 최신 화면의 실행 검수 결과가 아니며 이번에 코드를 수정하지 않았습니다.

- `SummaryPanel`: `summary.accuracy === null`을 `0%`로 표시합니다. 이전의 실측 없음=`미측정` 지침과 맞는지 확인하고, 실제0%와 미측정을 구분합니다.
- `ChartPanel`: 눈금은0~4로 고정되고 막대 높이는 관측 최댓값으로 정규화됩니다. 눈금·막대·실제 완료 건수의 같은 척도 여부를 확인합니다.
- `NotePanel`: 기존 노트 입력의 `하루 돌아보기` 레이블이 없어졌고, 분류 그룹명·AI 제목·타이머 모드 버튼명·요약 카드 구조도 변경됐습니다. `tests/browser.mjs`의 이전 선택자가 최신 화면과 일치하는지 확인합니다.
- `AnalysisPanel`: 분석 버튼은 준비 안내 모달을 여는 코드이며 실제 Gemini 호출이 아닙니다. 안내만으로 분석 완료라고 보고하지 않습니다.
- 툴바의 `하루 리셋`: 활성 세션을 정산 종료하거나 안내합니다. 할 일·노트 삭제, 일자 마감/다음 날 이동은 구현하지 않습니다. 버튼명과 실제 동작의 일치 여부를 확인합니다.
- `TaskEditor.tsx`: 작성 시점에 제출 버튼 `aria-label`을 추가하는 미커밋 변경이 있었습니다. 다른 CLI 작업이므로 이번 문서 커밋에 포함하지 않습니다. 재개 시 변경이 남아 있는지·누가 작업 중인지 먼저 확인합니다.
