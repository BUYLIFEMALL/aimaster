## 범위
1. **분류 고르기** — 「📥 받은 할 일」 칸 위 「넣을 분류」 선택 칸. 하나씩·한꺼번에 추가 모두 이 분류. 보관됐거나 없는 분류면 기본 분류(`receivedCategoryId`).
2. **한꺼번에 추가** — 2개 이상이면 「➕ 모두 추가 (N개)」. 서버 `action: "addAll"`(ids 1~50): 아직 안 가져간 줄만 한 번에 「가져감」 표시 → 할 일 N개 추가 → 기록 저장 1번 → 실패하면 가져감 표시 모두 되돌림. 응답 `addedIds`로 화면에서 실제 추가된 줄만 지움.
3. **메뉴 개수** — 좌측 메뉴 「대시보드」 옆 `📥 N` 배지(0개면 숨김).
4. 같이 넣은 공통 항목: 저장공간 위젯 한 줄(`layout.tsx`), 로그아웃 `signOut({ scope: "local" })`.
