## 3. 정식 모델 ID 및 연동 기술 명세

### 1) 나노바나나 (Gemini)
- **정식 모델 ID**: `gemini-nano-banana-2.1` (`NANO_BANANA_MODEL_CONFIGS.nanobanana.modelName`, 1K/2K)
- **공식 연동 기준**: `ai-image-studio`의 공용 기준 코드 사본 `geminiImage.ts` (`generateGeminiImage`)
- **인증 및 키**: 회원 본인 Google Gemini API 키 (`user_api_keys` provider `gemini`)
- **비용**: 회원 본인 Google Cloud 계정 청구 ($0 ~ 종량제)

### 2) OpenAI
- **정식 모델 ID**: `gpt-image-2.5-flare` (2026-11-03 공지된 gpt-image-1 계열 종료에 따른 공식 대체 최신 이미지 생성 모델)
- **공식 엔드포인트**: `https://api.openai.com/v1/images/generations`
- **인증 및 키**: 회원 본인 OpenAI API 키 (`user_api_keys` provider `openai`, `Authorization: Bearer <key>`)
- **해상도**: 비율별 1:1(`1024x1024`), 9:16(`1024x1792`)
- **비용**: 회원 본인 OpenAI 계정 크레딧 청구

### 3) 무료 모델 (FLUX)
- **엔진/서비스**: Pollinations.ai FLUX (Black Forest Labs의 오픈소스 FLUX.1 기반 무료 REST API)
- **실제 서비스 엔드포인트**: `https://image.pollinations.ai/prompt/{encodedPrompt}?width={w}&height={h}&seed={seed}&nologo=true&model=flux`
- **회원 인증/키**: **API 키 등록 불필요 (100% 무료)**
- **요금**: $0
- **전송 데이터**: 한글 글귀 및 주제의 영문 감성 키워드 요약 텍스트만 전송 (최대 300자 이내, 개인정보·계정정보 일체 미포함)
- **보안 및 캔버스 CORS 보호**: 브라우저 클라이언트가 직접 외부 URL을 이미지 소스로 로드하지 않고, 서버 라우트(`services.ts`)에서 fetch하여 `Buffer.from(buf).toString("base64")`로 변환된 `data:image/jpeg;base64,...` URL을 반환하므로 HTML5 Canvas API의 온디바이스 렌더링 시 CORS 오염(tainted canvas)이 원천 차단됨.
- **타 프로그램 기적용 사례**: `ai-webtoon-studio`에서 이미 "무료 대체 렌더러 (pollinations-flux)"로 채택 및 운영 중 (`src/lib/imageGen.ts:103`).

## 6. 모바일 375px 전 구간 레이아웃 측정 근거와 소스 추론 구분

1. **소스 코드 구조 추론**:
   - `choice-grid`는 CSS상 `grid-template-columns: repeat(auto-fit, minmax(140px, 1fr))`로 지정되어 있습니다.
   - 375px 화면 폭에서 좌우 패딩을 제외한 실 컨테이너 너비는 약 335px입니다.
   - 카드가 3개일 때 `335px < 140px * 3 (420px)`이므로 자동으로 2열 + 1열(또는 1열씩 3줄)로 유연하게 감싸집니다(wrap).
2. **미리보기 하단 버튼 (`QuoteCanvas.tsx`) 계산 근거**:
   - `grid-cols-2`로 배치 시 버튼 폭은 각 `(335px - 8px) / 2 = 163.5px`입니다.
   - 버튼 라벨:
     - `🍌 바나나 캔버스`: 한글 8자(약 96px) + 이모지/아이콘(약 32px) + 내부 패딩(16px) = 총 약 144px.
     - `🎨 이미지 스튜디오`: 한글 9자(약 108px) + 이모지/아이콘(약 32px) + 내부 패딩(16px) = 총 약 156px.
   - 163.5px 너비 안에 144px, 156px이 들어가며 `whitespace-nowrap`이 적용되어 텍스트가 줄바꿈되거나 잘리지 않습니다.
3. **한계 구분**:
   - 상기 내용은 폰트 크기(`text-xs` = 12px) 및 CSS 그리드 계산에 따른 **소스 추론 근거**입니다.
   - 실제 375px 모바일 디바이스 뷰포트에서의 시각적 검수는 배포 후 브라우저 실세션 검수(크롬 DevTools 또는 실기기)를 통해 최종 확정되어야 합니다.
