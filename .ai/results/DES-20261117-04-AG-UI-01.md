## 1. 현재 구현 분석 및 문제점

```tsx
// 현재 BookingSettingsCard.tsx 라인 142~149
<fieldset className="cs-steps" aria-label="예약 받을 요일">

        }
      />{" "}

    </label>
  ))}

```

### 식별된 문제점
1. **146 Professional Studio 테마 불일치**:
   - 146 확정안은 정제된 그리드와 인디고/블루 테마 칩 버튼을 지향하나, 현재는 기본 브라우저 체크박스 + 인라인 `marginRight: 8`로 배치되어 있어 투박하고 일체감이 떨어짐.
2. **모바일 375px 터치 타깃 협소**:
   - 모바일 화면에서 작은 체크박스와 단일 글자(`일`, `월`, `화`...)만 감싸고 있어 터치 미스 발생 가능성이 높음 (권장 터치 영역 최소 36×36px 이상).
3. **상태 피드백 부족 (Busy / Disabled)**:
   - 하단 버튼의 `disabled={!!busy}`와 달리, 요일 체크박스에는 `disabled={!!busy}`가 없어 저장/새 주소 생성 중 요일을 조작할 수 있는 결함 존재.
4. **키보드 접근성 및 포커스 링**:
   - 체크박스 자체에만 포커스가 맺히고 라벨 전체로 포커스 링이 확장되지 않아 시각적 포커스 인지가 어려움.

## 2. 146 Professional Studio UI 명세 (권장 설계)

### 2.1 시각 디자인 원칙
- **컨테이너**: `fieldset`을 리셋하고, 7개 요일(`일·월·화·수·목·금·토`)을 한눈에 파악할 수 있는 **7열 세그먼트 그리드** 또는 `flex gap-1.5 flex-wrap` 칩 형태로 구성.
- **선택 상태 (Checked)**:
  - 배경: `bg-blue-50` (`#eff6ff`) 또는 `bg-indigo-50` (`#eef2ff`)
  - 테두리: `border-blue-400` (`#60a5fa`)
  - 글자색: `text-blue-700` (`#1d4ed8`), `font-bold`
  - 체크 표시 아이콘 또는 볼드한 요일 텍스트
- **비선택 상태 (Unchecked)**:
  - 배경: `bg-slate-50` (`#f8fafc`)
  - 테두리: `border-slate-200` (`#e2e8f0`)
  - 글자색: `text-slate-500` (`#64748b`)
- **비활성 상태 (Disabled / Busy)**:
  - `opacity-50 cursor-not-allowed`

## 3. 권장 구현 코드 명세 (Workspace 구현용)

### A. TSX 마크업 (`BookingSettingsCard.tsx`)
```tsx
<fieldset className="rc-days-fieldset" aria-label="예약 받을 요일" disabled={!!busy}>
  <legend className="rc-legend">예약 받을 요일</legend>
  <div className="rc-days-grid" role="group" aria-label="예약 요일 선택">
    {DAYS.map((d, i) => {
      const isChecked = f.days.includes(i);
      const isWeekend = i === 0 || i === 6; // 일(0), 토(6)
      return (
        <label
          key={d}
          className={`rc-day-chip ${isChecked ? "active" : ""} ${isWeekend ? "weekend" : ""}`}
        >
          <input
            type="checkbox"
            className="sr-only" // 시각적으로 숨기고 라벨 칩으로 상호작용
            checked={isChecked}
            disabled={!!busy}
            onChange={(x) =>
              set({
                days: x.target.checked
                  ? [...f.days, i].sort()
                  : f.days.filter((n) => n !== i),
              })
            }
          />
          <span className="rc-day-label">{d}</span>
        </label>
      );
    })}
  </div>
</fieldset>
```
