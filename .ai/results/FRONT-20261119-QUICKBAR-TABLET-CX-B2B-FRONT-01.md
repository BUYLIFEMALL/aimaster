## 자체 검증

- 기존 빠른 메뉴·최근 본 상품·다크 머리글·내 섹션 시험 **28/28**. 반응형 클래스와 머리글 버튼, 포커스, Esc, 넓은 화면 접기·펼치기, 미리보기 분기 확인.
- 제품 의존성의 Tailwind로 새 두 유틸리티 규칙만 메모리에서 생성했습니다. 공개 페이지 복사본의 Chrome DOM에 같은 클래스 변경을 적용해 확인한 후보 첫 표시는 375·767·768·820·1024·1280·1366·1379px에서 머리글 40px, 패널·손잡이 0px. 1380·1440px에서 패널 100px, 손잡이 20px, 상품 24개 대상 가로챔 0. 운영 페이지의 JS와 서버 상태는 바꾸지 않았습니다.
- 자동 새로고침·페이지 조작은 격리 Chrome 프로필에 한정했습니다. 후보를 빌드하거나 배포하지 않았으므로 실제 후보 URL의 화면은 독립 검수 대상으로 남깁니다.
- 모바일 하위 카테고리는 상위 카테고리 페이지가 공개 자식 링크를 이미 표시합니다. 머리글에서 모바일로 숨는 것은 운영사 커스텀 하위 메뉴이며, 이 작업과 별도 후보입니다.
