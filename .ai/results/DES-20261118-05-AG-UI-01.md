## 6. 모바일 375px 전 구간 레이아웃 측정 근거와 소스 추론 구분

1. **소스 코드 구조 추론**:
   - `choice-grid`는 CSS상 `grid-template-columns: repeat(auto-fit, minmax(140px, 1fr))`로 지정되어 있습니다.
   - 375px 화면 폭에서 좌우 패딩을 제외한 실 컨테이너 너비는 약 335px입니다.
   - 카드가 3개일 때 `335px < 140px * 3 (420px)`이므로 자동으로 2열 + 1열(또는 1열씩 3줄)로 유연하게 감싸집니다(wrap).
2. **미리보기 하단 버튼 (`QuoteCanvas.tsx`) 계산 근거**:
   - `grid-cols-2`로 배치 시 버튼 폭은 각 `(335px - 8px) / 2 = 163.5px`입니다.
   - 버튼 라벨:
     - `🍌 바나나 캔버스`: 한글 8자(약 96px) + 이모지/아이콘(약 32px) + 내부 패딩(16px) = 총 약 144px.
     - `🎨 이미지 스튜디오`: 한글 9자(약 108px) + 이모지/아이콘(약 32px) + 내부 패딩(16px) = 총 약 156px.
   - 163.5px 너비 안에 144px, 156px이 들어가며 `whitespace-nowrap`이 적용되어 텍스트가 줄바꿈되거나 잘리지 않습니다.
3. **한계 구분**:
   - 상기 내용은 폰트 크기(`text-xs` = 12px) 및 CSS 그리드 계산에 따른 **소스 추론 근거**입니다.
   - 실제 375px 모바일 디바이스 뷰포트에서의 시각적 검수는 배포 후 브라우저 실세션 검수(크롬 DevTools 또는 실기기)를 통해 최종 확정되어야 합니다.
