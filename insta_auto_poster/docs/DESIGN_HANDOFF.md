# INSTA 포스팅 자동화 (`insta_auto_poster`) 디자인 핸드오프 문서

## 1. 템플릿 명칭 및 테마 개요
- **고유 템플릿 명**: **플로우 위저드 스타일 (인스타 바이럴 변형)** 다크 테마
- **적용 버전**: `v1.23`
- **테마 컨셉**: 기존의 단조로운 라이트 테마를 탈피하여 인스타그램 특유의 생동감 넘치는 로즈/핑크/퍼플 그라디언트와 딥 다크 슬레이트 캔버스가 결합된 몰입형 다크 테마. 단계별 진행 감각(스텝퍼)을 직관적으로 제공하면서 모바일에서도 완벽하게 작동하는 현대적인 SNS 자동화 콘솔.

## 2. 디자인 토큰 사양
- **기본 배경 (`Background`)**: `#0d0f17` (`bg-[#0d0f17]`)
- **서피스 / 카드 (`Surface / Card`)**: `#161922` (`bg-[#161922]`)
- **카드 테두리 (`Border`)**: `#262c3d` (`border-[#262c3d]`)
- **내부 인풋 / 패널 (`Input / Panel`)**: `#0d0f17` 및 `#1f2433`
- **포인트 액센트**:
  - 인스타 바이럴 그라디언트: `bg-gradient-to-r from-pink-500 via-rose-500 to-purple-600`
  - Facebook 블루: `bg-blue-600 hover:bg-blue-500 text-white`
  - Instagram 그린: `bg-emerald-600 hover:bg-emerald-500 text-white`
  - 앰버 악센트: `text-amber-400 bg-amber-500/10 border-amber-500/30`
- **타이포그래피**:
  - 헤드라인: `font-bold text-slate-100`
  - 본문 텍스트: `text-slate-300`
  - 서브 / 보조 설명: `text-slate-400`

## 3. 화면별 반응형 레이아웃 구조
### 데스크톱 (1440px 이상)
- 좌측 `w-64` (260px) 고정 다크 아틀리에 사이드바 (앱 타이틀, `v1.23` 핑크 배지, 개요 대시보드, 2단계 스텝퍼 `게시글 주제 수집` / `게시글 관리`, `API키등록·플랫폼연동`, 신규 `📖 연동 & 사용 매뉴얼`, 로그아웃)
- 우측 메인 콘텐츠 영역: `max-w-5xl` 중앙 정렬, 유연한 그리드 시스템 (카운터 5열, 가이드 4열 바로가기)

### 모바일 (375px ~ 768px 이하)
- 상단 `h-14` (56px) 고정 헤더:
  - 📸 브랜드 로고 및 앱 타이틀 (`INSTA 포스팅 자동화`)
  - `v1.23` 핑크 칩 배지
  - 접근성 지원 햄버거 토글 버튼 (`aria-label="메뉴 열기"`)
- 슬라이드 오버레이 드로어:
  - 딤드 배경 클릭 시 닫힘 처리
  - 모바일 터치 환경에 최적화된 큰 탭 영역 및 라우트 이동 시 자동 닫힘 연동

## 4. 신설 및 전면 개편 페이지
- **비주얼 연동 & 사용 매뉴얼 (`/guide`)**:
  - 🤖 마스코트 안내 배너: 카드뉴스/피드 제작 입문자를 위한 환영 및 파이프라인 소개
  - 5단계 원스톱 인스타그램 포스팅 파이프라인 비주얼 카드
  - Meta 개발자 센터 연동 2가지 경로 안내 (📘 Facebook 페이지 방식 vs 📗 Instagram 로그인 방식 상세 비교 및 원클릭 복사 바)
  - 인스타그램 단일 이미지 vs 캐러셀 4:5 화면 점유율 및 알고리즘 저장/공유 공식 가이드
  - 트러블슈팅 자주 묻는 질문(FAQ) 6종
  - 하단 CTA 배너
- **대시보드 (`/dashboard`)**:
  - 상단 헤더 & 빠른 액션 바 (새 게시글 작성, 예약 게시 즉시 실행)
  - 4대 핵심 파이프라인 바로가기 카드 바
  - 5종 상태 카운터(`임시저장`, `예약됨`, `게시 중`, `게시 완료`, `게시 실패`) 다크 서피스 정돈
  - 다가오는 예약 게시 목록 및 인스타 계정 연결 상태 배너 일체화
- **설정 페이지 (`/settings`)**:
  - 다크 서피스 카드 토큰 적용, 내 Meta 앱 주소 한눈에 보기 카드, API 키 등록 행 및 계정 연결 박스 시인성 극대화
