## 2. 향후 추가 개선 제안 (3대 핵심 항목)
### 1) 프로그램 로직 및 기능 개선
- **Instagram 릴스(Reels) 영상 자동 포스팅 지원**: 현재 피드 단일 이미지 및 캐러셀 위주에서, MP4 숏폼 비디오(9:16) 릴스 자동 발행 API 엔드포인트 연동 확장.
- **피드 게시물 최적 발행 시간대 AI 추천**: 계정별 팔로워 활동량 및 인게이지먼트 데이터를 기반으로 가장 반응률이 높은 요일/시간대를 AI가 자동 추천해 주는 스마트 예약 스케줄러 기능 도입.
- **스토리(Stories) 자동 공유 옵션**: 피드 발행과 동시에 인스타그램 스토리에 미리보기 카드로 크로스 포스팅하는 파이프라인 추가.

### 2) 사용자 인터페이스 (UI) 가독성 및 사용편리성 개선
- **인스타그램 피드 그리드 실시간 프리뷰 룸**: 발행 전 내 실제 인스타그램 프로필 9분할 피드 그리드에 게시물이 어떻게 배치되고 조화를 이루는지 시각적으로 미리 맞춰볼 수 있는 피드 플래너 시뮬레이터 제공.
- **게시글 본문 글자 수 & 해시태그 실시간 카운터 바**: 캡션 작성 시 2,200자 제한 및 해시태그 30개 제한을 시각적 프로그레스 바로 보여주는 카운터 위젯 탑재.

### 3) 타 자동화 프로그램과의 연계 가능한 기능
- **`cardnews-studio` (INSTA Cardnews 자동화) 연동**: 카드뉴스 스튜디오에서 완성된 4:5 고화질 카드뉴스(PNG 슬라이드)를 본 포스팅 자동화 프로그램으로 1클릭 전송하여 즉시 인스타 캐러셀 예약으로 등록하는 크로스 파이프라인 구축.
- **`threads-posting` (Threads 포스팅 자동화) 연동**: 인스타그램에 게시된 본문 캡션과 이미지를 Threads 피드에도 동시 1클릭 발행하는 통합 Meta SNS 멀티 퍼블리싱 연계.
