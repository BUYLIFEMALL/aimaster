> 주인님 결정(2026-10-22): 범위 ①③④ 승인 → 확인 중 **인스타그램 로그인 방식 토큰에는 `business_discovery`가 없음**(시험 회원 토큰으로 무료 요청 `Tried accessing nonexisting field`) → 「릴스 파일 올리기 + 리메이크」로 변경 승인.

## 문제
- 이미 있는 「🔥 떡상 리메이크」(관점 7개 중 3개 추천·항목 수에 맞춘 장수·캡처 이미지 분석)는 인스타 주소를 가져올 수 없고(로그인 필요), 릴스의 **말(음성)** 을 분석하지 못함.
- 릴스 파일을 그대로 서버로 보내면 Vercel 요청 한도(4.5MB)를 넘음.

## 범위
1. 리메이크 화면에 「🎬 릴스 영상 올리기」(mp4·mov·webm, 회원이 저장한 파일).
2. **브라우저 안에서** 장면 4장(긴 변 720px JPEG)과 소리(모노 12kHz WAV, 최대 90초 ≈ 2.9MB)를 뽑음 — 파일은 서버·저장소에 올리지 않음.
3. 분석 API에 `audio`(Gemini만) 추가, 장면은 기존 `images`로. Gemini가 아니면 장면만 분석(안내 문구).
4. 프롬프트에 「릴스 소리 받아쓰기 → 핵심 사실 반영」 한 줄.
- 하지 않음: 자동 수집(Apify·공식 API), DB·저장소 변경.

## 검수

- 배포 1회, 크롬 시험 회원: 짧은 시험 영상(말소리 있는 mp4)으로 장면·소리 추출 → Gemini 분석 1회 → 관점 TOP 3 표시.
