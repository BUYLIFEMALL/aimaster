# INSTA 피드 글·이미지 30일 자동 정리 개발 플랜 (2026-10-22, Claude Code 맥미니 — 승인 대기)

## 1. 발견한 문제
- 루트 최상위 규칙: 회원이 만든 데이터(본문·이미지·임시 캐시)는 **생성 30일 뒤 자동 삭제**.
- INSTA 포스팅 자동화는 **카드뉴스 기록(`cns_insta_posts`)만** 30일 정리(`cleanupOldPosts`)가 있다.
- **피드 글 표 `insta_posts`와 공개 버킷 `insta-post-images/<회원>/`(직접 첨부·AI 이미지·감성 글귀 넘김·상세페이지 넘김 `sd-*`)에는 정리 작업이 없다** — `vercel.json`에 정리 실행이 없고, 코드에도 오래된 글 삭제가 없다(회원이 직접 지울 때만 삭제). DB 쪽 `cron.job`에 따로 등록돼 있는지는 맥미니에서 조회하지 못함(확인 필요).
- 쓰레드 쇼핑제휴(`threads-affiliate-poster`)는 매일 `/api/cron/cleanup-media`가 30일 지난 **글과 그 글의 이미지**를 지우지만, **어느 글에도 연결되지 않은 이미지**(새 글 화면에서 첨부만 하고 저장하지 않은 것, `from-shop-detail/` 복사본 포함)는 지우지 않는다.

| 프로그램 | 버전 | 변경 |
