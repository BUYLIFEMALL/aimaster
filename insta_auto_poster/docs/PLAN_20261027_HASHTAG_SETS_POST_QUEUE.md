## 0. 만들 것 한눈에

| 기능 | 회원이 얻는 것 | 원본과 다른 점 |
|---|---|---|
| **A. 해시태그 묶음** | 자주 쓰는 해시태그를 「카페 홍보」「주말 이벤트」처럼 이름 붙여 저장 → 새 글·카드뉴스에서 한 번에 넣기 | 원본은 해시태그 파일에서 무작위로 한 줄. 우리는 회원이 고르고, AI 해시태그와 섞을 수 있음 |
| **B. 게시 대기열** | 미리 만든 피드 글·카드뉴스를 대기열에 쌓아 두면 「월·수·금 오전 10시」처럼 정한 시간에 하나씩 자동 게시 → 매번 예약 시각을 고르지 않아도 꾸준히 올라감 | 원본은 웹 화면 조작으로 같은 재료를 무작위로 섞어 반복 게시. 우리는 공식 API, 같은 글 재게시 없음 |

## 2. 기능 A — 해시태그 묶음

| 항목 | 내용 |
|---|---|
| 화면 | 설정 또는 새 글 화면 옆 「#️⃣ 해시태그 묶음」: 묶음 목록(이름·태그 수) · 만들기/고치기/지우기. 새 글·카드뉴스 캡션 편집 칸 아래 「묶음 넣기」 버튼 → 고르면 현재 해시태그에 합침(같은 태그는 한 번만) |
| AI와 섞기 | 「AI 해시태그 + 내 묶음」 선택 시 AI 결과 뒤에 묶음을 붙이고 전체 30개 상한(인스타 제한) 안에서 자름 |
| 저장(새 표) | `insta_hashtag_sets(id, user_id, name, tags text[], created_at, updated_at)` · RLS 본인만 · 묶음 이름 회원별 중복 금지 · 묶음 최대 50개·묶음당 30개 |
| 수명 | 회원 설정에 가까운 자료라 30일 자동 삭제 대상 아님(최상위 규칙의 「계정·설정」 구분) — 담당이 정리 정책 문서에 한 줄 명시 |
| 시험 | 묶음 만들기·넣기·중복 합치기·30개 자르기 단위 시험, 다른 회원 묶음 안 보임 |

## 3. 기능 B — 게시 대기열 (꾸준 게시)

**핵심 생각: 새 게시 엔진을 만들지 않는다.** 대기열에 넣은 글에 「다음 빈 시간」을 자동으로 예약 시각으로 넣어 주고, 실제 게시는 지금의 예약 실행(`dispatch.ts`)이 그대로 한다.

| 항목 | 내용 |
|---|---|
| 대기열 시간표 | 회원이 요일·시각을 고름(예: 월·수·금 10:00, 하루 최대 3칸). 저장 새 표 `insta_queue_settings(user_id, slots jsonb, enabled, timezone 'Asia/Seoul', updated_at)` · RLS 본인만 |
| 대기열에 넣기 | 새 글·카드뉴스 완성 화면에 「대기열에 넣기」 버튼(지금의 「즉시 게시」「예약」 옆). 넣는 순간 시간표에서 **비어 있는 다음 칸**을 찾아 `scheduled_at`을 채우고 `status='scheduled'`로 저장 + 대기열 표시 칸(`queued boolean` 또는 `source='queue'`)을 남김 — 피드(`insta_posts`)·카드뉴스(`cns_insta_posts`) 둘 다 |
| 대기열 화면 | 「📥 게시 대기열」: 다음 게시 시각 순서로 목록, 끌어서 순서 바꾸기(시각을 서로 바꿈), 빼기(다시 초안으로), 비어 가면 「남은 글 2개 — 3일 뒤 대기열이 비어요」 안내 |
| 반복 금지 | 이미 `published`인 글은 다시 대기열에 넣지 않음. 같은 사진·같은 캡션을 무작위로 다시 섞어 올리는 기능은 만들지 않음(원본 방식 ❌) |
| 안전 | 하루 게시 상한(시간표 칸 수, 최대 3) · 게시 실패 글은 대기열에서 빠져 「실패」로 표시되고 다음 글은 정상 진행 · 예약 실행이 멈춰 있으면(회원 cron-job.org 꺼짐) 대기열 화면 맨 위에 경고 |
| 예약 실행 | [예약 기능 지침](../../docs/SCHEDULER_POLICY.md) 그대로 — 대기열에 글이 생기면 회원 cron-job.org 작업 자동 켜기, 남은 예약이 없으면 자동 끄기(지금 동작 재사용) |
| 시험 | 다음 빈 칸 계산(요일·시각·하루 상한·한국 시간 경계), 순서 바꾸기, 빼기, 실패 뒤 다음 글 진행, 이미 게시된 글 재등록 막기, 다른 회원 자료 안 보임 |

## 4. 하지 않는 것
- 인스타 웹 화면 조작 게시, 여러 계정 돌려 쓰기·접속 위치 변경, 비밀번호 저장(원본 방식).
- 같은 재료 무작위 재조합 반복 게시.
- 릴스(동영상) 대기열 — 지금 프로그램이 릴스 게시를 하지 않으므로 범위 밖.
