## 2. 패키지 설치마법사 실행 (DB 만들기부터 인터넷에 올리기까지 한 번에)

프로그램 폴더 맨 위에 있는 실행 파일을 **더블클릭**합니다.

- **윈도우**: `패키지설치마법사.cmd` 더블클릭 (「Windows의 PC 보호」 창이 뜨면 [추가 정보] → [실행])
- **맥**: `패키지설치마법사.command` 더블클릭 (「확인되지 않은 개발자」 창이 뜨면 마우스 오른쪽 클릭 → [열기] → [열기], 처음 한 번만)

마법사가 8단계를 차례로 안내합니다. **필요한 화면은 마법사가 브라우저로 직접 열어 주고, 붙여 넣을 내용은 클립보드에 복사해 둡니다.**

| 단계 | 마법사가 하는 일 | 내가 할 일 |
|---|---|---|
| ① Node.js | 설치돼 있는지 확인(윈도우는 없으면 자동 설치 제안) | 설치 후 마법사 다시 실행 |
| ② Supabase 프로젝트 | 프로젝트 목록 열기(이미 조직이 있으면 그 조직의 [New project] — 새 조직 만들지 않기) | 이름·DB 비밀번호(Generate 후 메모)·지역 **Asia-Pacific**(서울은 Need a specific region?) → 생성 → **주소창 주소 붙여넣기** |
| ③ Supabase 키 | API Keys 화면 열기, **맞는 키인지 자동 확인** | Publishable key → Secret key 순서로 붙여넣기(화면에 안 보임) |
| ④ DB 만들기 | 설치 SQL을 **클립보드에 복사**하고 SQL Editor 열기, 끝나면 **성공 여부 자동 확인** | 빈 칸 클릭 → 붙여넣기 → [Run] |
| ⑤ 이메일 확인 끄기 | Sign In / Providers 화면 열기 | Email → **Confirm email 끄기** → Save |
| ⑥ 내 사이트 설정 | 주소·비밀값 자동 생성 | 사이트 이름(영문, 주소가 됨) · 화면에 표시할 내 이름/브랜드 |
| ⑦ 설치·빌드 | 프로그램 설치·확인(3~5분) | 기다리기 |
| ⑧ 인터넷에 올리기 | Vercel 연결·설정 등록·배포, **실제 주소 자동 확인** | 브라우저에서 Vercel 로그인(처음이면 무료 가입) |

- 중간에 창을 닫아도 **다시 더블클릭하면 이어서** 진행합니다(처음부터 하려면 질문에 `n`).
- 끝나면 내 사이트가 열리고, 프로그램 폴더에 **`설치결과.txt`**(내 사이트 주소·Meta 앱에 등록할 콜백 주소)가 생깁니다. 콜백 주소는 클립보드에도 복사돼 있습니다.

## 4. Meta 앱 만들기 (Instagram 로그인 방식 권장) — 상세는 `KIT/PLATFORMS.md` 1번

요약:
1. developers.facebook.com → **앱 만들기** → 이용 사례 **"Instagram에서 메시지 및 콘텐츠 관리"** → 앱 생성
2. 이용 사례 → 맞춤 설정 → **Instagram 로그인이 포함된 API 설정**
   - **4. Instagram 비즈니스 로그인 설정 → OAuth 리디렉션 URI**: `https://내주소/api/instagram/callback/byok` → 저장
   - 같은 화면 위쪽 **Instagram 앱 ID / Instagram 앱 시크릿 코드** 복사
3. **앱 역할 → 역할 → Instagram 테스터**에 내 인스타 계정 추가 → 인스타 **설정 → 앱 및 웹사이트 → 테스터 초대 → 수락**
4. **앱 설정 → 기본 설정 → 앱 도메인**: `내주소의 도메인`(예: `hong-insta.vercel.app`) → 저장

> 내 사이트 **API키등록·플랫폼연동** 맨 위 **「내 Meta 앱에 등록할 주소 한눈에 보기」** 카드에 내 주소가 복사 버튼과 함께 나옵니다.

## 5. 프로그램에 키 등록 · 인스타 계정 연결

내 사이트 → 좌측 **API키등록·플랫폼연동**
1. **Instagram 앱 ID / Instagram 앱 시크릿 코드** 저장 → 초록색 **Instagram 로그인 방식으로 연결하기** → 인스타 로그인·허용
2. **Gemini API 키**(이미지), **OpenAI 또는 Claude 키**(캡션) 저장
3. (선택) Perplexity 키(실시간 주제 수집)

**첫 게시 시험**: **게시글 관리 → + 새 게시글 작성**에서 주제 입력 → 캡션·이미지 생성 → **즉시 게시** → 내 인스타 피드에 올라오면 완료.

**내가 만든 이미지로 바로 올리기 (AI 생성 없이)**: 새 게시글 화면의 **「이미지 파일 직접 첨부 (n/필요 장수)」** 칸에 이미지를 넣고 캡션을 쓰면, 「게시물 생성하기」가 AI 생성을 건너뛰고 그대로 임시저장·예약·즉시 게시합니다(초록 안내 문구가 보이면 AI 키 없이도 됩니다). 피드는 1장, **카드뉴스는 4장**이 필요하고, 카드뉴스는 **여러 파일을 한 번에 선택**하면 파일 이름순으로 차례대로 올라갑니다(예: `1.png`~`4.png`).

## 6. 예약 게시 연결 (정해진 시각에 자동 게시)

> **공지 — 예약 게시는 1분마다 「올릴 시각이 된 글」을 확인해 주는 곳이 있어야 동작합니다.**
> Vercel **무료(Hobby)** 요금제는 자동 실행을 하루 1번만 허용하므로, Vercel로 1분 확인을 하려면 **Vercel 유료(Pro) 구독**이 필요합니다.
> 그래서 이 배포판의 **기본 방식은 B(내 cron-job.org)** 이고, Vercel 유료(Pro)라면 A를 켠 뒤 설정에서 「Vercel 예약 호출」을 고를 수도 있습니다(회원마다 선택). 「즉시 게시」는 아무 연결 없이도 됩니다.

### B. 기본 — 내 cron-job.org (무료, API 키만 등록)
1. https://console.cron-job.org/signup 에서 무료 가입 → 이메일 인증 → 로그인
2. 콘솔 **Settings → API** → **Create API key** → 키 복사 (**IP 제한은 켜지 마세요** — Vercel 서버 주소는 계속 바뀝니다)
3. 내 사이트 → **API키등록·플랫폼연동** → **⏰ 예약 발행** → 실행 방식이 「내 cron-job.org · 기본값」인지 확인 → 아래 **cron-job.org API 키** 칸에 붙여 넣고 **저장** → 끝
4. 이제 **게시글을 예약**하면 프로그램이 내 cron-job.org에 1분 확인 작업을 **자동으로 만들고 켭니다**. 남은 예약이 없으면 **자동으로 끕니다**(cron-job.org 콘솔에서 작업 「INSTA 포스팅 예약 발행(1분)」이 켜졌다 꺼졌다 하는 것이 정상).
5. **게시글 관리** 위 「⏰ 예약 발행」 줄에서 상태(실행 중·대기·일시정지됨)를 보고 **전체 일시정지 / 재개**를 할 수 있습니다.
   - 이 사이트에 가입한 사람마다 **각자 본인 키**로 돌아갑니다(서로의 글은 게시되지 않음). cron-job.org에는 사이트 비밀값(`CRON_SECRET`)이 아니라 **회원 전용 연결값**만 들어갑니다(프로그램이 자동으로 넣음 — 직접 작업을 만들지 마세요).
   - cron-job.org 무료 규칙: 작업당 1분 1회, 응답 30초 초과 시 실패, 실패 25번 넘으면 작업 자동 정지(프로그램이 예약할 때마다 다시 켬), API 하루 100회.
   - 예약 시각이 24시간 넘게 지난 글은 자동으로 올리지 않습니다(장애 뒤 오래된 글이 한꺼번에 올라가는 것을 막음).

### A. Vercel 유료(Pro) 구독자 — Vercel 예약 호출 켜기 (선택)
1. 프로그램 폴더에서 PowerShell을 엽니다(탐색기 주소창에 `powershell` → Enter).
2. 실행: `powershell -ExecutionPolicy Bypass -File KIT\enable-vercel-cron.ps1` (맥: `bash KIT/enable-vercel-cron.sh`)
3. 스크립트가 `vercel.json`에 1분 예약 호출을 넣고 환경변수 `INSTA_PLATFORM_SCHEDULER=on`을 등록한 뒤 다시 배포합니다.
4. 사이트 → **API키등록·플랫폼연동 → ⏰ 예약 발행**에서 「Vercel 예약 호출」을 고르면 cron-job.org 키 없이 예약할 수 있습니다(회원마다 선택, 고르지 않은 회원은 기본 cron-job.org 그대로).
   - 무료 요금제에서 실행하면 배포가 실패합니다 → 프로그램 폴더의 `vercel.json`을 지우고 B를 쓰세요.

> **예전 방식으로 설치했다면**(2026-10-19 이전: cron-job.org에 `/api/posts/dispatch-scheduled` + `CRON_SECRET` 작업을 직접 만든 경우): ① Supabase SQL Editor에서 `KIT/upgrade-20261019-cronjob.sql`을 한 번 실행 ② 새 코드로 다시 배포 ③ cron-job.org에서 예전 작업을 **끄거나 지우고** 위 B 순서대로 키만 등록하세요.

## 7. (선택) 내 도메인 연결

1. Vercel → **Settings → Domains → Add** → 안내대로 DNS 등록(`CNAME` → `cname.vercel-dns.com` / 루트는 `A` → `76.76.21.21`) → **Valid**
2. 새 주소로 고칠 곳: Vercel `NEXT_PUBLIC_SITE_URL`(수정 후 **Redeploy**) · Meta **OAuth 리디렉션 URI 추가** · Meta **앱 도메인 추가** · 내 `.env.local` · 사이트 설정 → ⏰ 예약 발행에서 **cron-job.org 키를 한 번 더 저장**(새 주소로 예약 작업이 다시 만들어짐 — cron-job.org 콘솔에 예전 주소의 작업이 남아 있으면 삭제)
3. 프로그램에서 **Instagram 로그인 방식으로 연결하기**를 한 번 더 누릅니다.

## 8. 자주 막히는 곳

| 증상 | 확인 |
|---|---|
| "가입 확인 메일" 안내가 뜸 | Supabase Email → **Confirm email 끄기** |
| 연결 시 "Invalid platform app" / 앱 ID 오류 | **Instagram 앱 ID**(Instagram 로그인 API 설정 화면)를 넣었는지 — Meta 앱 ID와 다름 |
| 연결 시 "리디렉션 URI" 오류 | Meta에 등록한 주소가 `https://내주소/api/instagram/callback/byok`와 **완전히 같은지**, `NEXT_PUBLIC_SITE_URL`이 실제 주소인지 |
| 연결은 되는데 게시 실패 | 인스타가 **비즈니스/크리에이터** 계정인지, 테스터 초대를 **수락**했는지 |
| 이미지 생성 실패 | Gemini 키와 **결제 연결**(이미지는 무료 한도 없음), 사용량: https://aistudio.google.com/usage |
| 예약 글이 안 올라감 | 설정 → ⏰ 예약 발행에 cron-job.org 키가 「등록됨」인지, 게시글 관리 위 상태 줄이 「일시정지됨」이 아닌지, cron-job.org 콘솔의 작업 「INSTA 포스팅 예약 발행(1분)」 최근 실행이 성공(200)인지(401이면 키를 다시 저장하면 새 연결값으로 다시 만들어짐) |
| 설정을 바꿨는데 반영 안 됨 | Vercel 환경변수는 바꾼 뒤 **Redeploy** |
| 빌드 실패 `file is too long` / `TurbopackInternalError` (윈도우) | 폴더 경로가 너무 깁니다. 바탕화면·다운로드 안 깊은 곳 말고 `D:\work\my-insta`처럼 **짧은 경로**로 폴더를 옮긴 뒤 다시 실행 |
