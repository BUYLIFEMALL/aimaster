## 1. 프로그램의 사용목적 및 대상
- **사용목적**: 가사 및 음악 기획부터 Suno 스타일 프롬프트 생성, 가사 기반 스토리보드 자동 분할, Gemini 나노바나나 엔진을 통한 고화질 장면(Scene) 이미지 생성, Google Veo 3.1 엔진을 통한 시네마틱 비디오 클립 일괄 렌더링 및 심리스 무한 루프(Seamless Loop) 영상 생성까지 원스톱으로 지원하는 AI 뮤직비디오 프로덕션 자동화 플랫폼.
- **주요 대상**:
  - AI 작곡(Suno/Udio) 음원에 맞춰 감각적인 비주얼 뮤직비디오를 제작하려는 크리에이터.
  - 유튜브 쇼츠, 인스타그램 릴스, 틱톡 등에 사용할 고화질 세로형(9:16) 및 가로형(16:9) 음악 배경 영상을 빠르게 양산하려는 숏폼 마케터.
  - 영상 제작/카메라 연출 지식이 부족해도 AI 연출 프롬프트로 완성도 높은 시네마틱 씬 클립을 얻고자 하는 1인 창작자.

## 2. 개발 구현에 사용된 도구 / 개발기법 / 플러그인 / 스킬
- **프레임워크 및 런타임**: Next.js 16.2.11 (App Router, Turbopack), React 19, TypeScript 5, Tailwind CSS v4.
- **디자인 테마 템플릿**: **사이버 네온 다크 콘솔 스타일 — 뮤직비디오 앰프 데크 에디션 (Cyber Neon Dark Console Style — Music Video Deck Edition)**
  - 퓨어 딥 블랙(`#060911`) 및 다크 네이비(`#0a0f1d`) 배경 일체화.
  - 네온 시안(`#00f2fe`) 및 네온 핑크/마젠타(`#f43f5e`, `#ec4899`) 앰프 데크 포인트 컬러.
  - 375px 모바일 전용 56px 슬림 네온 헤더 + 부드러운 슬라이딩 오버레이 드로어 네비게이션.
- **백엔드 및 연동 기술**:
  - Google Gemini 2.5: 가사 기획, 음악 무드/스타일 태그 추출, 비주얼 스토리보드 자동 분할.
  - Gemini 나노바나나(`gemini-nano-banana-2.1`, 기준 코드 사본): 장면별 고화질 시네마틱 이미지 생성.
  - Google Veo 3.1 (`veo-3.1-lite` / `veo-3.1`): 장면 이미지 기반 고화질 비디오 클립 렌더링 및 심리스 루프(8초) 처리.
  - Supabase SSR (`@supabase/ssr`): AIMaster 통합 인증 및 세션 제어, API 키 격리 관리.
  - JSZip: 전체 프로젝트(가사, 프롬프트, 이미지, 비디오 클립) 원클릭 압축 다운로드.

## 3. 핵심 기능 및 시스템 로직 / 아키텍처, 장점 및 단점

### 1) 시스템 워크플로우 (4단계 파이프라인)
```
[1단계: 음악 & 가사 기획] (/music)
  - 곡 제목, 장르, 무드, 템포, 보컬 프리셋 설정
  - Gemini 2.5를 통한 완성형 가사 자동 생성 및 Suno용 음악 프롬프트 추출
  - 참고 이미지(무드보드) 첨부 기능
          ↓
[2단계: AI 스토리보드 분할] (/storyboard)
  - 가사를 시간대별 씬(Scene)으로 자동 분할
  - 장면별 카메라 앵글 및 시네마틱 비주얼 프롬프트 자동 작성
  - 화풍(Art Style) 프리셋 선택 (시네마틱 8K, 사이버펑크 3D, 실사 등)
          ↓
[3단계: 고화질 장면 렌더링] (/scenes)
  - Gemini 나노바나나 기반 씬 이미지 개별/일괄 생성 (16:9 와이드 또는 9:16 쇼츠)
  - 이미지 기반 Google Veo 3.1 비디오 모션 렌더링 (8초 심리스 루프 지원)
  - 씬별 JPG/MP4 즉시 다운로드 및 전체 에셋 ZIP 일괄 패키징
          ↓
[매뉴얼 & 연동 콘솔] (/guide, /settings)
  - 비주얼 연동 매뉴얼 및 Suno/Veo 실전 팁 안내, 본인 Gemini API 키 암호화 보관
```

### 2) 시스템 장점
- **체계적인 엔드투엔드 파이프라인**: 단순 텍스트-비디오 생성이 아니라 기획(가사·Suno)-연출(스토리보드)-이미지-비디오 렌더링으로 이어지는 전문 프로덕션 워크플로우 구현.
- **심리스 루프 영상 특화**: 첫 프레임과 마지막 프레임을 일치시켜 숏폼 반복 재생에 최적화된 무한 루핑 영상 생성 가능.
- **철저한 본인 키 원칙 및 비용 투명성**: 회원 본인의 Gemini API 키로만 동작하며, 렌더링 전 예상 비용(달러 및 원화)을 사전 고지하여 안전한 비용 제어 가능.
- **일체형 ZIP 패키징**: 렌더링된 모든 클립과 가사, 프롬프트를 한 번에 압축 저장하여 외부 영상 편집 툴(프리미어, 캡컷) 연계 용이.

### 3) 단점 및 한계
- **Veo 비디오 렌더링 대기 시간**: Google Veo의 특성상 클립당 1~3분 정도의 비동기 폴링 시간이 소요됨.
- **오디오-비디오 자동 싱크 미포함**: 현재 버전은 음원과 비디오를 하나로 인코딩하는 기능은 포함하지 않으며, 클립과 가사/프롬프트를 ZIP으로 다운받아 편집기에서 조합하는 형태임.

## 4. 현재 버전 및 버전별 변경 히스토리

- **v1.12 (2026-10-23, 현재 버전 - Claude Code 윈도우)**: **Veo 3.1 Preview 종료 대응.** Google이 Gemini API의 `veo-3.1-*-generate-preview` 3종을 2026-10-22 종료(공식 문서 확인) → 장면 영상 모델을 **Gemini Omni Flash**(`gemini-omni-1.1-flash`, 초당 약 $0.10, 같은 회원 Gemini 키)로 교체.
  - 호출은 공용 기준 코드 `ai-video-models`·`ai-video-parse`·`ai-video-providers` 사본(`src/lib/video/*` — 직접 고치지 말 것, 기준 `ai-image-studio/lib/video/`)으로 통일. 기준에 선택값 `aspectRatio`(16:9 가로)·`startUrl` 생략(글만으로 생성) 추가.
  - `api/music/video/start` → `submitVideoJob`(작업 정보 `job` 응답, 업체가 바로 주면 MP4), `status`(POST `{job}`) → 진행 중 JSON / 완료 시 MP4 바로 응답. `download` API 삭제. `src/lib/music/veo.ts`는 옵션 검사·비용만 남김.
  - 루프: 끝 화면 = 시작 이미지(8초 고정 규칙 없음). 길이 4·6·8초는 프롬프트 안내(Omni는 길이 칸 없음). 저장된 옛 Veo 모델 값은 자동으로 Omni Flash로 바뀜.

## 6. 기존 다른 프로그램과의 연계 / 기능 병합 제안 및 기능 보완·확장 아이디어
- **`ai-audio-extractor` (오디오 추출기)와의 연계**: 업로드된 음악의 보컬/MR/드럼 비트를 자동 분리하여, 비트 드롭 지점에 정확히 맞춰 비디오 씬 전환 포인트를 추천하는 지능형 연동.
- **`shorts-viral-studio` (쇼츠 바이럴)와의 연계**: 생성된 9:16 심리스 루프 비디오 위에 바이럴 쇼츠 텍스트 후킹 자막과 음원을 결합하여 1클릭 숏폼 완성 파이프라인 구축.
- **`ai-image-studio` (AI 이미지 자동화)와의 연계**: 이미지 스튜디오에서 생성한 캐릭터 및 화풍 레퍼런스를 뮤직비디오 씬 레퍼런스로 직접 임포트하여 주인공 캐릭터의 일관성 완벽 유지.

## 7. 사용자 편의성 증대를 위한 디자인 UI개선안과 레이아웃/테마/스타일 변경 제안
- **오디오 시각화 웨이브폼 컴포넌트**: 1단계 음악 기획 및 프리뷰 영역에 네온 앰프 이퀄라이저 비주얼라이저를 도입하여 오디오 데크 감성 극대화.
