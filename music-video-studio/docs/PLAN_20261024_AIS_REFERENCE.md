# 개발 플랜 — AI 이미지 스튜디오 이미지를 참고 이미지로 가져오기 (2026-10-24)

작성: Claude Code 윈도우 · 음악 담당 세션 `claude-win-20261024-music`. 상태: **주인님 승인 대기**.
근거: `docs/IMPROVEMENT_BACKLOG.md` 3-3(맨 위 표 5번 → 주인님 순서상 4번).

## 1. 문제
- 2단계 스토리보드의 「참고 이미지(최대 3장)」는 내 PC 파일만 올릴 수 있습니다. AI 이미지 스튜디오에서 만든 캐릭터·스타일 이미지를 쓰려면 내려받았다가 다시 올려야 합니다.

## 2. 기준으로 삼는 기존 코드
- 뮤직비디오 v1.13 「AI 음악 스튜디오에서 곡 가져오기」(`src/lib/music/amsSongs.ts`) — 다른 프로그램의 공용 DB 기록을 **읽기만** 하고 회원 `user_id`로 거른 뒤, 비공개 저장소 파일을 1시간 서명 주소로 넘기는 방식. 같은 틀을 이미지에 씁니다.
- AI 이미지 스튜디오 저장 구조(코드 확인): 기록 `usage_logs`(program_id `26b9f0b2-…`, `metadata.image_path` 또는 옛 `metadata.image_url`), 비공개 저장소 `ai-image-generations`, 30일 보관. 경로 해석은 `ai-image-studio/lib/imageStorage.ts` `storagePathOf`와 같은 규칙.

## 3. 범위 (DB·저장소 변경 없음, AI 이미지 스튜디오 코드 변경 없음)
1. 서버 `GET /api/music/ais-images` — 내 최근 30일 AI 이미지 스튜디오 이미지 최대 40장(작은 미리보기용 1시간 서명 주소, 프롬프트 앞부분, 만든 날). 회원 본인 행만, 경로가 `{user_id}/`로 시작하는 파일만.
2. 스토리보드 참고 이미지 칸에 「AI 이미지 스튜디오에서 가져오기」 버튼 → 썸네일 목록 → 누르면 브라우저가 그 이미지를 받아 기존과 같은 JPEG 줄이기를 거쳐 참고 이미지에 추가(최대 3장 규칙 그대로). 이미지가 없으면 「AI 이미지 스튜디오에서 먼저 만들어 주세요」 + 링크.
3. 이후 흐름(장면 이미지 생성 때 참고 이미지 함께 보냄)은 그대로입니다.

## 4. 검수
- 로컬: 시험(경로 해석·회원 폴더 검사)·`tsc`·`npm run build`.
- 운영(메인 크롬, 시험 계정): 목록에 내 AI 이미지 스튜디오 이미지가 보이는지, 다른 회원 것은 없는지(행 소유자 DB 확인), 가져오면 참고 이미지 칸에 추가되는지, 그 참고 이미지로 장면 이미지 1장을 만들어 분위기가 따라가는지 확인. 비로그인 401.
