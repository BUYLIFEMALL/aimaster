## 2. 고칠 내용
1. **화풍 분석 단계(새 API `/api/music/style`)** — 참고 이미지(최대 3장)를 회원 본인 Gemini 텍스트 모델(이미지 입력)로 분석해 JSON으로 받음: 한국어 요약(화면 표시용), 영문 화풍 지시문(매체·선·채색·명암·질감·색감·사진 여부), 「사진인가/그림인가」, 인물 특징. 결과는 프로젝트에 저장(`styleProfile`).
2. **2단계 화면** — 참고 이미지를 넣으면 「🎨 화풍 분석」(자동 실행 + 다시 분석) → 요약 카드 표시·직접 고치기. 화풍 고르기에 **「참고 이미지 화풍(분석 결과)」** 항목을 추가하고 분석이 끝나면 자동 선택(다른 화풍으로 바꿀 수도 있음).
3. **스토리보드 프롬프트** — 분석된 화풍을 시스템 지시에 넣고, 그림 화풍이면 렌즈·필름 같은 사진 표현을 쓰지 말고 그 매체로 묘사하게 함. 인물은 참고 이미지 인물 특징을 우선(없으면 기존 한국인 규칙).
4. **장면 이미지 프롬프트** — 「참고 이미지의 화풍(선·채색·질감·색감)을 정확히 따르라 + 분석 지시문」을 맨 앞에, 사진처럼 만들지 말라는 문구 추가. 고른 프리셋 화풍 문구는 「참고 이미지 화풍」일 때 넣지 않음.
5. **영상 프롬프트·흐름** — 영상 프롬프트에도 분석 지시문과 「실사로 바꾸지 말 것」을 넣음. **참고 이미지가 있는데 장면 이미지가 없으면** 영상 단추에서 「장면 이미지를 먼저 만들고 그 그림으로 영상 만들기」를 기본으로 함(이미지 1장 비용 추가 안내), 「글만으로 영상」은 경고와 함께 선택 가능.
6. **시험** — 프롬프트 만들기 순수 함수 시험 추가(그림 화풍일 때 사진 표현·Cinematic 문구가 빠지는지, 분석 지시문이 들어가는지).
