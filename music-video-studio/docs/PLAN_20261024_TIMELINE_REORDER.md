## 1. 문제
- 장면은 스토리보드 AI가 만든 순서 그대로이고, 순서를 바꾸려면 가사·묘사를 칸마다 옮겨 적어야 합니다.
- 장면 화면은 큰 카드 2열이라 전체 흐름을 한눈에 보기 어렵습니다.

## 2. 범위 (화면만, 서버·DB·생성 방식 그대로)
1. 3단계 「장면 제작」 맨 위에 **가로 타임라인 띠**: 장면마다 작은 카드(번호·이미지 또는 영상 썸네일·가사 첫 줄·영상/이미지/없음 표시), 가로 스크롤.
2. **끌어서 놓기**로 순서 바꾸기(PC 마우스). 카드마다 **◀ ▶ 버튼**도 두어 휴대폰·키보드에서도 옮길 수 있게 합니다(누르는 영역 24px 이상).
3. 순서를 바꾸면 프로젝트의 장면 순서가 바뀌고(만든 이미지·영상은 장면에 붙어 그대로 따라감), 아래 장면 카드·최종 뮤직비디오 순서도 함께 바뀝니다.
4. 곡에 시간 가사가 있을 때 순서를 가사와 다르게 바꾸면 「가사 시각에 맞춤」이 맞지 않아 「고르게 나눔」으로 바뀝니다 — 타임라인 아래에 한 줄 안내.
5. 순수 함수 `moveItem(list, from, to)`(`src/lib/music/reorder.ts`) + 시험.

## 3. 검수
- 로컬: 시험(앞·뒤·같은 자리·범위 밖)·`tsc`·`npm run build`.
- 운영(메인 크롬, 시험 계정, v1.23 배포 후): 장면 2개에 이미지·영상을 만든 뒤 타임라인에서 끌어서·버튼으로 순서 바꾸기 → 새로고침 뒤 순서 유지, 장면 카드·최종 렌더 순서 반영 확인. 같은 시험에서 2번 일괄 진행 칸(영상 2개 일괄 생성)도 확인. 휴대폰 폭 가로 넘침 확인.
