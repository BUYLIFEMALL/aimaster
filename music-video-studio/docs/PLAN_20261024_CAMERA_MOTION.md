# 개발 플랜 — v1.21 장면별 카메라 움직임 고르기 (2026-10-24)

작성: Claude Code 윈도우 · 음악 담당 세션 `claude-win-20261024-music`. 상태: **주인님 승인 대기**.
근거: `docs/IMPROVEMENT_BACKLOG.md` 2-1(2026-10-24 정리에서 다음 후보 1순위).

## 1. 문제
- 장면 영상 프롬프트(`src/lib/music/prompts.ts` `buildVideoPrompt`)에 「부드러운 카메라 움직임」 한 줄이 늘 고정으로 붙습니다. 회원은 장면마다 움직임을 고를 수 없고, 바꾸려면 영문 장면 묘사를 직접 고쳐야 합니다.
- 스토리보드 AI가 장면 묘사에 카메라 지시를 자유롭게 넣기도 해서, 고정 문구와 지시가 겹치거나 엇갈릴 수 있습니다.

## 2. 범위
- 장면 카드마다 「카메라 움직임」 고르기 칸을 추가합니다. 기본값은 「자동」이며, 지금과 똑같이 동작합니다.
- 항목 8개: 자동 · 고정 · 천천히 다가가기 · 천천히 물러나기 · 옆으로 이동 · 피사체 돌기 · 위에서 내려다보며 이동(드론) · 손으로 든 느낌.
- 「자동」이 아니면 고정 문구 대신 고른 움직임의 영어 지시 한 줄을 넣고, 장면 묘사의 카메라 표현보다 이 지시를 따르라는 문장을 함께 넣습니다.
- 심리스 루프가 켜져 있으면 「처음 구도로 돌아오기」 문장이 그대로 붙습니다. 루프 + 한 방향 움직임(다가가기 등)은 서로 맞지 않을 수 있어, 화면에 짧은 안내만 띄웁니다(막지는 않음).
- 이미지 프롬프트·스토리보드 AI·공용 영상 코드(`src/lib/video/*` 사본)는 바꾸지 않습니다. 메뉴·흐름도 그대로입니다.

## 3. 구현 순서
1. `presets.ts`: `CAMERA_MOTIONS` 목록(값·한국어 이름·영어 지시) + `isCameraMotion()` 추가.
2. `types.ts`·`project.ts`: `Scene`에 `camera?: CameraMotionId` 추가. 저장본 정리 함수는 목록에 없는 값이면 「자동」으로 둡니다(옛 저장본·JSON 파일 그대로 열림).
3. `prompts.ts` `buildVideoPrompt(scene, artStyle, loop, camera)`: 「자동」이면 지금 문장 그대로, 아니면 고른 지시로 바꿉니다.
4. `api/music/video/start/route.ts`: `camera` 값을 받아 목록 검사 뒤 넘깁니다(목록 밖 값은 「자동」 취급).
5. `scenes/page.tsx`: 장면 카드의 영상 버튼 위에 선택 칩(또는 작은 선택 상자) 추가, 고르면 프로젝트에 저장, 영상 생성 요청에 함께 보냄. 휴대폰 폭에서 줄바꿈 확인.
6. 시험(`tests/music.test.mjs`): 자동 = 예전 문장과 같음, 고른 값 = 지시 포함·고정 문구 없음, 목록 밖 값 = 자동, 루프 문장 유지, 저장본 정리.
7. 사용 매뉴얼(`guide`)에 한 줄 추가. 버전 v1.21(코드 + DB `programs.version`).

## 4. 검수
- 로컬: 시험·`tsc`·`npm run build`.
- 운영(메인 크롬, 시험 계정 `buylifemall@naver.com`): 장면 카드에 선택 칸이 보이고 저장되는지, 새로고침 뒤에도 유지되는지, 영상 생성 요청 본문에 값이 실리는지 확인.
- 실제 영상 시험: 같은 장면 이미지로 4초 영상 2개(예: 「천천히 다가가기」·「피사체 돌기」)를 만들어 움직임 차이를 눈으로 확인.
