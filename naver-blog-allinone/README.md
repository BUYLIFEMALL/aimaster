# 네이버 블로그 올인원 자동화 (naver-blog-allinone)

> **공식 서비스 URL**: https://naver-blog-allinone.buylife.xyz  
> **현재 버전**: `v1.49` (2026-10-18)  
> **디자인 템플릿**: **플로우 위저드 스타일 (네이버 그린 라이트 변형)**

네이버 블로그를 위한 통합형 AI 자동화 프로그램입니다.  
E-E-A-T 기반 아이디어 발굴부터 멀티모달 사진 비전 분석, 실시간 뉴스 및 키워드 파인더 경쟁 분석, 네이버 스마트에디터 ONE 전용 서식 생성 및 전용 크롬 확장 1초 자동 주입까지 전체 라이프사이클을 지원합니다.

---

## 1. 프로그램 사용 목적 및 대상
- **사용 목적**: 네이버 검색엔진(C-Rank / D.I.A.+)에 최적화된 고품질 포스팅을 아이디어 기획부터 스마트에디터 ONE 입력까지 원스톱으로 자동화.
- **주요 대상**:
  - 네이버 블로그 일일 1포스팅을 빠르고 완성도 높게 작성하고자 하는 블로거
  - 스마트폰으로 촬영한 맛집, 카페, 여행 사진을 생생한 내돈내산 방문 후기로 발행하고 싶은 크리에이터
  - 서식 깨짐이나 복사/붙여넣기 번거로움 없이 1초 자동 주입을 원하는 사용자

---

## 2. 개발 도구 및 기술 스택
- **프레임워크**: Next.js 16.2.11 (App Router, Turbopack), React 19.2.4, TypeScript 5
- **스타일링**: Tailwind CSS v4, Lucide React
- **AI 멀티모달 & LLM**: Google Gemini 2.5 Flash / Pro, NanoBanana 2-2K (이미지 생성)
- **크롬 확장 프로그램**: Manifest V3 기반 네이버 블로그 전용 자동 주입 확장 (`extension/`)
- **인증 및 DB**: Supabase Auth (SSR 쿠키), Supabase Database (`programs`, `posts` 등)
- **브라우저 검수**: Microsoft Edge (`msedge`) Playwright 포그라운드 실세션 검수

---

## 3. 핵심 기능 및 워크플로우

1. **STEP 1: 주제 아이디어 발굴**:
   - E-E-A-T 기반(How-to, 비교분석, 트렌드 등), 5대 카테고리, 에버그린, 롱테일, 내 메모/파일 업로드 분석.
2. **STEP 2: 맛집/카페/여행 비전 엔진**:
   - 스마트폰 사진을 다중 업로드하면 Gemini 멀티모달 비전 AI가 음식 색감, 인테리어 톤, 뷰를 직접 관찰하여 네이버 플레이스 맞춤 원고 집필.
3. **STEP 3: 키워드 파인더 PRO (7대 분석 엔진)**:
   - 검색량, 문서수, 경쟁도, 네이버/구글 실시간 자동완성 다이렉트 프록시 연동, 실시간 속보 뉴스 RSS 수집기.
4. **STEP 4: 생성 본문 보관함**:
   - 생성한 글과 이미지를 안전하게 보관하고 다시 열어 편집 및 배포.
5. **스마트에디터 ONE 크롬 확장 프로그램 1초 자동 주입**:
   - 전용 크롬 확장(`naver-blog-allinone-latest.zip`)을 통해 네이버 글쓰기 화면에서 원클릭으로 제목, 인라인 HTML 서식 본문 자동 주입.
6. **비주얼 사용 매뉴얼 (`GuideSection.tsx`)**:
   - 초보자도 쉽게 따라 할 수 있는 4단계 파이프라인 가이드, 크롬 확장 1초 설치 안내, C-Rank/D.I.A.+ 노하우, FAQ 아코디언 탑재.
