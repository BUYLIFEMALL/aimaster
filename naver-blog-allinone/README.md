# 네이버 블로그 올인원 자동화 (naver-blog-allinone)

네이버 블로그를 위한 통합형 AI 자동화 프로그램입니다.
E-E-A-T 기반 아이디어 발굴부터 멀티모달 사진 비전 분석, 실시간 뉴스 및 키워드 파인더 경쟁 분석, 네이버 스마트에디터 ONE 전용 서식 생성 및 1클릭 포스팅까지 전체 라이프사이클을 지원합니다.

## 핵심 기능 현황 (v1.17)
- **스마트에디터 ONE 원클릭 자동 주입 크롬 확장 프로그램 (신규 탑재)**:
  - `extension/`: 매니페스트 V3 기반 네이버 블로그 스마트에디터 ONE 전용 자동화 확장 프로그램 구축
  - `원클릭 1초 자동 주입`: 네이버 글쓰기 화면(`blog.naver.com`) 접속 시 플로팅 위젯을 통해 제목, 인라인 서식 HTML 본문 자동 입력
  - `웹-확장 양방향 브릿지`: 웹 앱에서 생성된 원고가 크롬 확장에 자동 동기화 (`window.postMessage` & `chrome.storage.local`)
  - `다운로드 ZIP 제공`: 사이트 상단 `[크롬 확장 다운로드]` 및 `public/downloads/naver-blog-allinone-latest.zip` 즉시 다운로드 지원
- **SEO 모드 선택 & AI 키워드 자동 추출 & 3단 서식 뷰어**:
  - `SEO 최적화 모드 선택`: 홈판 노출 모드(감성 스토리텔링 & 1인칭 에세이, 네이버 MY피드/홈판 픽 유도) vs 기본 SEO 모드(정보형 리뷰, D.I.A+ 점수 극대화)
  - `SEO 키워드 설정 & AI 자동 추출`: 장소명과 사진 분석 기반 메인 키워드 및 서브 키워드 AI 실시간 자동 추출 (`[AI 키워드 자동 추출]` 버튼)
  - `3단 포맷 뷰어 & 원클릭 복사`:
    - 네이버 블로그 (스마트에디터 ONE 전용 인라인 HTML 서식 복사)
    - 마크다운 (티스토리, 워드프레스, 깃허브 블로그용 Markdown 복사)
    - 일반 텍스트 (줄글 Plain Text 복사)
  - `네이버 글쓰기 새 탭 바로가기`: 원고 생성 즉시 네이버 블로그 스마트에디터 ONE 글쓰기 페이지(`https://blog.naver.com/GoBlogWrite.naver`) 원클릭 연결
- **키워드 파인더 PRO 7대 분석 엔진 (v1.03)**:
  1. `키워드 경쟁력 분석`: 검색 의도, PAA(사람들이 자주 묻는 질문 5선), 콘텐츠 갭 분석, 클릭률 극대화 추천 제목
  2. `자동완성 키워드 분석`: Naver & Google 실시간 자동완성 다이렉트 프록시 연동 (`/api/keywords/autocomplete`)
  3. `AI 연관검색어 분석`: 연관 키워드, 검색 난이도 평가(Easy/Medium/Hard), 확장 롱테일 키워드 발굴
  4. `실시간 최신 뉴스`: Google News RSS 기반 주요 언론사 실시간 기사 수집기 (`/api/keywords/news`), 기사 링크 원문 조회 및 원클릭 블로그 포스트 기획 연동
  5. `상위 블로그/글 분석`: 네이버 뷰탭 1~5위 상위 노출 원리 및 차별화 초월 공략 가이드
  6. `다각도 블로그 주제 발굴`: 1개 키워드 입력 시 4대 관점(초보자 가이드, 비교/분석, 문제 해결, 전문가 팁) 동시 확장
  7. `오늘의 전략 키워드 10선`: 2026년 실시간 트렌드 기반 고효율 10대 전략 키워드 카드 발굴
- **주제 아이디어 얻기 (5대 기획 엔진)**:
  - `E-E-A-T 기반`: 5가지 콘텐츠 유형(How-to, 비교분석, 트렌드, 사례연구, 개인경험) × 6가지 분야(IT, 건강, 금융, 요리, DIY, 교육)
  - `카테고리별`: 최신 트렌드/소셜 공유 유도 인기 주제 (9개 카테고리)
  - `에버그린 콘텐츠`: 장기 자산형 20대 콘텐츠 유형 × 9개 분야
  - `롱테일 키워드 주제`: 저경쟁 고전환 롱테일 키워드 (11대 분야)
  - `메모/파일 기반`: 아이디어 메모 및 `.txt`, `.md` 파일 업로드 분석
- **맛집/카페/여행 멀티모달 비전 분석 엔진 (v1.02)**:
  - 스마트폰 촬영 실제 사진 다중 업로드 (클라이언트 사이드 캔버스 리사이즈 & Base64 인코딩)
  - 대표 썸네일 별 클릭 지정 및 사진 순서 번호 매칭 (`[사진 1]`, `[사진 2]`)
  - 방문 정보 폼: 장소명\*, 카테고리(맛집/카페/여행/쇼핑/기타), 지역, 방문일, 동행(연인/가족/친구), 한 줄 인상, 장소 상세정보
  - Gemini Vision 모델이 사진 속 음식 색감, 플레이팅, 인테리어 톤, 뷰를 직접 관찰하여 네이버 플레이스/D.I.A+에 최적화된 생생한 내돈내산 원고 작성
  - 자주 묻는 질문(FAQ) 섹션 자동 생성 토글
- **환경설정 (API 키 격리 보관)**:
  - 사용자 본인의 Google Gemini API 키를 브라우저 `localStorage`에만 안전 보관
  - 무료 API 키 발급 안내 및 실시간 연결 테스트 지원
  - 텍스트 모델: `gemini-flash-latest` (추천) vs `gemini-flash-lite-latest` (초고속)
  - 이미지 모델: `Nano Banana 2` (고화질) vs `Nano Banana 2 Lite` (초고속)
- **트렌드 링크 허브**: 네이버 데이터랩, 시그널 실검, 정부 정책포털 등 8개 핵심 출처 바로가기
- **공통 포스트 생성 & 에디터**:
  - 7가지 테마 컬러 팔레트 (블루그레이, 그린오렌지, 퍼플옐로우 등)
  - 고급 옵션: 대표 썸네일 생성(16:9/1:1), 서브 이미지, 썸네일 텍스트, 인터랙티브 요소(계산기/체크리스트), 인간적인 글쓰기 스타일 PRO
