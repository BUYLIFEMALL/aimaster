## 2. 추가개선 제안 (타 프로그램 탐색 기반 필수 3대 항목)

### 1) 프로그램 로직 및 기능 개선
- **다중 이미지 일괄 멀티모달 비전 분석 고도화**:
  - 현재 스마트폰 사진 개별/소수 업로드에서 최대 10장의 사진을 한 번에 드래그앤드롭하여, 사진 촬영 시간/순서에 맞춰 '매장 외관 → 인테리어/메뉴판 → 메인 요리 → 디저트/총평'으로 문단을 자동 배치하는 '타임라인 자동 정렬 비전' 기능 도입 검토.
- **네이버 형태소 분석기 기반 키워드 밀도 실시간 체커**:
  - 원고 작성 및 편집 시 본문 내 타겟 키워드의 반복 횟수와 백분율 밀도(1.5%~2.5% 적정 범위)를 실시간 게이지 바로 표시하여 어뷰징 방지.

### 2) 사용자 인터페이스/UI 가독성 및 사용편리성 개선
- **스마트에디터 ONE 실제 미리보기 뷰어 모드**:
  - 모바일 네이버 블로그 앱 화면 프레임(375px)으로 생성된 글이 어떻게 보이는지 가상 폰 뷰어로 실시간 프리뷰를 제공하여 발행 전 줄바꿈과 폰트 크기를 직관적으로 확인.
- **원클릭 클립보드 서식 복사 토스트 피드백 강화**:
  - [HTML 복사], [텍스트 복사], [마크다운 복사] 버튼 클릭 시 복사 완료 알림 팝업 및 네이버 블로그 글쓰기 새 탭 바로가기 링크 제공.

### 3) 현재 만들어져 있는 다른 자동화 프로그램과의 연계 가능한 기능
- **AI 이미지 스튜디오 (`ai-image-studio`) 연동**:
  - 사용자가 촬영한 사진이 부족할 경우, 본문 문맥에 맞는 대표 썸네일이나 일러스트 이미지를 `ai-image-studio`의 최신 이미지 생성 엔진과 연동하여 고화질 생성.
- **인스타 카드뉴스 스튜디오 (`cardnews-studio`) 및 스레드 포스팅 (`threads-posting`) 연계**:
  - 네이버 블로그에 포스팅한 원고를 바탕으로 핵심 요약 5장 카드뉴스 및 스레드 홍보용 숏 텍스트로 원클릭 변환하여 멀티채널 트래픽 유입 극대화.
- **유튜브 쇼츠 생성기 (`shorts-remaker`) 연동**:
  - 맛집/여행 블로그 글을 기반으로 60초 숏폼 릴스/쇼츠 대본으로 변환하여 숏폼 영상 제작까지 원스톱 확장.
