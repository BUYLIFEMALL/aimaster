# 티스토리 화면 조사 도구 (조사 전용 크롬 확장)

티스토리 글쓰기 화면의 구조를 **읽기만** 해서 JSON으로 모아 주는 도구입니다. 클릭·입력·발행은 하지 않고, 제목·본문 내용도 저장하지 않습니다(글자 수만 기록).
`docs/PLATFORM_PATTERNS.md` §20 규칙 3("셀렉터는 추측 금지, 실제 화면을 조사한 뒤에만 자동화 코드 작성")을 지키기 위한 0단계 도구입니다.

## 설치 (주인님 PC, 1회)
1. 크롬에서 `chrome://extensions` 열기 → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`tistory-auto-blog/inspector-extension`) 선택
   (BLOG 입력 확장·SEO 확장과는 다른 폴더이므로 서로 영향이 없습니다)

## 사용 순서
1. 티스토리에 **직접 로그인**하고 글쓰기 화면(`내블로그.tistory.com/manage/newpost`)을 엽니다.
2. 확장 아이콘을 눌러 오른쪽 사이드패널을 엽니다.
3. 아래 화면 상태를 하나씩 만든 뒤, 드롭다운에서 해당 항목을 고르고 **"이 화면 분석하기"** 를 누릅니다.
   - 01 막 열었을 때 / 02 제목·본문에 글자를 조금 직접 쓴 상태 / 03 모드(기본·마크다운·HTML) 메뉴를 연 상태
   - 04 HTML 모드로 바꾼 화면 / 05 사진 버튼을 직접 누른 상태 / 06 이미지가 올라간 상태
   - 07 카테고리 목록을 연 상태 / 08 완료(발행) 설정창을 연 상태 / 09 태그 칸에 직접 태그를 쓴 상태
   - **발행 버튼은 누르지 마세요.** 08번은 설정창을 열기만 하면 됩니다. 테스트 글은 나중에 임시저장 없이 닫아도 됩니다.
4. **"JSON 파일로 저장"** 으로 파일을 받아 Claude 대화에 첨부합니다(또는 "전체 결과 복사" 후 붙여넣기).

## 알아둘 것
- 모든 항목을 못 만들어도 됩니다. 되는 것만 보내 주시면 됩니다(특히 03·04·08·09번이 중요).
- 블로그가 여러 개이거나 새/옛 에디터가 섞여 있으면 메모 칸에 적어 주세요.
- 이 도구는 **조사용**이며 회원에게 배포하지 않습니다. 실제 입력 확장은 이 결과를 읽은 뒤 `tistory-auto-blog/extension/`에 따로 만듭니다.
- 카카오 로그인·2단계 인증은 주인님이 직접 하며, 에이전트는 비밀번호 입력 로그인을 하지 않습니다.
