## 문제
- 실측(글 20번, `docs/IMPROVEMENTS.md` 「⑩ GPT-4.1 분량 실측」): 1,000단어·GPT-4.1에서 공백 제외 2,097자 = 목표(약 3,500자)의 **59.9%**.
- 원인 ① 「약 N단어」는 한국어에서 애매(AI가 약 630단어만 씀) ② 「문단마다 공백 제외 875자 이상」(`minPerParagraph`)은 AI가 세며 쓸 수 없어 무시됨. 출력 한도는 원인 아님(`utils/ai/contentJson.ts` — OpenAI 한도 미지정, Claude 12000).

## 범위

## 구현 순서
1. 목표 글자 수(단어×3.5, 없으면 2,000자)로 **문단마다 단락 수** 계산(단락 1개 = 3~4문장 ≈ 250자, 최소 2개). 예: 1,000단어 → 문단당 단락 4개.
2. 지시문을 「문단마다 ### 작은 제목 1개 + 단락 N개, 단락마다 3~4문장, 단락마다 예시·수치·방법 중 하나」 **개수 구조**로. 「약 N단어」 → 「공백 제외 약 N자」.
3. `###` 규칙 「글 전체 정확히 3번」 → 「문단마다 1개(총 4개)」. 소제목 반복 제거(`headingDedupe.ts`)는 유지.
4. 기존 규칙 유지: 연도·한국 시간, 자료 사실 살리기, 따옴표 강조 금지, 제목 반복 금지, JSON 10개 키.

## 검수
1. `npx tsc --noEmit` + 기존 시험(`test:post-source`·`test:extension-api` 등) — 무료.
2. 단락 수 계산 작은 시험 추가 — 무료.
3. 실제 생성 1회: 글 20번과 같은 조건(글감 「캠핑의 역사와 장비」 `ec2fddbc`, 1,000단어, 이미지 0장, 전문적), GPT-4.1, 시험 계정 `buylifemall@naver.com` 본인 키, **로컬 실행·저장 안 함**. 통과 기준: 공백 제외 **약 3,000자(85%) 이상**.
4. 미달이면 숫자와 함께 주인님께 보고하고 (가) 보충 호출 추가 여부를 여쭙는다.
