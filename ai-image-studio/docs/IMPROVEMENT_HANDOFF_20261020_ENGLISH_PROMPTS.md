# v1.20 상황별 영문 프롬프트 보강 인수인계

## 변경 내용
- 관리자 공통 예시 16개 화풍 × 10개, 총 160개의 본문을 상황별로 직접 새로 작성했습니다. 각 본문은 94~132단어입니다.
- 한국어 제목·분류·ID·정렬순서·등록일은 보존합니다. 회원별 생성물·개인 키·외부 계정·30일 보관 정책 변경은 없습니다.
- lib/prompts/stylePresetPrompts.json을 이 프로그램의 기본 예시 원본으로 삼아, 관리자 초기 등록 API와 작업실 기본 예시가 함께 참조합니다. 운영 DB의 관리자 편집 내용이 계속 우선합니다.
- 실사는 실제 피부·의류·금속·유리·빛·시점과 렌즈를 구체화했고, 비실사는 각 매체의 선·명암·종이·붓질·3D 재질·수작업 흔적을 구체화했습니다.
- 기존 메뉴 이동(v1.19)은 그대로 포함됩니다.

## 검수
- node --test tests/stylePresetPrompts.test.mjs: 4개 통과(160개 대응/영문/중복/촬영 주제/매체별 특성).

- 실제 유료 이미지 생성은 하지 않았습니다. 문구·코드·저장·표시는 검수하지만 결과 이미지 품질 향상은 실제 생성 전까지 측정한 것이 아닙니다.

## 운영 반영 절차 및 복구
- 백업: docs/evidence/prompts-before-20261020.json.
- node scripts/build-style-prompt-release.mjs는 SQL만 생성하며 DB에 접속하지 않습니다. docs/releases/20261020_prompts_v120.sql을 지정된 운영 DB esgxyikcnnvmlhygjkth에서 실행합니다.
- 원문·ID·제목·분류·순서·등록일이 백업과 하나라도 다르면 전체 갱신을 취소합니다. 테이블 DDL·추가·삭제는 없습니다.
- 복구 자료: --rollback으로 만든 docs/releases/20261020_prompts_v120_rollback.sql. 복구도 새 본문과 일치하는 경우에만 가능합니다. 자동 실행하지 않습니다.
- 완료 증거(커밋/배포/운영 160개 일치/버전/Edge)는 아래 운영 결과에 이어 씁니다.

## 다음 CLI 참고: 발견했지만 이번 작업에서 바꾸지 않은 것
1. app/api/enhance-prompt/route.ts의 별도 AI 최적화 시스템 지시에는 모든 화풍에 no anime/no painting/no 3D render 등의 부정 프롬프트를 예시로 주는 부분이 있습니다. 이번 요청은 등록 예시 본문 교체이므로 별도 최적화 API 동작은 보존했습니다. 선택 화풍별 부정 문구 분리는 다음 개선 우선 검토 대상입니다.
2. 프롬프트가 길어져 게시판 표의 행 높이가 커집니다. 검색·화풍 필터는 기존대로 쓰며, 접힌 미리보기/전문 펼침/복사 기능은 다음 디자인 개선 제안입니다.
3. 초기 등록 API는 기존처럼 insert 방식입니다. 운영 목록에 다시 초기 등록을 누르면 중복될 수 있으므로 이번 적용은 해당 버튼으로 하지 않습니다.
4. 이번 실세션 화면은 관리자 기존 Edge 세션으로 확인합니다. 일반 회원 실세션·유료 생성 품질 시험은 별도입니다.
