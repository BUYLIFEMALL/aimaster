# AI 이미지 스튜디오 v1.22 — 문서 챗봇 기준 메뉴 정렬

## 요청·적용
- 주인님이 문서 챗봇 메뉴 화면을 제시하며 같은 레이아웃을 요청했습니다. 개발 계획을 먼저 제시하고 적용했습니다. 대상은 운영 `ai-image-studio` 한 개입니다.
- 레퍼런스: `ai-doc-chatbot/src/components/layout/Sidebar.tsx`, 공통 `docs/SIDEBAR_LAYOUT_STANDARD.md`. 문서 챗봇 코드 자체는 변경하지 않았습니다.
- 로고 옆 제목/버전 배지 → 별도 줄의 「다른 프로그램 보기」 → 「이미지 작업」 3개 → 「도움말 & 설정」의 매뉴얼/API 연동 → 구분선/계정/로그아웃 순서입니다.
- 번호 연결선·관리 배지·큰 매뉴얼 배너를 간결한 아이콘 링크로 바꾸고 원래 앰버 색상을 유지했습니다. 이번 사용자 지시는 해당 프로그램 번호형 메뉴의 명시적 예외입니다. 기능·주소·본인 계정/API·저장 로직은 같습니다.
- 계정의 `mt-auto`를 제거했습니다. 높은 화면에서도 마지막 메뉴 아래에 붙으며 낮은 화면은 메뉴 내부를 스크롤할 수 있습니다.
- 767px 이하에서는 상단 접는 메뉴를 적용했습니다. 같은 메뉴 순서·링크, 이동 후 닫기, Escape 닫기/버튼 초점 복귀, `aria-expanded`/`aria-controls`/활성 링크 `aria-current`를 제공합니다.

## 검수
- `npm run build`: 컴파일·타입·린트·페이지 생성 통과.
- 보이는 Microsoft Edge에서 실제 Sidebar 소스와 로컬 가상 회원으로 확인했습니다(실제 운영 로그인 검수와 구분).
- 1440×1000: 5개 메뉴 목적지/순서·활성 표시·카탈로그 링크·버전 일치. 설정 메뉴 끝에서 이메일까지 25px(구분선/내부 여백 포함), 이메일 아래 끝 y=546.625px로 큰 빈 공간 없이 배치.
- 1440×450: 메뉴 내부 스크롤 후 로그아웃 접근 가능.
- 375×812: 기본 닫힘·가로 넘침 없음·메뉴 순서 일치·펼침/닫힘·Escape 초점 복귀·작업실 링크 이동 후 닫힘.
- 767/768px: 모바일/데스크톱 전환 확인.
- 증거: `docs/evidence/sidebar-v122/verification.json`, `desktop.png`, `mobile-closed.png`, `mobile-open.png`.
- 재현용 임시 검수 실행기는 `.vercel/verify-sidebar.mjs`(Git 제외)에 있습니다. 재개 시 기존 `tests/helpers/customPromptPreview.mjs`에 실제 Sidebar를 렌더링하고 위 시나리오로 확인하면 됩니다. 유료 API 호출 0.

## 원인·후속
- 이전 v1.19는 매뉴얼 위치만 옮겼고, v1.21은 개인 프롬프트 기능에 집중하면서 남아 있던 계정 `mt-auto`와 전체 메뉴 구조를 보존했습니다. 따라서 2026-10-12 계정 밀착 원칙과 실제 화면이 불일치했습니다. 이번에 구조를 맞췄습니다.
- 기존 v1.21 일반 회원 실세션 저장/수정/삭제 미검수는 별도 항목이며 이번 레이아웃 검수 완료로 대체하지 않습니다. [기능 인수인계](IMPROVEMENT_HANDOFF_20261020_CUSTOM_STYLE_PROMPTS.md).
- 새 기능 제안 없음. 향후 화면 승인 시 PC/모바일을 함께 대조하고 계정 위치를 실제 좌표로 확인하는 점을 공통 아이디어 원장에 기록합니다. 기존 프로그램 전체를 일괄 변경하지 않습니다.
