# v1.20 상황별 영어 프롬프트 상세 보강 계획

## 승인 범위
주인님이 /prompts의 등록된 각각의 상황을 직접 읽고 영어로 상세 보강하도록 요청했습니다. 관리자 공통 추천 예시 16개 화풍 × 10개 = 160개만 수정합니다. 회원별 생성물·키·개인 프롬프트는 수정하지 않습니다.

## 작성 방식
1. DB 실제 원문·한국어 제목·상황을 160개 모두 대조합니다. ID·제목·분류·표시순서·등록일은 보존합니다.
2. 실사: 주체·행동·장소·구도·렌즈·조명·실제 소재·피부·공간적 관계를 장면에 맞게 작성합니다. 의미 없는 품질 단어 반복과 상충하는 카메라/조명 설명을 정리합니다.
3. 비실사: 3D의 조형과 재질, 애니의 선·셀 명암·배경, 수채의 번짐·종이, 수묵의 먹 농담·여백, 벡터/플랫의 도형·색면, 클레이의 손자국 등 매체별 표현을 구체화합니다.
4. 인물 기본 한국인, 실존 작가명/브랜드를 모방 지시로 쓰지 않고 화풍 특성을 묘사합니다. 요청한 장면의 계절·빈티지 미학은 유지하며 현재 연도를 강제로 장면에 삽입하지 않습니다.
5. 장면마다 영문 본문을 직접 새로 쓰고 이미지 속 글자·로고·워터마크 제외를 명시합니다.

## 반영과 검증
- 운영 원문 160개를 evidence/prompts-before-20261020.json에 보존합니다.
- 프로그램 내부 단일 예시 파일을 만들고 관리자 초기 등록 API와 작업실 기본 예시가 같은 값을 참조합니다.
- 기존 DB ID+원문 일치 조건으로만 본문을 교체합니다. 중간에 타 CLI/관리자가 바꾼 행이 있으면 원문 대조에서 중단하며 덮어쓰지 않습니다. 스키마 변경·행 추가·삭제는 없습니다.
- 검사: 160개 대응·분류별 10개·영문·중복·상황별 표현, 기존 권한 검사, npm run build, 실제 Edge 게시판 표시. 유료 이미지 생성은 하지 않습니다.
- 코드/DB v1.20 일치, 자체 커밋·푸시·프로덕션 배포, 결과와 남은 일 인수인계.

## 처리 상태
구현·문구 검사·기존 권한 검사·빌드·커밋·푸시·운영 배포·DB 160개 정확 대조 완료. 배포 후 로그인 화면 검수는 Edge 재로그인 대기입니다. 유료 생성은 미실시. 세부 결과는 IMPROVEMENT_HANDOFF_20261020_ENGLISH_PROMPTS.md 참조.
