# AI 이미지 스튜디오 (ai-image-studio) — 개선사항 및 고도화 인수인계서 (2026-10-17)

> **프로그램명**: AI 이미지 스튜디오 (`ai-image-studio`)  
> **공식 서비스 URL**: [https://ai-image-studio.buylife.xyz](https://ai-image-studio.buylife.xyz)  
> **현재 버전**: `v1.12`  
> **작성 일자**: 2026-10-17  
> **작성 CLI**: Antigravity CLI (`agy`)

---

## 1. 프로그램 로직 및 기능 개선 제안
1. **인터랙티브 인페인팅 / 아웃페인팅 캔버스 모듈 신설**:
   - 현재 생성된 이미지에서 일부분(얼굴, 손, 배경 소품 등)만 마스킹 브러시로 칠해 재성형하는 `Inpainting` API(Replicate FLUX Inpaint 등) 연동.
   - 캔버스 기반으로 상하좌우를 확장하는 `Outpainting` 지원을 통해 포스터나 와이드 배너 제작 효율 극대화.
2. **이미지 대 이미지 (Image-to-Image / Style Transfer) 파이프라인**:
   - 기존 사진을 업로드하고 화풍(수묵화, 지브리, 픽사 3D 등)을 적용해 새로운 이미지로 재해석하는 Img2Img 모드 추가.
3. **생성물 보관함 30일 자동 파기 Cron 로직 연동**:
   - 최상위 규칙에 따라 회원의 생성 이미지가 생성일 기준 30일 경과 시 Supabase Storage 및 DB 레코드에서 자동 삭제되는 Cron 작업 연동.

---

## 2. 사용자 인터페이스 (UI/UX) 가독성 및 사용편리성 개선 제안
1. **종횡비(Aspect Ratio) 비주얼 카드 셀렉터 도입**:
   - 드롭다운 셀렉트 방식 대신, `[ 1:1 정방형 ]`, `[ 16:9 가로 와이드 ]`, `[ 9:16 세로 쇼츠 ]`, `[ 4:3 클래식 ]` 등의 미니 비율 사각형 아이콘 칩을 클릭하여 원클릭 선택할 수 있도록 개선.
2. **실시간 소요 비용 및 예상 소요시간 계산기 위젯**:
   - 사용자가 모델, 해상도(1K/2K/4K), 생성 매수(1~10장)를 선택했을 때 실시간으로 예상 과금액(예: `약 $0.034`)과 평균 생성 소요시간(예: `약 12초`)을 생성 버튼 옆에 툴팁으로 안내.
3. **갤러리 다중 선택 일괄 다운로드 (ZIP 압축)**:
   - 생성된 여러 장의 이미지를 체크박스로 한 번에 선택하여 ZIP 파일로 압축 다운로드하는 기능 지원.

---

## 3. 타 자동화 프로그램과의 연계 가능한 기능 제안
1. **상세페이지 제작 자동화 (`detail-page-maker-12p`) 연동**:
   - 상세페이지 제작 시 필요한 원료 연출컷, 제품 사용컷을 `ai-image-studio`의 `recraft-v4.1` 및 `gemini-nano-banana-2.1` 어댑터를 통해 원클릭으로 호출·생성하여 상세페이지 에디터에 자동 삽입.
2. **바이닐 앨범 커버 제작기 (`music-album-cover`) 연동**:
   - 바이닐 커버 제작기에 `ai-image-studio`의 35mm 필름 레트로 감성 및 수묵화/애니메이션 어댑터 로직을 공통 SDK 라이브러리로 연동하여 다양한 아트워크 커버 생성.
3. **유튜브 플레이리스트 및 썸네일 제작기 (`youtube-playlist-maker`) 연동**:
   - 16:9 규격 유튜브 썸네일 제작 시 텍스트 렌더링에 특화된 `ideogram-v4-quality`를 호출하여 글자가 깨지지 않는 고화질 썸네일 자동 생성 파이프라인 구축.
