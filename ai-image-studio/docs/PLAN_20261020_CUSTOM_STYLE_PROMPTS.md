# v1.21 회원별 커스텀 화풍 프롬프트 개발 계획

## 요청과 분석
일반 회원도 160개 기본 화풍 예시를 바탕으로 본인만 사용하는 프롬프트를 수정·저장하도록 확장합니다. 기존 공통 예시 수정권을 일반 회원에게 열면 다른 회원의 기본값이 바뀌므로, 별도 개인 사본을 만들고 기존 관리자 원본 관리 기능은 유지합니다. 운영 대상 DB는 esgxyikcnnvmlhygjkth입니다.

## 구현 범위
- 기본 예시/나만의 프롬프트 탭, 기본에서 개인 버전 만들기, 제목·화풍·본문 편집, 개인 사본 삭제·복사, 원본 참고.
- 개인 프롬프트를 작업실로 불러오기. ID만 링크에 넣고, 본문은 본인 인증 후 조회합니다. AI 보강 없이 그대로 Step2에 보내는 선택을 제공합니다.
- 전용 테이블 user_id + owner-only RLS, 서버 소유자/권한 검증, 본문·제목·ID 유효성 확인. 원본 삭제 시 개인 사본 cascade 삭제 금지.
- 생성일 기준 30일 보관. 만료된 개인 프롬프트는 조회·수정·작업실 사용에서 제외하고, 서버 주기 정리 작업과 삭제예정일 안내를 함께 준비합니다.
- 기존 원본 관리·키·이미지 생성·기본 예시 160개 본문 변경 없음.

## 검수 및 운영
권한·소유자·만료·입력 검사, 기본 예시 보존, 작업실 불러오기, 컴파일/타입/빌드, 실제 Edge 1440/375 화면. 일반 회원 실세션이 없으면 사실대로 미완료 기록합니다.

## DB 변경 승인 절차
기존 DB에는 해당 회원별 보관함이 없습니다. 새 개인 전용 테이블과 RLS·기한 보호·정리 작업 SQL을 작성·검수하고 구현을 준비합니다. AGENTS.md §2의 DB 스키마 사전 승인 규칙에 따라, 구체적 변경을 검토할 수 있는 상태로 만든 뒤 운영 DB 적용 전 승인받습니다. 승인 전 운영 스키마/정리 작업은 변경하지 않습니다.

## 비용
개발·시험 유료 API 호출 없음. 별도 유료 서비스/환경변수/계정 추가 없음. 기존 DB 저장 공간·조회·서버 트래픽 범위 사용. 운영 이미지 생성·선택적 AI 보강 비용은 회원 본인의 등록 키로 기존과 동일하게 발생하며 이번 검수에서는 호출하지 않습니다.
