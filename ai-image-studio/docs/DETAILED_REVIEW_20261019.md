## 현재 기능과 보존할 장점

1단계에서 짧은 아이디어를 구도·조명·스타일·렌즈·제외할 요소가 담긴 영문 프롬프트로 다듬어 줍니다. / 2단계에서 GPT Image, Gemini 나노바나나, FLUX 2.0, Seedream, Ideogram(글자 표현), Recraft(SVG 벡터), Z-Image 같은 엔진을 고르면, 그 모델이 지원하는 비율·해상도·화질·시드 옵션만 화면에 나타납니다. / 만든 이미지는 내 갤러리에 자동으로 보관되고 히스토리에서 언제든 다시 볼 수 있습니다.

**보존할 장점:** 여러 엔진의 기준 이미지 호출

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
