## 1. 문제 (실측)

| 항목 | 값 |
|---|---|
| 기존 프리셋(한국 가요·POP·장르·월드) | 461개, 스타일 그룹 243개 |
| 실제로 서로 다른 Style 조합(장르·분위기·악기) | **22가지뿐** — 그룹 이름을 정규식 묶음(`PALETTES`)에 맞춰 고르기 때문 |
| 어느 묶음에도 안 걸려 기본값 `pop, expressive, balanced, piano, bass guitar, drums`로 떨어진 프리셋 | **113개**(예: 「트로트 (Trot)」, 「1980년대 한국 록」, 「BRAZILIAN」, 「Britpop」, 「Doo-Wop」) |
| 그룹 이름(영어)만으로 공식 장르에 자동 일치 | 그룹 204개·프리셋 298개 — 단, 「2010년대 한국 힙합 / R&B」 → `r&b`, 「K-Pop/Disco-Pop」 → `disco`처럼 어긋난 것 있음 |
| 자동 일치 안 됨 | 프리셋 163개 — 한글 장르명(트로트·힙합·록·인디), 연대 이름(「2020s - Current Era」), 공식 목록에 없는 장르(trot·j-pop·bollywood) |

→ 프리셋 이름은 461가지인데 Suno에 들어가는 Style은 22가지라, 「어떤 프리셋을 골라도 비슷하게 나온다」는 랜덤성 불만과 연결된다.

## 2. 목표
1. 기존 프리셋마다 가장 가까운 **Suno 공식 장르 1개(필요하면 2개)**를 연결한다.
2. Style의 장르·분위기·악기·BPM을 연결한 공식 장르 값으로 구체화한다 → 서로 다른 Style 조합 **22 → 150개 이상**, 기본값 `pop`으로 떨어지는 프리셋 **113 → 10개 이하**.
3. 화면 카드에 「🔗 공식 장르: ○○」를 보여 주고, 누르면 「Suno 공식 장르」 탭의 그 장르로 이동한다.
4. 프리셋 id·이름·시대·그룹·분류는 그대로 둔다(저장된 기획·북마크 호환).

## 4. 주인님 결정 항목
1. **연결 방법** — (권장) 자동 후보 + 사람 검토 1번 / 자동 일치만(빠르지만 R&B·디스코처럼 어긋난 연결이 남음).
2. **Style 바꾸는 범위** — (권장) 연결이 확실한 프리셋은 Style을 공식 장르 값으로 구체화, 애매한 것은 지금 Style 유지 + 배지만 / 461개 전부 교체 / Style은 그대로 두고 배지·이동 버튼만.
3. **공식 목록에 없는 한국 장르(트로트 등)** — (권장) 자체 태그 `trot`을 유지하고 가장 가까운 공식 장르(예: `enka`가 없으면 `ballad`)를 보조로 / 연결하지 않음. Suno `style`은 자유 입력이라 공식 목록 밖 태그도 쓸 수 있다.
4. **배포 시점** — (권장) 이 작업만으로 배포(Style이 바뀌어 회원 결과가 달라지므로 바로 확인) / 다른 수정과 모아서.

## 5. 하지 않는 것
- 프리셋 id·이름·그룹·시대 변경, 프리셋 삭제·병합.
- AI로 Style 자동 작성(비용·재현성 문제) — 연결표는 규칙 + 사람 검토로 만든다.
- 「장르별 분위기·악기·BPM」을 Suno 공식 값처럼 소개(v1.56과 같이 「우리 출발값」으로 표기).
