# 제안서 — Suno V6 시대 추가 기능 (음악(SUNO)자동화)

> 2026-10-21 Claude Code(윈도우). 주인님 지시: 「Suno V6의 추가 기능 제안: 타임스탬프 가사, 악기별 12트랙 분리, 페르소나 등 진행해」.
> 근거: [SUNOAPI_REFERENCE.md](SUNOAPI_REFERENCE.md) §5(sunoapi.org 문서 2026-10-21). **제안 단계 — 코드·DB 변경 없음.** 구현은 고르신 기능만 기능별로 플랜 → 승인 → 구현.
> 모든 기능은 회원 본인 sunoapi.org 키·크레딧으로 동작(운영자 비용 없음). 크레딧 단가는 문서에 스템 분리만 있고 나머지는 https://sunoapi.org/billing 확인 필요.

## 1. 기능별 제안
| # | 기능 (엔드포인트) | 회원이 얻는 것 | 화면 | DB 변경 | 크레딧(문서) | 난이도 | 추천 |

## 2. 추천 진행 순서
1. **1차(작고 확실)**: ① 타임스탬프 가사 + LRC/SRT ② 악기별 분리(12트랙·특정 악기) — 각각 실제 호출 시험 1회.
2. **2차**: ③ 페르소나 ④ 구간 다시 만들기.
3. **3차**: ⑤ 보컬/반주 추가 ⑥ 매시업 ⑦ Suno 커버 선택 ⑧ 뮤직비디오.
- 함께 처리할 남은 검수: 곡 연장·MR(실호출 미검수, 각 1회).

## 3. 결정 필요
1. 1차 범위(① ② 그대로 / 다른 조합).
2. 기능마다 실제 호출 시험 1회씩(시험 계정 크레딧) 승인 — ②는 50크레딧.
3. ② ③의 DB 변경(칼럼·표 추가) 승인.
