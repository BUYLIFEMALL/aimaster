# 📅 Booking Reminder — 예약 리마인드 · 노쇼 방지 자동화

병원·미용실·학원·스튜디오 등 예약 기반 업종을 위한 자동 알림 프로그램입니다. 예약을
등록해두면 예약일시 기준으로 "전날 리마인드 → 당일 확인 → 방문 후 리뷰 요청" 같은
메시지를 이메일·문자·카카오 알림톡·카카오 친구톡으로 자동 발송해 노쇼를 줄이고 재방문을
유도합니다.

**배포 URL**: (배포 후 기입)

SOLAPI(`solapi.com/crm`)가 소개한 CRM 자동화 활용 사례(예약 자동화: "예약일 전날 리마인드
→ 당일 확인 메시지 → 방문 후 리뷰 요청")를 벤치마킹해서 AIMaster 서브프로젝트로 제품화한
것입니다. crm-google-form과 발송 인프라(이메일/SOLAPI/텔레그램 계정)를 100% 공유하지만,
타겟 고객군(오프라인 예약 업종)과 트리거 기준(구글폼 접수 시점이 아니라 "예약일시")이
달라서 별도 서브프로젝트로 만들었습니다. 설계 배경은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) 참고.

---

## 🎯 핵심 흐름

```
직원이 예약 등록(고객명/연락처/예약일시)
  → 리마인드 규칙(예약일시 기준 "N시간 전/후")을 여러 개 등록해두면
  → 15분마다 도는 cron이 조건에 맞는 예약 건을 찾아
  → 이메일 / SMS / 카카오 알림톡 / 카카오 친구톡으로 자동 발송
  → (선택) 원장 본인 텔레그램으로도 예약 알림
```

## 📦 Phase 진행 상태

| Phase | 내용 | 상태 |
|-------|------|------|
