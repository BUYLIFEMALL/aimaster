## 현재 기능과 보존할 장점

PDF·DOCX·XLSX·TXT 문서를 올리면 내용을 읽어 슬라이드별 핵심 지표와 전략을 자동으로 정리합니다. / 22개 전문 슬라이드 형식과 3가지 기획 프레임워크(표준·확장판·경영진 보고 형식)로 IR 피치덱·사업계획서·경영진 보고서를 만들고, 슬라이드를 카드로 하나씩 고칩니다. / 16:9 슬라이드쇼로 미리 보고, 브라우저에서 바로 16:9 와이드 PPTX 파일로 내려받아 파워포인트에서 이어서 편집합니다.

**보존할 장점:** 문서를 발표 구조와 PPTX로 변환

기능 설명은 기존 카탈로그·분석 기록을 재사용한 개요입니다. 이번 근거는 아래 선택 소스 경로의 조건이며 전체 메뉴/실제 기능을 모두 다시 실행한 것은 아닙니다.
