# 개발 플랜 — YOUTUBE Shots에 「브라우저에서 만들기(무료)」 (v1.24, 2026-10-21 Claude Code 윈도우)

> 유튜브 보류 F 「엔진 공유」 2번. 1번(쇼츠 원스톱 v1.19 유튜브 업로드)은 완료. 대상 운영 ① AIMaster, DB ref `esgxyikcnnvmlhygjkth`.

## 1. 문제 (실측 2026-10-21)
- Shots 영상 합성은 JSON2Video 한 가지뿐이다. JSON2Video가 **합성 + 내레이션(ElevenLabs) + 자막**을 모두 맡아, 회원은 JSON2Video 키·크레딧과 ElevenLabs Voice ID가 있어야 영상을 만들 수 있다.
- 운영 DB: Shots 영상 6개(회원 2명) 중 완성 1개. **JSON2Video 키 등록 회원 1명 vs OpenAI 키 등록 회원 27명** → 합성 단계에서 대부분 막힌다.

## 2. 범위
렌더 화면에 만드는 방식 선택: **① 브라우저에서 만들기(무료, 기본)** / ② 고급 합성(JSON2Video, 지금 그대로).
- 브라우저 방식
  - 내레이션: 회원 본인 **OpenAI 키** TTS(`gpt-4o-mini-tts`, 목소리 선택). 서버가 장면별 음성을 만들어 바로 돌려줌(파일 저장 없음, 장면당 수십 KB).
  - 화면: 장면 이미지(9:16) + 느린 확대(켄 번스) + 노란 굵은 자막(검은 테두리, 2~3어절씩 — JSON2Video 설정과 같은 모양). 장면 길이 = 음성 길이 + 여백(최소 3초).
  - 소리: 내레이션 + 선택한 배경음악(목소리 나올 때 자동으로 줄임·끝 1초 페이드).
  - 결과: 1080×1920·30fps MP4. 화면에서 바로 미리보기·내려받기.
  - **완성 MP4를 저장소에 올려 `rendered_video_url`·`render_status=ready`로 저장** → 기존 유튜브 업로드·인스타 게시가 코드 변경 없이 그대로 동작(인스타는 공개 영상 주소가 필요).
- 공용 기준 코드(엔진 공유): 원스톱 `lib/render/export.ts`에서 대본과 무관한 부분(H.264/AAC 인코딩·MP4 묶기·소리 섞기·자동 볼륨)을 `browser-mp4-encoder`로 떼어 기준 등록, Shots는 사본 사용. 원스톱도 같은 공용 함수를 쓰도록 바꿔 결과 같음 확인(v1.20).

## 3. 주인님 확인이 필요한 것
1. **저장소 버킷 추가**(DB 변경): `shots-videos`(공개 읽기, 회원 폴더 `user_id/…`, 회원 본인만 올리기·지우기 RLS, 1개 최대 100MB, mp4만). 업로드는 브라우저 → 저장소 직접(서명된 업로드 주소, Vercel 4.5MB 한도 회피).
2. **30일 자동 삭제**(최상위 규칙: 생성 데이터 30일): 같은 영상을 다시 만들면 이전 파일 즉시 삭제 + 매일 정리 작업(기존 운영 예약 호출에 Shots 정리 1개 추가) — 운영자 저장 용량 비용을 묶어 둔다.
- 대안(버킷 없이): 브라우저 MP4는 내려받기만 하고 유튜브는 원스톱처럼 브라우저 직접 업로드. 단, **인스타 게시는 불가**(공개 주소 필요). 추천하지 않음.

## 4. 구현 순서
1. 공용 `browser-mp4-encoder` 추출(원스톱 기준) → 원스톱 export.ts가 사용 → 원스톱 MP4 재확인.
2. Shots: `/api/render/tts`(본인 OpenAI 키, 접근 권한·같은 출처), 이미지 스토리 그리기 함수, 렌더 화면 방식 선택·진행 막대·멈추기.
3. 저장소 업로드(서명 주소) → `render_status=ready` 저장 → 유튜브·인스타 흐름 그대로.
4. 30일 정리, 매뉴얼·설정 안내, 버전 v1.24(+ 미배포 공용 사본 함께), 상세 소개 문구.

## 5. 검수
tsc·build·공용 점검. 크롬: 관리자 계정 Shots 대본으로 브라우저 MP4(음성 6장면 = 저가 TTS 6회, 약 10원) → 미리보기·저장소 저장 확인. 원스톱 MP4 다시 만들기(결과 같음). 시험 계정으로 권한·회원 분리.

## 6. 비용
- 회원: OpenAI `gpt-4o-mini-tts` 장면당 약 1~2원(영상 1편 약 10원). JSON2Video 크레딧·ElevenLabs 불필요.
- 운영자: 저장 용량(영상 1편 약 15~30MB, 30일 뒤 삭제). 영상 합성 서버 비용 없음.
- 시험: 위 TTS 6회 정도.
