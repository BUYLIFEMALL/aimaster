## 1. 3대 관점 분석 및 개선 아이디어

### ① 프로그램 개발 및 유지보수 관점 (로직/안정성/재사용)
- **비디오 렌더링 큐 시스템 도입**: Remotion 영상 합성은 서버 CPU/메모리 부하가 높으므로, 동시 요청 시 Vercel 서버리스 람다 제한(300초)을 피할 수 있도록 비동기 작업 큐 및 웹훅 콜백 체계 도입 검토.
- **이미지 생성 실패 시 자동 재시도 & 캐싱**: 나노바나나 2.1 API 호출 중 일시적 네트워크 타임아웃 발생 시 씬별 단위로 캐싱하여 성공한 이미지는 재호출하지 않고 실패한 씬만 재시도하는 로직 고도화.
- **공용 YouTube OAuth 모듈 연계**: 현재 프로그램 내 개별 OAuth 콜백을 공용 `insta_accounts`와 유사한 `youtube_channels` 중앙 테이블로 점진 통합하여 타 유튜브 자동화 프로그램과 연동 계정 공유 지원.

### ② 디자인 및 UX 관점 (가독성/조작/작업 흐름)
- **유튜브 스튜디오 감성 완벽 일체화**: 사용자의 "유투브 느낌을 살려줘" 지시를 충실히 반영하여 옵시디언 다크(`#0f0f0f`), 스튜디오 서피스(`#181818`), 유튜브 레드(`#ff0000`) 알약형 토큰 시스템 완성.
- **5단계 파이프라인 시각화**: 좌측 사이드바에 1~5단계 번호형 스텝퍼를 배치하여 사용자가 현재 쇼츠 제작의 어느 단계에 있는지 즉시 직관적으로 인지.
- **독립 비주얼 가이드북 (`/guide`) 신설**: 5단계 제작 흐름, 9:16 프롬프트 매트릭스 표, 3대 오디오 팁, FAQ 5종 레드 아코디언을 제공하여 신규 사용자 진입 장벽 대폭 해소.

### ③ 기존 AIMaster에 없던 창의적 자동화 시스템 관점
- **AI 훅(Hook) A/B 스플릿 테스터**: 하나의 쇼츠 소재로 초반 3초 훅 3종을 동시 생성하고, 클릭률(CTR)과 시청 지속 시간이 가장 높을 것으로 예측되는 베스트 훅을 AI가 점수화하여 자동 추천하는 기능.
- **음악 비트 자동 싱크 컷 편집(Auto Beat-Sync Editor)**: Suno AI가 생성한 BGM의 드럼 킥과 베이스 드롭 타이밍을 파형 분석하여 6개 씬의 전환 타이밍을 밀리초(ms) 단위로 완벽하게 자동 정렬하는 하이퍼 싱크 시스템.
- **쇼츠 ➔ 릴스 ➔ 틱톡 동시 원클릭 배포기**: 완성된 MP4를 한 번에 3대 숏폼 플랫폼 규격에 맞춰 제목, 해시태그를 플랫폼별로 자동 최적화 변환하여 동시 예약 게시하는 멀티 플랫폼 디스패처.
