## 2. 현재 구조와 문제 (분석)
- 한 화면 3단: ① 사이드바(대시보드 + 5단계 + 설정·가이드·히스토리) ② 입력 패널(`ControlPanel.tsx` 1,081줄) ③ 미리보기·캡션(`ImageDisplay.tsx`).
- 흰 바탕(slate 계열 클래스 약 400개), 미리보기 빈 화면 안내가 영어 「Configure & Generate」.
- **매뉴얼이 팝업(`HelpModal`)뿐** — 메뉴 이름 「💡 사용 가이드」, 표준 「📖 연동 & 사용 매뉴얼」 아님(원칙 ⑦).
- `components/Header.tsx`는 어디서도 쓰지 않는 파일(지우지 않고 기록만).
- 휴대폰 ☰은 이미 있음 → 유지.

## 3. 화면별 구현
| 화면 | 내용 |
|---|---|
| 공통 | `if-*` 토큰·스크롤바 다크, 로그인·모달·서랍까지 같은 다크(원칙 ⑪) |
| 사이드바 | 색 교체, 「📖 연동 & 사용 매뉴얼」로 이름 표준화 |
| 입력 패널 | 색만 교체(입력·생성 로직 그대로), 이미지 생성 버튼 핑크 그라데이션 유지 |
| 미리보기 | 어두운 캔버스, 빈 화면 안내를 한글 + 캐릭터로 |
| 📖 매뉴얼 | 팝업 대신 **화면 안 매뉴얼 보기**(가운데·오른쪽 영역을 매뉴얼로 전환, 사이드바는 그대로) — 기존 `HelpModal` 내용을 옮겨 말풍선·5단계 카드(외형 → 일과·앵글 → 표정·포즈 → 광고/공구 → 화보·캡션)·TIP·주의·FAQ로 시각화 |
| 모달·서랍 | API 키 모달·히스토리 서랍 다크 |
