## 1. 프로그램 개요

**AI 인플루언서 자동화 (AI Influencer Studio)**는 인스타그램, 틱톡, 쓰레드, 유튜브 등 SNS 마케팅에 즉시 투입 가능한 **초현실적(Hyper-realistic) AI 가상 인플루언서 화보**와 **3종 맞춤 인스타그램 캡션(해시태그 포함)**을 원클릭으로 생성·기획하는 전문 스튜디오 솔루션입니다.

### 핵심 특장점
1. **극사실적 포토리얼리즘 화보**: 피부 모공, K-Glass 물광, 복숭아 솜털, 자연스러운 땀방울 등 30여 종의 초미세 텍스처 조합
2. **인플루언서 하루 일과 기획 (AI 플래닝)**: 시간대별 5대 스토리라인 및 상황별 최적의 의상·장소·조명 자동 세팅
3. **PPL / 광고 모드**: 실제 제품 사진을 최대 3장 업로드하여 모델이 자연스럽게 들고 있는 1:1 합성 화보 생성
4. **인스타그램 3종 캡션 & 2중 피드백**: 감성형 / MZ위트형 / 소통질문형 캡션 동시 생성 및 직전 결과 기반 미세 보정
5. **원클릭 주사위 전체 옵션 랜덤 믹스**: 누를 때마다 트렌디한 설정값을 무작위로 매칭하여 새로운 영감 제공

## 2. 화면 구성 및 레이아웃 안내

화면은 작업 효율성을 극대화하기 위해 **3단 분할 스튜디오 구조(클린 화이트 테마)**로 설계되어 있습니다:

```
┌─────────────────┬──────────────────────────┬─────────────────────────────┐
│ 1. 좌측 사이드바 │ 2. 중앙 옵션 컨트롤 패널 │ 3. 우측 실시간 뷰어 & 캡션   │
│                 │                          │                             │
│ • 프로그램명    │ • 상단 유틸리티 툴바     │ • 고화질 화보 캔버스        │
│ • 대시보드      │ • Step 1: 외형 스타일링  │ • 1:1 / 9:16 / 16:9 뷰어   │
│ • Step 1 ~ 5    │ • Step 2: 일과/앵글 기획 │ • 인스타 3종 맞춤 캡션      │
│ • 연동 & 계정   │ • Step 3: 표정/포즈/연출 │ • 캡션 복사 & 재생성        │
│                 │ • Step 4: 광고/공구 모드 │ • 이미지 미세 보정 피드백   │
│                 │ • Step 5: 화보 생성 버튼 │ • 원본 다운로드             │
└─────────────────┴──────────────────────────┴─────────────────────────────┘
```

## 3. 필수 준비 사항 (Google Gemini API 키 연동)

AIMaster의 **최상위 불변 규칙(본인 계정·본인 API 키 연동 원칙)**에 따라, 모든 회원은 본인의 Google Gemini API 키를 직접 연동하여 사용합니다.

### API 키 발급 및 등록 방법
1. [Google AI Studio (aistudio.google.com)](https://aistudio.google.com/)에 접속하여 구글 계정으로 로그인합니다.
2. **`Get API key`** 메뉴에서 `Create API key` 버튼을 클릭하여 새 키를 발급받습니다. (무료 사용 가능)
3. 스튜디오 좌측 사이드바의 **`🔑 API키등록·플랫폼연동`** 메뉴(또는 상단 툴바의 톱니바퀴 아이콘)를 클릭합니다.
4. 발급받은 API 키를 붙여넣고 **`연동 저장하기`** 버튼을 누릅니다.
5. 등록이 완료되면 녹색 체크 배지가 표시되며 영구적으로 안전하게 본인 계정에 저장됩니다.

## 4. 단계별 사용 가이드 (Step 1 ~ 5)

### Step 1. 외형 스타일링 (Appearance)
* **성별**: 여성(기본 권장), 남성, 기타/중성적 매력
* **국적**: 대한민국(K-Beauty 기본 권장), 일본, 중국, 미국, 프랑스 등 전 세계 30여 개국 지원
* **나이**: 18세부터 40세까지 인플루언서 최적 연령대 설정
* **헤어스타일**: 레이어드 컷, 긴 생머리, 히피펌, 시스루뱅, 숏컷 등 31종의 트렌디 헤어 선택
* **얼굴형 & 분위기**: 청순 우아형, 도회적 시크형, 큐티 러블리형, 스포티 건강미 등

### Step 2. 일과 & 앵글 기획 (Routine & Multi-Angle Planning)
* **AI 일과 플래닝**:
  * 한 줄 일과(예: `"성수동 팝업스토어 투어 후 저녁 루프탑 와인바"`)를 입력하고 보라색 전송 버튼을 누르면, **5가지 시간대별(오전, 브런치, 오후, 골든아워, 야경) 스토리라인**을 AI가 자동으로 기획합니다.
  * 기획된 시나리오 카드를 클릭하면 해당 장소, 의상, 포즈, 조명이 한 번에 즉시 적용됩니다.
* **랜덤 일과 버튼**: 20여 종의 실제 인기 인플루언서 일과 프리셋 중 무작위 제안
* **단일 이벤트 5각 앵글 변형 (Event Variations)**:
  * 특정 이벤트(예: `"한강 피크닉"`)를 입력하면 거울 셀카, 핸드헬드 전면 셀카, 전신 샷, 소품 감성 컷 등 5가지 카메라 구도로 기획해 줍니다.

### Step 3. 표정·포즈 & 연출 (Styling & Scene)
* **표정**: 은은한 미소, 윙크, 도도한 무표정, 자연스러운 대화 표정 등 18종
* **포즈 (셀카 특화)**: 핸드폰 거울 셀카, 턱 괴기, 음료 들고 포즈, 뒤돌아보기 등 25종
* **의상**: 캐주얼 데일리, 오버핏 셔츠, 슬림핏 니트, 애슬레저 룩 등 25종 (직접 영문 커스텀 가능)
* **장소**: 햇살 드는 카페, 모던 편집숍, 스튜디오, 도심 야경 등 25종 (직접 영문 커스텀 가능)
* **조명 & 렌즈 연출**:
  * 조명: 골든아워 자연광, 부드러운 창가광, 시네마틱 네온, 스튜디오 소프트박스 등 13종
  * 카메라 모드: iPhone 16 Pro 전면/후면 셀카, 35mm 스트리트, 85mm 포트레이트 등 11종
  * 필름 감성: Kodak Portra 400, Fuji Pro 400H, Cinestill 800T 등 필름 그레인 9종
* **피부 질감 30종 멀티 체크**:
  * K-Glass 물광 피부, 극세 모공 질감, 복숭아빛 잔솜털, 은은한 땀방울 등 복수 선택 지원

### Step 4. 광고 / 공구 모드 (Ad / Sponsored Mode)
* **광고/공구 모드 토글**: 인스타그램 협찬/공구/마케팅 전용 모드 활성화
* **5대 광고 유형**:
  1. `공동구매 (Group Buy)`: 인플루언서 공구 오픈 안내 화보
  2. `단순협찬 (Sponsorship)`: 제품 무상 제공 감사 피드
  3. `브랜디드 콘텐츠 (Branded Content)`: 공식 기업 콜라보 에디토리얼
  4. `브랜드 앰버서더 (Brand Ambassador)`: 전속 모델 감성 화보
  5. `내돈내산 (Self-Purchase)`: 진솔하고 사실적인 실사용 후기 피드
* **제품 사진 1:1 합성**: 최대 3장의 제품 실물 사진을 업로드하면 AI가 인플루언서의 손이나 테이블 위에 자연스럽게 들고 있는 씬을 생성합니다.

### Step 5. 화보 & 캡션 생성 (Generate & Fine-tune)
* **화면비 선택**:
  * `9:16`: 인스타그램 릴스, 스토리 전용 세로 비율 (기본값)
  * `1:1`: 인스타그램 전통 피드 정사각형 비율
  * `3:4`: 클래식 화보 및 매거진 비율
  * `16:9`: 시네마틱 유튜브 썸네일 가로 비율
* **해상도 설정**: `1K` (고속 프리뷰) / `2K` (고화질) / `4K` (초고해상도 화보)
* **`이미지 생성` 버튼 클릭**: 최신 Gemini 3 Pro 엔진을 통해 약 5~10초 내에 화보와 인스타그램 3종 캡션이 동시에 완성됩니다.

## 5. 캡션 스튜디오 & 2중 피드백 미세 보정

### 인스타그램 3종 맞춤 캡션
생성된 화보와 스토리 맥락을 분석하여 3가지 페르소나의 캡션을 자동으로 제안합니다:
* **Option 1. 감성/스토리텔링형**: 하루의 일상과 생각을 따뜻하고 진솔하게 전하는 글
* **Option 2. MZ 트렌디 위트형**: 이모지와 유쾌한 줄임말, 솔직 발랄한 인플루언서 톤앤매너
* **Option 3. 질문/소통형**: 팔로워들의 댓글 참여를 유도하는 질문 중심의 글
* *각 옵션마다 고성과 관련 해시태그가 자동으로 포함되며, 원클릭 복사 버튼으로 즉시 복사 가능합니다.*

### 2중 피드백 미세 보정
* **캡션 피드백**: 원하는 문맥(예: `"더 짧고 귀여운 말투로 써줘"`)을 입력하고 다시 작성
* **이미지 미세 보정**: 직전 결과물을 바탕으로(예: `"미소를 조금 더 활짝 짓게 해줘"`, `"배경을 더 어둡게 해줘"`) 연속적인 피드백 수정 생성 지원

## 6. 상단 유틸리티 도구 안내

컨트롤 패널 상단 우측의 4가지 도구:
1. 💡 **사용 가이드 (`HelpCircle`)**: 기본 사용법 및 꿀팁 팝업 안내
2. ⚙️ **API 키 설정 (`Settings`)**: Gemini API 키 등록 및 상태 조회
3. 🎲 **주사위 전체 옵션 랜덤 믹스 (`Dices`)**: 클릭 시 외형, 표정, 포즈, 의상, 장소, 조명, 피부 텍스처 등 전체 옵션을 트렌디하게 무작위 믹스 (180도 회전 애니메이션)
4. 📊 **작업 히스토리 (`Sliders`)**: 생성했던 화보와 캡션, 설정값을 브라우저 로컬 저장소에 안전하게 보관하여 언제든 다시 불러오기 및 다운로드 가능

## 7. 자주 묻는 질문 (FAQ)

**Q1. 이미지 생성이 실패하거나 오래 걸립니다.**  
A. 등록된 Google Gemini API 키가 올바른지 확인해 주십시오. 구글 무료 티어의 경우 분당 요청 수(RPM) 제한이 있으므로 약 10초 후 다시 시도해 주시기 바랍니다.

**Q2. 한국인 인플루언서로만 생성되나요?**  
A. 기본값은 한국인(동아시아인) 인플루언서로 최적화되어 있으나, Step 1의 국적 옵션에서 일본, 미국, 프랑스 등 30여 개국 중 원하는 국적을 자유롭게 선택하실 수 있습니다.

**Q3. 생성된 이미지를 상업적으로 사용할 수 있나요?**  
A. 사용자 본인의 Gemini API 키로 생성된 결과물이므로 마케팅, SNS 채널 운영, 쇼핑몰 상세페이지 등에 자유롭게 활용하실 수 있습니다.
