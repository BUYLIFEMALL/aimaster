- **버전**: `v1.05`
- **도메인**: `ai-influencer.buylife.xyz`
- **프로그램 명칭**: **AI 인플루언서 자동화 (AI Influencer Studio)**
- **정체성**: 인스타그램 및 SNS 마케팅에 즉시 활용 가능한 초현실적(Hyper-realistic) AI 가상 인플루언서 화보 및 3종 맞춤 캡션(해시태그 포함) 자동 생성 스튜디오

## 핵심 엔진 & 주요 기능

0. **AIMaster 메인 지침 준수 좌측 표준 사이드바 메뉴 (`docs/SIDEBAR_LAYOUT_STANDARD.md`)**
   - 상단 프로그램명 + 버전 배지(`v1.05`) + `← 다른 프로그램 보기`
   - `🏠 대시보드` 진입점
   - 번호형 핵심 작업 흐름 (원형 배지 + 연결선):
     - Step 1: 외형 스타일링 (`#step-1-appearance`)
     - Step 2: 일과 & 앵글 기획 (`#step-2-routine`)
     - Step 3: 표정·포즈 & 연출 (`#step-3-styling`)
     - Step 4: 광고/공구 모드 (`#step-4-admode`)
     - Step 5: 화보 & 캡션 생성 (`#step-5-generate`)
   - 하단 구분선 아래:
     - `🔑 API키등록·플랫폼연동`
     - `💡 사용 가이드`
     - `⚙️ 작업 히스토리`
     - 회원 이메일 및 로그아웃 폼 바짝 밀착 (2026-10-12 주인님 확정 규격)


1. **초정밀 이미지 생성 엔진 (Gemini 3 Pro Image Preview)**
   - 1K / 2K / 4K 초고해상도 렌더링 지원
   - 비율 지원: 1:1 (정사각형 피드), 9:16 (릴스/스토리), 16:9 (시네마틱), 3:4 (클래식 화보)
   - 카메라 3각 시점 제어:
     - `MIRROR SELFIE`: 거울 셀카 (스마트폰 기기 노출)
     - `FRONT-FACING HANDHELD SELFIE`: 전면 셀카 (기기 프레임 밖)
     - `THIRD-PERSON VIEW`: 타인이 찍어준 에디토리얼 모델 화보
   - 피부 텍스처 30종 멀티 조합: 초정밀 모공, K-Glass 물광, 복숭아빛 솜털, 땀, 주근깨 등

2. **AI 일과 플래닝 & 변형 엔진 (Gemini 3 Flash Preview)**
   - 하루 일과 문장 입력 시 5개 타임라인 시나리오 자동 기획 (시간대, 의상, 장소, 조명, 렌즈 자동 세팅)
   - 20가지 대표 K-인플루언서 일과 프리셋 (주사위 버튼)
   - 단일 이벤트 5각 앵글/분위기 변형 기획 (셀카, 전신, 소품 감성컷 등)

3. **광고 / 공구 모드 (Ad Mode & PPL 합성)**
   - 제품 사진 최대 3장 업로드 시 1:1 자연스러운 합성
   - 5대 광고 유형: 공동구매, 단순협찬, 브랜디드 콘텐츠, 앰버서더, 내돈내산

4. **레퍼런스 이미지 일관성 유지**
   - 인물 고정 사진: 모델 이목구비 일관성 유지 (헤어스타일 고정 지원)
   - 장소 고정 사진: 특정 공간 인테리어/조명 유지

5. **인스타그램 3종 캡션 & 2중 피드백 미세 보정**
   - 옵션 1: 감성/스토리텔링형
   - 옵션 2: 위트/트렌디 MZ형
   - 옵션 3: 질문/소통형
   - 2중 피드백: 캡션 다시 작성 + 이미지 미세 보정 (직전 결과 기반 연속 수정)

## 보안 및 플랫폼 규칙

- **최상위 불변 규칙**: 사용자 본인 Gemini API 키 (`user_api_keys.provider = 'gemini'`) 직접 등록 및 연동. 타인/운영자 키 폴백 원천 금지.
- **테마 규칙**: 클린 화이트 스튜디오 테마 (`bg-white` / `bg-slate-50`).
- **권한 체계**: AIMaster 공유 Supabase DB 통합 세션 및 `requireProgramAccess()`.
- v1.02 (2026-10-12): 핸드폰 번호 필수 정책 적용 — 핸드폰 번호가 없는 회원(관리자 제외)은 이용할 수 없고 메인 사이트 설정에서 번호를 등록하도록 안내합니다. 공용 규칙은 루트 `lib/utils/phone.ts`, 상세는 `docs/HANDOFF.md` 2026-10-12 항목.
