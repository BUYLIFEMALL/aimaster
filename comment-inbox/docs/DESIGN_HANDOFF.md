- **색 토큰**(`tailwind.config.ts`의 `ig-*`): 배경 `#0d0f17`, 표면 `#161922`, 띄운 표면 `#1f2433`, 테두리 `#262c3d`, 글자 `#f1f5f9`, 흐린 글자 `#94a3b8`, 포인트 `#ec4899`(핑크) + 핑크→보라 그라디언트, 성공·경고·위험 토큰.
- **구성**: 좌측 메뉴(브랜드 📥 + 버전 → 받은편지함 전체·플랫폼별 건수 → 원래 프로그램 바로가기 → 사용 매뉴얼 → 계정, 메뉴 바로 아래 계정), 머리 카드(제목·검토 대기·4시간 안 DM), 권한 없는 프로그램 안내 줄, 항목 카드(플랫폼 칩 색: 인스타 핑크·DM 보라·쓰레드 회색·유튜브 빨강).
- **휴대폰(767px 이하)**: 좌측 메뉴 숨김 + 위쪽 ☰ 접는 메뉴, 카드 버튼 높이 40px 이상. 400px에서 가로 넘침 없음 확인(2026-10-21 크롬).
